### 你知道吗？

我们最近添加了对拉取请求 (PR) 工作流程的改进，可帮助贡献者帮助 _you_ 了解他们对 Astro 代码库所做的更改。

我们的新工作流程会自动检查任何变更集并根据我们的 [changeset writing and style guidelines](https://contribute.docs.astro.build/docs-for-code-changes/changesets/) 进行验证。 它帮助我们确保对更改有帮助且一致地描述，重点关注面向用户的更改，以便读者在涉及到您自己的项目中的代码时始终知道实现细节的含义。 而且，此工作流还将捕获诸如不正确的降价标题级别，当您的更改集添加到完整 `CHANGELOG.md` 时会破坏格式。

我们为 Astro 致力于记录我们的代码更改而感到自豪，从补丁版本到主要升级指南。 感谢 [![](/_astro/matt.DK7kFqz2.webp)Matt Kane](https://bsky.app/profile/mk.gg “关注 Bluesky 上的 Matt Kane”) 贡献了这个功能！

更改会添加一个新的工作流，用于检查任何添加的变更集并根据准则对其进行验证。 它检查措辞，例如不正确的动词，使用不正确的标题来破坏格式，以及...

提示和工具
-------------

最新的社区构建的 [utilities and integrations](/integrations/) 可帮助您使用 Astro 构建。 🛠

*   [Astro Takumi](https://github.com/vikas5914/astro-takumi) - 使用 Takumi 为您的 Astro 网站生成开放式图形图像。
*   [Astro Open Telemetry](https://github.com/dvelasquez/astro-prometheus-integration/tree/main/packages/astro-opentelemetry-integration) - 为在 Node.js 上运行的 Astro 站点提供全面的 OpenTelemetry 可观察性。
*   [Astro Layout Grid](https://github.com/iaslfw/astro-layoutgrid) - 一种轻量级、零依赖性的响应网格覆盖组件，用于帮助开发人员将内容与视觉精度保持一致。
*   [Astro Tree View](https://www.npmjs.com/package/@pindoba/astro-tree-view) - 用于 Astro 应用程序的灵活且可访问的树视图组件。
*   [Astrolab UI](https://www.npmjs.com/package/astrolab-ui) - Astrolab 将您的所有存储库的 Astro 组件带到一个地方，您可以在其中查看和修改您的道具和插槽。
*   [Astro LinkedIn Insight](https://github.com/icruzdevelopment/astro-linkedin-insight) - 将 LinkedIn Insight 标签集成到您的网站中的 Astro 组件和辅助功能。
*   [Astro Awaited](https://github.com/matheusbronca/astro-awaited) - 允许您在获取服务器端数据时渲染回退占位符
*   [Astro PlantUML](https://www.npmjs.com/package/@thwbh/astro-plantuml) - 用于在 Markdown 文件中渲染 Plantuml 图的 Astro 集成。
*   [Mux Uploader Astro](https://www.npmjs.com/package/@mux/mux-uploader-astro) - 一种多功能多功能的 Astro 视频上传组件。
*   [Mux Player Astro](https://www.npmjs.com/package/@mux/mux-player-astro) - 一种复式风格的 Astro 视频播放器组件。
*   [Astro Utils](https://www.npmjs.com/package/@jaydixit/astro-utils) - 用于 Astro 项目的实用组件和插件的集合。
*   [Basis UI](https://github.com/zhengyishen0/basis-ui) - 纯粹为 Astro 设计的 SHADCN 风格组件库。
*   [Astro Favi Link](https://github.com/gingerchew/astro-favi-link) - 轻松地将时尚的图标添加到您的外部链接。
*   [Spiderseek Astro Analytics](https://github.com/spiderseek/astro-analytics) - SpiderSeek AI 分析和跟踪的 Astro 集成。
*   [Astro Create Portal](https://github.com/Bl4cky99/astro-create-portal) - Astro 5+ 的无头门户原语，可让您以声明性方式将标记投影到文档头和 DOM 中的其他任何地方。

……还有一些是用 Astro 建造的！

*   [Z-Links](https://zlinks.netlify.app/) - 使用 Z-Links，您可以将所有链接整理到文件夹中，从而使书签、团队资源和项目整齐可访问。
*   [Git Diff Viewer](https://github.com/trueberryless-org/git-diff-viewer) - 查看自特定日期以来公共 GitHub 存储库上的文件差异。
*   [EventCatalog](https://www.eventcatalog.studio/) - 用于分布式系统的专用图表。
