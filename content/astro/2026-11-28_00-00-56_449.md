我们很高兴欢迎 [Stainless](https://www.stainless.com/) 成为 Astro 项目的新官方赞助合作伙伴，随着由 Astro 驱动的新 [Stainless Docs Platform](https://www.stainless.com/products/docs) 的发布！

Stainless 已经成为团队构建高质量、易于使用的 API 的首选平台。Stainless 直接从您的 API 规范生成强大的 SDK，并自动在每种语言中保持更新。今天，[Stainless Docs Platform](https://www.stainless.com/products/docs) 的 Early Access 发布，您还将获得一个美丽的文档网站，用于您的 SDK 和 API，该网站会自动与您的规范保持同步。通过选择 Astro，Stainless 确保他们生成的每个文档网站都快速、可访问且易于维护。

阅读来自 Stainless 的 [发布帖子](https://www.stainless.com/blog/stainless-docs-early-access) 以了解更多信息。

> 因为 Stainless Docs 平台建立在 Astro 提供的坚实基础上，开发者获得了极好的开发体验（DX）、可扩展性以及部署到任何地方的能力。对于最终用户，生成的网站感觉很棒，加载速度几乎瞬间。我们非常高兴成为 Astro 社区的最新成员。

— Alex Arena，Stainless Docs 产品负责人

## API & SDK 的即时文档

Stainless Docs 作为单个 Astro 集成集成到您的代码库中。一旦设置完成，它就会自动将完整的文档、API 和 SDK 参考文档添加到您的文档站点。

在内部，它建立在 [Starlight](https://starlight.astro.build/) 之上，Starlight 是 Astro 的官方文档主题。Starlight 是一个快速且灵活的文档框架，已经被 Cloudflare、Google、GitHub、GitLab、Microsoft、Netlify、OpenAI、WPEngine 和无数其他公司使用。随着 Stainless 建立在 Starlight 之上，他们意识到可以将自己的工作提取到单个 Astro 集成中——去除对 Starlight 的间接依赖，同时保留 Starlight 的组件库、搜索体验和高度灵活的自定义功能。

阅读完整的 [发布帖](https://www.stainless.com/blog/stainless-docs-early-access) 以了解更多关于 Stainless Docs 平台的信息。 在接下来的几个月里，Stainless 还将发布一个独立的 Starlight 插件，该插件将为任何现有的 Starlight 网站添加 API/SDK 参考页面，适用于希望将 Stainless Docs 平台集成到现有网站的开发人员。
