[Evil Martians](https://evilmartians.com/) 是 DevTools、网络安全和 AI 初创公司的设计和工程咨询公司。 他们的网站还拥有火星编年史，这是一个每年有 500,000 名开发人员阅读的技术博客。

连续三年，邪恶的火星人无法为从盖茨比的网站迁移辩护，即使该框架正在倒闭。 对于一个繁忙的咨询公司来说，这意味着将工程师从客户项目中拉下来，这是一个昂贵且费力的前景。 但令团队惊讶的是，在 2026 年 8 月，**一位工程师在短短 9 天内将整个网站移至 Astro**。

主页 JavaScript 总体上下降了 61%，移动灯塔的性能得分从 66 上升到 90。如果不改变任何现有的 React 组件，他们的主页重量从 2.1 MB 减少到 1.8 MB。 在优化了他们的水合作用策略并完全转换为 Astro [islands architecture](https://docs.astro.build/en/concepts/islands/) 之后，团队看到这一下降到 1.1 MB。

![Homepage weight is 48% less, JavaScript at load is now 61% less, and Mobile Lighthouse scores are up 24 points.](/_astro/evil-martians-metrics.Dmky6Y6T_Z2riruy.webp)

邪恶火星人迁移到天文的改进

挑战
-----------

邪恶的火星人意识到盖茨比不可能成为他们的企业网站和博客基础设施的未来。 随着他们的网站增长到 1000 多个 HTML 页面，维护成本和代码脆弱性随着时间的推移而加速：

*   **17 Gatsby Plugins** 在 `package.json` 中与框架本身以及 **4 依赖项** 需要手写的补丁才能运行。
*   ** GraphQL 数据层** 位于静态站点前，组件和页面通过 Gatsby 特定的钩子提取其数据。
*   **依赖性安全咨询积累**，没有可用的上游修复，在一棵树中，没有人会更新。
*   **具有专业盖茨比知识的邪恶火星人的缩小池**可以安全地触摸代码。

他们需要迁移到现代框架以减少技术债务并保持网站的可维护性。 但他们也需要尽可能少的停机时间来做到这一点。

要求
-------------

邪恶的火星人团队正在寻找一种使迁移可管理的方法。 他们确定了三种不可转让：

*   无论更换 Gatsby 的任何内容都必须**接受现有的 React 组件**。
*   **Gatsby 的 GraphQL 层需要一个有效的替换**，它将涵盖页面、组件和自定义内容管道，而不会成为自己的迁移。
*   新框架必须与旧框架一起**构建在同一仓库中**。 这将允许他们在允许的时间和资源允许的情况下迁移，在旧路由可用时将新路由交换。

幸运的是，Astro 检查了所有三个盒子。

解决方案和实施
----------------------------

Astro 与框架无关的岛屿架构和强大的插件生态系统使 Gatsby 的迁移变得简单。 Astro 的第一方 React 集成意味着现有的组件库无需任何更改即可移植。

> ASTRO让我们快速发货。 我们首先从整页岛开始，然后完善我们的补水策略。 由于我们的 React 组件保持完好，LLM 可以处理大部分重复的翻译。

——Rita Klubochkina，邪恶火星人的前端工程师

Astro 的内容集合取代了 GraphQL 层，完全不需要更改团队的自定义内容管道。 现有的 LiquidJS 和 JSX 变压器继续运行，仅在内容集合加载器之后，而不是 Gatsby GraphQL 解析器。

结果
--------

邪恶的火星人面临着一个老化的框架，一个对静态站点来说太过分的 GraphQL 层，以及一个缩小的工程师池来维护它。

迁移到 Astro 使团队能够逐步重构现有的 React 组件，最终使用 Astro 的细粒度控制来独立地水合每个部分。 仅此更改就将加载时 JavaScript 的数量减少了 61%。

岛屿还清楚地表明了该地点的哪些部分很重。 团队发现主页上最重的元素是网站搜索模式。 以前，无论打开与否，这都是在每一页的前面加载的。 将此推迟到首次打开，因为岛上删除了整个站点的 437 KB 加载时间 JavaScript。

删除 GraphQL 层也会删除其昂贵的预取行为。 Gatsby 提取了 13.6 MB 的查询结果，用于尚未单击的链接，是页面本身重量的六倍多。 Astro 的预取功能优化了导航，但不那么激进，只是在悬停时预取链接页面。

此外，邪恶的火星人通过减少依赖来提高性能和安全性。 17 个 Gatsby 插件和 4 个修补的依赖项现在消失了。 `package.json` 从 108 下降到 86 直接依赖。
