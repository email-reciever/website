在 i18n 后备中重写
---------------------------

[internationalization (i18n) routing](https://docs.astro.build/en/guides/internationalization/) 中添加了一个新选项，它允许更多地控制回退的方式。 您现在可以指定回退是否会导致重写（来自服务器的 `200` 响应）或重定向，即当前默认值。

i18n 中的回退系统允许您在用户的区域设置中定义该内容不可用时用于区域设置的内容。 例如，您的配置可能如下所示：

从“astro/config”导出默认 defineConfig({ i18n: { defaultLocale: "en", locales: ["es", "en", "fr"], fallback: "es" }, 路由: { fallbackType: “重写” } }})

有关此新功能的更多信息，请参阅 [our revamped documentation on handling fallbacks in i18n](https://docs.astro.build/en/guides/internationalization/#fallback)。

Astro DB中的Libsql远程
---------------------------

您现在可以将 [libSQL](https://turso.tech/libsql) 服务器实例指定为 `@astrojs/db` 的远程实例。 这允许您自主托管您自己的 Libsql 服务器，以替代将 Astro DB 与 Astro Studio 结合使用。 此选项适用于任何受支持的 LibSQL 协议。

要使用此功能，请设置以下环境变量：

*   `ASTRO_DB_REMOTE_URL`：与 Libsql 服务器的连接 URL。
*   `ASTRO_DB_APP_TOKEN`：对您的 libsql 服务器的 auth 令牌。

启用此功能允许您在生产环境中连接到 LibSQL 服务器，还允许您使用 Astro DB 部署和与 Libsql 实例的推送（迁移）命令。 感谢 [Fryuni](https://github.com/Fryuni) 的惊人贡献！

有关在 Astro DB 中使用 LibSQL 服务器的更多信息，[visit our Astro DB guide](https://docs.astro.build/en/guides/astro-db/#libsql)。

`client:idle`中的超时选项
------------------------------

当用户的 CPU 处于空闲状态时，`client:idle` 指令用于加载 [Astro Island](https://docs.astro.build/en/concepts/islands/)（没有其他 JavaScript 执行）。 在引擎盖下，此功能依赖于浏览器的 [requestIdleCallback](https://developer.mozilla.org/en-US/docs/Web/API/Window/requestIdleCallback) 功能。

在 Astro 4.15 中，您现在可以指定一个 `timeout` 属性，该属性将触发水合，以确保您的元素在指定的时间范围内是交互的。 这有助于为可能与其他空闲组件竞争的组件添加优先级。

{/* 组件在最大等待 500ms 后加载组件 */}<Counter id="client-idle-timeout" {...someProps} client:idle={{ timeout: 500 }}> <h1>Hello, Client:Idle={'{{Timeout: 500}}'}!</h1></Counter>

感谢 [ph1p](https://github.com/ph1p) 的贡献。

ViewTransitions 的交换助手
--------------------------------

Astro 的 `<ViewTransitions />` 路由器为您提供单页应用程序 (SPA) 的 UX，同时保留了 Astro 多页应用 (MPA) 的 DX。 它通过获取有关导航的页面并将内容交换为客户端路由来做到这一点。 在某些情况下，您可能希望对交换的工作方式进行更多控制，这可以通过在 [`astro:before-swap`](https://docs.astro.build/en/guides/view-transitions/#astrobefore-swap) 事件中覆盖交换来完成。

在 Astro 4.15 中，内置交换函数现在从 `astro:transitions/client` 中导出。 这些助手允许您使用 Astro 默认执行的部分内容，并在两者之间添加您自己的自定义逻辑。
