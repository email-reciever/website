我们很高兴宣布 [Cloudinary](https://cloudinary.com/) 作为 Astro Content Layer API 的发布合作伙伴，这是我们将外部内容引入 [content collections](https://docs.astro.build/en/guides/content-collections/) 的新方法。 Cloudinary 是一个用于媒体资产的托管平台，可让您转换和优化媒体类型。

内容集合是 Astro 对有组织、管理、类型安全的内容的回答。 现在使用 Astro 的内容层，您可以在构建期间从外部来源引入所有不同类型的内容和数据。 Content Layer API 有效地同步和缓存内容，为您提供熟悉的、统一的处理任何数据源的体验。

使用 Cloudinary 加载器
----------------------------

要使用新的加载程序，首先从 npm 安装 `astro-cloudinary` 包：

npm 安装 Astro-Cloudinary

接下来，您需要使用 API 密钥配置您的环境。 有关详细信息，请参见 [Cloudinary loader configuration guide](https://astro.cloudinary.dev/installation)。

然后导入并使用 `src/content/config.ts` 配置文件中的加载程序：

从“astro:content'import { CLDASsetsLoader }”导入 { defineCollection } 来自“astro-cloudinary/loaders”
const samples = defineCollection({ loader: cldassetsloader({ limit: 4, folder: 'samples/food' })})
导出常量集合 = { 资源 }

就是这样！ 从这里，您可以像对本地集合一样查询和使用集合。 请参阅 Astro Docs [content collections guide](https://docs.astro.build/en/guides/content-collections/) 以了解更多信息。

有关使用 Cloudinary 加载器的更多阅读，请阅读 [Source Cloudinary Assets in Astro With the Astro Content Layer](https://cloudinary.com/blog/source-cloudinary-assets-astro-content-layer) 其中包含更多详细信息。 另请查看昨天在新内容层 API 上的 [deep dive](/blog/content-layer-deep-dive/)，了解加载器的工作原理以及如何构建自己的。
