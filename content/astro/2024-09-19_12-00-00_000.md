我们很高兴地宣布 [Hygraph](https://hygraph.com/) 作为 Astro Content Layer 的发布合作伙伴，这是我们将外部 CMS 内容引入 [content collections](https://docs.astro.build/en/guides/content-collections/) 的新方法。 Hygraph 是一款 API 优先的 CMS，可让您使用任何前端技术组织复杂、结构化的内容并构建高性能、内容驱动的应用程序。

Content Collections 允许您将各种类型的内容组合成一个 API。 使用内容层，现在包括从各种外部来源引入内容，例如 HyGraph CMS。

使用 hygraph 加载器
-------------------------

要使用新的加载器（处于测试阶段），首先安装 `@hygraph/hygraph-astro-loader` 包：

npm 安装 @hygraph/hygraph-astro-loader

在 HyGraph 仪表板中，找到 API 的端点并复制 URL 并将其作为环境变量提供，并将其命名为 `HYGRAPH_ENDPOINT`。

然后导入并使用 `src/content/config.ts` 配置文件中的加载程序：

import { defineCollection, z } 来自 'astro:content';import { hygraphloader } 来自 '@hygraph/hygraph-astro-loader';
const pages = defineCollection({ loader: hygraphloader({ endpoint: import.meta.env.hygraph_endpoint, operation: 'pages', fields: "id", "title", "slug", { "body": ["text"] }], }),
模式：z.object({ id: z.string(), title: z.string({ required_error: 'required' }).min(1, { message: 'title 必须至少是 1 个字符' }), slug: z.string(), body: z.Object({ 文本: z.string(), }), })})
导出常量集合 = { 页 }

就是这样，从这里您可以像本地集合一样查询和使用集合。 请参阅 [content collections](https://docs.astro.build/en/guides/content-collections/) 上的 Astro 文档以了解更多信息。

还可以查看昨天的内容层上的 [deep dive](/blog/content-layer-deep-dive/)，了解加载器的工作原理，以及如何构建自己的。 还可以查看 Hygraph 加载程序的 [GitHub repo](https://github.com/hygraph/hygraph-astro-loader) 以报告问题并做出贡献。
