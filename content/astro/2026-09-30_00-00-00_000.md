查看一些最新的社区构建的 [utilities and integrations](/integrations/) 以帮助您使用 Astro 构建。 🛠

*   [@astroscope/react](https://github.com/entwico/astroscope/tree/main/packages/react#readme)：为 Astro Islands 调谐的 React，为服务器调谐。

*   [@igorskyflyer/astro-saferesource](https://github.com/igorskyflyer/npm-astro-saferesource)：为您的网站添加符合 CSP 的内联脚本和样式的 Astro 集成。
*   [@qymera/effects](https://www.npmjs.com/package/@qymera/effects)：Astro 的自由、微小的、原生优先运动原语，完全由 `data-q-*` 属性驱动。
*   [@sudodevstudio/astro-ai](https://github.com/SudoDevStudio/astro-ai#readme)：仅限开发人员使用 AI 工具，用于 Astro 项目。

*   [@typed/astro](https://github.com/TylorS/typed-smol/tree/main/packages/astro#readme)：类型化的 HTML 模板和水合岛的 Astro 集成。

*   [astro-feedback](https://www.npmjs.com/package/astro-feedback)：用于在 Viewport 分隔的页面上收集设计/开发反馈的轻量级 Astro 集成。 仅开发和分期。
*   [astro-feedback-board](https://github.com/SlashGordon/astro-feedback-board#readme)：对 Astro 网站的匿名、审核反馈：反馈按钮、内联问卷和公共板，由 Cloudflare 工作人员支持。
*   [astro-flag](https://pascal-brand38.github.io/astro-dev/packages/astro-flag/)：在 Astro 中添加一个响应式国家标志，作为内联的 SVG。
*   [astro-iconify-component](https://github.com/Avaray/astro-iconify-component#readme)：Astro的内联SVG图标。 完全打字，默认可访问，顺风友好。
*   [astro-if](https://gitlab.com/net.christianto/deps/astro-if#readme)：Astro的声明式条件渲染组件（if / then / else / when / 除非 / switch / case）。 对于那些讨厌三角形的人来说，从 React-If 中无耻地抄袭。
*   [astro-image-zoom](https://github.com/antoniohg/astro-image-zoom)：Astro的中型图像缩放：可访问，页面动画，带有可滑动的画廊。
*   [astro-pkg-stats](https://github.com/MrGKanev/astro-pkg-stats#readme)：显示 npm 和 packagist (composer/laravel) 的 Astro 组件和帮助程序下载您的软件包的统计信息。
*   [astro-refs](https://www.npmjs.com/package/astro-refs)：Sphinx风格的Astro命名refs：在任何地方声明锚点，按名称链接，内容移动时保持有效
*   [astro-tweet-card](https://www.npmjs.com/package/astro-tweet-card)：用于渲染推文卡片的 Astro 组件。
*   [astro-xitter](https://github.com/Namchee/astro-xitter#readme)：将 Xitter Post 嵌入您的 Astro 网站。
*   [daisy-astro](https://github.com/ok-98/daisy-astro#readme)：ASTRO 组件适用于每一个 Daisyui 5 组件，其中每个 Daisyui 变体是一个类型化的道具，并且每个本机 HTML 属性都被转发。
*   [remark-myanmar-reading-time](https://github.com/kalixlouiis/remark-myanmar-reading-time#readme)：缅甸（缅甸）脚本和 Astro、Next.js 和 Remark 中混合语言内容的准确读取时间计算器。
