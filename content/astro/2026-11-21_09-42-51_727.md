### 提示和工具

最新的社区构建的实用程序和集成，可帮助您使用 Astro 构建。

*   [`astro-react-i18next`](https://github.com/jeremyxgo/astro-react-i18next) - 将 i18next 和 react-i18next 无缝集成到您的 Astro 网站中，为 React 组件提供强大的 i18n 支持。
*   [Astro Resend](https://www.npmjs.com/package/@hbertoson/astro-resend) - 使用 Astro 项目中的 Resend 轻松发送表单提交的电子邮件通知。
*   [DeWP](https://delucis.github.io/dewp/) - 在 Astro 项目中使用您的 WordPress 数据
*   [`starlight-site-graph`](https://github.com/fevol/starlight-site-graph/) - 将图形组件添加到站点右侧栏中的星光插件。
*   [Astro NPM Loader](https://www.npmjs.com/package/astro-npm-loader) - 将有关 npm 包的信息加载到内容集合中。
*   [Local AstroDB Viewer](https://marketplace.visualstudio.com/items?itemName=YuriAlvesGuernsey.localastrodb) - 直接在 Visual Studio Code 中查看 .db 文件并与之交互。
*   [Astro Mail Obfuscation](https://www.npmjs.com/package/astro-mail-obfuscation) - 使用基于 XOR 的混淆保护 Astro 应用程序的源代码中的电子邮件地址和电话号码。
*   [`react-alpine-store`](https://www.npmjs.com/package/react-alpine-store?activeTab=readme) - 允许跨 React 和 Alpine 的 $store 之间的反应状态之间进行同步。 在此处查看有关 Alpine $STORE 的更多信息。
*   [Expressive Code Color Chips](https://delucis.github.io/expressive-code-color-chips/) - 为您的 CSS 代码示例添加颜色预览的插件
*   [Astro AO3 loader](https://github.com/FujoWebDev/fujocoded-plugins/tree/main/astro-ao3-loader) - 用于 ASTRO 的 AO3 数据加载器，使用实验内容层和 ao3.js 将数据从 AO3 加载到您的 Astro 网站。
*   [Portal Gun](https://inox-tools.fryuni.dev/portal-gun) - 用于在定义它们的组件之外添加 HTML 元素的服务器端门户。
