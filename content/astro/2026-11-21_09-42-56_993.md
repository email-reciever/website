自从添加了对 Astro Content Layer API 的实验支持以来，我们已经看到几个加载器正在为各种类型的内容构建。 我们已经强调了一些构建装载机的 CMES。 在这篇文章中，我们将介绍一些其他类型的加载器，以查看内容层的不同用例。

我们将在这里介绍的装载机是：

*   **[Notion](#notion)**
*   **[Stripe](#stripe)**
*   **[Feed loader](#feed-loader)**
*   **[Airtable](#airtable)**
*   **[Strapi](#strapi)**

概念
-------

概念是所有类型文档的协作平台。 虽然它通常不被认为是一种 CMS，但许多人确实将其作为一种使用。

使用 [notion-astro-loader](https://www.npmjs.com/package/notion-astro-loader) 您可以将概念文档同步到项目的集合之一中。 加载器会根据概念数据库的模式自动推断出模式。

安装 `notion-astro-loader` 并像这样配置它：

import { defineCollection } 从 "Astro:Content";import { notionLoader } 从 "notion-astro-loader";
const database = defineCollection({ loader: notionloader({ auth: import.meta.env.notion_token, database_id: import.meta.env.notion_database_id, filter: { property: "hidden", checkbox: { 等于：假 }, }, }),});
导出常量集合 = { 数据库};

进料装载机
------------

[Astro feed loader](https://github.com/ascorbic/astro-loaders/tree/main/packages/feed) 允许您加载 RSS、RDF 和 Atom 提要，并使用 Astro 站点中的数据。 有很多用例，因为 RSS 是一种广泛使用的出版格式。 例如，您可以在您的网站上 [use RSS to show recent releases for GitHub projects](https://hideoo.dev/notes/starlight-list-recent-github-releases)。

要使用加载器，请安装 `@ascorbic/feed-loader` 包并将指向的集合定义为 Feed URL ，如下所示：

import { defineCollection } 从 "astro:content";import { feedLoader } 从 "@Ascorbic/Feed-Loader";
const releases = defineCollection({ loader: feedLoader({ url: "https://github.com/withastro/astro/releases.atom", }),})
const podcasts = defineCollection({ loader: feedLoader({ url: "https://feeds.99percentinvisible.org/99percentinvisible", }),})
导出 const 集合 = { 发布，播客 }

条纹
-------

使用 [Stripe loader](https://github.com/notrab/stripe-astro-loader) 您可以从 Stripe API 中提取产品和价格信息。

要使用它，您需要 `stripe-astro-loader` 和 `stripe` 包。 使用 API 密钥创建 `Stripe` 的实例，然后将其传递给加载器，这就是您需要做的一切。

import { defineCollection } 从 "astro:content";import { StripePriceLoader, StripeProductLoader } 来自 "Stripe-Astro-Loader";导入条带从 "Stripe";
常量条带 = 新条纹（“<API_KEY>”）；
const products = defineCollection({ loader: StripeProductLoader(stripe),})
const prices = defineCollection({ loader: StripePriceLoader(stripe),})
导出常量集合 = { 产品，价格 }

空气表
---------

Airtable 是一种组织数据和构建无代码应用程序的方式。 使用 [Airtable loader](https://github.com/ascorbic/astro-loaders/tree/main/packages/airtable) 您可以从 Airtable 基地加载记录并在 Astro 项目中使用它们。

AirTable 装载机可从 `@ascorbic/airtable-loader` 包中获得。 从环境变量提供 API 密钥，并使用加载器加载表。

import { defineCollection } 从 "astro:content";import { airtableLoader } 从 "@Ascorbic/Airtable-Loader";
const launches = defineCollection({ loader: airtableLoader({ base: import.meta.env.airtable_base, table: "product launches", }),})
导出常量集合 = { 启动 }

带子
-------

[Strapi](https://strapi.io/) 是一种开源无头 CMS，可以自托管或与 Strapi Cloud 一起使用。 使用 Strapi，您可以创建集合和自定义内容类型。

开发的新社区 [Strapi loader](https://www.npmjs.com/package/strapi-community-astro-loader) 可让您将内容拉到本地收藏中。 要使用它，请从 npm 安装 `strapi-community-astro-loader`。 在您的内容集合配置 (`src/content/config.ts`) 中，创建一个集合并使用您要同步的 `contentType` 调用加载程序。 在这个例子中，我们抓取所有远程文章并将它们同步到一个名为 `posts` 的集合中。

import { defineCollection } 从 "astro:content";import { strapiLoader } 来自 "strapi-community-astro-loader";
const posts = defineCollection({ loader: strapiLoader({ contentType: "article" }),})
导出常量集合 = { 帖子 }

另请参阅 Strapi 博客文章 [How To Create a Custom Astro Loader for Strapi Using Content Layer API](https://strapi.io/blog/how-to-create-a-custom-astro-loader-for-strapi-using-content-layer-api)。
