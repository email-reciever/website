本月，一群专门的社区志愿者[translated the official Astro Docs Tutorial into German](https://github.com/withastro/docs/pull/12502)！ 10 人，33 个文件更改，51 天，96 次提交！ 请加入我们的热情“Vielen Dank！” 如果您有兴趣将 Astro Docs 翻译成您的语言，请查看我们的 [i18n contributing docs](https://contribute.docs.astro.build/guides/i18n/)。

内容
--------

以下是本月引起我们注意的事情：

*   在 macOS 上使用 [Astro Editor](https://astroeditor.danny.is/) 为 Astro 内容集管理您的内容。 获取验证、交叉集合引用、带预览的图像字段和多框架 MDX 组件——所有这些都在受 IA Writer 启发的漂亮界面中。
*   在移动设备上管理您的内容：查看 Jonathan Yeong 寻找 [mobile-friendly headless CMS for Astro](https://jonathanyeong.com/writing/mobile-friendly-headless-cmss-with-astro/) 时发生的事情。
*   使用 [OpenCourse](https://opencourse.appwrite.network/) 出售您的内容：一个轻量级的开源平台，让内容创作者可以构建、托管和销售单一课程。 它提供了一个最小的、自托管的替代平台，可以替代 Teachable — 使用 Astro 构建！

*   [Astro Orbit](https://github.com/delta-incubator/astro-orbit) - 用于 ASTRO 项目的主题包，具有设计系统、可重用组件和 Tailwind CSS V4 集成。
*   [Astro Snapshot](https://github.com/twocaretcat/astro-snapshot) - 用于在构建时自动生成页面屏幕截图的 Astro 集成。
*   [Silk Astro](https://www.npmjs.com/package/@sylphx/silk-astro) - 用于 Silk 的 Astro 集成 - 具有岛屿架构和部分水合支持的零运行时 CSS-in-TypeScript。
*   [Scalar API Reference for Astro](https://github.com/scalar/scalar/tree/main/integrations/astro) - Astro 的标量 API 参考组件。
*   [EdgeOne Astro](https://www.npmjs.com/package/@edgeone/astro) - 将您的 Astro 站点部署到 EdgeOne 页面的适配器。
*   [Astro Auth](https://github.com/mridang/astro-auth) - Astro 集成，用于 Auth.js 的 Astro 集成，可与 Astro 中的多个提供者、会话管理和 UI 原语提供无缝身份验证。
*   [Astro Dynamic Assets](https://github.com/BearStudio/astro-dynamic-assets) - 使用 React 帮助您构建自定义图像，如 Open Graph Image、Instagram Post 等的 Astro 集成。
*   [Astro Trakt.tv Loader](https://github.com/LekoArts/astro-loaders/tree/main/packages/trakt) - 用于 Astro 内容层的 Trakt.tv 内容加载器。
*   [Astro HTML Minifier Next](https://github.com/jonasgeiler/astro-html-minifier-next) - 使用提供的 `html-minifier-next` 选项在构建过程中自动最小化由 Astro 生成的所有 HTML 资源的集成。
*   [AstroJS Atom](https://github.com/flcdrg/astrojs-atom) - 用于在 Astro 项目中生成 Atom RSS 提要的库。
*   [Vitest Browser Astro](https://github.com/ascorbic/vitest-browser-astro/) - 使用 Viste 浏览器模式在真实浏览器中测试 Astro 组件。
