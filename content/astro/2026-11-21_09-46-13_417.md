新：Astro 集成
------------------------

世界上有一些不可否认的真理：太阳会升起。 披萨味道鲜美。 开发人员喜欢定制他们的构建工具。

我们对前两个无能为力，但我们可以让 Astro 更容易为您定制。 您应该能够将您的框架（React vs. Svelte，Go！）、CSS 工具（Tailwind 与 Sass，Go！）以及包带入 Astro 中，只需几个按键即可。

**Astro Integrations** 是一个全新的概念，让这个梦想成为现实。 集成在几行代码中解锁了整个星系。

在接下来的两周内，我们将分享更多关于这方面的内容，但您可以立即开始探索新的 API [on our docs site.](https://docs.astro.build/en/guides/integrations-guide/)。 要将现有的 Astro 项目迁移到此新 API，[read through our migration guide](https://docs.astro.build/en/migrate/#astro-integrations)。

新：`astro add` 命令
-------------------------

为了使集成更易于使用，Astro V0.25 包含一个新的 _experimental_ CLI 命令：`astro add` 🚀

![astro add wizard to 1. enable frameworks 2. select other integrations 3. update your config 4. install all dependencies](/_astro/astro-add-demo.VaKzNPyL_1THrvL.webp)

运行 `astro add` 将引导您将新集成添加到您的项目中。 一旦您选择了要添加的集成，Astro 将自动对您的配置文件进行必要的更改，并将任何新的依赖项安装到您的项目中。

改进的构建 CLI 输出
--------------------------

到目前为止，`astro build` 命令拒绝告诉您超过两件事：

1.  您的构建已经开始。
2.  您的构建已完成。

通过在更大和更大的项目上测试 Astro，我们第一手知道长长的沉默永远不会非常鼓舞人心。 在幕后，有无数关于您的构建的细节被报告，但隐藏在调试日志中。

从 Astro v0.25.0 开始，这些细节现在是构建输出的前沿和中心，为您提供有关构建进展的有用信息。

立即尝试在您的项目中运行 `astro build` 以查看新的漂亮输出。 🚀

Astro + Shiki 语法 Highligher
------------------------------

我们喜欢找到“开箱即用”的明智默认设置。 在 Astro v0.25.0 中，我们作为新的默认语法高亮器迁移到 [Shiki](https://github.com/shikijs/shiki)。 Shiki 是一款功能强大的语法高亮器，可为您的前端代码块中的流行 VSCode 主题和语法突出显示开箱即用的支持。

如果您更喜欢将 Prism 保留为语法突出显示器，请不要担心。 您可以在项目配置中 [将 `syntaxHighlight` 选项设置为 `'prism'`](https://docs.astro.build/en/guides/markdown-content/#prism-configuration) 以保持之前的 v0.24.0 默认行为。

查看我们的新 [syntax highlighting docs](https://docs.astro.build/en/guides/markdown-content/#syntax-highlighting) 以获取完整详细信息。
