我们很高兴欢迎 [Stainless](https://www.stainless.com/) 作为 Astro 项目的新官方赞助合作伙伴，同时推出由 Astro 支持的新 [Stainless Docs Platform](https://www.stainless.com/products/docs)！

不锈钢已经是团队构建高质量、易于使用的 API 的首选平台。 不锈钢直接从您的 API 规范生成强大的 SDK，并在每种语言中自动保持最新状态。 随着 [Stainless Docs Platform](https://www.stainless.com/products/docs) 的提前访问，您还可以获得一个漂亮的文档站点，用于您的 SDK 和 API，它会自动与您的规范保持同步。 通过选择 Astro，不锈钢可确保他们生成的每个文档站点都快速、易于访问且易于维护。

从不锈钢中阅读[launch post](https://www.stainless.com/blog/stainless-docs-early-access)以了解更多信息。

> 因为不锈钢文档平台建立在Astro提供的强大基础之上，开发人员获得了出色的DX、可扩展性和部署到任何地方的能力。 对于最终用户，生成的网站感觉很棒，并且立即加载接近。 成为 Astro 社区的最新成员，我们感到非常兴奋。

— Alex Arena, 不锈钢文档产品线

API 和 SDK 的即时文档
-----------------------------

不锈钢文档作为单一的 Astro 集成集成到您的代码库中。 设置完成后，它会自动将完整的 PROSE、API 和 SDK 参考文档添加到您的文档站点中。

在内部，它建立在 Astro 的官方文档主题 [Starlight](https://starlight.astro.build/) 之上。 Starlight 是 Cloudflare、Google、GitHub、GitLab、Microsoft、Netlify、OpenAI、Wpengine 和无数其他人已经使用的 [fast](https://x.com/astrodotbuild/status/1979138579751174498) 和灵活的 Docs 框架。 作为基于星光的不锈钢，他们意识到他们可以将他们的工作提取到一个单一的 Astro 集成中——消除对星光的间接依赖性，同时保留星光组件库的强大功能、搜索体验和高度灵活的定制。

阅读完整的 [launch post](https://www.stainless.com/blog/stainless-docs-early-access) 以了解有关不锈钢文档平台的更多信息。 在接下来的几个月中，不锈钢还将发布一个独立的 Starlight 插件，将 API/SDK 参考页面添加到任何现有的 Starlight 网站，供希望将不锈钢 Docs 平台集成到现有网站的开发人员。
