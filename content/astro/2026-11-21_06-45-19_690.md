建立一个更快的网站有一个简单的秘诀——_Just Shipless_。

不幸的是，现代 Web 开发一直朝着相反的方向发展——朝着 _more._ 更多的 JavaScript、更多的功能、更多的移动部件，以及最终需要更多的复杂性来保持其顺利运行。

今天，我很高兴能公开分享 Astro：一种新型静态站点构建器，它提供了具有现代开发体验的快速性能。 为了设计Astro，我们借用了我们最喜欢的工具的最佳部分，然后添加了一些我们自己的创新，包括：

*   **自带框架（BYOF）：**使用React、Svelte、Vue、Preact、Web Components，或者只是简单的HTML + JavaScript构建您的网站。
*   **100% 静态 HTML，没有 js:** Astro 将您的整个页面呈现为静态 HTML，默认情况下从您的最终版本中删除所有 JavaScript。
*   **按需组件：**需要一些JS？ Astro 可以在页面上可见时自动补水。 如果用户永远看不到它，他们永远不会加载它。
*   **功能齐全：** ASTRO 支持 TypeScript、范围 CSS、CSS 模块、SASS、Tailwind、Markdown、MDX 和任何您最喜欢的 npm 包。
*   **SEO 启用：** 自动站点地图、RSS 提要、分页和集合消除了 SEO 和联合的痛苦。

这篇文章标志着 Astro 的第一个公开测试版。 **在这个早期阶段仍有望出现缺少的功能和错误。 当我们在今年晚些时候转向 V1.0 版本时，我们会很高兴您的早期反馈。

Astro 的工作原理
----------------

Astro 的工作方式很像静态站点生成器。 如果您曾经使用过 Enventy、Hugo 或 Jekyll（甚至像 Rails、Laravel 或 Django 等服务器端 Web 框架），那么您应该对 Astro 感到宾至如归。

在 Astro 中，您使用您最喜欢的 JavaScript Web 框架（React、Svelte、Vue 等）中的 UI 组件来编写您的网站。 Astro 在构建过程中将整个站点呈现为静态 HTML。 结果是一个完全静态的网站，所有 JavaScript 都从最后一页中删除。 不需要单一的 JavaScript 应用程序，只需在浏览器中尽可能快地加载的静态 HTML，无论您使用多少 UI 组件来生成它。

当然，有时客户端 JavaScript 是不可避免的。 图像传送带、购物车和自动完成搜索栏只是需要在浏览器中运行的一些 JavaScript 的示例。 这就是 Astro 真正闪耀的地方：当一个组件需要一些 JavaScript 时，Astro 只加载一个组件（和任何依赖项）。 您网站的其余部分继续以静态、轻量级的 HTML 形式存在。

在其他全栈 Web 框架中，如果不加载整个页面，则无法在 JavaScript 中加载整个页面，从而延迟交互性。 在 Astro 中，这种 [partial hydration](https://addyosmani.com/blog/rehydration/) 内置于工具本身中。

您甚至可以 [automatically defer components](https://codepen.io/jonneal/full/ZELvMvw) 仅在使用 `:visible` 修饰符在页面上可见时才加载它们。

这种 Web 架构的新方法称为 [islands architecture](https://jasonformat.com/islands-architecture/)。 我们没有创造这个词，但 Astro 可能已经完善了这项技术。 我们相信，以 HTML 为先、仅限 JavaScript 的方法是大多数基于内容的网站的最佳解决方案。

拥抱成功的深渊
-----------------------------

> 精心设计的系统使做正确的事情变得容易（但并非不可能）做错误的事情
> 
> 杰夫·阿特伍德，
> 
> [
> 
> 落入成功的坑
> 
> ](https://blog.codinghorror.com/falling-into-the-pit-of-success/)

性能不佳通常被认为是开发人员的失败，但我们恭敬地不同意。 在许多情况下，性能不佳是工具的故障。 建立一个缓慢的网站应该很困难。

Astro 的主要设计原则是引导开发人员进入 [Rico Mariani](https://twitter.com/ricomariani) 所说的“成功之坑”。 我们的目标是“默认快速”构建每个站点，同时提供熟悉的现代开发人员体验。

通过默认将您的站点构建为静态 HTML，Astro 使构建缓慢的站点变得困难（但绝不是不可能的😉）。

长期可持续性
-------------------------

Astro 由 [Snowpack](https://snowpack.dev) 和 [Skypack](https://skypack.dev) 背后的开源开发人员团队构建，社区提供了额外的贡献。

**ASTRO 是并且永远是免费的。** 它是 [MIT license](https://github.com/withastro/astro/blob/main/LICENSE) 下发布的开源项目。

我们非常关心为开源软件构建更可持续的未来。 同时，我们需要长期支持Astro的发展。 这需要钱（仅靠捐款还不够。）

我们受到 [Tailwind](https://tailwindcss.com/)、[Rome](https://rome.tools/)、[Remix](https://remix.run/)、[Ionic](https://ionicframework.com/) 等项目的早期成功的启发，以及其他在开源之上尝试长期财务可持续性的项目。 在接下来的一年里，我们将探索如何创建可持续的业务，以支持未来几年的 100% 免费开源 Astro。
