[CloudCannon](https://cloudcannon.com/astro-cms/?utm_campaign=Astro%20out-of-beta&utm_source=astro-partner-blog&utm_medium=blog) — 一种流行的基于 Git 的静态站点生成器 CMS — 宣布全面支持 Astro，并准备为所有 Astro 站点设置实时视觉编辑。

借助此版本，Astro 用户可以为 CloudCannon 中的新建和现有 Astro 项目设计和配置其理想的编辑界面，为非技术团队提供直观的无代码界面选项，以及发布和审查大型组织的工作流程。

要开始使用 CloudCannon 作为 Astro CMS，请创建一个 CloudCannon 帐户并按照 [Astro Starter Guide](https://cloudcannon.com/documentation/guides/astro-starter-guide/?utm_campaign=Astro%20out-of-beta&utm_source=astro-partner-blog) 处的说明进行操作。 简而言之，您需要：

*   从 GitHub、GitLab 或 Bitbucket 同步您的 Astro 站点文件。 您在 CloudCannon 中所做的任何更改都将被推回您的 Astro 存储库。
*   构建和配置您的网站。 （请注意，[CloudCannon Collections](https://cloudcannon.com/documentation/articles/defining-your-collections/?utm_campaign=Astro%20out-of-beta&utm_source=astro-partner-blog) 与 Astro Content Collections 完全对应。）您还可以配置您的输入和结构，这将允许您为您的网站创建页面构建器或可配置导航。
*   设置视觉编辑。 使用 CloudCannon 的 [visual data previews](https://cloudcannon.com/documentation/articles/using-live-editing-with-vanilla-js/?utm_campaign=Astro%20out-of-beta&utm_source=astro-partner-blog) 和 Astro 的客户端 Hydration，您可以监听 CloudCannon 中的更改并自动更新页面上的内容。 使用 CloudCannon 的可视化数据绑定标记元素允许您将 UI 直接附加到 CMS 可视化编辑器中页面上的元素，从而为站点用户提供直观的编辑界面。

对于具有 MDX 组件的 Astro 用户，CloudCannon 支持 [embedding rich Snippets in Markdown content](https://cloudcannon.com/documentation/articles/editing-with-mdx-components/?utm_campaign=Astro%20out-of-beta&utm_source=astro-partner-blog) — 允许内容编辑器使用结构化组件而不触及底层代码。

最后，CloudCannon 还发布了一个时尚的新 Astro 主题 [Sendit](https://cloudcannon.com/templates/sendit/?utm_campaign=Astro%20out-of-beta&utm_source=astro-partner-blog)，预配置用于实时视觉编辑。 它包括二十个预样式组件，既可在 [Astro Themes directory](https://astro.build/themes/details/sendit/) 中使用，也可用于 CloudCannon 上的即时部署。
