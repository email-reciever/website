提示和工具
-------------

最新的社区构建的实用程序和集成，可帮助您使用 Astro 构建。 🛠

*   [Back Link](https://events-3bg.pages.dev/library/BackLink/) - 一个组件，让您在使用 Astro 的客户端路由器时翻转视图过渡动画的方向。
*   [Astro Validate Env](https://github.com/adamhl8/astro-validate-env) - Astro 的环境变量验证集成，可让您控制何时/何处验证环境变量并在所有上下文中工作。
*   [Astro Medium loader](https://github.com/ykocaman/astro-medium-loader) - 一个 Astro 加载器，它按用户名获取和解析中等 RSS 提要。 支持规范链接、可选缓存和灵活的存储策略。
*   [Astro content loader](https://github.com/dnlzro/astro-content-loader) - 使用 Astro Content Layer API 加载 `.astro` 文件，就像您使用其他格式（例如 Markdown、MDX）一样。
*   [unDocs](https://github.com/K0Rhq/un) - 使用 Astro 构建的文档框架，您可以在其中构建自己的文档和组件游乐场，您可以在其中控制布局、组件和设计。
*   [Stripe Astro loader](https://github.com/notrab/stripe-astro-loader) - 从 Stripe API 中获取数据并在 Astro 集合中使用。
*   [Astro Payload local loader](https://github.com/jliguori1312/payload-astro-template/tree/main/astro-payload-local-loader) - 使用本地 API 在 Astro 构建期间从有效负载 CMS 实例加载和缓存数据。
*   [Astro Markdown prerender](https://github.com/johnzanussi/astro-markdown-prerender) - 基于 Markdown 文件中的 FrontMatter 属性自动设置 `route.prerender` 的 Astro 集成。
*   [Astro Loader Hashnode](https://github.com/raisedadead/astro-loader-hashnode) - 强大的内容加载器，用于使用 Content Layer API 将 HashNode 博客文章集成到您的 Astro 网站中。
*   [Astro TOC generator](https://github.com/bhargav-bkpatel/astro-toc-generator) - 专门与 Sanity CMS 博客内容一起使用的 Astro.js 目录生成器。
*   [Astro Swiper](https://github.com/pascal-brand38/astro-swiper) - 用于滑动的 ASTRO 组件，专用于滑块/旋转木马/照片滑动/幻灯片。
*   [Astro llms.txt](https://github.com/4hse/astro-llms-txt) - Astro 集成以生成 AI 友好的文档文件。
*   [Astro terminal themes](https://github.com/danlourenco/astro-terminal-themes) - 将终端主题配置（Ghostty、Warp、iTerm2 等）转换为 Astro 网站的 Tailwind CSS 主题。
*   [Astro Mermaid](https://github.com/joesaby/astro-mermaid) - 用于渲染美人鱼图的自动主题切换和客户端渲染的 Astro 集成。
*   [Astro SEO plugin](https://github.com/bhargav-bkpatel/astro-seo-plugin) - Astro 的零配置 SEO 插件。
*   [Astro Strapi loader](https://github.com/VirtusLab-Open-Source/astro-strapi-loader) - Astro 集成，可轻松从 Strapi Content API 加载数据。
