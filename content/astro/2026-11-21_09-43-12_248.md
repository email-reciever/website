### 提示和工具

最新的社区构建的实用程序和集成，可帮助您使用 Astro 构建。

*   [Astrobook](https://github.com/ocavue/astrobook) - 支持多种框架的最小 UI 组件游乐场，包括 React、Vue、Preact、Svelte、Solid、Lit 和 Astro。 它提供了一个统一的环境来开发、测试和展示组件。
*   [`create-krew`](https://github.com/Cspeisman/krew) - 使用 GitHub 存储库、Vercel 部署和 CI/CD 管道快速设置 Astro 项目的 CLI 工具。
*   [Bag of Tricks: `<InspectionChamber />`](https://events-3bg.pages.dev/library/InspectionChamber/) - 添加一个控制面板，可用于检查您的视图过渡动画。
*   [`stripe-astro-loader`](https://github.com/notrab/stripe-astro-loader) - 从 Stripe API 中获取数据并在 Astro 集合中使用。
*   [Chuck Norris facts content loader](https://gist.github.com/NuroDev/4957f92f957d6c26fff216cff4c082fa) - 你知道有人会这样做！
*   [`@jcayzac/astro-build-cache`](https://www.npmjs.com/package/@jcayzac/astro-build-cache) - 您可能在 Astro 构建期间生成的用于工件的简单构建缓存。
*   [`@jcayzac/astro-classlist`](https://www.npmjs.com/package/@jcayzac/astro-classlist) - 当您要将其传递给子组件时，强制/消毒 class:list 的小实用程序。
*   [`notion-astro-loader`](https://github.com/NotWoods/travel/tree/main/packages/notion-astro-loader) - 从概念数据库加载页面，然后将它们呈现为集合中的页面。
*   [DatoCMS Astro starter kit](https://www.datocms.com/marketplace/starters/astro-starter-kit)
*   [`astro-loader-gather`](https://github.com/dustinlacewell/astro-loader-gather) - 类似于内置 glob loader 的用于从文件系统路径中提取元数据的扩展名的加载器。
*   [`mdxtree`](https://github.com/mayneyao/mdxtree) - 生成 MDX 格式的文件树结构的 Rust 命令行工具，用于 Astro 的 Starlight 组件。
*   [`astro-social-share`](https://www.npmjs.com/package/astro-social-share) - V2.0！ 为您的 Astro 网站提供社交媒体共享按钮。
*   [`astro-dump`](https://www.npmjs.com/package/astro-dump) - 更好的调试体验。
*   [`astro-console-cleaner`](https://www.npmjs.com/package/astro-console-cleaner) - 在构建过程中从代码中删除 `console.log`、`console.warn` 和 `console.error` 语句的 ASTRO 集成。
*   [Astro Breadcrumbs](https://docs.astro-breadcrumbs.kasimir.dev/) - Astro 的可配置面包屑组件。
*   [Astroboard](https://github.com/wpplumber/astroboard) - AstroBoard 是一个 Umbraco 仪表板，可深入了解您的内容、资产和成员。
*   [Inox Tools: Request State](https://inox-tools.fryuni.dev/request-state) - 两个组件之间的共享请求状态以及从服务器到客户端的共享请求状态。
*   [Inox Tools: Request Scoped Nano Stores](https://inox-tools.fryuni.dev/request-nanostores) - 使 Nano 存储在服务器上使用，并在客户端上保留其服务器值。
*   [Inox Tools: Content Git Authors](https://inox-tools.fryuni.dev/content-utils/git#getentrygitinfo) - 检索参与编写内容集合条目的 Git 作者和合著者。
