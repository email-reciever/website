Astro 2.10 对我们的实验视图过渡支持进行了改进。 此外，我们发布了 Astro 3.0 的第一个早期测试版。 继续阅读以了解更多信息！

如果您已经安装了Astro，则可以通过在项目中运行升级命令（使用您选择的软件包管理器）将其升级到2.10：

npm install astro@latestpnpm 升级 astro --latestyarn 升级 astro --latest

当您使用它时，也可以升级您安装的任何 `@astrojs/*` 集成和适配器！

视图转换中的持久性 UI
--------------------------------

我们第一次发布的 `<ViewTransition />` 路由器带来了页面之间的平滑过渡，但仍然导致任何有状态的岛屿或元素被重新渲染。

在 2.10 中，我们在 API 中添加了一个新的 `transition:persist` 指令来解决这个问题。

使用此指令，您可以在转换到新页面时从旧页面中保留 DOM 元素和岛屿的状态。 [Here’s a demo](https://stackblitz.com/edit/github-stfdbe-ikkp2e?file=src%2Fpages%2Findex.astro) 正在行动。

例如，要在页面导航中保持视频播放，请将 `transition:persist` 添加到元素：

    <video controls="" autoplay="" transition:persist>  <source    src="https://ia804502.us.archive.org/33/items/GoldenGa1939_3/GoldenGa1939_3_512kb.mp4"    type="video/mp4"  /></video>

这个 `<video>` 元素及其当前状态将被移动到下一页（如果视频也存在于该页面上）。

同样，此功能适用于任何客户端框架组件岛。 在这个例子中，一个计数器的状态被保留并移动到新页面：

    <Counter count={5} client:load transition:persist />

请参阅我们的 [View Transitions Guide](https://docs.astro.build/en/guides/view-transitions/#maintaining-state) 以了解有关使用情况的更多信息。

先看看Astro 3.0
------------------------

我们已经发布了 Astro 3.0 的第一个测试版作为 `astro@3.0.0-beta.0`。 如果您喜欢冒险，请立即尝试！ 到目前为止，此版本主要包含对非常古老模式的弃用和删除。 但是，您可能会遇到一些兼容性问题或重大更改。 请注意，这个早期的预览正在迅速变化，就在您的脚下！

一些值得注意的变化包括：

*   HTML 现在默认压缩。
*   API 路由现在使用大写的方法名称，例如：`export function GET() ...`
*   适配器可以告知ASTRO他们支持哪些功能，例如每页拆分入口点和Sharp/Squoosh兼容性。

[See the changelog](https://github.com/withastro/astro/blob/refs/heads/next/packages/astro/CHANGELOG.md#300-beta0) 有关更改的完整列表。 我们目前没有关于重大更改的文档，但正在编写指南。 在我们接近 3.0 时，将有更多关于这些变化的信息。

一旦所有重大更改完成，您可以期待一个候选版本，我们希望在 8 月底/九月初发布稳定的 3.0。
