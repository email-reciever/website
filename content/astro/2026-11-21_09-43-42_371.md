生日快乐，星光！

一年前的今天，我们推出了 [Starlight](https://starlight.astro.build/) 中的 v0.1——我们所知道的关于构建文档的一切，包裹在一个易于使用的模板中。

它是如何开始的
---------------

我们发布了具有内置站点搜索、生成导航、国际化、可访问性、SEO、干净的排版、代码突出显示、黑暗模式、“在 GitHub 中编辑”、MDX 和 MarkDoc 支持的 V0.1。 在过去的 12 个月中，我们添加了更多内容。

我们的目标一直是提供明智的默认设置。 只需添加 Markdown 内容，即可获得功能性、快速、轻便、令人愉快的文档。 看到有多少人在过去的一年里为自己的文档采用了星光，真是令人欣慰。

进展如何
---------------

24 个小版本、181 个贡献者、2,000 个提交、4,000 个 GitHub 星和 2,700 个开源星光站点之后，我们还没有完成。

我们专注于为您提供对文档项目至关重要的更多内置组件。 感谢我们的全球贡献者社区，我们很自豪能够以 27 种官方支持的语言提供翻译的文档基础设施，开箱即用。

Starlight 展示了一个开发团队对文档充满热情的事情，我们很感谢你们中的许多人加入了我们，带来了你们的热情，让 Starlight 变得比我们希望的还要多。
