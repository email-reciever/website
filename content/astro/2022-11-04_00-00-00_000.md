我们希望您喜欢 Astro Docs 周，我们的 Docs 核心维护人员控制了键盘和我们的 Twitter 帐户！ 每天，我们在团队文档上发布了生活的幕后花絮：

*   我们的[low-code Hacktoberfest drive](https://twitter.com/astrodotbuild/status/1587160080717434881)
*   我们的[custom-built translation status tracker](https://twitter.com/astrodotbuild/status/1587547028258582528)
*   我们如何公开承认[Astro Badges](https://twitter.com/astrodotbuild/status/1587901468585205760)和个性化[first-time contributor celebrations](https://twitter.com/astrodotbuild/status/1588285834054148096)的贡献者

为了结束这周，我们很高兴分享迄今为止最大的文档项目：我们的第一个 Astro 教程。

你好，世界！
--------------

你能读到的只有这么多； 有时，您需要构建。 在第一个基于项目的教程中，您将从头开始构建 Astro 博客的所有基本部分。

Astro，就像网络一样，适合所有人。 让刚开始使用编码的人可以访问本教程对我们来说很重要。 您可以找到有关设置开发环境和使用终端开始的指南。 您甚至可以找到完全在云中完成项目的说明。 选择您最喜爱的在线编码环境，即使在 Chromebook 或平板电脑上也可以！

因此，如果您想尝试 Astro，但不确定从哪里开始，请查看我们的 [Build a Blog tutorial](https://docs.astro.build/en/tutorial/0-introduction/) 文档！ 如果你是一个经验丰富的宇航员，你现在还有一个地方可以派你的天文好奇的朋友。

[Build a blog today!](https://docs.astro.build/en/tutorial/0-introduction/)

我们才刚刚开始…
----------------------------

本教程很热门，我们正在寻找有关如何改进它的反馈。 我们也有关于更高级主题的新想法。 请务必联系 Discord 上的团队文档，让我们知道您接下来想看到什么！

非常感谢参与这个具有挑战性的项目的每个人！

[Sarah Rainsberger](https://twitter.com/sarah11918) 花了几个月的时间计划和写作，始终支持 Astro 初学者、新开发人员或非传统设备所有者的温和入门。

该项目需要对我们的文档站点进行大量的 UI，从交互式组件到导航。 [Chris Swithinbank](https://twitter.com/swithinbank) 不知疲倦地工作，将文字变成一种体验。 如果你可以点击它，你可以感谢克里斯！

我们还从社区成员那里得到了一些有用的早期反馈。 感谢所有在过去几周与我们通话并提供修复的人。 这一点，通过 [Dan Jutan](https://twitter.com/jutanium) 的无情编辑、测试和追逐错误，有助于集中和完善我们的方向。

文档周结束，但“文档从未完成”
------------------------------------------

您有兴趣参与 Astro 的文档吗？ 查看我们的 [Contributor’s Guide](https://github.com/withastro/docs/blob/main/CONTRIBUTING.md) 中的 [the docs repo on GitHub](https://github.com/withastro/docs) 或在 `#docs` 频道中找到我们 (`#docs` 频道](https://astro.build/chat/)。 加入我们的作家、编辑、翻译人员、设计师、编码人员、测试人员、建设者、思想家和梦想家团队。 制作文档需要一个社区，我们迫不及待地等待您加入我们！
