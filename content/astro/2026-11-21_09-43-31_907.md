对 500.ASTRO 的改进
--------------------------

[`src/pages/500.astro`](https://docs.astro.build/en/basics/astro-pages/#custom-500-error-page) 是 Astro 中的一个特殊页面文件，允许您优雅地处理 [500](https://developer.mozilla.org/en-US/docs/Web/HTTP/Status/500) 错误。 500 错误最常发生在您的应用程序中存在错误的地方； 比如不在 `try/catch` 中包装精致的代码。 当组件代码抛出时，Astro 捕获并返回 500 响应。 如果您有 `src/pages/500.astro` 此页面将呈现到响应正文中。

4.11 中的新功能，`500.astro` 现在接收 `error` 作为道具。 这允许您提供有关错误的更多上下文信息。

---接口道具 { 错误：未知}const { 错误 } = astro.props---
<html lang="en"><head> <title>服务器错误 - 自定义 500</title></head><body> <h1>服务器错误</h1> <p>{错误实例 error.message : '未知错误'}</p></body></html>

代码组件中的 Shiki 变换器
--------------------------------------

Astro 的内置 [`<Code />` Component](https://docs.astro.build/en/reference/api-reference/#code-) 用于在 Astro 页面中呈现语法突出显示的代码块。 该组件使用 [Shiki](https://shiki.style/) 并支持所有流行的主题和语言。 现在，您还可以通过传递 `transformers` 道具在代码块上使用 [Shiki transformers](https://shiki.style/packages/transformers#shikijs-transformers)：

---import { transformerNotationFocus } from '@shikijs/transformers'import { code } from 'astro:components'const code = `const foo = 'hello'const bar = ' world'console.log(foo + bar) // [!code focus]`---<Code {code} lang="js" transformers={[transformerNotationFocus()]} /><style is:global> pre.has-focused .line:not(.focused) { 过滤器：模糊(1px); }</style>
