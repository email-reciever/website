npx @astrojs/升级

npm install astro@latestpnpm 升级 astro --latestyarn 升级 astro --latest

新的可访问性审计规则
-----------------------------

我们为开发工具栏添加了两个新的审计规则。 您现在将被警告：

*   不支持的 ARIA 属性
*   缺少ARIA角色所需的属性

这两个规则都有助于确保您的页面上的元素具有正确和有效的 ARIA 角色。

扩展 `client:visible` 指令
---------------------------------

`client:visible` 指令现在接受 `rootMargin` 选项，它允许您在视口周围指定一个边距以计算可见性。 这允许组件在靠近视口时进行水化，而不是等待它变得可见。

<!-- 当组件在距离进入视口 200 像素以内时加载组件 --><Component client:visible={{rootMargin: "200px"}} />

自定义cookie编码和解码
---------------------------------

现在可以通过新的 `encode` 和 `decode` 功能在设置和获取 cookie 时自定义 Cookie 编码/解码。

例如，当将 URL 添加为 cookie 的一部分时，您可以通过 `encodeURIComponent` 绕过默认编码：

---import { encodeCookieValue } from './cookies';astro.cookies.set('url', astro.url.toString(), { // 覆盖默认编码，以使 URI 组件不被编码 encode: (value) => 编码CookieValue(值),});---

稍后，您可以以相同的方式解码 URL：

---import { decodeCookieValue } from './cookies';const url = astro.cookies.get('url', { decode: (value) => decodeCookieValue(value),});---
