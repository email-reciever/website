提示和工具
-------------

最新的社区构建的实用程序和集成，可帮助您使用 Astro 构建。 🛠

*   [Astro Prettier Response](https://www.npmjs.com/package/@altano/astro-prettier-response) - 这个包注入了一个中间件，该中间件运行更漂亮的格式化器，以使所有输出都变得不凡。
*   [Astro Strapi Blocks](https://github.com/VirtusLab-Open-Source/astro-strapi-blocks) - Strapi 丰富文本块字段的 Astro 块。
*   [Piny Tailwind Visual Editor](https://getpiny.com/) - 一个 VSCode 扩展，可让您在 React 和 Astro 文件中直观地编辑 Tailwind CSS。
*   [Astro Image Dithering](https://github.com/bashbers/astro-image-dithering) - 在将图像提供给您的观众之前，以更快的图像加载时间与较低的碳足迹相结合。
*   [Remark Auto Diff](https://github.com/HiDeoo/remark-auto-diff) - 一个备注插件，为 Markdown 中的 diff 代码块提供了另一种语法。
*   [Schema-driven Astro Starter Kit](https://github.com/greynewell/schema-driven-astro-starter) - 为您的 Astro 项目带来结构化数据、SEO 优化和模式驱动开发的生产就绪入门套件。
*   [Astro Loader i18n](https://github.com/openscript/astro-loader-i18n) - 用于 i18n 文件和文件夹结构的 Astro Glob 内容加载程序。
*   [WebApp Astro PWA](https://github.com/aondodawid/WebApp-Astro-PWA) - 现成的 Astro 组件库，用于为您的 Astro 项目添加渐进式 Web 应用 (PWA) 支持。
*   [Astro Simple Modal](https://github.com/henrycorredor/astro-simple-modal) - 一个简单且高度可定制的 Astro 模式 — 最小设置，全样式控制。
*   [Astro Maintenance](https://github.com/alexandr-studio/astro-maintenance) - 轻松将维护和即将推出的页面添加到您的 Astro 网站。
*   [Astro Iubenda](https://github.com/Valyay/astro-iubenda) - 此 Astro 集成为您的 Astro 项目提供并提供 Iubenda 隐私政策、Cookie 政策和条款和条件内容。
*   [Light-Auth](https://lightauth.github.io/) - 一个轻量级、安全且易于实现的身份验证框架，带有 [Astro Hello World example](https://github.com/lightauth/light-auth-astro-sample-one)。
*   [Astro Wordpress ACF Generator](https://github.com/sijad/astro-wordpress/tree/main/packages/acf-generator) - 用于 WordPress 高级自定义字段 (ACF) 的 PHP 代码生成器。
*   [Astro Daisy Theme Toggle](https://github.com/Grahf0085/astro-daisy-theme-toggle) - 为您的 AstroJS 和 Daisyui 项目添加黑暗和浅色主题的组件。
*   [Astro OG Images](https://github.com/ReunMedia/astro-og-images) - 另一个用于生成开放图形图像的 Astro 集成。 比大多数替代品更轻便。
*   [Astro Starter Kit: Component Package](https://www.npmjs.com/package/@openpanel/astro) - Astro 组件库的模板。 使用此模板编写组件以在多个项目中使用或发布到 NPM。
*   [Flotiq Astro SDK](https://www.npmjs.com/package/@flotiq/flotiq-astro-sdk) - 用于 Flotiq 无头 CMS 的专用 Astro Collections 生成器。
*   [Astro Mailer](https://www.npmjs.com/package/@hbertoson/astro-mailer) - 一种 ASTRO 集成，使您能够使用 NodeMailer 通过任何 SMTP 服务发送电子邮件通知。
*   [Astro Resend](https://github.com/hkbertoson/astro-integrations/tree/main/packages/astro-resend) - Astro 集成，允许您在 Astro 项目中使用 ReSend 轻松发送表单提交的电子邮件通知。
*   [Remark Livecodes for Astro](https://livecodes.io/docs/markdown-to-livecodes/#astro) - 支持 Astro 的开源客户端游乐场。
*   🌟 [Starlight Custom Navigation](https://github.com/frostybee/starlight-custom-navigation) - 通过自定义页面导航功能（包括对键盘快捷键的支持）增强文档站点。
*   🌟 [Starlight Code Block Fullscreen](https://frostybee.github.io/starlight-codeblock-fullscreen/) - 将全屏切换功能添加到文档中的富有表现力的代码块中。
*   [Astro Adapter Nekoweb](https://github.com/indiefellas/astro-adapter-nekoweb) - Astro 的适配器，可在 NekoWeb 上自动部署您的应用程序。
*   [Astro PlantUML](https://www.npmjs.com/package/astro-plantuml) - 用于在 Markdown 文件中渲染 Plantuml 图的 Astro 集成。
*   [Astro Tips](https://github.com/xingwangzhe/astro-tips) - 具有 18 种内置样式和自动暗模式支持的 Astro 可定制的提示和通知块。
*   [Vemetric Astro SDK](https://vemetric.com/docs/sdks/astro) - 通过 Astro SDK for VeMetric 跟踪您的数据。
*   [Astroboard](https://github.com/wpplumber/astroboard) - 使用动态仪表板转换您的 Umbraco CMS。
*   [Inox Tools Cut-short](https://inox-tools.fryuni.dev/cut-short#pre-rendering) - 一种 ASTRO 集成，可让您立即停止处理请求并发送回自定义响应，现在使用 `cancelPrerender` 选项动态跳过特定页面的生成。 而不是呈现 404 页面，此实用程序可确保从您的最终静态输出中完全省略该页面。

…和一些内置的_with_ astro：

*   [Astro Life in Weeks](https://github.com/juanchiparra/astro-life-in-weeks) - 一个 ASTRO 项目，用于创建您自己的“几周内的生活”，这是一个交互式可视化，每个矩形代表您生活中的一周。
*   [Ubikute Relay](https://ark.sudovanilla.org/Korbs/Ubikute-Relay/) - 一个新的状态页面，供社区和组织自托管，前端构建在 Astro 上。
*   [html2astro](https://html2astro.mb-js.site/) - 拖放您的 HTML。 立即转换为 Astro 项目。
*   [Historical Timeline Calculator](https://timeline.design/) - 创建和导出历史时间线的图形。
