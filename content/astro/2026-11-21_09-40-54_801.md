最新的社区构建的 [utilities and integrations](/integrations/) 可帮助您使用 Astro 构建。 🛠

*   🌟 [Starlight contextual menu](https://github.com/corsfix/starlight-contextual-menu) - 将上下文菜单添加到您的 Starlight 文档中，快速访问 AI 优化的内容。
*   🌟 [Starlight GitHub alerts](https://github.com/HiDeoo/starlight-github-alerts) - 将 GitHub 警报呈现为星光之外。
*   🌟 [Starlight plugin icons](https://github.com/Rettend/starlight-plugin-icons) - 将图标添加到 Astro Starlight：侧边栏、代码块、FileTree。
*   [Astro Table of Contents](https://github.com/elstron/astro-table-of-contents) - 自动生成并包含网页的目录 (TOC)。
*   [Astro Simple Feature Flags](https://github.com/sushichan044/astro-simple-feature-flags) - 一个简单的、类型安全的 Astro 功能标志集成，由 Content Layer API 提供支持。
*   [Astro Loader Obsidian](https://github.com/aitorllj93/astro-loader-obsidian) - 用于 Astro 的内容加载器，可让您将 Obsidian Vault 视为本机内容集合。
*   [Astro LLMS Generator](https://github.com/ColdranAI/astro-llms-generate) - 自动发现和处理所有 Astro 页面以生成优化的文档文件。
*   [Varlock Astro integration](https://www.npmjs.com/package/@varlock/astro-integration) - 帮助您将 Varlock 集成到 Astro 项目中。
*   [Astro Mithril](https://github.com/pioleong/astro-mithril) - 为您的 Mithril 组件启用服务器端渲染和客户端水合作用。
*   [Astro Selfie](https://github.com/celest-io/astro-selfie) - 生成页面截图以显示为打开的图形图像。
*   [Astro Remove Comments](https://www.npmjs.com/package/astro-remove-comments) - 通过减少文件大小和删除与开发相关的评论来优化您的静态站点
*   [Inline](https://github.com/PlayForm/Inline) - 将野兽（一个库用于内联应用的关键 CSS 并延迟加载其余部分）到您的 Astro 项目中。
*   [Astro CNAME](https://github.com/sidetrails/astro-integrations/tree/master/packages/astro-cname) - 使用配置的 `site` 值生成 CNAME 文件。
*   [Astro Render Component](https://github.com/igorskyflyer/npm-astro-render-component) - 即插即用的 Astro 组件渲染器，可在任何类似 DOM 的 JS/TS 环境中进行快速、零配置的测试。
*   [Astro Dev Only](https://github.com/FujoWebDev/fujocoded-plugins/tree/main/astro-dev-only) - 从您的最终静态生产版本中删除文件。 适用于草稿或其他仅限开发人员的页面。
*   [Authproto](https://github.com/FujoWebDev/fujocoded-plugins/tree/main/astro-authproto) - 使用 AtProto 验证您的网站访问者。 对于蓝天和超越。
*   [Astro Lit](https://github.com/manujoz/-mjo-astro-lit) - 为您点亮的自定义元素启用服务器端渲染和客户端补水。
*   [Astro AI LLMS TXT](https://www.npmjs.com/package/@waldheimdev/astro-ai-llms-txt) - 为您的 HTML 页面创建 AI 优化的摘要。
*   [Astro Dynamic Header](https://github.com/SofiDevO/astro-dynamic-header) - 一种动态的、响应式的头部组件，可以在多层下拉导航支持下在浮动和全屏样式之间切换。
*   [Astro Static Headers](https://github.com/abemedia/astro-static-headers) - 在 PreRender 期间捕获标头和重定向，并为 Cloudflare、Netlify 和 Vercel 编写特定于平台的配置。
*   [Astro Tailwind 4 auto reference](https://github.com/bitgumbo/astro-tw-autoreference) - 在 Astro 组件样式块中自动注入 Tailwind `@reference` 指令。
*   [Astrojs Hyperapp](https://github.com/zaceno/astrojs-hyperapp) - 使用 Astro 渲染的静态/服务器渲染 HyperApp 组件。
*   [Astro ESLint setup](https://github.com/danielz0102/astro-eslint-setup) - 使用 TypeScript 语法自动将 ESLint 设置为 lint astro 文件。
