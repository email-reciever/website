实验：内容层API
------------------------------

在 Astro 2.0 中，我们引入了 [Content Collections](https://docs.astro.build/en/guides/content-collections/)，这是一种在 Astro Projects 中管理本地内容的强大方法。 虽然这已帮助数十万开发人员使用 Astro 构建内容驱动的网站，但我们听到您的反馈，您希望在管理内容时获得更多的灵活性和功能。 我们很高兴地宣布在 Astro: 内容层 API 中发布下一代内容集合的实验性版本。

新的 Content Layer API 建立在内容集合的基础上，将它们超越 `src/content/` 中的本地文件，并允许您从任何地方获取内容，包括远程 API。 这些新集合与您现有的内容集合一起使用，您可以按照自己的节奏将它们迁移到新的 API。 我们认为您很快就会想要，因为它们有很多优势，但并不着急——现有的系列将像往常一样继续工作。

### 开始

要尝试新的内容层 API，请在 Astro Config 中启用它：

从“astro/config”导入 { defineconfig }；
export default defineConfig({  experimental: {    contentLayer: true  }})

然后，您可以使用 Content Layer API 在 `src/content/config.ts` 中创建集合。

### 创建加载程序

您不仅限于内置装载机——我们希望您尝试构建自己的装载机。 您可以从任何地方获取内容并返回一组条目：

src/content/config.ts

const countries = defineCollection({ loader: async () => { const response = await fetch("https://restcountries.com/v3.1/all"); const data = await response.json(); // 必须返回一个带有 id 属性的条目数组， // 或一个 ids 作为键和条目的对象作为值返回 data.map((country) => ({ id: country.cca3, ...country, })); }, // 可选地添加一个模式以验证数据并使其对用户进行类型安全 // schema: z.object...});
导出常量集合 = { 国家 };

对于更高级的加载逻辑，您可以定义一个对象加载器。 这允许增量更新和条件加载，同时还可以完全访问数据存储。 它还允许加载器定义自己的模式，包括基于源 API 动态生成它。 有关详细信息，请参阅 [the Content Layer API RFC](https://github.com/withastro/roadmap/blob/content-layer/proposals/0050-content-layer.md#loaders)。

### 共享您的装载机

加载器在共享时会更好！ 您可以创建一个导出加载器并将其发布到 npm 的模块，然后任何人都可以在其网站上使用它。 用关键字 [`astro-loader`](https://www.npmjs.com/search?q=keywords:astro-loader) 标记您的包，以便找到它们。 我们很高兴看到社区的想法！ 开始，[take a look at some examples](https://github.com/ascorbic/astro-loaders/)。 以下是使用 RSS/Atom 馈送加载器加载内容的方法：

src/content/config.ts

import { defineCollection } 从 "astro:content";import { feedLoader } 从 "@Ascorbic/Feed-Loader";
const podcasts = defineCollection({ loader: feedLoader({ url: "https://feeds.99percentinvisible.org/99percentinvisible", }),});
导出常量集合 = { 播客};

实验：内容文件中的智能感知
--------------------------------------------

Astro 4.14 在内容的前提中引入了对 IntelliSense 的实验支持。 此功能通过为 FrontMatter 键和值提供完成、验证、悬停信息等，帮助您更有效地编写内容文件。 这些工具基于您的内容架构，可直接在编辑器中使用。

此功能在 VS Code 和其他支持 Markdown、MDX 和 MarkDoc 文件的语言服务器协议的编辑器中可用。

![](/_astro/frontmatter-intellisense.Cxa6V3Li_12yPV9.webp)

要启用内容文件 IntelliSense，请将以下内容添加到您的 Astro 配置中：

从“astro”导入 { defineConfig }；
导出默认 defineConfig({ 实验性: { contentIntellisense: true }})

在 VS Code 中，启用 `astro.content-intellisense` 设置。 对于其他编辑器，将 `contentIntellisense: true` 传递到 Astro 语言服务器的初始化参数。

{ "astro.content-intellisense": true}

此功能目前仅在编辑器中工作，并将在未来的版本中在 `astro check` 中启用。

弃用对动态 `prerender` 值的支持
--------------------------------------------

为了提高我们的捆绑和树摇树功能，Astro 4.14 不推荐使用 Astro 页面中 `prerender` 选项的动态值。

现在可以在 Astro 集成中用新的 `astro:route:setup` 钩子替换此功能，它允许您动态控制特定页面的预渲染。

--- export const prerender = import.meta.env.prod;---

astro.config.mjs

从“astro/config”导入 { defineconfig }；
导出默认 defineConfig({ 集成：[setPrerender()],});
函数 setPrerender() { return { name: 'set-prerender', hooks: { 'astro:route:setup': ({ route }) => { if (route.component.endswith('/blog/[slug].astro')) { route.prender = true; } }, }, };}

新 `injectTypes` 集成 API
--------------------------------

类型生成近年来风靡一时，Astro也不例外！ 我们非常广泛地将类型生成用于 Astro DB 和内容集合（或新的内容层 API）等功能。

感谢 [@florian-lefebvre](https://github.com/florian-lefebvre)，Astro Integrations 现在可以通过新的 `injectTypes` 集成 API 加入乐趣！ 此 API 允许集成将类型注入到用户的项目中，从而更轻松地为集成功能提供类型定义。

my-integration/index.js

导出默认 { 名称：'my-integration', 'astro:config:done': ({ injectTypes }) => { injectTypes({ filename: "types.d.ts", content: "declare module 'virtual:my-integration' {}" }) }};

有关此功能的更多信息，请查看 [Astro integration API documentation](https://docs.astro.build/en/reference/integrations-reference/#injecttypes-options)。

支持代码组件中的元字符串
-------------------------------------------

Astro 4.14 在 `Code` 组件中添加了对 `meta` 属性的支持。 此属性模拟使用 Markdown 中代码块上的属性，例如 ` ```js astro=cool `，然后 [Shiki transformers](https://shiki.matsu.io/guide/transformers#meta) 可以将其用于将自定义转换应用于代码块。

---import { code } 来自 "astro:components";import { transformerMetaHighlight } 来自 '@ShikiJS/Transformers';---<Code  code={code}  lang="js"  transformers={[transformerMetaHighlight()]}  meta="{1,3}" />

感谢 [@jcayzac](https://github.com/jcayzac) 的贡献！
