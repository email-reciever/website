提示和工具
-------------

最新的社区构建的 [utilities and integrations](/integrations/) 可帮助您使用 Astro 构建。 🛠

*   [🌟 Starlight Links](https://github.com/HiDeoo/starlight-links) - Visual Studio Code Extension 为 Starlight 文档项目的 Markdown 和 MDX 文件中的链接提供 IntelliSense。
*   [🌟 Mixedbread Search for Starlight](https://github.com/mixedbread-ai/mixedbread-starlight) - 用于 Starlight 的 Mixedbread 集成，以替换默认的 PageFind 搜索。
*   [🌟 Starlight DocSearch Typesense](https://github.com/typesense/starlight-docsearch-typesense) - 添加由 TypeSense 支持的 DocSearch 的 Starlight 插件，用于快速、容错的文档搜索。
*   [Astro Chatty GPT](https://github.com/unfolding-io/astro-chatty-gpt) - 为您的 Astro 网站提供的简单聊天机器人 API。 由 Upstash 搜索、GPT-5 和 AI-SDK 提供支持。
*   [Astro ATProto OAuth Starter](https://tangled.org/@daffl.xyz/astro-atproto-starter) - 一个最小的 ASTRO 初学者模板，演示使用 AT 协议 (ATPROTO) 的 OAuth 身份验证，这是 Bluesky 和其他服务使用的去中心化社交网络协议。
*   [Astro Single File](https://github.com/onmax/astro-single-file) - 允许您将 CSS 和 HTML 捆绑到单个文件中的集成。
*   [Astro Users](https://github.com/CosyZone/astro-users) - 使用 Cloudflare D1 数据库进行用户管理的 ASTRO 集成。
*   [Expressive Code language badge](https://github.com/frostybee/expressive-code-language-badge) - 一种用于表达代码的插件，可自定义样式为代码块添加语言徽章。
*   [Astro View Transition Script](https://github.com/byronogis/astro-view-transition-script) - 执行与 Astro 的视图转换兼容的回调的实用程序函数。
*   [Astro NProgress](https://github.com/byronogis/astro-nprogress) - 支持 nProgress.js 纳米进度条的集成，与 Astro 的视图转换兼容。
*   [Astro Markdown Export](https://github.com/shaheemMPM/astro-markdown-export) - 在构建过程中从内容集合生成静态 Markdown 文件的 Astro 集成。
*   [Astro Loader for Valise](https://github.com/zakj/astro-loader-valise) - Art Inventory System Valise 的 Astro Content Loaders，可用于艺术品和收藏。
*   [Astro Google Reviews](https://github.com/wally-website/wally-astro/tree/main/packages/astro-google-reviews) - 使用单个组件将 Google 评论小部件（由 Wally 提供支持）嵌入到您的 Astro 网站中。
*   [Astro Theme Toggler](https://github.com/yarso-su/astro-theme-toggler) - 一个简单、最小和优化的主题切换器实用程序，适用于 Astro with Vanilla JS。
*   [Astro Dropdown](https://github.com/yarso-su/astro-dropdown) - 一个简单的、可自定义的下拉菜单实用程序，仅适用于仅限香草 JS 的 Astro。
*   [Astro Shield](https://github.com/meeghele/astro-shield) - 一种最小化的集成，可以阻止自动刮板机通过客户端挑战而无需外部服务。
*   [Astro Plugin Media](https://github.com/moecasts/remark-media) - 支持在 Markdown 中嵌入多个音频和视频播放器的 Astro Media 插件。
*   [Agent Summary](https://github.com/nuasite/nuasite/tree/main/packages/agent-summary) - 一个微小的 Astro 集成，可将您的构建站点变成用于代理或 LLM 驱动工具的机器可读目录 (`AGENTS.md`)。

……还有一些是用 Astro 建造的！

*   [npm provenance overview](https://delucis.github.io/npm-provenance-overview/) - 快速查看维护者的 npm 软件包的发布安全性。
*   [🌟 Starlight themes](https://starlight-themes.netlify.app/) - 预览所有星光主题的一处。 在 Catppuccin、Flexoki、Rapide 和 Ion 之间进行选择时遇到了困难？ 在一个主题切换的演示网站中找到所有您最喜欢的社区构建的星光主题！
