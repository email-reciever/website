实验：容器 API
----------------------------

Astro 4.9 介绍了期待已久的容器 API。 此 API 允许您在 Astro 应用程序之外渲染 Astro 组件。 这类似于如何使用 `react-dom/server` 等库在服务器上呈现 React 组件或使用 `preact-render-to-string` 进行 Preact 组件。

以下是如何使用容器 API 将 Astro 组件呈现为字符串的示例：

import { experiment_AstroContainer as AstroContainer } 来自“Astro/Container”；从“./components/component.astro”导入组件；
const container = await astrocontainer.create();console.log(await container.RenderToString(component));

此 API 添加的可能性是无穷无尽的，但这只是第一步。 我们在这个阶段的主要重点是让 Vite 支持的测试框架内更容易渲染 Astro 组件，例如 Viste。

import { experiment_astrocontainer as astrocontainer } 来自 'Astro/Container';import { expect, test } from 'viest';import card from '../src/components/card.astro';
test('card with slot', async () => { const container = await AstroContainer.create(); const result = await container.RenderToString(card, { slots: { default: 'card content', }, });
expect(result).tocontain('这是一张卡片'); expect(result).tocontain('card content');});

为了开始使用 Viste 测试 Astro 组件，我们制作了 [a new example](https://github.com/withastro/astro/tree/main/examples/container-with-vitest) 您可以直接使用以下方法结帐或创建新项目：

npm create astro@latest -- --template container-with-viest

[Our testing guide](https://docs.astro.build/en/guides/testing/#vitest-and-container-api) 还更新了有关如何使用容器 API 进行测试的更多信息。 测试一切！

要了解有关 Container API 以及如何使用它的更多信息，请查看 [Container API documentation](https://docs.astro.build/en/reference/container-reference/)。 要对这个实验和开发功能提供反馈，请访问 [Container API RFC](https://github.com/withastro/roadmap/pull/916)。

反应 19 支持
-----------------

第一个 React 19 发布候选者出来了，Astro 准备好了。 我们在 React 集成中添加了对 React 19 的全面支持，并为 Astro Actions 添加了一些优点。

要在 Astro 项目中使用 React 19，[follow the React 19 beta installation guide.](https://react.dev/blog/2024/04/25/react-19-upgrade-guide#installing) 这可以解锁 React 的新表单操作功能，它允许您从 `<form>` 中调用操作并跟踪组件中的“待处理”和“结果”值。

此示例使用名为 `like()` 的 Astro 操作，该操作接受 `postId` 并返回喜欢的数量。 使用 React 19，您可以将此操作传递给 `useActionState()` 钩子以跟踪结果。 应用 `experimental_withState()` 功能自动应用渐进增强信息：

src/components/like.tsx

import { actions } from 'astro:actions';import { useActionState } 来自 'react';import { experiment_withState } 来自 '@astrojs/react/actions';
导出函数 like({ postid }: { postID: string }) { const [state, action, pending] = useActionState( experiment_withState(actions.like), 0, // initial likes );
返回 (<form action={action}> <input type="hidden" name="postId" value={postId} /> <button disabled={pending}>{状态} ❤️</button> </form> );}

您还可以使用 `experimental_getActionState()` 访问 `useActionState()` 存储的操作 `handler` 中存储的状态。 [See the CHANGELOG](https://github.com/withastro/astro/blob/refs/heads/main/packages/astro/CHANGELOG.md#490) 用于使用示例。

如果您不需要跟踪状态，您还可以将 Astro 操作直接应用于任何 React `<form>` 的 `action` 属性。 这也将应用渐进增强信息：

src/components/signout.tsx

从“astro:actions”导入 { 动作 }；
导出函数 signOut() { 返回 (<form action={actions.signOut}> <button>注销 </button> </form> );}

要了解有关 Astro Actions 的更多信息并提供有关此实验性 API 的反馈，请查看 [Astro Actions RFC](https://github.com/withastro/roadmap/blob/actions/proposals/0046-actions.md)。

稳定的实验特征
--------------------------------

此版本稳定了 CSRF 保护（在 [Astro 4.6](/blog/astro-460/#experimental-support-for-csrf-protection) 中引入）和 i18n 域支持（在 [Astro 4.3](/blog/astro-430/#experimental-add-domain-support-for-i18n) 中引入）功能。 不再需要启用 Astro Config 中的 `experimental.csrfProtection` 和 `experimental.i18nDomains` 选项来使用这些功能。

`experimental.security.csrfProtection` 选项已被移除以支持新的 `security.checkOrigin` 选项。 要启用跨站点请求伪造保护，请在 Astro Config 中将 `security.checkOrigin` 设置为 `true`，并在启用后删除 `experimental.security.csrfProtection` 选项：

从“astro/config”导入 { defineconfig }；
导出默认值 defineConfig({ 安全性：{ checkOrigin: true } 实验性的：{ 安全性：{ csrfProtection: { 来源：真 } } },});

至于 i18n 域，您可以保持您的配置，无需 `experimental.i18nDomains` 选项：

从“astro/config”导入 { defineconfig }；
导出默认的 defineConfig({ site: "https://example.com", 输出: "server", 适配器: node({ mode: 'standalone', }), i18n: { defaultlocale: "en", locales: ["en", "fr", "pt-br", "es"], PrefixDefaultLocale: false, 域: { fr: "https://fr.example.com", es: "https://example.es", }, }, 实验: { i18domains: true, },});

有关这些功能的更多信息，请分别参见 Astro 文档的 [security](https://docs.astro.build/en/reference/configuration-reference/#security) 和 [i18n domains](https://docs.astro.build/en/guides/internationalization/#domains) 部分。
