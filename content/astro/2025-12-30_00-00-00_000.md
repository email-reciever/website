提示和工具
-------------

最新的社区构建的 [utilities and integrations](/integrations/) 可帮助您使用 Astro 构建。 🛠

*   [Astro Auto Load](https://www.npmjs.com/package/astro-auto-load) - Astro SSR 的自动组件级数据加载。
*   [Astro Content Viewer](https://github.com/dofbi/astro-content-viewer) - Astro 的开发工具栏应用程序，可将您的内容集合、ZOD 模式和相关变量可视化。
*   [Astro Dynamic Component](https://github.com/shjyh/astro-dynamic-component) - ASTRO 集成，支持使用全局模式和客户端指令支持动态组件导入。
*   [Astro Shortlinks](https://github.com/Ovyerus/astro-shortlinks) - 自动为您的 Astro 网站创建简短链接。
*   [Astro Tips](https://github.com/xingwangzhe/astro-tips) - 具有 18 种内置样式和自动暗模式支持的 Astro 的精美、可定制的提示和通知块。
*   [Astro Compress](https://github.com/jgabriel98/astro-compress) - Astro 中静态资产的强大压缩集成。
*   🌟 [Starlight GitHub Stats](https://www.npmjs.com/package/starlight-github-stats) - 在文档站点的标题中显示 GitHub 存储库统计信息（星形、分叉和最新版本）的 Starlight 插件。
*   [Simple Tips](https://www.npmjs.com/package/super-tips) - 一个简单易用的 Astro 集成，用于在 Markdown 和 MDX 文件中创建漂亮的工具提示。
*   [Astro Speed Measure](https://github.com/casoon/astro-speed-measure) - 测量 Astro 端到端的构建性能。 包装集成和 Vite 插件，汇总每页和资产时序，并发出人文、JSON 或 HTML 报告。
*   [EdgeOne Astro Adapter](https://github.com/TencentEdgeOne/astro-adapter) - 一个适配器，允许您将 Astro 站点部署到 EdgeOne 页面。
*   [Astro Pirsch Proxy](https://github.com/freshcodes/astro-pirsch-proxy) - 公开 Pirsch Analytics 代理的 Astro 集成。
*   [Auto Param Astro](https://github.com/newgentdigital/auto-param-astro) - 在构建时将配置的查询参数添加到外部链接的 Astro 集成。
*   [Astro SEO](https://github.com/ByManuelCaballero/astro-seo) - 支持完整打字稿的 Astro 的 SEO 组件。
*   [Astro Deck](https://github.com/sandikodev/astro-deck) - Astro - 具有 CMS、AI 内容生成器和开发人员工具的 Admin Hub 的命令甲板。
*   [sweetcorn](https://github.com/delucis/sweetcorn) - 适用于夏普的 JavaScript 图像抖动工具。 将平滑像素变成松脆的内核。
*   [Astro Content AI Translator](https://github.com/affiliatefm/astro-content-ai-translator) - 使用 OpenAI 进行 AI 驱动的内容翻译的 Astro 集成。
*   [CMS Marker](https://github.com/nuasite/nuasite/blob/main/packages/cms-marker/) - 自动标记带有唯一标识符的 HTML 元素并生成清单映射内容到源文件和行号的 ASTRO 集成。 非常适合构建需要跟踪代码库中内容的来源的 CMS 编辑器。
*   [Astro Click to Source](https://github.com/invisible1988/astro-click-to-source) - 用于 Alt+Click 的 ASTRO 集成，可在开发期间在编辑器中打开源文件。
*   [ez i18n](https://github.com/zachhandley/ez-i18n) - 基于 cookie 的 i18n 用于 Astro + Vue + React。 没有 URL 前缀，反应式语言切换。
*   [Astro Marp](https://github.com/astro-marp/astro-marp) - 将 `.marp` Markdown 幻灯片源转换为具有完整资产管道集成和服务器端美人鱼图渲染的优化演示页面的 Astro 集成。
*   [Astro NocoDB](https://github.com/dofbi/astro-nocodb) - 将 NoCodb 数据集成到 Astro 内容集合中的 Astro Loader 包。
*   [Spectre UI Astro](https://github.com/phcdevworks/spectre-ui-astro) - Spectre UI 的一流 Astro 层。 打包 Spectre UI 的类和令牌的 SSR 友好的 Astro 组件（按钮、卡片、输入等）。
*   [Astro Shield](https://github.com/kindspells/astro-shield) - ASTRO 集成，通过子资源完整性哈希、内容安全策略标头和其他技术增强您网站的安全性。
*   [Writenex Astro](https://github.com/erlandv/writenex/tree/main/packages/astro) - Astro Content Collections 的可视化编辑器 - 为您的 Astro 网站进行所见即所得的编辑。
*   [Dynamic Storage Interface](https://github.com/Adammatthiesen/s3-interface-test) - 用于云存储文件管理的可重复使用的 Astro 组件。 目前实现与 S3 兼容的存储提供商（AWS S3、Backblaze B2、Minio 等）。
*   [Bejamas UI](https://github.com/bejamas/ui) - 现代设计系统的天体构建块。
*   [Vault CMS](https://github.com/davidvkimball/vault-cms) - 使用 Obsidian 作为您的 Astro 网站的内容管理系统。
*   [Pageel](https://github.com/pageel/pageel-core) - 强大的客户端内容管理系统 (CMS)，用于 Astro 和 Next.js，用于直接在 GitHub、Gitea 或 Gogs 存储库上管理 Markdown/MDX 内容和图像。
*   [Astroscope](https://github.com/smnbbrv/astroscope/) - 用于制作就绪应用程序的 Astro 软件包的集合：用于 Astro SSR 的 HTTP 代理、开放式遥测支持、扩展的 CSRF 保护以及用于 Astro SSR 的生命周期挂钩（启动/关闭）以运行初始化和 Astro 服务器的清理代码。
*   [Photosuite](https://github.com/achuanya/photosuite) - 一个简单但功能丰富的图像集成，将 Lightbox、EXIF 数据、路径分辨率等集成到一个单一的零配置包中。
*   [Astro Spearly](https://www.npmjs.com/package/astro-spearly) - 使 Spearly CMS REST API 与 Astro 一起使用的集成。
*   [Astro GraphQL](https://github.com/dofbi/astro-graphql) - GraphQL 端点的 Astro 内容加载程序。 从任何 GraphQL API 中获取数据并将其用作 Astro 内容集合。
*   [Astro Env Bun](https://github.com/raiondesu/astro-env-bun) - 将使用 `envField` 定义的 `.env` 类型添加到 BUN 的 `env` 中的 Astro 集成。
*   [Storybook Astro](https://github.com/thinkoodle/storybook-astro) - Astro 组件的故事书框架。 直接在 Storybook 中渲染 `.astro` 文件，完全支持道具、控件和自动源代码生成。
*   [Astro IndexNow](https://github.com/velohost/astro-indexnow) - 在每次构建后自动将所有构建的页面提交到 IndexNow 的 Astro 集成，帮助搜索引擎更快地发现更新。
*   [Expressive Code Collapsible](https://github.com/frostybee/expressive-code-collapsible) - 一种用于表达代码的插件，用于向代码块添加可折叠功能，使用展开/折叠控件自动折叠长代码。
*   [Leaflet Loader Astro](https://github.com/nulfrost/leaflet-loader-astro) - 包括用于从您的个人数据服务器获取传单文档记录的构建时和实时加载程序，然后在您的 Astro 站点上使用。
*   [Astro Grab](https://astro-grab.nickradford.dev/) 是一个仅限开发人员的工具，可帮助您快速定位并从 Astro 组件中获取源代码。 只需按住 Cmd+G (Mac) 或 Ctrl+G (Windows/Linux) 一秒钟，然后单击任何元素将其源代码片段复制到剪贴板。

……还有一些是用 Astro 建造的！

*   [Logment](https://logment.docs.sudovanilla.org/) 是以性能为重点的发行说明和变更日志软件，可帮助个人向用户发布产品和项目更新。
