## 提示和工具

查看一些最新的社区构建的 [utilities and integrations](/integrations/) 以帮助您使用 Astro 构建。 🛠

*   [@dennismiranda/astro-cart](https://github.com/DennisMiranda/cart-npm#readme)：ASTRO的功能性电子商务购物车：侧面抽屉、浮动触发器、产品变体、持久性和通过CSS变量的主题化。
*   [@destination/astro-purge-css](https://github.com/wearedestination/astro-purge-css#readme)：从静态构建中删除未使用的 CSS 并内联小样式表的 Astro 集成。
*   [@halfgray/astro-plugin-classic-js](https://github.com/jack126guy/astro-plugin-classic-js#readme)：此 Astro 插件可以将“经典”（非模块）脚本作为静态资产进行导入，并进行最小化。
*   [@rgglez/music-laserharp](https://github.com/rgglez/music-laserharp#readme)：可播放的激光竖琴 Web 组件 (Three.js + Tone.js) 具有 Astro、React 和 Svelte 包装器以及 `gettext` 翻译。
*   [@sjohansson/astro-votes](https://www.npmjs.com/package/@sjohansson/astro-votes)：静态 Astro 网站的喜欢和不喜欢按钮。 投票作为事件进入您的分析工具，CI 作业将总数写入 JSON 文件，该站点在构建时显示它们。 没有数据库。
*   [@sudodevstudio/astro-dom-stamp](https://github.com/SudoDevStudio/astro-dom-stamp#readme)：将 `data-*` 属性印在从获取的数据中呈现的 DOM 元素上。
*   [astro-comments](https://www.npmjs.com/package/astro-comments)：即插即用的自托管评论 Astro：任何服务器、任何存储，都可以在没有 JavaScript 的情况下工作。 在开发中。
*   [astro-smart-links](https://astro-smart-links.vercel.app/)：ASTRO 集成，为内部和外部链接添加智能造型和断链检测。
*   [astro-strict-csp](https://github.com/Evgenii-Zinner/astro-strict-csp#readme)：零依赖性 ASTRO 集成用于严格内容安全策略（零“不安全内联”）、内联样式和脚本提取、捆绑、子资源完整性 (SRI) 散列和 CSP 强制执行。
*   [env-parity-plugin](https://github.com/acus9345/env-parity-plugin#readme)：当 `.env.example` 中的变量丢失或为空时，或者当您的代码读取一个时，您的 Astro Build 或 Dev 服务器失败，示例没有列出。
*   [sri-sentinel](https://mrlouiswright.github.io/sri-sentinel/)：子资源完整性 (SRI) 生成器和检查器。
