**ASTRO 将捐赠 100,000 美元来支持我们生态系统中的开源项目，这些项目每天都能改善 Astro 用户的生活。**

Astro 是用于构建博客、营销和电子商务等内容驱动网站的 Web 框架。 这个新的 Astro 生态系统基金将在未来 12 个月内向 10 家项目维护者奖励 10,000 美元的赠款**。 每个接受者将获得一次性赠款，以支持和继续他们的工作，代表更大的 Astro 生态系统。

为了庆祝发布，我们的前三个赠款接受者是：

*   **[@pilcrowonpaper](https://twitter.com/pilcrowonpaper) — 用于 [Lucia](https://lucia-auth.com/) 和 [Lucia + Astro middleware](https://lucia-auth.com/getting-started/astro/)** 的工作
Lucia 是目前开发中最令人兴奋的 JavaScript 库之一，不仅适用于 Astro，还适用于整个 JavaScript 生态系统。 Lucia 专注于对 Astro 的内置第一方支持，为用户提供了一个完整的解决方案来拥有自己的身份验证。
*   **[@ota-meshi](https://github.com/ota-meshi) — 用于 [eslint-plugin-astro](https://github.com/ota-meshi/eslint-plugin-astro)** 的工作
Astro ESLint 插件已下载超过 1,000,000 次，并为您的项目的其余部分提供了对 Linting `.astro` 文件的基本支持。
*   **[@Mike\_Andreuzza](https://twitter.com/Mike_Andreuzza) — 用于天文主题和模板的工作**
Michael (AKA [Lexington Themes](https://lexingtonthemes.com/)) 是 Astro 生态系统中最令人兴奋的主题作者之一，已经发布到 [our catalog](https://astro.build/themes/) 的 30 多个免费和高级模板。

资金来自我们自己的开源赞助基金，通过企业赞助和个人捐款收集和管理。 我们感谢主要的开源赞助商使这成为可能：[Vercel](https://vercel.com/)、[Storyblok](https://www.storyblok.com/)、[Sentry](https://sentry.io/)、[Netlify](https://www.netlify.com/)、[Google Chrome](https://developer.chrome.com/)、[and more](https://github.com/withastro/astro#sponsors)。 没有他们的支持，这一举措将永远不可能实现。

**有兴趣支持我们的工作吗？ [Sponsor us!](https://www.notion.so/Partner-with-Astro-b05cfd5dcf4248dcbea4a2d81554efed?pvs=21)** 筹集的资金的 100% 被投资回社区。 详细了解我们在 [GitHub](https://github.com/withastro/.github/blob/main/FUNDING.md) 上的开源资金方法，并在 [Open Collective](https://opencollective.com/astrodotbuild) 上浏览我们完全透明的项目资金。

从 0 美元到 200,000 美元
--------------------

Astro 作为一个开源项目运营。 通过[Open Collective](https://opencollective.com/astrodotbuild)，我们遵循开放式治理模式、开放式路线图流程和完全开放的预算流程。 我们对 Open Collective 的资金完全由赞助和捐赠给该项目，这些项目来自公司和一些了不起的个人。

两年前，我们的开放集体有 0 美元。 今天，我们管理着估计的年度赞助预算为 178,374.52 美元，总资金超过 200,000 美元，全部来自外部捐赠。

达到这种程度的赞助不是一夜之间发生的，也不是偶然发生的。 我们的资金是过去两年与大型赞助商的持续努力和外展的结果。 这是我个人最自豪的 Astro 中不太明显的项目之一。

早期，我们中的一群人也决定形成[The Astro Technology Company](https://astro.build/blog/the-astro-technology-company/)。 该公司为该项目提供额外的全职资源，这也是我们能够为维护者、贡献者和生态系统建设者社区保留 100% 的赞助的另一个原因。

我们不会掉以轻心。 像 Astro 生态系统基金这样的倡议让我们利用这个幸运的位置，也回馈和支持我们社区中其他不太明显的开源项目。

支持开源软件
-----------------------------

![xkcd comic about open-source dependencies depicting a complex and barely stable structure made out of various sized blocks labeled as "All modern digital infrastructure". A small block seemingly integral to the building's infrastructure is labeled as "A project some random person in Nebraska has been thanklessly maintaining since 2003."](https://imgs.xkcd.com/comics/dependency.png)

开源软件是我们都受益的技术基础的重要组成部分。 每个使用开源软件赚钱的公司都应该以某种方式支持他们的支持。

我们很幸运有赞助商了解这一点的重要性。 例如：

*   谷歌通过他们的 [Web Framework & Tools Performance Fund](https://opencollective.com/chrome) 分散了超过 2,000,000 美元。
*   Sentry 最近在 2023 年宣布了 [$500,000 total contribution to open-source software](https://blog.sentry.io/we-just-gave-500-000-dollars-to-open-source-maintainers/?original_referrer=https%3A%2F%2Fsentry.io%2F)。
*   Vercel、Netlify 和 CloudCannon 都赞助 React、Svelte、Solid.js 和 Eleventy 等流行开源项目的全时开发。

[Nicholas Zakas](https://twitter.com/slicknet)（[ESLint](https://eslint.org/)的创建者）对我们来说也是一个巨大的灵感，[his original writing](https://humanwhocodes.com/blog/2022/06/sponsoring-dependencies-open-source-sustainability/)和[advocacy](https://eslint.org/blog/2022/02/paying-contributors-sponsoring-projects/)对于开源项目之间的再分配模型也是如此。 仅仅因为我们自己是一个开源项目并不意味着我们也不能与其他不太明显的项目和维护者共享我们的资源。

Astro 生态系统基金是我们把钱放在嘴边。 每个 Astro 用户都将从这些未来的赠款接受者的工作中受益，我们很自豪能够支持他们。
