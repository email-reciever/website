发布
---------

Astro 的发展不断前进，在 10 月份有几个值得注意的版本：

*   [Astro 3.2](/blog/astro-320/)：此更新使您可以更好地控制浏览器历史堆栈，通过视图转换实现页面导航，包括用于屏幕阅读器的路由播音员，并且集成现在可以动态添加其他集成。
*   [Astro 3.3](/blog/astro-330/)：此版本引入了一个实验性的 `<Picture />` 组件，增强了语法突出显示，带来了包的出处，并添加了各种生活质量的改进。
*   [Astro 3.4](/blog/astro-340/)：引入页面部分，以及图像优化的改进和实验开发覆盖的第一次预览。
*   [Starlight 0.11](https://github.com/withastro/starlight/releases/tag/%40astrojs%2Fstarlight%400.11.0)：添加了对带有组件覆盖的自定义星光 UI 的支持，向侧边栏链接添加属性，并改进了 `<title>` 标签。

请参阅 [Astro Discord](https://astro.build/chat) 中的 `#announcements` 通道了解我们所有 repos 中的版本，包括 Starlight、VS Code 扩展、编译器、软件包和集成！ 遵循 [Astro on GitHub](https://github.com/withastro/) 了解所有更新。

文档
-----

我们扩展了一些高度请求的功能教程！

*   [Content Collections](https://docs.astro.build/en/tutorials/add-content-collections/)
*   [View Transitions](https://docs.astro.build/en/tutorials/add-view-transitions/)

“Talking and Doc'ing”是我们每周的现场不和谐电话，我们在参与文档项目时让社区参与其中！ 我们通常会跳入共享的代码空间或 hackmd 文档，每个人都可以参与。 本月的活动包括：

*   现场复习和测试两个新的迷你教程
*   改进我们的文档公关模板并创建一个新的 GitHub 操作以欢迎首次贡献者
*   所有动手使用Astro Docs检查表查看翻译提交，以获得每个人的`hacktoberfest-accepted` PRs合并
