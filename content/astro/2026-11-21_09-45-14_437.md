[Contenda](https://contenda.co/)是一家2021年登场的人工智能公司，一直在朝着为每个人制作内容的雄心勃勃的目标而努力。 他们的愿景始于成为开发者倡导者的催化剂，通过使各种媒体的内容重新利用变得容易。

开发者倡导者是软件公司与他们的开发者用户之间的桥梁，经常创建内容以帮助教育和提高社区对特定功能的认识。 Contenda 可以将视频教程变成博客。 这可以节省时间，甚至可以使跨职能团队更容易合作。

当 Contenda 需要与其他人公开分享博客文章时，他们求助于 Astro 和 Netlify 作为他们的解决方案。 这种技术的组合使他们专注于使协作和内容创建变得容易的目标。

挑战
-----------

Contenda 是一个不到 10 人的团队。 他们经常需要互相分享博客来解决痛点和进行评论，但如果不互相分享他们的电子邮件和 API 密钥，他们就无法做到这些事情。 这也给他们知道最终必须解决的客户带来了安全问题。 为了解决内部和外部用户的这些问题，Contenda Created [Share Pear](https://github.com/Contenda-Team/share-pear) 是一种用于快速共享 Markdown 博客文章预览的开源工具。

要求
-------------

[Share Pear](https://github.com/Contenda-Team/share-pear) 需要在不要求后端更改的情况下构建，因为 Contenda 不想通过管理额外的复杂性来使自身超载。 理想情况下，它还需要具有成本效益但最好是免费的。

除了满足他们的要求外，选择 Astro 的主要好处是它的灵活性。 借助 Astro，可以使用 React 等流行的 JavaScript 框架。 可以仅使用 HTML、CSS 以及必要时的普通 JavaScript 构建站点。 这使具有较少 Web 开发经验的团队成员（例如产品设计师和内容作者）能够编辑和维护网站，而无需任何开发人员干预。

Cassidy（竞争首席技术官）看到了将 Astro 与 Netlify 的按需建设者配对的机会。 Astro 是显而易见的选择，因为它具有原生支持 Netlify 的构建器和将 Markdown 渲染为 HTML 的组件。 这也有助于 Contenda 之前为他们的主要营销网站选择了 Astro，因此该技术足够熟悉，让团队的其他成员加入。

解决方案和实施
----------------------------

Contenda 在 Astro 的开发者社区中取得了成功。 该团队能够在 [Astro’s community Discord server](https://astro.build/chat/) 中获得核心团队和积极贡献者的帮助。 从那里，建筑共享梨迅速移动。

结果
--------

[Share Pear](https://github.com/Contenda-Team/share-pear) 已经上线了大约一个月，开源社区和 Contenda 的客户都使用 [use their app](https://signup.contenda.co/)。 在撰写本文时，30% 的用户使用共享 PEAR 方法共享博客，此功能已成为该平台上使用最多的 3 个用户之一。

Contenda 只用了一个月的时间就构建了这个功能。 该团队估计，如果他们没有选择 Astro 作为他们的解决方案，他们的时间会增加两倍或三倍。
