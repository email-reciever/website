### Astro Team News

This month saw two new additions to the team: welcome, [Kenji Tomita](https://github.com/jp-knj) as our newest maintainer! We’re happy to have you aboard!

We’re also excited to announce our newest Astro core maintainer, [Armand Philippot](https://github.com/ArmandPhilippot "Follow Armand Philippot on Github")! You’ll see Armand taking charge on several documentation initiatives, as well as keeping our French translations up to date, and contributing to several areas of the codebase.

Please join us in welcoming both Kenji and Armand! Further proof that if you start translating Astro docs, you just might find yourself riding the “Translator-to-Maintainer Express” 🚄

### Did you know?

Astro now has a [Luma event calendar](https://luma.com/astrodotbuild) to track conferences, meetups, and other events around the Astroverse… like [Reuben Tier](https://bsky.app/profile/otterlord.dev "Follow Reuben Tier on Bluesky") at [React Advanced London](https://reactadvanced.com/#person-reuben-tier) in November!

If you are holding a local meetup, talk, event, or speaking at a conference, let [Sarah Rainsberger](https://bsky.app/profile/sarah11918.rainsberger.ca "Follow Sarah Rainsberger on Bluesky") know! We don’t have all the details worked out, nor the specific criteria for posting external events. But we do want to make Astro events around the globe more discoverable. So, if you’re willing to give this a try, so are we!

And the first (past) event on our Luma calendar was the Astro Happy Hour in Amsterdam, sponsored by Netlify! Thanks for coming out for drinks, snacks, and great conversations. Stickers were exchanged, acquaintances were (re)united, new friends were made, alliances were formed, and plans were hatched.

## Tips & Tools

The latest community-built [utilities and integrations](/integrations/) to help you build with Astro. 🛠

*   [🌟 Starlight Links](https://github.com/HiDeoo/starlight-links) - Visual Studio Code extension providing IntelliSense for links in Markdown and MDX files for Starlight documentation projects.
*   [🌟 Mixedbread Search for Starlight](https://github.com/mixedbread-ai/mixedbread-starlight) - A Mixedbread integration for Starlight to replace the default Pagefind search.
*   [🌟 Starlight DocSearch Typesense](https://github.com/typesense/starlight-docsearch-typesense) - A Starlight plugin that adds DocSearch powered by Typesense for fast, typo-tolerant documentation search.
*   [Astro Chatty GPT](https://github.com/unfolding-io/astro-chatty-gpt) - A simple chatbot API for your Astro site. Powered by Upstash search, GPT-5 and AI-SDK.
*   [Astro ATProto OAuth Starter](https://tangled.org/@daffl.xyz/astro-atproto-starter) - A minimal Astro starter template demonstrating OAuth authentication with the AT Protocol (ATProto), the decentralized social networking protocol used by Bluesky and other services.
*   [Astro Single File](https://github.com/onmax/astro-single-file) - An integration that allows you to bundle the CSS and HTML in a single file.
*   [Astro Users](https://github.com/CosyZone/astro-users) - An Astro integration for user management with Cloudflare D1 database.
*   [Expressive Code language badge](https://github.com/frostybee/expressive-code-language-badge) - A plugin for Expressive Code that adds language badges to code blocks with customizable styling.
*   [Astro View Transition Script](https://github.com/byronogis/astro-view-transition-script) - A utility function to execute a callback that is compatible with Astro’s view transitions.
*   [Astro NProgress](https://github.com/byronogis/astro-nprogress) - An integration to support NProgress.js nanoscopic progress bar that is compatible with Astro’s view transitions.
*   [Astro Markdown Export](https://github.com/shaheemMPM/astro-markdown-export) - An Astro integration that generates static Markdown files from your content collections during build.
*   [Astro Loader for Valise](https://github.com/zakj/astro-loader-valise) - Astro content loaders for the art inventory system Valise, available for both artwork and collections.
*   [Astro Google Reviews](https://github.com/wally-website/wally-astro/tree/main/packages/astro-google-reviews) - Embed the Google reviews widget (powered by Wally) in your Astro site with a single component.
*   [Astro Theme Toggler](https://github.com/yarso-su/astro-theme-toggler) - A simple, minimal, and optimized theme toggler utility for Astro with vanilla JS.
*   [Astro Dropdown](https://github.com/yarso-su/astro-dropdown) - A simple, customizable dropdown menu utility for Astro with only vanilla JS.
*   [Astro Shield](https://github.com/meeghele/astro-shield) - A minimal integration that deters automated scrapers through client-side challenges without requiring external services.
*   [Astro Plugin Media](https://github.com/moecasts/remark-media) - An Astro media plugin that supports embedding multiple audio and video players in Markdown.
*   [Agent Summary](https://github.com/nuasite/nuasite/tree/main/packages/agent-summary) - A tiny Astro integration that turns your built site into a machine-readable catalog (`AGENTS.md`) for agentic or LLM-driven tooling.

… and some built with Astro!

*   [npm provenance overview](https://delucis.github.io/npm-provenance-overview/) - Quickly see publishing security for a maintainer’s npm packages.
*   [🌟 Starlight themes](https://starlight-themes.netlify.app/) - The one place to preview all Starlight themes. Having trouble choosing between Catppuccin, Flexoki, Rapide, and Ion? Find all your favourite community-built Starlight themes available in one demo site with a theme toggle!
