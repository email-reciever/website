我们很高兴地宣布 [Storyblok](https://www.storyblok.com/) 是 Astro Content Layer API 的发布合作伙伴，这是我们将远程和 CMS 数据引入 [content collections](https://docs.astro.build/en/guides/content-collections/) 的新方法。 Storyblok 是无头 CMS 的先驱，具有内置的可视化编辑器。 它可以与营销人员进行协作，而不会阻碍开发团队采用新兴的前端技术。

借助内容层，您现在可以将来自 Storyblok 等 CMSE 的内容以及本地 Git 支持的 Markdown 和 MDX 组合在一起。 使用 Storyblok 加载器，您可以在 Dev 中同步远程数据并在更改时自动刷新。

使用 Storyblok 加载程序
---------------------------

要使用新加载器（在 alpha 中），首先安装 `@storyblok/astro` 包：

npm 安装@storyblok/astro@alpha

然后导入并使用 `src/content/config.ts` 配置文件中的加载程序：

从“@StoryBlok/Astro”导入 { StoryBlokLoader }；从“Astro:Content”导入 { DefineCollection }；
const storyblokCollection = defineCollection({ loader: storyblokloader({ accessToken: import.meta.env.StoryBlok_token, version: "published", }),})
导出常量集合 = { Storyblok: StoryblokCollection,}

就是这样，从这里您可以像本地集合一样查询和使用集合。 Storyblok 附带一个 `StoryblokComponent` 为您渲染块。 以下是您如何在传播途径中使用它的示例。
