最新版本
----------------

次要版本引入了新功能和改进。 看看有什么新鲜事！

*   [Astro 5.11](https://github.com/withastro/astro/blob/refs/heads/main/packages/astro/CHANGELOG.md#5110) - 新的内容安全策略 (CSP) 功能，在使用 Node.js 适配器时选择退出 HTML 流的功能等等！
*   [Astro 5.12](https://github.com/withastro/astro/blob/refs/heads/main/packages/astro/CHANGELOG.md#5120) - TOML 支持内容加载器、实验原始环境值、改进的 Netlify 适配器开发体验等等！
*   [Starlight 0.35](https://github.com/withastro/starlight/blob/main/packages/starlight/CHANGELOG.md#0350) - 自定义文档的新方法，包括旁边的图标、自动生成的侧边栏链接的属性、页面 slug 处理等！

提示和工具
-------------

最新的社区构建的 [utilities and integrations](/integrations/) 可帮助您使用 Astro 构建。 🛠

*   [Astro YouTube Loader](https://github.com/ascorbic/astro-loaders/tree/main/packages/youtube) - 一种集成，允许您使用 YouTube Data API v3 加载 YouTube 视频，并使用 Astro 网站中的数据。 包括用于实时内容集的实验性运行时 YouTube 视频加载。
*   [Resend Newsletter Starter](https://github.com/notrab/resend-newsletter-starter) - 使用 Astro、重新发送和 React 电子邮件创建您自己的时事通讯表单！
*   [Astro SSR Table](https://github.com/tresero/astro-ssr-table/) - 一种集成功能，用于创建强大的、服务器端渲染的数据表。 包括用于服务器端分页、排序和全文搜索的帮助程序和组件。
*   [Continuous Translation](https://github.com/pelikhan/action-continuous-translation) - 使用内置支持 Astro Starlight 的 AI 自动翻译和维护 Markdown 文档的 GitHub 操作。
*   [Blogue](https://github.com/iabrmv/blogue) - 使用 Astro 集成和 GitHub 工作流自动化创建和管理 Markdown 博客文章的 CLI 工具。
*   [Astro Leaflet](https://github.com/pascal-brand38/astro-leaflet) - 用于 Leaflet 的原生 Astro 组件，一个用于显示移动友好交互地图的 JavaScript 库。
*   [Astro Headstart](https://github.com/san4d/astro-headstart) - 用于管理 HTML 文档头的 Astro 组件和实用程序。
*   [Astro HTML Helper](https://github.com/kjrocker/astro-html-helper) - 将普通 HTML 转换为更惯用的 Astro 语法的 CLI 工具。
*   [Astro Google Tag Manager](https://github.com/codiume/orbit/tree/main/packages/astro-gtm) - 将 Google 跟踪管理器集成到您的项目中的插件，让您可以直接从 Astro 网站管理营销和分析代码。
*   [Astro Auto Alias](https://github.com/zakarialaoui10/astro-auto-alias) - 根据您的项目结构自动生成路径别名。
*   [Astro i18next](https://github.com/vyxos/astro-i18next) - i18Next 集成了 Astro 的动态命名空间加载和 TanStack 路由器支持。
*   [WorldMap Astro component](https://www.npmjs.com/package/astro-worldmap-choropleth) - 具有搜索功能、可配置数据视图和可自定义模式内容的 Astro 交互式世界地图组件。
*   [Astro Nanostores i18n](https://github.com/openscript/astro-i18n/tree/main/libs/astro-nanostores-i18n) - NanoStore i18n JS 库的 Astro 版本，可使您的 Web 应用程序可翻译。
*   [Astro LLMS text](https://github.com/aligundogdu/astro-llms-txt) - 在构建 Astro 项目时基于您的页面生成 `llms.txt` 的集成。
*   [Zastro Web Sockets](https://github.com/zachhandley/ZAstroWebsockets) - 支持带有预先修补的适配器的 Astro SSR 应用程序的通用 WebSocket 支持。
*   [Expressive Code Fullscreen](https://github.com/frostybee/expressive-code-fullscreen) - 一个富有表现力的代码插件，可为您的代码块添加全屏查看模式。
*   [Astro Routify](https://github.com/oamm/astro-routify) - 用于 ASTRO 的 API 路由器，由基于 TRIE 的匹配器提供支持。
*   [Astrojs Mixpanel](https://github.com/litlynx/astrojs-mixpanel) - 需要最少配置的 Astro.js 的 MixPanel 集成。
*   [Astro m3e](https://github.com/fabesmo/astro-m3e) - 基于材料 3 表现设计系统的现代 Astro UI 组件库。
*   [Astro React i18next](https://github.com/jeremyxgo/astro-react-i18next) - 将 i18next 和 react-i18next 集成到您的 Astro 网站中，为 React 组件提供强大的 i18n 支持。
*   [Astro WebAudioStream](https://github.com/ZachHandley/WebAudioStream/tree/main/packages/astro-web-audio-stream) - 用于 iOS Safari 安全的 Web 音频流的 Astro 集成，具有即时播放、逐行加载和内存管理的功能。
*   [Astro ETag](https://github.com/Ovyerus/astro-etag) - 用于为您的构建生成 ETag sidecar 文件的 Astro 集成。
*   [Astro Normalize Trailing Slash](https://github.com/ReunMedia/astro-normalize-trailing-slash) - 一个简单的实用程序，用于将 URL 中的尾随斜线标准化以匹配您的 Astro 项目的 `trailingSlash`。
*   [Astro Varlock](https://www.npmjs.com/package/@varlock/astro-integration) - Varlock 的 Astro 集成，用于管理您的环境变量，具有类型安全和安全性。
*   [Astro Posthog](https://github.com/jop-software/astro-posthog) - 用于 Posthog 的 Astro 集成，在您的 Astro 应用程序/网站中进行 GDRP 友好跟踪。
*   [BCMS Astro Components](https://www.npmjs.com/package/@thebcms/components-astro) - 一组使用 BCMS 内容的 Astro 组件。
