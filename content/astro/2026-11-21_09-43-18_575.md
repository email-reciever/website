**ASTRO 4.13 现已推出！ 此版本包括稳定的实验功能、日志记录改进等。**

此版本包括以下亮点：

*   [**Stable: Request Rewriting**](#stable-request-rewriting)
*   [**Stable: Content Collections JSON Schemas**](#stable-content-collections-json-schemas)
*   [**Logging Improvements**](#logging-improvements)

要升级现有项目，请使用自动 `@astrojs/upgrade` CLI 工具。 或者，通过运行包管理器的升级命令手动升级：

    # 推荐：NPX @ASTROJS/升级
    # 手动：npm安装astro@latestpnpm升级astro --latestyarn升级astro --latest

稳定：请求重写
--------------------------

[In Astro 4.8](https://astro.build/blog/astro-480/#experimental-request-rewriting)，我们添加了对请求重写的实验性支持，这是一个强大的功能，可以用于渲染另一个页面，而无需在 Astro 页面和端点中更改浏览器的 URL。 在 Astro 4.13 中，我们很高兴地宣布请求重写现在稳定！

如果您在 Astro 4.13 之前已经使用请求重写，您现在可以从 Astro 配置中删除 `experimental.rewriting` 选项。 现在默认启用该功能。

从“astro”导入 { defineConfig }；
导出默认的 defineConfig({ 实验性: { 重写：true }})

有关此功能的更多信息，请查看 [Astro rewrites documentation](https://docs.astro.build/en/guides/routing/#rewrites)。

稳定：内容集合 JSON 模式
---------------------------------------

[In Astro 4.5](https://astro.build/blog/astro-450/#experimental-json-schemas-for-data-collections)，我们介绍了自动为数据内容集合生成 JSON 模式的（实验）功能。 在 Astro 4.13 中，此功能现在稳定！

如果您在 Astro 4.5 中使用 Content Collection JSON 模式，您现在可以从 Astro Config 中删除 `experimental.contentCollectionJsonSchema` 选项。 现在默认启用该功能。

从“astro”导入 { defineConfig }；
导出默认 defineConfig({ 实验性: { contentCollectionJsonSchema: true }})

在 Astro 项目中定义数据内容集合时，Astro 现在将自动为该集合生成 JSON 架构。 然后可以在编辑器中使用此模式来为您的数据提供自动完成、验证等。

有关此功能的更多信息，请查看 [Astro content collections schema documentation](https://docs.astro.build/en/guides/content-collections/#enabling-json-schema-generation)。

记录改进
---------------------

作为我们对缓慢构建的无休止的斗争的一部分，Astro 4.13 在构建过程中对日志记录输出进行了小幅改进。

需要很长时间的页面现在将其时间记录为红色，从而更容易发现构建过程中的瓶颈。

![A screenshot of the terminal showing the output of a build with two pages. One of the page has the time it took to build (603ms) highlighted in red.](/_astro/slow-page.CGU4Z9CX_ZSeUtW.webp)
