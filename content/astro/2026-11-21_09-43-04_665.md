下一级本地化
------------------------

Starlight 从第一天开始就具有多种语言，V0.28 将其提升到一个新的水平。 Starlight 的内置本地化系统现在由一流的 [`i18next`](https://www.i18next.com/) 库提供支持，可供您在网站的任何地方使用。

使用任何 Astro 组件的新 [`Astro.locals.t()`](https://starlight.astro.build/guides/i18n/#using-ui-translations) 方法来渲染 Starlight 的内置 UI 标签或您自己的自定义字符串，包括对插值和复数化的支持：

<p>{astro.locals.t('404.text')}</p><!-- <p>页面未找到。 检查 URL 或尝试使用搜索栏。 </p> -->
<p>{astro.locals.t('componentcount', { count: 99 })}</p><!-- <p>我有 99 个组件 🎉</p> -->

此更新使 Starlight 成为开箱即用的国际化功能的无与伦比的选择。 今天从单一语言开始，并有信心在时机成熟时准备好翻译您的文档。

按需渲染支持
----------------------------

自 v0.27 起，Starlight 支持全动态服务器端渲染。 在星光选项中设置 `prerender: false` 以禁用页面的静态生成并切换到 Astro [on-demand rendering mode](https://docs.astro.build/en/basics/rendering-modes/)：

astro.config.mjs

starlight({ title: 'Docs on Demand', PreRender: false,}),

这可以解锁用户身份验证和个性化等功能，使 Starlight 更加灵活。 查看我们的 [Docs on Demand demo](https://starlight-ssr.netlify.app/) 以了解一些可能性。 感谢 [Fryuni](https://github.com/Fryuni) 实现此功能！

记住你的标签
-----------------------

Starlight 的 [`<Tabs>` 组件](https://starlight.astro.build/components/tabs/) 现在支持跨页面导航记住用户首选项。 这使您的读者可以选择他们喜欢的软件包管理器或操作系统等选项，并查看文档中其他地方反映的偏好。 要启用此功能，请为 `<Tabs>` 添加匹配的 `syncKey` 属性：

src/content/docs/example.mdx

从“@ASTROJS/STARLIGHT/COMPONENTS”导入 { TABS, TABITEM }；
<Tabs syncKey="package-manager"> <TabItem label="npm">npm安装@astrojs/starlight</TabItem> <TabItem label="pnpm">pnpm add @astrojs/starlight</TabItem> <TabItem label="yarn">yarn 添加@astrojs/starlight</TabItem></Tabs>

侧边栏状态持久性
--------------------------

Starlight 建立在久经考验的 Web 技术之上，以最少的 JavaScript 提供简单的静态 HTML，以实现最佳性能。 我们听到用户反馈，全页导航可能会造成破坏性，因为每个页面加载时侧边栏状态都会丢失。

从 v0.26 开始，Starlight 凭借轻量级的自定义元素在导航中持久并恢复侧边栏状态，从而实现更流畅的浏览体验。 这是一种渐进式增强功能——如果 JavaScript 在用户设备上不可用，侧边栏照常呈现，确保所有人都能获得强大的体验。

更简单的侧边栏配置
-----------------------------

在早期版本的 Starlight 中，设置 [sidebar config](https://starlight.astro.build/guides/sidebar/) 可能会变得有点冗长：

astro.config.mjs

starlight({ title: 'old skool starlight', sidebar: [ { label: 'page on', link: '/one' }, { label: 'page 2', link: '/two' }, // ... ],}),

使用 Starlight v0.25，内部链接变得更加简单。 您现在可以仅指定要链接到的页面的 Slug，Starlight 将自动将页面标题用作链接标签：

astro.config.mjs

starlight({ title: 'Cutting Edge Starlight', sidebar: [ '一', '两个', // ... ],}),

作为奖励，使用此语法，您可以免费获得链接检查 - 不再是意外的 404S！ 感谢 [Lorenzo](https://github.com/lorenzolewis) 添加此功能。
