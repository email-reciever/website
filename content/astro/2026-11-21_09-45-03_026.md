欢迎，世界。

**“ASTRO 适合所有人”**是我们团队中的一句共同话语。 它最初是帮助我们设计 API 并与我们的用户建立联系的一种说法。 但随着 Astro 的发展，这种可访问性的核心价值已经不仅仅是功能开发。

Astro 适合所有人
----------------------

如果 Astro 真的适合所有人，那么您必须包括地球上大多数不会说英语的地球（83%）！ 18 个月前，我们决定认真投资并投资于改革我们的文档，这包括一项重大国际化 (I18N) 倡议。

今天，Astro Docs 已被正式翻译成 12 种不同的语言，总共翻译了 1000 多页。 甚至我们完整的介绍性教程（总共 32 页）也被翻译成六种不同的语言。 这些语言覆盖了 50 多个国家的数十亿人，为许多原本难以可靠使用 Astro 的人打开了大门。

![Astro docs homepage with the language picker drop down menu of available languages](/_astro/langpicker.BxABmFu8_1wb2rK.webp)

我们的翻译几乎完全由世界各地的志愿者提交的开源贡献组成。 我们非常感谢迄今为止做出贡献的每一个人。

今天是我们的官方社区日庆祝活动，所以我们想分享我们如何在 Astro 建立这个国际化引擎。 我们很幸运拥有开源中最好的社区之一，并希望在这篇文章中与您分享我们的一些成功和挑战。

识别非代码贡献
---------------------------------

通常，开源项目过于关注代码贡献（问题、拉取请求、错误修复、新功能）而忽略其他形式的支持。 我们使用 Astro 做出的最重要的早期决定之一是改变这一点，并从第一天就明确指出和识别非代码贡献。

这已明确写入我们的 [GOVERNANCE.md](https://github.com/withastro/.github/blob/main/GOVERNANCE.md#get-involved) 文档中，该文档指出某人可以通过任何措施和贡献形式成为 Astro 的维护者，而不仅仅是代码行。

今天，我们一些最好的新维护者通过非代码贡献开始：

*   文档
*   翻译
*   支持
*   社区建设和宣传

贡献者入职
-----------------------

成功完成您的第一个开源贡献有时是最困难的部分。 考虑到这一点，我们精心构建了我们的 i18n 贡献者的旅程，尽可能少的摩擦和进入障碍。

并非所有潜在的贡献者都会熟悉 GitHub 涉及 Git、分支、合并冲突等的工作流程。将非代码贡献者投入到这样一个代码繁重的环境中似乎是一个奇怪的选择。 但是，通过将我们的代码存储在 GitHub 上，我们可以将我们的内容保存在开放平台上，同时将翻译的内容与文档网站本身的代码保持一致。

**这意味着每个贡献者，对于各种贡献，使用相同的平台并具有相同的贡献经验。** 不是将国际化视为“其他”事物，而是文档的一部分。 我们的开放式 PR 列表包括翻译以及内容更新和站点基础设施代码修复。

![A selection of Astro docs open PRs on GitHub, showing translation PRs next to a PR to add new CMS guide content.](/_astro/github-pulls.BhGG5JmA_LN4X0.webp)

为了帮助人们感到舒适，并为他们提供一些关于如何开始的明确方向，我们创建了一个完整的 [Translation Guide](https://github.com/withastro/docs/blob/main/contributor-guides/translating-astro-docs.md) 以及我们的常规 [CONTRIBUTING.md](https://github.com/withastro/docs/blob/main/CONTRIBUTING.md)。 这不仅包含有关我们的翻译如何运作的技术细节，而且对于任何可能对贡献前景感到不知所措的初学者来说，也充满了建议和提示。

通讯
--------------

我们的翻译人员不仅完全融入了我们的“文档作为代码”流程，而且还更广泛地进行了社区讨论和决策。

我们的翻译人员在他们自己的 `#docs-i18n` 通道和专用的语言专用线程中协调和密谋在 Astro Discord 服务器上。 这是一个特殊的地方，他们可以在翻译工作时自由地用自己的语言说话（或谈论）自己的语言。

同时，我们的翻译人员是更广泛的 Astro 社区和讨论中的积极参与部分，参与一般或非主题对话。 您还经常会在更具体的渠道（例如 `#dev` 或 `#docs`）中找到它们，由于它们的参与，我们能够从他们的反馈中为我们的文档和我们的核心产品提供一些国际化改进。

当然，您还会发现他们在我们的 `#support` 线程中删除了文档链接并回答问题，因为他们对文档的翻译非常了解，因为他们对文档进行了翻译！

自动化和工具
-----------------------

知道如何开始是一回事。 但是，翻译人员也需要知道_where_才能开始！

在心爱的 Astro 维护者 Hippo 的带领下，我们的文档团队构建了一个自定义 [Translation Tracker](https://i18n.docs.astro.build/)，是我们 i18n 自动化的展示品！ 它跟踪每个由语言标记为“可用于翻译”的文档页面，并报告其当前状态：

*   完全翻译和最新；
*   需要更新以匹配英文文档；
*    或者，尚未翻译。

![The Translation Tracker table, showing languages across the top, individual pages down the side, and various symbols in each cell, such as an X for missing content or a green check for up-to-date.](/_astro/translation-tracker-table.CjnbP5Ol_Z1YhzIr.webp)

在内部，它使用 Git 历史来比较语言之间的变化，通过一些检查定义每个页面的状态，并生成一个 GitHub 链接，其中包含页面需要与英文版本同步的所有提交。 它由 GitHub Actions 提供支持，就在我们的文档库中。

![A small selection of the Translation Tracker's summary by language, showing one language expanded to list the translations needed for that language.](/_astro/translation-tracker-summary.DsJkRc16_ZG7YlR.webp)

我们的翻译跟踪器还使用 GitHub Data 列出需要母语人士评论的开放式翻译 PR，这是无需打开自己的 PR 的压力就可以开始的好方法！

![A list of open PRs needing reviews, for example 'i18n(ko) translate rss.mdx'](/_astro/translations-needing-reviews.1qkHE-m3_Z2f6Oor.webp)

**清楚地了解我们的翻译需求，我们能够快速欢迎和加入已经知道哪些贡献的新 i18n 贡献者。**

通过数据驱动决策
------------------------------

最初，我们仅根据我们社区对我们的兴奋和可用性做出翻译决定（例如在文档中支持哪些语言）。 当我们刚刚开始时，这被证明是一个很好的策略。 但随着 Astro Docs 的发展，我们需要做出更明智的决定。

我们必须尽早做出的困难电话之一是决定我们将正式支持哪些语言进行翻译。 或者更确切地说，我们不会。 官方支持一种语言是一个相当大的承诺，这意味着我们不能接受向我们提出的每一种语言。 我们的目标是在更容易维护的语言和最能产生影响的语言之间找到平衡。 获得优质信息和教育的机会在任何地方都不一样——作为那些拥有英语能力特权的人，我们能够解决这些不平等问题，并为最需要翻译的社区倡导。

为了帮助我们做出这些困难的决定，我们分析了几个数据点，例如我们不和谐中每种语言的成员数量、每种语言的国家列表、几项开发人员调查的人口统计数据和 [EF’s English Proficiency Index](https://www.ef.com/wwpt/epi/)。 通过从明确的目标开始，我们可以选择帮助我们专注于满足全球开发者社区需求的语言。

支持我们的贡献者
----------------------------

尤其是过去几个月，我们一直专注于支持和认可我们的国际化团队所做的大量工作。 虽然 Astro Docs 长期以来一直拥有存储库的每个贡献者的 GitHub 头像的“脸堆”，但我们现在在网站的每个翻译版本上显示一个 [dedicated translators’ face pile](https://docs.astro.build/es/getting-started/#traducir)。 我们受欢迎的社区 [Astro Badges](https://astro.badg.es/v1/achievements/) 现在还展示了独特的 i18n 贡献，以确认翻译和翻译评论。

![Four Astro badges, displaying various achievement levels for community members, such as Universal Translator for merging 40 i18n PRs or Rosetta Stone for reviewing 40 i18n PRs](/_astro/translator-badges.Bo5vXbdQ_PNIA.webp)

多亏了 Astro 开源项目拥有如此多的慷慨赞助商和支持者，我们能够定期颁发货币社区奖项。 在发布时，我们已经直接向我们的国际社会提供了 4000 多美元的公开集体资金。 其他形式的奖励包括来自 [Astro Swag Shop](https://shop.astro.build/) 的限量版 SWAG 物品（所有收益直接返回我们的公开集体）、津贴和赞助。

往前走
--------------

我们对文档中的国际化（i18n）的专注结果感到非常兴奋，我们对我们收到的热情和赞赏感到谦卑和满足。 我们知道任何开源项目的成功取决于支持您所在社区的_every_ 成员。

这只是一个开始，我们非常高兴能与更广泛的开源社区分享我们的国际化故事！ 特别是，我们希望对我们的本地开发工具（例如我们的翻译跟踪器）进行概括和打包，以便其他开源项目可以使用它们。 敬请期待，加入我们，为开源国际化打造一个新时代！
