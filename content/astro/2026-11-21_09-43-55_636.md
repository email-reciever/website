开发工具栏 API 改进
-----------------------------

Astro 4.7 对用于制作工具栏应用程序的 API 进行了相当大的改进。 我们此版本的主要目标之一是让您更轻松地构建和维护工具栏应用程序，我们很高兴为您带来：

*    一个 `defineToolbarApp()` 助手，可以更轻松地定义工具栏应用程序。 这种模式应该感觉很熟悉，因为它类似于 Astro 配置中的 `defineConfig()` 和用于定义中间件的 `defineMiddleware()`。
*   新的 `app` 和 `server` 助手，使工具栏和服务器之间的消息更容易发送和接收。
*   用于构建工具栏应用程序的全新入门项目。 这将帮助您立即开始构建自己的工具栏应用程序。 运行 `npm create astro@latest -- --template toolbar-app` 并开始构建您的工具栏应用程序。
*   A [recipe guiding you step-by-step through building your own toolbar app](https://docs.astro.build/en/recipes/making-toolbar-apps/) 从头开始，包括如何使用 React 或 Preact 等 JSX 框架构建您的应用程序。
*   改版 [documentation of the Dev Toolbar App API](https://docs.astro.build/en/reference/dev-toolbar-app-reference/)，更新了所有示例以显示使用新方法。

我们希望您会喜欢这些改进，我们迫不及待地想看看您用它们构建了什么！

更新检查器
---------------

从此版本开始，Astro 现在将在您运行开发服务器时检查更新。 如果有新版本可用，您将在终端中看到一条消息，其中包含有关如何更新的说明，并在开发工具栏中。

![A screenshot of the message that Astro shows in the terminal when an update is available: update > New version of Astro available: 4.6.3. Run npx @astrojs/upgrade to update.](/_astro/update-checker.VJTwn7dc_Z1q0h0s.webp)

为避免向您发送太多更新消息，Astro 将每 10 天检查一次更新，并且仅在您落后多个版本时才会显示消息。 您可以通过运行 `astro preferences disable checkUpdates` 或将 `ASTRO_DISABLE_UPDATE_CHECK` 环境变量设置为 `false` 来禁用此功能。

`allowJs: true` 用于最严格的打字稿预设
--------------------------------------------

我们的 `strictest` TypeScript 预设先前包含 `allowJs: false`，以完全禁用 `.js` 文件的使用。 事实证明，这对普通用户来说有点过于严格，并且经常引起混乱。 我们现在将此更改为 `allowJs: true`，它允许您在项目中使用 `.js` 文件。

这不应该是一个重大更改，但如果您使用的是 `strictest` 预设并且仍希望禁用 `.js` 文件，请在 `tsconfig.json` 中手动设置 `allowJs: false`。
