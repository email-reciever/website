我很高兴地宣布 [Webflow](https://webflow.com/?utm_source=Astro&utm_medium=tech-partner&utm_campaign=fy26-astro&utm_content=fy26-blog-post) 已捐款 **150,000** 以支持 ASTRO 作为我们最新的官方赞助合作伙伴。 此外，Webflow 刚刚宣布他们选择 Astro 来支持他们即将到来的 AI 应用程序功能，我们非常高兴能与他们合作。

Webflow 是一个原生网站体验平台，使团队能够直观地构建、管理和优化令人惊叹的网站，这些网站提供客户期望的消费者体验以及他们需要的企业级性能和规模。

> Webflow 为营销人员、设计师和开发人员提供了不妥协的构建自由。 Astro 和 Webflow 通过消除障碍、加快工作流程和开辟新的创意可能性，共享同样的精神。 我们很高兴与 Astro 合作，确保我们的社区依赖于保持开放、可持续和为未来做好准备。

— [Allan Leinwand](https://x.com/leinwand)，CTO

网络流云
--------------

[Webflow Cloud](https://webflow.com/feature/cloud?utm_source=Astro&utm_medium=tech-partner&utm_campaign=fy26-astro&utm_content=fy26-blog-post) 通过在您的 Webflow 网站旁边部署全栈 Web 应用程序和动态的品牌 Web 体验，扩展了 Webflow 平台的功能。 它在今年早些时候通过Astro和Next.js支持JavaScript和React生态系统推出。

借助 WebFlow Cloud 上的 Astro，您可以将可视化站点构建与代码相结合，以构建动态站点体验——预订引擎、定价计算器、客户门户、仪表板等——同时还可以从 Webflow 中实现 Astro 所熟知的性能和开发人员体验。

Webflow Cloud 在 Cloudflare 的全球边缘网络上运行，这意味着开发人员还可以通过我们的官方部署适配器受益于 Astro 对 Cloudflare 的测试支持。

即将推出：AI Code Gen，由Astro提供支持
----------------------------------------

但这还不是全部。 在今天的 Webflow Conf 上，Webflow 的首席执行官 Linda Tong 和联合创始人 Vlad Magdalin 宣布了 Webflow 的最新 AI 演变：一种 AI 驱动的代码生成工具，可让用户从一个提示中构建生产就绪的 Web 应用程序和可重用的代码组件。 然后选择 Astro 为它供电。

**即将推出，所有由 Webflow AI 在其平台上构建的应用程序都将由 Astro 提供支持。** 这是很多新的 Astro 开发人员！

我们喜欢这种配对。 这意味着 Webflow 上的所有 AI 生成的应用程序都将受益于 Astro 成熟的基础——默认快、可访问且易于扩展。 我们专注于构建内容驱动网站的开发人员使 Astro 非常适合此用例。 了解更多信息并申请提前访问 [Webflow’s code generation beta](https://webflow.com/feature/code-gen?utm_source=Astro&utm_medium=tech-partner&utm_campaign=fy26-astro&utm_content=fy26-blog-post) 以使用 Webflow AI 构建 Astro Web 应用程序和代码组件。

我们迫不及待地想在未来几个月内分享更多关于这个令人兴奋的新平台的信息。

Astro ❤️ Webflow
-----------------

我们感谢整个 Webflow 团队对 Astro 的支持。 这笔赞助资金将直接投资于开源项目，以支持 Astro 的长期维护，使每个人都受益。 您可以在 GitHub 上的 [FUNDING.md](https://github.com/withastro/.github/blob/main/FUNDING.md) 中了解有关我们如何使用这些资金的更多信息。

谢谢你，网络流！
