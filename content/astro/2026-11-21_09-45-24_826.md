Astro 2.4 刚刚掉落，功能：

*   **[Stronger scoping for CSS](#scopedstylestrategy)**：新的选择加入标志 `scopedStyleStrategy` 允许您为 Astro 组件的范围样式配置更高的特定性。
*   **[Improved <Code /> component](#code--component-improvements)**：升级 Shiki 和对内联的支持。
*   **[SSR support in sitemaps](#ssr-in-sitemaps)**：现在在构建过程中将已知路由内置到站点地图中。
*   **[Middleware (experimental)](#middleware-experimental)**：定义在页面组件和端点之前运行的代码，以拦截请求和修改响应。
*   **[CSS inlining (experimental)](#css-inlining-experimental)**：允许您通过 `<style>` 标记内联样式表。

范围风格策略
--------------------

Astro 使用 `:where` 伪选择器进行范围内的 Astro 组件样式。 这种方法意味着您的组件样式具有与用普通 CSS 编写的相同的特殊性。 这种方法的缺点是，我们不能保证组件样式总是会覆盖全局样式，这通常是预期的和想要的行为。

我们添加了 `scopedStyleStrategy` 选项，可用于使用基于类的选择器打开高特异性策略：

从“astro/config”导入 { defineConfig }
导出默认的 defineConfig({ scopedStyleStrategy: "class",})

此策略可能会用作 Astro 3.0 中的默认值。

<Code /> 组件改进
------------------------------

<Code /> 组件有一些新的改进：

*   升级到 **Shiki 0.14** - Astro 以前在 Shiki 0.11 上。 此升级带来了许多改进，最显着的是新主题和语言支持。
*   新的 `inline` 道具防止添加包装 `<pre>`。 如果您希望在段落中内联语法突出显示，这很有用。

站点地图中的 SSR
----------------

`@astrojs/sitemaps` 包已更新为包括对服务器端渲染的支持。 以前，仅在使用 `output: 'static'` 时才支持站点地图，因为在构建时动态路由未知。

新版本现在也可以与 `output: 'server'` 一起使用，并将仅输出 _known_（即静态）路由的站点图。 动态路由被排除在外。 无需更改配置即可启用此功能。

中间件（实验）
--------------------------

中间件支持的早期预览已登陆 2.4。 这允许您拦截请求和响应并动态注入行为。 要启用实验中间件支持，请在 `astro.config.mjs` 中添加 `experimental` 标志：

从“astro/config”导入 { defineConfig }
导出默认 defineConfig({ 实验性: { 中间件: true, },})

除了修改请求和响应之外，使用中间件，您还可以修改所有 Astro 组件和 API 端点中可用的 `locals` 对象。 这是一个身份验证中间件的示例。 使用以下内容创建 `src/middlware.ts` 文件：

导入类型 { MiddleWareResponseHandler } 来自“Astro/Middleware”

locals.user = 用户返回 next()}
导出 { 身份验证作为 onRequest }

然后，您可以通过 Astro 组件访问：

---const { 用户 } = astro.locals---

当我们完善 API 并修复早期采用者发现的错误时，此功能将保持实验性。 请参阅 [middleware guide](https://docs.astro.build/en/guides/middleware/) 以了解更多信息。

CSS内联（实验）
----------------------------

您现在可以通过启用实验配置将样式表配置为内联到 `<style>` 标记中：

从“astro/config”导入 { defineConfig }
导出默认 defineConfig({ 实验性: { inlineStyleSheets: "auto", },})

使用 `'auto'` 选项，`vite.assetInlineLimit` 下方的样式表将作为 `<style>` 标记添加，而不是通过 `<link>` 获取。

您还可以将选项设置为 `'always'` 以强制内联。 目前，默认值为 `'never'`，但在 Astro 3.0 中可能会更改为 `'auto'`。
