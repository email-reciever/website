**更多实验性内容安全策略，包括使用您首选的适配器为 CSP 提供服务！**

Astro 5.11 是一个小的次要功能，它带有新的 CSP 功能，并且在使用 Node.js 适配器时可以选择退出 HTML 流。

*   [**CSP with adapters**](#csp-with-adapters)
*   [**Disable HTML streaming**](#disable-html-streaming)

要升级现有项目，请使用自动 `@astrojs/upgrade` CLI 工具。 或者，通过运行包管理器的升级命令手动升级：

    # 推荐：NPX @ASTROJS/升级
    # 手动：npm安装astro@latestpnpm升级astro --latestyarn升级astro --latest

带适配器的 CSP
------------------

到目前为止，静态页面只能通过 `<meta http-equiv="content-security-policy">` 元素提供内容安全策略 (CSP) 标头。 这对某些用户来说是一个不便，因为 `<meta>` 元素不支持诸如 `report-uri`、`frame-ancestors` 和 `sandbox` 等某些 CSP 指令。

从 Astro 5.11.0 开始，官方 `@astrojs/node`、`@astro/netlify` 和 `@astro/vercel` 适配器可以为预渲染页面指定自定义标头。 这意味着这些适配器现在可以为静态页面设置 CSP 标头，即使在预渲染页面上也允许支持所有指令。

这是通过启用新的 `experimentalStaticHeaders` 适配器选项而获得的实验功能：

astro.config.mjs

从“astro/config”导入 { defineconfig }；从“@astrojs/node”导入节点；
导出默认的 defineConfig({ experimental: { csp: true }, 适配器: node({ mode: "standalone", experimentalStaticHeaders: true })})

您可以立即在 Netlify、Vercel 和 Node.js 上开始使用此功能，Cloudflare 支持即将推出。

我们也将很快提供对 Cloudflare 的支持，它将使用 [`_headers` 文件](https://developers.cloudflare.com/pages/configuration/headers/)。

在引擎盖下，适配器利用了名为 [`experimentalStaticHeaders`](https://docs.astro.build/en/reference/adapter-reference/#experimentalstaticheaders) 的新适配器 API 功能。 如果您是适配器开发人员，您现在可以为您的用户提供完整的 CSP 功能。

禁用 HTML 流
-----------------------

现在可以将 `@astrojs/node` 适配器配置为使用新的 `experimentalDisableStreaming` 选项禁用按需页面的 [HTML streaming](https://docs.astro.build/en/guides/on-demand-rendering/#html-streaming)。

HTML 流式传输有助于提高性能，通常提供更好的访问者体验。 在大多数情况下，不建议禁用流式传输。

但是，当您需要禁用 HTML 流（例如，您的主机仅支持 CDN 级别的非流式 HTML 缓存）时，您现在可以选择退出默认行为：

astro.config.mjs

从“astro/config”导入 { defineconfig }；从 '@astrojs/node' 导入节点；
导出默认 defineConfig({ 适配器：node({ 模式：'standalone', ExperimentalDisableStreaming: true })});
