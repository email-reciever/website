我们很高兴宣布 [Netlify](https://www.netlify.com/?utm_campaign=Astro-2024&utm_source=astro-referral) 作为 Astro 的新**官方部署合作伙伴**。

这种新的合作伙伴关系将为 Astro 开发人员提供更多的协作、更多功能和更好的体验。

Netlify 将每月赞助 12,500 美元用于 Astro 正在进行的开源维护和开发。 新的赞助资金将直接投资于我们的开源社区和长期维护，使所有人受益。

以下是Netlify的Mathias Biilmann对新闻的看法：

> ASTRO 无疑是我最喜欢的开源项目之一，并为前端开发带来了新的简单感。 我一直是岛屿建筑的粉丝，Astro 已经设法围绕它建立了一个一流的框架。 在 Netlify，我们很高兴与 Astro 团队合作，帮助开发人员创建和解锁 Web 的强大功能。

— [Mathias Biilmann](https://x.com/biilmann?lang=en)，Netlify 的首席执行官兼联合创始人

在服务器岛上投注
--------------------------

Netlify 正在积极支持我们在今年晚些时候将 Server Islands 带到 Astro 的工作。 服务器岛允许您在 HTML 的静态页面上定义个性化的动态内容部分。 结果？ 从您的全球 CDN 和动态岛屿分开加载的静态“页面外壳”立即加载的网站。

服务器岛不需要任何特殊或专有的基础设施，并且无论 Astro 今天运行的地方都可以运行。 我们很高兴能与 Netlify 就此功能继续合作。 我们正在联手确保 Netlify 用户在今年晚些时候向公开的非实验性推出服务器岛时拥有丰富的服务器岛体验。

本周晚些时候回来查看一些令人兴奋的更新。

Astro ❤️ Netlify
-----------------

Astro 很荣幸也很高兴能够将 [Netlify](https://www.netlify.com/?utm_campaign=Astro-2024&utm_source=astro-referral) 作为我们的新官方部署合作伙伴。 我们感谢 Mathias Biilmann 和整个 Netlify 团队对开源软件的帮助和传福音的支持。 正是由于来自 Netlify 等公司的支持，我们才能够接受持续的维护并以开放、财务可持续的方式继续开发 ASTRO。

您可以通过阅读 GitHub 上的 [FUNDING.md](https://github.com/withastro/.github/blob/main/FUNDING.md) 文档了解更多关于我们如何使用这些资金的信息。

谢谢，网化！
