我很高兴宣布 [Mux](https://www.mux.com?utm_campaign=21819274-Astro&utm_source=astro) 作为我们的新**官方视频合作伙伴**。 Mux 将以每月 5,000 美元的价格赞助 Astro，以支持 Astro 正在进行的开源维护和开发。 此外，我们将在一些新项目上与他们密切合作（更多内容如下）。

[Mux](https://www.mux.com?utm_campaign=21819274-Astro&utm_source=astro) 为 Web 提供视频基础设施，使开发团队可以轻松发布高性能、经济高效的视频。 我们将视频视为网络上的核心原语，因此我们自然而然地抓住了合作伙伴的机会，让 Astro 开发人员更容易大规模使用视频。

> ASTRO 一直以他们对 Web 性能和开发人员体验的专注和承诺给我留下了深刻的印象。 我很高兴我们的合作伙伴关系意味着使用 Astro 的开发人员可以添加高性能视频，而不会牺牲最初将他们吸引到 Astro 的速度和简单性。

— [Matt McClure](https://x.com/matt_mcclure)，联合创始人兼开发人员体验负责人

阿斯特罗❤️复选机
-------------

此次合作伙伴发布包括两个用于 MUX 的新官方 Astro 组件：`@mux/mux-player-astro`（用于网络上的简单、高性能视频）和 `@mux/mux-uploader-astro`（用于将视频上传到 Mux 的临时解决方案）。 您今天可以在 npm 上获得这两个组件。

我们与 Mux 团队密切合作，开发了这种集成，并确保它易于使用并与 Astro 配合得很好。 查看我们的 [new documentation](https://docs.astro.build/en/guides/media/mux/) 以了解有关这些新组件以及如何在任何 Astro 项目中使用 Mux 的更多信息。

如果您需要一个帐户，您可以在 [mux.com](https://www.mux.com?utm_campaign=21819274-Astro&utm_source=astro) 免费开始使用 MUX。 为了庆祝我们的合作伙伴关系，您可以通过使用代码 `ASTRO` 在注册时获得额外的 50 美元积分。

我们非常感谢整个 MUX 团队对 Astro 的支持。 新的赞助资金将直接投资于开源项目，以支持 Astro 的长期维护，使所有人受益。 您可以通过阅读 GitHub 上的 [FUNDING.md](https://github.com/withastro/.github/blob/main/FUNDING.md) 文档了解更多关于我们如何使用这些资金的信息。

谢谢你，多克！
