Astro 4.4 现已上市！ 此版本包括开发工具栏的性能审核、改进的流媒体性能、自动推断远程图像尺寸的能力等。

亮点包括：

*   [**Performance Audits**](#performance-audits)
*   [**Audit list**](#audit-list)
*   [**Improved streaming performance**](#improved-streaming-performance)
*   [***远程图像的新 `inferSize` 属性**](#自动推断远程图像)

如何升级
---------------

要利用最新功能，请确保您运行的是最新版本的 Astro。 您可以通过运行 `@astrojs/upgrade` 命令升级到 Astro 4.4：

npx @astrojs/升级

或者通过为您的包管理器运行升级命令：

npm install astro@latestpnpm 升级 astro --latestyarn 升级 astro --latest

绩效审计
-------------------

Astro 4.4 包括为开发工具栏添加性能审计。 与当前可用的可访问性审核非常相似，性能审核将帮助您识别和修复 Astro 网站中的性能问题。 例如，当延迟加载的图像在折叠上方时，开发工具栏会警告您，建议您使用急切加载来获得更好的性能。

![Shows a tooltip telling the user to use loading='lazy' on an image below the fold.](/_astro/perf-audit.YzxhGteG_aCk6.webp)

审计清单
-----------

从 Astro 4.4 开始，开发工具栏的审计应用程序包含一个小 UI，显示已检测到的问题列表。 此列表是快速查看需要解决的问题并跳转到页面的相关部分以修复它们的好方法。 将来，我们将扩展此 UI 以显示有关每个问题的更多信息，并提供有关如何修复它们的更多指导。

改进的流媒体性能
------------------------------

此版本包括流式传输的性能改进。 我们最近发现，在 Node.js 上运行 `ReadableStream`s 比预期的要慢，并且在 Node.js 上运行时迁移了 Astro 使用 `AsyncIterable` 而不是使用 `AsyncIterable`。 值得注意的是，这种变化在极端情况下将大型侧边栏的 Starlight 网站的构建时间缩短了多达 47%。 有关此更改的更多技术细节，请查看 [pull request](https://github.com/withastro/astro/pull/9614)。

无需更改即可利用这些改进，这对静态构建和运行时性能都有好处。 作为一种享受，您可以拥有更快的构建时间和改进的运行时性能。

自动推断远程图像的尺寸
--------------------------------------------

感谢 [Oliver Speir](https://github.com/OliverSpeir)，Astro 4.4 现在可以推断出远程图像的尺寸。 新的 `inferSize` 属性可用作远程图像上先前所需的 `width` 和 `height` 属性的替代品。 在使用 CMS 或其他外部来源的图像时，这在构建时不知道图像的尺寸时特别有用。

要启用此功能，请将 `Image` 或 `Picture` 组件上的 `inferSize` 属性设置为 `true`：

---import { image, picture } 来自 "Asro:assets" ;---
    <Image src="https://example.com/image.jpg" alt="A cool image" inferSize /><Picture src="https://example.com/image.jpg" alt="A cool image" inferSize />

或作为 `getImage()` 的参数：

从“astro:assets”导入 { getImage };const processedImage = await getImage({ src: "https://example.com/image.jpg", inferSize: true });

请注意，此功能具有性能成本，尤其是在 SSR 中，因为它需要部分下载图像以推断页面的其余部分才能呈现页面的其余部分。 我们建议仅在必要时使用此功能，而应尽可能手动指定 `width` 和 `height` 属性。

在我们的文档中阅读有关 [使用 `inferSize` 与远程图像](https://docs.astro.build/en/guides/images/#infersize) 的更多信息。
