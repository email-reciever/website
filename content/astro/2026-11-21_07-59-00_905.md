反应性部分水合作用
-----------------------------

![Code example that shows off using the new client:media hydrator.](/_astro/responsive-hydration.C_TVey0Z_1aHaWs.webp)

响应式网站通常会加载仅在特定设备尺寸上可见的组件，例如移动侧边栏菜单。 作为开发人员，避免在非移动设备上加载仅移动代码可能很困难（不可能？）。 结果是浪费了在最终用户甚至无法看到的代码上的时间。

Astro 用 [partial hydration](https://docs.astro.build/core-concepts/component-hydration) 解决了不必要的 JavaScript 的问题，这种技术只涉及水化需要交互性的组件，并将其余部分保留为静态 HTML。 **ASTRO v0.18 添加了一种使用 [CSS media queries](https://docs.astro.build/core-concepts/component-hydration#mycomponent-clientmediaquery-) 来定制部分水合的新方法，以避免将代码发送到不需要它的设备。**

将 `client:media` 指令添加到组件中，它仅在满足介质条件后才会水合。 在手机上？ 跳过您永远不会看到的桌面标头的任何昂贵且不必要的 JavaScript。 在台式机或笔记本电脑上？ 不要加载移动汉堡菜单。 这是 Astro 致力于最大限度地减少发送给用户的不必要的 JavaScript 的承诺的一部分。

Astro Components 中的命名插槽
------------------------------

![Using multiple slots to provide the head and body parts of a Layout component.](/_astro/named-slots.C45kXt2R_2b4i2e.webp)

[Named slots](https://developer.mozilla.org/en-US/docs/Web/Web_Components/Using_templates_and_slots) 是 [browser APIs](https://developer.mozilla.org/en-US/docs/Web/Web_Components/Using_templates_and_slots) 和 [Vue](https://vuejs.org/v2/guide/components-slots.html#Named-Slots) 等 Web 框架中使用的标准 Web 功能。 在此版本中，[Astro adds support for named slots](https://docs.astro.build/core-concepts/astro-components#slots) 到 Astro 组件、页面和布局。

命名插槽对于页面布局特别有用。 布局现在可以为页面的不同部分指定插槽。 您可以将元数据标记放在“头”插槽中，将页面内容放在“正文”或“内容”插槽中。 您的布局现在完全可定制，您需要的插槽数量多或少。

坚实的支持
--------------

[Solid](https://www.solidjs.com/) 是一个基于 JSX 的 UI 框架，它将自己称为 React 熟悉的、现代的、更具反应性的替代方案。 我们对 Solid 感到非常兴奋，使用 Astro 的新 [Solid renderer](https://github.com/withastro/astro/tree/main/packages/renderers/renderer-solid)，您可以在项目中使用 SOLID 作为一流的框架。

添加对 Solid（我们的第三个官方支持的 JSX 框架）的支持并不容易，并且需要对 Astro 如何处理 JSX 进行重大重构。 最终的结果是值得的：Astro现在更擅长支持不同类型的JSX，甚至可以支持新的React V17 JSX转换。 Astro 的这个新基础应该在未来为我们提供支持。

Solid v1.0 的发布是 Astro 多框架承诺的完美展示：在现有项目中与其余组件并排尝试您的第一个 Solid 组件。 在其他构建工具迫使您选择单个框架并坚持下去的地方，Astro 使多框架项目轻松用于短期代码迁移或长期站点架构。

点燃 SSR 支持
----------------

Web 组件的服务器端渲染 (SSR) 终于出现在这里，这要归功于 LIT 和新的 [Lit renderer for Astro](https://github.com/withastro/astro/tree/main/packages/renderers/renderer-lit)。

多亏了 [Declarative Shadow DOM](https://web.dev/declarative-shadow-dom/) - 一个现在在 Chrome 中可用的新 HTML 功能 - LIT 项目能够发布对 LIT 的实验性 SSR 支持。 在 JavaScript 中定义自定义元素，并使用 Astro 渲染它，就像 React 或 Vue 中的任何其他组件一样。 与其他 JS 组件不同，您仍然在 HTML 中使用自定义元素标记名称。

Lit SSR 渲染器是实验性的，一些现有的 Web 组件可能无法使用新的 API。 随着其他 Web 组件库采用声明式阴影 DOM 和常见的 API 进行渲染，我们希望也为这些库提供支持。 随着我们转向 Astro V1.0，我们将继续改进和改进这种支持。
