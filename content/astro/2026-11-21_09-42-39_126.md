### 提示和工具

最新的社区构建的实用程序和集成，可帮助您使用 Astro 构建：

*   [Domain Expansion](https://domainexpansion.gg/) - 添加对增量构建的支持的 Astro 集成。
*   [Sonda](https://sonda.dev/frameworks/astro) - 可视化您的 Astro 捆绑包
*   [`astro-word-loader`](https://astro-word-loader.netlify.app/) - 将 `.docx` 和 `.doc` 文件加载到 Astro 内容集合中
*   [`astro-typed-links`](https://github.com/florian-lefebvre/astro-typed-links) - 自动获取指向页面的链接的 Astro 集成
*   [`astro-globals`](https://github.com/gingerchew/astro-globals) - 在全局虚拟模块中存储站点数据的 ASTRO 集成
*   [`@terrahq/astro-core`](https://www.npmjs.com/package/@terrahq/astro-core) - 旨在简化资产管理和简化表单创建的核心 Astro 组件的集合
*   [Flickr loader](https://astro-loaders.lekoarts.de/) - Flickr API 的内容层加载器
*   [`github-repos-astro-loader`](https://github.com/chenasraf/github-repos-astro-loader) - 用于获取 GitHub 存储库及其自述文件的 Astro 内容加载程序
*   [`starlight-plugin-show-latest-version`](https://starlight-plugin-show-latest-version.trueberryless.org/) - 在您的插件的 Starlight 文档中显示您的 Starlight 插件的最新发布版本
*   [Bag of tricks: `<TurnSignal />`](https://events-3bg.pages.dev/library/TurnSignal/) - 设置每个导航的单独的每个链接视图转换并选择不同的动画

…和一些内置的_with_ astro：

*   [RSS Beauty](https://rss.beauty/) - 将 RSS 提要转换为精美的阅读格式，以获得更好的阅读体验。
*   [ASTRO `glob()` Loader Config Generator](https://astro-glob-loader-config-generator.netlify.app/) - 需要检查您的内容集合 `loader` 配置？ 使用 Astro 的内置 `glob()` 加载程序时，使用此 Web 应用程序生成正确的设置。
*   [OG image maker](https://ogimagemaker.com/) - 一个免费的 OG 图像生成器工具，可用于为您的博客文章、文章和社交媒体帖子创建漂亮的开放图形图像。
*   [Two idiots, one keyboard](https://two-idiots-one-keyboard.pages.dev/) - 一个受Primagen“两个白痴一键盘”视频启发的工程团队结合游戏
