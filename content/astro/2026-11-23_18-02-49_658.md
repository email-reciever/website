Starlight 是 Astro 的官方包，用于构建快速、可访问的文档网站，内置所有所需的功能。

以下是此版本的新功能：

* [**更灵活的自动生成侧边栏链接**](#flexible-sidebar-autogeneration)
* [**样式改进**](#styling-improvements)
* [**多语言网站功能**](#better-multilingual-sites)

要升级现有的 Starlight 网站，请使用自动化的 `@astrojs/upgrade` CLI 工具。这将更新 Starlight、Astro 和您正在使用的任何其他集成：

```sh
npx @astrojs/upgrade
```

请参阅 [Starlight CHANGELOG](https://github.com/withastro/starlight/blob/main/packages/starlight/CHANGELOG.md) 以获取迁移指导和破坏性更改的完整详细信息。

## 灵活的侧边栏自动生成

Starlight 从第一天开始就支持从内容目录生成侧边栏导航链接。此版本为此功能带来了新的灵活性。

之前，自动生成总是为指定的目录在侧边栏中创建一个带标签的组。有了 v0.39，Starlight 的自动生成链接可以与任何其他链接类型一起使用。

如果您在侧边栏中已经有自动生成的链接组，请通过将配置包裹在 `items` 数组中来更新它们：

astro.config.mjs

```js
starlight({  sidebar: [    {      label: 'My group',      autogenerate: { directory: 'some-dir' },      items: [{ autogenerate: { directory: 'some-dir' } }],    },  ],  // ...}),
```

这种变化使得将自动生成与不同类型的链接结合起来变得容易。例如，您现在可以在自动生成的链接旁边添加一次性自定义链接。以下示例将本地页面、`features` 目录中的所有页面和外部链接分组：

```js
starlight({  sidebar: [    {      label: 'Features',      items: [        // A page not in the features directory        'features-overview',        // All pages in the features directory        { autogenerate: { directory: 'features' } },        // An external link        { label: 'Support', link: 'https://support.example.com' },      ],    },  ],  // ...}),
```

## 样式改进

现代 CSS 每天都使每个人的生活更容易，并且在此版本中，我们将其发挥到极致。

* 我们通过 `:has()` 的魔力改进了内容中嵌套列表的间距。（查看 [完整的选择器](https://github.com/withastro/starlight/blob/ec70630cbbe43bb5b026ddabfe7224759c798a4b/packages/starlight/style/markdown.css#L34-L60) — 它非常复杂。）
* 当用户展开或折叠侧边栏组时，导致溢出，Starlight 侧边栏现在更加稳定。我们用一个简单的 `scrollbar-gutter: stable` 驱逐了布局偏移。

## 更好的多语言网站

Starlight 的国际化功能从一开始就是关键的，并且我们始终在寻找方法来推动它向前发展。本版本带来了：

* 通过 `x-default` 元链接提高多语言 SEO，链接到站点默认语言的页面。这些替代链接被 [搜索引擎](https://developers.google.com/search/docs/specialty/international/localized-versions#xdefault) 用作信号，指示如果没有其他语言可用，则应回退到哪种语言。
* 得益于 `text-autospace` CSS 属性，中文和日文文档的文本布局有所改善。这一 [较新的 CSS 属性](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/text-autospace) 通过自动在 CJK 和非 CJK 字符之间应用间距，使文本更易读。
* 我们已经将 `i18next` 更新从 v23 到 v26，`i18next` 是 Starlight 本地化 API 背后的基础库。
