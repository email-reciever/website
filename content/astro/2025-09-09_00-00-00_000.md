[CodeTV](https://codetv.dev/) 为开发人员提供视频节目，从实时编码会话到游戏节目。 他们需要一个可以处理复杂数据架构并为订阅者提供高性能流媒体平台的框架。

Jason Lengstorf 厌倦了每一次直播活动的感觉，都开始为开发人员创建引人入胜的视频内容。 CodeTV 的节目专注于原创概念和高产值，为那些厌倦了观看发布到 YouTube 的 Zoom 电话的人提供真正的电视般的选择。

借助 Astro，Lengstorf 拥有构建整个媒体平台的工具，该平台可以处理内容和性能需求并“发挥作用”，主要专注于创建原创节目。

![Four TV screens featuring CodeTV shows: Web Dev Challenge, Leet Heat, Learn With Jason, and Unspoken Tech.](/_astro/codetv-shows.CVDJsy2W_2haV46.webp)

CodeTV 的产品包括多种类型的节目。

挑战
-----------

当 Jason Lengstorf 在他的网络系列“与 Jason 一起学习”中取得成功时，他意识到他希望制作更多、多样化的视频内容。 他梦想着扩大他的教育内容，将脚本化节目与您投资的角色一起包含在内，以及开发人员正面交锋的游戏节目。

但为了朝着这个新方向前进，他需要一种新的网站。 Lengstorf意识到：“我在做电视。电视是什么样的？” 他注意到，Netflix、Hulu 和 Nebula 等已建立的媒体流媒体平台都遵循具有特定功能的一致架构：通过多个系列进行直观导航、跟踪观看的内容、新内容的通知以及对支付和帐户信息的自助订阅者控制。

CodeTV 需要做很多事情，并且可靠地做到这一点，因此花费了时间来创建内容而不是对其交付平台进行故障排除。

要求
-------------

作为一个成熟的媒体平台，CodeTV 需要一种易于与各种服务集成的解决方案：内容管理系统 (CMS)、MUX 视频流、身份验证、电子商务、数字资产管理、站点搜索以及将所有内容连接在一起的复杂工作流自动化。

有了这一切，没有膨胀的余地。 CodeTV 需要轻量级和高性能。 而且，代码需要易于组织和维护。 Astro 的“选择加入复杂性”模型正是所需要的。

> 如果我想添加一些客户端交互性，或者如果我想添加一个服务器岛，这一切都在桌面上。 它是每个组件的选择加入。 那感觉真的很好。

— Jason Lengstorf，代码电视

CodeTV 选择 MUX 提供仅订阅者视频内容的自适应比特率流。 Astro 对 Web 组件的原生支持使 Mux 的轻量级视频播放器集成起来变得轻而易举。 接下来将集成一个完整的、基于订阅的视频点播流媒体服务提供商所需的一切。

解决方案和实施
----------------------------

Astro 的渲染策略是让观众保持关注的关键。尽管 CodeTV 为用户提供了动态和个性化的体验，但 Astro 的默认静态理念使几乎每个页面都可以轻松地预渲染静态 HTML，从而缩短加载时间并降低成本。 Astro 的服务器岛允许 CodeTV 推迟个性化动态内容的加载，而不会阻止所有用户共有的内容呈现。

快速渲染、高性能页面和点播视频对 Astro 来说是没有问题的。 即使有复杂的内容层次结构，包括多个节目、季节、主持人、嘉宾等，导航 CodeTV 也感觉与改变频道一样快。

Astro 的可扩展性意味着将必要的集成添加到 CodeTV 以构建流式平台：流式传输视频的 MUX、身份验证的 Clerk、支付处理的 Stripe、内容管理的理智、对后台任务的 Inngest 以及部署到 Netlify。 通过使用服务器岛增强预渲染页面，一切都很好地集成在一起。 订阅支付、用户仪表板、自定义订阅者内容……无论他们在 Astro 投掷的内容如何，它都“正常工作”，Lengstorf 说。

> 我只是不断地添加更多的东西，每次都在想，“也许这会阻止我。” 但到目前为止，我还没有找到限制。 而且，我开始怀疑它们是否存在。

— Jason Lengstorf，代码电视

Astro 对 UI 框架的灵活支持通过在新站点中重新使用现有的 React 组件来加快迁移时间。 无需重建站点搜索解决方案，因为 Astro 完全兼容来自 Jason 站点的原始 Learn 中的 React 代码。

结果
--------

现在，Lengstorf 的大部分时间都花在了他最初的目标上，因为维护 CodeTV 网站几乎可以是事后的想法。 但是当需要添加新功能时，很容易跳回 Astro Code。 Astro 的心理模型和代码组织是有意义的，优化 API 调用或数据库延迟是没有困难的。 几乎每次他们想要提高性能时，Astro 的预渲染都是解决方案。

结果是一个内容丰富的网站，感觉动态和对观众的反应，在核心 Web Vitals 指标中在桌面和移动设备中得分非常高。

![Real World Core Web Vitals (p75): 1.5s LCP, 45ms INP, 0.0 CLS.](/_astro/codetv-cwv.CW3Aroyp_191CRI.webp)

从 Crux 报告中收集的真实世界核心 Web 重要指标。 CodeTV 在关键指标上在桌面和移动设备上具有良好的性能：最大的内容性绘画、与下一个油漆的交互以及累积的布局变化。

最初的计划是“让它工作，然后让它快点”。 但有了Astro，它马上就很快了，因为正如Lengstorf所指出的，“这就是你建立Astro的本质。” CodeTV作为一个复杂的、内容丰富的媒体流媒体平台，具有多种集成和自动化工作流程，证明了Astro的限制可能不存在。

> 我想，“让我们看看我们可以在这件事破裂之前把它推多远。” 我只是从来没有找到突破点。

— Jason Lengstorf，代码电视
