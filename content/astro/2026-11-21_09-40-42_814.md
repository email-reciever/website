我很高兴地宣布 [Cloudflare](https://www.cloudflare.com/) 已捐款 **150,000** 以支持 ASTRO 作为我们最新的官方托管合作伙伴。 这种伙伴关系加强了整个 Astro 生态系统，并有助于确保 Astro 在 Cloudflare 上获得更快、更强大的部署体验。

Cloudflare 是世界上最大的网络之一，通过其全球网络和开发者平台为数百万个网站提供支持（每秒 7800 万个 HTTP 请求！）。 与 Astro 一样，Cloudflare 相信为开发人员提供出色的开发体验并为最终用户提供出色的性能。 Cloudflare 支持我们的项目的选择验证了这一共同的使命和强大的开源软件的力量。

> 我们投资Astro是因为它代表了一个更健康的网络未来。 我们自己建立在 Astro 上，因为它是对优雅简洁的回归，为我们的开发人员和客户提供真实世界的性能。

— [Dane Knecht](https://x.com/dok2001)，Cloudflare 的首席技术官

将 Astro 部署到 Cloudflare
-----------------------------

Astro 和 Cloudflare 非常适合现代 Web 开发。 对于静态站点，Cloudflare 提供 Cloudflare 一流的全球 CDN 的即时部署。 当您需要动态功能或实时 API 时，Cloudflare 工作人员为 Astro 的服务器端渲染 (SSR) 功能提供了良好的基础。
