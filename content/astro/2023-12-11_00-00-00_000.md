[Thinkmill](https://www.thinkmill.com.au/)是一家位于澳大利亚悉尼的工程和设计咨询公司。 他们专门与包括 [Atlassian](https://www.thinkmill.com.au/work/atlassian) 和 Westpac（澳大利亚四大银行之一）的客户一起建造 [digital products](https://www.thinkmill.com.au/services/product-design-engineering) 和 [design systems](https://www.thinkmill.com.au/services/design-systems)。

Astro通过消除复杂性和避免过度设计使ThinkMill能够提高团队生产力。 Astro 对现代 Web 开发的 HTML 友好方法意味着开发人员可以更轻松地做出更改，而不会过度依赖 JavaScript。 借助Astro，ThinkMill 能够消除瓶颈，并将项目的贡献者总数从 1 增加到 15。

![](/_astro/thinkmill-results-summary.BWYAyEJU_Z16oU3O.webp)

之前：需要高级开发人员对网站进行更改，并且是流程的瓶颈。 之后：技术要简单得多，因此更多的人无需高级开发人员即可进行更改。

挑战
-----------

ThinkMill 是一个有点非常规的机构。 他们没有项目经理，而是由一群喜欢一起工作的设计师和开发人员组成。 在这种结构下，不同学科的人在项目的相同部分上合作的情况并不少见——即使这不是他们的强项。 在这里，ThinkMill 的主要挑战是。

该团队希望设计师和内容编辑能够自主地为代码库做出贡献。 但是，他们之前的技术堆栈使用了 Next.js，因为该团队喜欢 React。 这使得非开发人员和经验不足的开发人员很难做出贡献。 因此，更新网站需要团队寻求高级开发人员的帮助。 这将使开发人员脱离其流程状态并进入完全不同的环境中——这将需要时间让他们收集足够的数据来交付工作。 它还将停止最初负责这项工作的任何人的工作，因为他们需要解除封锁。

要求
-------------

为了维护一个对经验不足的开发人员以及不熟悉代码的人来说都易于使用的网站，ThinkMill 需要一个简单的解决方案。

![](/_astro/astro-benefits.D_QSi3rE_Z2r7bej.webp)

Astro 的记录非常好，并且有一个友好的社区。

ThinkMill 的开发者倡导者 Simon Swiss 强烈主张该团队使用 Astro，因为它的记录非常好。 任何想跳入该网站的人都可以轻松地提高自己的技能以开始贡献。 非高级开发人员可以仅使用 HTML 和 CSS 管理该站点，而喜欢 React 的高级开发人员可以使用 JSX 语法感到宾至如归。 Astro 还提供了非常理想的内容功能，例如 MDX 支持、语法突出显示和开箱即用的分页，因此 ThinkMill 不必构建这些功能。

> “Astro似乎在不影响开发人员的力量的情况下达到了简单使用的最佳位置。文档和友好的社区是我们选择Astro的两个重要因素。”

— Simon Swiss，开发者倡导者

该团队也不确定他们是否会坚持他们选择的解决方案。 这使得解决方案必须灵活，以防他们以后需要更换它。 Astro 允许 ThinkMill 直接支持他们的传统 MDX 文件。 同时，如果 ThinkMill 曾经想转移到无头 CMS 甚至使用 API，他们可以。

Astro 最终成为一个如此简单和灵活的工具，以至于该团队使其成为永久性的解决方案。

解决方案和实施
----------------------------

当被问及关于 Astro 最有利的两件事是什么时，Simon 引用了强大的文档和非高级工程师的入口便利性。

根据西蒙的说法，阿斯特罗很容易向双方解释。 React 工程师发现 Astro 很熟悉，因为 JSX 语法，对于只知道 HTML 和 CSS 的开发人员来说，这并没有那么大的触手可及。 Astro 感觉就像使用具有 JSX 功能的 HTML，这是整个团队都喜欢的。

该团队在他们的网站中大量利用了 Astro 组件——将其视为一个 React 项目，但没有 React 可能带来的任何复杂性。 [content collections](https://docs.astro.build/en/guides/content-collections/) 一发布，西蒙的团队就开始使用它们。 内容集合甚至允许 ThinkMill 将 Astro 与他们的内容管理工具 - 使内容集合在 GUI 中编辑。

> “Astro是跨职能团队的游戏规则改变者。它的简单性为我们的网站回购提供了一种更具包容性的工作方式。”

——罗纳德·阿维尔，首席设计师

结果
--------

### 减少摩擦

ThinkMill 从需要高级开发人员对网站进行更改，变成了今天积极管理网站的 4 名非高级设计工程师。 此外，近15人为ThinkMill网站的源代码做出了贡献——设计师和开发人员包括在内。

在 Astro 之前，由于需要时间来获得足够的上下文来做出贡献，人们很难在几天内加入该网站项目。 然而，使用 Astro，该工具非常简单、有据可查且灵活，人们可以加入 Astro 项目并在 3-4 天内发挥作用。

### 性能提升

ThinkMill 通过 [Unlighthouse](https://unlighthouse.dev/) 运行他们的 Astro 站点，该站点通过 [Lighthouse](https://chromewebstore.google.com/detail/lighthouse/blipmdconlkpinefehnmjammfjpmpbjk?pli=1) 运行每个页面。 几乎每个页面在性能、最佳实践、SEO 和可访问性方面都获得了 100 分。

![](/_astro/unlighthouse-results.iGuIBH49_1mRTOS.webp)
