欢迎来到 Astro Docs 周！ 整个星期，我们的文档维护者都在接管 [Astro’s Twitter account](https://twitter.com/astrodotbuild)。 我们将分享来自社区的文档更新和乐趣，因此请确保您关注我们！

首先，让我们花点时间谈谈 Astro Docs 和 Hacktoberfest。 我们喜欢庆祝 Astro 令人惊叹的开源贡献者。 以下是 Hacktoberfest 如何帮助我们做到这一点。

社区驱动的文档
----------------------

![Avatars for the many, many contributors to Astro docs](/_astro/contributors.rvvGfhX3_Z1LUvrf.webp)

[Astro’s documentation website](https://docs.astro.build/) 是开源的，由我们的社区驱动。 我们的 [270+ contributors](https://github.com/withastro/docs/graphs/contributors) 让您更轻松地每天使用 Astro，没有它们我们就无法做到！ 所以今年，我们想利用 Hacktoberfest 来认识他们所做的工作。

[Hacktoberfest](https://hacktoberfest.com/) 是 Digital Ocean 举办的年度活动，旨在鼓励开源参与。 每年 10 月，注册的人都可以看到他们的 PR 奖励一件 T 恤——或者以他们的名义种植一棵树！ 今年的版本首次受到欢迎[low or non-code contributions](https://hacktoberfest.com/about/#low-or-non-code)。 我们怎么能拒绝一片森林文档捐款？

播种
------------------

对我们来说，贡献有各种形状和大小。 从错字修复和 CSS 调整到更大的文档改进。 但这还不是全部！ 多亏了我们不知疲倦的翻译，Astro 的文档有 10 种语言版本。 这就是我们决定在本月集中精力的地方。

根据 Hacktoberfest 的低代码重点，我们希望鼓励新的翻译。 但是**我们不能在没有来自多语言社区的评论的情况下合并翻译。** 这可能并不明显，但好的公关审查与公关本身一样有价值。 为了认识到这一点，我们使 [get Hacktoberfest credit for reviewing PRs](https://github.com/withastro/docs/blob/main/.github/hacktoberfest.md) 成为可能。 然后我们让人们知道我们在 [Discord](https://astro.build/chat/) 和 [Twitter](https://twitter.com/astrodotbuild/status/1576221838950412289) 上的计划，坐下来等待……

那么，它是如何进行的呢？
-------------------

鼓声请... Astro 的文档合并了来自 58 个独特贡献者**的 130 多个 PR，作为今年 Hacktoberfest 的一部分！ 这包括 **41 首次贡献者** 到 DOCS 仓库。 🎉

正如我们所希望的，这些 PR 中有一半以上与翻译有关。 并且一路走来：

*   有人加快了我们的 CI 测试。
*   我们出色的西班牙团队与即将到来的PR进行了战斗，以保持“翻译收件箱零”。 （事实上，当你读到这篇文章时，他们可能会翻译这篇博文！）
*   DeNo Deploy 和 GitHub Pages 的部署指南获得了一次。
*    一位新撰稿人提交了史诗般的七页俄语翻译。
*   我们的文档中的一个错误被压制了。
*   我们的社区对我们所有的语言进行了改进。
*   一位贡献者提交了_Seven_翻译评论。
*   错别字是否得到修复？ 你打赌！

非常感谢所有参与的人！ 我们欢迎新的贡献者，但也很高兴看到我们现有的贡献者也加入了乐趣。 我们希望你们都像我们一样喜欢参加 Hacktoberfest。

Hacktoberfest 结束了，但开源是终生的
----------------------------------------------

您有兴趣参与 Astro 的文档吗？ 您可以随时在 [the docs repo on GitHub](https://github.com/withastro/docs) 或 `#docs` 频道中找到我们（`#docs` 频道](https://astro.build/chat/)。 迫不及待地想见到你并合并你的公关！
