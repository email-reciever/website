提示和工具
-------------

最新的社区构建的实用程序和集成，可帮助您使用 Astro 构建。 🛠

*   [Starwind UI](https://starwind.dev/) - 一组功能强大、可访问的组件，适用于使用 Tailwind CSS v4 设计的 Astro 项目。
*   [Zorn Player](https://studio.sudovanilla.org/) - 具有多种可定制功能的 Astro 视频播放器。
*   [Accessible Astro](https://accessible-astro.incluud.dev/) - 使用 Astro 构建可访问、高性能和美丽的网站所需的一切。
*   [`astro-obsidian-starlight-notes-template`](https://github.com/adityatelange/astro-obsidian-starlight-notes-template) - 使用您的黑曜石笔记作为内容的星光入门模板。
*   [`astro-teleport`](https://github.com/ok-98/astro-teleport) - 一个轻量级的 Astro 组件，用于使用 Web 组件在 DOM 的不同部分渲染内容。
*   [`astro-typesafe-routes`](https://github.com/feelixe/astro-typesafe-routes) - 用于类型安全 URL 生成和路由的 ASTRO 集成。
*   [`storyblock-loader`](https://github.com/nonsponsored/storyblok-loader) - 用于从 Storyblok 的 API 中获取内容的 Astro 内容层的社区构建加载程序。
*   [`astro-qiita-loader`](https://github.com/t0yohei/astro-qiita-loader) - 用于 Astro 的 Qiiita 加载器，允许您将 Qiita 帖子用作内容集。
*   [Bit](https://github.com/bitbons-ai/bit) - 用于脚手架 Astro + Pocketbase 项目的 CLI 工具。
*   [`static-only-collections`](https://inox-tools.fryuni.dev/content-utils#static-only-collections) - 指定仅在静态页面上使用的内容集合，以减少代码构建的服务器端并提高页面性能。
*   [Starlight View Transitions Plugin](https://events-3bg.pages.dev/library/StarlightPlugin/) - 在 Astro 配置中使用一行添加跨文档、浏览器原生视图转换到您的 Starlight 站点。

…和一些内置的_with_ astro：

*   [StudioCMS](https://studiocms.dev/) - 用于 Astro DB 的专用 CMS，具有全新的 Beta 8 版本。
*   [Tract Stack](https://tractstack.org/) - 一个发布平台和无代码的 Astro 网站构建器。
*   [GitHub Activity](https://github-activity.trueberryless.org/) - 查看漂亮列表中任何用户最近的 GitHub 活动。
*   [Mayo App](https://github.com/mayo-dayo/app) - 一个自托管的基于 Web 的音频流应用程序。
