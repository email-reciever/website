使用 SVGO 进行 SVG 优化
---------------------------

Astro 5.16 使用 SVGO 添加了对自动 SVG 优化的实验性支持，SVGO 是一种强大的工具，可以在不影响质量的情况下减少 SVG 文件大小。

SVG 文件通常可以进行显着优化——删除不必要的元数据、简化路径和消除冗余属性。 通过将 SVGO 集成到 Astro 的资产管道中，您的 SVG 现在会在构建过程中自动优化，从而减少带宽并缩短页面加载时间。

在 Astro Config 中启用实验性 SVG 优化标志：

astro.config.mjs

从“astro/config”导入 { defineconfig }；
导出默认的 defineConfig({ 实验性: { svgo: true, },});

默认情况下，SVGO 会使用其推荐的设置运行。 您可以通过传递 SVGO 配置选项来自定义优化行为：

astro.config.mjs

导出默认的 defineConfig({ experiment: { svgo: { plugins: [ 'preset-default', { name: 'removeViewbox', active: false } ] } }})

有关配置选项和 SVGO 插件的更多详细信息，请参阅 [SVG optimization documentation](https://docs.astro.build/en/reference/experimental-flags/svg-optimization/)。

`astro preview`的交互式快捷方式
----------------------------------------

`astro preview` 命令现在支持键盘快捷键，从而更容易控制预览服务器。 与 `astro dev` 类似，您现在可以在服务器运行的终端中使用以下热键：

    > 本地：http://localhost:4321/- 按下 O + ENTER 在浏览器中打开 - 按 Q + ENTER 退出

这些 DX 改进消除了在浏览器中手动导航到您的站点或使用 `Ctrl+C` 终止流程的需要，使预览体验更加直观且与开发服务器的工作流保持一致。

具有 `astro add --yes` 的更好的代理支持
-----------------------------------------

随着编码代理和 AI 工具在开发工作流程中变得越来越普遍，Astro 正在使使用它们变得更容易。 `astro add` 命令现在显示了一个有用的提示，说明使用 `--yes` 标志跳过人工友好的提示，清楚地表明代理如何在不卡在交互式提示上的情况下自动化 Astro 集成。

通过此更新，AI 代理和自动化工具可以无缝运行：

Astro 添加反应 - 是

当您以交互方式运行 `astro add` 时，您将在第一个交互式提示上看到有用的提示：

Astro add react# output:# 要在没有提示的情况下运行此命令，请传递 --yes 标志

无论您使用的是 Claude 代码、游标、副驾驶或任何其他 AI 辅助开发工具，这都使代理能够自主配置 Astro 项目。 无需再等待交互式确认 - 代理商现在可以完全自动化您的 Astro 设置。

`ActionInputSchema` 用于类型安全操作的实用程序类型
--------------------------------------------------

Astro Actions 现在包含 `ActionInputSchema` 实用程序类型，从而更容易地从操作定义中提取和使用输入模式。 这在构建抽象或创建可重用的操作处理程序时特别有用。

使用 `ActionInputSchema`，您可以获得操作的输入模式的确切类型：

import { type actionInputschema, defineAction } 来自 'astro:actions';import { z } 来自 'astro/zod';
Const ContactAction = defineAction({ accept: 'form', input: z.object({ email: z.string().email(), message: z.string(), }), 处理程序: ({ email, message }) => { // 处理联系表单 return { success: true }; },});
// 提取模式类型类型 ContactSchema = ActionInputSchema<typeof contactAction>;
// 获取实际输入类型 contactInput = z.input<ContactSchema>;// 结果：{ email: string; 消息：字符串 }

当您这样做时，这一点特别有价值：

*   围绕动作创建包装器函数。
*   构建表单提交摘要。
*   在您的代码库中共享操作类型。

`ActionInputSchema` 使开发人员在高级 TypeScript 模式中仍然可以获得正确的类型推断，而无需手动复制架构定义。
