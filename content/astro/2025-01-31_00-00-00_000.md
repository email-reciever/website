*   [Astro GitHub file loader](https://github.com/gingerchew/astro-github-file-loader) - 将存储在 GitHub 存储库中的文件加载到您的 Astro 内容层中。
*   [Astro Integration Template](https://astro-integration-template.netlify.app/get-started/pick-a-template/) - 构建 Astro 集成？ 只需选择一个模板并开始！
*   [`astro-ghostcms-loader`](https://github.com/MatthiesenXYZ/ghostcms-loader) - 将您的 GhostCMS 内容与 Astro 内容层一起使用。
*   [`@polar-sh/astro`](https://github.com/polarsource/polar-adapters/tree/main/packages/polar-astro) - 使用 Astro 使付款和结帐变得简单。
*   [Starlight Spell Checker](https://starlight-spell-checker.trueberryless.org/) - 这个插件为您的 Starlight 项目带来了多语言拼写、平等、可读性、英文用法、引号检查等。
*   [`astro-transition-event-polyfill`](https://github.com/louisescher/astro-transition-event-polyfill) - 在未使用视图转换时为 astro:page-load 事件添加 polyfill 的集成。
*   [Astro server todo app](https://github.com/devgauravjatt/astro5-server-todo-app) - 一个简单的 TODO 列表应用程序，由 Astro 和 Better Auth 构建。
*   [`astro-font` v1.0](https://github.com/rishi-raj-jain/astro-font) - 自动优化您的自定义字体、本地字体、字体，超过任何 CDN 和 Google 字体以提高性能。
*   [`@inox-tools/server-islands`](https://inox-tools.fryuni.dev/server-islands) - 提供一组实用程序以与 Astro 的服务器岛一起使用的集成。
