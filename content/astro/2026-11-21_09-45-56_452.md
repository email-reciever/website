**我们很高兴宣布 Astro v1.0：一个用于构建快速、以内容为中心的网站的 Web 框架。**

在过去的 16 个月中，[Astro](https://astro.build/) 已经从一个空回购增长到 [GitHub](https://github.com/withastro/astro) 和全球 30,000 名早期用户的 13,000 多颗星。 Astro 文档已被翻译成 6 种不同的语言，Astro 已经部署在 [Firebase (Google)](https://firebase.blog/)、[Trivago](https://tech.trivago.com/)、[The Guardian](https://theguardian.engineering/) 和 **IKEA** 等令人惊叹的公司中。

Astro v1.0 包含了自 4 月最初的 Beta 公告以来的一些新功能和改进，包括：

*   [Image Optimization](https://docs.astro.build/en/guides/integrations-guide/image/)：新的 `<Image />` 和 `<Picture />` 组件。
*   [MDX Support](https://docs.astro.build/en/guides/integrations-guide/mdx/)：在 Markdown 中混合 UI 组件的标准语法。
*   [SSR Builds](https://docs.astro.build/en/guides/server-side-rendering/)：服务器输出现已稳定，可供生产使用。
*   [Vite 3.0](https://vitejs.dev/blog/announcing-vite3.html#dev-improvements)：升级我们的内部构建引擎，Vite。

此 V1.0 版本象征着我们对 API 稳定性和生产准备能力的承诺。 如果您一直在等待 Astro 尝试，现在是开始的好时机。

开始使用Astro
-----------------------

*   要了解有关 Astro 的更多信息，请访问我们的新网站：[astro.build](https://astro.build)。
*   要在浏览器中立即尝试 Astro 1.0，请访问 [astro.new](https://astro.new)。
*   要在本地机器上试用 Astro，请在任何终端中运行 `npm create astro@latest`。

    # 跟随你的第一个Astro Project.npm的指导演练create astro@latest

您还可以使用下面的 Netlify Deploy 按钮将 Astro V1.0 初学者模板部署到 Web _Right Now_。 没有帐户？ 不用担心：Netlify 可以免费用于基本网站。

[![Deploy to Netlify Button](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/netlify-templates/astro-quickstart)

如果您需要帮助将现有的 Astro 项目迁移到新的 Astro V1.0，请查看我们更新的 [Migration Guide](https://docs.astro.build/en/migrate/) 和 [full documentation website](https://docs.astro.build/)。

Astro的新网站
------------------------

为了庆祝 Astro v1.0，我们启动了全新的网站重新设计：[astro.build](https://astro.build)。

![The brand new astro.build redesign](/_astro/website.CjGaxJAB_uHmou.webp)

自从我们首次推出 [astro.build](https://astro.build) 以来，发生了很多变化。 Astro 不再只是一个静态站点构建器。 您现在可以在任何流行的托管平台上将 Astro 构建为动态的 SSR 服务器。 此外，我们的生态系统已扩展为 100 多个集成，并不断增长以涵盖越来越多的功能和用例。

新网站更好地讲述了我们的故事，有一罐新鲜的油漆，专注于内容、性能和社区。 （另外，它去[warp speed](/#warp-speed)）。
