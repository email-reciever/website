奇怪的宽网
---------------

上个月的一些网站展示了您可以使用 Astro 做些什么，这些网站既古怪、创新、鼓舞人心，或者只是简单的乐趣！

*   [Utsubo](https://www.utsubo.com/) - 一个屡获殊荣的技术第一的创意工作室，专门从事实时 3D 体验、交互式装置和 WebGPU。
*   [Space Bingo](https://artechfuz3d.itch.io/space-bingo) - 由 Astro 和 Socket.io 构建的多人银河宾果游戏。 在实时多人比赛中与整个银河系的朋友或陌生人竞争。
*   [Radio Rock Hits](https://radiorockhits.com/) - 一个使用 SSR 构建的网络广播电台和一个带有 React 的持久播放器组件。 由 GraphQL 提供支持的新闻。
*   [Cat Cafe Map](https://catcafemap.com/) - 探索世界各地的舒适景点，您可以与毛茸茸的同伴一起收养、玩耍和闲逛。
*   [MontFort](https://mont-fort.com/) - 一个由三个.js、GSAP 和 Storyblok CMS 构建的令人惊叹的 Astro 网站。
*   [Interior Scene](https://vr-interior.oaksun.studio/) - 在 3.js 和 Astro 中具有渐进纹理加载的 Matterport 风格的虚拟导览演示。 奖励：它有香蕉FPS模式。

提示和工具
-------------

最新的社区构建的实用程序和集成，可帮助您使用 Astro 构建。 🛠

*   [`react-router-astro`](https://github.com/lilnasy/react-router-astro) - 使用 React Router 和 Astro 创建服务器渲染 SPA 的入门模板。
*   [`astro-rerun-island`](https://github.com/TheOtterlord/astro-rerun-island) - 在 `astro:after-swap` 上重新运行持久服务器岛以刷新您的内容而不会显示用户不必要的加载屏幕的集成。
*   [`astro-meta`](https://github.com/ArifRabbaniIn/astro-meta) - 轻松为您的 Astro 应用添加元标记。
*   [`astro-path-helpers`](https://www.npmjs.com/package/astro-path-helpers) - 为 Astro 路由生成类型安全路径辅助函数的 ASTRO 集成。
*   [`astro-ai-robots-text`](https://delucis.github.io/astro-ai-robots-txt/) - 禁止 `robots.txt` 中禁止 AI 刮刀的 ASTRO 集成。
*   [`s3-compatible-loader`](https://github.com/L4Ph/something-with-astro/tree/main/packages%2Fs3-compatible-loader) - 将 S3 兼容的对象存储转换为与 Obisidian 的远程保存功能良好的 CMS 的内容加载器。
*   [`astro-gemtext`](https://github.com/aspizu/astro-gemtext) - 一种 ASTRO 集成，可让您将 `.gmi`（双子座协议文档格式）文件作为 Astro 站点中的页面使用。
*   [`astro-itchio`](https://artechfuz3d.github.io/astro-itchio-publisher/) - 自动部署到 itch.io 的 ASTRO 集成。
*   [Astro Clerk loader](https://github.com/LekoArts/astro-loaders/tree/main/packages/clerk) - 只需提供方法名称即可访问 Clerk 后端 API 的选择。
*   [Astro Plausible loader](https://github.com/LekoArts/astro-loaders/tree/main/packages/plausible) - 为 Astro 的内容层提供一个合理的内容加载器。 您可以访问 Stats API v2 以查看您网站的历史和实时统计数据。
*   🌟 [`starlight-markdown-blocks`](https://delucis.github.io/starlight-markdown-blocks/) - 使用自定义 (`:::block`) 类型扩展 Starlight 的 Markdown Asides 语法。
*   🌟 [`starlight-toc-overview-customizer`](https://github.com/trueberryless-org/starlight-toc-overview-customizer) - 使用可自定义的概览标题增强星光的目录
*   [`reveal-animation-handler`](https://github.com/CarloBu/reveal-animation-handler) - 智能检测和尊重自然换行符的 Astro 响应式文本动画系统。 此实用程序提供具有多种动画类型和可定制选项的动态、视口感知动画，同时在所有设备上保持响应式设计。
*   [`astro-appwrite-demo`](https://ark.sudovanilla.org/Korbs/astro-appwrite-demo) - 在 Astro 上使用 AppWrite 的演示，允许最终用户在帐户页面上创建帐户并更新其用户名。
*   [`astro-d1-magiclink`](https://github.com/OliverSpeir/astro-d1-magiclink) - 基于 Lucia-Auth、Astro Actions 和 Cloudflare D1 的 Magic Link Auth。
*   [`@inox-tools/content-utils`](https://inox-tools.fryuni.dev/content-utils#git-times) - 内容集的实用程序，现在为任何基于文件的内容加载器提供 Git 信息。

…和一些内置的_with_ astro：

*   [WorksForMe](https://worksforme.online/) - 输入一个时间和一个时区并获得一个可共享的链接，以便世界各地的每个人都知道该会议的确切时间！
*   [Astro UI](https://github.com/BTS-CM/astro-ui) - 使用 Astro、React 和 Electron 构建的 BitShares UI。
