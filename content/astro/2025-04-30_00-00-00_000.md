最新版本
----------------

次要版本引入了新功能和改进。 看看有什么新鲜事！

*   [Astro 5.6](https://github.com/withastro/astro/blob/refs/heads/main/packages/astro/CHANGELOG.md#560) - Cloudflare 中的一流 Astro:Env 和实验会话支持，对预取的更多控制等等！

提示和工具
-------------

最新的社区构建的实用程序和集成，可帮助您使用 Astro 构建。 🛠

*   [Astro Tanstack](https://github.com/universse/astro-tanstack) - 使用 Astro、TanStack 路由器和查询构建单页应用程序 (SPA)。
*   [cfetch](https://github.com/withstudiocms/cfetch) - 为 Astro SSR 提供可缓存获取功能的 Astro 集成。
*   [Astro WordPress](https://github.com/sijad/astro-wordpress) - 使用 Astro 构建 WordPress 主题。
*   [Nova IDE Astro extension](https://extensions.panic.com/extensions/com.johnlindop/com.johnlindop.nova-astro/) - 为 Panic 的 Nova IDE 提供 `.astro` 文件的语法高亮和基本自动完成功能。
*   🌟 [Starlight Fullview Mode](https://windmillcode.github.io/starlight-fullview-mode/) - 将星光的侧边栏折叠并将主要内容扩展为全宽的极简主义插件。
*   [Inox Tools: cut short](https://inox-tools.fryuni.dev/cut-short) - 一种 ASTRO 集成，可让您立即停止处理请求并发送回自定义响应，现在使用 `disableStreaming` 选项。
*   [Typed Rest Routes](https://github.com/louisescher/typed-rest-routes) - 允许创建类型安全服务器端点的 ASTRO 集成。
*   🌟 [Starlight scroll to top](https://frostybee.github.io/starlight-scroll-to-top/) - 向文档网站添加滚动到顶部按钮。
*   [Astro og](https://github.com/morinokami/astro-og) - 在社交平台上预览您的页面并显示其开放图形数据的 Astro Dev 工具栏应用程序。
*   [Astro Google tag manager](https://www.npmjs.com/package/@picoo-studio/astro-google-tagmanager?activeTab=readme) - 用于将 Google Tag Manager 代码段注入 Astro 项目的集成，支持流行的 Web 分析工具。

…和一些内置的_with_ astro：

*   [Starlight Changelog](https://starlight-changelog.netlify.app/) - 一个漂亮的星光自己的 `CHANGELOG.md` 版本，每个新版本都会自动更新。 为它添加书签以跟上星光的变化！ 内置Astro的[Starlog theme](https://astro.build/themes/details/starlog/)和[`astro-loader-github-releases`内容加载器](https://github.com/lin-stephanie/astro-loaders/tree/main/packages/astro-loader-github-releases)
*   [Tract Stack](https://tractstack.com/) - 一个无代码构建您自己的网站漏斗，将您的在线形象从静态小册子转变为适应每个读者的动态对话，并带有仪表板以了解您的用户互动。 用Astro和Turso建造。
