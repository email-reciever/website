**Astro 5.8 是一个新的节点更新，它会颠覆 Node.js 的最低要求版本。**

🔄 保持最新状态：

*   [**Updated minimum Node.js version to 18.20.8**](#updated-minimum-nodejs-version)

要升级现有项目，请使用自动 `@astrojs/upgrade` CLI 工具。 或者，通过运行包管理器的升级命令手动升级：

    # 推荐：NPX @ASTROJS/升级
    # 手动：npm安装astro@latestpnpm升级astro --latestyarn升级astro --latest

将最小 Node.js 版本更新为 18.20.8
----------------------------------------

Node.js 18 现在已经到了寿命结束，将不再接收安全更新或支持。 因此，Astro 5.8 现在需要 V20.3.0、V22.0.0 或更高版本。 （不支持 v19 和 v21。）为了帮助用户升级，Astro 将暂时继续支持 Node.js 18.20.8，这是 Node.js 18 的最终 LTS 版本。

我们将在未来的版本中完全放弃对 Node.js 18 的支持，因此我们建议尽快升级到 Node.js 22。 有关我们如何以及何时升级最低维护 LTS 版本的更多详细信息，请参阅 Astro 的 [Node.js support policy](https://docs.astro.build/en/upgrade-astro/#nodejs-support-and-upgrade-policies)。

您可以通过运行来检查您当前的 Node.js 版本：

节点 -v

您需要更新本地开发环境和任何 CI/CD 环境以使用 Node.js 18.20.8 或受支持的版本之一。 您可以检查 [deployment platform](https://docs.astro.build/en/guides/deploy/) 的文档以了解如何设置 Node.js 版本。 这可能涉及在仪表板中选择选项、设置环境变量或向项目中添加配置文件。 许多平台将遵守 `NODE_VERSION` 环境变量或 [`.nvmrc`](https://github.com/nvm-sh/nvm#nvmrc) 文件。

例如，要将 Node.js 版本设置为 22，您可以在项目根目录中创建一个包含以下内容的 `.nvmrc` 文件：

.NVMRC

22

有关如何使用 `.nvmrc` 文件的更多详细信息，请参阅 [nvm docs](https://github.com/nvm-sh/nvm#nvmrc)。
