发布
---------

即使有 4.0 即将到来，本月也看到了几次 Astro 发布！

*   [Astro 3.5](https://github.com/withastro/astro/releases/tag/astro%403.5.0)：集成现在可以添加其他集成，添加了 `<form>` 支持和预取。 您也可以试用实验性的i18n！
*   [Astro 3.6](https://github.com/withastro/astro/releases/tag/astro%403.6.0)：此版本添加了三个新事件以查看过渡。
*   [Starlight 0.12](https://github.com/withastro/starlight/releases/tag/%40astrojs%2Fstarlight%400.12.0)：使用自定义组件覆盖 Starlight 的 UI，并进行了许多改进。
*   [Starlight 0.13](https://github.com/withastro/starlight/releases/tag/%40astrojs%2Fstarlight%400.13.0)：内置支持 [Expressive Code](https://github.com/hippotastic/expressive-code) 代码块功能。
*   [Starlight 0.14](https://github.com/withastro/starlight/releases/tag/%40astrojs%2Fstarlight%400.14.0)：添加新的 [plugin API](https://starlight.astro.build/reference/plugins/) 并启动对 [Algolia DocSearch](https://starlight.astro.build/guides/site-search/) 的官方支持。

文档
-----

Docs 团队正在努力将 Astro 文档迁移到 Starlight！ 我们有非常好的消息要告诉你！ 下周就来了！

为了帮助您更好地做出贡献，我们将 `help - confirm behaviour` 和 `help - leave feedback` 添加到我们的 PR 标签列表中，以阐明我们需要帮助的地方。 开放的问题和 PR 已经被新分类，有很多东西可以深入研究。

我们每周的不和谐称为“谈话和记录”是您观看团队文档在公共场合工作、跳入代码空间并为文档做出贡献的机会。 本周的主题包括：

*   在星光中测试驾驶新的Astro Docs
*   复习和合并完成的法语教程
*   重建 [astro.build](http://astro.build) 页脚，以便我们可以链接我们的新社区网站
*   测试新星光 `<Testimonial />` 组件
*   构建 Astro V3 到 V4 升级指南
