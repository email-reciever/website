令人兴奋的消息：[Vercel](https://vercel.com/) 现在支持 Astro 项目的自动零配置部署。 当您在 Vercel 中导入或创建新项目时，平台将自动检测 Astro 并为您的项目配置正确的设置，包括针对 JavaScript 和 CSS 资产的优化缓存标头。

Vercel 是 Astro 开源项目的 [long-time sponsor](https://astro.build/#sponsors)。 感谢 Vercel 赞助我们的社区并使 Astro 开发人员更容易进行 Web 开发！

[Get started with Vercel](https://vercel.com/new/templates)
