# I need to be AI native but I'm not sure how

September 15, 2026

![Diego Velázquez, Las Hilanderas (The Spinners)](/_astro/header.CQ-TQqpe_Z1hAp3S.jpeg)

I still don’t know what it means to be a competent software developer in the post-LLM world, to be an AI-native engineer as the kids call it.

Keeping up with the times is a survival skill, and I, too, want to pay my bills.

You need to be making the most of the tools you have, but the shift is so rapid and unevenly spread that I feel like I’m living in two separate realities. When I open X, I see a prequel to Neuromancer, but daily corporate software engineering is just as Kafka-esque as it was before LLMs.

I know that the whole “you will be left behind” thing is greatly exaggerated, but when I see posts from people asking their spouses to take care of their children solo while they work on becoming AI native, I admit I’m not fully immune to FOMO.

* * *

Sinking hours into the latest paradigm is the easiest way to cool off the fear of falling into the permanent underclass, but this misses the forest for the trees.

_Remember prompt engineering?_

_Remember when RAGs were the solution to all your agentic problems?_

These are only cascading effects of the broader paradigm shift that **engineers need to be able to make an economic trade-off** between their time and a model’s cost. Money is something I only dealt with when it came to cloud infrastructure, but now I weigh in the cost of using an agent for every task I have to do.

Not writing code by hand was the first product of this paradigm shift. I’ve already forgotten how time-intensive it was to write an exhaustive test suite. I’ve spent days writing tests, changing the implementation to make it more easily testable, then testing again.

Now every time I need to write code, I have all these questions popping into my head:

_Can an agent do it faster?_

_Can it do it well enough?_

_Is it worth spending money on this?_

_Does perfection matter?_

_Do I know exactly what I want to accomplish?_

_Will I recognize what a good implementation looks like?_

Once I have an answer to them, I decide whether and how much I can offload to a coding agent.

From my observations, developers who are using LLMs well are blocked less often.

Early in the coding agent hype, I saw a friend of mine ask a model to create an SVG for a pattern from a screenshot he was given, and this was a lightbulb moment for me. When I need a simple asset like an image or an icon, I’d use a model to generate one. The torn background behind the names of these cards is generated with a prompt.

![](/_astro/image-2.BxzaIBSZ_2gqWqa.png)

The same goes for translations. I want to test with real-world language so I can catch formatting edge cases. I still need a human to verify the copy, but I’m not blocked by one.

* * *

I’m, however, not going overboard with skills, setups, and orchestration.

This draws away the focus from the product to the tooling, and I find it more important to be end-result driven in this day and age.

LLMs helped me realize how little of our day-to-day work requires senior+ level knowledge, and I’d much rather spend my efforts on the pockets of complexity that need my full attention than try to automate the rest.
