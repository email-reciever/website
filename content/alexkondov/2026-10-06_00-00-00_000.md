但这种狂热不仅仅局限于工程部门，还渗透到了产品、商业和销售部门。你可能认为自己精神失常，但你有使用代理构建软件的现实检验，所以你知道他们的能力。有些人与技术联系较少，只是被无尽的 AI 生产力信息轰炸，没有任何过滤。

## 发生了什么变化？

很多事。

人们比以前更容易陷入下一个功能的幻觉。

你的想法和其实现之间的摩擦意味着你必须更加小心地对待你的功能和产品。你花费了很多开发者小时来解释和理解它，所以你必须为他们带来一些投资回报。

但是，在使用 Claude 生成 PRD 然后将其发送给一个不读它的工程师，他又将其输入另一个 Claude 的噩梦场景中，那种摩擦消失了。

你发布的产品变得 menos 有用，更多的是廉价拙劣的软件。

当某个功能因为设计不够完善而被忽视时，我们不会去改进它，而是采用“随便搞搞”的方式，希望下一个发布的功能能带来改变。

质量很重要，但如果没有速度，那么质量就不够完善；而速度如果没有质量的保证，那么速度就没有意义。

并非所有的事情都很糟糕。

## 但是有些事情不会改变。

我可以更快地设计和编码。

但我只能以每周与需要审批我工作的人开会的速度移动，所以虽然我在个人生产力方面有了净改进，但我们在交付新产品方面的速度并没有提高太多。

如我们所提到的，新功能并不总是解决方案，因此可能有一些意外的智慧在于这种延迟。

另一件没有改变的事情 *(并且永远不会改变)* 是压力。

业务永远不会停止要求更多的产出和更快的速度。我曾经在职业生涯初期在网页代理机构工作时一直处于持续的压力之下，因为他们为了生存而承受着压力。软件行业的末日即将来临的感觉只会让大公司的工作感觉更像这样。

如果你不习惯与截止日期和成本进行艰难的对话，你将不得不习惯它。在一家资金充足的公司工作可能会让我们与工作的财务现实隔离开来，直到现在。

# 简介

## 介绍

该自定义元素用于创建一个布局混排效果。

## 用法

使用 `<layout-shuffle>` 元素即可创建一个布局混排效果。

### 属性

* `caption`: 设置混排的标题。
* `interval`: 设置混排的间隔时间，单位为毫秒。

### 示例

```html
<layout-shuffle caption="screen" interval="2000"></layout-shuffle>
```

## 代码

```javascript
const n = [
  e => [8, 7 + e * 13, 84, 10],
  e => [8 + e % 3 * 29, 8 + Math.floor(e / 3) * 40, 26, 34],
  e => e < 3 ? [8, 7 + e * 27, 28, 23] : [40, 7 + (e - 3) * 27, 52, 23],
  e => e < 5 ? [8, 7 + e * 15, 48, 11] : [62, 0, 38, 100],
  e => [8 + e % 3 * 29, 8 + Math.floor(e / 3) * 24, 26, 20],
  e => e === 5 ? [22, 22, 56, 46] : [8, 7 + e * 15, 84, 10]
];

class l extends HTMLElement {
  boxes = [];
  step = 0;
  timer = null;
  visible = !1;
  observer = null;
  reduced = window.matchMedia("(prefers-reduced-motion: reduce)");

  sync = () => {
    this.visible && !document.hidden && !this.reduced.matches ? this.start() : this.stop();
    this.reduced.matches && this.show(0);
  };

  connectedCallback() {
    if (this.setAttribute("aria-hidden", "true"), this.boxes.length === 0) {
      this.boxes = Array.from({ length: 6 }, () => {
        const t = document.createElement("div");
        return t.className = "ls-box", this.append(t), t;
      });
      const s = this.getAttribute("caption") ?? "screen";
      if (s) {
        const t = document.createElement("span");
        t.className = "ls-caption", t.textContent = s, this.append(t);
      }
    }
    this.show(0);
    this.observer = new IntersectionObserver(([s]) => {
      this.visible = s.isIntersecting;
      this.sync();
    });
    this.observer.observe(this);
    document.addEventListener("visibilitychange", this.sync);
    this.reduced.addEventListener("change", this.sync);
  }

  disconnectedCallback() {
    this.stop();
    this.observer?.disconnect();
    this.observer = null;
    document.removeEventListener("visibilitychange", this.sync);
    this.reduced.removeEventListener("change", this.sync);
  }

  show(s) {
    this.step = s;
    this.boxes.forEach((t, i) => {
      const [h, r, c, o] = n[s](i);
      t.style.left = `${h}%`;
      t.style.top = `${r}%`;
      t.style.width = `${c}%`;
      t.style.height = `${o}%`;
      t.style.opacity = s === 5 && i !== 5 ? "0.35" : "1";
    });
  }

  start() {
    if (this.timer) return;
    const s = Number(this.getAttribute("interval")) || 1500;
    this.timer = setInterval(() => this.show((this.step + 1) % n.length), s);
  }

  stop() {
    this.timer && clearInterval(this.timer);
    this.timer = null;
  }
}

customElements.get("layout-shuffle") || customElements.define("layout-shuffle", l);
```
