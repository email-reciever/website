上个月，大型语言模型（LLM）渗透测试和编排框架的数量激增。 就在几周前，Artex——一个实现进攻性安全工作流程自动化的开源代理渗透测试系统——是唯一可用的框架。 在过去的三天里，我们看到超过 50 个框架系列试图在全球范围内扫描 Cloudflare 客户。 运行这些框架的 Internet 协议 (IP) 地址的数量已增长到数千个，并且每天都在继续增加。 这些框架的扩散极大地改变了网络防御的现状：防御者正在努力跟上这些自主引导的攻击的体积性质。

Artex 于 10 月 8 日被其创建者 Autumn-27 击倒。（“该工具的恶意利用与其最初的意图完全背道而驰，”他们 [wrote in Chinese.](https://github.com/Autumn-27)），但在此后的一个月里，生态系统已经爆发了新的碎片化版本。 现在有超过 12,000 个存储库，数百个独特的分叉包含来自原始存储库的血统。 此外，自 10 月 8 日以来，已经创建了数百个类似的代理编排框架。自 10 月 1 日以来，AI 渗透测试（渗透测试）和利用工具的每日请求增长了 30 倍。这些工具还开始在一些更复杂的攻击中链接被盗的客户凭据，例如 在整个环境中进行横向运动链式。

Artex的分叉树：204个公共存储库，它们自己的代码更改，按类型分组和按星星大小。

我们预计这些框架将继续扩散，每个组织都应该准备好应对这一威胁。 为了对抗基于 LLM 的 Pentest 框架，我们建议所有组织采用我们所谓的现代安全模型，该模型有六个关键支柱：

*   **Fortify Front Gate**：实施具有速率限制等高级规则的 Web 应用程序防火墙 (WAF)。
*   **门厅中的安全站**：对您的客户访问的所有 Web 应用程序进行异常检测。
*   **识别虚假访问者**：实施机器人防御。
*   **移除后门**：为所有高风险的外部和内部 Web 应用程序实施身份门禁访问。
*   **检查交付：** 实施已验证的模式和显式安全控制。
*   **邻居观察**：实施威胁情报以获得攻击的可见性。

什么是法学硕士渗透和利用编排器？
-----------------------------------------------------

开源渗透测试框架能够协调 AI 代理以大规模执行传统 [Cyber Kill Chain](https://www.lockheedmartin.com/en-us/capabilities/cyber/cyber-kill-chain.html) 的阶段。 像 Artex 这样的工具能够以新颖的方式快速插入现有的模型上下文协议 (MCP) 并连接传统的独立渗透测试工具。 有些甚至允许操作员就完成什么类型的任务进行指导。 这些工具可以从内部和外部映射和枚举环境。 Artex 及其分叉将资产和环境映射到图表上，允许多个独立的并行代理以推理的速度枚举、验证、原型和攻击。 这些工具将妥协变成了一个爬山问题，代理特别擅长。

### 目前存在的 AI LLM 渗透测试工具

我们目前正在跟踪 50 多名 AI LLM 代理。 下表显示了排名前五的 LLM 渗透和利用 Orchestrator。 每个都非常受欢迎（1K+ GitHub Stars）并且完全自主。 这些代理的完全自主性代表了进攻性网络能力的理论转变：

*   人际交往不再是极限：一个安全带通过观察环境来执行 [OODA loop](https://en.wikipedia.org/wiki/OODA_loop) 的每一步，定位自己以优先考虑有价值和/或易受攻击的目标，决定行动并自主行动。
*   速度增加：与单一操作员或由AI增强的多个操作员相比，有多个并行代理朝着目标而努力是一个大的转变。
*   规模：单个操作员可以同时针对多个组织，大大增加其爆炸半径。
*   很容易发现小错误：自治框架无情地系统地测试暴露的服务，包括它们的配置。

### 身份链式法学硕士开发

在过去的八周里，我们的 Cloudforce One 团队被召集到涉及 Artex 和 Artex 衍生的 LLM 利用框架的多起事件响应调查中。 我们已经亲眼目睹了暴露的凭证如何与基于法学硕士的开发框架相结合，以获得对防御者的优势。
我们观察到了多个事件，其中威胁参与者获得了对超扩展环境的初始访问权，并直接转到了客户的 Cloudflare 环境中。 根本原因分析揭示了常见的凭证卫生失败。 攻击者在 CI/CD 管道中反复破坏了运行的静态、非过期令牌，从而在组织的超扩展器基础设施中获得了广泛的跨环境访问权限。 LLM 框架极大地扩展了客户端的 API 密钥被横向利用以接管其他租户环境的可能性。

### 阿特克斯在行动

作为一项事件响应调查的一部分，我们的团队观察到 Artex 获得了以前用于 CI/CD 的受损帐户级 API 令牌的访问权限，没有 IP 限制或速率限制。 现有证据表明，妥协很可能源于第三方超大规模商。

我们观察到大量新的工作脚本创建了不同的名称，例如 artex-\*、artex-pgrecon-\*、artex-pgw-\* 和 artex-do-\*。 每个工作脚本的命名与它所采取的不同行为和动作相关，并且通常由字母数字标识符加以后缀。 我们观察到超过 **69 次请求的活动**在其 Cloudflare 基础设施的多个独特部分和 400 个数据库转储请求中的小时内。 我们还观察到尝试持久性机制并尝试验证其他第三方应用程序的会话令牌。 虽然我们相信这项活动的大部分是由人工操作员轻描淡写的，但这只是 Artex 和类似框架可以在后妥协中实现的速度和广度的一个例子。

我们的建议：现代安全模式
-------------------------------------------

大型语言模型增加了威胁参与者快速迭代目标的网络杀戮链的能力。 他们通过给演员速度和验证的优势来做到这一点。 网络杀伤链的每一步都可以被验证并输入到攻击的下一阶段。 这种级别的编排是无与伦比的，有效地蒸发了传统的网络安全模型。 必须使用现代模型来对抗这些攻击。

为了进一步解释这个模型，让我们使用保护庄园上的房子的隐喻。 下面的每个部分都概述了如何在每个步骤中防御威胁。

### 强化前门：实施交通管制和先进规则的WAF

在任何人踏上你的草坪之前，他们必须到达周边围栏。

在不受保护的庄园中，对手可以将无休止的诱饵卡车车队直接驶入您的车道，完全挡住入口并砸穿障碍物（第 3/4 层体积洪水和直接 IP 探测）。

有了外围门安全，所有传入的交通都通过远离主屋的巨大、分布式的外门进行路由。 流氓送货卡车被过滤到高速公路上，试图窃听您的财产的流氓公用隧道被切断，只有合法的人流量才能到达您的家庭住址。

[Network traffic](https://developers.cloudflare.com/magic-transit/) [control](https://www.cloudflare.com/products/network-firewall/) 在阻止体积攻击中起着重要作用。

### 门厅内的安全站：异常检测

一旦游客到达主入口，他们会在门厅遇到一个严格的安全站。

自动驾驶者不只是踢门； 他们伪装自己。 他们尝试奇怪的方法进入门——把纸塞进锁里，尝试像 `//front-door//back-room/` 这样的变体来欺骗机制打开。

门口的保安执行明确的规定：

*   你不能在五秒内敲500次。
*   你不能用诡计来掩饰你的道路。
*   您不能尝试将一辆巨大的平板推车推过前厅以拖走房屋的内部蓝图（诊断堆垃圾）。 可疑行为立即被拒之门外。
*   实现安全密钥和基于硬件的 FIDO 密钥。

[Web Application Firewall (WAF)](https://www.cloudflare.com/products/waf/) 作为通过速率限制和异常检测停止应用程序利用的关键防御机制。

### 识别虚假访问者：实施机器人防御

复杂的入侵者很少看起来像蒙面窃贼； 他们将自己伪装成普通游客。 但自动化代理、无头浏览器刮板和人工智能侦察工具并不像真实的人。

他们不眨眼，他们的姿势令人不安，他们的节奏是机械的，他们的“识别”往往是对真正的游客徽章的草率模仿。

[Bot Defense](https://www.cloudflare.com/products/bot-management/) 和 [challenges](https://www.cloudflare.com/products/turnstile/) 充当行为专家，通过单向玻璃观察人群。 它标记了不自然的节奏，捕捉合成的微观行为，并在机器触摸单个门把手之前悄悄地护送机器离开该物业。

### 移除后门：实现身份门禁和微分段

许多历史上的房屋都是用侧门或地窖舱口建造的（内部管理面板、`/actuator` 诊断终端和远程网关）。 即使被锁上，徘徊者也可以站在人行道上，在地窖门上照一个手电筒，然后开始挑选锁。

[Zero Trust](https://www.cloudflare.com/sase/) [application access](https://www.cloudflare.com/sase/products/access/) 做一些激进的事情：**它从外面变砖，限制可以进入的房间。**

对于任何在周边徘徊的人来说，地窖的门都不存在。 没有锁可以摘，没有把手拉手，里面也没有灯。 唯一的方法是与检查您的生物识别徽章、确认您的设备有一个干净的健康状况并直接进入您需要的特定房间的护送人员——让房子的其余部分不可见。

对于那些进入的人，您必须确保他们不能破坏他们进入的房间旁边的房间。 [Micro-segmentation](https://www.cloudflare.com/learning/access-management/what-is-microsegmentation/) 是一种有效的停止横向运动的策略。 它限制了违反生产、测试和开发系统的受损凭据。

### 检查交付：强制执行已验证的模式和显式安全控制

您会收到每日供应到您的庄园的货物——杂货、邮件、维护零件。 在数字术语中，这是您的传入 API 流量，必须进行检查和验证。

入侵者经常试图通过发送用于受限内部系统的未经验证的有效负载或伪造的交付清单来绕过控制。

Porch 协议要求对所有流量进行全面检查和架构验证：

*   每个传入的请求都必须 [undergo OpenAPI schema validation](https://developers.cloudflare.com/api-shield/security/schema-validation/) 以确保其严格符合预期的定义和结构。
*    司机和快递员必须出示经过验证的相互TLS (MTLS) 证书以建立受信任的认证连接。
*   任何未能检查或缺失有效凭证的请求在边界处立即被拒绝。
*   default-deny stepure：每个积极的安全实现都以规则集底部的明确拒绝所有规则结束。

### 邻里观察：实施威胁情报以获得攻击的可见性

即使有铁甲墙，如果辛迪加在城镇中发明了一种全新的渗透技术，一个孤立的财产也可能很脆弱。

如何获得实时帮助
--------------------------

Artex 和类似的基于法学硕士的框架对传统的网络防御模型构成了重大挑战。 即使是历史上的深度防御模型——强调经典的网络 DMZ——在当今复杂的架构中也达不到要求。 随着编排工具成为新常态，明天的攻击只会推进。

保护传统设备和本地设备需要一种身份门控的方法，从逻辑上讲，这些设备无法在互联网上使用。 除了身份之外，减缓或使横向运动更嘈杂是微分段的目标。 这种架构强调安全优先的安全性方法，当用户不断丢失其密钥时，这是必不可少的。 结合起来，现代安全模型的元素就是解决这个令人烦恼的问题的答案。
