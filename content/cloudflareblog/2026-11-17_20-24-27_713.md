上个月，瑞士非营利基金会 Quad9 [announced](https://quad9.net/news/blog/au-revoir-france/) 将从法国撤回其免费的公共 DNS 解析器。 这一艰难的决定是在数月的诉讼和法国法院的裁决之后，对 Quad9 因未能阻止与涉嫌侵犯版权的域名相关的域名进行每日经济处罚。

Quad9 离开法国既令人沮丧又可以理解。 法院的裁决使该组织处于不可能的约束中，必须在严重的诉讼和处罚之间做出选择，或者以破坏用户隐私和安全的方式从根本上改变其服务。 没有好的选择，Quad9 正在选择出口门。

从法国撤出一项基本基础设施服务对自由开放的互联网造成了根本性的损害，如果权利持有人和政策制定者继续要求对互联网的每一层进行最大限度的封锁，它将成为对损害的警告。 它不仅剥夺了法国互联网用户值得信赖且重要的工具； 它会给他们的日常生活带来真正的风险。 Quad9 的解析器被法国的各种个人和组织（包括政府机构、教育机构、医院和公用事业公司）使用，Quad9 无法直接通知这些个人和机构他们的解析器很快就会停止工作。 如果受影响方在 Quad9 删除其服务之前没有更改其解析器，则他们的互联网将无法解释。

Quad9 不是第一个在封锁订单后退出国家的公共 DNS 解析器，而且几乎肯定不会是最后一个。 思科此前曾在类似情况下（暂时）从法国、葡萄牙和比利时撤回其 OpenDNS 解析器。 比利时法院最近发布了一项 [order](https://lawyerd.net/news/brussels-dns-blocking-dazn-google-cloudflare-opendns/)，如果 Cloudflare、Google 和 Cisco 没有在 2027 年 1 月之前开始通过其公共解析器阻止网站，这将受到重大处罚。这是 Cloudflare 从未做过的事情。

Cloudflare 多年来一直在倡导反对此类订单。 我们担心，权利人对公共 DNS 解析器的阻止的无情要求最终会对互联网造成真正的伤害。

DNS（域名系统）的复习
----------------------------------------

要了解为什么会出现这样的问题，有助于了解互联网在幕后的运作方式。 DNS 解析器是 Internet 基础设施的基础。 DNS 是 Internet 的通讯簿：当您键入诸如 Cloudflare.com 等网站名称时，DNS 系统会将该域名转换为您设备连接到它所需的 IP 地址。 DNS 解析器是查找该地址并将其发送回您的设备的服务，就像操作员在目录中查找电话号码一样。

DNS 解析器可以由任何人操作，但它们通常由互联网服务提供商 (ISP)、移动网络、企业和大学运行。 如果您在家中阅读这篇博文并且以前从未想过 DNS，那么您很可能正在使用 ISP 的默认解析器。 因为您每次访问网站时都使用 DNS 解析器，因此可靠和值得信赖非常重要。

而且由于 DNS 解析器可以访问您的所有浏览活动，因此您使用的解析器具有真正的隐私影响。

除了本地 ISP 提供的 DNS 解析器外，还有多种公共 DNS 解析器可用。 Cloudflare 于 2018 年 4 月推出了我们的公共 DNS 解析器 [1.1.1.1](https://one.one.one.one/)，以回馈互联网。 [Our goal](https://blog.cloudflare.com/announcing-1111/) 是为了让每个人都免费提供快速、可靠、隐私优先的消费者 DNS 服务。 我们成功了。 1.1.1.1 是最快的 DNS 解析器 [in the world](https://www.dnsperf.com/#!dns-resolvers)，包括在欧洲。 Cloudflare 的解析器不收集任何用户数据，更不用说将其出售给广告商。 1.1.1.1 一直是我们最喜欢的 Cloudflare 示例之一，履行其帮助建立更好的互联网的使命。

1.1.1.1 是任何人都可以使用的众多公共解析器之一。 除了 1.1.1.1 和 Quad9 的 9.9.9.9 之外，其他一些最著名的公共解析器还包括 Google 的 8.8.8.8 和 Cisco 的 OpenDNS。 仅仅因为这些服务是免费提供的并不意味着它们很容易提供。 运行良好的全球公共 DNS 解析器是一项非同寻常的工程壮举，旨在通过全球分布的数百个服务器位置的全球分布式网络安全和私下解决数千亿甚至数万亿次的查询。

正如 Quad9 所指出的，还有许多其他可供用户使用的 DNS 解析器，其中许多由本质上是匿名服务提供的，其实践未知或未记录。 更改您的 DNS 解析器很容易，人们这样做是出于各种原因，包括性能、可靠性或访问特定的安全功能。

为什么不应该要求公共 DNS 解析器阻止
----------------------------------------------------

权利持有人在防止在线盗版方面具有合法利益。 但试图通过公共 DNS 解析器解决在线侵权基本上是错误的方法。

除此之外，这种阻塞是无效的。 回想一下操作员在目录中找到电话号码的类比。 如果法院想关闭非法业务，强迫目录运营商将业务名称从电话簿中划掉，实际上并不会关闭该业务。 店面仍然开放，产品仍然存在，任何已经知道地址或使用不同电话簿的人都可以走进来。

互联网也是如此。 DNS 解析器只是传输链中的一环。 DNS 解析器可以“阻止”内容的唯一方法是拒绝返回特定网站的 IP 地址。 但是公共 DNS 解析器无法从 Internet 中删除实际侵权内容，也无法删除托管它的服务器。

正因为如此，由公共DNS解析器阻止非常容易绕过。 任何想要到达被阻止站点的互联网用户都可以在不到一分钟的时间内通过切换到在线提供的数千个其他 DNS 解析器之一来绕过该块。 事实上，如果用户已经知道底层 IP 地址，他们甚至根本不需要解析器来访问侵权内容。 不出所料，虽然通过公共解析器进行阻止可能会在访问内容时给一些用户带来一些摩擦，但没有证据表明它实际上减少了在线侵权的总量。

除了无效之外，正如我们 [written previously](https://blog.cloudflare.com/latest-copyright-decision-in-germany-rejects-blocking-through-global-dns-resolvers/) 一样，DNS 阻断是一种导致附带损害的钝器。 由于 DNS 在域级别运行，因此解析器无法阻止特定的侵权视频或文件； 它必须阻止整个域。 这会影响该域上的所有内容，无论是合法的还是非法的。 它对用户来说也是完全不透明的：当解析器被迫阻止域时，网站根本无法加载。 用户没有收到任何解释或法律通知，因此无法知道该网站是否因维护而停机，网络是否中断，或者该网站是否被法院命令阻止。

对于公共 DNS 解析器，问题要严重得多。 因为公共解析器在全球范围内运行，任何阻塞自然都会跨越国界，这意味着一个国家可以决定哪些内容可以在世界各地访问。 例如，虽然由 Whalebone 为响应特定国家订单而运营的欧盟专用 DNS 解析器 DNS4EU 运行，但它在整个欧盟都是如此。 重新设计公共 DNS 解析器以允许更多本地化阻止的努力将从根本上改变服务，损害性能和弹性，破坏用户隐私，并使开放的互联网碎片化。

出于这些原因，Cloudflare、Google、Cisco 和 Quad9 都反对强制阻止公共 DNS 解析器阻止，并取得了一些成功。 几年前，德国的法院裁决支持 [Cloudflare](https://blog.cloudflare.com/latest-copyright-decision-in-germany-rejects-blocking-through-global-dns-resolvers/) 和 [Quad9](https://quad9.net/news/blog/quad9-turns-the-sony-case-around-in-dresden/)，拒绝要求阻止 DNS 的请求。 最近，法国法院 [rejected](https://torrentfreak.com/cloudflare-keeps-1-1-1-1-out-of-piracy-blocking-escapes-penalties-in-france/) 对 Cloudflare 未能通过 1.1.1.1 进行处罚，发现我们通过 CDN 和反向代理服务采取的其他行动足以遵守基本命令。

权利持有人没有被吓倒，继续以难以解释的决心为由公共解决者施压。 最近的一项研究 [found](https://labs.ripe.net/author/antonio-prado/live-event-blocking-at-scale-effectiveness-vs-collateral-damage-in-italys-piracy-shield/) 欧洲的大多数在线盗版活动都在欧洲进行。 如果权利人想要真正解决在线侵权问题，那么有更好的地方可以集中精力——最引人注目的是要求实际存储盗版文件的托管服务提供商将其删除。

将公共 DNS 解析器排除在市场之外会损害互联网
---------------------------------------------------------

法国法院对 Quad9 的判决令代表了这些权利人努力的高潮。 作为一个只提供公共 DNS 解析器的小型非营利组织，Quad9 没有其他方法来证明遵守订单。 因此，法国法院批准了权利人要求对违规行为进行处罚，迫使 Quad9 破坏自己的服务或离开该国。

Quad9 退出法国代表了互联网的真正损失。 在短期内，Quad9 的分解器的移除可能会立即和潜在地严重中断互联网接入。 由于他们的服务是为了保护隐私而设置的方式，Quad9 无法知道究竟是谁在使用其解析器，更不用说直接与他们沟通即将推出的服务。 这意味着当解析器停止工作时，个人、医院、大学和政府办公室都可能不知道。 同样，由于 DNS 解析器的工作方式，这些用户将不会收到解释所发生事情的详细错误消息——他们的互联网将停止工作。 当安全系统或恒温器等设备硬连线使用 Quad9 的解析器时，问题将更加严重。 修复这些问题可能很慢甚至是不可能的。

更一般地说，将 Quad9 赶出法国绝对无助于防止在线侵权，但它确实让普通互联网用户的安全、可靠的选项更少，尤其是像 Quad9 这样的选项，这些选项也可以保护用户免受网络钓鱼和恶意软件的侵害。 将已建立的公共 DNS 解析器带走，迫使互联网用户使用其 ISP 提供的默认解析器（可能会通过其浏览数据获利），尝试由匿名或不太可信的组织运营的鲜为人知的解析器，或运行自己的解析器。 具有讽刺意味的是，Quad9 和 Cloudflare 正因为我们是透明、有信誉的组织而被推上法庭。 惩罚透明服务只会将用户推向网络上不太负责任的角落。

前进之路
----------------

如果不出意外，我们希望 Quad9 的公告可能会为权利持有人和政策制定者敲响警钟，他们寻求在互联网的每一层阻止侵权行为都有实际成本。

我们相信有更好的方法可以在不损害互联网完整性的情况下共同打击盗版，Cloudflare 继续为此而努力 [innovative collaborations](https://blog.cloudflare.com/h1-2025-transparency-report#innovating-to-address-abuse-and-identify-new-threats)。 我们在解决在线侵权方面的集体努力将更好地用于寻求在托管提供商处删除此类内容，这既可以实现更持久的解决方案，又可以避免对互联网的附带损害。

与此同时，我们将继续抵制错误的努力，要求公共 DNS 解析器阻止。 与谷歌和思科一起，我们对比利时命令提出上诉，如果我们在 2027 年 1 月之前不开始 DNS 封锁，我们将对我们施加处罚。我们希望在年底之前得到解决方案，以避免像 Quad9 现在在法国面临的另一种情况。

我们对如果额外的解决方案被迫退出市场而造成的中断感到严重担忧，我们将继续倡导反对这一可能的结果。
