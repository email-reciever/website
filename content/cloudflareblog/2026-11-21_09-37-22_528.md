我们 [introduced](https://blog.cloudflare.com/kitesurf/) [Kitesurf](https://kitesurf.dev/)，我们的无状态浏览器，用于在 8 月和 9 月 [followed up](https://blog.cloudflare.com/kitesurf-update/) 完全在工人之上运行的 AI 代理，支持 WebMCP，新 API 和改进的兼容性。 在每一次，我们都提到了我们对开源的承诺，以便开发人员可以在自己的 Cloudflare 帐户上运行自己的浏览器引擎。

这个承诺现在是真实的。 [Kitesurf is open source on GitHub](https://github.com/cloudflare/kitesurf) 在 Apache 2.0 许可下。 您可以读取代码，在本地运行，更改它，并将您自己的实例部署到 Cloudflare 工作人员。

专为代理构建的浏览器
---------------------------

KiteSurf 完全在 Cloudflare 工作人员上运行。 它解析HTML，应用CSS，执行页面JavaScript，并在没有浏览器容器的情况下渲染屏幕截图。 它支持 Chrome DevTools 协议 (CDP)，因此您可以连接 Puppeteer 等客户端。

我们的主要目标是为 AI 代理提供一个轻量级、高效的浏览器——它可以加载网站、执行 JavaScript 和与页面交互，同时使用比 Chromium 这样的完整浏览器更少的 CPU 和内存，并在 Cloudflare 的全球工作人员网络中按需扩展。

阅读更多关于我们为什么以及如何在我们的初始 [announcement](https://blog.cloudflare.com/kitesurf/) 中构建 KiteSurf 以及如何在浏览器运行的 [developer](https://developers.cloudflare.com/browser-run/kitesurf/) 文档中使用它。

仓库里面有什么？
------------------------------

KiteSurf 建立在 Cloudflare 的开发者平台和 API 之上，以及编译成 WebAssembly 的开源 Rust 包的生态系统：

*   [Blitz](https://github.com/DioxusLabs/blitz) 提供 HTML 解析、DOM、布局和绘画。
*   [Stylo](https://github.com/servo/stylo) 提供 CSS 解析、级联和计算样式。
*   [Boa](https://github.com/boa-dev/boa) 在 WebAssembly 中运行 JavaScript（仅当我们无法在动态工作器中运行 JavaScript 时才作为最后的手段）。
*   [Linebender](https://linebender.org/) 库提供文本布局和 2D 图形，[Krilla](https://github.com/LaurenzV/krilla) 生成 PDF 输出。

这些项目使风筝冲浪成为可能。 他们保留各自的许可证； 存储库的 [NOTICE](https://github.com/cloudflare/kitesurf/blob/main/NOTICE) 记录了第三方通知。

KitesUrf 有三个主要部分：引擎管理浏览器会话和客户端连接，PageScript 运行页面及其 JavaScript，PageRenderer 绘制结果。

所有软件包、引擎、它的 Rust 核心、Dom Shims、渲染器和 [Kitesurf CLI](https://github.com/cloudflare/kitesurf/tree/main/packages/kitesurf-cli) 分别位于存储库 [packages](https://github.com/cloudflare/kitesurf/tree/main/packages) 目录下的文件夹中，您可以在其中探索所有部分如何组合在一起。

经营自己的风筝冲浪
----------------------

要在本地运行 KiteSurf，请按照存储库的 [build requirements](https://github.com/cloudflare/kitesurf#requirements) 进行克隆 [repository](https://github.com/cloudflare/kitesurf)，安装依赖项并启动引擎：

git 克隆 https://github.com/cloudflare/kitesurf.git
CD 风筝冲浪
pnpm install --frozen-lockfile
pnpm 运行开发

第一个版本编译了 Rust 核心及其依赖项，所以给它一些时间。 后续构建重用构建缓存。 最后，Wrangler 在 **http://127.0.0.1:8787**. 打开该地址以尝试 Chrome 开发工具中的页面，或以编程方式使用它。

您可以将 [puppeteer](https://github.com/cloudflare/kitesurf/tree/main#connect-with-puppeteer) 与 NodeJS 脚本一起使用：

从“Puppeteer-Core”导入Puppeteer；
    
常量浏览器 = 等待 puppeteer.connect({
BrowserWsEndpoint：“ws://127.0.0.1:8787/devtools/browser”，
});
    
试试{
常量页面 = 等待浏览器.newPage();
等待 page.goto("https://example.com/");
等待 page.screenshot({ 路径："page.png" });
} 最后{
等待浏览器.disconnect();
}

或者您可以将您的 AI 安全带指向当地 [CDP](https://github.com/cloudflare/kitesurf/tree/main#use-chrome-devtools) 端口（代理人喜欢 CDP），并观看它完全控制 Kitesurf。

部署到您的 Cloudflare 帐户
--------------------------------

当您在本地完成更改和测试后，您可以 [deploy the engine to your own account](https://github.com/cloudflare/kitesurf#cloudflare-deployment) 并从那里使用 Kitesurf 而不是我们提供的浏览器运行托管 API。 请注意，需要工人付费计划，因为 KiteSurf 使用 [Dynamic Workers](https://developers.cloudflare.com/dynamic-workers/) 为页面创建孤立的工人。

从存储库根目录：

pnpm 运行部署

帮助我们让它变得更好
-----------------------

与我们所有的开源项目一样，Kitesurf 住在 GitHub，我们欢迎分叉和 [contributions](https://github.com/cloudflare/kitesurf/pulls)。 但是，请注意，KiteSurf 正在进行大量开发，我们专注于使发动机更兼容（签出 [Web Platform Test evolution](https://kitesurf.dev/wpt)）、更可靠和 [efficient](https://kitesurf.dev/benchmarks)。

如果您想贡献，请从 [contribution guidelines](https://github.com/cloudflare/kitesurf/blob/main/CONTRIBUTING.md) 开始。 以最小的复制或建议的方法打开问题，并在打开拉取请求之前由维护者进行担保。 与大型重写或不相关的清理相比，使用测试、清晰证据和明确定义的范围进行的重点修复更容易查看，但所有贡献都不必是代码：重现渲染错误的小页面、自动化工作流程失败或清晰的文档更正可以帮助我们向前迈进。

敬请期待
-----------

风筝冲浪正在迅速发展。 请继续关注 [blog](https://blog.cloudflare.com/tag/browser-run/) 和我们的 [changelog](https://developers.cloudflare.com/changelog/) 中的更新，并密切关注 [Web Platform Tests](https://kitesurf.dev/wpt) 页面和 [benchmarks](https://kitesurf.dev/benchmarks) 中最新的标准兼容性。

并在 [Discord](https://discord.com/invite/cloudflaredev) 上与团队聊天。 我们正在为代理商构建浏览器，我们希望您的帮助使它变得更好。
