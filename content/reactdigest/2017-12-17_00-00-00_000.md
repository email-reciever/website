[Dockerizing a React App](https://reactdigest.net/link/4588/{SUBSCRIBER_ID}/{MEDIUM})

Docker是一种有助于加快开发和部署流程的技术。 如果您使用微服务，Docker 可以更轻松地将小型独立服务链接在一起。 它还有助于消除特定于环境的错误，因为您可以在本地复制您的生产环境。

[Optimize React Performance](https://reactdigest.net/link/4597/{SUBSCRIBER_ID}/{MEDIUM})

您是否知道在列表中错误地使用 key={} 可以将 DOM 操作增加 10 倍以上？ 众所周知，React 的虚拟 DOM 实现速度非常快。 然而，即使有了 React 的内置性能，在某些情况下，UI 也会开始感到迟钝。 性能不佳的主要罪魁祸首是产生过多的渲染和协调。 我们将介绍 4 种技术，以帮助确保您的应用得到优化并提供快速的用户体验。

[Testing React Components](https://reactdigest.net/link/4603/{SUBSCRIBER_ID}/{MEDIUM})

测试应该让我们充满信心。 确信我们的软件可以按照我们的想法执行，并且随着我们的功能积累，它将继续这样做。 但测试 UI 组件很少会产生信心。 相反，它常常让我们感到愤怒和效率低下。
