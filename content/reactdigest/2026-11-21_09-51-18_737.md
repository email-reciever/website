[React Futures - Server Components](https://reactdigest.net/link/10417/{SUBSCRIBER_ID}/{MEDIUM})

如果您熟悉 React，您就知道它是一个客户端库，它为开发人员提供了一组在 JavaScript 之上的抽象，可以快速有效地将用户界面写入 Web 应用程序。 客户端库意味着使用 JavaScript 在客户端的浏览器中呈现 DOM 中的视图。 在这种情况下，服务器仅负责交付包含 HTML、CSS 和 JavaScript 的应用程序包，不执行任何渲染。
