[React State with Hooks: useReducer, useState, useContext](https://reactdigest.net/link/6832/{SUBSCRIBER_ID}/{MEDIUM})

如果您还没有在 React 函数组件中过度使用状态管理，本教程可能会帮助您更好地了解 React Hooks（例如 UseState、UseReducer 和 UseContext）如何组合用于 React 应用程序中令人印象深刻的状态管理。 在本教程中，我们几乎将达到这些钩子模仿全局托管状态的复杂状态管理库的地步。 让我们深入了解我们将一步一步实现的应用程序。

[How I Built This: IsraelVC — Gatsby, Google Sheets, Now Serverless](https://reactdigest.net/link/6841/{SUBSCRIBER_ID}/{MEDIUM})

这是一个简单的网站：一页包含以色列最近发生的 20 项投资的列表。 它还有一个连接到它的谷歌表，作为网站的数据库。 该数据库包含 4000 笔投资。 在不久的将来，该网站也将显示所有投资。

[Interesting points from Abramov’s “A Complete Guide to useEffect”](https://reactdigest.net/link/6847/{SUBSCRIBER_ID}/{MEDIUM})

今年我在个人和制作项目中使用了很多钩子和 Redux Hooks。 API 边缘有点粗糙 — 但它们通常不辜负炒作。 我已经能够相对无缝地重构应用程序，并且使所有组件都具有功能性非常好。

[Urql—an alternative to Apollo Client for GraphQL](https://reactdigest.net/link/6846/{SUBSCRIBER_ID}/{MEDIUM})

该项目的最初动机是回归基础。 URQL 是出于对 Apollo 和 Relay 等 GraphQL 客户端库的最大化方法的挫败而创建的。 这些项目非常强大，但具有如此多的功能，以至于它们的 API 的庞大规模（更不用说它们的代码包！）提高了在 React 应用程序中使用 GraphQL 的门槛。
