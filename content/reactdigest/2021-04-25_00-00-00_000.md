本周的最爱

[The definitive guide to profiling React applications](https://reactdigest.net/link/10131/{SUBSCRIBER_ID}/{MEDIUM})

了解如何分析 React 应用程序以提高现实世界的性能是任何前端开发人员工具包中的一个好工具。 Profiler API 允许我们通过深入了解组件呈现的原因和时间来做到这一点。

[Styled components best practices](https://reactdigest.net/link/10130/{SUBSCRIBER_ID}/{MEDIUM})

[5 key lessons React tutorials don't teach](https://reactdigest.net/link/10132/{SUBSCRIBER_ID}/{MEDIUM})

[Comparing the new generation of build tools](https://reactdigest.net/link/10134/{SUBSCRIBER_ID}/{MEDIUM})
