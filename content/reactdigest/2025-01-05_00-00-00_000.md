React 19 通过从传统的“Promise Throwing”方法过渡到新的 `.use()` API，对 Suspense 处理异步数据加载的方式进行了重大更改。 虽然传统的抛出 Promise 触发悬念边界的方法仍然支持向后兼容性，但新的 `.use()` API 提供了一种更简洁、更明确的处理异步资源的方法，并且正在成为未来 React 应用程序的推荐方法。

_5分钟_ 作者：Benny Kok

ComfyDeploy 的一个团队将他们的仪表板从 Next.js 迁移到与 TanStack 路由器和 rspack 进行纯 React 的操作，从而实现了显着的性能改进。 构建时间从 3 分钟减少到 18 秒，热重装时间降至 200 毫秒以下。 虽然他们失去了一些 Next.js 功能，例如服务器端渲染和内置缓存，但迁移迫使更好的架构决策和改进的开发人员体验。
