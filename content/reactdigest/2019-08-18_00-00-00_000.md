[A library for building cross-platform native desktop apps](https://reactdigest.net/link/7225/{SUBSCRIBER_ID}/{MEDIUM})

NodeGui 是一个开源库，用于构建跨平台的原生桌面应用程序，使用 JavaScript 和 CSS 进行样式设计。 NodeGUI 应用程序可以从单个代码库在 Mac、Windows 和 Linux 上运行。 NodeGUI 由 Qt5 支持，与其他基于 Chromium 的解决方案（如 Electron）相比，它使 CPU 和内存更高效。 NodeGUI 支持类似于 CSS 的样式语法（这包括实际级联）。
