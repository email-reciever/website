[Fixing a hydration mismatch error and UI flicker](https://reactdigest.net/links/23606/rss)  
_9 分钟_ 乔尔吉·莫尼亚瓦

服务器端渲染在 JavaScript 加载之前将 HTML 发送到浏览器，然后对它进行“水化”以使页面具有交互性。 当服务器渲染的 HTML 与 React 在客户端产生的不同时，会发生水合不匹配，通常是因为在渲染过程中使用了像 localStorage 这样的仅客户端数据。 常见的修复包括将渲染延迟到组件安装之后，使用内联脚本将保存的状态应用于水化之前的 DOM，或者在预期不匹配且无害的情况下抑制警告。

[Optimizing TanStack start](https://reactdigest.net/links/23608/rss)  
_18 分钟_ 作者：Sarthak Mishra

尽管经过预渲染，但 TanStack 开始主页在移动设备上获得了 73 分，因为浏览器正在下载它从未需要的代码和资产。 最大的收获来自于删除每个页面上加载的站点范围的图像清单、延迟加载的关闭对话框、子集字体以及添加一个度量匹配的回退以防止布局偏移，以及阻止隐藏的导航图像在移动设备上的下载。 关键的 CSS 提取和延迟补水有助于增加维护开销，并自行产生不确定的评分改进。
