React ProSemirror 用于文本编辑的速度很快，但当多个组件使用相同的编辑器状态时可能会减慢速度。 本文展示了 React 的过渡 API 如何通过使一些更新非阻塞来解决这个问题。 主编辑器在预览组件更新时保持响应，略有延迟。 然而，这种方法会引入开发人员必须小心避免的陈旧数据的风险。

[Avoiding TanStack form pitfalls](https://matthuggins.com/blog/posts/avoiding-tanstack-form-pitfalls)  
_5分钟_马特·哈金斯

Matt 发现验证错误未显示，尽管验证以 tansack 形式运行。 问题是一个类型系统的差距，同步验证器接受异步函数而不会出现 TypeScript 错误。 当使用 onsubmit 等同步验证器选项使用异步验证时，表单在验证完成之前重新渲染，隐藏错误消息。 解决方案是使用 onSubmitAsync 之类的异步验证器变体。
