用于连接 React 组件的快速 Redux 提示
======================================================

#98 – 2017年6月4日

本周的最爱
---------------------

[Quick Redux tips for connecting your React components](https://reactdigest.net/link/3920/{SUBSCRIBER_ID}/{MEDIUM})

如果您在 React 应用程序中使用 Redux，您可能会使用 react-redux 将您的组件连接到您的状态。 Connect 方法是一个棘手的 Sum Bitch——尽管它有一个非常简单的 API，但引擎盖下却发生了很多魔力。 这很容易，尤其是在第一次学习 Redux 时，开始连接事物而不考虑实际发生的事情。 最简单的混乱之一是在渲染树顶部连接您的组件。

[Top 5 Recompose HOCs](https://reactdigest.net/link/3924/{SUBSCRIBER_ID}/{MEDIUM})

Andrew Clark 的重新组合确实改变了我和我的团队开发 React 组件的方式。 如果您还没有使用此库，它提供了各种高阶组件，为工程师提供了非常“lodash”的功能，就像开发人员体验一样。

[Converting React to Typescript](https://reactdigest.net/link/3925/{SUBSCRIBER_ID}/{MEDIUM})

在任何需要定期维护的项目上，我更喜欢 TypeScript 而不是 JavaScript。 考虑到我用 React 编写了大多数 Web UI 项目，我最终将两者结合起来——它工作得很好。 与现在大多数 JavaScript 库一样，React TypeScript 定义文件可用且最新。 你不应该担心你喜欢使用的东西不被支持的情况——最坏的情况是它只是在编写JavaScript。

[使反应迅速\[第2部分\]：为什么-did-you-update](https://reactdigest.net/link/3933/{SUBSCRIBER_ID}/{MEDIUM})

React 通常很快，但很容易犯一些导致性能问题的小错误。 缓慢的组件装载、深层组件树和不必要的渲染周期会很快加起来让一个感觉很慢的应用程序。

[SearchKit](https://reactdigest.net/link/3938/{SUBSCRIBER_ID}/{MEDIUM})

React UI 组件/小部件。 使用 Elasticsearch 构建出色搜索体验的最简单方法。
