[Idiomatic Redux: The History and Implementation of React-Redux](https://reactdigest.net/link/5980/{SUBSCRIBER_ID}/{MEDIUM})

react-redux 在概念上非常简单。 它订阅 Redux 存储，检查组件所需的数据是否已更改，并重新渲染您的组件。 然而，实现这一点有很多内部复杂性，大多数人并不知道 React-Redux 在内部所做的所有工作。 我想深入研究一些关于 react-redux 工作方式的设计决策和实现细节，以及这些实现细节如何随时间变化。

[Lazy loading (and preloading) components in React 16.6](https://reactdigest.net/link/5985/{SUBSCRIBER_ID}/{MEDIUM})

React 16.6 添加了一个新功能，使代码分割更容易：react.lazy()。 让我们看看如何以及为什么使用此功能与小型演示。

[Inside Fiber: in-depth overview of the new reconciliation algorithm in React](https://reactdigest.net/link/5989/{SUBSCRIBER_ID}/{MEDIUM})

React 是一个用于构建用户界面的 JavaScript 库。 其核心是跟踪组件状态变化并将更新状态投影到屏幕的机制。 在 React 中，我们知道这个过程是和解。 我们调用 setState 方法，框架检查状态或道具是否已更改并重新渲染 UI 上的组件。
