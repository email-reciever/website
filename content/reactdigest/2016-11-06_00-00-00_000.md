本周的最爱
---------------------

[SVG to React CLI](https://reactdigest.net/link/3216/{SUBSCRIBER_ID}/{MEDIUM})

一个命令行实用程序，它获取一个 SVG 图像文件并输出一个完整格式化的无状态功能 React 组件，其中包含 props 的高度和宽度。 使用标志切换格式和删除样式属性。

[Responsive React](https://reactdigest.net/link/3224/{SUBSCRIBER_ID}/{MEDIUM})

React 为您的前端提供了一个简单的、无状态的和声明式的组件架构，使您的应用程序从 20 多行增长到 20,000 多行代码时易于理解和扩展。 与任何其他新的 Web 技术一样，您在此过程中选择的一些基础知识（媒体查询、Z 索引等）将需要重新审视以适应组件的心态。

[Is React a good choice for a stable, long-term app?](https://reactdigest.net/link/3229/{SUBSCRIBER_ID}/{MEDIUM})

你认为 React 足够稳定，可以在这种情况下成为一个不错的选择吗？ 它是否接近 jQuery 之类的坚如磐石的 API 稳定性？ 或者它是典型的“我们在这个新版本中更改了一半的整个 API，因为我们的小辈很无聊，或者推特上有人敢让他这样做，欢迎来到 JS，婊子”？

[React.js Forms: Controlled Components](https://reactdigest.net/link/3234/{SUBSCRIBER_ID}/{MEDIUM})

本教程涵盖受控表单组件，并涉及不变性和单向数据流等 React 最佳实践。 有很多例子可供您借用和调整以用于您自己的项目。

[A MobX introduction and case study](https://reactdigest.net/link/3236/{SUBSCRIBER_ID}/{MEDIUM})

Mobx（以前是 Mobservable）是 JavaScript 前端应用程序的状态管理库。 本文介绍了它的示例以及它如何在带有 TypeScript 的真实应用程序中工作。 它基于我最近在大阪网页设计师和开发人员聚会上发表的演讲。
