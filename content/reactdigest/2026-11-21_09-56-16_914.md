在大规模的 React 应用中，路由、数据提取和代码分割自然是相互关联的。 即将推出的 React Router V4 牺牲了优化处理数据获取和代码分割的能力，以换取其更清晰的路由匹配 API。 我已经构建了一个名为 found 的新路由器，该路由器能够为通用用例实现高效的并行数据和代码获取，同时还保留一个可扩展的 API 来处理专门的用例。

[React's Children API](https://reactdigest.net/link/3254/{SUBSCRIBER_ID}/{MEDIUM})

React 的孩子是一个顶级的 API，它提供了处理“props.children”的实用程序。 它可以被组合中的父组件使用来转换和操纵它的子组件的渲染方式。
