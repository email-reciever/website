在 next.js 中的授权
===========================

第499章 2025年3月30日

> 使用 React Server 组件和服务器操作

[Authorization in Next.js](https://www.robinwieruch.de/next-authorization/)  
_10 分钟_ 罗宾·维鲁克

在本指南中，Robin 探讨了在 Next.js 应用程序中使用 React Server 组件和服务器操作实现授权。 他强调将授权作为主要的安全机制，最靠近数据源，包括 API、服务和数据访问层的多层防御层。 虽然授权也可以在路由、UI 元素和中间件中实现，但这些应该被视为补充措施，而不是主要的安全控制。 Robin 提供了在各个应用层实现授权检查的实用代码示例。

[A Guide to Understanding APIs in the Automotive World](https://api.carsxe.com/blog/a-guide-to-understanding-apis-in-the-automotive-world?utm_source=bonobo+press&utm_medium=email&utm_campaign=bonobo-3-27)  
_由 CarsXe_ 赞助

汽车 API 的新功能？ 这种深度潜水涵盖了车辆数据如何流动、VIN 解码的作用以及如何构建由 CarsXe 的 API 支持的 React 应用程序。 无论您使用的是 Next.js、GraphQL 还是 REST，本指南都将帮助您设计更智能的数据驱动应用程序。

[Experimenting with React View Transitions](https://frontendatscale.com/issues/43)  
_11 分钟_ 由马克西·费雷拉

在这篇新闻通讯中，Maxi 关注 React 的新视图转换 API，通过在最佳时间自动启动过渡、即时应用视图转换名称以及提供有用的生命周期类和回调来强调它如何简化以前笨拙的实现。 他还与 Frontend Masters 创始人 Marc Grabanski 一起播放了一个播客集，并包含有关基于浏览器的数据库、CSS 函数和编写可读代码的策略的资源。

[How React Works Behind the Scenes](https://www.deepintodev.com/blog/how-react-works-behind-the-scenes)  
_20 分钟_ 由 Kaan Peksen

深入了解 React 的内部工作原理，详细说明 JSX 如何通过 Babel 转换为 JavaScript，从而通过 React.createElement() 函数调用生成 React 元素。 Kaan 描述了渲染过程，区分了初始渲染和重新渲染，并解释了 React 如何使用虚拟 DOM 和光纤树优化性能。 他还涵盖了协调过程、差异算法，以及 React 如何确定 DOM 中何时以及更新什么，强调关键道具在跨渲染管理组件状态和身份方面的重要性。

[You should know this before choosing Next.js](https://eduardoboucas.com/posts/2025-03-25-you-should-know-this-before-choosing-nextjs/)  
_14 分钟_ 爱德华多·布萨斯

在这篇文章中，Eduardo 批评了 Vercel 的 Next.js 治理，强调了三个主要问题：缺乏对部署可移植性的适配器支持支持、尽管宣传其优势而缺乏官方无服务器文档，以及存在其他提供商无法使用的特定于 Vercel 的代码路径。 他还批评了 Vercel 对最近一个严重的安全漏洞的处理，他们将通知其他提供商的时间推迟了 8 天。 虽然承认 Vercel 有权从其开源创作中获利，但作者认为该公司未能在框架与其商业托管服务之间保持适当的界限。

[React i18next tips and tricks](https://www.mensurdurakovic.com/react-i18next-tips-and-tricks/)  
_12分钟_ Mensur Durakovic

Mensur 提供了使用 i18next 和 react-i18next 的高级 React 国际化的综合指南，涵盖了 TypeScript 集成、用于组织翻译的命名空间、回退机制、动态键、基于上下文的翻译、多元化规则、ICU 格式支持和自定义格式 功能。 他演示了用于处理不同语言的复杂翻译场景、确保类型安全和验证翻译完整性的实用代码示例，最终帮助开发人员创建具有具有文化意识的用户体验的全球可访问的应用程序。
