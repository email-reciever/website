[React X11](https://reactdigest.net/link/3943/{SUBSCRIBER_ID}/{MEDIUM})

React Custom Rendering 的副作用是与 X11 服务器通信的地方。 目标是创建一个简单的库，您可以应用您的 React 或 React Native 经验来构建小型 GUI 程序以在 X 窗口环境中运行（通常是 Linux 桌面，但我个人更经常使用 OSX + xquattz 下的代码）

[Building a React Component Library](https://reactdigest.net/link/3947/{SUBSCRIBER_ID}/{MEDIUM})

[Top 5 Recompose HOCs](https://reactdigest.net/link/3948/{SUBSCRIBER_ID}/{MEDIUM})

[React + D3 = VX](https://reactdigest.net/link/3956/{SUBSCRIBER_ID}/{MEDIUM})

VX 是可重用的低级可视化组件的集合。 VX 结合了 D3 的强大功能，可生成您的可视化效果，以及 React 更新 DOM 的优势。
