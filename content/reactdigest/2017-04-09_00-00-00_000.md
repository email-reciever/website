2017 年的简单 React 开发
==================================

#90 – 2017年4月9日

本周的最爱
---------------------

[Simple React Development in 2017](https://reactdigest.net/link/3723/{SUBSCRIBER_ID}/{MEDIUM})

也许您是一位希望尝试现代框架的 jQuery 开发人员。 或者，也许您是一个 Angular 开发人员，想了解所有炒作的内容。

[Create a realtime football voting app using React, Redux, React-Router-v4 and Firebase](https://reactdigest.net/link/3725/{SUBSCRIBER_ID}/{MEDIUM})

在本系列教程中，我们将使用 React、Redux、Redux-Saga、React-Router V4 和 Firebase 创建一个足球投票应用程序。 在第一部分中，我们将设置项目。

[A gentle Introduction to Higher Order Components](https://reactdigest.net/link/3734/{SUBSCRIBER_ID}/{MEDIUM})

高阶组件，或在缩写 HOC 下已知的，通常是 React 中难以掌握的模式。 这些组件可用于多个用例。 我想挑选出一种用例，即高阶组件的条件渲染，作为读者从本文中得到两个结果。

[Java UI Component on React Native](https://reactdigest.net/link/3739/{SUBSCRIBER_ID}/{MEDIUM})

在本文中，我们将学习如何将我们的 Android Java 视图组件转换为 React Native。 如果我们需要使用 Java UI 库或在我们的 React Native 应用程序中实现自定义视图组件，这尤其有趣。

[React Image Multi](https://reactdigest.net/link/3740/{SUBSCRIBER_ID}/{MEDIUM})

使用 React Image Multi，您可以指定多个图像作为后备，以防浏览器无法加载先前的图像。 此外，您可以指定在加载图像之前（即微调器）和无法加载指定图像的任何 React 元素。
