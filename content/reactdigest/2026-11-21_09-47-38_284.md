React Server 组件在没有框架的情况下支持
=======================================================

第522章 2025年9月7日

> 不需要 next.js 或其他框架

[React Server Components support without a framework](https://krasimirtsonev.com/blog/article/vanilla-react-server-components-with-no-framework)  
_9分钟

在这篇文章中，Krasimir 介绍了 Forket，它允许您在没有 Next.js 或其他框架的情况下使用 React Server 组件。 Forket 将您的代码拆分为单独的客户端和服务器版本。 它在您现有的构建工具之前工作，让您可以自由地在任何设置中实现服务器组件。 该工具自动处理组件序列化、水化和服务器操作。

[Take Control of User Access with WorkOS](https://workos.com/rbac?utm_source=reactdigest&utm_medium=newsletter&utm_campaign=q32025)  
_由工作赞助_

随着您的应用程序的扩展，管理角色和权限变得混乱。 硬编码访问会减慢您的速度，无法满足企业的需求。 WorkOS RBAC 为您提供结构化、可扩展的访问控制，使用干净的 API、强大的仪表板以及内置的单点登录和自动用户配置。

[Using activity with suspenseful data](https://www.simeongriggs.dev/use-the-activity-boundary-to-hide-suspenseful-components)  
_5 分钟_ 西蒙·格里格斯

Activity 是一个新的 React 19 组件，可让您隐藏和显示应用的部分，同时保持其数据和设置的完整性。 隐藏时，组件停止运行后台任务，但继续以较低的优先级加载数据。 当子组件需要基于只有他们才能看到的数据来控制自己的可见性时，这很有帮助。 它比其他方法更好，因为它可以保持组件状态并在后台预加载数据。

[Creating a review analyser using the Vercel AI SDK and React 19](https://codeboosted.com/blog/review-analyser/)  
_11分钟_卡尔·里彭

在本教程中，Carl 展示了如何使用 React 19 和 Vercel AI SDK 构建 AI 驱动的产品评论分析器。 您将创建一个表单，用户可以在其中粘贴客户评论以获得情感分析和业务见解。 该应用程序使用 React 19 的 UseActionState 钩子和服务器函数来处理表单提交和 AI 处理。 它与 OpenAI 的 GPT-4O Mini 模型相集成，以分析评论并返回结构化 JSON 响应，并提供情绪得分和可操作的建议。

[Deriving client state from server state](https://tkdodo.eu/blog/deriving-client-state-from-server-state)  
_5 分钟_ 由 Dominik Dorfmeister

Dominik 探索如何使用 useEffect 将客户端状态与服务器状态同步，而是可以直接导出状态。 检查所选用户 ID 是否仍然有效时，请即时计算结果，而不是更新存储的值。 这种方法更简单，并为您提供了更大的灵活性，例如在数据更改时自动恢复选择。

[Production-ready Astro middleware: Dependency injection, testing, and performance](https://www.lorenstew.art/blog/production-ready-astro-middleware/)
