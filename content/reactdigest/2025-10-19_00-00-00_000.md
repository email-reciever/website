> 在 React 中使用 JSON 数据可能会导致性能问题

[Serialization and deserialization without blowing React](https://www.orilivni.com/2025/10/serialization-and-deserialization/)  
_6分钟_由奥里·利夫尼

在 React 中使用 JSON 数据可能会导致性能问题。 使用 json.parse 将字符串转换为对象并使用 json.stringify 返回时，每次转换都会创建新的对象引用。 这使得 React 认为数据即使没有发生变化，也会导致不必要的重新渲染。 该解决方案使用结构共享。 此技术仅为实际更改的部分数据创建新的引用。 不变的零件保留其旧参考，防止不需要的重新渲染并提高高达 50% 的性能。
