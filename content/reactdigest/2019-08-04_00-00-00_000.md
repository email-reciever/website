本周的最爱
---------------------

[Secret Powers of Chrome DevTools](https://reactdigest.net/link/7133/{SUBSCRIBER_ID}/{MEDIUM})

Anushree在2019年6月25日的ReactJS Girls London聚会上查看了谷歌Chrome开发工具的一些鲜为人知的省时功能，提供了提高生产力水平的提示。

[Using Redux with React Hooks - Should You Though?](https://reactdigest.net/link/7145/{SUBSCRIBER_ID}/{MEDIUM})

React Redux 最近发布了 7.1 版，其中包括期待已久的 React Hooks 支持。 这意味着您现在可以放弃 Connect 高阶组件并在功能组件中使用带有钩子的 Redux，但您应该吗？ 这篇文章将了解如何开始使用带有钩子的 Redux，然后探索这种方法的一些问题。

[Decoupling logic from react components](https://reactdigest.net/link/7149/{SUBSCRIBER_ID}/{MEDIUM})

每当有一个新的 React 项目时，大多数前端开发人员都会摸索基本配置。 样式实现、组件解耦和文件夹结构的模式将出现 - 并不总是为了好。 最糟糕的是，我见过的每一个前端开发人员都会以不同的方式解决其中最大的问题，即业务逻辑难题。 为了创建一个标准来解决 Labcodes 的领域层问题，我进行了一些研究，并找到了一种处理请求和数据处理的良好且可持续的方法。 最终结果：react-redux-api-tools。

[React defaultProps is dying, who’s the contender?](https://reactdigest.net/link/7151/{SUBSCRIBER_ID}/{MEDIUM})

在 React 团队宣布 Hooks，并将功能组件作为“解决我们所有问题的解决方案”之后，我脑海中闪过这个想法，为什么我们应该使用 React 的 DefaultProps 而不是 ES6 的功能组件的默认值？ 然后我找到了这个 RFC，它几乎说明了 React 核心团队对这个想法的看法。

[Component Story Format](https://reactdigest.net/link/7152/{SUBSCRIBER_ID}/{MEDIUM})

Storybook 5.2 引入了组件故事格式 (CSF)，这是一种基于 ES6 模块的创作故事的新方法。 组件故事简单、易于阅读，并且与 Storybook 的内部 API 分离，因此您可以在任何地方使用它们。
