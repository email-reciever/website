本周的最爱
---------------------

[React’s Five Fingers of Death. Master these five concepts, then master React.](https://reactdigest.net/link/3453/{SUBSCRIBER_ID}/{MEDIUM})

几年前，我的朋友 Sean 开始告诉我这个名为 React 的全新前端库将如何接管网络。 起初，我将其视为另一个框架时尚。 但后来我开始越来越多地听到 React 的消息，以至于我觉得忽略它不再是一种选择。

[Children in JSX](https://reactdigest.net/link/3455/{SUBSCRIBER_ID}/{MEDIUM})

React 是高度可组合的。 以及启用它的 API 是 props.children。 它赋予我们创建一个占位符，该占位符将从外部填充内容。

[The Good and Bad parts of JSX](https://reactdigest.net/link/3460/{SUBSCRIBER_ID}/{MEDIUM})

JSX 是在 React 应用中声明组件结构的事实上的标准。 它因熟悉的语法而变得流行，在这种情况下它是 HTML。 但不仅如此。 我个人开始使用 JSX 是因为它不如普通 JavaScript 冗长，我认为这是主要原因。

[A Prettier JavaScript Formatter](https://reactdigest.net/link/3467/{SUBSCRIBER_ID}/{MEDIUM})

今天我宣布 Prettier，一个受 Refmt 启发的 JavaScript 格式化程序，支持 ES2017、JSX 和 Flow 的语言功能。 Prettier 摆脱了所有原始样式，并通过将 JavaScript 解析为 AST 并漂亮地打印 AST 来保证一致性。

[Crafting a high-performance TV user interface using React](https://reactdigest.net/link/3473/{SUBSCRIBER_ID}/{MEDIUM})

随着我们努力为会员找出最佳体验，Netflix TV 界面不断发展。 例如，在 A/B 测试、眼动追踪研究和客户反馈之后，我们最近推出了视频预览，以帮助会员对观看内容做出更好的决定。
