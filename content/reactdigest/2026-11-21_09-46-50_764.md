[Who owns the tree? RSC as a protocol, not an architecture](https://tanstack.com/blog/who-owns-the-tree)  
_9 分钟_ 由坦纳·林斯利

React Server 组件既是架构又是协议。 大多数框架仅使用服务器拥有的模型，其中服务器控制树，客户端填充交互部分。 TanStack Start 还支持客户端拥有的模型，让您在不重构整个应用程序的情况下将服务器呈现的片段提取并丢弃到客户端控制的树中。 这使得 RSC 成为一个灵活的工具，而不是你必须构建的固定架构。

[DOM manipulation that kills your 60fps](https://stackinsight.dev/blog/dom-manipulation-empirical-study/)  
_20分钟_ 梁高新

Ko-HSin 研究了某些 JavaScript DOM 操作模式如何减慢网页的速度并破坏 60fps 的流畅性能。 他对真正的浏览器进行基准测试并分析 275 个代码存储库。 结果表明，在循环中重复使用 innerHTML 和低效地改变样式会导致严重的减速，混合读取和写入。 许多现实世界的项目仍然使用这些模式。 该研究建议批量更新并使用 CSS 类以获得更好的性能。
