ReactJS 的最佳 UI 库和框架
===============================================

#112 – 2017年9月10日

本周的最爱
---------------------

[Best UI libraries and frameworks for ReactJS](https://reactdigest.net/link/4266/{SUBSCRIBER_ID}/{MEDIUM})

自从 React 引入以来，数十个 UI 库和框架开始一一出现并继续进行。 所有这些工具、样板和 UI 组件都可以节省您的时间并帮助您专注于构建应用程序。

[react-offline-hoc](https://reactdigest.net/link/4271/{SUBSCRIBER_ID}/{MEDIUM})

React Higher-Order Component Factory 以指示应用程序的在线/离线状态的 isOnline 道具来增强您的现有组件。 此 HOC 使用浏览器的本机 window.navigator.online 属性及其在线/离线事件来确定当前的脱机状态。

[Component Lifecycle Simulators](https://reactdigest.net/link/4278/{SUBSCRIBER_ID}/{MEDIUM})

该模拟器允许您在初始化和安装组件时逐步执行每个生命周期方法，并观察 this.state 和 this.props 如何响应每个时间点的各种操作。

[react-imgpro](https://reactdigest.net/link/4281/{SUBSCRIBER_ID}/{MEDIUM})

📷 用于 React 的图像处理组件

[React-PDF](https://reactdigest.net/link/4282/{SUBSCRIBER_ID}/{MEDIUM})

在 React 应用程序中轻松显示 PDF 文件。
