本周的最爱

[Do React Hooks Replace Redux?](https://reactdigest.net/link/7165/{SUBSCRIBER_ID}/{MEDIUM})

在我看来，钩子和 Redux 之间几乎没有重叠。 Hooks 并没有为我们提供神奇的新状态能力。 相反，它增强了我们已经可以使用 React 做的事情的 API。 但是，Hooks API 使本机 React 状态 API 更有用，而且由于它比它所取代的类模型更容易，我在适当时使用组件状态的次数比以前多得多。

[How to fix the ugly focus ring and not break accessibility in React](https://reactdigest.net/link/7169/{SUBSCRIBER_ID}/{MEDIUM})

在保持可访问性的同时创造美丽、美学的设计一直是前端的挑战。 一个特别的障碍是可怕的“：焦点”环。

[React Spaces](https://reactdigest.net/link/7173/{SUBSCRIBER_ID}/{MEDIUM})

React Spaces 允许您将页面或容器 HTML 元素划分为空格。 这些空间知道如何相互关联，也可以分成更多的嵌套空间。

[Use React.memo() wisely](https://reactdigest.net/link/7175/{SUBSCRIBER_ID}/{MEDIUM})

用户享受快速响应的用户界面 (UI)。 小于 100 毫秒的 UI 响应延迟对用户来说是即时的。 100 到 300 毫秒之间的延迟已经可以察觉。

[Shallow Testing Hooks with Enzyme](https://reactdigest.net/link/7182/{SUBSCRIBER_ID}/{MEDIUM})

很容易直接使用钩子——直到您尝试测试您的新组件。 如果您习惯使用 Enzyme 的浅层渲染，您会在没有任何测试通过时发现自己真的很困惑，即使一切都在您的浏览器中完美运行。 别担心! 问题可能不在于您的代码，并且不需要太多时间让这些测试再次工作。
