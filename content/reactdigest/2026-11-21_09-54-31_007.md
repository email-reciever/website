[React Flip Toolkit](https://reactdigest.net/link/5315/{SUBSCRIBER_ID}/{MEDIUM})

[Fullstack React's Guide to using Refs in React Components](https://reactdigest.net/link/5316/{SUBSCRIBER_ID}/{MEDIUM})

[React Native is Getting Evicted by Airbnb: Our Response](https://reactdigest.net/link/5327/{SUBSCRIBER_ID}/{MEDIUM})

Airbnb 长期以来一直是 React Native 的支持者，并且在早期投入了大量的工程资源，以在他们的移动堆栈中采用它。 本周，他们发布了一份关于这种用法的事后分析，并宣布他们打算全面远离 React Native。 虽然 React Native 可能不是他们的应用生态系统的最佳工具，但我们仍然相信它是我们在 Headway 的最佳选择。 让我们谈谈 Airbnb 的经历以及为什么 React Native 的未来仍然非常光明。

[Clean Code saves Devs. The Caffeina approach to ReactJS](https://reactdigest.net/link/5332/{SUBSCRIBER_ID}/{MEDIUM})
