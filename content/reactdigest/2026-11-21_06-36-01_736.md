[The future of CSS](https://reactdigest.net/links/23537/rss)  
_19 minutes_ by Josh Comeau

Major browsers are collaborating on Interop, a yearly project to standardize web feature support. Josh highlights their top 10 picks for Interop 2027, including CSS functions, new corner shapes like squircles and bevels, scroll-triggered animations, and scroll state queries. Many features already work in Chrome today and could reach full browser support within the year.

[Pure UI in the agentic era](https://reactdigest.net/links/23539/rss)  
_5 minutes_ by Matt Rothenberg

UI is a function of state, but most teams never see all the states their screens can occupy. According to Matt, agents make this worse: they check one account, report success, and miss role or plan combinations that break the layout. Making display state explicit at the component boundary lets you render every relevant combination as a visual grid, turning a hidden assumption into something you can actually inspect before merging.

[WebSocket servers in JavaScript](https://reactdigest.net/links/23540/rss)  
_2 minutes_ by Daniel Lemire

A benchmark tests WebSocket server speed across Node.js, Bun, and Deno using a simple ping-pong message loop between two clients. Node.js with uWebSockets.js comes out fastest at 49,000 round trips per second, close to a raw C server at 54,000. Bun and Deno trail behind. Using the popular ws package, Node.js still leads, while ws actually outperforms Bun's built-in server on Bun itself.

[React Native 0.88 released](https://reactdigest.net/links/23541/rss)  
_10 minutes_ by Fabrizio Cucci et at.

React Native 0.88 ships with Web-based event dispatching on by default, bringing real capture and bubble paths that match how browsers work. It adds variable font support on both platforms, SceneDelegate lifecycle support for upcoming iOS 27 requirements, and bumps React to 19.3.0. This is the third release in a row with no user-facing breaking changes, making upgrades straightforward for most apps.

[Building a filterable menu that works for everyone](https://reactdigest.net/links/23542/rss)  
_13 minutes_ by Jenna Smith, James Nelson

Filtering a menu sounds simple, but making it work well with keyboards, screen readers, and submenus requires careful thought. Picking the right ARIA role matters because it sets user expectations. A combobox or autocomplete pattern would mislead users since they imply selecting a value, not running a command, so a dialog containing a search field and a menu fits better. Small details like where focus lands, how keys behave while typing, and when submenus steal focus all shape whether the interaction feels natural.
