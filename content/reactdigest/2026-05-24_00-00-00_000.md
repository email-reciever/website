GitHub 问题很慢，因为太多的页面加载重复相同的数据提取，打破了开发人员的重点。 修复涉及使用 IndexedDB 构建客户端缓存、在用户单击之前填充该缓存的预热策略以及将优势扩展到全页加载的服务工作者。 结果是戏剧性的：中位加载时间从 1,200 毫秒下降到 700 毫秒，现在在 120 毫秒以下完成了所有导航的四分之一。

_7 分钟_ 拉斐尔·萨拉哈

Calligraph 是一个 React 库，通过平滑地将一个字符串变形为另一个字符串来动画文本更改。 它跟踪字符差异并流畅地转换它们，而不是立即交换文本。 该库重量轻且易于进入现有项目。 它适用于计数器、标签或文本经常更新的任何 UI 元素。

[The hidden cost of React Activity](https://www.peterp.me/articles/hidden-cost-of-react-activity/)  
_7 分钟_ 彼得·皮卡尔奇克

当屏幕被隐藏时，React Activity 会保留 UI 状态，但不会保留订阅或效果等副作用。 当屏幕再次变得可见时，这些效果将被销毁并重新创建，这可能是昂贵的。 在具有许多嵌套组件和 UseEffect 逻辑的 React Native 应用程序中，这可能会导致返回屏幕时的性能问题。 关键的收获是 Activity 是有用的，但前提是子树具有最小的影响重的逻辑。
