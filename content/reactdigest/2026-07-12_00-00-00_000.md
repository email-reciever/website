_11 分钟_ 艾萨克·奥科罗

React Compiler v1.0 自动化了内存，因此您可以从代码中删除大多数 UseMemo 和 UseCallback 钩子。 在真正的 next.js 应用程序上启用它主要有效，但出现了两个微妙的错误：表单预览由于 React Hook 表单不兼容的内部结构而冻结，以及移除 UseCallback 暴露了图表组件中的陈旧数据时序问题。 Isaac 建议首先运行 lint 规则，在第三方库依赖函数标识的地方保留明确的钩子，并在出货前通过端到端测试进行验证。

[React compiler is a retrofit](https://longho.dev/posts/react-compiler-is-a-retrofit/)  
_4 分钟_ 由 Long Ho

React Compiler 减少了对手动记忆的需求，但它是在框架的核心模型已经确定后添加的。 这意味着它必须从一开始就推断出像Svelte和Solid这样的编译器优先框架。 它还增加了大约 20% 的捆绑大小，这对于加载时间是真正瓶颈的应用程序很重要。 在分析显示明显的好处的地方使用它，但不要将更少的可见备忘录误认为更清洁的基础。
