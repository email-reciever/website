[TDD in a React frontend](https://reactdigest.net/link/9637/{SUBSCRIBER_ID}/{MEDIUM})

如今，只有少数专业开发人员严重怀疑测试驱动开发和测试驱动设计 (TDD) 的价值。 但我见过的许多代码库的现实是，TDD 通常仅限于“业务逻辑”所在的后端。

[MERN Auth - Login with Email (JWT)](https://reactdigest.net/link/9627/{SUBSCRIBER_ID}/{MEDIUM})

使用 React、Node.js、Express 和 MongoDB 在之前的视频中，您已经学会了如何构建一个完整的 Mern 项目。 在本视频中，我们将添加身份验证！ Auth是一个复杂的过程，它意味着允许用户注册和登录。

[GUI tool to generate React-Table code for your projects](https://reactdigest.net/link/9630/{SUBSCRIBER_ID}/{MEDIUM})

react-table 是一个很棒的库，用于创建具有多个标题、排序、过滤、分页等的表。但学习起来很复杂。 有时我们的用例很简单，我们不想花时间从头开始学习。 为了解决这个问题，我们提供了一个 GUI 实用程序，可以为您生成表代码，包括排序功能、过滤和分页。 您可以将生成的代码直接使用到您的项目中。

[3 Approaches to Integrate React with Custom Elements](https://reactdigest.net/link/9632/{SUBSCRIBER_ID}/{MEDIUM})

由于其可移植性，我被 Web 组件所吸引。 它是有道理的：自定义元素是功能齐全的 HTML 元素，适用于所有现代浏览器，而 Shadow DOM 封装了正确的样式，并带有一个不错的表面区域进行定制。 这是一个非常适合的，特别是对于希望跨多个框架（如Angular、Svelte和Vue）创建一致的用户体验的大型组织。

[Why React Context is Not a "State Management" Tool (and Why It Doesn't Replace Redux)](https://reactdigest.net/link/9636/{SUBSCRIBER_ID}/{MEDIUM})

鉴于有关该主题的问题的普遍性，我将这篇文章作为对这些问题的权威答案。 我将尝试澄清实际上是什么上下文和 Redux，它们应该如何使用，它们的不同之处以及何时应该使用它们。
