[React, Redux and JavaScript Architecture](https://reactdigest.net/link/4692/{SUBSCRIBER_ID}/{MEDIUM})

无论您是否使用它们，React 和 Redux 都很重要。 它们改变了我们对前端 Web 应用程序结构的思考方式。 他们可以非常强大。 但它们不是魔法。 JavaScript 代码不会因为使用 React 而自动变得更好。 编写可怕的 React 代码很容易，就像编写可怕的 Vanilla JavaScript 一样容易。 那么，为什么 React 很重要呢？

[Next.js-like framework for server-rendered React apps built with React Router 4](https://reactdigest.net/link/4697/{SUBSCRIBER_ID}/{MEDIUM})

Next.js 很棒。 但是，它的路由系统不适合我。 IMHO React Router 4 是构建这样一个框架的更好基础......这就是这里的目标：路由只是组件，不/不应该/不应该与文件夹结构有任何关系。 静态路由配置很好。 Next.js 的 GetInitialProps 是一个绝妙的主意。 基于路由的代码拆分应该是免费的或易于选择的。 基于路由的过渡/分析/数据加载/预加载等，应该是免费的，或者是微不足道的自己实现的。 必须与 TypeScript（即没有 Babel）一起使用得很好，一般来说，所有东西都应该随附了电池组，但可以覆盖。
