[Debugging React Like a Champ with VSCode](https://reactdigest.net/link/4425/{SUBSCRIBER_ID}/{MEDIUM})

我花时间在终端、浏览器和编辑器之间来回跳动的日子已经一去不复返了。 没有人有时间做这件事！ 在本指南中，我将向您展示如何使用 Visual Studio Code 的调试功能来增强您的 React 工作流程。 您将学习如何连接VSCode和Chrome，以便您可以直接从VSCode调试浏览器代码😎
