> 导航时应发出多少请求

[One roundtrip per navigation](https://overreacted.io/one-roundtrip-per-navigation/)  
_26分钟_丹·阿布拉莫夫

Dan 讨论了在 Web 应用程序中导航到新页面时应该发出多少 HTTP 请求。 他探索了各种数据获取方法，从传统的 HTML 网站开始，与通常需要多个请求的客户端方法形成对比。 DAN 还检查了托管和性能之间的权衡，分析了包括 REST API、基于组件的获取、加载器、服务器函数、GraphQL 片段和 React Server 组件在内的几种模式。

[Why React error boundaries aren't just try/catch for components](https://www.epicreact.dev/why-react-error-boundaries-arent-just-try-catch-for-components-i6e2l)

[The visual editor for React](https://github.com/puckeditor/puck)  
_10 分钟_ 由 Puck 编辑器

Puck 是 React 的可视化编辑器，允许开发人员使用基于组件的方法构建和自定义页面。 它包括一个简单的配置系统，用于定义组件和渲染编辑器和页面视图，并为 next.js、remix 和 React 路由器应用程序提供各种入门配方。

[The beauty of TanStack Router](https://tkdodo.eu/blog/the-beauty-of-tan-stack-router)  
_11分钟_多米尼克·多夫梅斯特

TanStack 路由器因其类型的安全性、细粒度的状态订阅和周到的开发人员经验而脱颖而出。 路由器提供完全类型安全的路径参数和链接，集成的搜索参数验证，并通过基于选择器的订阅防止不必要的重新渲染。 它支持基于代码和基于文件的路由方法，同时提供内置的 Suspense 支持，使其成为构建现代 Web 应用程序的 React 查询的理想伴侣。
