_10 分钟_ 马特·哈金斯

[React server components in TanStack](https://frontendmasters.com/blog/react-server-components-in-tanstack/)  
_12 分钟_ 作者：Adam Rackis

TanStack Start 中的 React Server 组件仅在服务器上运行，因此它们的代码永远不会到达浏览器。 这减少了向用户发送的 JavaScript 的数量，这在组件树很大或拉入繁重的库时最有帮助。 TanStack 的方法是明确的，使用 Clear Server 函数来声明呈现为服务器组件的内容。 像任何工具一样，它在正确的情况下效果最好，不会使每个项目受益。
