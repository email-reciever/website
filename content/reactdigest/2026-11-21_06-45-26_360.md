[JPEG XL vs AVIF for web use-cases](https://reactdigest.net/links/23491/rss)  
_about 1 hour_ by Jake Archibald

AVIF beats JPEG XL in most web use cases, producing smaller files, encoding faster, using less memory, and decoding quicker. JPEG XL occasionally wins for certain photos, lossless images, and possibly HDR, but these are exceptions. For most web images, AVIF at high effort with full color resolution is the best default choice, though a newer JPEG XL encoder called jixel is closing the gap fast.

[GraphQL as a foundation for malleable UI](https://reactdigest.net/links/23493/rss)  
_6 minutes_ by Jovi De Croock

GraphQL was built around the idea that clients define their own data needs, and that principle matters more now that AI agents can reshape interfaces on the fly. When a user asks to turn a product grid into an inventory table, the data requirements change too, and a fixed endpoint either falls short or over-delivers. A capable GraphQL schema lets the client update both the interface and its query together, without touching the server.

[className considered harmful](https://reactdigest.net/links/23497/rss)  
_5 minutes_ by Matt Rothenberg

Accepting className on design system components feels convenient, but it lets teams quietly build up inconsistent overrides that are hard to track and break during refactors. Renaming it to something like DANGEROUS\_className keeps the escape hatch open while making overrides visible in code review and easy to find with a simple search. Repeated overrides often signal a missing variant or an unreported bug. Tracking them over time turns drift into useful feedback.
