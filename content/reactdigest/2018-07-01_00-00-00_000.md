本周的最爱
---------------------

[Lessons learned from my first React app](https://reactdigest.net/link/5290/{SUBSCRIBER_ID}/{MEDIUM})

如果您刚刚开始学习 React，请从官方文档开始。 就文档而言，React 很容易理解，并提供了很多示例。 不要做我所做的，并从 React 教程开始。 我从 Egghead.io 的《初学者反应指南》开始（在我看来“初学者”是用词不当），这很粗糙。 公平地说，我听说 Egghead.io 是为更有经验的开发人员准备的，他们希望了解新的框架。

[✨ Immensely upgrade your development environment with these Visual Studio Code extensions](https://reactdigest.net/link/5293/{SUBSCRIBER_ID}/{MEDIUM})

让我们谈谈代码 — Visual Studio Code。 一些我亲爱的读者要求我写下我使用的扩展 — 所以我们开始吧！ 🙂

[Custom error pages in React with GraphQL and Error Boundaries](https://reactdigest.net/link/5299/{SUBSCRIBER_ID}/{MEDIUM})

我最近在使用 GraphQL 和 React 时遇到的一项挑战是如何处理错误。 作为开发人员，我们之前可能已经在服务器渲染的应用程序中实现了默认的 500、404 和 403 页，但是弄清楚如何使用 React 和 GraphQL 做到这一点很棘手。

[How to use React’s experimental new Profiler feature](https://reactdigest.net/link/5302/{SUBSCRIBER_ID}/{MEDIUM})

React 16.4.0 最近发布！ 🎉 🎉 🎉 正是这样的时候，你会意识到你对你最喜欢的框架的小版本版本感到兴奋的时候有多少是一个 JavaScript 书呆子。 好！

[How to Combine Node JS Back-end with React JS Front-End](https://reactdigest.net/link/5309/{SUBSCRIBER_ID}/{MEDIUM})

上传文件似乎是一项需要征服的任务，尤其是在 Web 开发中。 在本教程中，我们将了解如何在前端使用 ReactJS 和后端的 Node.js 上传一个基于 Ajax 的简单文件。 这很容易通过以下技术实现，因为整个源代码将使用一种语言，即 JavaScript。 为了向您展示如何将 Node.js 后端与 React JS 前端组合，我们将使用一个简单的文件上传示例。
