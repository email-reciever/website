[具有 `@supports named-feature()`](https://www.bram.us/2026/08/27/feature-detecting-undetectable-css-features-with-supports-named-feature/ "www.bram.us") — `@supports` 的功能检测“无法检测”的 CSS 特征，让您检测到对选择器、属性和值以及规则的支持，但是更广泛的功能组合呢？ `named-feature()` 可以堵塞差距，并且广泛的支持是紧密的（已经在 Chrome 150 中，以及 Firefox 和 Safari 的 Beta/Preview 版本）。

⚡️简介

*   🦊 Firefox 现在每两周发布一个主要版本，[Firefox 155 landed yesterday](https://developer.mozilla.org/en-US/docs/Mozilla/Firefox/Releases/155) 具有较大的 CSS 传送：`attr()` 在 _any_ 属性中，加上 `progress()`、`alpha()` 和 `font-width`（_4]_ 的新名称）。
    
*   🚫 终于发生了：[Google has removed all remaining Manifest V2 extensions from the Chrome Web Store](https://webiterate.dev/google-removed-extensions-ublock-origin-108/)，包括Ublock Origin。
    
*   ✨ Rachel Andrew 四舍五入 [what's new to the web platform in August](https://web.dev/blog/web-platform-08-2026)，这是一个很好的基线月份，`text-box` 属性引领潮流。
    
*   📱 iOS 上的 Firefox 具有 [added a built-in, opt-in ad blocker](https://blog.mozilla.org/en/firefox/ad-blocker-on-ios/)，它基于 WebKit 的内容阻止程序 API 和 EasyList 过滤器列表（_no 扩展名必需_）。
    
*   📏 [CSSUnits.com](https://cssunits.com/) 为 CSS 中的每个单元提供了一个解释器。

🕰️一路走下记忆之路

[![](https://res.cloudinary.com/cpress/image/upload/w_1280,e_sharpen:60,q_auto/oumji2ws7amzmk1duqau.jpg)](https://contemporary-home-computing.org/prof-dr-style/)

在 Olia Lialina 2010 年的文章 [Prof. Dr. Style: Top 10 Web Design Styles of 1993](https://contemporary-home-computing.org/prof-dr-style/) 中，您可以回到最早的日子，当时人们才刚刚开始考虑“网页设计”，几乎没有功能可以增加任何天赋。

作者触及了在接下来的几年中逐渐出现的功能，例如动画 GIF、表格甚至背景颜色（可以由页面作者指定，而不仅仅是最终查看器）。

⭐如果您喜欢这样的东西并且想要比 1993 年更远的地方扩展，[Web Design Museum](https://www.webdesignmuseum.org/all-websites) 致力于在其前几十年中保留 Web 的屏幕截图。
