[css 嵌套与 `CSSNestedDeclarations`](https://web.dev/blog/css-nesting-cssnesteddeclarations "web.dev") — `CSSNestedDeclarations` 是一个新的 CSS 工作组批准的接口，用于修复一些 CSS 嵌套的怪癖，例如在样式规则混淆起来之后出现的声明。 它采用 V130 的 Chrome 版本，在 Firefox 和 Safari 中进行了测试。 Bramus 共享一个 [quick behind-the-scenes here](https://www.bram.us/2024/10/08/cssnesteddeclarations-is-coming-to-all-browsers-to-improve-css-nesting/)，但简而言之：“这意味着 CSS 嵌套在 Chrome 130 中变得更好了。”_
