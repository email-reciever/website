每个人的互操作2027愿望清单

上周我们分享了你现在可以 [rank the Interop web platform proposals for 2027](https://interop-rank.fxdx.dev)。 从那时起，很多人分享了他们自己的排名并解释了他们的选择：

*    = [Josh Comeau's _The Future of CSS_](https://www.joshwcomeau.com/css/interop-2027/) – Josh 的前十名，从 CSS 函数和 `corner-shape` 到锚定的容器查询和滚动触发的动画，每个都有实时演示、当前的浏览器支持以及您今天可以使用的提示。 一个特别好的起点。
    
*   🔎 [Sara Soueidan's picks](https://www.sarasoueidan.com/blog/interop-2027-rankings/) 将可访问性放在首位。 她指出，这是一种特权，我们可以影响浏览器制造商的工作。 `focusgroup` 是她的首选。
    
*   ✏️ [Declan Chidlow's 13 features](https://vale.rocks/micros/20261011-0700) – 顶部的 SVG 改进，其次是 CSS `reading-flow` 和 `reading-order` 属性。
    
*   📝 更多的选择 [Stuart Robson](https://www.alwaystwisted.com/articles/and-thats-my-rank-2027-edition)、[Eric Meyer](https://meyerweb.com/eric/thoughts/2026/10/14/my-interop-2027-rankings/)、[Ana Rodrigues](https://ohhelloana.blog/my-interop-2027/) 和 [Tyler Sticka](https://tylersticka.com/journal/interop-2027-rank/)，而 🦋 [this Bluesky thread](https://bsky.app/profile/sturobson.com/post/3mxlhrdlock22) 有更多的选择。
    

灵感提交自己的？ [Rank about ten proposals you'd like to see prioritized](https://interop-rank.fxdx.dev/)。 Firefox 团队表示，这足以提供有用的输入。

一丝不苟的赞助商

🗳️ [HTML 2026 的状态](https://survey.devographics.com/en-US/survey/state-of-html/2026 "survey.devographics.com") — 年度调查回报，以衡量 HTML 功能和浏览器 API 的认识和采用情况。 今年涵盖 Web 组件、渐进增强、AI 等。 只需不到 15 分钟，您只需服用即可学习新事物。

文理学

[Safari Blocks 'Identity Resolution'跟踪基础设施](https://webkit.org/blog/18438/blocking-identity-resolution-infrastructure/ "webkit.org") — 跨站点 cookie 在 Safari 中早已不复存在，因此跟踪器移至“身份解决方案”，第三方将您输入的电子邮件地址输入到表单中并将其转换为跨站点， 跨设备跟踪 ID。 Safari 现在在域级别阻止它们。

威兰德、沃尔夫和芬克尔（网络工具包）

⚡️简介

*   ⚠️ 如果 PHP 运行在您的站点后面的任何位置： [PHP 8.5.12, 8.4.27, 8.3.36 and 8.2.35 fix two critical bugs](https://www.php.net/archive/2026.php#2026-10-21-5) 允许未经身份验证的远程代码执行。 立即更新，_mod\_php_ 安装尤其如此。
    
*   🌐 [Chrome 157 is in beta](https://chromestatus.com/release-notes/157) 与 `corner` 速记，`text-overflow` 和 `anchor-valid` 的 `<string>` 值。 Chrome 156 本周使用 CSS `random()` 稳定。
    
*   🚫 [Chrome 已经完成了 `unload` 事件](https://developer.chrome.com/blog/unload-deprecated-in-chrome) 的弃用：处理程序默认不再触发，因此请改用 `pagehide` 或 `visibilitychange`。

[JPEG XL vs Avif for Web 用例](https://jakearchibald.com/2026/jpeg-xl-vs-avif/ "JakeArchibald.com") — 现在 JPEG XL 已经登陆所有主要浏览器，Jake 采用了这种格式，将其与 Avif 进行了基准测试。 这里有很多细节，有一些好的收获。 您可能还会对 JPEG XL 的 [what you can cram in under 200 bytes](https://jpegxl.info/art/big_gallery.html) 感到惊讶。
