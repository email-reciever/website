✍️ **您好，欢迎来到 2024 年前端焦点上一期！** 这是 Web 平台充实的一年，我们的开发人员工具带添加了许多令人兴奋的新功能，改进了浏览器合作，开发了 AI 工具的情况， 还有更多。 与以往一样，我们将回顾我们在 2024 年整个 _frontend focus_ 中分享的内容，并重新审视一些亮点 - 毫无疑问，您会发现一些值得书签、分享或重新访问的东西（或者您可能错过了） 这是第一次）。

如果您喜欢这份时事通讯并发现它今年很有价值，请考虑 [following us on Bluesky](https://bsky.app/profile/frontendfocus.bsky.social)，也许将其转发给朋友——甚至可能有人在新的一年开始他们的前端旅程。 非常感谢阅读。 我们将在一月初回到您的收件箱。 _现在，这是一个大问题，让我们开始吧！_

🗓️ 2024年十强

01：[十二个现代 CSS 单行升级](https://moderncss.dev/12-modern-css-one-line-upgrades/ "moderncss.dev") — Stephanie 分享了今年早些时候非常值得了解的十几种 CSS 属性的列表 — 这里的单行升级将有助于减少技术性 债务，删除不必要的 JavaScript 行，并为用户体验获得一些轻松的胜利。

斯蒂芬妮·埃克尔斯

[![](https://res.cloudinary.com/cpress/image/upload/c_limit,w_480,h_480,q_auto/copm/d652a898.png)](https://frontendmasters.com/courses/complete-react-v9/?utm_source=email&utm_medium=frontendfocus&utm_content=reactv9)

[Complete Intro to React V9: New Project, Modern Stack](https://frontendmasters.com/courses/complete-react-v9/?utm_source=email&utm_medium=frontendfocus&utm_content=reactv9 "frontendmasters.com") — 加入 Brian Holt 从头开始构建比萨送货应用程序。 在这本现代化的 React 开发综合指南中，Master Hooks、TanStack 路由器、测试和 React 19 功能。 无需之前的 React 经验。

前端大师赞助商

02：[每个前端开发人员都应该在 2024 年知道的五个 CSS 片段](https://web.dev/articles/5-css-snippets-every-front-end-developer-should-know-in-2024 "Web.dev") — Adam 做到了这一点 [in 2023](https://web.dev/articles/6-css-snippets-every-front-end-developer-should-know-in-2023)，并且 2024 版本也被证明非常受欢迎。 这里的所有代码段都是值得的、功能强大的 CSS 提示（包括嵌套、子网格、容器查询单元等），它们将与我们进入 2025 年一样有价值。

亚当·阿盖尔

03：[CSS 中的内联条件？](https://lea.verou.me/blog/2024/css-conditionals/ "lea.verou.me") — 在夏季，CSS 工作组 [resolved to add](https://github.com/w3c/csswg-drafts/issues/10064) 一个内联 `if()` 到 CSS。 CSS 是令人兴奋的一步，但也引发了很多问题。 来自 LEA 的这个解释器对许多人来说都是有价值的。

利维鲁

04：[你需要了解的关于现代 CSS](https://frontendmasters.com/blog/what-you-need-to-know-about-modern-css-spring-2024-edition/ "frontendmasters.com") — 一个书可标记的指南，来自过去的春天，列出了所有 CSS 的新添加内容（_think 嵌套、查看过渡、`:has()` 等）。 它仍然非常方便，因为有一个解释器、演示、代码示例和一些关于为什么要关心每个条目的细节。 如果您想了解我们今年获得的新 CSS 功能，那么这不是一个糟糕的地方。

克里斯·科耶尔

⚡️简介

**这里只是今年前端世界上发生的一些快速片段：**

*   💨 获得 [a formal solution in place for CSS masonry](https://css-tricks.com/css-masonry-css-grid/) 的努力背后有很多持续的蒸汽。
*   ⚙️这是[a big year for Web Components](https://utilitybend.com/blog/getting-into-web-components-an-intro/)以及我们对它们的共同理解和利用。
*   🗓️ 网络变成了 35 — [here's what Sir Tim Berners-Lee had to say](https://webfoundation.org/2024/03/marking-the-webs-35th-birthday-an-open-letter/)。
*   🍏 Apple 向 iOS、Safari 和 App Store 宣布了 [significant changes](https://www.apple.com/newsroom/2024/01/apple-announces-changes-to-ios-safari-and-the-app-store-in-the-european-union/) 为欧盟的用户。
*   📱 ...作为这些变化的一部分，出现了 [fight on the future of PWAs on iOS](https://open-web-advocacy.org/blog/apple-backs-off-killing-web-apps/)。
*   🍪 谷歌 [changed the deprecation timeline](https://privacysandbox.com/news/privacy-sandbox-update/) 用于第三方 cookie... [W3C had thoughts](https://www.w3.org/blog/2024/third-party-cookies-have-got-to-go/)...
*   😬 WordPress 使用 WP 引擎和 [it got messy](https://wpvswpe.report) 进入废品。
*   🗳️我们从 [2024 State of CSS](https://2024.stateofcss.com/en-US/) 和 [State of HTML](https://2024.stateofhtml.com/en-US/) 调查中获得了结果，加上 _Just systemround_ 的 2024 版 [State of JS](https://2024.stateofjs.com/en-US) 下降。
*   🟪 CSS [got it's own logo](https://github.com/CSS-Next/logo.css#readme)！ 再见 CSS3 盾牌。 🫡
*   📑 优秀、全面的[Web Almanac returned to summise the year](https://almanac.httparchive.org/en/2024/)，2024年的网络状态共享。

05：[如何集中一个 div](https://www.joshwcomeau.com/css/center-a-div/ "www.joshwcomeau.com") — 你们中的许多人都使用这个的事实告诉我们，要做到正确仍然是一场棘手的考验。 是的，由于新工具（Flex、Grid 等），现在更容易了，但要使用哪个？ Josh 分享了不同方法之间的权衡，以及使用的最佳策略。

乔什·沃科莫

06：[剪辑路径的魔力](https://emilkowal.ski/ui/the-magic-of-clip-path "emilkowal.ski") — 这篇文章旨在“激励你，向你展示在盒子外面思考可以带来一些伟大的动画”——所有这些都是通过非常强大的 `clip-path` CSS 属性的魔力。

埃米尔·科瓦尔斯基

[AuthKit：世界上最好的登录框——由 Workos & Radix 提供支持](https://www.authkit.com/?utm_source=cpff&utm_medium=newsletter&utm_campaign=q42024 "www.authkit.com") — Authkit 是身份验证、授权和用户管理的完整解决方案。 它的免费容量高达 100 万 MAU，并标配 RBAC、BOT 保护、MFA 等。

AuthKit 赞助商

07：[css selectors](https://css-tricks.com/css-selectors/ "css-tricks.com") — 一个全面、完整的指南，涵盖了我们在 CSS 中选择元素的所有各种方法（例如伪选择器、嵌套选择器、属性选择器、 等）以及如何使用它们来应用样式。

杰夫·格雷厄姆

08：[CSS 容器查询交互式指南](https://ishadeed.com/article/css-container-query-guide "ishadeed.com") — 这是关于 [CSS container queries](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_containment/Container_queries) 的详细说明，探索它们解决的问题、它们的工作方式以及我们如何在工作流程中使用它们。 大量的代码和视觉效果也可以帮助事情。 非常值得书签。

艾哈迈德阴影

💡 Josh Comeau 也看了今年的容器查询，指出到目前为止的采用并不是那么高。 [Here he goes into why that may be](https://www.joshwcomeau.com/css/container-queries-introduction/)，将我们重新引入该特征，并建议我们可能希望如何使用它。

09：[如何在加载网页之前更快地让您的网页更快](https://blog.sentry.io/how-to-make-your-web-page-faster-before-it-even-loads/ "blog.sentry.io") — Salma 查看了浏览器甚至接收到网页的第一个字节的事件。 询问我们是否可以衡量这些事件，并随后对其进行优化以使我们的网页和应用程序加载速度更快。 整洁。

萨尔玛·阿拉姆-奈勒

10：[前端开发人员/工程师手册 2024](https://frontendmasters.com/guides/front-end-handbook/2024/ "frontendmasters.com") — 这个关于当前 Web 开发环境的令人难以置信的深入和详细的指南受到了好评。 它仍然是一个极好的资源，可以快速掌握代码编辑器、CSS、UX、UI、命令行、性能、可访问性、测试、AI 等等。

科迪·林德利

🧰 今年我们分享的热门工具和资源

[![](https://res.cloudinary.com/cpress/image/upload/w_1280,e_sharpen:60,q_auto/v1734427865/pz0ucwv4k2etm8jfyt8x.png)](http://anchor-tool.com/)

[锚位置工具](http://anchor-tool.com/ "anchor-tool.com") — CSS 锚定定位正在进行中，规范中的一种相当整洁的布局机制是 `position-area`。 来自 Una 的这个（仅 Chromium 129+）演示演示了它的工作原理。 对这一款有很多兴趣，虽然它仍然在 [draft](https://www.w3.org/TR/css-anchor-position-1/) 中，但一旦广泛使用，它应该会变得相当强大。

乌娜·克拉维茨

[Speedometer 3.0: WebApp Responsiveness 的浏览器基准](https://browserbench.org/announcements/speedometer3/ Browserbench.org") — 2024 为我们提供了一个新的主要版本的 Speedometer — 第一个采用跨行业协作方法，每个主要浏览器引擎都支持 壁虎，网络工具包）。 [Version 3](https://www.browserbench.org/Speedometer3.0/about.html) 在许多新测试、性能胜利和改进中添加。 你可以[run the test for yourself here.](https://browserbench.org/Speedometer3.0/)

苹果、谷歌、微软和莫兹拉

[CSS 网格生成器](https://cssgridgenerator.io/ "cssgridgenerator.io") — 这个基于浏览器的方便的工具让您点击了很多 — 您可以使用它轻松创建自定义 CSS 网格布局 — 您可以指定列数、行和 排水沟尺寸。

克里斯蒂詹·雷特
