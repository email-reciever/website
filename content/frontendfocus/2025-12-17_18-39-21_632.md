✍️ **嗨！ 这是 2025 年的最后一期前端焦点**。 对于 Web 平台来说，这是又一个忙碌的一年，我们的工具带中添加了各种新功能和 API。 我们已经查看了我们一年中分享的内容，我们正在重新审视一些 2025 年的亮点——_全部基于读者的点击，无论是在电子邮件中，还是通过我们的 [RSS feed](http://frontendfoc.us/rss)_。 这是回顾一年、回顾并突出您第一次错过的一些事情的有趣方式。

如果您喜欢该时事通讯并发现它很有价值，请考虑将其转发给朋友或同事，或者可能 [follow us on Bluesky](https://bsky.app/profile/frontendfocus.bsky.social)。 非常感谢阅读！ 我们将在 1 月份回到您的收件箱，以应对 2026 年的所有前端。_让我们开始吧！_

🗓️ 2025年十强

01：[每个前端开发人员都应该知道的六个 CSS 片段](https://nerdy.dev/6-css-snippets-every-front-end-developer-should-know-in-2025 "Nerdy.dev") — Adam 分享了一个 [similarly popular list last year](https://web.dev/articles/5-css-snippets-every-front-end-developer-should-know-in-2024)，所以看到这个想法再次流行起来也就不足为奇了。 一个值得了解的声音片段，“_bigger、更强大，并且更多地利用渐进增强_”。

亚当·阿盖尔

02：`H1` 元素的默认样式正在更改](https://developer.mozilla.org/en-US/blog/h1-element-styles/ "developer.mozilla.org") — 我们在 4 月分享了这一点 — 它概述了浏览器如何更新嵌套部分标题的默认用户代理 (UA) 样式。 你们中的许多人都想成为一个高层次的变化。

西蒙·彼得斯 (MDN)

[![](https://res.cloudinary.com/cpress/image/upload/c_limit,w_480,h_480,q_auto/copm/a6ab3376.png)](https://workos.com/?utm_source=cpff&utm_medium=newsletter&utm_campaign=q42025)

[解决您的应用的企业认证、身份和安全性](https://workos.com/?utm_source=cpff&utm_medium=newsletter&utm_campaign=q42025 "workos.com") — 企业客户需要符合严格合规性标准的 SSO、SCIM、RBAC 和审计日志。 WorkOS 为开发人员提供了一个平台，通过一套易于集成的 API 和一个用于简化客户入门的门户，快速运送这些功能。

工作赞助商

03：[在你拥有之前你不是前端开发人员......](https://www.nicchan.me/blog/youre-not-a-front-end-developer-until-youve/ "www.nicchan.me")——这个有趣的、诙谐的清单，讲述了我们在前端开发人员所做的各种奇怪之处，现在仍然很有趣。

尼克陈

04：[你需要了解的关于现代 CSS 的知识](https://frontendmasters.com/blog/what-you-need-to-know-about-modern-css-2025-edition/ "frontendmasters.com") — Chris 列出了一些现在有价值的事情，因为它们“_pretty fresh 或在浏览器支持中得到了提升_”。 涵盖 `popover` 属性、强大的 `if()` 功能、新的 `field-sizing` 属性等内容。 对我们应该关注哪些新事物的出色概述，以及有关地平线上内容的一些指示。

克里斯·科耶尔

📺⏪ 前端倒带 — 2025 年 YouTube 热门视频

[25 New & Rad Features of CSS](https://www.youtube.com/watch?v=QW6GECIzvsw) — 一个充满活力的半小时谈话，亚当在其中参观了最近的 CSS 功能，包括字段大小、自定义滚动条样式、数学函数、滚动驱动动画等。
亚当·阿盖尔

[css `if()` functions & `reading-flow`](https://www.youtube.com/watch?v=Apn8ucs7AL0) — 我们现在可以使用 `if` 函数执行的可靠且简单的演示。
乌娜·克拉维茨

[What is CSS Owl Selector (\* + \*)?](https://www.youtube.com/watch?v=0O0ssm70g1g) — 快速浏览 CSS ‘Owl’ selector，包括它的工作原理、你应该使用它的原因以及可行的替代方案。
佐兰·詹姆博尔

[Next-Level Features Every Web Dev Should Know](https://www.youtube.com/watch?v=KGWU7DK9Paw) — 各种现代功能的高级概述，包括容器查询、`scroll-state()`、`dialog` 等。
贾德·朱布兰

[The Death of the Browser](https://www.youtube.com/watch?v=pznpsgZqlGQ&list=PL6kQg8bP1Ji48T7tM-ScCNm_IfrEtce0d&index=6) — 网络浏览器会成为怀旧的记忆吗？ 这次谈话分享了从浏览器发明到数据军备竞赛的旅程，再到人工智能代理的黎明。
雷切尔-李纳博尔斯

05：[<`select`\> 元素现在可以使用 css](https://developer.chrome.com/blog/a-customizable-select?hl=en "developer.chrome.com") 进行自定义 — 早在 3 月，我们就获得了一种可访问的、标准化的方法来创建可样式的 <`select`\> 元素 — 由于 `[appearance: base-select](https://caniuse.com/mdn-css_properties_appearance_base-select)`。 亚当解释了这种变化是如何“_____ ”的。 结果？ 我们现在有一个丰富的组件，不会在旧浏览器中破坏。

亚当·阿盖尔

06：[css `text-box-trim`](https://developer.chrome.com/blog/css-text-box-trim "developer.chrome.com") — 另一个来自 Adam 的，这次解释了这个方便的属性的工作方式，让我们可以很好地控制上下文中的领先空间。

亚当·阿盖尔

[LLMS 正在查询数据库 - Postgres 不是为此构建的](https://www.tigerdata.com/blog/the-database-new-user-llms-need-a-different-database "www.tigerdata.com") — Tiger Data 正在尝试自我描述 Postgres，允许 LLMS 生成更好的 SQL。 高达 27% 的收益。

老虎数据赞助商

07：[面包屑在网页设计中“死”了](https://webdesignerdepot.com/breadcrumbs-are-dead-in-web-design/ "webdesignerdepot.com") — 曾经是网页设计中的主要内容，作者认为它们现在已经变得有些过时了。

诺亚戴维斯

08：[酷酷的本机 HTML 元素，您应该已经使用](https://harrisonbroadbent.com/blog/cool-native-html-elements/ "HarrisonBroadbent.com") — 一个由众多的原生 HTML 元素组成的集合，这些元素相对于其他人的用法并不多（例如 `kbd`、`datalist`， `progress` 等）。

哈里森·布罗德本特

09：[仅使用 css 滚动驱动动画指南](https://webkit.org/blog/17101/a-guide-to-scroll-driven-animations-with-just-css/ "webkit.org") — 早在夏天，Saron 就分享了如何通过 CSS 开始使用滚动驱动动画的外观。 此处共享的代码示例突出了如何使用此技术将进度条或动画元素设置为视口。

萨隆·伊特巴雷克

10：[“我对这 128 千字节比我从那以后构建的任何东西更自豪”](https://medium.com/@mikehall314/im-more-proud-of-these-128-kilobytes-than-anything-i-ve-built-since-53706cfbdc18 "medium.com") — 回顾一个项目以及严格的约束（例如带宽、处理能力等）如何导致 创新。 一个流行且技术丰富的人，提醒我们所有人考虑最广泛的用户并相应地设计事物。

迈克霍尔

[我们对 5 个 AI 代码审查工具进行了基准测试。 这是我们发现的](https://links.macroscope.com/frontend-focus-benchmark "links.macroscope.com") — Macroscope 的错误检测率是市场上最高的。 前 2 个月使用 `MACROFOCUS` 可享受 50% 的折扣。

宏观赞助商

11：[A Friendly Introduction to SVG](https://www.joshwcomeau.com/svg/friendly-introduction-to-svg/)
乔什·W·科莫

12：[The Web Animation Performance Tier List](https://motion.dev/blog/web-animation-performance-tier-list)
马特佩里

13：[Liquid Glass in the Browser — Refraction with CSS and SVG](https://kube.io/blog/liquid-glass-css-svg/)
克里斯·费茹

14：[Brand New Layouts with CSS Subgrid](https://www.joshwcomeau.com/css/subgrid/)
乔什·W·科莫

15：[Item Flow: A Unified Concept for Layout](https://webkit.org/blog/16587/item-flow-part-1-a-new-unified-concept-for-layout/)
