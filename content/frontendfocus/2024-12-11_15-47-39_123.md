🗓️ [The 2024 Web Almanac](https://almanac.httparchive.org/en/2024/ "Almanac.HttpArchive.org") — 这份关于 Web 状态的综合报告将归结为 2024 年。此版本有 21 章（其中大部分是 现在可用_) 涵盖 UX、可访问性、发布、内容分发等。 所有共享的指标都基于来自超过 1600 万个网站的现实世界数据。

HTTP 存档

[在 3 个声明中创建纯 CSS 半色调效果](https://frontendmasters.com/blog/pure-css-halftone-effect-in-3-declarations/ "frontendMasters.com") — 仅使用单个 div 创建半色调效果，没有伪斯和三个属性。 谈论有效性（并且在视觉上也很引人注目）。

[WORKOS：向有几行代码的企业销售](https://workos.com/?utm_source=cpff&utm_medium=newsletter&utm_campaign=q42024 "workos.com") — B2B SaaS 的现代身份平台，提供灵活、易于使用的 API，在几分钟而不是几个月内集成 SSO、SCIM 和 FGA。

工作赞助商

[CSS Wrapped 2024](https://chrome.dev/css-wrapped-2024/ "chrome.dev") — 对 2024 年 Web 平台的新增功能进行了有趣的（像素艺术填充）探索，包括跨文档视图转换、滚动驱动动画、锚点 定位等。

Chrome Devrel 团队

[由现代 CSS 解决：特征图像](https://ishadeed.com/article/modern-css-feature-image/ "ishadeed.com") — Ahmad 分享了容器查询和 CSS `:has()` 如何帮助构建根据视口/容器大小而变化的整洁的特色图像组件。 与以往一样，出色的插图和代码示例可以帮助我们理解。
