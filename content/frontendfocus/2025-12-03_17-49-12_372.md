🎄 Tis the Season（用于降临日历）

现在是 12 月，传统上，各种与 Web 相关的降临日历都在这里，在圣诞节之前分享了各种开发人员内容。 我们将在整个月内分享这些日历中的文章，但如果您想要每日开门，这里有一些首选：

*   🗓️ [CSS Advent Calendar](https://cssadventcalendar.dev) — 这张来自 Steve Harrison 的，每天都分享不同的功能或属性，并快速介绍它的作用。
    
*   🗓️ [HTMHell Advent Calendar](https://www.htmhell.dev/adventcalendar/) — Manuel Matuzovic 的第四年年度年鉴回归，以作者的安全性、性能、可访问性等为特色。
    
*   🗓️ [AdventJS](https://adventjs.dev) — 将测试您的 JavaScript 知识的日常挑战。
    
*   🗓️ [Web Performance Calendar](https://calendar.perfplanet.com/2025/) — Stoyan Stefanov 汇集了性能专家，在整个月内分享他们的知识。
    

开发人员生态系统中还有更多，和 [Adrian Roselli has done a stellar job of bringing them all together](https://adrianroselli.com/2025/12/web-design-dev-advent-calendars-for-2025.html)。

[![](https://res.cloudinary.com/cpress/image/upload/c_limit,w_480,h_480,q_auto/copm/a33b8492.png)](https://frontendmasters.com/courses/react-performance-v2/?utm_source=email&utm_medium=frontendfocus&utm_content=reactperfv2)

[Ship High-Performance React Apps](https://frontendmasters.com/courses/react-performance-v2/?utm_source=email&utm_medium=frontendfocus&utm_content=reactperfv2 "frontendmasters.com") — 加入 Steve Kinney 的 React Performance 的详细视频课程。 您将涵盖水合作用、悬念、资源加载、服务器操作等，从而获得构建外观和感觉快速的应用程序的专业知识。

前端大师赞助商

[2026年的性能不平等差距](https://infrequently.org/2025/11/performance-inequality-gap-2026/ "infrequently.org") — 尊敬的浏览器和 Web 标准专家 Alex Russell 着眼于客户端 Web 性能的状态，您应该考虑什么样的带宽，人们的设备是什么设备 使用并警告不断增长的 JavaScript 捆绑包大小。 这里有很多数据。
