🖼️ [HTML-in-Canvas: Interactive DOM inside 2D, WebGL 和 WebGPU Canvas](https://developer.chrome.com/blog/html-in-canvas "developer.chrome.com") — 下周进入稳定的 Chrome，这个长期孵化的 API 绘制 真实的实时 HTML 到 2D、WebGL 和 WebGPU 画布，文本选择、表单控件、查找页面和屏幕阅读器都仍在工作。 3.js、babylon.js 和 pixijs 已经支持它。 目前仅限 Chrome，但对于帆布重型 UI 来说是一个巨大的飞跃。 有 [a related video here too](https://www.youtube.com/watch?v=mB0eWkWubuk)。

⚡️简介

*   🎉 [CSS-Tricks](https://css-tricks.com/)，在 DigitalOcean 的所有权下，是 [independent once again](https://css-tricks.com/css-tricks-has-a-new-owner/) 在编辑 [Geoff Graham](https://bsky.app/profile/geoffgraham.me) 的管理下。
    
*   🦊 [Firefox 159](https://developer.mozilla.org/en-US/docs/Mozilla/Firefox/Releases/159) 默认启用滚动驱动动画，因此它们现在可以在所有主要引擎中运行。 它还添加了范围的自定义元素注册表。
    
*   🪪 自 Chrome 155 以来，网站可以 [use the Digital Credentials API to offer credentials](https://developer.chrome.com/blog/digital-credentials-api-issuance?hl=en)（例如数字 ID）到用户手机上的兼容钱包应用程序。
    
*   ⚙️ W3C 已经启动了 [a polyfill pilot for WebMCP](https://www.w3.org/blog/2026/w3c-launches-second-pilot-of-program-to-support-open-source-projects/)，这是一个 JavaScript API，将 Web 应用程序的功能公开为代理调用的工具。
    
*   🌅今年12月的[Arc browser is being sunset](https://arc.net)，以及[Dia is suggested](https://www.diabrowser.com)作为可行的替代方案。 [Zen](https://zen-browser.app) 是另一种非铬变体。
    
*   📺 Firefox 有 [▶️ a new ad with various 'meme icons'](https://www.youtube.com/watch?v=E2AoYIKwJqM) 过去的岁月（Numa Numa Guy 开始了事情）。
