CSS现在可以对过去坐在[reset](https://css-tricks.com/reboot-resets-reasoning/)之外的类型进行选择。 [`text-wrap: pretty`](https://css-tricks.com/pretty-is-in-the-eye-of-the-beholder/) 可以防止搁浅的单词，容器查询单元可以将标题缩放到它所占据的列中，[`text-box`](https://css-tricks.com/almanac/properties/t/text-box/) 可以修剪内置在行框中的半导引线。 其中一些功能是实验性的，浏览器支持不均匀，因此它们需要护栏而不是盲目包含。

我整理了 **tidy-typography.css**，它将有用的部分收集到一个默认样式表中：渲染和回退规则、流体大小、垂直节奏、包装、连字符和 OpenType 细节。

完整地使用它，或者采取解决你面前特定刺激的声明。 我将向您介绍本文中的所有详细信息，并在最后为您提供完整的代码。

[](#rendering-and-fallback-sanity)渲染和回退理智
-----------------------------------------------------------

html {
-webkit-font-smoothing：抗锯齿；
文本渲染：优化可读性；
字体合成：无；
    
-moz-text-size-adjust：无；
-webkit-text-size-adjust：无；
文本大小调整：无；
}
    
身体{
字体大小调整：from-font;
}

`font-synthesis: none` 阻止浏览器在家庭缺乏该面孔时发明粗体或斜体。 平滑和文本渲染声明是呈现提示，主要针对 WebKit； 结果仍然因平台而异。

`text-size-adjust` 禁用移动字体膨胀，可以使故意尺寸的布局在旋转时跳跃。 `font-size-adjust: from-font` 使用字体度量来减少明显的大小变化，同时回退到 webfont。

（与本文中的其他片段一样，此 ⁠`:root` 块是部分摘录，最终样式表将其与稍后定义的其他自定义属性相结合。）

[](#fluid-typography)流体排版
-----------------------------------

[Viewport-based fluid type](https://css-tricks.com/snippets/css/fluid-typography/) 不知道它的元素有多宽。 因此，狭窄侧边栏中的标题可以像填满视口一样缩放。

.article-container {
容器类型：内联大小；
}
    
:root {
--step-0：钳位（1rem，0.9rem + 1cqi，1.125rem）；
--step-3：钳位（2rem，1.6rem + 3cqi，2.75rem）；
}

`container-type: inline-size` 使包装器成为 [container query](https://css-tricks.com/css-container-queries/)，因此其子级可以使用 `cqi`：基于容器而不是视口的单元。 替换 `clamp()` 中的 `vw` 在没有特定于组件的媒体查询的文章列或 `300px` 侧栏中允许相同的标题缩放。

[](#vertical-rhythm-trim-the-half-leading)垂直节奏：修剪半导向
--------------------------------------- ---------------------------------------

:heading, p, blockquote, figcaption, li {
文本框修剪：修剪两者；
文本框边缘：字母表字母；
/* 速记：文本框：修剪两个字母； */
}

[`line-height`](about:blank) 包括上限高度和基线之下的空间：半前导。 当文本必须与另一个元素紧密对齐时，这一点变得很明显。 [`text-box-trim`](https://css-tricks.com/almanac/properties/t/text-box-trim/) 将其移除，而 [`text-box-edge`](https://css-tricks.com/almanac/properties/t/text-box-edge/) 从大写字母上限测量到字母基线。 这是特定于字体的负边距缩小的指标感知替代方案。

@支持选择器(:heading) {
: 标题 {
文本框：修剪均限字母；
}
}

[Selectors Level 5 proposes :heading](https://drafts.csswg.org/selectors-5/#headings)，将 `h1` 与 `h6` 和 `[role="heading"]` 匹配。 它没有落在浏览器中，因此请将其放在 `@supports selector()` 检查后面。

[](#balanced-headlines-orphan-free-paragraphs)平衡的标题，无孤儿段落
------------------------------------------ ------------------------------------------

：标题，块引用，figcaption {
文本包装：平衡；
}
    
P，李，dd {
文本包装：漂亮；
最大宽度：65ch；
}
    
[内容可编辑="真"] {
文本包装：稳定；
}

默认的航向包装可以留下一短的最后一行。 `text-wrap: balance` 在其行上分布文本，最适合最多六行的块。 对于段落，`text-wrap: pretty` [avoids a stranded final word without balancing the whole block](https://css-tricks.com/pretty-is-in-the-eye-of-the-beholder/)。 两者都取代了 JavaScript 孤儿修复器。 可编辑的文本需要 `text-wrap: stable`，这可以防止每个新单词重新调整段落。

[](#hyphenation-properly-tuned)连字符，适当调整
------------------------------------------------------

    <html lang="en-GB">

p {
连字符：自动；
}

`hyphens: auto` 依赖于浏览器的语言字典，因此文档需要一个正确的 `lang` 属性（例如 `<html lang="en-GB">`）。 没有一台，浏览器就没有字典可以使用，也无法使用连字符。 即使使用正确的 `lang`，默认值也可以连续留下微小的单词片段或几行连字符。

p {
连字符：自动；
连字符限制字符：6 3 3； /* 字长，休息前的最小值，休息后的最小值 */
连字符字符：“-”； /* 使用适当的连字符字形代替破折号 */
连字符限制线：2； /* 不超过 2 个连续的连字符行 */
连字符限制区：8%； /* 降低整体连字符频率 */
连字符限制最后：总是； /* 永远不要连字符段落的最后一个词 */
    
/* Safari Legacy 等价物 */
-webkit-连字符：自动；
-webkit-hyphenate-limit-before：4；
-webkit-hyphenate-limit-之后：3；
-webkit-连字符-限制-线：2；
}
    
预，代码，var，samp，kbd，：heading {
连字符：手动；
-webkit-连字符：手动；
}

[`hyphenate-limit-chars`](https://css-tricks.com/almanac/properties/h/hyphenate-limit-chars/) 控制最小的易碎字和碎片； [`hyphenate-limit-lines`](https://drafts.csswg.org/css-text-4/#hyphenate-line-limits) 防止梯子效应。 [`hyphenate-limit-zone`](https://drafts.csswg.org/css-text-4/#hyphenate-size-limits) 使休息频率降低，而 `hyphenate-limit-last` 保护最终单词。 Safari 需要前缀等效项，因此将两个集合在一起。

将代码、变量和标题设置为 `hyphens: manual`：损坏的代码字可以更改含义，而连字符的标题通常读作错误。

[](#hanging-punctuation-and-ink-aware-underlines)悬挂标点符号和墨水感知下划线
------------------------------------------- --------------------------------------------

块引用，p {
悬挂标点符号：第一个允许结束；
}
    
一个{
文本装饰厚度：from-font;
文本下划线偏移：0.15em；
文本装饰-跳过墨水：自动；
}

标点符号与字母的视觉重量不同，因此位于行首的引号可以在其下方的文本上看起来略微缩进。 [`hanging-punctuation`](https://css-tricks.com/almanac/properties/h/hanging-punctuation/) 让指定的标点符号位于文本块边缘之外。

`first` 值处理打开的标点符号，`last` 处理块末端的关闭标点，而 `allow-end` 让标点符号挂在右边缘而不是强制包裹中。 结果是一个文本块，其边缘读作真正的齐平。

下划线有相关问题。 无论字体的实际重量如何，浏览器都应用平坦、一尺寸适合所有厚度和位置。

`text-decoration-thickness: from-font` 读取字体设计器预期的厚度。 [`text-underline-offset`](https://css-tricks.com/almanac/properties/t/text-underline-offset/) 为下降者提供了呼吸的空间，`text-decoration-skip-ink: auto` 中断下划线，无论下降者穿过它的地方，而不是直接穿过字母。

[](#variable-font-fine-tuning)可变字体微调
---------------------------------------------------

身体{
字体光学大小：自动；
字体-变体-连字：普通连字上下文；
字体字距：正常；
}
    
/* 暗模式等级补偿 */
:root {
--vf-grad：0；
}
    
@media（首选颜色方案：深色）{
:root { --vf-grad: -50; }
}
    
    * {
字体变量设置：“grad” var(--vf-grad, 0);
}

[Variable fonts](https://css-tricks.com/one-file-many-options-using-variable-fonts-web/) 通常包括光学尺寸轴，或 `opsz`。 它让字体在大显示屏尺寸和更厚、更清晰的笔触时使用更薄的笔触。

`font-optical-sizing: auto` 允许字体根据其实际渲染的大小进行调整。 `@supports` 块涵盖了一些浏览器仍然需要的较旧的 `font-variation-settings` 语法，而 [`font-variant-ligatures`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/font-variant-ligatures) 和 [`font-kerning`](https://css-tricks.com/almanac/properties/f/font-kerning/) 启用字体自己的连字和字距对。

[Light text on a dark background genuinely reads heavier than the same weight on a light background.](https://css-tricks.com/dark-mode-and-variable-fonts/) 当字体发出 `GRAD` 或坡度轴时，暗模式块会在不改变字形形状或宽度的情况下将感知到的重量降低到实际重量变化的方式。 没有 `GRAD` 轴的字体可以安全地忽略设置。

@字体脸{
字体系列：“单声道”；
src: url("/fonts/mono-var.woff2") 格式("woff2");
尺寸调整：105%； /* 调整字体 */
}

将 Monospace 字体混合到正在运行的散文中通常会暴露出与声明的 [`font-size`](https://css-tricks.com/almanac/properties/f/font/font-size/) 不匹配的 X 高度。 `size-adjust` 关键字，在 [`@font-face`](https://css-tricks.com/almanac/rules/f/font-face/) 级别设置一次，专门缩放该字体呈现的输出，使实际的 `font-size` 值保持不变。

[](#numeric-emoji-and-script-aware-text)数字、表情符号和脚本感知文本
------------------------------------ --------------------------------------

表格中的数字需要相同的宽度，因此它们堆叠成屏幕上的干净列。 相反，流动文本中的数字不需要相同的处理方式，应该自然地与周围的单词并排。

表，.tabular {
font-variant-numeric: tabular-nums lining-nums;
}
    
.散文{
font-variant-numeric: oldstyle-nums 比例数值；
}
    
.表情符号颜色 {
字体变体表情符号：表情符号；
}
    
.emoji-mono {
font-variant-emoji：文本；
}

`tabular-nums` 和 `lining-nums` 关键字为表格数字提供了固定的宽度和全顶盖高度。 `oldstyle-nums` 和 `proportional-nums` 让数字与小写字母并列，而不会粘连并破坏句子的纹理。

[`font-variant-emoji`](https://css-tricks.com/almanac/properties/f/font-variant-emoji/) 明确地选择了全彩色和单色表情符号。 没有它，浏览器或平台可以选择回退，结果可能会比您预期的更多。 将 `.emoji-color` 或 `.emoji-mono` 应用于要强制执行该选择的容器，而不是将其全局设置在主体上。

[](#locale-aware-quotes-and-native-subcripts-and-superscripts)本地感知引号和本机分词和上标
-------------------------------------------------------- --------------------------------------------------------

引用风格和字符顺序因语言和地区而异。 英语在双引号中嵌套单引号，英式英语颠倒了这一惯例，而法语则使用带有较薄空间的 guillemets。

:where(:lang(en)) > * { 引用："\"" "\"" "'" "'"; }
:where(:lang(en-GB)) > * { 引用：“'”“'”“\”““\””； }
:where(:lang(fr)) > * { 引号："«\\00202f" "\\00202f»" "\"" "\""; }
    
Q::before { 内容：打开引用； }
Q::after { 内容：关闭报价； }

[`quotes`](https://css-tricks.com/almanac/properties/q/quotes/) 属性通过 [`:lang()`](https://css-tricks.com/almanac/pseudo-selectors/l/lang/) 声明每种语言的顺序。 然后，本机 `q` 元素通过 `open-quote` 和 `close-quote` 插入正确的对。 相同的标记可以在每个区域设置中正确呈现，而无需将字符硬编码到内容中。

将规则包装在 [`:where()`](https://css-tricks.com/almanac/pseudo-selectors/w/where/) 中，使它们的特异性保持为零，因此项目可以使用一个普通类覆盖引用样式。

默认 `sub` 和 `sup` 样式是合成的。 浏览器只是缩小文本并移动基线，而不是使用实际为该位置设计的字形。

@supports (font-variant-position: sub) {
:is(sub, .sub) {
垂直对齐：基线；
字体大小：100%；
行高：继承；
字体-变体-位置：子；
}
}
    
@supports (font-variant-position: super) {
:is(sup, .sup) {
垂直对齐：基线；
字体大小：100%；
行高：继承；
字体变体位置：超级；
}
}

`font-variant-position` 切换到字体自己专门构建的子字形和上标字形，重置 `vertical-align`、`font-size` 和 `line-height`，因此它们不会与真正的字形的预期大小和位置作斗争。 大多数字体仅包含正确的数字而不是字母，因此在广泛应用之前检查特定字体。

[](#a-note-on-specificity-is-and-where)**关于特异性的说明：** **`:is()`** **和***`:where()`**
---------------------------------------------- ----------------------------------------------

[`:where()` 总是解析为零特异性](https://css-tricks.com/quick-reminder-that-is-and-where-are-basically-the-same-with-one-key-difference/)，这对重置很有用。 这里的每条规则都是一个固有的默认值，并在 `:where()` 中将其包装起来，让项目使用普通类覆盖一个属性。

:where(h1, h2, h3, h4, h5, h6) {
边距块：0.5em；
}

`:is()` 解决了一个不同的问题：重复。 标题选择器列表在排版样式表中多次出现，并将其分组避免了忘记关卡的风险。

:is(h1, h2, h3, h4, h5, h6), p, blockquote, figcaption, li {
文本框：修剪均限字母；
}

与 `:where()` 不同，`:is()` 具有其最具体论点的特殊性。

[](#what-belongs-in-a-reset)什么属于重置
-----------------------------------------------

其中大部分 CSS 删除了用于泄漏到构建的其他部分的工作。 `text-wrap` 可以从 JavaScript 中接管孤儿处理，容器查询单元将组件的类型比例与自己的宽度绑定在一起，`text-box-trim` 避免了用于补偿前导的负边距。 引号、字体-变体-位置和 `font-optical-sizing` 将几个较小的细节传递回语言和字体，而不是一次性修复。

浏览器支持将继续改变，特别是对于 `text-wrap` 和 `text-box-trim`。 不支持的声明被忽略，但这只有在未增强的排版本身可以接受的情况下才会有所帮助。

其中一些规则对于基线重置仍然太新了。 一篇新闻文章、一个营销页面和一个可编辑的产品界面不会向他们的文本提出同样的要求； 属于您的集合取决于您仍然需要支持的字体、内容和浏览器。
