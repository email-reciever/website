标题听起来有点奇怪，对吧？ 为什么要重新实现现有功能，完全没用！ 我有两个原因。 第一个原因是能够即时调整 [`:nth-child()`](https://css-tricks.com/almanac/pseudo-selectors/n/nth-child/) 参数。

假设你有以下几点：

div:nth-child(5n + 8) {
背景：红色；
}

您决定更新 `5` 或 `8`。 唯一的方法是手动重写选择器，这并不理想。 我们不能有像下面这样的东西，您可以根据需要更改变量：

.容器{
--A：5；
--B：8；
}
    
.container > div:nth-child(var(--a)*n + var(--b)) {
背景：红色；
}

通过我的实现，您将能够做到！

第二个原因是玩得开心并玩一些新功能。 您可能永远不需要依赖动态 `:nth-child()` 选择器，但我相信您会在此过程中学到一两个有用的技巧。

我们将在所有示例中依赖相同的代码结构：一个容器中包含一堆 `<div>` 元素。

    <div class="container">
      <div></div>
      <div></div>
      <div></div>
<!-- ... -->
    </div>

并且容器控制 `:nth-child()` 的变量：

.容器{
--A：；
--B: ;
}
    
.container > div {
/* 基于 --a 和 --b 的值更改背景值 */
背景：??;
}

我并不是说这种结构是强制实施的。 我只是考虑了一个简单的方法来让事情变得容易理解。

[](#nth-childb)`:nth-child(B)`
------------------------------

让我们从最简单的情况开始，一个只选择一个元素的选择器：

div:nth-child(5) { }

我认为我不需要解释这个选择器的作用。 `5` 只是所选元素的索引。 因此，如果 `B` 等于元素的索引，则选择该元素。

我们可以将其转换为以下 CSS 代码：

.容器{
--B：5；
}
    
.容器 div {
背景： if(style(sibling-index() = --b): 红色);
}

> 这是一个有效的CSS代码吗？！

是的，它是有效的，它有效！

我正在使用 [新 `if()` 语法](https://css-tricks.com/if-css-gets-inline-conditionals/) 允许我 [define a condition within](https://css-tricks.com/digging-deeper-into-container-style-queries/) [`style()`](https://css-tricks.com/digging-deeper-into-container-style-queries/)。 如果该条件为 true，则背景颜色设置为红色。 否则，什么都不会发生。

我们也可以有一个`if/else`：

.容器{
--B：5；
}
    
.容器 div {
背景： if(style(sibling-index() = --b): 红色; else: lightblue);
}

`if()` 语法不是那么复杂。 在我们的案例中，我们只有一种条件，因此您可以看到如下：

.容器 div {
背景：
if(style( 条件): <color_if_condition_true>;
其他：<color_if_condition_false>）；
}

棘手的部分是如何定义 `style()` 中的条件。 我写了一篇解释这部分的小帖子，所以帮自己一个忙，在我们继续之前阅读它：[“风格查询和 `if()` 的隐藏技巧。 从那里，您会注意到我们的条件可以写成几种有效的方式：

.容器 div {
背景： if(style(sibling-index() = --b): 红色);
背景： if(style(sibling-index() = var(--b)): 红色);
背景： if(style(var(--b) = sibling-index()): 红色);
背景： if(style(--b = sibling-index()): 红色);
}

我们有第一个实现！ 您也可以轻松地将其应用于任何属性：

.容器{
--B：5；
}
    
.容器 div {
背景： if(style(sibling-index() = --b): 红色; else: lightblue);
颜色： if(style(sibling-index() = --b): 白色);
}

代码看起来有点多余，这可能是这种方法的缺点之一，但是实现选择器并能够即时调整 `--B` 的值仍然很酷。 不要忘记我们的目标是学习新技巧，并且您的口袋里已经有两个（[`sibling-index()`]（https://css-tricks.com/almanac/functions/s/sibling-index/#browser-support）和 `if()`）。

这是一个交互式演示，您可以在其中调整 `--B` 的值并查看更改：

[](#nth-childn-b)`:nth-child(n + B)`
----------------------------------

让我们转移到我们的下一个选择器。 它选择不止一种元素。

div:nth-child(n + 5) { }

想一想如何实现这样的选择器。 和上一期差不多。

你明白了吗？ 我希望如此！

.容器{
--B：5；
}
    
.容器 div {
背景： if(style(sibling-index() >= --b): 红色; else: lightblue);
}

如果元素的索引大于或等于 `--B` 的值，则选择该元素。 就这么简单！

[](#nth-child-n-b)`:nth-child(-n + B)`
------------------------------------

这一款呢？ 简单，对吧？ 我们只是使用 `<=` 而不是 `>=`！

.容器{
--B：5；
}
    
.容器 div {
背景： if(style(sibling-index() <= --b): 红色; else: lightblue);
}

我们还可以轻松实现 [a range selection](https://css-tip.com/range-selection/)，这是两个选择器的组合：

/* 选择范围 [x y] 中的任意元素 */
div:nth-child(n + x):nth-child(-n + y) {
背景：红色；
}

它转化为：

.容器{
--x: ;
--y：；
}
    
.容器 div {
背景： if(--x <= sibling-index() <= --y): 红色);
}

代码应该是不言自明的。 它甚至比 `:nth-child()` 符号更直观，如果您不习惯，它需要几分钟的解密时间。

[](#nth-childan)`:nth-child(An)`
--------------------------------

现在让我们处理 `A` 参数。 例如，以下选择器：

div:nth-child(3n) { }

…选择第 3、6、9 等元素。 换句话说，元素的索引必须是 `3` 的倍数。 要进行此类测试，我们可以使用 [`mod()`](https://css-tricks.com/almanac/functions/m/mod/) 功能。 如果 `mod(index, 3)` 返回 `0`，则表示 `index` 除以 `3` 的其余部分等于 `0`，因此，它是 `3` 的倍数。

.容器{
--A：3；
}
    
.容器 div {
背景： if(style(mod(sibling-index(), var(--a)) = 0): 红色);
}

它有效！ 另一个具有简单实现的选择器。

我们可以识别两种特殊情况。 当 `--A` 等于 `1` 时，我们有 `:nth-child(n)`，它选择所有元素，当它等于 `2` 时，我们有 `:nth-child(2n)` 也是 `:nth-child(even)`。

虽然这工作正常，但有一个小问题。 当 `A` 是负值时，选择器不应该选择任何逻辑，因为所有索引都是正数，但是如果您尝试在我的实现中使用负值，某些元素仍然会被选择错误。

`mod()` 函数适用于负数，并且在这种情况下仍然可以返回 `0`，因此更准确地说，我们应该测试 `A` 的符号。

.容器{
--A：3；
}
    
.容器 div {
背景：
if(style(mod(sibling-index(), var(--a)) = 0) 和 (var(--a) > 0): 红色);
}

看到了吗？ 我只是使用 `and` 关键字在 `style()` 中添加了另一个条件。 乍一看，`if()` 的语法可能听起来令人困惑，但最终它与任何其他语言相同：在 `style()` 中定义的一堆条件。 您可以将任意数量与 `and` 和 `or` 结合使用。

现在，我们的选择更加精确。

[](#nth-childan-b)`:nth-child(An + B)`
------------------------------------

现在让我们结合我们到目前为止学到的所有技巧来实现 `:nth-child()` 的通用形式。 在这种情况下，索引等于 `An + B`，我们可以像这样表达 `n`：

n = (指数 - b)/a

`n` 应该是一个正整数（包括零）。 对于积极的部分，我们可以使用：

（索引 - b）/a >= 0

对于整数部分，我们需要确保 `index - B` 是 `A` 的倍数，为此，我们使用 `mod()`：

MOD（索引 - B，A）= 0

我们将其转换为CSS以获得以下内容：

.容器{
--A：3；
--B：5；
}
    
.容器 div {
背景：
if(style(mod(sibling-index() - var(--b), var(--a)) = 0)
和 (calc((sibling-index() - var(--b))/var(--a)) >= 0)
）：红色）；
}

除了 `--A` 等于 `0` 的情况外，我们几乎是好的。 在这种情况下，选择完全是错误的。 `mod()` 导致 `NaN`，因为它的第二个参数等于 `0`，这将与条件混淆。 实际上，该条件不适合 `--A` 等于 `0` 的工作。

我们要么认为此实现仅对 `--A` 不同于 `0` 的值有效（这可能是我们想要的），要么我们尝试找到包含该情况的解决方案。

我们在这里学习和发现新事物，所以让我们尝试其他东西。 可能有很多方法可以解决 `0` 的情况，但这是我的想法：

.容器{
--A：3；
--B：5；
}
    
.容器 div {
--n：calc((sibling-index() - var(--b))/var(--a));
--g: if(style(--a = 0):
calc(sign(sibling-index() - var(--b)) + 1);
其他：
calc(sign(var(--n) + 1) + mod(var(--n),1))
);
背景： if(style(--g = 1): 红色);
}

它是如何工作的？ 好吧，这将是你的家庭作业！
