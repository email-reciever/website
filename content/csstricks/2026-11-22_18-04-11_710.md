# 驯服字体：构建现代CSS重置

![](https://secure.gravatar.com/avatar/c9fcb20e74fd016b3fa91e8d919b435d3d50cc78a823aa1d65cfce782a8b5f36?s=80\&d=retro\&r=pg)

By [Stu Robson](https://css-tricks.com/author/stualwaystwisted-com/) on Nov 5, 2026

CSS 现在可以对字体做出以前需要在 [reset](https://css-tricks.com/reboot-resets-reasoning/) 之外做出的选择。 [`text-wrap: pretty`](https://css-tricks.com/pretty-is-in-the-eye-of-the-beholder/) 可以防止单词孤立，容器查询单位可以将标题缩放到其占据的列，且 [`text-box`](https://css-tricks.com/almanac/properties/t/text-box/) 可以修剪行框中内置的半导高。其中一些功能是实验性的，浏览器支持也不均匀，因此它们需要防护措施，而不是盲目包含。

我已经编写了 **tidy-typography.css**，它将有用的部分收集到默认样式表中：渲染和回退规则、流体尺寸、垂直节奏、换行、连字和 OpenType 详细信息。

使用整体，或选择解决您当前面临的特定问题的声明。我将在本文中逐步指导您了解所有细节，并在最后提供完整的代码。

## 渲染和fallback理智

```css
html {
  -webkit-font-smoothing: antialiased;
  text-rendering: optimizeLegibility;
  font-synthesis: none;

  -moz-text-size-adjust: none;
  -webkit-text-size-adjust: none;
  text-size-adjust: none;
}

body {
  font-size-adjust: from-font;
}
```

`font-synthesis: none` 防止浏览器在字体家族缺少某种样式时自动生成粗体或斜体。平滑和文本渲染声明主要是针对WebKit的渲染提示，不同平台的结果仍然有所不同。

`text-size-adjust` 禁用移动设备上的字体膨胀，当屏幕旋转时，这种膨胀可能会导致故意设计的布局跳动。 `font-size-adjust: from-font` 使用字体度量来减少字体大小的明显变化，而fallback则替换为网络字体。

（与本文中的其他代码片段一样，这个 `:root` 块是最终样式表的部分摘录，样式表将其与稍后定义的其他自定义属性结合起来。）

## 流体排版

[基于视口的流体排版](https://css-tricks.com/snippets/css/fluid-typography/) 不知道其元素的宽度。因此，侧边栏中的标题可以像填满整个视口一样缩放。

```css
.article-container {
  container-type: inline-size;
}

:root {
  --step-0: clamp(1rem, 0.9rem + 1cqi, 1.125rem);
  --step-3: clamp(2rem, 1.6rem + 3cqi, 2.75rem);
}
```

`container-type: inline-size` 可以使包装器成为 [容器查询](https://css-tricks.com/css-container-queries/),这样其子元素就可以使用 `cqi`：一个基于容器而非视口的单位。将 `vw` 替换为 `clamp()` 中的单位，可以让同一个标题在文章列或 `300px` 侧边栏中适当缩放，而无需组件特定的媒体查询。

## 垂直节奏：修剪半距

```css
:heading, p, blockquote, figcaption, li {
  text-box-trim: trim-both;
  text-box-edge: cap alphabetic;
  /* shorthand: text-box: trim-both cap alphabetic; */
}
```

[`line-height`](about:blank) 包括字体上方的空间和下方的基线以下的空间：半距。当文本必须与其他元素紧密对齐时，这一点就会变得明显。[`text-box-trim`](https://css-tricks.com/almanac/properties/t/text-box-trim/) 可以去除半距，而 [`text-box-edge`](https://css-tricks.com/almanac/properties/t/text-box-edge/) 则从大写字母的顶部到字母的基线测量。这是一个与字体相关的负边距调整的替代方法，且考虑到了字体的度量。

```css
@supports selector(:heading) {
  :heading {
    text-box: trim-both cap alphabetic;
  }
}
```

[选择器第 5 级提出：heading](https://drafts.csswg.org/selectors-5/#headings)，它可以匹配 `h1` 到 `h6` 以及 `[role="heading"]`。由于它尚未在浏览器中实现，因此应将其放在 `@supports selector()` 检查后面。

## 平衡的标题，孤行-free 段落

```css
:heading, blockquote, figcaption {
  text-wrap: balance;
}

p, li, dd {
  text-wrap: pretty;
  max-width: 65ch;
}

[contenteditable="true"] {
  text-wrap: stable;
}
```

默认的标题包装可能会留下一个短的最后一行。 `text-wrap: balance` 将文本分布在其行中，并且对于最多大约六行的块效果最佳。对于段落，`text-wrap: pretty` [避免了一个被遗弃的最后一个单词，而不平衡整个块](https://css-tricks.com/pretty-is-in-the-eye-of-the-beholder/)。两者都可以替换JavaScript孤儿修复器。可编辑的文本需要 `text-wrap: stable`，它可以防止每个新单词重新排列段落。

## 连字符，适当调节

```markup
<html lang="en-GB">
```

```css
p {
  hyphens: auto;
}
```

`hyphens: auto` 依赖于浏览器的语言字典，因此文档需要正确的 `lang` 属性（例如 `<html lang="en-GB">`）。没有它，浏览器就没有可用的字典，无法对文本进行连字符。即使有正确的 `lang`，默认值也可能留下微小的单词碎片或连续几行带有连字符的文本。

```css
p {
  hyphens: auto;
  hyphenate-limit-chars: 6 3 3; /* word length, min before break, min after break */
  hyphenate-character: "‐"; /* use proper hyphen glyph instead of dash */
  hyphenate-limit-lines: 2; /* no more than 2 consecutive hyphenated lines */
  hyphenate-limit-zone: 8%; /* reduce overall hyphenation frequency */
  hyphenate-limit-last: always; /* never hyphenate the last word of a paragraph */

  /* Safari legacy equivalents */
  -webkit-hyphens: auto;
  -webkit-hyphenate-limit-before: 4;
  -webkit-hyphenate-limit-after: 3;
  -webkit-hyphenate-limit-lines: 2;
}

pre, code, var, samp, kbd, :heading {
  hyphens: manual;
  -webkit-hyphens: manual;
}
```

[`hyphenate-limit-chars`](https://css-tricks.com/almanac/properties/h/hyphenate-limit-chars/) 控制最小可断行的单词和片段；[`hyphenate-limit-lines`](https://drafts.csswg.org/css-text-4/#hyphenate-line-limits) 防止梯形效果。[`hyphenate-limit-zone`](https://drafts.csswg.org/css-text-4/#hyphenate-size-limits) 使断行变得不那么频繁，同时 `hyphenate-limit-last` 保护最后一个单词。Safari 需要带前缀的等价物，因此同时声明两个集合。

将代码、变量和标题设置为 `hyphens: manual`：一个断行的代码单词可以改变其含义，而一个连字符的标题通常被视为错误。

## 悬挂标点和墨水感知下划线

```css
blockquote, p {
  hanging-punctuation: first allow-end last;
}

a {
  text-decoration-thickness: from-font;
  text-underline-offset: 0.15em;
  text-decoration-skip-ink: auto;
}
```

标点符号与字母相比没有相同的视觉重量，因此一个位于行首的引号可能看起来与下面的文本略微缩进。 [`hanging-punctuation`](https://css-tricks.com/almanac/properties/h/hanging-punctuation/) 允许指定标点符号稍微超出文本块的边缘。

`first` 值处理开头的标点符号，而 `last` 处理块末尾的标点符号，同时 `allow-end` 允许标点符号超过右边缘，而不是强制换行。结果是一个文本块，其边缘看起来真正是对齐的。

下划线有一个相关的问题。浏览器应用统一的、无论字体的实际粗细如何的线宽和位置。

`text-decoration-thickness: from-font` 读取字体设计师预期的线宽。[`text-underline-offset`](https://css-tricks.com/almanac/properties/t/text-underline-offset/) 给下降部位留出空间，而 `text-decoration-skip-ink: auto` 会在下降部位与下划线相交的地方中断下划线，而不是直接穿过字母。

## 可变字体的细致调整

```css
body {
  font-optical-sizing: auto;
  font-variant-ligatures: common-ligatures contextual;
  font-kerning: normal;
}

/* Dark mode grade compensation */
:root {
  --vf-grad: 0;
}

@media (prefers-color-scheme: dark) {
  :root { --vf-grad: -50; }
}

* {
  font-variation-settings: "GRAD" var(--vf-grad, 0);
}
```

[可变字体](https://css-tricks.com/one-file-many-options-using-variable-fonts-web/) 通常包括一个光学尺寸轴，或 `opsz`。它允许字体在大显示尺寸下使用较细的笔画，而在设置小尺寸时使用较粗、更易读的笔画。

`font-optical-sizing: auto` 允许字体根据其实际渲染大小进行调整。 `@supports` 块覆盖了较旧的 `font-variation-settings` 语法，仍有一些浏览器需要它，而 [`font-variant-ligatures`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/font-variant-ligatures) 和 [`font-kerning`](https://css-tricks.com/almanac/properties/f/font-kerning/) 启用了字体自己的连字和字距对。

[浅色文字在深色背景下读起来比在浅色背景下更重。](https://css-tricks.com/dark-mode-and-variable-fonts/) 当字体包含一个 `GRAD` 或等级轴时，暗黑模式块会在不改变字形或宽度（像实际的字重变化那样）的情况下降低感知到的字重。没有 `GRAD` 轴的字体会安全地忽略该设置。

```css
@font-face {
  font-family: "Mono";
  src: url("/fonts/mono-var.woff2") format("woff2");
  size-adjust: 105%; /* tune per-font */
}
```

将等宽字体混合到连续的文字中，通常会暴露出在相同的声明 [`font-size`](https://css-tricks.com/almanac/properties/f/font/font-size/) 下不匹配的 x 高度。 `size-adjust` 关键字，在 [`@font-face`](https://css-tricks.com/almanac/rules/f/font-face/) 级别设置一次，会根据特定的字体缩放其渲染输出，同时保持实际的 `font-size` 值不变。

## 数值、表情符号和脚本感知文本

表格中的数字需要相同的宽度，以便它们可以在屏幕上堆叠成干净的列。相反，流式文本中的数字不需要相同的处理，它们应该自然地与周围的文字一起放置。

```css
table, .tabular {
  font-variant-numeric: tabular-nums lining-nums;
}

.prose {
  font-variant-numeric: oldstyle-nums proportional-nums;
}

.emoji-color {
  font-variant-emoji: emoji;
}

.emoji-mono {
  font-variant-emoji: text;
}
```

`tabular-nums` 和 `lining-nums` 关键字为表格数字提供固定宽度和全大写高度。 `oldstyle-nums` 和 `proportional-nums` 允许数字与小写字母一起放置，而不会突出并破坏句子的质地。

[`font-variant-emoji`](https://css-tricks.com/almanac/properties/f/font-variant-emoji/) 使得彩色和单色emoji之间的选择变得明确。没有它，浏览器或平台会选择一个备用方案，结果可能会比你预期的更为不同。应用 `.emoji-color` 或 `.emoji-mono` 到你想要强制选择的容器中，而不是在 body 全局设置它。

## 区域感知的引号和本地的下标和上标

引用样式和字符顺序会因语言和地区而异。英语在双引号内嵌套单引号，英国英语则反转这种约定，法语使用带有细空格的引号。

```css
:where(:lang(en)) > * { quotes: "\"" "\"" "'" "'"; }
:where(:lang(en-GB)) > * { quotes: "'" "'" "\"" "\""; }
:where(:lang(fr)) > * { quotes: "«\\00202F" "\\00202F»" "\"" "\""; }

q::before { content: open-quote; }
q::after { content: close-quote; }
```

[`quotes`](https://css-tricks.com/almanac/properties/q/quotes/) 属性通过 [`:lang()`](https://css-tricks.com/almanac/pseudo-selectors/l/lang/) 为每种语言声明顺序。原生的 `q` 元素然后通过 `open-quote` 和 `close-quote` 插入正确的引号对。相同的标记可以在每个区域正确渲染，而无需将字符硬编码到内容中。

将规则包裹在 [`:where()`](https://css-tricks.com/almanac/pseudo-selectors/w/where/) 中可以保持其特异性为零，因此项目可以使用一个普通类覆盖引号样式。

默认的 `sub` 和 `sup` 样式是合成的。浏览器只是缩小文本并移动基线，而不是使用实际为该位置设计的字形。

```css
@supports (font-variant-position: sub) {
  :is(sub, .sub) {
    vertical-align: baseline;
    font-size: 100%;
    line-height: inherit;
    font-variant-position: sub;
  }
}

@supports (font-variant-position: super) {
  :is(sup, .sup) {
    vertical-align: baseline;
    font-size: 100%;
    line-height: inherit;
    font-variant-position: super;
  }
}
```

`font-variant-position` 切换到字体自己的专用子脚本和上标字形（如果存在），并重置 `vertical-align`、`font-size` 和 `line-height`，以避免与实际字形的预期大小和位置冲突。大多数字体只包含适当的数字而不是字母，因此在广泛应用此功能之前，请检查特定的字体。

## **关于特异性的注意事项：** **`:is()`** **和** **`:where()`**

[`:where()` 始终解析为零特异性](https://css-tricks.com/quick-reminder-that-is-and-where-are-basically-the-same-with-one-key-difference/), 这对于重置很有用。这里的每个规则都是一个有主见的默认值，使用 `:where()` 包裹它允许项目使用一个普通类覆盖属性。

```css
:where(h1, h2, h3, h4, h5, h6) {
  margin-block: 0.5em;
}
```

`:is()` 解决了一个不同的问题：重复。标题选择器列表在一个排版样式表中出现了多次，分组可以避免忘记某个级别的风险。

```css
:is(h1, h2, h3, h4, h5, h6), p, blockquote, figcaption, li {
  text-box: trim-both cap alphabetic;
}
```

与 `:where()` 不同，`:is()` 携带了其最具体参数的特异性。

## **最终** tidy-typography.css

这是完整的重置样式，结合了稳定的层。浏览器会忽略不支持的声明，因此样式表可以逐渐被采用。

```css
/* ==========================================================================
tidy-typography.css — a modern typography reset
Every rule degrades gracefully in unsupported browsers.
========================================================================== */

html {
  -webkit-font-smoothing: antialiased;
  text-rendering: optimizeLegibility;
  font-synthesis: none;
  -moz-text-size-adjust: none;
  -webkit-text-size-adjust: none;
  text-size-adjust: none;
}

body {
  max-width: 800px;
  margin: 0 auto;
  padding: 1rem;
}

/* ---- Fluid typography ---- */

.article-container {
  container-type: inline-size;
}

:root {
  --step-0: clamp(1rem, 0.9rem + 1cqi, 1.125rem);
  --step-1: clamp(1.25rem, 1.1rem + 1.5cqi, 1.5rem);
  --step-2: clamp(1.6rem, 1.35rem + 2cqi, 2rem);
  --step-3: clamp(2rem, 1.6rem + 3cqi, 2.75rem);
  --step-4: clamp(2.5rem, 1.9rem + 4.5cqi, 4rem);
  --vf-grad: 0;
}

@media (prefers-color-scheme: dark) {
  :root {
    --vf-grad: -50;
  }
}

/* ---- Variable font fine-tuning ---- */

* {
  font-variation-settings: "GRAD" var(--vf-grad, 0);
}

body {
  font-size: var(--step-0);
  font-size-adjust: from-font;
  line-height: 1.6;
  font-optical-sizing: auto;
  font-variant-ligatures: common-ligatures contextual;
  font-kerning: normal;
}

/* ---- Text box trim ---- */

:is(h1, h2, h3, h4, h5, h6), p, blockquote, figcaption, li {
  text-box: trim-both cap alphabetic;
}

/* ---- Text wrap ---- */

:is(h1, h2, h3, h4, h5, h6), blockquote, figcaption {
  text-wrap: balance;
  font-size: var(--step-3);
  line-height: 1.15;
  letter-spacing: -0.01em;
}

h1 {
  font-size: var(--step-4);
}

p, li, dd {
  text-wrap: pretty;
  max-width: 65ch;
  hyphens: auto;
  hyphenate-limit-chars: 6 3 3;
  hyphenate-limit-lines: 2;
  hyphenate-limit-zone: 8%;
  hyphenate-limit-last: always;
}

pre, code, var, samp, kbd, :is(h1, h2, h3, h4, h5, h6) {
  hyphens: manual;
}

blockquote, p {
  hanging-punctuation: first allow-end last;
}

[contenteditable="true"] {
  text-wrap: stable;
}

/* ---- Numeric, emoji, and script-aware text ---- */

table, .tabular {
  font-variant-numeric: tabular-nums lining-nums;
}

.prose {
  font-variant-numeric: oldstyle-nums proportional-nums;
}

.emoji-color {
  font-variant-emoji: emoji;
}

.emoji-mono {
  font-variant-emoji: text;
}

/* ---- Locale-aware quotes ---- */

:where(:lang(en)) > * {
  quotes: '"' '"' "'" "'";
}

:where(:lang(en-GB)) > * {
  quotes: "'" "'" '"' '"';
}

q::before {
  content: open-quote;
}

q::after {
  content: close-quote;
}

/* ---- Native sub and superscripts ---- */

@supports (font-variant-position: sub) {
  sub, .sub {
    vertical-align: baseline;
    font-size: 100%;
    line-height: inherit;
    font-variant-position: sub;
  }
}

@supports (font-variant-position: super) {
  sup, .sup {
    vertical-align: baseline;
    font-size: 100%;
    line-height: inherit;
    font-variant-position: super;
  }
}

/* ---- Ink-aware underlines ---- */

a {
  text-decoration-thickness: from-font;
  text-underline-offset: 0.15em;
  text-decoration-skip-ink: auto;
}
```

## 什么属于重置

这段 CSS 中的大部分内容都移除了曾经泄漏到构建的其他部分的工作。`text-wrap` 可以接管 JavaScript 中的孤儿处理，容器查询单位可以保持组件的类型比例与其自身宽度绑定，而 `text-box-trim` 避免了曾经用来补偿leading的负边距。quotes、font-variant-position 和 `font-optical-sizing` 将几个较小的细节交回给语言和字体，而不是一系列一次性的修复。

浏览器支持将会继续变化，特别是对于 `text-wrap` 和 `text-box-trim`。不支持的声明将被忽略，但这只有在未增强的排版在其自身权益中是可以接受时才有帮助。

其中一些规则对于基线重置仍然太新。新闻文章、营销页面和可编辑的产品界面对其文本的要求不同；属于您自己的集合取决于字体、内容和您仍需要支持的浏览器。
