当我 30 年前开始设计网站时，David Siegel 刚刚出版了 [Creating Killer Web Sites](https://archive.org/details/creatingkillerwe00sieg)，这本书普及了 HTML 表格和用于布局网页的 Spacer GIF。 CSS最终通过浮点和定位让我们对布局进行了更多控制。 两者都不是用于页面布局，不一致的浏览器行为可能会使使用它们感到沮丧。 尽管如此，这并没有阻止我和其他一代设计师使用浮动和定位。

当 CSS 框架开始提供现成的网格系统时，事情变得更容易了。 [Blueprint CSS](https://en.wikipedia.org/wiki/Blueprint_\(CSS_framework)) 提供了一个 24 列的网格，而 Nathan Smith 的 [960 Grid System](https://960.gs) 提供了 12 列和 16 列选项。 这些框架为设计师和开发人员提供了一个共享的结构，使布局规划和实施变得更加容易。

![](https://css-tricks.com/wp-content/uploads/2026/10/css-tricks-1-1.webp)

*   **1996:** HTML 表和间隔 GIF
*   **2007：**蓝图CSS及其24列网格
*   **2008:** 960 网格系统及其十二列网格
*   **今天：** 十二列网格仍然是一个熟悉的框架约定。

2000 年代没有发明十二列网格。 图形设计师几十年来一直使用基于列的和模块化的网格，十二是一个方便的数字，因为你不需要成为数学天才来将其分成两半、三分之一和四分之一来创建我们到处都能看到的2-UP、3-UP和4-UP组件 在线。

[Bootstrap](https://getbootstrap.com) 和 [Foundation](https://get.foundation) 之类的框架遵循，帮助将十二列网格建立为页面布局的事实上的标准。 我明白为什么会发生这种情况。 但在此过程中，一种布局选项成为几乎所有内容的默认起点。

![Three page layouts side-by-side demonstrating typical typical column layouts.](https://css-tricks.com/wp-content/uploads/2026/10/css-tricks-1-2.webp)

来自 _Standout 设计的通用网站设计_。

[CSS Grid](https://css-tricks.com/complete-guide-css-grid-layout/) 更改了页面布局的可能内容，但我仍然看到设计师首先将页面划分为十二个相等的列，然后决定如何将其内容放入其中。 他们最终使用的设计可能非常好，但它们也可以看起来非常相似。

不过，我不认为十二列网格本身是问题所在。 在考虑是什么让我为其设计的公司以及其网站需要交流的内容之前，它正在寻求一个熟悉的解决方案。 那么当我从这些问题开始时会发生什么？

[](#every-company-has-a-story-worth-telling)每家公司都有一个值得讲述的故事
---------------------------------------- ----------------------------------------

在我决定布局需要多少列之前，我想了解我正在设计的公司。 是什么让它与竞争对手不同？ 它希望人们记住什么？ 它的个性是否可以影响其网站的外观和感觉？

这些问题很重要，因为布局不仅仅是安排内容。 元素之间的大小、位置和关系会影响人们体验网站的方式。 一种克制、有序的作品可以传达出与充满活力和运动的完全不同的东西。 所以为了证明我的意思，我将使用 Wheelman。 这是我为我的书_[Standout Designs for the Web](/product/standout-web-design-for-the-web)_发明的一家虚构公司。

_[Standout Designs for the Web](/product/standout-web-design-for-the-web)_ 的预购现已在 CSS-Tricks 商店中开放。

Wheelman 为 Getaway 司机提供产品和服务，包括法律咨询、抢劫保险和销售磨合必需品的在线商店。 它还出版了一本杂志，其中包含有关方向盘生活的建议、新闻和故事。

![A series of page layouts that look outside the typical column-based grid showing creative use of space without losing balance.](https://css-tricks.com/wp-content/uploads/2026/10/css-tricks-1-3.webp)

Wheelman 可能是一家虚构的公司，但在这样的项目中涉及的创造性挑战和设计决策是非常非常真实的。 （[View large](https://css-tricks.com/wp-content/uploads/2026/10/css-tricks-1-3.webp)）

Wheelman 不是一家普通的公司，那么为什么它的网站看起来像是日常组件的集合？ 它认真对待它的业务，但不怕从它的设计中获得乐趣。 它是叛逆的，但不想看起来令人反感。 它的观众是罪犯，但他们需要专业精神。 Wheelman 有很多个性可以使用，我希望它的设计能够反映这一点。

这并不意味着为了差异而让 Wheelman 与众不同。 它的客户仍然需要找到他们正在寻找的东西，了解它提供的内容，并购买其产品和服务。 但我可以通过选择适合公司的布局来让这些体验更加难忘，而不是满足于熟悉的安排。

[](#starting-with-content-not-columns)从内容开始，而不是列
---------------------------------------------------------------------

假设我正在为 Wheelman 的在线商店设计一个新的登陆页面。 它包括两种产品，一种具有巨大的标题、产品图像以及您在大多数商店中可以找到的功能类型和信息。

在我决定如何安排这些元素之前，我想超越它们并考虑它们的关系。 我问自己这样的问题：

*   哪些元素最值得关注？
*   什么属于一起？
*   信息有自然顺序吗？

只有这样我才开始思考视觉设计问题：“大照片会设置场景吗？我应该让介绍更突出吗？空白能引导眼睛并创造空间来暂停吗？我如何将图像和文本组合成一个经过深思熟虑的构图？”

在我决定哪个网格可以帮助我实现它之前，这些问题可以帮助我了解布局需要完成的工作。

我可以将所有内容都安排在一个专栏中，以获得简单的阅读体验。 这将使响应式设计变得更加容易。 但我不会。

![A webpage layout next to a 12-column grid demonstrating how the layout fits the space.](https://css-tricks.com/wp-content/uploads/2026/10/css-tricks-1-4.webp)

想象一下，我正在为 Wheelman 商店设计一个新的产品登陆页面。 （[View large](https://css-tricks.com/wp-content/uploads/2026/10/css-tricks-1-4-large-scaled.png)）

威廉有叛逆的性格，我希望它的商店反映这一点。 更有活力的布局似乎是合适的，但我仍然需要在产品及其信息之间建立清晰的层次结构。 两个等宽的色谱柱使两种产品都具有同等的突出性。

![A wide page layout split in two large columns that each play with their own complementary inner grid-based layouts.](https://css-tricks.com/wp-content/uploads/2026/10/css-tricks-1-5.webp)

等宽的列给予同等的突出。 （[View large](https://css-tricks.com/wp-content/uploads/2026/10/css-tricks-1-5-large-scaled.png)）

即使大多数元素保持相同的大小，改变它们的比例也会创建一个层次结构。

![Dividing a page layout in two columns, two thirds and one third respectively, shows how one area drives more focus while remaining balanced.](https://css-tricks.com/wp-content/uploads/2026/10/css-tricks-1-6.webp)

更改布局比例会创建层次结构。 （[View large](https://css-tricks.com/wp-content/uploads/2026/10/css-tricks-1-6-large-scaled.png)）

我可以将这些比例基于十二列网格，但我不会。 列只垂直划分空间，我想要一个添加另一个维度的布局。

[](#adding-another-dimension-with-modular-grids)使用模块化网格添加另一个维度
------------------------------------------- -------------------------------------------

将布局划分为列是一个有用的起点，但添加行会创建另一个维度并开辟更多创造性的可能性。 在列和行相交的地方，它们形成称为模块的矩形或正方形单元。

![](https://css-tricks.com/wp-content/uploads/2026/10/css-tricks-1-7-1024x576.webp)

来自 _standout 设计的 web_ 的模块化网格。

组合这些模块会创建更大的空间区域，可以建立层次结构、控制空白并为组合增添多样性。

![Comparing two page layouts, specifically how grids can be used creatively to create both interest and balance with the same content.](https://css-tricks.com/wp-content/uploads/2026/10/css-tricks-1-8.webp)

来自 _standout 设计的 Web_ 的更多模块化网格。

使用模块化网格，我可以添加戏剧，通过不同的规模建立层次结构，并使构图感觉难以预测。 从四列四行开始，我可以使用十六个模块，但我不需要全部填充。

![A four-by-four wireframe next to a page layout showcasing a box cutter product that is based on it.](https://css-tricks.com/wp-content/uploads/2026/10/css-tricks-1-9.webp)

4×4 模块化网格提供 16 个模块供您使用。 （[View large](https://css-tricks.com/wp-content/uploads/2026/10/css-tricks-1-9-large-756x1024.png)）

我可以通过将大型图形标题和产品图像分布在四个模块中来创造戏剧性，而产品信息和购物工具各占一个模块。

模块化结构在替代产品的网格中变得更加明显。 大多数只占用一个模块，而其他模块则横向或垂直填充两个模块。 改变它们的尺寸使一些产品更加突出，并使整体布置感觉不那么可预测。

结果仍然感觉像一个产品页面，有清晰的阅读顺序和内容的呼吸空间。 但这也让人感觉毫无疑问，就像 Wheelman 会发布的东西。

我不希望这种组合适用于每个屏幕尺寸，因此我可以调整模块的大小和数量以改善阅读体验。

![](https://css-tricks.com/wp-content/uploads/2026/10/css-tricks-1-10.webp)

来自 _standout 设计的 web_ 的模块化网格。

如果一个网格提供了如此多的灵活性，想象一下组合两个或多个网格可以做什么。

[](#mixing-grids-to-create-compound-layouts)混合网格以创建复合布局
---------------------------------------- ----------------------------------------

我想从 Wheelman 的网站上获得的一件事是多样性。 它的杂志、商店和服务有不同的用途，我不希望每个页面都觉得我将其内容倒入了同一个模板中。

Wheelman 需要感觉有条理的布局，而不是可预测的。 复合网格为我提供了所需的结构，同时为较少传统的布置留出了空间。

复合网格在同一页面上组合了两个或多个类型的网格——列、模块化或层次结构。 这些网格可以重叠、并排坐下，或者堆叠在另一个顶部。 组合网格创造了两种网格本身都没有提供的可能性。

我可以首先用包含三列的两列网格叠加。 它们的组合网格线创建了两个不同宽度的四列，为我提供了更大的灵活性，而不会失去底层结构。

![](https://css-tricks.com/wp-content/uploads/2026/10/css-tricks-1-11.webp)

三列网格重叠的两列网格。

这些比例为安排内容提供了更多可能性。 我可能会使用更宽的区域作为照片或标题，然后将拉引号放入较窄的空间之一。 另一个页面可以使用相同的底层网格，但将其空间组合起来以适应另一个故事。

随着这些数字的增加，将具有不同列数的网格组合变得更加有趣。 在 _[Standout Designs for the Web](/product/standout-web-design-for-the-web)_ 中，我探索了几种组合，包括混合四列和五列网格，为 Wheelman 的页面创建不同的构图，同时保持连接的视觉结构。

![](https://css-tricks.com/wp-content/uploads/2026/10/css-tricks-1-12.webp)

五列网格重叠的四列网格。

关键不是为了让每个页面看起来都不一样。 这是为了给每个部分一个适合其内容的布局，同时让它们都感觉自己是同一家公司的一部分。

[](#dont-let-familiarity-make-choices-for-you)不要让熟悉为你做出选择
------------------------------------------ ------------------------------------------

十二列网格很有用，我当然不建议你完全停止使用它们。 但它们只是众多选择中的一种，以相同的结构开始每个设计都会限制您的可能性，甚至在您考虑到您的设计所讲述的故事之前。

十二列网格所激发的 2-UP、3-UP 和 4-UP 模式本质上也没有错。 它们有时正是需要的。 但自动接触它们可能会为使网站令人难忘的性格和个性留下很少的空间。

Wheelman 给了我很多选择不同布局的理由。 它的故事、产品和服务并不都需要相同的安排，它的个性让我有机会让这些安排变得更加独特。 网格只是帮助我将这些想法付诸实践的工具。

这不仅适用于布局。 同样的想法应该会影响我选择的颜色、我使用的排版、我委托的图像以及我将这些元素组合在一起的方式。

![A gallery of web pages that demonstrate creative grid-based layouts in different contexts.](https://css-tricks.com/wp-content/uploads/2026/10/css-tricks-1-13.webp)

一致性并不意味着让一切看起来都一样。 不同的设计可以共享视觉语言，并且仍然有自己的性格。

这就是为什么我为 Web_ 编写了 _standout 设计。 我想鼓励设计师超越熟悉的解决方案，对颜色、排版、图像和布局做出更深思熟虑的决定。 不要为了差异而有所不同，而是要创建外观和感觉就像属于他们背后的公司的网站。 没有其他人。
