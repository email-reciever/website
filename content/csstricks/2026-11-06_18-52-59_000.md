**嘿，你们这些出色的 RSS 订阅者！** 我们刚刚软推了一个网站重新设计，并想给你们第一次提醒。 完整的文章将于周一发布，但以下是高级细节：

*   **Ghost Busting：** 正如您可能想象的那样，这个网站在 19 年中已经承载了大量的作品。 我决定挖掘这个主题，并明确找到了一些要破产的鬼魂。
*   **现代开发工具：** 比我们之前的 5 年工作流程要好得多。 更漂亮、styleint、github 操作、自动缓存！
*   **安全：** 我决定请克劳德帮助我进行整体审计。 我提示它查看最近的 WordPress 安全版本说明，并确定主题可以强化以符合 WordPress 正在执行的操作的区域。
*   **sass rewrite:** 我很高兴看到 CSS 的整体大小在这个过程中下降。 它从 180 kb (31.7 kb) 到 169 kb (24.6 kb 的压缩)。 意义不大，但也不是_不重要。
*   **设计-ish系统：**广泛的主题一致性！ 用于颜色、字体、字体大小、重用值的语义标记。
*   **主题切换：** 尽管内容是在白色背景下，但该网站主要是黑暗的，因此我将事物视为已经存在的“黑暗”模式。 结果是一个奶油般的轻盈主题。
*   **Jawbreaker 质地：** 我称它为“Jawbreaker”，因为它没有更好的术语，因为它让我想起了我小时候喜欢的 Jawbreaker 糖果。 你会发现它在整个网站上飞溅。
*   **新年鉴索引：** 现在该页面是 CSS 功能的真实索引，可让您快速到达需要到达的地方。 某个地方的某个时间有人做了某种 CSS 周期表。
*   **新指南索引：** 有一个特色指南，一个新添加和更新的指南的小部件，以及下面所有内容的分类网格。
*   **作者页面：**这是一个小小的变化，真的。 右侧边栏向左移动，作者图像和生物移动到了，使文章爬到顶部。
*   **WordPress 管理样式：** 诸如字体和文本样式之类的东西现在具有反映前端的最小样式。

完整的文章将深入研究这些内容，并提供与之前设计的并排比较。 周一注意它！ 我希望你周末过得愉快。
