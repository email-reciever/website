Amazon Polly 推出语音克隆：为您的品牌带来独特的声音
======================================================================================

Amazon Polly 中的语音克隆现在通常作为封闭版本提供。 给 Amazon Polly 几分钟的录音，来自同意克隆他们的语音的扬声器，Amazon Polly 用该扬声器的声音构建您自己的克隆语音。 克隆的声音在亚马逊 Polly 生成引擎上运行，它提供与其他生成声音相似的自然性和准确性。 Amazon Polly Voice 克隆推出七种语言：英语、西班牙语、德语、法语、意大利语、葡萄牙语和印地语。 每个克隆的语音都会说出它所记录的语言。克隆的语音会自动加密并被访问控制：只有您可以访问克隆的语音。

Amazon Polly Voice 克隆在 Amazon Polly 生成引擎支持的所有 AWS 区域（包括 AWS GovCloud (US)）区域都可用。 已为选定的 Amazon Polly 客户启用访问权限。 其他人可以联系他们的 AWS 客户团队或 [apply for access](https://pages.awscloud.com/amazon-polly-voice-cloning-20261119.html) 以获取访问权限。

有了这个新功能，您可以将克隆生命周期构建到 AWS 应用程序中。 为 Amazon Polly 客户免费构建克隆语音，Amazon Polly 对按需付费的语音使用收费，详情请参阅 [Amazon Polly Pricing page](/polly/pricing/)。

你可以建造什么
-------------------

**跨渠道的一致品牌声音**

建立一种可识别的语音并在您的交互式语音响应 (IVR) 系统、级联语音代理、移动应用程序、店内公告、广告和连接设备中使用它。 您可以按需生成品牌音频，而不是依赖普通的普通语音或每次更改录制会话重新预订录制会话，每个频道都可以生成一致的声音。

**联系中心**

跨服务流程提供独特的品牌语音，并在没有新的 Studio 会话的情况下随优惠和策略更改提示。 您可以从源文本创建提示，在推出前对其进行测试，并在问候、路由和通知体验中使用相同的语音。

**大规模媒体和内容**

创作者、出版商和工作室可以以多种自定义语音创建有声读物、课程、播客、游戏角色和视频，以增强聆听体验，并快速生成后续章节或更新。

**具有一致角色的本地化**

在内容库中保持可识别的语音身份，因此叙述在标题和更新中保持一致。 每个克隆的语音只会说出它所记录的语言。对于多语言体验，创建和审查每种支持的语言的批准语音。

**可访问性和个性化**

为阅读体验、辅助工具和个性化互动提供自然、人性化的声音。 每次创建语音时，您都确认了演讲者的同意。

语音克隆的工作原理
------------------------

使用语音克隆，您可以从单个扬声器的录音中构建自定义的 Amazon Polly 语音，然后通过 Amazon Polly 生成引擎在该语音中合成语音。 声音经过四个步骤，从录制扬声器到使用完成的声音：

[![The voice cloning lifecycle: record, create, wait, use](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/11/19/ML-22432-1.png)](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/11/19/ML-22432-1.png)

图 1：语音克隆生命周期，从录制扬声器到使用完成的语音

克隆的声音经过四个步骤：

1.  **记录。** 您录制一名扬声器（请参阅以下录音提示）。 您可以直接在 `CreateVoice` 请求中发送录音或将其上传到控制台。 您还可以将它们存储在 AWS 区域中的 Amazon Simple Storage Service (Amazon S3) 存储桶中，并在其中将 Amazon Polly 指向它们。
2.  **CREATE.** 您用 1-10 条录音、所使用的语言和 `TermsAccepted=True` 确认您已获得演讲者的同意而致电 `CreateVoice`。 Amazon Polly 立即返回语音 ID (`vc-…`) 并在后台构建语音。
3.  **等待。** 创建是异步的，通常需要 5-10 分钟。 在此期间，Amazon Polly 还会检查您的文本到语音 (TTS) 语音的质量，以获得扬声器的相似性。 您呼叫 `GetVoice` 直到状态从 `pending` 更改为 `active` 或 `failed`。
4.  **使用。 当您不再需要声音时，您会拨打 `DeleteVoice`。

同意和控制
--------------------

一个人的录音发出克隆的声音。 您确认您已获得所有录音的演讲者的同意，并且您可以控制谁可以使用该语音以及何时被删除。

*   您确认您创建的每个声音的同意。 当您在控制台上或在 API 中使用 `TermsAccepted=True` 创建语音时，您确认您已获得创建和使用克隆语音所需的所有权利和同意。 您对语音克隆的使用取决于[AWS Service Terms](/service-terms/)、[Biometric Notice and Consent Terms](/legal/biometric-notice-and-consent-terms)、[AWS Responsible AI Policy](/ai/responsible-ai/policy/)和[AWS Acceptable Use Policy](/aup/)。
*   生成的语音带有水印。 Amazon Polly 为使用克隆语音生成的文本到语音的音频添加了一个水印。
*   只有您的帐户可以使用它。 克隆语音的范围仅限于创建它的 AWS 账户，您可以通过 AWS Identity and Access Management (IAM) 控制访问权限。 您可以使用您自己的 AWS Key Management Service (AWS KMS) 密钥对语音进行加密并标记它们。
*   你决定它什么时候消失。 在一个 `DeleteVoice` 通话或控制台上删除一个语音，一旦它处于活动状态或其创建失败。
*    Amazon Polly 在创建语音后不会保留您的录音副本，并且不使用它们来训练 Amazon Polly 模型。 它只保留合成语音所需的语音数据，并将其存储加密。 您可以使用自己的 AWS KMS 密钥进行加密，并 `DeleteVoice` 立即删除数据。

我们建议您：

*   记录每位发言者的同意。
*   如果说话者撤回同意，则删除语音。
*   告诉听众何时在合适的地方听到合成声音。
*   仅授予需要的人和系统的语音权限。

有关预期用途和限制的详细信息，请参阅[Amazon Polly AI Service Card](https://docs.aws.amazon.com/ai/responsible-ai/amazon-polly/overview.html) 和[AWS Responsible Use of AI](/ai/responsible-ai/) 指南。

录音的最佳做法
-----------------------------

您的克隆语音从录音中学习，包括您宁愿没有的部分：笔记本电脑风扇、房间回声、会议应用程序的噪声过滤器。

*   记录两到十分钟的自然语音，分成最长一分钟的片段。 每个语音最多可以发送 10 条录音，总共最多可发送 15 分钟的音频。 质量比长度更重要：更多的音频可能不会改变语音的声音。
*   一个扬声器，一个安静的房间，与麦克风的距离相同。 使用 USB 麦克风或可以记录 WAV 的手机应用程序。 从一开始就以 16 位的单声道 wav 录制，以 24 kHz 的速度录制，因此以后没有任何转换。 Amazon Polly 接受其他音频格式，但我们推荐 WAV。 有关支持的格式和限制，请参见 [Amazon Polly Developer Guide](https://docs.aws.amazon.com/polly/latest/dg/what-is.html)。
*   避免使用会议应用和浏览器记录器。 它们的回声消除和噪声抑制改变了声音，克隆也学习了这些变化。
*   记录你想要的声音的每一个风格。 克隆的声音从录音中汲取了风格，无法融合几个，所以乐观、悲伤和愤怒不会给你一个可以做到这三种的声音。
*   用语音应该说的语言记录。 语音克隆通过美国英语、德语、美国西班牙语、法语、意大利语、巴西葡萄牙语和印地语的录音进行测试。 这些语言的其他口音（例如英式英语或加拿大法语）的录音也有效，但测试较少，因此请使用您自己的内容检查语音。

生产注意事项
--------------------------

**提前创建声音**

语音创建需要几分钟，因此将其视为配置步骤，而不是用户请求的一部分。 小型工作流（例如 AWS Step 函数或作业队列）可以调用 `CreateVoice`，每 30 秒检查一次 `GetVoice`，直到语音处于活动状态，然后将语音 ID 存储在您的配置中。 `CreateVoice` 和 `DeleteVoice` 每秒共享 1 个请求的限制，因此将批量创建和删除排队。

**保持库存**

`DescribeVoices` 列出您的克隆语音以及内置于 Amazon Polly 中的语音。 克隆的声音 `Origin` 设置为 `customer`。 存储每个语音的语音 ID、区域、语言、同意参考和所有者，并为每个语音赋予独特的 `Name`。 如果 `CreateVoice` 呼叫超时或返回服务器错误，则语音可能已经存在，并且 SDK 的自动重试可以创建第二个。 在您重试之前检查该名称的 `DescribeVoices`。

**计划错误**

`CreateVoice` 返回 `ThrottlingException` 当您超过它与 `DeleteVoice` 共享的每秒 1 请求限制时，以及当帐户在该区域中达到克隆语音配额时返回 `ThrottlingException`。 与仍在创建的声音的合成或删除会返回 `ConflictException`。 如果语音使用您自己的 KMS 密钥，则无法访问密钥的呼叫者会收到拒绝访问的错误。 当创建失败时，`StatusReason` 仅提供一条一般信息，因此请根据前面的录制最佳实践检查录制，然后删除失败的声音并创建一个新的录音。

**语音的范围权限**

克隆的语音是 IAM 资源，因此您可以为交通许可提供服务的角色，以使用一种选择的声音进行综合。 如果语音使用您自己的 KMS 密钥，该角色还需要访问密钥。 保留 `polly:CreateVoice` 和 `polly:DeleteVoice` 以获取单独的配置角色。 以下是服务角色的示例策略：

{
"版本": "2012-10-17",
“陈述”：[
{
“效果”：“允许”，
“动作”：“波莉：合成语音”，
"资源": "ARN:AWS:Polly:US-East-1:111122223333:Voice/VC-0123456789"
}
]
}

使用标签，您可以使用 `aws:ResourceTag` 条件为整组语音编写一次相同的规则。 还要查看您现有的政策：允许 `polly:SynthesizeSpeech` 对所有资源（`"Resource": "*"`）的声明也涵盖了帐户中的每个克隆语音。

**计划配额和地区**

每个帐户的初始配额为每个区域 10 个克隆的语音。 要请求增加，请联系您的客户团队或 [AWS Support](/contact-us/)。 语音仅存在于您创建它的帐户和区域中。 要服务于另一个地区或帐户，请从相同的录音中再次在该区域创建声音，并确保演讲者的同意涵盖每个副本。

**使用您的真实脚本进行测试**

在声音上线之前，请听它阅读您自己的内容：产品名称、数字、地址和您拥有的最长的句子。 相同的文本可能会与一项请求略有不同。 对于诸如电话线问候的固定提示，生成一次音频，与扬声器和您的品牌团队一起批准它，并提供存储的文件。 如果名称或术语出现错误，请在文本中以不同的方式拼写或使用语音合成标记语言 (SSML) `<phoneme>` 标记。 音素标签适用于英语、法语、意大利语、德语和西班牙语的克隆语音。 见[Supported SSML tags](https://docs.aws.amazon.com/polly/latest/dg/supportedtags.html)。

---------------

**可用性**

每个 AWS 账户都启用了访问权限。 如果您在 Amazon Polly 控制台中看到语音克隆（展开左侧面板并查看是否列出了语音克隆），它将为您的帐户启用。 如果没有，您可以联系您的 AWS 账户团队或 [apply for access](https://pages.awscloud.com/amazon-polly-voice-cloning-20261119.html) 请求访问权限。 支持的 AWS 区域与生成引擎相同：美国东部（弗吉尼亚北部）、美国西部（俄勒冈州）、欧洲（法兰克福）、欧洲（苏黎世）、欧洲（伦敦）、亚太地区（悉尼）、亚太地区（首尔）、亚太地区（新加坡）、亚洲 太平洋（东京）、加拿大（中部）和 AWS GovCloud（美国-西部）。 克隆的语音位于您创建它的 AWS 区域中。

**语言**

英语、德语、西班牙语、法语、意大利语、葡萄牙语和印地语。 测试记录地点：美国英语 (`en-US`)、德语 (`de-DE`)、美国西班牙语 (`es-US`)、法语 (`fr-FR`)、意大利语 (`it-IT`)、巴西葡萄牙语 (`pt-BR`) 和印地语 (`hi-IN`)。 这些语言的其他口音也有效，但测试较少。 每个声音都会说出它所记录的语言。

**记录**

每个语音 1-10 次录音，总共长达 15 分钟。 WAV 推荐：单声道、16 位、24 kHz 或 44.1/48 kHz。 Amazon Polly 也接受其他音频格式。 控制台上传限制为每个文件 5 MB。 对于较大的文件，请使用 Amazon S3。

**数据处理**

创建语音后，Amazon Polly 会删除其录制副本，并且不使用它们来训练 Amazon Polly 模型。 它只保留合成所需的语音数据，加密存储（您可以使用自己的 AWS KMS 密钥），直到您拨打 `DeleteVoice`。

**创作时间**

通常需要 5-10 分钟来构建 TTS 语音，异步。

**合成延迟**

与 Amazon Polly 中的生成语音相同。

**配额**

每个 AWS 区域的每个账户的 10 个克隆语音最初。 要请求增加，请联系 AWS 支持。 `CreateVoice` 和 `DeleteVoice` 每秒共享 1 个请求的限制。

**合成**

克隆的语音遵循亚马逊 Polly 的生成语音配额，包括每个请求和每个综合任务的文本限制。 见[Amazon Polly quotas](https://docs.aws.amazon.com/polly/latest/dg/limits.html)。

**定价**

创建克隆的声音是免费的。 Amazon Polly 对按需付费的克隆语音使用收费。 见[Amazon Polly pricing](/polly/pricing/)。

**API**

`CreateVoice`、`GetVoice`、`DeleteVoice`和`DescribeVoices`管理语音。 `SynthesizeSpeech` 和 `StartSpeechSynthesisTask` 与 `Engine="generative"` 一起使用它们。 见[Amazon Polly API reference](https://docs.aws.amazon.com/polly/latest/dg/API_Reference.html)。

总结
-----------

Amazon Polly 中的语音克隆为您的应用程序提供了语音，人们可以识别：在演讲者的同意下录制一次，并准备通过 Amazon Polly API 使用。 要在控制台上开始使用，请确保为您的帐户启用了语音克隆、准备录制和所需的同意，打开 [Amazon Polly console](https://console.aws.amazon.com/polly/) 并创建您的第一个克隆语音。 如果您是新客户并希望启用语音克隆，请联系您的 AWS 客户团队或 [apply for access](https://pages.awscloud.com/amazon-polly-voice-cloning-20261119.html) 以获取访问权限。

有关开发人员指南，请参阅 [Amazon Polly documentation](https://docs.aws.amazon.com/polly/)。 有关定价，请参见[Amazon Polly Pricing Page](/polly/pricing/)。 对于您可以使用 Amazon Polly 构建的其他语音 AI 用例，包括语音克隆，请查看 [GitHub repo](https://github.com/aws-samples/amazon-ai-samples/tree/main/text-to-speech)。
