Svelte 的新功能[](#What's-new-in-Svelte)
-------------------------------------------

*   `<svelte:element>` 元素允许您渲染动态指定类型的元素。 例如，这在从 CMS 呈现富文本内容时很有用。 查看 [docs](https://v4.svelte.dev/docs#template-syntax-svelte-element) 或 [tutorial](/tutorial/svelte/svelte-element) 了解更多信息 (**3.47.0**)！

语言工具更新[](#Language-Tools-updates)
---------------------------------------------

现在支持 *   `svelte:element` 和 `sveltekit:reload`
*   现在将自动检测到无效的svelte导入路径 - 请参阅PR以获取旧行为（[#1448](https://github.com/sveltejs/language-tools/pull/1448)）
*   `source.sortImports` 允许您在不删除未使用的导入的情况下对导入进行排序 ([#1338](https://github.com/sveltejs/language-tools/issues/1338))
*   悬停在 HTML 属性上现在将显示 HTML 悬停信息而不是 ts 悬停信息 - 导致更多有用的信息 ([#1447](https://github.com/sveltejs/language-tools/pull/1447))
*   在 VS Code 中，您现在可以使用 `Insert Snippet` 命令 ([#1373](https://github.com/sveltejs/language-tools/pull/1373)) 包装控制流标签中的现有代码块

sveltekit的新增功能[](#What's-new-in-SvelteKit)
-----------------------------------------------

*   文件和目录现在可以在路由目录（[#4438](https://github.com/sveltejs/kit/pull/4438)）中命名为 `__tests__` 和 `__test__`
*   现在支持 Netlify 边缘函数 ([#4657](https://github.com/sveltejs/kit/pull/4657)) 和 Vercel 构建输出 API ([#4663](https://github.com/sveltejs/kit/pull/4663))
*   自定义 `load` 依赖关系，表示页面所依赖的 URL 的字符串数组现在在加载路由时可用（[Docs](/docs/kit/load#Rerunning-load-functions)、[#4536](https://github.com/sveltejs/kit/pull/4536)）

### 突破性变化[](#What's-new-in-SvelteKit-Breaking-Changes)

*   验证器现在称为“匹配器”（[Docs](/docs/kit/advanced-routing#Matching)、[#4358](https://github.com/sveltejs/kit/pull/4358)）
*   `__layout.reset` 已被命名布局替换 - 对共享布局元素具有很大的可配置性（[Docs](/docs/kit/advanced-routing#Advanced-layouts-layout)、[#4388](https://github.com/sveltejs/kit/pull/4388)）
*   现在跳过了`rel="external"`链接的预渲染([#4545](https://github.com/sveltejs/kit/pull/4545))
*   `maxage`现在是`LoadOutput`中的`cache`（[#4690](https://github.com/sveltejs/kit/pull/4690)）
