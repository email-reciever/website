Svelte 和 Sveltekit 的新功能[](#What's-new-in-Svelte-and-SvelteKit)
---------------------------------- -----------------------------------

本月，Svelte 维护者一直在努力构建 [Asynchronous Svelte](https://github.com/sveltejs/svelte/discussions/15845)，但仍有时间提供一些有用的功能。 如果您有兴趣尝试 async 分支，或者只是想跟随开发，请查看 [feat: allow await in components #15844](https://github.com/sveltejs/svelte/pull/15844)

*   现在将部分评估某些表达式以提高运行时性能（**svelte@5.27.0/5.28.0**、[#15494](https://github.com/sveltejs/svelte/pull/15494)/[#15781](https://github.com/sveltejs/svelte/pull/15781)）
*   Svelte CLI (`sv`) 在 `create` 和 `add` 中添加了 `--install <package-manager>` 标志，以指定运行时要使用的包管理器 (**cli@0.8.1**, [#531](https://github.com/sveltejs/cli/pull/531))
*   两个单独的 Cloudflare 适配器已合并为一：`adapter-cloudflare` (**adapter-cloudflare@7.0.0**, [#13634](https://github.com/sveltejs/kit/pull/13634))
*   `adapter-vercel`现在将为每条路由创建符号链接函数，以提高可观察性（*adapter-vercel@5.7.0**，[#13679](https://github.com/sveltejs/kit/pull/13679)）

Sveltekit 中也有许多修复程序 - 包括对 `HandleServerError` 钩子的改进以使其访问 `getRequestEvent`！ （[#13666](https://github.com/sveltejs/kit/pull/13666)）

有关 Svelte、Sveltekit 及其适配器中的错误修复的完整列表，请查看它们的 changelogs [here](https://github.com/sveltejs/svelte/blob/main/packages/svelte/CHANGELOG.md) 和 [here](https://github.com/sveltejs/kit/tree/main/packages)。 对语言工具的所有新修复感兴趣？ 你可以找到它们[here](https://github.com/sveltejs/language-tools/releases)。

### 使用 svelte 构建的应用和网站 [](#Community-Showcase-Apps-Sites-built-with-Svelte)

*   [TableSlayer](https://github.com/siege-perilous/tableslayer)是一款开源软件，用于管理带数字显示器的RPG游戏（查看[Reddit](https://www.reddit.com/r/sveltejs/comments/1jnco5h/built_with_svelte_my_open_source_software_for/)上的视频演示）
*   [Iconia](https://iconia.dev/) 是一个免费的工具，它可以理解自然语言并通过著名图标库中的相关图标进行响应
*   [CMSDocs](https://cmsdocs.com/) 将您的 Google 文档转换为博客 CMS
*   [Svelte Changelog v2](https://svelte-changelog.dev/) 现已推出，是一种重新构想的方式，可让您了解 Svelte 生态系统的所有新变化
*   [Hookah UI](https://github.com/AdamShannag/hookah-ui)是水烟项目的可视化配置构建器
*   [mockiapi](https://github.com/sfeSantos/mockiapi) 是一个模拟 API 服务器，允许您定义端点、返回自定义 JSON 响应和模拟真实世界的 API 行为
*   [soarSQL](https://soarsql.com/)是一个用于Postgres，MySQL和CSVs的分析处理的SQL编辑器-由DuckDB提供支持
*   [Persona Simulator](https://personasim.fow.sh/) 通过与不同的角色聊天来帮助您练习沟通技巧
*   [Typo](https://typo.robino.dev/) 是一个基于 Web 的 Markdown 编辑器，在代码块和 TypeScript 执行中具有格式
*   [FernOS](https://github.com/mrtechtroid/fernos)是在浏览器中运行的轻量级操作系统
