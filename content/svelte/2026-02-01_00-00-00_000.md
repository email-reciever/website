本月为 Svelte 和 Sveltekit 带来了一些新功能，以及来自社区的一些新库。

此外，如果您上个月错过了它，Svelte 维护者会在 Svelte 生态系统中发布针对 5 个漏洞的补丁。 因此，请通过阅读博客文章 [CVEs affecting the Svelte ecosystem](/blog/cves-affecting-the-svelte-ecosystem) 确保您是最新的。

现在，不用多说，让我们潜入...

Svelte & Sveltekit 的新功能[](#What's-new-in-Svelte-SvelteKit)
------------------------------------------------------------------

*   为了支持允许它的更新的浏览器，你现在可以使用CSS和丰富的HTML内容（**svelte@5.47.0**、[Docs](https://developer.chrome.com/blog/a-customizable-select)、[#17429](https://github.com/sveltejs/svelte/pull/17429)）自定义`<select>`元素。
*   Svelte 的 CSS 解析器现在从 `svelte/compiler` 导出为 `parseCss`。 它是一个部分但轻量级的 CSS AST 解析器，目前在 sveltekit 中使用（**svelte@5.48.0**，[#17496](https://github.com/sveltejs/svelte/pull/17496)）
*   当使用 `customElement` 创建阴影根时，可以将 `ShadowRootInit` 对象传递到 `attachShadow()` (**svelte@5.49.0**, [Docs](/docs/svelte/custom-elements#Component-options), [#17088](https://github.com/sveltejs/svelte/pull/17088))
*   Sveltekit 的远程功能的突破性变化从实验远程表单函数中删除了 `buttonProps`。 改为创建多个提交按钮时使用 `<button {...myForm.fields.action.as('submit', 'register')}>Register</button>` （**kit@2.50.0**、[Docs](/docs/kit/remote-functions#form-Multiple-submit-buttons)、[#15144](https://github.com/sveltejs/kit/pull/15144)）
*   Node：服务器的 `keepAliveTimeout` 和 `headersTimeout` 选项现在可以通过设置相应的环境变量 (**sveltejs/adapter-node@5.5.0**, [Docs](/docs/kit/adapter-node#Environment-variables-KEEP_ALIVE_TIMEOUT-and-HEADERS_TIMEOUT), [#15125](https://github.com/sveltejs/kit/pull/15125)) 来配置
*   Vercel：远程函数调用现在可以在 Observability 的 /\_app/remote 路由下找到（**sveltejs/adapter-vercel@6.3.1**，[#15098](https://github.com/sveltejs/kit/pull/15098)）

有关更改的完整列表（包括本月发布的所有重要错误修正），请查看 svelte 编译器的 [CHANGELOG](https://github.com/sveltejs/svelte/blob/main/packages/svelte/CHANGELOG.md) 和 sveltekit / 适配器 [CHANGELOGs](https://github.com/sveltejs/kit/tree/main/packages)。

### 使用 svelte 构建的应用和网站 [](#Community-Showcase-Apps-Sites-built-with-Svelte)

*   [Frame](https://getframe.vercel.app/) 是基于 Tauri V2 框架构建的高性能媒体转换实用程序。 它为 FFmpeg 操作提供了一个本机接口，允许对视频和音频转码参数进行精细控制
*   [LogTide](https://logtide.dev/) 是 Datadog、Splunk 和 Elk 的开源替代方案。 专为需要 GDPR 合规性、数据所有权和简单性的开发人员和欧洲中小企业而设计，无需管理 Elasticsearch 集群的复杂性
*   [funcalling](https://www.funcalling.com/)是一款P2P通话应用，内置棋盘游戏、文字游戏和动作捕捉游戏（[Reddit post](https://www.reddit.com/r/sveltejs/comments/1qgrq2c/i_built_a_p2p_calling_app_with_built_in_board/)包含视频演示）
*   [book by book](https://bookbybook.app/) 可让您在几秒钟内将图书数据、封面和定价同步到方形 POS。 您可以从 Ingram、Edelweiss 和 Pubeasy 导入分销商订单——无需电子表格或手动输入
*   [zsweep](https://zsweep.com/)是一款极简主义的键盘驱动的扫雷游戏，使用Vim Motions进行
*   [PulseKit](https://trypulsekit.com/) 提供专业的反馈管理，以收集并确定客户反馈的优先级
*   [Bitphase](https://bitphase.app/) 是一款现代化的基于 Web 的 ChipTune 追踪器，专为在复古音响芯片上创作音乐而设计
*   [CapCheck](https://capcheck.ai/) 是图像、视频、音频、文本和 URL 的事实核查器 AI
*   [Distill](https://www.distillintelligence.com/competitor-finder)（最后一次提到在 7 月）已更新为新的竞争对手 Finder，以更轻松地跟踪市场中的直接和间接竞争对手
*   [Pelican](https://pelican.alexey.work/) 允许您从文本提示生成 SVG 矢量图形和 ASCII 艺术。 通过多步改进，AI 看到其输出并迭代地改进它

### 图书馆、工具和组件[](#Community-Showcase-Libraries-Tools-Components)

_UI 组件和动画

*   [mapcn-svelte](https://github.com/MariusLang/mapcn-svelte) 是基于 MapLibre GL 的 MapCN 的 Svelte 端口，采用 Tailwind 样式，与 shadcn-svelte 无缝配合
*   [AgnosticUI Local (v2)](https://github.com/AgnosticUI/agnosticui) 是一个基于 CLI 的 UI 组件库，可将 Lit 的 Web 组件直接复制到您的项目中
*   [Motion Core](https://github.com/motion-core/motion-core) 是 GSAP 和 3.js 支持的动画 Svelte 组件的集合
*   [Tilt Svelte](https://github.com/Savy011/tilt-svelte) 是基于 vanilla-tilt.js 的平滑 3D 倾斜 svelte 附件

_状态管理_

*   [Reddo.js](https://github.com/eihabkhan/reddojs) 是一个用于 JavaScript、React、Vue 和 Svelte 的小型 Undo/Redo 实用程序包
*   [svstate](https://github.com/BCsabaEngine/svstate) 为复杂的真实应用提供了验证、快照/撤消和副作用的深度反应代理
*   [rune-sync](https://github.com/antepodeum/rune-sync) 同步各种存储后端的反应状态

_plugins、编译器和运行时_

*   [fastify-svelte-view](https://github.com/matths/fastify-svelte-view)是一个fastify插件，用于渲染支持SSR（服务器端渲染）、CSR（客户端渲染）和带有水性的SSR的svelte组件
*   [kit-on-lambda](https://github.com/beesolve/kit-on-lambda) 是在 AWS Lambda 上运行 sveltekit 的适配器。 它支持部署到与 esbuild/bun 捆绑的 Node.js 和 BUN 运行时
*   [voca](https://github.com/treyorr/voca) 是一个用前端SDK编写的自托管、无状态和快速的WebRTC信号服务器
*   [@svelte-safe-html/core](https://github.com/patel-vansh/svelte-safe-html-core) 静态分析 `.svelte` 文件并检测不安全 `{@html}` 插入
*   [sveltekit-discriminated-fields](https://www.npmjs.com/package/sveltekit-discriminated-fields) 为 Sveltekit 远程功能表单字段提供类型安全的歧视联合支持
*   [svelte-fast-check](https://github.com/astralhpi/svelte-fast-check) 是一种类型和 svelte 编译器警告检查器，适用于 svelte/sveltekit 项目，声称比内置的 svelte-check 快 24 倍
