本月，我们看到了 Sveltekit 及其文档的许多贡献。 语言工具还具有一些新功能，最明显的是与 JavaScript 或 TypeScript 文件中的 svelte 文件的更深入集成。 让我们跳入更新中...

Sveltekit 中的新功能[](#New-in-SvelteKit)
-----------------------------------

*   `svelte.config.js` 配置文件现在以 ESM 格式加载（`.js` 而不是 `.cjs`）。
*   AMP 页面现在将使用渲染的 CSS，而不是发出的 CSS
*   `svelte-check` 已添加到打字稿模板 ([sveltejs/kit#1556](https://github.com/sveltejs/kit/pull/1556))
*   支持 HTTPS 密钥对 [sveltejs/kit#1456](https://github.com/sveltejs/kit/pull/1456)
*   现在将 Vite 与 Sveltekit 捆绑并使用升级版本。 如果存在，请从 `package.json` 中删除 Vite
*   二进制响应的 ETags [sveltejs/kit#1382](https://github.com/sveltejs/kit/pull/1382)
*   将`$layout`改为`__layout`，将`$error`改为`__error`
*   移除 `getContext` 支持 `request.locals`
*   将 `.svelte` 输出目录重命名为 `.svelte-kit`。 相应地更新您的 `.gitignore`
*   `trailingSlash: 'never' | 'always' | 'ignore'` 现在在配置中可用。 这应该可以更轻松地构建与静态托管服务提供商一起使用的站点，这些提供程序期望 `index.html` 页面有尾随斜杠，并为需要更复杂行为的任何人提供逃生舱口。

sveltekit[](#Notable-bug-fixes-in-SvelteKit)中值得注意的错误修复
--------------------------------------------------------------

*   `adapter-netlify`在README [https://github.com/sveltejs/kit/tree/master/packages/adapter-netlify](https://github.com/sveltejs/kit/tree/master/packages/adapter-netlify)中获得了修复[sveltejs/kit#1467](https://github.com/sveltejs/kit/pull/1467)和新文档
*   路由器将不再拦截应用程序不拥有的 URL 的导航。 这可以修复页面上具有相同来源的`<a>`元素但不与应用共享基本路径的应用程序的崩溃。
*   在某些情况下，路由器在哈希更改之间修复了浏览器的“后退”导航，现在只处理哈希更改。

Svelte 和语言工具的新功能[](#New-in-Svelte-Language-Tools)
-----------------------------------------------------------

*   Svelte 3.38.1 和 3.38.2 修复了导致重复元素的水合问题。 如果您在项目中看到了这一点，请务必更新最新版本！
*   新的 TypeScript 插件提供了与 JavaScript 或 TypeScript 文件中的 svelte 文件的更深入集成。 这包括变量的诊断、引用和重命名。 它带有VS代码扩展名，但目前默认关闭。 您可以通过 [this setting](https://github.com/sveltejs/language-tools/tree/master/packages/svelte-vscode#svelteenable-ts-plugin) 启用它。 我们鼓励您测试它和 [provide feedback](https://github.com/sveltejs/language-tools/issues/580)
*   在 `svelte-check` 的最新版本中，您现在可以提供 `tsconfig.json` 或 `jsconfig.json` 的路径。 示例：`svelte-check --tsconfig "./tsconfig.json"`。 这确保了诊断仅在该配置中引用的文件上运行。 它还在 JavaScript 和/或 TypeScript 文件上运行诊断程序，从而无需对非 Svelte 文件（`svelte-check` 版本 [**1.6.0**](https://github.com/sveltejs/language-tools/releases/tag/svelte-check-1.6.0)）运行另一个检查（如 `tsc --noEmit`）。
*   VS Code 扩展和 `svelte-check` 获得了新的主要版本。 以前，只有当用户同时使用 TypeScript 和激活的 `strict` 模式时，才需要没有初始化器 (`export let foo;`) 的属性。 现在改变了：使用 TypeScript 的人，以及在 JavaScript 文件中使用 `checkJs` 的人，现在将始终将这些属性标记为需要（`svelte-check` 版本 [**2.0.0**](https://github.com/sveltejs/language-tools/releases/tag/svelte-check-2.0.0)，扩展版本 [**105.0.0**](https://github.com/sveltejs/language-tools/releases/tag/extensions-105.0.0)）

### 应用和网站[](#Community-Showcase-Apps-Sites)

*   [vidu](https://github.com/pa-nic/vidu) 是一个最小的 Web 分析收集器和仪表板
*   [River Runner](https://river-runner.samlearner.com/) 是跟随河流下游的虚拟方式——用 Mapbox 和 Svelte 构建。
*   [JSDoc Type Generator](https://rafistrauss.github.io/jsdoc-generator/) 为有效 JSON 生成 JSDOC 类型。
*   [pagereview.io](https://pagereview.io/) 是一个网站反馈工具，可让您直接对正在审查的网站发表评论。
*   [gamesroom.io](https://gamesroom.io/)是内置视频聊天的在线棋盘游戏平台。
*   [Greedy Goblin](https://greedygoblin-fe11c.web.app/) 是老式 Runescape 玩家的食谱应用程序。
*   [hashbrown.geopjr.dev](https://hashbrown.geopjr.dev/) 是一个受 Gnome-shell 启发的网页，可了解、探索源代码和下载 Hashbrown GTK 应用程序 ([link to source](https://github.com/GeopJr/Hashbrown/tree/website))。

### 图书馆、工具和组件[](#Community-Showcase-Libraries-Tools-Components)

*   [svelte-image-crop](https://novacbn.github.io/svelte-image-crop/) 是一个简单的 click'n'Drag 图像裁剪库，使用 Web API。
*   [svelte-datepicker](https://github.com/andrew-secret/svelte-datepicker) 是一款轻巧且包容的日期选择器，具有 Svelte 的功能。
*   [svelte-regex-router](https://www.npmjs.com/package/svelte-regex-router) 是一个简单、轻量级的库，可让您轻松处理 Svelte 应用程序中的路由。
*   [Svelte Micro](https://www.npmjs.com/package/svelte-micro) 是一种轻型和反应式单组件路由器，适用于 Svelte。
*   [svelte-entity-store](https://www.npmjs.com/package/svelte-entity-store) 是提供一个简单的通用解决方案来存储实体对象的集合。
*   [svelte-animation-store](https://github.com/joshnuss/svelte-animation-store) 是一家基于 Svelte 的补间商店的商店，可让您暂停、继续、重置、重播、反转或调整补间的速度。
