从新的语法到改进的开发工具，Svelte 团队这个月一直忙于在 Svelte 和 SvelteKit 中构建新的功能。随着我们步入新的一年，还有更多值得期待的东西……比如 *10th Svelte Summit*！[加入 Svelte 社区](https://www.sveltesummit.com/)，可以在线参加或亲自前往巴塞罗那参加：5月8日和9日。

现在让我们看看新闻 👀

## Svelte 中的新功能[](#What's-new-in-Svelte)

* 代码片段现在可以从模块脚本中导出（**5.5.0**，[Docs](/docs/svelte/snippet#Exporting-snippets)，[#14315](https://github.com/sveltejs/svelte/pull/14315)）
* `defaultValue` 和 `defaultChecked` 现在支持输入元素（**5.6.0**，[Docs](https://developer.mozilla.org/en-US/docs/Web/API/HTMLInputElement/defaultChecked)，[#14289](https://github.com/sveltejs/svelte/pull/14289)）
* 宽松解析器模式为开发者工具创建了更现代的 AST（**5.13.0**，[Docs](/docs/svelte/svelte-compiler#parse)，[#14691](https://github.com/sveltejs/svelte/pull/14691)）
* 新的“worker”导出条件有助于更好地支持基于 worker 的环境的打包（**5.15.0**，[#14779](https://github.com/sveltejs/svelte/pull/14779)）
* `class` 属性现在可以是对象或数组，使用 `clsx`（**5.16.0**，[Docs](/docs/svelte/class#Attributes-Objects-and-arrays)，[#14714](https://github.com/sveltejs/svelte/pull/14714)）

*新/更新语法*

* `<svelte:boundary>` 是一个新的特殊元素，可以捕获客户端渲染过程中其子树内发生的错误 (**5.3.0**, [Docs](/docs/svelte/svelte-boundary), [#14211](https://github.com/sveltejs/svelte/pull/14211))
* `\#each` 现在支持不使用 `as` (**5.4.0**, [Docs](/docs/svelte/each), [#14396](https://github.com/sveltejs/svelte/pull/14396))
* `svelte/motion` 中新的 `Spring` 和 `Tween` 类使得构建自定义动画更加容易 (**5.8.0**, [Docs](/docs/svelte/svelte-motion), [#11519](https://github.com/sveltejs/svelte/pull/11519))
* `unmount` 中新的 `outro` 选项将在组件从 DOM 中移除之前播放过渡效果 (**5.13.0**, [Docs](/docs/svelte/svelte#unmount), [#14540](https://github.com/sveltejs/svelte/pull/14540))
* `$inspect.trace` 符号会导致周围的函数在开发过程中被追踪。每当函数作为效果或派生的一部分重新运行时，控制台将打印有关哪些反应性状态导致效果触发的信息 (**5.14.0**, [Docs](/docs/svelte/$inspect#$inspect.trace\(\)), [#14290](https://github.com/sveltejs/svelte/pull/14290))

*反应性 API*

* `createSubscriber` 创建依赖于订阅的响应式值 (**5.7.0**, [Docs](/docs/svelte/svelte-reactivity#createSubscriber), [#14422](https://github.com/sveltejs/svelte/pull/14422))
* 响应式的 `MediaQuery` 类创建一个媒体查询，并提供一个当前属性，反映是否匹配 (**5.7.0**, [Docs](/docs/svelte/svelte-reactivity#MediaQuery), [#14422](https://github.com/sveltejs/svelte/pull/14422))
* 获取器和设置器现在可以使用 `bind` 绑定 (**5.9.0**, [Docs](/docs/svelte/bind), [#14307](https://github.com/sveltejs/svelte/pull/14307))
* `svelte/reactivity/window` 模块导出各种 `window` 值的响应式版本，每个值都有一个可以在响应式上下文中引用的响应式当前属性 (**5.11.0**, [Docs](/docs/svelte/svelte-reactivity-window), [#14660](https://github.com/sveltejs/svelte/pull/14660))

## SvelteKit、Svelte CLI 和语言工具的新功能[](#What's-new-in-SvelteKit-Svelte-CLI-and-Language-Tools)

* 新的 `init` hook 在服务器创建或应用在浏览器中启动时运行一次，是一个有用的异步工作位置，例如初始化数据库连接 (**2.10.0**, [Docs](/docs/kit/hooks#init), [#13103](https://github.com/sveltejs/kit/pull/13103))
* 新的 [`transport`](/docs/kit/@sveltejs-kit-hooks#Transport) hook 允许您在服务器/客户端边界上编码/序列化和解码/反序列化自定义的非 POJOs (**2.11.0**, [#13149](https://github.com/sveltejs/kit/pull/13149))
* 新的 `$app/state` 模块替换了现有的 `$app/stores` 模块，但使用 Svelte 5 状态。CLI/language 工具中的 `migrate` 工具已更新以匹配 (**2.12.0**, [Docs](/docs/kit/$app-state), [#13140](https://github.com/sveltejs/kit/pull/13140))
* `bundleStrategy` 允许您在 JS 和 CSS 文件中选择 `'split'`、`'single'` 和 `'inline'` 输出选项 (**2.13.0** 和 **2.15.0**, [Docs](/docs/kit/configuration#output), [#13173](https://github.com/sveltejs/kit/pull/13191) 和 [#13193](https://github.com/sveltejs/kit/pull/13193))
* 新的 `sveltekit-adapter` 添加到 Svelte CLI (`sv`) 中，安装并替换现有的 SvelteKit 适配器 ([Docs](/docs/cli/sv-add), [#346](https://github.com/sveltejs/cli/pull/346))
* 语言工具扩展现在将使用松散的 Svelte 解析器并提供更好的 intellisense (**109.4.0**, [#2631](https://github.com/sveltejs/language-tools/pull/2631))

*适配器更新*

* `adapter-auto` 已添加对 bun 语言服务器的支持 (**3.3.0**, [#12854](https://github.com/sveltejs/kit/pull/12854))
* `adapter-cloudflare-workers` 现在支持 `wrangler.json` 配置文件 (**2.7.0**, [#13151](https://github.com/sveltejs/kit/pull/13151))
* `adapter-cloudflare` 将为 Cloudflare Workers Static Assets 生成一个 `.assetsignore` 文件 (**4.9.0**, [#13109](https://github.com/sveltejs/kit/pull/13109))

### 库、工具和组件[](#Community-Showcase-Libraries-Tools-Components)

* [Svelte 文档](/content.json) 现在以 LLM 友好格式提供（感谢 Stanislav Khromov 为 [svelte-llm](https://svelte-llm.khromov.se/) 做出的贡献）
* [svelte-mainloop](https://github.com/retrotheft/svelte-mainloop) 是 MainLoop.js 的一个包装器，处理函数注册和清理，并允许您使用单个组件加入和离开循环（[Reddit](https://www.reddit.com/r/sveltejs/comments/1hfto6y/sveltemainloop_the_easiest_way_to_add_a_loop_to/))
* [bsky-comments-svelte](https://github.com/nsarrazin/bsky-comments-svelte/) 是一个简单的可定制组件，用于在您的网站中添加评论，使用 Bluesky
* [Svelte Mini Router](https://github.com/rodrigocfd/svelte-mini-router) 是一个声明式的、最小化的单页应用路由器，适用于 Svelte 5，不需要 SvelteKit
* [svelte-firebase-state](https://github.com/pierregoutheraud/svelte-firebase-state) 通过提供易于使用的反应状态类来简化 Svelte/Sveltekit 应用中的 Firebase 集成，用于管理 Firestore 和实时数据库数据
* [monoco-svelte](https://github.com/monokai/monoco-svelte) 允许您为 Svelte 组件创建自定义（squircle）角和边框
* [svelte-audio-waveform](https://github.com/Catsvilles/svelte-audio-waveform) 将峰值数据数组转换为美丽的、可定制的波形，适用于音乐播放器、播客、音频编辑工具等
* [Svader](https://github.com/sockmaster27/svader) 使用 WebGL 和 WebGPU 片段着色器创建 GPU 渲染的 Svelte 组件
