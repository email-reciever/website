欢迎来到我们的“Svelte 新增功能”系列的第一版！ 我们将尝试将其作为每月的博客文章，您将在其中找到有关新功能、错误修复和社区周围 svelte 项目的展示。

新功能[](#New-features)
-----------------------------

1.  `use:obj.method` 允许在动作中使用定义的函数（[Example](/playground/c305722adb4a4545b27b198ea8ff9bde?version=3.27.0)，**3.26.0**，在 **3.27.0** 中删除的警告）
2.  `_` 现在支持作为“数字分隔符”，类似于 `.` 或 `,` ([Example](/playground/844c39e91d1248649fe54af839fab570?version=3.26.0), **3.26.0**)
3.  `import.meta`现在在模板表达式中工作（[Example](/playground/9630de41957a4c80a4fce264360a6bc7?version=3.26.0)，**3.26.0**）
4.  CSS选择器现在支持`~`和`+`组合器（[Example](/playground/91ad9257d2d1430185a504a18cc60172?version=3.29.0)，**3.27.0**，编译器修复**3.29.0**）
5.  现在，`{#key}` 块可用于表达式上的任意关键任意内容。 每当表达式发生变化时，`{#key}` 块内的内容将被销毁并重新创建。 如需深入解释并了解它是如何实施的，请查看 Svelte 团队成员 Tan Li Hau 的 [new blog post](https://lihautan.com/contributing-to-svelte-implement-key-block/)。 （[More info](https://github.com/sveltejs/svelte/issues/1469)，**3.29.0**）
6.  现在可以通过子组件转发插槽！ 这过去只能通过添加额外的包装器 `<div>`s ([More info](https://github.com/sveltejs/svelte/issues/2079), **3.29.0**)
7.  使用 TypeScript 时，您现在可以键入 `createEventDispatcher` 方法：

    <script lang="ts">
从“svelte”导入 { createEventDispatcher }；
    
常量调度 = CreateEventDispatcher<{
/**
    		 * 您也可以添加文档
*/
选中：布尔值； // 将转换为 `CustomEvent<boolean>`
你好：字符串；
}>();
    
// ...
    </script>

这将确保您只能使用指定的事件名称及其类型调用 dispatch。 还更新了 Svelte for VS Code 扩展以处理此新功能。 它将为这些事件以及自动完成和悬停信息提供强大的类型。

### Sapper![](#New-features-New-from-Sapper)的新功能

Sapper 0.28.9 刚刚问世。 它的亮点包括对 CSP nonces 的更好支持、对导出页面的资产预加载支持以及错误详细信息现在在错误页面的 `$page` 存储中提供。

此外，Sapper 的 CSS 处理在最近发布的过程中进行了重写，以修复现有的 CSS 处理错误，将 CSS 处理重构为完全在 Rollup 插件中进行，并在内部消除在路由系统中注册 CSS 的需要。 恭喜并感谢为 Sapper 工作的人们所做的一切扎实的工作！

有影响力的错误修复[](#Impactful-bug-fixes)
-----------------------------------------

*   CSS 编译将不再删除 `<details>` 元素上 `open` 属性的规则 ([Example](/playground/ab4c0c177d1f4fab92f46eb8539cea9a?version=3.26.0), **3.26.0**)
*   `prettier-plugin-svelte` 现在在处理空格方面做得更好，尤其是在内联元素周围。 它还将保留 `<pre>` 标签中的格式，并且不再格式化 Prettier 不支持的语言，例如 Sass、Pug 或 Stylus。
