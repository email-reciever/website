CSS 是任何 Web 应用程序的核心部分。 通过扩展，没有内置方式向组件添加样式的 UI 框架尚未完成。

这就是为什么 Svelte 允许您在组件的 `<style>` 标记中添加 CSS。 将您的 CSS 与您的标记共同定位意味着我们可以 [solve the biggest problems developers face when writing CSS](/blog/the-zen-of-just-writing-css) 不引入新的，同时提供相当不错的开发体验。

但 Svelte 的风格处理确实有一些限制。 在组件之间共享样式或应用应用级优化太困难。 这些是我们计划在未来版本中解决的领域，但与此同时，如果您需要这些内容，您可以使用任何与框架无关的 css-in-js 库。

需要注意的是，大多数 CSS-in-JS 库都有一个运行时库，而且许多库不支持在构建时将样式静态提取到单独的 `.css` 文件中（这对于获得最佳性能至关重要）。 因此，如果您的应用程序需要，您应该仅使用 CSS-in-JS！

请注意，您可以混合和匹配 - 您仍然可以在 CSS-in-JS 库中使用 Svelte 的内置 CSS 处理。
