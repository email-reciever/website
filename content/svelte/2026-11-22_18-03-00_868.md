本月，我们在 Svelte、SvelteKit 和甚至 Svelte CLI 中获得了大量新功能。另外，[State of JS 2025](https://2025.stateofjs.com/en-US) 已经发布，Svelte 在反应式框架中继续保持最高的正面情绪评分。

那么，不再多说，让我们深入探讨！

## Svelte 中的新功能[](#What's-new-in-Svelte)

* `createContext` 现在可以在程序化实例化组件时使用 (**svelte@5.50.0**, [Docs](/docs/svelte/context), [#17575](https://github.com/sveltejs/svelte/pull/17575))
* `{@html}` 表达式现在支持 `TrustedHTML` (**svelte@5.52.0**, [#17701](https://github.com/sveltejs/svelte/pull/17701))
* 现在允许在 HTML 标签中使用注释 (**svelte@5.53.0/svelte-language-server@0.17.28**, [#17671](https://github.com/sveltejs/svelte/pull/17671))
* 错误边界现在可以在服务器上工作 (**svelte@5.53.0**, [Docs](/docs/svelte/svelte-boundary#Using-transformError), [#17672](https://github.com/sveltejs/svelte/pull/17672))

为了获取完整的变更列表，包括本月发布中包含的所有重要 bug 修复，请查看 Svelte 编译器的 [CHANGELOG](https://github.com/sveltejs/svelte/blob/main/packages/svelte/CHANGELOG.md)

## SvelteKit 中的新功能[](#What's-new-in-SvelteKit)

* `hydratable` 的注入脚本现在支持 CSP (**kit@2.51.0**, [#15048](https://github.com/sveltejs/kit/pull/15048))
* 导航回调（beforeNavigate、onNavigate 和 afterNavigate）现在包括滚动位置信息，通过 `from` 和 `to` 目标上的 `scroll` 属性提供。这使得可以使用浏览器的后退/前进导航来实现基于目标滚动位置的过渡动画 (**kit@2.51.0**, [Docs](/docs/kit/$app-navigation#NavigationTarget), [#15248](https://github.com/sveltejs/kit/pull/15248))
* 现在支持 Vite 8 (**kit@2.53.0**, [#15024](https://github.com/sveltejs/kit/pull/15024))
* `match` 函数可以将路径映射回路由 ID 和参数 (**kit@2.52.0**, [Docs](/docs/kit/$app-paths#match), [#14997](https://github.com/sveltejs/kit/pull/14997))
* Breaking（Netlify Adapter）：`platform.context` 现在使用现代 Netlify Functions - 之前这是 AWS Lambda 风格的上下文。如果你在应用程序中使用了这个（不太可能），你需要更新代码来读取新的字段。 (**adapter-netlify@6.0.0**, [More details](https://docs.netlify.com/build/functions/api/#netlify-specific-context-object), [Docs](https://developers.netlify.com/guides/migrating-to-the-modern-netlify-functions/), [#15203](https://github.com/sveltejs/kit/pull/15203))
* 现在可以在 `netlify.toml` 中配置重定向 - 删除了只能通过 `_redirects` 文件配置重定向的限制 (**adapter-netlify@6.0.0**, [#15203](https://github.com/sveltejs/kit/pull/15203))
* `better-auth` 现在是 Svelte CLI 中的官方插件 (**sv@0.12.0**, [#898](https://github.com/sveltejs/cli/pull/898))

正在寻找本月许多错误修复和性能优化的更多详细信息？查看 SvelteKit / Adapter [CHANGELOGs](https://github.com/sveltejs/kit/tree/main/packages)。
