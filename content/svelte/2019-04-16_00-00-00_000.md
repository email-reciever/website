这本简短的指南旨在帮助您——那些看过 [tutorial](/tutorial) 并希望开始创建 Svelte 应用程序但没有大量使用 JavaScript 构建工具的经验的人——启动和运行。

如果有些事情没有意义，或者我们正在掩饰，请随时 [raise an issue](https://github.com/sveltejs/svelte/issues) 或 [suggest edits to this page](https://github.com/sveltejs/svelte/blob/master/site/content/blog/2019-04-16-svelte-for-new-developers.md) 帮助我们帮助更多的人。

如果您在本指南中的任何时候卡住了，寻求帮助的最佳位置是 [chatroom](/chat)。

第一件事首先[](#First-things-first)
----------------------------------------

您将使用_command line_，也称为终端。 在 Windows 上，您可以通过从开始菜单运行 **Command Prompt** 来访问它； 在 Mac 上，同时点击 `Cmd` 和 `Space` 以调出 **Spotlight**，然后开始键入 `Terminal.app`。 在大多数 Linux 系统上，`Ctrl-Alt-T` 会启动命令行。

命令行是一种与您的计算机（或另一台计算机！但这是另一个话题）交互的方式，比大多数人日常使用的 GUI（图形用户界面）更强大和控制。

进入命令行后，您可以使用 `ls`（Windows 上的 `dir`）导航文件系统以列出当前目录的内容，并 `cd` 更改当前目录。 例如，如果您的主目录中有一个项目的 `Development` 目录，您将键入

光盘开发

去它。 从那里，您可以使用 `mkdir` 命令创建一个新的项目目录：

mkdir svelte 项目
CD svelte 项目

对命令行的完整介绍超出了本指南的范围，但这里有一些更有用的命令：

*   `cd ..` — 导航到当前目录的父级
*   `cat my-file.txt` — 在 Mac/Linux 上（`type my-file.txt` 在 Windows 上），列出 `my-file.txt` 的内容
*   `open .`（或 Windows 上的 `start .`） — 在 Finder 或文件资源管理器中打开当前目录

安装 node.js[](#Installing-Node.js)
----------------------------------------

[Node](https://nodejs.org/en/) 是一种在命令行上运行 JavaScript 的方法。 它被许多工具使用，包括 Svelte。 如果您还没有安装它，最简单的方法是直接从 [website](https://nodejs.org/en/) 下载最新版本。

安装后，您将可以访问三个新命令：

*   `node my-file.js` — 在 `my-file.js` 中运行 JavaScript
*   `npm [subcommand]` — [npm](https://www.npmjs.com/) 是一种安装应用程序所依赖的“包”的方法，例如 [svelte](https://www.npmjs.com/package/svelte) 包
*   `npx [subcommand]` — 一种在 npm 上运行可用程序的便捷方式，而无需永久安装它们

安装文本编辑器[](#Installing-a-text-editor)
-------------------------------------------------

要编写代码，您需要一个好的编辑器。 最流行的选择是 [Visual Studio Code](https://code.visualstudio.com/) 或 VSCode，这是有道理的——它设计精良且功能齐全，并且具有丰富的扩展（[including one for Svelte](https://marketplace.visualstudio.com/items?itemName=svelte.svelte-vscode)，它在您编写组件时提供语法突出显示和诊断消息）。

创建项目[](#Creating-a-project)
----------------------------------------

我们将使用 [Svelte + Vite](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-svelte) 模板。 您不必使用项目模板，但这意味着您必须少做很多设置工作。

在命令行中，导航到您要创建新项目的位置，然后键入以下行（您可以粘贴整个批次，但如果您养成了一次将每行写出一行然后运行它的习惯，您将获得更好的肌肉记忆）：

npm create vite@latest my-svelte-project ----template svelte
cd my-svelte-project
npm 安装

> 如果您喜欢打字稿，您可以将 `--template svelte` 替换为 `--template svelte-ts`。

这将创建一个新目录，`my-svelte-project`，从 [create-vite/template-svelte](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-svelte) 模板中添加文件，并从 npm 安装多个软件包。 在文本编辑器中打开目录并环顾四周。 该应用程序的“源代码”位于 `src` 目录中，而您的应用程序可以加载的文件位于 `public` 中。

在 `package.json` 文件中，有一个名为 `"scripts"` 的部分。 这些脚本定义了处理应用程序的快捷方式 — `dev`、`build` 和 `preview`。 要在开发模式下启动应用，请键入以下内容：

npm 运行开发人员

运行 `dev` 脚本启动一个名为 [Vite](https://vitejs.dev/) 的程序。 Vite 的工作是获取应用程序的源文件，将它们传递给其他程序（包括 Svelte，在我们的例子中），并将它们转换为在浏览器中打开应用程序时实际运行的代码。

说到这，打开浏览器并导航到 [http://localhost:5173](http://localhost:5173)。 这是您的应用程序在本地 _web 服务器_（因此“localhost”）上运行在端口 5173。

尝试更改 `src/App.svelte` 并保存它。 该应用程序将随您的更改而更新。

构建您的应用程序[](#Building-your-app)
--------------------------------------

在最后一步，我们以“开发模式”运行该应用程序。 在开发模式下，Svelte 添加了有助于调试的额外代码，而 Vite 会跳过压缩应用程序 JavaScript 的最后一步。

当您与世界共享您的应用程序时，您希望在“生产模式”中构建它，以便最终用户尽可能小而高效。 为此，请使用 `build` 命令：

npm 运行构建

您的 `dist` 目录现在包含应用的优化版本。 你可以像这样运行它：

npm 运行预览
