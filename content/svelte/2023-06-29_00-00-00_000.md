四年前发布Svelte V3的初始版本时，它包含了人们熟悉的单页文档。 该文档结构与 Svelte 的 API 表面稳步增长并添加了更多细节相同。 结果，单页变得越来越大，以至于很难找到东西。 社区一直在要求改造，现在它就在这里！

认识新的 svelte.dev — 对旧网站的全面改革。

多页文档[](#Multi-page-docs)
---------------------------------

目录已经变得非常大，您必须滚动到六个屏幕上才能看到整个内容。 我们听到了！ 文档现在都被分成多个页面，所有页面都在右侧边栏中列出了它们的部分。

svelte 暴露的所有模块也列在 `Runtime` 部分的侧边栏中：

*   [svelte](/docs/svelte)
*   [svelte/store](/docs/svelte-store)
*   [svelte/motion](/docs/svelte-motion)
*   [svelte/transition](/docs/svelte-transition)
*   [svelte/animate](/docs/svelte-animate)
*   [svelte/easing](/docs/svelte-easing)
*   [svelte/action](/docs/svelte-action)

> [svelte/compiler](/docs/svelte-compiler) 位于 **编译器和 API** 部分

我们还特别注意确保旧网站的所有链接都将被重定向到正确的新页面。

搜索[](#Search)
------------------

缺乏搜索功能可能会使查找内容变得麻烦，因为 Ctrl+F 仅按发生顺序返回结果而不是重要性顺序。 虽然 Ctrl+F 确实有它的好处，例如不需要 JS，但现在该网站有多个页面，它不再是一个选项。

为此，新网站带有一个搜索栏，可以搜索文档和 API 表面。 点击 Ctrl+K（或 Mac 用户的 Cmd+K）并开始搜索——它甚至可以在没有 JavaScript 的情况下工作！

灯光，打字稿，动作![](#Lights-TypeScript-Action)
----------------------------------------------------

新网站带有 JavaScript / TypeScript 切换功能，因此您可以查看喜欢的文档。 页面底部列出了每个模块的导出类型，以便于参考。 这些类型是从 Svelte 的源代码自动生成的，因此它们始终是最新的。

所有 JavaScript 和 TypeScript 代码段都有可用的类型提示。 只需将鼠标悬停在变量上即可查看其类型。 这允许在构建时对文档进行类型检查，从而确保它们永远不会过时。

我们还（终于！）添加了 [Actions](/docs/svelte-action) 的文档。 Svelte 操作是与 DOM 交互的一种方式，是为应用添加交互性的好方法。 TypeScript 中也提供了用于操作的文档。

暗模式[](#Dark-mode)
------------------------

经过多年的用户在网站上要求黑暗模式以便他们可以阅读他们的夜间编码会话的文档之后，我们终于添加了它！ 该网站现在有一个深色模式切换，它也与您的操作系统的暗模式设置同步。 它可以从顶部导航栏（移动设备底部导航栏）切换。

更新的REPL[](#Updated-REPL)
-----------------------------

REPL 已从头开始重写为完全类型安全，并具有深色模式等功能。 它被重新实现升级到 CodeMirror 6，它具有许多可访问性改进、多选择模式、性能改进、树木震动和更多功能。

重新设计的主页[](#Redesigned-homepage)
-----------------------------------------

如果主页没有得到同样数量的爱，它是重新设计的网站吗？ 🙃

主页也已更新以与 [kit.svelte.dev](https://kit.svelte.dev) 对齐，并具有 [@vedam](https://github.com/vedam) 的精美 Svelte 机器。

底部导航![](#Bottom-navigation)
---------------------------------------

我们发送了一个[tweet](https://twitter.com/Rich_Harris/status/1664712880791404546)关于在移动设备而不是传统的顶部导航栏上尝试底部导航栏。 反应非常积极，所以我们继续添加它！ 这使得只需一只手在移动设备上浏览网站变得更加容易。 我们还确保您通过尽可能少的互动到达您想要的地方。 如果您在网站的文档部分，您可能希望浏览其他文档页面，这就是为什么在打开它时默认显示这些页面的原因将显示这些页面，并选择转到常规站点导航一级。

如果您在移动设备上，您已经可以在底部看到它。 如果您在桌面上，您可以通过将浏览器窗口大小调整为较小的大小来查看它。

svelte网站的统一[](#Unification-of-Svelte-websites)
--------------------------------------------------------------

现在 svelte.dev、[kit.svelte.dev](https://kit.svelte.dev) 和 [learn.svelte.dev](https://learn.svelte.dev) 都使用相同的设计系统，并且彼此更加一致。 这使得在网站之间导航更容易，也使维护它们变得更容易。 我们在网站上共享了一个名为 `@sveltejs/site-kit` 的软件包，该软件包在过去 4 个月中经历了严格的更改，因为我们一直将所有常用代码移入此包中。

例如，我们在 `@sveltejs/site-kit` 中实现了暗模式切换。 然后，我们只需在 [learn.svelte.dev](https://learn.svelte.dev) 和 [kit.svelte.dev](https://kit.svelte.dev) 上更新包，这些站点会自动切换到暗模式（这也是这些站点在 svelte.dev 重新启动之前获得黑暗模式切换的原因）。
