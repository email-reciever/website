自上个月以来，我们在 Svelte 和 Sveltekit 上看到了一些次要版本，这是一堆支持 1.0 版本的教育内容，以及 [State of JS survey](https://stateofjs.com) 结果...

Svelte 再次增加了满意度和兴趣，因此感谢所有投票的人！

让我们深入了解更新...

sveltekit的新增功能[](#What's-new-in-SvelteKit)
-----------------------------------------------

本月 Svelte 生态系统的工作重点是 Sveltekit 错误修复和解决 1.0 发布的反馈。 期待已久的 [bug fixes to SvelteKit’s base path support](https://github.com/sveltejs/kit/issues/2958) 之一，这意味着您现在可以在远程开发环境中创建 sveltekit 项目。 已经有几个 [new releases](https://github.com/sveltejs/kit/blob/master/packages/kit/CHANGELOG.md) 与这些修复以及一些新功能，例如：

*   当逐步增强时，提交者的价值将自动包含在内
*   如果全局fetch与相对URL（**1.0.8**，[#8370](https://github.com/sveltejs/kit/pull/8370)）一起使用，在dev模式中添加了错误
*   现在将发出警告，如果从 HTML 中删除注释，水化可能会中断 (**1.0.11**, [#8423](https://github.com/sveltejs/kit/pull/8423))
*   在 `.svelte` 文件中使用页面选项或检测到布局中缺少 `<slot />` 时会出现警告 (**1.1.0**, [#8475](https://github.com/sveltejs/kit/pull/8475))
*   新的 `text(...)` 助手使生成文本响应变得容易 (**1.2.0**, [#8371](https://github.com/sveltejs/kit/pull/8371))
*   现在可以在 app.html (**1.2.0**, [Docs](/docs/kit/project-structure#Project-files-src), [#8449](https://github.com/sveltejs/kit/pull/8449)) 中访问公共环境
*   如果 cookie 超出大小限制（**1.2.1**，[#8591](https://github.com/sveltejs/kit/pull/8591)），将引发错误
*   生成的`tsconfig`现在可以修改（**1.3.0**，[#8606](https://github.com/sveltejs/kit/pull/8606)）

svelte和语言工具的新增功能[](#What's-new-in-Svelte-and-Language-Tools)
---------------------------------------- ----------------------------------------

*   在VS Code HTML语言服务中添加了对`html.customData`的支持（**extensions-107.0.0**，[#1824](https://github.com/sveltejs/language-tools/pull/1824)）
*   需要导入的商店的自动补全 ([#1823](https://github.com/sveltejs/language-tools/pull/1823)) 和对象/类成员片段 ([#1817](https://github.com/sveltejs/language-tools/pull/1817)) 已添加到 svelte 扩展 (**extensions-107.0.0**)
*   改进对也功能的承诺的检测（**Svelte 3.55.1**，[#8162](https://github.com/sveltejs/svelte/pull/8162)）
*   分别为全局 `part` 属性和 `on:submit` 添加缺失的类型和属性 (**Svelte 3.55.1**, [#8181](https://github.com/sveltejs/svelte/issues/8181))
*   大量的性能和错误修复（**Svelte 3.55.1\***和**extensions-107.0.x**）

\*对于 svelte 编译器的所有更改，包括未发布的更改，请查看 [CHANGELOG](https://github.com/sveltejs/svelte/blob/master/CHANGELOG.md)。
