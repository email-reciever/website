让我们深入了解新闻🐬

sveltejs/svelte的新增功能[](#What's-new-in-sveltejs-svelte)
-----------------------------------------------------------

*   SSR 存储处理已被重新设计为在 DOM 模式下订阅和取消订阅。 SSR 商店现在应该更稳定地工作（**3.31.2**，参见 [custom stores](/playground/custom-stores) 和 [Server-side component API](https://v4.svelte.dev/docs#run-time-server-side-component-api) ）
*   现在允许在一个元素上使用相同动作的多个实例（**3.32.0**，[example](/playground/01a14375951749dab9579cb6860eccde?version=3.32.0)）
*   新的 `foreign` 命名空间应该通过禁用某些特定于 HTML5 的行为和检查（**3.32.0**，[more info](https://github.com/sveltejs/svelte/pull/5652)），使替代编译目标（如 Svelte Native 和 Sveltegui）更容易
*   支持预处理器代码中的内联注释源映射（**3.32.0**）
*   解构默认值现在允许引用其他变量（**3.33.0**，[example](/playground/0ee7227e1b45465b9b47d7a5ae2d1252?version=3.33.0)）
*   当连接和清理时，自定义元素将调用 `onMount` 函数 断开连接时（**3.33.0**，签出 [this PR](https://github.com/sveltejs/svelte/pull/4522) 以了解人们如何使用 Web 组件的 Svelte 进行有趣的对话）
*   在编译器选项中添加了一个 `cssHash` 选项来控制用于 CSS 范围的类名 (**3.34.0**, [docs](https://v4.svelte.dev/docs#compile-time-svelte-compile))
*   继续改进打字稿定义

有关更改的完整列表，包括错误修复和 PR 链接，请查看 [the CHANGELOG](https://github.com/sveltejs/svelte/blob/master/CHANGELOG.md)

Sveltejs/语言工具的新功能[](#New-from-sveltejs-language-tools)
----------------------------------------------------------------

*   对于不支持 `didChangeWatchedFiles` 的语言服务器客户端，将使用回退文件观察器
*   商店访问器和元素指令的新突出显示规则（如`bind:`和`class:`）
*   HTML 标签现在可以一起重命名
*   Mustache 标签解析现在更加健壮，将在更多情况下提供更好的智能感知

还没有尝试过语言工具？ 查看 [Svelte Extension for VSCode](https://marketplace.visualstudio.com/items?itemName=svelte.svelte-vscode) 或为您最喜欢的 IDE 找到一个插件！

sveltejs/\*[](#Other-changes-from-sveltejs)的其他更改
---------------------------------------------------------

*   [eslint-plugin-svelte3](https://github.com/sveltejs/eslint-plugin-svelte3)现在支持3.1.0起的TypeScript
*   [prettier-plugin-svelte](https://github.com/sveltejs/prettier-plugin-svelte/) 发布了一些次要版本来解决空白和评论修剪问题。
*   [svelte-preprocess](https://github.com/sveltejs/svelte-preprocess/)本月修正错误包括对`postcss-load-config`的后CSS变换和V2和V3的支持的修正
*   [sapper](https://github.com/sveltejs/sapper/) 的 0.29.1 版本修复了类型定义中的一些不良导入，更新了与 Express/Polka 兼容的类型，并恢复了所有 CSS 文件名的散列。
