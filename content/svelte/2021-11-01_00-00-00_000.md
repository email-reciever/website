现在到新的！

Svelte 和 Sveltekit 中的新功能[](#New-in-Svelte-and-SvelteKit)
--------------------------------------------------------

*   [svelte.dev](/) 现在在 Sveltekit 旁边运行 [sveltesociety.dev](https://sveltesociety.dev)。 svelte.dev 是一个相对复杂的站点，具有实时代码编辑、身份验证和基于 Markdown 的博客 - 使其成为我们真正测试 sveltekit 的好方法
*   新的编译器选项`enableSourcemap`，对JS和CSS SourceMaps (**3.44.0**)的编译器输出提供了更多控制。 有了这个新功能，Sveltekit 和 Vite Svelte 插件现在可以正确处理 `.svelte` 模板中的环境变量（参见 [sveltejs/kit#720](https://github.com/sveltejs/kit/issues/720) 和 [sveltejs/vite-plugin-svelte#201](https://github.com/sveltejs/vite-plugin-svelte/pull/201)）
*   Svelte语言工具现在支持读取VS Code CSS设置的配置（[#1219](https://github.com/sveltejs/language-tools/issues/1219)）
*   `vite-plugin-svelte` 添加了一个新的 `experimental.prebundleSvelteLibraries` 选项，可以更快地加载包含许多图标库和 UI 框架等组件的 svelte 库。 该选项可以在 `svelte.config.js` 的根目录中设置。 请测试一下并给我们反馈！
*   sveltekit只会在客户端上路由端点，除非标记为`rel="external"` - 缩小客户端JS的大小并使将来更容易重构路由器([2656](https://github.com/sveltejs/kit/pull/2656))
*   Sveltekit 不再支持节点 12 ([2604](https://github.com/sveltejs/kit/pull/2604))
*   Sveltekit 已从 Vite 2.6.0 升级到 Vite 2.6.12 修复 Vite 会破坏 svelte 运行时 ([https://github.com/vitejs/vite/issues/4306](https://github.com/vitejs/vite/issues/4306)) 的问题。 它还包括 Sveltekit 团队的两个修复程序，以避免或使 Sveltekit 模板中的 Vite 问题诊断更容易（[https://github.com/vitejs/vite/pull/5192](https://github.com/vitejs/vite/pull/5192) 和 [https://github.com/vitejs/vite/pull/5193](https://github.com/vitejs/vite/pull/5193)）。 Vite 2.7 现已在测试版中提供，并针对 SSR 进行了额外的修复

要查看 Svelte 和 Sveltekit 的所有更新，请分别查看 [Svelte](https://github.com/sveltejs/svelte/blob/master/CHANGELOG.md) 和 [SvelteKit changelog](https://github.com/sveltejs/kit/blob/master/packages/kit/CHANGELOG.md)。

### 图书馆、工具和组件[](#Community-Showcase-Libraries-Tools-Components)

*   [svelte-adapter-azure-swa](https://github.com/geoffrich/svelte-adapter-azure-swa) 是用于创建 Azure 静态 Web 应用的 Svelte 应用的适配器，使用用于动态服务器渲染的 Azure 函数
*   [Inlang](https://docs.inlang.dev/getting-started/svelte-kit) 是一个本地化和国际化工具包，现在支持 sveltekit
*   [svelte-translate-tools](https://github.com/noelmugnier/svelte-translate-tools)在构建时为您的Svelte应用提取/生成/编译翻译文件
*   [@egjs/svelte-infinitegrid](https://github.com/naver/egjs-infinitegrid/tree/master/packages/svelte-infinitegrid) 允许您实现由不同大小的卡片元素组成的各种网格
*   [svelte-reactive-css-preprocess](https://github.com/srmullen/svelte-reactive-css-preprocess) 每当组件状态发生变化时，更容易更新 CSS 变量值
*   [Sveltegen](https://github.com/snuffyDev/sveltegen) 是简单轻松地创建动作、组件和路由的 CLI
*   [svelte-advanced-multistep-form](https://www.npmjs.com/package/svelte-advanced-multistep-form) 有助于将表单元素的样式传递给要渲染的组件，它还以有序和时尚的方式呈现每个表单步骤
*   [gQuery](https://github.com/leveluptuts/gQuery) 是 Sveltekit 的 GraphQL 获取和缓存
*   [date-picker-svelte](https://github.com/probablykasper/date-picker-svelte) 是 Svelte 的日期和时间选择器
*   [TwelveUI](https://twelveui.readme.io/reference/what-is-twelveui)是内置可访问性的Svelte组件库
*   [svelte-outclick](https://github.com/babakfp/svelte-outclick/) 是一个 svelte 组件，它允许您通过为您提供 Outclick 事件来监听元素外部的点击
*   [svelte-zero-api](https://github.com/ymzuiku/svelte-zero-api) 允许您使用 Sveltekit API，如客户端函数 - 支持 TypeScript
*   [svelte-recaptcha-v2](https://github.com/basaran/svelte-recaptcha-v2) 是针对 Svelte SPA、SSR 和 Sveltekit 静态站点的 Google ReCAPTCHA V2 实现。
*   [Svelte Body](https://github.com/ghostdevv/svelte-body) 允许您在路线中将样式应用于身体 - 旨在与 sveltekit 和 routify 一起使用。
*   [svelte-debug-console](https://github.com/basaran/svelte-debug-console) 是 Svelte SPA、SSR 和 Sveltekit 静态站点的 Debug.js 实现，可让您在浏览器中查看调试语句。
*   [SVEO](https://github.com/didier/sveo) 是一种在 sveltekit 页面上声明元数据的无依赖性方法
*   [@svelte-drama/suspense](https://www.npmjs.com/package/@svelte-drama/suspense) 是实现 React `<Suspense>` 的核心思想的 Svelte 组件。 还可以查看 [SWR for Svelte](https://www.npmjs.com/package/@svelte-drama/swr) 以使重新刷新更容易。
*   [sveltekit-adapter-browser-extension](https://github.com/antony/sveltekit-adapter-browser-extension) 是 sveltekit 的适配器，它将您的应用程序变成跨平台浏览器扩展程序
