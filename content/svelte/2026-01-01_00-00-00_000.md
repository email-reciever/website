在 12 月的假期期间，Svelte 团队分享了 24 天的 24 天知识、技巧和见解，以展开 2025 年的 [Advent of Svelte](https://advent.sveltesociety.dev/2025)。 通过一系列有趣和互动的视频了解有关未充分利用的 Svelte 功能的更多信息！

上个月，Svelte 生态系统还进行了一系列改进和展示项目。 那么让我们看看...

Svelte & Sveltekit 的新功能[](#What's-new-in-Svelte-SvelteKit)
------------------------------------------------------------------

`hydratable` 选项（将内联 `<script>` 块添加到 `head`）中现在有一个 `csp` 选项来支持内容安全策略（**svelte@5.46.0**、[Docs](/docs/svelte/hydratable#CSP)、[#17338](https://github.com/sveltejs/svelte/pull/17338)）
*   Vercel 适配器现在支持节点 24 (**adapter-vercel@6.2.0/adapter-auto@7.0.0**、[#14982](https://github.com/sveltejs/kit/pull/14982) 和 [#14737](https://github.com/sveltejs/kit/pull/14737))
*   Svelte CLI 现在能够为 Cloudflare Workers/Pages 开发（**sv@0.11.0**、[Docs](/docs/cli/sveltekit-adapter#Options-cloudflare-target)、[#851](https://github.com/sveltejs/cli/pull/851)）完全设置 Sveltekit 项目
*   Svelte MCP 现在将工具公开为 JS API 和 CLI (**mcp@0.1.16**, [#128](https://github.com/sveltejs/ai-tools/pull/128))
*   本月在语言工具中完成了大量的 [performance improvements](https://github.com/sveltejs/language-tools/releases)，因此请确保您的扩展是最新的！

有关更改的完整列表（包括本月发布的所有重要错误修正），请查看 svelte 编译器的 [CHANGELOG](https://github.com/sveltejs/svelte/blob/main/packages/svelte/CHANGELOG.md) 和 sveltekit / 适配器 [CHANGELOGs](https://github.com/sveltejs/kit/tree/main/packages)。

### 图书馆、工具和组件[](#Community-Showcase-Libraries-Tools-Components)

*   [SvelteDoc](https://marketplace.visualstudio.com/items?itemName=burke-development.sveltedoc)是VS代码扩展，在悬停时显示Svelte组件道具
*   [pocket-mocker](https://github.com/tianchangNorth/pocket-mocker) 是用于前端开发的页内 HTTP 控制器，可直接在浏览器中拦截、修改和模拟 API 响应
*   [Avatune](https://github.com/avatune/avatune) 是一个生产就绪的 Avatar 系统，具有 AI 驱动的生成和框架原生组件
*   [svelte-image-input](https://github.com/saabi/svelte-image-input)是用于加载、缩放和调整个人资料图片的组件
*   [Mint](https://github.com/mosaiq-software/mint)是一种数字合成工具，可用于裁剪和调整图像大小、创建拼贴、构建模型或完成基本的合成任务
*   [SvelteKit Auto OpenAPI](https://github.com/SaaSTEMLY/sveltekit-auto-openapi) 是 Sveltekit 的类型安全 OpenAPI 生成和运行时验证
*   [Svelte Drawer](https://github.com/AbhiVarde/svelte-drawer)是Svelte 5的抽屉组件，灵感来自Vaul
*   [trioxide](https://github.com/ObelusFi/trioxide) 是一组可定制的组件，专注于重新实现乏味的非平凡 UI 片段
*   [svelte-asciiart](https://github.com/xl0/svelte-asciiart) 是一个 svelte 5 组件，用于将 ASCII 艺术渲染为具有可选网格覆盖和框架的可扩展 SVG
*   [svelte-bash](https://github.com/YusufCeng1z/svelte-bash)是一个完全类型化的、轻量级的、可定制的终端仿真器组件，具有虚拟文件系统、自定义命令、主题和演示的自动播放模式
*   [SvelTTY](https://github.com/miunau/sveltty) 提供了一个运行时，允许您在终端中渲染并与 svelte 应用进行交互
*   [svelte-tablecn](https://github.com/itisyb/svelte-tablecn)是一个强大的数据网格和tablecn.com的端口
*   [Svelte runtime components](https://github.com/MrGentle/svelte-runtime-components) 支持在运行时从文本中编译 svelte 组件，允许在浏览器中编译和安装动态、用户提供的 svelte 组件代码
