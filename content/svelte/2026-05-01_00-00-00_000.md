本月，我们对 Sveltekit 的远程功能、TypeScript 6.0 支持和 Svelte CLI 中社区插件的实验性版本进行了大量改进。

斯维尔特也是[featured in ThoughtWorks Technology Radar](https://www.thoughtworks.com/radar/languages-and-frameworks/summary/svelte)！

大月份，更大的展示......所以让我们潜入吧！

sveltekit的新增功能[](#What's-new-in-SvelteKit)
-----------------------------------------------

*   SvelTekit 现在支持 TypeScript 6.0 (**2.56.0**, [Docs](https://devblogs.microsoft.com/typescript/announcing-typescript-6-0/), [#15595](https://github.com/sveltejs/kit/pull/15595))
*   `form` 字段现在可以使用 `field.as(type, value)` 指定默认值，减少预填充表单的样板 (**2.56.0**, [Docs](/docs/kit/remote-functions#form-Fields), [#15577](https://github.com/sveltejs/kit/pull/15577))
*   远程函数传输现在使用 `hydratable`，在查询结果中启用更丰富的数据类型 (**2.56.0**, [#15533](https://github.com/sveltejs/kit/pull/15533))
*   Form `submit`现在返回一个`boolean`表示增强表单远程功能的提交有效性（**2.57.0**、[Docs](/docs/kit/remote-functions#form-enhance)、[#15530](https://github.com/sveltejs/kit/pull/15530)）
*   **远程功能中断更改（2.56.0）**
    *   客户端请求的查询刷新必须获得服务器的权限（[#15562](https://github.com/sveltejs/kit/pull/15562)）
    *   通过排序对象键来稳定远程功能缓存（[#15570](https://github.com/sveltejs/kit/pull/15570)）
    *   向查询添加`run()`方法，禁止在渲染外部等待查询（[#15533](https://github.com/sveltejs/kit/pull/15533)）
    *   隔离每个查询的命令触发的查询刷新失败 ([#15562](https://github.com/sveltejs/kit/pull/15562))
    *   `requested` 现在需要 `limit` 并产生 `{ arg, query }` 条目，而不是经过验证的 args ([#15739](https://github.com/sveltejs/kit/pull/15739))

正在寻找有关本月许多错误修复和性能优化的更多详细信息？ 查看 sveltekit / 适配器 [CHANGELOGs](https://github.com/sveltejs/kit/tree/main/packages)。

Svelte 和 Svelte 开发工具的新功能[](#What's-new-in-Svelte-and-Svelte-Dev-Tools)
----------------------------------------- ------------------------------------------

*   社区附加组件现在作为实验功能提供在 `sv` 中（**sv@0.1.0**、[Docs](/docs/cli/community)、[#1020](https://github.com/sveltejs/cli/pull/1020)）
*   CLI 包中的 `sv` 和 `sv-utils` 包现在是分开的 - 导致更明确的公共 API 和旧功能的弃用通道（**sv@0.2.0**、[Docs](/docs/cli/sv)、[#1046](https://github.com/sveltejs/cli/pull/1046)）
*   `sv`现在将更可靠地检测配置项目时是否安装了Viste V3（**sv@0.15.2**、[#1073](https://github.com/sveltejs/cli/pull/1073)）
*   `TweenOptions`、`SpringOptions`、`SpringUpdateOptions`和`Updater`的类型现在可作为`svelte/motion`（**svelte@5.55.0**、[Docs](/docs/svelte/svelte-motion)、[#17967](https://github.com/sveltejs/svelte/pull/17967)）的输出

有关更改的完整列表 - 包括本月发布的所有重要错误修正 - 查看 Svelte 编译器的 [CHANGELOG](https://github.com/sveltejs/svelte/blob/main/packages/svelte/CHANGELOG.md)。
