距离[SvelteKit 1.0](/blog/announcing-sveltekit-1.0)发布仅两周时间！ 如果您还没有，请查看 [livestream](https://www.youtube.com/watch?v=N4BRVkQVoMc)、[new website](https://kit.svelte.dev/) 和 [tutorial](/tutorial) 逐步了解 Sveltekit 的所有功能。

让我们深入了解细节...

sveltekit的新增功能[](#What's-new-in-SvelteKit)
-----------------------------------------------

*   `@sveltejs/kit` 1.0 出局！ 所有未来的版本都将跟随 SEMVER，更改将在 [CHANGELOG](https://github.com/sveltejs/kit/blob/master/packages/kit/CHANGELOG.md#100) 中作为主要/次要/补丁列出。
*   加强了对 Storybook 和 Histoire 的支持 ([#7990](https://github.com/sveltejs/kit/pull/7990))。 正在进行全面支持这些工具的工作（[storybook#20239](https://github.com/storybookjs/storybook/pull/20239)）。
*   `vitePreprocess` 现在是默认的预处理器。 请参阅 [the docs](/docs/kit/integrations#vitePreprocess) 了解 `vitePreprocess` 和 `svelte-preprocess` ([#8036](https://github.com/sveltejs/kit/pull/8036)) 之间的区别。

### 突破性变化：[](#What's-new-in-SvelteKit-Breaking-changes:)

*   `+(layout|page)(.server)?.js`和`+server.js`文件不再允许未知导出（以下划线开头时除外）
*   `__data.json` 现已从 URL ([#7979](https://github.com/sveltejs/kit/pull/7979)) 中删除
*   `sveltekit()`现在将返回一个Vite插件数组的承诺([#7994](https://github.com/sveltejs/kit/pull/7994))
*   新的 `embedded` 选项，默认关闭，有助于在嵌入 sveltekit ([docs](/docs/kit/configuration), [#7969](https://github.com/sveltejs/kit/pull/7969)) 时进行链接点击
*   自动后备生成已被 `builder.generateFallback(fallback)` ([#8013](https://github.com/sveltejs/kit/pull/8013)) 取代
*   `invalid()`现在是`fail()`，`ValidationError`现在是`ActionFailure`([#8012](https://github.com/sveltejs/kit/pull/8012))
*   sveltekit现在将在无效的加载响应上抛出错误（[#8003](https://github.com/sveltejs/kit/pull/8003)）
*   Sveltekit现在使用的是Vite 4，需要`^3.54.0`的一个小`peerDependency`（[#7543](https://github.com/sveltejs/kit/pull/7543)）
*   当 `ssr` 为 false 且 `prerender` 不为 false 时，Shells 现在被预渲染 - 当 SSR 也是 false 时，确保 PreRender 为 False ([#8131](https://github.com/sveltejs/kit/pull/8131))
*   关于已移除/更改的 API 的警告和错误已被移除 ([#8019](https://github.com/sveltejs/kit/pull/8019))

Svelte 的新功能[](#What's-new-in-Svelte)
-------------------------------------------

*   现在可以将 `options.direction` 参数传递给自定义转换函数 (**3.54.0**, [#3918](https://github.com/sveltejs/svelte/issues/3918))
*   变量现在可以从 `@const` 声明的函数 (**3.54.0**, [#7843](https://github.com/sveltejs/svelte/issues/7843)) 更新
*   `svelte/elements` 已为 svelte/html 类型定义添加 (**3.55.0**, [#7649](https://github.com/sveltejs/svelte/pull/7649))

语言工具的新增功能[](#What's-new-in-Language-Tools)
---------------------------------------------------------

Svelte 扩展和语言工具现在有一些新的最低版本要求：

*   节点版本现在是 16
*   TypeScript 版本现在是 4.9
*   Svelte版本现在是3.55

还发布了以下功能：

*   缺少处理程序快速修复（[#1731](https://github.com/sveltejs/language-tools/pull/1731)）
*   添加svelte锚缺少属性代码动作（[#1730](https://github.com/sveltejs/language-tools/pull/1730)）
*   更好的提交字符处理（[#1742](https://github.com/sveltejs/language-tools/pull/1742)）
*   添加 `--preserveWatchOutput` 选项 ([#1715](https://github.com/sveltejs/language-tools/pull/1715))
*   增强快速修正以包括苗条商店（[#1789](https://github.com/sveltejs/language-tools/pull/1789)）
*   仅在 Sveltekit 项目中显示 sveltekit 文件上下文菜单 ([#1771](https://github.com/sveltejs/language-tools/pull/1771))
*   如果可能，使用 `satisfies` 运算符 ([#1770](https://github.com/sveltejs/language-tools/pull/1770))

对于 svelte 编译器的所有更改，包括未发布的更改，请查看 [CHANGELOG](https://github.com/sveltejs/svelte/blob/master/CHANGELOG.md)。
