本月为 Svelte 和 SvelteKit 带来了几个新功能，并且社区中也有很多新的库。

另外，上个月 Svelte 维护者发布了针对 Svelte 生态系统中 5 个漏洞的补丁。如果你错过了，请务必通过阅读博客文章 [影响 Svelte 生态系统的 CVE](/blog/cves-affecting-the-svelte-ecosystem) 来保持更新。

现在，不再啰嗦，让我们开始...

## Svelte & SvelteKit 中的新功能[](#What's-new-in-Svelte-SvelteKit)

* 为支持允许此功能的新浏览器，您现在可以使用 CSS 和富 HTML 内容自定义 `<select>` 元素（**svelte@5.47.0**，[Docs](https://developer.chrome.com/blog/a-customizable-select)，[#17429](https://github.com/sveltejs/svelte/pull/17429)）
* Svelte 的 CSS 解析器现在从 `svelte/compiler` 中导出为 `parseCss`。它是一个部分但轻量级的 CSS AST 解析器，目前正在 SvelteKit 中使用（**svelte@5.48.0**，[#17496](https://github.com/sveltejs/svelte/pull/17496)）
* 当使用 `customElement` 创建影子根时，现在可以将 `ShadowRootInit` 对象传递给 `attachShadow()`（**svelte@5.49.0**，[Docs](/docs/svelte/custom-elements#Component-options)，[#17088](https://github.com/sveltejs/svelte/pull/17088)）
* SvelteKit 中的远程函数的一个破坏性变更删除了实验性的远程表单函数中的 `buttonProps`。创建多个提交按钮时，请使用 `<button {...myForm.fields.action.as('submit', 'register')}>Register</button>` 代替（**kit@2.50.0**，[Docs](/docs/kit/remote-functions#form-Multiple-submit-buttons)，[#15144](https://github.com/sveltejs/kit/pull/15144)）
* Node：服务器的 `keepAliveTimeout` 和 `headersTimeout` 选项现在可以通过设置相应的环境变量来配置（**sveltejs/adapter-node@5.5.0**，[Docs](/docs/kit/adapter-node#Environment-variables-KEEP_ALIVE_TIMEOUT-and-HEADERS_TIMEOUT)，[#15125](https://github.com/sveltejs/kit/pull/15125)）
* Vercel：远程函数调用现在可以在 observability 中的 /\_app/remote 路由下找到（**sveltejs/adapter-vercel@6.3.1**，[#15098](https://github.com/sveltejs/kit/pull/15098)）

为了获取完整的更改列表 - 包括本月发布的所有重要 bug 修复 - 请查看 Svelte 编译器的 [CHANGELOG](https://github.com/sveltejs/svelte/blob/main/packages/svelte/CHANGELOG.md) 和 SvelteKit / Adapter [CHANGELOGs](https://github.com/sveltejs/kit/tree/main/packages)。

## 社区展示[](#Community-Showcase)

### 使用 Svelte 构建的应用和网站[](#Community-Showcase-Apps-Sites-built-with-Svelte)

* [Frame](https://getframe.vercel.app/) 是一个基于 Tauri v2 框架的高性能媒体转换工具。它提供了对 FFmpeg 操作的本地接口，允许对视频和音频转码参数进行细粒度控制
* [LogTide](https://logtide.dev/) 是 Datadog、Splunk 和 ELK 的开源替代品。它面向需要 GDPR 合规、数据所有权和简单性的开发人员和欧洲中小企业，且无需管理 ElasticSearch 集群的复杂性
* [funcalling](https://www.funcalling.com/) 是一个具有内置桌面游戏、文字游戏和动作捕捉游戏的 P2P 通话应用 ([Reddit帖子](https://www.reddit.com/r/sveltejs/comments/1qgrq2c/i_built_a_p2p_calling_app_with_built_in_board/) 包含视频演示)
* [book by book](https://bookbybook.app/) 允许您在几秒钟内将书籍数据、封面和价格同步到 Square POS。您可以从 Ingram、Edelweiss 和 PubEasy 导入分销商订单——无需电子表格或手动输入
* [zsweep](https://zsweep.com/) 是一个极简主义的、基于键盘的《扫雷》游戏，使用 Vim 动作进行游戏
* [PulseKit](https://trypulsekit.com/) 提供专业的反馈管理，用于收集和优先处理客户反馈
* [Bitphase](https://bitphase.app/) 是一个现代的基于 Web 的 chiptune 跟踪器，用于在复古声卡上创建音乐
* [CapCheck](https://capcheck.ai/) 是一个用于图像、视频、音频、文本和 URL 的事实检查 AI
* [Distill](https://www.distillintelligence.com/competitor-finder) (上次提及于七月) 已更新，新增了竞争对手查找器，使跟踪市场中的直接和间接竞争对手变得更加容易
* [Pelican](https://pelican.alexey.work/) 允许您从文本提示生成 SVG 矢量图形和 ASCII 艺术。通过多步骤的精化，AI 可以看到其输出并迭代改进它

### 库、工具和组件[](#Community-Showcase-Libraries-Tools-Components)

*UI 组件和动画*

* [mapcn-svelte](https://github.com/MariusLang/mapcn-svelte) 是一个基于 MapLibre GL 的 Svelte 版本的 mapcn，使用 Tailwind 样式，并与 shadcn-svelte 无缝集成
* [AgnosticUI Local (v2)](https://github.com/AgnosticUI/agnosticui) 是一个基于 CLI 的 UI 组件库，可以直接将 Lit 网页组件复制到您的项目中
* [Motion Core](https://github.com/motion-core/motion-core) 是一个由 GSAP 和 Three.js 驱动的动画 Svelte 组件集合
* [Tilt Svelte](https://github.com/Savy011/tilt-svelte) 是一个基于 vanilla-tilt.js 的平滑 3D 倾斜 Svelte 附加组件

*状态管理*

* [Reddo.js](https://github.com/eihabkhan/reddojs) 是一个用于JavaScript、React、Vue和Svelte的微型撤销/重做实用程序包
* [svstate](https://github.com/BCsabaEngine/svstate) 提供带有验证、快照/撤销和副作用的深度响应式代理 —— 为复杂的实用应用程序构建
* [rune-sync](https://github.com/antepodeum/rune-sync) 在各种存储后端同步响应式状态

*插件、编译器和运行时*

* [fastify-svelte-view](https://github.com/matths/fastify-svelte-view) 是一个 Fastify 插件，用于渲染 Svelte 组件，支持 SSR（服务器端渲染）、CSR（客户端渲染）和带有水合的 SSR
* [kit-on-lambda](https://github.com/beesolve/kit-on-lambda) 是一个适配器，用于在 AWS Lambda 上运行 SvelteKit。它支持部署到 Node.js 和 Bun 运行时，使用 esbuild/Bun 打包
* [voca](https://github.com/treyorr/voca) 是一个自托管、无状态、快速的 WebRTC 信令服务器，使用 Rust 编写，具有前端 SDK
* [@svelte-safe-html/core](https://github.com/patel-vansh/svelte-safe-html-core) 静态分析 `.svelte` 文件，检测不安全的 `{@html}` 插入
* [sveltekit-discriminated-fields](https://www.npmjs.com/package/sveltekit-discriminated-fields) 为 SvelteKit 远程函数表单字段提供类型安全的区分联合支持
* [svelte-fast-check](https://github.com/astralhpi/svelte-fast-check) 是一个 Svelte/SvelteKit 项目的类型和 Svelte 编译器警告检查器，声称比内置的 svelte-check 快到 24 倍
