使用 [Async Svelte](https://github.com/sveltejs/svelte/discussions/15845) 和其配套的 [Remote Functions](https://github.com/sveltejs/kit/discussions/13897) 官方发布后， 有很多更新要分享！

请务必查看展示，里面有 Rich、Paolo 和 Stanislav 关于 Svelte 中所有全新功能的视频。

让我们深入了解亮点...

## Svelte、SvelteKit、语言工具和 CLI (sv) 中的新功能[](#What's-new-in-Svelte-SvelteKit-Language-Tools-and-CLI-\(sv\))

* 远程函数可以在应用程序的任何地方调用，但始终在服务器上运行，因此可以安全地访问包含环境变量和数据库客户端等内容的仅服务器模块（**kit@2.27.0**，[Docs](/docs/kit/remote-functions)，[#13986](https://github.com/sveltejs/kit/pull/13986)）
* `getAbortSignal` 返回一个 `AbortSignal`，当当前派生或效果重新运行或被销毁时会中止（**svelte@5.35.0**，[Docs](/docs/svelte/svelte#getAbortSignal)，[#16266](https://github.com/sveltejs/svelte/pull/16266)）
* 已添加一个新的 `parent` 属性到开发时添加到元素的 `__svelte_meta` 属性中 - 有助于调试嵌套层次结构（**svelte@5.35.1**，[#16255](https://github.com/sveltejs/svelte/pull/16255)）
* 现在支持在使用 `experimental.async` 编译器选项时在组件中使用 `await`（**svelte@5.36.0/extensions@109.10.0**，[Docs](/docs/svelte/await-expressions)，[#15844](https://github.com/sveltejs/svelte/pull/15844)）
* 现在为页面/布局组件中的 `params` 属性和 `page` 属性提供了类型（**kit@2.24.0, kit@2.26.0 & extensions@109.10.0**，[#13999](https://github.com/sveltejs/kit/pull/13999) / [#13864](https://github.com/sveltejs/kit/pull/13864)）
* SvelteKit 的 `read` 现在可以在 `fs.readFile` 不可用的边缘环境中工作，例如 Cloudflare 的工作人员、Netlify 和 Vercel 的边缘函数（**kit@2.25.0**，[#13859](https://github.com/sveltejs/kit/pull/13859)）
* 已添加 `resolve(...)` 和 `asset(...)` 帮助器来解析路径（**kit@2.26.0**，[#13864](https://github.com/sveltejs/kit/pull/13864)）
* 已添加对现代 SvelteKit 属性类型的支持到 VS Code 代码片段（**extensions-109.10.0**，[#2796](https://github.com/sveltejs/language-tools/pull/2796)）
* 新的 `vite.addPlugin` 简化了在各种 vite 配置样式中添加插件（**sv@0.8.20**，[#633](https://github.com/sveltejs/cli/pull/633)）
* vite-plugin-svelte 现在支持 vite7、rolldown-vite 和 [更多](https://github.com/sveltejs/vite-plugin-svelte/blob/main/packages/vite-plugin-svelte/CHANGELOG.md) 功能

为了查看 Svelte、SvelteKit 及其适配器的全部 bug 修复列表，请查看他们的 CHANGELOG：[这里](https://github.com/sveltejs/svelte/blob/main/packages/svelte/CHANGELOG.md) 和 [这里](https://github.com/sveltejs/kit/tree/main/packages)。

### 库、工具和组件[](#Community-Showcase-Libraries-Tools-Components)

* [Svelte Interval](https://github.com/PuruVJ/svelte-interval) 是一个用于管理间隔的综合 Svelte 实用程序包，具有响应式持续时间、同步和高级控制功能
* [@hvniel/svelte-router](https://github.com/HanielU/svelte-router) 是 React Router 的 Svelte 5 端口
* [@hvniel/vite-plugin-svelte-inline-component](https://github.com/hanielu/vite-plugin-svelte-inline-component) 允许您使用标记模板文字直接在 JavaScript/TypeScript 测试中编写小型 Svelte 组件
* [wuchale](https://github.com/wuchalejs/wuchale) 是一个非侵入性、基于正常代码的编译时国际化（i18n）工具包
* [SSGOI](https://github.com/meursyphus/ssgoi) 将原生应用程序般的页面过渡带到网页
* [Svelte 表单构建器](https://github.com/moalamri/svelte-form-builder) 是一个现代的、拖放式表单构建器，使用 Svelte 5 构建
* [Svelte 持久符文](https://github.com/MacFJA/svelte-persistent-runes?tab=readme-ov-file#svelte-persistent-runes) 提供一个 Svelte 响应式符文，可以在页面和重新加载之间保持其值
* [gositemap](https://github.com/lelabdev/gositemap) 是一个快速、测试驱动的 sitemap.xml 生成器，用于静态 SvelteKit 站点
