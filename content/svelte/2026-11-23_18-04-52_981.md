就在年底来临之际，新的 [Svelte Society Website](https://sveltesociety.dev/) 已经推出！它带来了全新的体验。与其只是一个静态资源网站，不如说它现在提供了所有最新的 Svelte 内容的动态 feed。包括视频、库、活动等。

与其打开 PR 来添加库和包，你现在可以直接在 [网站](https://sveltesociety.dev/submit) 上提交它们。如果你发现了一个有趣的包，可以前往提交。登录的用户还可以喜欢和保存内容。所以一定要试试看，并 [分享你的反馈](https://www.reddit.com/r/sveltejs/comments/1ox9znh/announcing_the_new_svelte_society_website/)！

SvelteKit 有很多更新，并且有一个展示要涵盖，所以让我们深入探讨...

## Svelte 和 SvelteKit 的新功能[](#What's-new-in-Svelte-SvelteKit)

* `hydratable` API是一个低级别的API，用于在服务器和客户端之间协调hydration（**svelte@5.44.0**，[Docs](/docs/svelte/hydratable)，[#17154](https://github.com/sveltejs/svelte/pull/17154))
* `print`将Svelte AST节点转换回Svelte源代码。它主要用于解析和转换使用编译器的现代AST表示的组件的工具（**svelte@5.45.0**，[Docs](/docs/svelte/svelte-compiler#print)，[#16188](https://github.com/sveltejs/svelte/pull/16188))
* 文件上传现在可以在`form`远程函数中流式传输，允许在大文件上传完成之前访问表单数据（**kit@2.49.0**，[Docs](/docs/kit/remote-functions#form)，[#14775](https://github.com/sveltejs/kit/pull/14775))
* （小）破坏性变化在 **kit@2.48.8** 中：
  * `invalid`现在必须从@sveltejs/kit导入（[#14768](https://github.com/sveltejs/kit/pull/14768)）
  * 从实验性的表单`validate()`方法中删除了`submitter`选项。它现在将始终使用默认的提交者（[#14762](https://github.com/sveltejs/kit/pull/14762)）
* **Svelte CLI：**
  * 链接现在被`resolve()`包裹，以遵循最佳实践（**sv@0.9.14**，[Docs](/docs/kit/$app-paths#resolve)，[#754](https://github.com/sveltejs/cli/pull/754)）
  * `npx sv create`现在支持一个新的参数`--add`，用于在同一个命令中将插件添加到项目中（**sv@0.10.0**，[#695](https://github.com/sveltejs/cli/pull/695)）
  * `sv create`中的新选项`--no-dir-check`将抑制所有目录检查提示，即使文件夹不为空（**sv@0.9.15**，[#785](https://github.com/sveltejs/cli/pull/785)）

为了获取完整的更改列表 - 包括本月发布的所有重要错误修复 - 请查看 Svelte 编译器的 [CHANGELOG](https://github.com/sveltejs/svelte/blob/main/packages/svelte/CHANGELOG.md) 和 Svelte Kit / Adapter [CHANGELOGs](https://github.com/sveltejs/kit/tree/main/packages)。

## 社区展示[](#Community-Showcase)

### 使用 Svelte 构建的应用和网站[](#Community-Showcase-Apps-Sites-built-with-Svelte)

* [Apple 的新网页版 App Store](https://apps.apple.com) 使用 Svelte 构建！这增加了其他在野外发现使用 Svelte 的 Apple 产品，包括 Apple Music 和 Apple Podcasts
* [Aphex](https://getaphex.com/) 是一个现代的、开源的无头 CMS，使用 SvelteKit 构建
* [ShareNhac](https://www.sharenhac.com/) 允许你和你的朋友一起观看视频和听音乐，且无广告打断
* [starterindex](https://starterindex.com/) 是一个精选的顶级模板列表，帮助你开始下一个项目（这很棒，因为我们一年多前停止在 Svelte 新闻稿中发布“starter”仓库）
* [PGPlayground](https://pg.firoz.co/playground) 帮助任何后端工程师快速原型和验证他们的模式的更改或修复，而无需离开浏览器
* [Engramma](https://engramma.dev) 是一个网页版编辑器和转换器，用于管理设计令牌，visualize 它们在树结构中，并以 CSS 变量、SCSS 或 JSON 格式导出
* [Multi](https://multi.dev/) 是一个用于 VS Code 的编码代理
* [Gardenjs](https://gardenjs.org/) 提供一个集中化的平台，供开发人员创建、测试和展示 UI 组件和页面
* [bookemoji](https://bookemoji.dev/) 是一个展示、协作和开发用户界面技术方面的工具 - 是 StoryBook.js 或 Histoire 在你最喜欢的技术栈中的替代品

### 库、工具和组件[](#Community-Showcase-Libraries-Tools-Components)

* [better-svelte-email](https://github.com/Konixy/better-svelte-email) 允许您在 Svelte 中渲染电子邮件，具有原生 Tailwind 支持
* [svelte-number-format](https://www.npmjs.com/package/svelte-number-format) 是一个轻量级且响应式的数字输入组件，现已作为稳定版本 v1.0 发布
* [chain-enhance](https://github.com/michaelcuneo/chain-enhance) 允许您顺序链式调用多个 SvelteKit 表单操作，具有深度合并的数据传播、类型安全的结果、响应式进度跟踪和自动文件安全
* [svelte-socket](https://www.npmjs.com/package/@hardingjam/svelte-socket) 是一个为 Svelte 5 使用 runes 的 WebSocket 包装器
* [@edgeone/sveltekit](https://pages.edgeone.ai/document/framework-sveltekit) 允许您将 SvelteKit 应用部署到腾讯云 EdgeOne Pages，以在中国提供闪电般的速度，同时在全球范围内保持优异的性能
* [Davia](https://github.com/davialabs/davia) 是一个开源工具，旨在为代码库生成交互式内部文档，专为 AI 编码代理设计
* [svelte-ui-kit](https://github.com/ChulkovDanila/svelte-ui-kit) 提供一个易于使用且可定制的按钮组件，具有平滑的悬停动画 —— 受 shadcn/ui 风格启发
* [Svelte AI Elements](https://github.com/SikandarJODD/ai-elements) 是一个组件注册表，建立在 shadcn-svelte 之上，提供适用于构建 AI 驱动应用程序的生产就绪组件
* [sveltekit-api-gen](https://github.com/Michael-Obele/sveltekit-api-gen) 自动从 SvelteKit 服务器端点生成 OpenAPI 3.0 规范，使用 JSDoc `@Swagger` 注释
* [Rune Scroller](https://runescroller.lelab.dev/) 为 Svelte 5 提供了“迷人的”滚动动画，采用本地性能和零依赖项
* [vite-plugin-sveltekit-decorators](https://github.com/KiraPC/vite-plugin-sveltekit-decorators/) 是一个插件，自动装饰 SvelteKit 函数，现在支持远程函数
* [svelte-breakpoint-badge](https://github.com/AnakKucingTerbang/svelte-breakpoint-badge) 是一个轻量级的 Svelte 组件，显示当前的 Tailwind CSS 断点，在开发过程中使用
