本简短指南旨在帮助您 —— 您已经查看了 [tutorial](/tutorial) 并希望开始创建 Svelte 应用，但您没有太多使用 JavaScript 构建工具的经验 —— 快速上手。

如果有您不理解的内容，或者我们没有详细说明的部分，请随时 [提问](https://github.com/sveltejs/svelte/issues) 或 [建议修改本页面](https://github.com/sveltejs/svelte/blob/master/site/content/blog/2019-04-16-svelte-for-new-developers.md) 以帮助我们更好地帮助更多人。

如果您在遵循本指南的任何时候遇到困难，寻求帮助的最佳地点是 [聊天室](/chat)。

## 首先[](#First-things-first)

您将使用 *命令行* ，也称为终端。在 Windows 上，您可以通过从开始菜单运行 **命令提示符** 来访问它；在 Mac 上，按 `Cmd` 和 `Space` 键同时打开 **Spotlight** ，然后开始输入 `Terminal.app` 。在大多数 Linux 系统上，按 `Ctrl-Alt-T` 即可打开命令行。

命令行是与计算机（或其他计算机！但那是另一个话题）交互的一种方式，具有比大多数人日常使用的 GUI （图形用户界面）更强的力量和控制力。

一旦进入命令行，您可以使用 `ls` （在 Windows 上为 `dir` ）列出当前目录的内容，并使用 `cd` 更改当前目录。例如，如果您在主目录中有一个名为 `Development` 的项目目录，您可以输入

```bash
cd Development
```

进入该目录。从那里，您可以使用 `mkdir` 命令创建一个新项目目录：

```bash
mkdir svelte-projects
cd svelte-projects
```

对命令行的全面介绍超出了本指南的范围，但以下是一些其他有用的命令：

* `cd ..` — 导航到当前目录的父目录
* `cat my-file.txt` — 在 Mac/Linux 上（在 Windows 上为 `type my-file.txt` ），列出 `my-file.txt` 的内容
* `open .` （或在 Windows 上为 `start .` ） — 在 Finder 或文件资源管理器中打开当前目录

## 安装 Node.js[](#Installing-Node.js)

[Node](https://nodejs.org/en/) 是一种在命令行中运行 JavaScript 的方式。它被许多工具使用，包括 Svelte。如果您还没有安装它，最简单的方法是直接从 [网站](https://nodejs.org/en/) 下载最新版本。

安装完成后，您将可以访问三个新的命令：

* `node my-file.js` — 运行 `my-file.js` 中的 JavaScript
* `npm [subcommand]` — [npm](https://www.npmjs.com/) 是一种安装应用程序依赖的 ‘包’ 的方式，例如 [svelte](https://www.npmjs.com/package/svelte) 包
* `npx [subcommand]` —一种方便的运行 npm 上可用程序而无需永久安装的方式

## 安装文本编辑器[](#Installing-a-text-editor)

要编写代码，您需要一个好的编辑器。最受欢迎的选择是 [Visual Studio Code](https://code.visualstudio.com/) 或 VSCode，这也正当其然 —— 它设计良好，功能齐全，并且有大量的扩展（包括一个用于 [Svelte](https://marketplace.visualstudio.com/items?itemName=svelte.svelte-vscode) 的扩展），该扩展提供了语法高亮和诊断消息，当您编写组件时。

## 创建项目[](#Creating-a-project)

我们将使用 [Svelte + Vite](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-svelte) 模板。你不必使用项目模板，但是这样可以减少很多设置工作。

在命令行中，导航到你想要创建新项目的位置，然后输入以下行（你可以复制并粘贴整个内容，但是如果你习惯逐行输入然后运行，每行输入一次会帮助你更好地发展肌肉记忆）：

```bash
npm create vite@latest my-svelte-project -- --template svelte
cd my-svelte-project
npm install
```

> 你可以将 `--template svelte` 替换为 `--template svelte-ts`，如果你更喜欢 TypeScript。

这将创建一个新的目录 `my-svelte-project`，从 [create-vite/template-svelte](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-svelte) 模板添加文件，并从 npm 安装一系列包。打开目录在你的文本编辑器中并查看一下。应用程序的“源代码”位于 `src` 目录中，而应用程序可以加载的文件位于 `public` 中。

在 `package.json` 文件中，有一个名为 `"scripts"` 的部分。这些脚本定义了与应用程序合作的快捷方式 —— `dev`、`build` 和 `preview`。要以开发模式启动应用程序，请输入以下内容：

```bash
npm run dev
```

运行 `dev` 脚本会启动一个名为 [Vite](https://vitejs.dev/) 的程序。Vite 的任务是获取应用程序的源文件，将它们传递给其他程序（在我们的例子中，包括 Svelte），并将它们转换为实际运行代码，当您在浏览器中打开应用程序时。

说到这，打开一个浏览器并导航到 <http://localhost:5173>。这是您的应用程序在本地 *web 服务器* （因此为 ‘localhost’）上的 5173 端口运行。

尝试修改 `src/App.svelte` 并保存它。应用程序将随着您的更改而更新。

## 构建您的应用程序[](#Building-your-app)

在上一步中，我们以 ‘开发模式’ 运行应用程序。在开发模式下，Svelte 添加了额外的代码以帮助调试，而 Vite 跳过了压缩应用程序 JavaScript 的最后一步。

当你将应用分享给世界时，你希望以“生产模式”构建它，以便使其对于最终用户来说尽可能小和高效。为此，使用 `build` 命令：

```bash
npm run build
```

你的 `dist` 目录现在包含了应用的优化版本。你可以这样运行它：

```bash
npm run preview
```
