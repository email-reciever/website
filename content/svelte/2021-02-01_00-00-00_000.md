随着一年中最短的一个月的到来，Svelte 维护者和社区成员上个月一直很忙——从 `svelte-loader`、`prettier-plugin-svelte`、`rollup-plugin-svelte` 和 `language-tools` 的重大变化到 Sapper 和 `svelte-preprocess` 的稳步进展。 与此同时，许多人一直忙于将 Svelte 与其他流行的框架集成。

新编译器功能[](#New-compiler-features)
--------------------------------------------

*   来自 [WAI-ARIA Graphics Module](https://www.w3.org/TR/graphics-aria-1.0/#role_definitions) 的 Aria 角色现在被识别为 Svelte 组件中的有效 ARIA 角色 (**3.31.1**)
*   常见的 React 属性的编译器警告，`className` 和 `htmlFor`，现在使 React 组件更容易移植到 Svelte (**3.31.1**)

对编译器功能有建议或想帮助实现新功能/错误修复？ 查看[“triage: good first issue” tag for Svelte](https://github.com/sveltejs/svelte/issues?q=is%3Aopen+is%3Aissue+label%3A%22triage%3A+good+first+issue%22)

语言工具中的新位[](#New-bits-in-language-tools)
-----------------------------------------------------

*   VS Code中不再显示用户自动导入建议（**103.0.0**）
*   重命名变量现在更安全，通过对重命名变量的前缀/后缀进行智能添加（**104.0.0**）
*   Typescript用户的语义（令牌）突出显示让主题制作者在他们的主题中应用语义样式（**104.0.0**）
*   “提取组件”已添加到上下文菜单中 - 允许您从文件中提取组件，而无需打开命令窗口键入“svelte：提取组件”（**104.0.0**）
*   VS Code 扩展现在监听 JavaScript/TypeScript 文件更改 - 您不再需要保存文件以注意更改 (**104.1.0**)

有关更改的完整列表，请查看语言工具 [Releases page](https://github.com/sveltejs/language-tools/releases)。

尝试语言工具的一个好方法是下载 [Svelte Extension for VSCode](https://marketplace.visualstudio.com/items?itemName=svelte.svelte-vscode)。 此扩展使用 Svelte 语言服务器为 VS Code 中的 Svelte 组件提供语法突出显示和丰富的智能感知。 检查编辑器的扩展源，看看是否有适合您的 IDE 的 Svelte 插件或构建您自己的插件（例如，请参阅 [coc-svelte](https://github.com/coc-extensions/coc-svelte)）！

整个 Svelte 生态系统的重大改进[](#Big-improvements-across-the-Svelte-ecosystem)
------------------------------------------- --------------------------------------------

*   [svelte-loader](https://github.com/sveltejs/svelte-loader) 发布了一个主要版本，3.0.0 - 支持 Webpack 5 和 Node 14 支持，更好的热重载，以及新的 `compilerOptions` 以匹配 `rollup-plugin-svelte`。 重大更改包括放弃 svelte 2 和 node 8 支持。 [More info in the changelog](https://github.com/sveltejs/svelte-loader/blob/master/CHANGELOG.md)
*   [rollup-plugin-svelte](https://github.com/sveltejs/rollup-plugin-svelte) 现在处于版本 7.x - 支持相对文件名，更好地处理源图和一致性 `compilerOptions`。 升级时请务必 [checkout the changelog](https://github.com/sveltejs/rollup-plugin-svelte/blob/master/CHANGELOG.md) 进行重大更改
*   [svelte-preprocess](https://github.com/sveltejs/svelte-preprocess) 本月通过一些 4.6.x 版本进行了迭代，以改进 PostCSS 和 SCSS 处理，并修复 TypeScript 用户的 SourceMap 转换。 [More info in the changelog](https://github.com/sveltejs/svelte-preprocess/blob/main/CHANGELOG.md)
*   [Sapper](https://github.com/sveltejs/sapper) 在滚动跟踪和处理编码查询参数方面得到了一些改进。 动态导入现在也可以在不支持 ES 模块的浏览器中按预期工作。 0.29.0和分步迁移指南的这些变化可以找到[in the changelog](https://github.com/sveltejs/sapper/blob/master/CHANGELOG.md)
*   [prettier-plugin-svelte](https://github.com/sveltejs/prettier-plugin-svelte) 版本 2 发布。 它接受了大修，并附带了对 HTML 格式的重写。 输出现在更符合标准 Prettier 格式化 HTML 的方式。 `svelteBracketNewLine` 和 `options-scripts-markup-styles` 的更好默认值现在应该与大多数用户喜欢订购代码块的方式相匹配。 此外，现在支持 Prettier 的 `htmlWhitespaceSensitivity` 设置。 [More info in the changelog](https://github.com/sveltejs/prettier-plugin-svelte/blob/master/CHANGELOG.md)

Svelte Society 网站的新更改包括 [a new cheat sheet](https://sveltesociety.dev/cheatsheet)，以便轻松访问有用的代码模式和整个网站的一些较小的视觉修复。 **想帮助 Svelte Society 网站为黄金时段做好准备吗**？ [Checkout the GitHub repo](https://github.com/svelte-society/sveltesociety.dev) 开始！

*   [This css grid gallery](/playground/3a1b7fae13b242fe9cd4a4f7aa092fa4?version=3.31.2) @Joja制作（在Svelte Discord中）基于用户的鼠标位置进行网格过渡
*   [Patchcab](https://github.com/spectrome/patchcab) 是一种采用 Web 音频制作的模块化 EuroRack 风格合成器。
*   [svelte-knob](https://github.com/MelihAltintas/svelte-knob) 是一个旋钮控制，有助于速度计风格的可视化
*   [descent-ripple](https://github.com/micha-lmxt/descent-ripple)是一个高度可定制的按钮的JavaScript Ripple动画
*   [makeItSnow](https://github.com/florianlouvet/make-it-snow/blob/main/makeItSnowAction.js)是@mrpoule（在svelte discord中）制作的svelte动作，可用于将❄️snow❄️添加到任何组件（[Demo](/playground/de5223beb45540a5a11c9bd7b318304f?version=3.31.2)）

### 新的集成和初学者[](#Community-Showcase-New-Integrations-Starters)

*   [svelte-derver-starter](https://github.com/AlexxNB/svelte-derver-starter) 是一个启动器，用于创建基于 Svelte 的客户端和 Derver 驱动的服务器的全栈应用程序。
*   [eleventy-plugin-embed-svelte](https://github.com/shalomscott/eleventy-plugin-embed-svelte) 可以轻松地将 Svelte 组件嵌入到 11Ty 站点中。
*   [svelte-tailwind-extension-boilerplate](https://github.com/kyrelldixon/svelte-tailwind-extension-boilerplate) 是使用 JavaScript 或 TypeScript 的 Chrome 扩展、前端的 Svelte、用于样式的 Tailwind CSS、用于测试的 Jest 以及作为构建系统的汇总的良好基础。
*   [snowpack-ui](https://github.com/rajasegar/snowpack-ui) 让您从浏览器而不是终端运行和管理 Snowpack 项目
*   [Svelte for Appwrite](https://dev.to/torstendittmann/svelte-for-appwrite-4fkg) 说明如何与自托管的 Firebase 替代方案 AppWrite 集成 [GitHub Repo](https://github.com/appwrite/sdk-for-svelte)
*   [here-maps-svelte](https://github.com/peopledrivemecrazy/here-maps-svelte) 可以轻松地将地图包含在 svelte 应用中
*   [p5-svelte](https://github.com/tonyketcham/p5-svelte) 是将创意编码/草图工具 P5 投入项目中的一种绝对简单的方法
*   [svelte-windicss-preprocess](https://github.com/voorjaar/svelte-windicss-preprocess)是一个svelte预处理器，用于在构建时基于windicss编译器编译tailwindcss
*   [MitzaCoder/svelte-boilerplate](https://github.com/MitzaCoder/svelte-boilerplate) 具有 TypeScript、TailwindCSS、IE11 兼容性（与 Babel）和延迟加载模块的配置。
