祝大家二月快乐！ 在过去的一个月左右的时间里，我们看到了 Svelte 和 Sveltekit [develop at rapid speed](accelerating-sveltes-development)，新的社区规则跨 [Reddit](https://www.reddit.com/r/sveltejs/comments/s9n8ou/new_rules/)、[GitHub](https://github.com/sveltejs/community/blob/main/CODE_OF_CONDUCT.md) 和 [Discord](https://discord.com/channels/457912077277855764/831611707667382303/935264550436102315)，以及许多令人惊叹的应用程序、教程和库。

让我们看看...

svelte 变更日志中的亮点[](#Highlights-from-the-Svelte-changelog)
------------------------------------ --------------------------------------

*   **3.45.0** 带来了 [新 A11Y 警告 `a11y-no-redundant-roles`](https://v4.svelte.dev/docs#accessibility-warnings-a11y-no-redundant-roles)，解构和缓存修复
*   **3.46.0** 添加了很多请求的 [`{@const}` 标记](https://v4.svelte.dev/docs#template-syntax-const) 和 [`style:` 指令](https://v4.svelte.dev/docs#template-syntax-element-directives-style-property)
*   查看 **3.46.1 - 3.46.3** 的 `{@const}` 标签和 `style:` 指令的修复，以及对动画的一些修复
*   [AST output is now available in the Svelte REPL](/playground/hello-world)

sveltekit的新增功能[](#What's-new-in-SvelteKit)
-----------------------------------------------

*   `inlineStyleThreshold` 允许您指定将内联样式表插入页面的位置（[Docs](/docs/kit/configuration#inlineStyleThreshold)、[#2620](https://github.com/sveltejs/kit/pull/2620)）
*   `beforeNavigate` / `afterNavigate` 生命周期函数允许您在页面导航之前或之后添加功能（[Docs](/docs/kit/$app-navigation)、[#3293](https://github.com/sveltejs/kit/pull/3293)）
*   平台上下文现在可以从适配器传递（[Docs](/docs/kit/adapters#Platform-specific-context)，[#3429](https://github.com/sveltejs/kit/pull/3429)）
*   钩子现在在 `resolve` 中有一个 `ssr` 参数，以便在需要时更容易跳过 SSR ([Docs](/docs/kit/hooks#handle)、[#2804](https://github.com/sveltejs/kit/pull/2804))
*   `$page.stuff` 为页面提供了一种将数据“向上”传递到布局的机制（[Docs](https://kit.svelte.dev/docs/loading#input-stuff)、[#3252](https://github.com/sveltejs/kit/pull/3252)）
【1】FallThrough Routes 让您指定无法加载路由时的路由（[#3217](https://github.com/sveltejs/kit/pull/3217)）

### 新配置[](#What's-new-in-SvelteKit-New-configs)

*   使用内联 JavaScript 或样式表（[Docs](/docs/kit/configuration#csp)、[#3499](https://github.com/sveltejs/kit/pull/3499)）时，支持内容安全策略 (CSP)，以提高安全性
*   `kit.routes` config 允许您在构建期间自定义公共/私有模块 ([#3576](https://github.com/sveltejs/kit/pull/3576))
*   `prerender.createIndexFiles` config 允许您预渲染 index.html 文件作为其子文件夹的名称 ([#2632](https://github.com/sveltejs/kit/pull/2632))
*   HTTP 方法现在可以使用 `kit.methodOverride` ([Docs](https://kit.svelte.dev/docs/routing#endpoints-http-method-overrides), [#2989](https://github.com/sveltejs/kit/pull/2989)) 覆盖

### 配置更改[](#What's-new-in-SvelteKit-Config-changes)

*   `config.kit.hydrate`和`config.kit.router`现在嵌套在`config.kit.browser`([3578](https://github.com/sveltejs/kit/pull/3578))下

### 突破性变化[](#What's-new-in-SvelteKit-Breaking-change)

*   在端点和钩子中使用 `Request` 和 `Response` 对象 ([#3384](https://github.com/sveltejs/kit/pull/3384))

### 图书馆、工具和组件[](#Community-Showcase-Libraries-Tools-Components)

*   [threlte](https://github.com/grischaerbe/threlte) 是 Svelte 的 3.js 组件库
*   [svelte-formify](https://github.com/nodify-at/svelte-formify) 是一个用于管理和验证表单的库，它使用装饰器定义验证
*   [gQuery](https://github.com/leveluptuts/gQuery) 是 Svelte 套件的 GraphQL 获取和缓存
*   [Unlock-protocol](https://github.com/novum-insights/sveltekit-unlock-firebase) 是一种集成，用于帮助 MetaMask、Firebase 和 Paywall 客户登录
*   [AgnosticUI](https://github.com/AgnosticUI/agnosticui) 是一组 UI 原语，它们以干净的 HTML 和 CSS 开始它们的生活
*   [Vitebook](https://github.com/vitebook/vitebook) 是 Storybook 的快速轻量级替代品，由 Vite 提供支持
*   [SwyxKit](https://swyxkit.netlify.app/) 是 Sveltekit + Tailwind + Netlify 的固执己见的博客启动器。 2022年刷新！
*   [svelte-themes](https://github.com/beynar/svelte-themes) 是 Sveltekit 应用程序中主题的抽象
*   [svelte-transition](https://www.npmjs.com/package/svelte-transition) 是一个 svelte 组件，可以更轻松地使用基于 CSS 类的转换 - 非常适合与 Tailwindcss 一起使用
*   [Svelte Inview](https://www.npmjs.com/package/svelte-inview) 是监视元素进入或离开视口/父元素的 Svelte 动作
*   [svelte-inline-compile](https://github.com/DockYard/svelte-inline-compile) 是 Babel 变换，在使用 Jest 和 `@testing-library/svelte` 测试 Svelte 组件时，可以获得更愉快的体验
*   [@feltcoop/svelte-mutable-store](https://github.com/feltcoop/svelte-mutable-store) 是一个 svelte 存储，用于具有 `immutable` 编译器选项的可变值
*   [headless-svelte-ui](https://www.npmjs.com/package/@bojalelabs/headless-svelte-ui) 是一组可用于构建苗条应用程序的无头组件。
