到目前为止，它一直是最需要的功能，它终于在这里：Svelte 正式支持 TypeScript。

我们认为它会为您提供更好的开发体验——无论您是使用 TypeScript 还是 JavaScript，它都会精美地扩展到更大的苗条代码库。

![Screenshot of TypeScript in Svelte](/media/svelte-ts.png)

VS Code中的TypeScript + Svelte图像（主题为[Kary Pro](https://marketplace.visualstudio.com/items?itemName=karyfoundation.theme-karyfoundation-themes)）。

立即尝试[](#Try-it-now)
--------------------------

您可以通过运行 `npm create svelte@latest` 并遵循提示来使用 Svelte 的官方脚手架 CLI 启动新的 Svelte TypeScript 项目。 这为您建立了一个新的 Sveltekit 项目。

或者，您可以使用 Svelte 和 TypeScript 运行 `npm create vite@latest myapp -- --template svelte-ts` 来搭建 Vite 项目。

如果您是 VS Code 用户，请确保您使用的是 (new) [official extension](https://marketplace.visualstudio.com/items?itemName=svelte.svelte-vscode)，它取代了 James Birtles 的流行扩展。 在这篇博文中，我们将详细介绍在现有 Svelte 项目中使用 TypeScript 所涉及的各个步骤。

支持 svelte 中的 TypeScript 意味着什么？ [](#What-does-it-mean-to-support-TypeScript-in-Svelte)
------------------------------------------------ ------------------------------------------------

Svelte 中的 TypeScript 支持已经有很长时间了，但是您必须将许多不同的工具混合在一起，每个项目都独立运行。 今天，几乎所有这些工具都存在于苗条的组织之下，由一群负责整个管道并有共同目标的人维护。

在COVID被宣布为大流行之前的一周，[I pitched a consolidation](https://github.com/sveltejs/svelte/issues/4518)来自类似开发生态系统的最好的svelte工具和想法，并提供了一组步骤来获得一流的Typescript支持。 从那时起，许多人都投入并编写了代码以使我们到达那里。

当我们说 Svelte 现在支持 TypeScript 时，我们的意思是一些不同的东西：

*   您可以在 `<script>` 块中使用 TypeScript - 只需添加 `lang="ts"` 属性
*   TypeScript的组件可以通过`svelte-check`命令进行类型检查
*   在编写组件时，您会获得自动完成提示和类型检查，即使是在标记内的表达式中
*   TypeScript 文件了解 Svelte 组件 API — 将 `.svelte` 文件导入 `.ts` 模块时不再出现红色波浪

### 它是如何工作的？[](#What-does-it-mean-to-support-TypeScript-in-Svelte-How-does-it-work)

为了了解 TypeScript 支持的两个主要部分，我们将其与 TypeScript 用于提供开发工具的技术进行比较。 有一个编译器 `tsc` 在命令行上运行以将 `*.ts` 转换为 `*.js`，然后有一个 `TSServer`，它是响应来自文本编辑器的请求的节点 API。 `TSServer` 是在编码时为编辑者提供所有 JavaScript 和 TypeScript 实时内省的东西，并且它包含了编译器的大部分代码。

对于 Svelte，我们有 svelte 编译器，现在我们有 [`svelte-language-server`](https://github.com/sveltejs/language-tools/tree/master/packages/language-server#svelte-language-server) 通过 [Language Server Protocol standard](https://microsoft.github.io//language-server-protocol/overviews/lsp/overview/) 响应文本编辑器的调用。 第一类 TypeScript 支持意味着这两个系统中的 _both_ 都能很好地处理 TypeScript 代码。

对 TypeScript 的 svelte 编译器支持由 [Christian Kaisermann](https://github.com/kaisermann) 的 [`svelte-preprocess`](https://github.com/sveltejs/svelte-preprocess#svelte-preprocess) 处理，它现在是一个官方的 svelte 项目。

对于编辑器级别，我们通过[Vetur](https://github.com/vuejs/vetur)从[Vue](https://vuejs.org)生态系统中的[Pine’s](https://github.com/octref)工作中获得灵感。 Vetur 提供 [LSP](https://github.com/vuejs/vetur/blob/master/server)、VS 代码扩展和 [CLI](https://github.com/vuejs/vetur/blob/master/vti)。 Svelte 现在还有一个 [LSP](https://github.com/sveltejs/language-tools/blob/master/packages/language-server)、一个 [VS Code extension](https://github.com/sveltejs/language-tools/blob/master/packages/svelte-vscode) 和一个 [CLI](https://github.com/sveltejs/language-tools/blob/master/packages/svelte-check)。

### \*.svelte 内省[](#What-does-it-mean-to-support-TypeScript-in-Svelte-.svelte-Introspection)

对于官方的 svelte vs 代码扩展，我们建立了 [James Birtles](https://github.com/UnwrittenFun) 在 [`UnwrittenFun/svelte-vscode`](https://github.com/UnwrittenFun/svelte-vscode) 和 [`UnwrittenFun/svelte-language-server`](https://github.com/UnwrittenFun/svelte-language-server/) 中创建的基础。

[Simon Holthausen](https://github.com/dummdidumm) 和 [Lyu, Wei-Da](https://github.com/jasonlyu123) 在改进 JavaScript 和 TypeScript 内省方面做了出色的工作，包括集成 [@halfnelson](https://github.com/halfnelson) 的 [svelte2tsx](https://github.com/sveltejs/language-tools/tree/master/packages/svelte2tsx#svelte2tsx)，它支持您在代码中的组件上理解道具。

将 TypeScript 添加到现有项目[](#Adding-TypeScript-to-an-existing-project)
---------------------------------------- -----------------------------------------

在开始之前，添加依赖项：

npm install --save-dev @tsconfig/svelte typescript svelte-preprocess svelte-check

### 1\ 编译打字稿[](#Adding-TypeScript-to-an-existing-project-1.-Compiling-TypeScript)

您首先需要设置 [`svelte-preprocess`](https://github.com/sveltejs/svelte-preprocess#svelte-preprocess)，将 `<script lang="ts">` 块的内容传递给 TypeScript 编译器。

在一个汇总项目中，它看起来像这样——请注意，我们还需要安装 `@rollup/plugin-typescript` 以便 rollup 可以处理 `.ts` 文件：

从“svelte-preprocess”导入 AutoPreprocessImport autoPreprocess；
从 '@rollup/plugin-typescript' 导入 TypeScriptImport 打字稿；
    
导出默认 {
// ...,
plugins(property) plugins: any[]: [
svelteany({
预处理（属性） 预处理： 任何：AutoPreprocessImport autoPreprocess()
}),
TypeScriptImport TypeScript({ sourcemap(property) sourcemap: boolean: !productionany })
]
}

[Full instructions for other environments here](https://github.com/sveltejs/svelte-preprocess#usage)。

要配置 TypeScript，您需要在项目的根目录中创建一个 `tsconfig.json`：

{
“扩展”：“@tsconfig/svelte/tsconfig.json”，
    
"include": ["src/**/*", "src/node_modules"],
"排除": ["node_modules/*", "__sapper__/*", "public/*"]
}

您的 `include` / `exclude` 每个项目可能会有所不同 - 这些是适用于大多数较小项目的默认值。

### 2\。 编辑支持[](#Adding-TypeScript-to-an-existing-project-2.-Editor-Support)

可以支持任何编辑器 [using an LSP](https://langserver.org/#implementations-client)。 [VS Code](https://marketplace.visualstudio.com/items?itemName=svelte.svelte-vscode) 扩展一直是我们的主要关注点，但仍在进行中 [on Atom](https://github.com/sveltejs/language-tools/pull/160)，并且 Vim 通过 [coc-svelte](https://github.com/coc-extensions/coc-svelte) 已更新为最新的 LSP。

即使您仅使用 JavaScript，这些编辑器扩展也会改善您的编码体验。 编辑器不会提供错误，但它将提供推理和重构工具。 您可以使用 JavaScript 将 `<script>` 标记的顶部 [添加 `// @ts-check`](https://www.staging-typescript.org/docs/handbook/intro-to-js-ts.html) 获取更好的错误消息，而没有任何次要更改。

要将 `<script>` 切换为使用 TypeScript，请使用 `<script lang="ts">`，这应该是。 希望你不会看到一片红色的波浪海域。

### 3\ CI检查[](#Adding-TypeScript-to-an-existing-project-3.-CI-Checks)

有红色的曲线是伟大的，嗯，有点。 但从长远来看，您希望能够验证代码中没有错误。 要验证您的项目是否无错误，您可以使用 CLI 工具 [`svelte-check`](https://www.npmjs.com/package/svelte-check)。 它的作用就像一个编辑器，要求对你的所有`.svelte` 文件产生错误。

您可以将依赖项添加到项目中，然后将其添加到 CI。

❯ npx svelte-check
    
在工作空间中加载 svelte-check: /users/ortatherox/dev/svelte/example-app
获得纤巧的诊断...
=======================================
    
/用户/Ortatherox/dev/svelte/example-app/src/app.svelte:3:2
错误：类型“123”不能分配给“字符串”类型。 （TS）
    
=======================================
svelte-check 发现 1 错误
错误命令失败，退出代码 1。

Sapper项目中的TypeScript怎么样？[](#What-about-TypeScript-in-Sapper-projects)
----------------------------------------- -----------------------------------------

在 0.28 中向 Sapper 添加了 TypeScript 支持，因此如果您使用的是旧版本，请务必 [upgrade](https://sapper.svelte.dev/migrating#0_27_to_0_28)。
