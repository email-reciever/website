从 ChangeLog ([JS Party Ep. 182](https://changelog.com/jsparty/182)) 到 Svelte 收音机（第 [29](https://share.transistor.fm/s/adc23e84) 和 [30](https://share.transistor.fm/s/6316622d) 集），似乎人们不禁谈论 Svelte，这个月！ 此外，Shadow DOM 支持和新的导出和等待功能在 Svelte 中是新的。

Svelte 中的新功能[](#New-in-Svelte)
------------------------------

七月是自 2019 年底以来 Svelte Core 回购最活跃的月份，因为我们确实在努力减少优秀 PR 的数量，并看到 Svelte 3.39.0、3.40.0 和 3.41.0 的发布。 添加了大量的错误修复以及以下新功能：

*   `|trusted`事件修改器允许您在调用（[#6137](https://github.com/sveltejs/svelte/issues/6137)）之前检查事件是否受信任
*   支持改进Sveltekit SSR的新`svelte/ssr`包([#6416](https://github.com/sveltejs/svelte/pull/6416))
*   新的 `errorMode` 编译器选项，支持对 TypeScript 文件进行改进的预处理 ([#6194](https://github.com/sveltejs/svelte/pull/6194))
*   现在可以在创建组件时将`ShadowRoot`指定为`target` - 可以在阴影DOM（[#5869](https://github.com/sveltejs/svelte/issues/5869)）内渲染Svelte组件
*   Svelte 组件现在支持 `export { ... } from` ([#2214](https://github.com/sveltejs/svelte/issues/2214))、`export let { ... } =` ([#5612](https://github.com/sveltejs/svelte/issues/5612)) 和 `{#await ... then/catch}` ([#6270](https://github.com/sveltejs/svelte/issues/6270)) 语法

有关功能和错误修复的完整列表，请查看 [Svelte changelog](https://github.com/sveltejs/svelte/blob/master/CHANGELOG.md)。

Sveltekit 更新[](#SvelteKit-Updates)
--------------------------------------

*   `prerender.force`现在是`prerender.onError`，它可以让你微调哪些错误失败，哪些没有（[#2007](https://github.com/sveltejs/kit/pull/2007)）
*   ESBuild 的配置现已公开用于 Sveltekit 适配器 ([#1914](https://github.com/sveltejs/kit/pull/1914))
*   对于常见的配置错误（[#1910](https://github.com/sveltejs/kit/pull/1910)）和编译器错误（[#1827](https://github.com/sveltejs/kit/pull/1827)），错误消息现在更加友好
*   仅当目标主机与 sveltekit 应用程序或其更具体的子域名相同时，cookies 才会通过 ([#1847](https://github.com/sveltejs/kit/pull/1847))
*   在打包时，index.js 导出将更改为目录导出 - 使导入更好（[#1905](https://github.com/sveltejs/kit/pull/1905)）
*   Vite.js 的 `mode` 现已从 `$app/env` ([#1789](https://github.com/sveltejs/kit/pull/1789)) 中曝光
*   整体类型更好（[#1778](https://github.com/sveltejs/kit/pull/1778)、[#1791](https://github.com/sveltejs/kit/pull/1791)、[#1646](https://github.com/sveltejs/kit/pull/1646)）

要查看 Sveltekit 的所有更新，请查看 [SvelteKit changelog](https://github.com/sveltejs/kit/blob/master/packages/kit/CHANGELOG.md)。

Svelte/\*[](#Features-bug-fixes-from-around-svelte)周围的功能和错误修复
---------------------------------------- ----------------------------------------

*   语言工具现在更好地支持“工作场所信任”功能（在VS Code中使用）
*   在 svelte2tsx 中，环境类型声明现在被重命名，以避免将来发生冲突的声明。 用户现在应该自己提供环境类型定义 - 修复JS输出
*   Sapper 发布了 v0.29.2，用于修复正则表达式路由、请求目录时的状态代码以及用户未提供 `base` 标记时导出的导出 ([changelog](https://github.com/sveltejs/sapper/blob/master/CHANGELOG.md))
