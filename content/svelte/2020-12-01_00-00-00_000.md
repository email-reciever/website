这是今年最后一个“Svelte 中的新事物”，有很多值得庆祝的地方！ 本月的报道包括来自 `rollup-plugin-svelte`、`Sapper` 和 `SvelteKit` 的更新以及来自 Svelte 社区的一系列展示！

新功能和有影响力的错误修复[](#New-features-impactful-bug-fixes)
-------------------------------------------------------------------

1.  `$$props`、`$$restProps`和`$$slots`现在都支持自定义Web组件（**3.29.5**，[Example](/playground/ad8e6f39cd20403dacd1be84d71e498d?version=3.29.5)）和`slot`组件，现在支持传播道具：`<slot {...foo} />`（**3.30.0**）
2.  新的 `hasContext` 生命周期函数可以轻松检查父组件的上下文中是否设置了 `key` (**3.30.0** & **3.30.1**, [Docs](https://v4.svelte.dev/docs#run-time-svelte-hascontext))
3.  现在有一个新的 `SvelteComponentTyped` 类，它可以更容易地添加扩展基本 svelte 组件的强类型组件。 组件库和框架作者欢欣鼓舞！ 一个例子：`export class YourComponent extends SvelteComponentTyped<{aProp: boolean}, {click: MouseEvent}, {default: {aSlot: string}}> {}`（**3.31.0**，[RFC](https://github.com/sveltejs/rfcs/pull/37)）
4.  `{:else}`块内的过渡现在应该成功完成（**3.29.5**，[Example](/playground/49cef205e5da459594ef2eafcbd41593?version=3.29.5)）
5.  Svelte现在包含一个导出地图，其中明确说明可以从其npm包中导入哪些文件（**3.29.5**，在**3.29.6**、**3.29.7**和**3.30.0**中进行一些修复）
6.  `rollup-plugin-svelte` 有一个新的 [7.0.0 release](https://github.com/sveltejs/rollup-plugin-svelte/blob/master/CHANGELOG.md)。 最大的变化是 `css` 选项被删除。 使用该选项的用户应该添加另一个插件，如 `rollup-plugin-css-only` 所示 [in the template](https://github.com/sveltejs/template/blob/5b1135c286f7a649daa99825a077586655051649/rollup.config.js#L48)

Sapper 发生了什么？[](#What's-going-on-in-Sapper)
----------------------------------------------------

许多新的 TypeScript 定义改进，使编辑 Sapper 应用程序变得更加容易！ 动态导入的 CSS 现在也应该在 `client.js` 文件中运行。 （未发布）

--------------------------------------------------------------

社区展示[](#Community-Showcase)
----------------------------------------

### 应用和网站[](#Community-Showcase-Apps-Sites)

*   [narration.studio](https://narration.studio/)（仅限 Chrome）是一个自动浏览器内的录音和编辑平台，用于语音旁白。
*   [Vippet](https://vippet.netlify.app/)是浏览器的视频录制和编辑工具。
*   [Pattern Monster](https://pattern.monster/) 是一个简单的在线模式生成器，用于创建可重复的 SVG 模式。
*   [Plant-based diets](https://planetbaseddiets.panda.org/) 是世界野生动物基金会 (WWF) 的网站，该网站采用 Svelte 构建。
*   [johnells.se](https://www.johnells.se/) 是瑞典时尚电子商务网站，搭建了 [Crown](https://crownframework.com/) - 一个由 Svelte 驱动的框架。
*   [sentence-length](https://sentence-length.netlify.app/) 是一种学习和分析工具，展示了一些作者如何以不同的长度玩耍，而另一些则坚持使用。
*   [svelte-presenter](https://github.com/stephane-vanraes/svelte-presenter) 可让您使用 Svelte 和 MDSVEX 快速制作精美的演示文稿。

### 演示[](#Community-Showcase-Demos)

*   [u/loopcake got SSR working in Java Spring Boot](https://www.reddit.com/r/sveltejs/comments/jkh5up/svelte_ssr_but_its_java_spring_boot_and_its_native/) 对于所有希望渲染 svelte 服务器端的 Java 商店。
*   [svelte-liquid-swipe](https://github.com/tncrazvan/svelte-liquid-swipe) 使用 SVG 路径展示了一种花哨的交互模式。
*   [Crossfade Link Animation](/playground/7f68e148caf04b2787bb6f296208f870?version=3.29.7)演示了如何使用交叉淡入淡出导航链接之间的动画（由Blu制作，来自Discord社区）
*   [Clip-Path Transitions](/playground/b5ad281ae8024b629b545c70c9e8764d?version=3.29.7) 展示了如何使用剪辑路径和自定义过渡来创建神奇的进出转换（由 Faber 制作，来自 Discord 社区）

### 学习资源[](#Community-Showcase-Learning-Resources)

*   [lihautan](https://www.youtube.com/channel/UCbmC3HP3FaAFdcZkui8YoMQ/featured) 一直在制作易于关注的视频，以分享他对 Svelte 的深入了解。
*   [Lessons From Building a Static Site Generator](https://nicholasreese.com/lessons-from-building-a-static-site-generator/) 分享了 Elder.js 背后的背景故事和想法——以及一路上做出的设计决定。
*   [Svelte Tutorial and Projects Course](https://www.udemy.com/course/svelte-tutorial-and-projects-course/) 是 John Smilga 的 Udemy 课程，学生通过构建有趣的项目来学习 svelte.js。
*   [Building Pastebin on IPFS - with FastAPI, Svelte, and IPFS](https://amalshaji.wtf/building-pastebin-on-ipfs-with-fastapi-svelte-and-ipfs) 解释了如何制作分布式 Pastebin 应用程序。

### 组件、库和工具[](#Community-Showcase-Components-Libraries-Tools)

*   [svelte-crossword](https://russellgoldenberg.github.io/svelte-crossword/) 是 Svelte 的可定制填字游戏组件。
*   [svelte-cloudinary](https://github.com/cupcakearmy/svelte-cloudinary) 使 Cloudinary 与 Svelte 集成（包括 TypeScript 和 SSR 支持）
*   [Svelte Nova](https://extensions.panic.com/extensions/sb.lao/sb.lao.svelte-nova/) 扩展了新的 Nova 编辑器以支持 Svelte
*   [saos](https://github.com/shiryel/saos) 是一个小巧的组件，用于为您的滚动元素设置动画。
*   [Svelte-nStore](https://github.com/lacikawiz/svelte-nStore) 是一种通用的商店替换，它满足 Svelte 商店合同并添加了 Getter 和计算功能。
*   [svelte-slimscroll](https://github.com/MelihAltintas/svelte-slimscroll) 是一个 svelte 动作，它将任何 div 转换为带有漂亮滚动条的可滚动区域。
*   [svelte-typewriter](https://github.com/henriquehbr/svelte-typewriter) 是一种简单且可重复使用的打字机效果，适用于您的 Svelte 应用程序
*   [svelte-store-router](https://github.com/zyxd/svelte-store-router) 是 Svelte 的基于商店的路由器，它表明路由只是另一个全局状态，历史 API 更改只是该状态的可选副作用。
*   [Routify](https://routify.dev/blog/routify-2-released) 刚刚发布了其 Svelte 路由器的第 2 版。
*   [svelte-error-boundary](https://www.npmjs.com/package/@crownframework/svelte-error-boundary) 为 Svelte 提供了一个简单的误差边界分量，可以与 DOM 和 SSR 目标一起使用。
*   [svelte2dts](https://www.npmjs.com/package/svelte2dts) 从 svelte 文件生成 d.ts 文件，创建真正可共享且类型良好的组件。
