但在那之前，我们有一些更新要Highlight...

## Svelte 和 SvelteKit 中的新功能[](#What's-new-in-Svelte-and-SvelteKit)

Svelte 维护者们这个月一直在努力构建 [异步 Svelte](https://github.com/sveltejs/svelte/discussions/15845) ，但仍然有时间发布了一些有用的功能。如果您有兴趣尝试异步分支，或者只是想跟随开发进度，请查看 [feat: allow await in components #15844](https://github.com/sveltejs/svelte/pull/15844)

* 某些表达式现在将被部分评估以提高运行时性能 (**svelte@5.27.0/5.28.0**, [#15494](https://github.com/sveltejs/svelte/pull/15494)/[#15781](https://github.com/sveltejs/svelte/pull/15781))
* Svelte CLI (`sv`) 已添加一个 `--install <package-manager>` 标志到 `create` 和 `add` 中，以指定运行时使用的包管理器 (**cli@0.8.1**, [#531](https://github.com/sveltejs/cli/pull/531))
* 两个单独的 CloudFlare 适配器已合并为一个： `adapter-cloudflare` (**adapter-cloudflare@7.0.0**, [#13634](https://github.com/sveltejs/kit/pull/13634))
* `adapter-vercel` 现在将为每个路由创建符号链接函数，以提高可观察性 (**adapter-vercel@5.7.0**, [#13679](https://github.com/sveltejs/kit/pull/13679))

SvelteKit 中也有许多修复，包括对 `HandleServerError` hook 的改进，使其能够访问 `getRequestEvent`！ ([#13666](https://github.com/sveltejs/kit/pull/13666))

为了获取 Svelte、SvelteKit 及其适配器的全部 bug 修复列表，请查看它们的 CHANGELOG 文件，分别位于 [这里](https://github.com/sveltejs/svelte/blob/main/packages/svelte/CHANGELOG.md) 和 [这里](https://github.com/sveltejs/kit/tree/main/packages)。如果您对语言工具的新修复感兴趣，可以在 [这里](https://github.com/sveltejs/language-tools/releases)找到它们。

## 社区展示[](#Community-Showcase)

### 使用 Svelte 构建的应用和网站[](#Community-Showcase-Apps-Sites-built-with-Svelte)

* [TableSlayer](https://github.com/siege-perilous/tableslayer) 是一个开源软件，用于管理现场 RPG 游戏的数字显示（请查看 [Reddit](https://www.reddit.com/r/sveltejs/comments/1jnco5h/built_with_svelte_my_open_source_software_for/) 上的视频演示）
* [Iconia](https://iconia.dev/) 是一个免费工具，理解自然语言并用著名图标库中的相关图标响应
* [CMSDocs](https://cmsdocs.com/) 将您的 Google Docs 转换为博客 CMS
* [Svelte Changelog v2](https://svelte-changelog.dev/) 现已发布，是一种重新imagined的方式，用于跟踪 Svelte 生态系统中的所有新变化
* [Hookah UI](https://github.com/AdamShannag/hookah-ui) 是 Hookah 项目的视觉配置生成器
* [mockiapi](https://github.com/sfeSantos/mockiapi) 是一个模拟 API 服务器，允许您定义端点、返回自定义 JSON 响应并模拟真实世界的 API 行为
* [soarSQL](https://soarsql.com/) 是一个为 Postgres、MySQL 和 CSV 的分析处理而设计的 SQL 编辑器，powered by duckDB
* [Persona Simulator](https://personasim.fow.sh/) 通过与不同角色聊天帮助您练习您的沟通技巧
* [Typo](https://typo.robino.dev/) 是一个基于 Web 的 markdown 编辑器，具有代码块中的格式化和 typescript 执行
* [FernOS](https://github.com/mrtechtroid/fernos) 是一个在您的浏览器中运行的轻量级操作系统
