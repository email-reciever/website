本月，Svelte 和 Sveltekit 的一些甜蜜新功能都下降了。 很高兴看到有多少产品和副项目使用 Svelte 作为其核心技术推出了许多产品和副项目！

更多关于下面的所有...

Svelte 和语言工具的新功能[](#What's-new-in-Svelte-Language-Tools)
------------------------------------ --------------------------------------

自 Svelte 4 发布以来，出现了一堆小错误修正。 您可以在 [CHANGELOG](https://github.com/sveltejs/svelte/blob/master/packages/svelte/CHANGELOG.md) 中找到它们。

**4.1.0 版本** 添加了进一步自定义包装底层 svelte 组件的自定义元素类的功能。 查看 [Custom Elements API docs](/docs/svelte/custom-elements) 或 [PR](https://github.com/sveltejs/svelte/pull/8991) 了解更多信息！

除了支持 sveltekit 的新 `HEAD` 服务器方法外，Svelte 的语言工具现在还支持 Prettier V3 (**extensions-107.9.0**) 和 Workspace 信任设置现在用于支持 Workspace 中的所有设置 （**扩展-107.8.0**）。

sveltekit的新增功能[](#What's-new-in-SvelteKit)
-----------------------------------------------

*   API 路由（**1.22.0**、[Docs](/docs/kit/routing#server)、[#9753](https://github.com/sveltejs/kit/pull/9753)）中提供了 `HEAD` 服务器方法
*   现在也缓存了 `Vary` 标头的响应（`Vary: *`）（**1.22.0**、[Docs](/docs/kit/routing#server-Content-negotiation)、[#9993](https://github.com/sveltejs/kit/pull/9993)）
*   如果 sveltekit 的构建输出不存在（**1.22.2**，[#10337](https://github.com/sveltejs/kit/pull/10337)），现在有一个更有用的预览错误

对于本月的所有补丁和性能更新，请查看 [SvelteKit CHANGELOG](https://github.com/sveltejs/kit/blob/master/packages/kit/CHANGELOG.md)。 您还可以在每个 `adapter` 目录](https://github.com/sveltejs/kit/tree/master/packages) 中找到适配器特定的更改日志。
