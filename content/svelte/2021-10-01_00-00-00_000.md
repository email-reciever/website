嘿，你们都已经 1 年了，“Svelte 的新功能”开始交叉发布到 Svelte 博客已经 1 年了。 我想在顶端抓住这一刻，感谢你们所有人的阅读和每个月的所有贡献者。 从维护者到在 Discord 和 Reddit 中发布他们的工作的每个人，见证使 Svelte 社区变得伟大所付出的所有努力，真是令人惊叹。

大家继续努力吧！ 现在，让我们深入了解本月的新闻...

Svelte 周围的新功能[](#New-around-Svelte)
--------------------------------------

*   Svelte导出地图的新增功能现在公开了SSR生命周期函数的无操作版本（Svelte **3.43.0**）
*   具有 `src` 属性的自定义组件不再中断 `svelte-native` 构建（Svelte **3.42.4**）
*   现在将提示未启用 [the TypeScript plugin](https://www.npmjs.com/package/typescript-svelte-plugin) 的 Svelte 插件用户启用它。 它通过额外的 IntelliSense 增强了 TypeScript 和 JavaScript 文件，以与 svelte 文件进行交互。 [Please leave feedback](https://github.com/sveltejs/language-tools/issues/580) 如果您使用它（Svelte 扩展名 **105.4.0**）
*   事件修改器已添加到 IntelliSense 作为自动完成和悬停信息（Svelte 扩展 **105.4.0**）
*   Typescript 用户在使用 Svelte 3.39 或更高版本和 `svelte-preprocess` 版本 4.9.5 或更高版本时不再需要严格分开类型导入和值导入。 这意味着您现在可以编写 `import { MyInterface, myValue } from './somewhere'` 而不是 `import type { MyInterface } from './somewhere'; import { myValue } from './somewhere'`。 非常感谢社区成员 [@SomaticIT](https://github.com/SomaticIT) 主要实施了这一点！

有关功能和错误修复的完整列表，请查看 [Svelte changelog](https://github.com/sveltejs/svelte/blob/master/CHANGELOG.md)。

Sveltekit 更新[](#SvelteKit-Updates)
--------------------------------------

上个月有近 100 个 PR 再次承诺，但仍有很多工作要做，而 Svelte 维护者则 [looking for help getting SvelteKit to 1.0](https://github.com/sveltejs/kit/issues/2100)。 安东尼在[recent comment](https://github.com/sveltejs/kit/issues/2100#issuecomment-895446285)上说得很好：

> 如果您认为自己太n00b无法贡献（您不是），那么在添加之前为要添加的功能添加测试或编写测试！ 从小处着手，以这种方式学习代码库。

如果您想提供帮助，请考虑使用 [1.0 milestone issues labeled with “help wanted”](https://github.com/sveltejs/kit/issues?q=is%3Aopen+is%3Aissue+milestone%3A1.0+label%3A%22help+wanted%22) 中的任何一个。

本月值得注意的Sveltekit改进包括...

*   现在允许服务工作者使用 `$lib` 别名 ([#2326](https://github.com/sveltejs/kit/pull/2326)) 访问文件
*   Svelte库现在应该在没有任何Vite配置的情况下开箱即用（[#2343](https://github.com/sveltejs/kit/pull/2343)）
*   改进包导出字段（[#2345](https://github.com/sveltejs/kit/pull/2345)和[#2327](https://github.com/sveltejs/kit/pull/2327)）
*   \[breaking\] `prerender.pages` 配置选项已重命名为 `prerender.entries` ([#2380](https://github.com/sveltejs/kit/pull/2380))
*   添加了一个新的通用参数以允许从钩子中键入主体（[#2413](https://github.com/sveltejs/kit/pull/2413)）
*   运行package命令时，`svelte`字段将添加到package.json中（[#2431](https://github.com/sveltejs/kit/pull/2431)）
*   \[breaking\] 加载函数的 `context` 参数被重命名为 `stuff` ([#2439](https://github.com/sveltejs/kit/pull/2439))
*   添加了 `entryPoint` 选项，用于使用 `adapter-node` ([#2414](https://github.com/sveltejs/kit/pull/2414)) 构建自定义服务器
*   `vite-plugin-svelte` 改进了对 [useVitePreprocess](https://github.com/sveltejs/vite-plugin-svelte/blob/main/docs/config.md#usevitepreprocess) 的支持，它使用 Vite 在 Svelte 组件中自动预处理 TypeScript、PostCSS、SCSS 等

要查看 Sveltekit 的所有更新，请查看 [SvelteKit changelog](https://github.com/sveltejs/kit/blob/master/packages/kit/CHANGELOG.md)。
