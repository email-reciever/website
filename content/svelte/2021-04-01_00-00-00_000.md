两个经过数月（甚至数年）的项目已经走向世界。 Sveltekit 现在处于公共测试阶段，Slotted 组件现在以 Svelte 提供！

sveltekit 怎么了？[](#What's-up-with-SvelteKit)
--------------------------------------------------

[SvelteKit](https://kit.svelte.dev/) - Svelte 的用于构建 SSR、无服务器应用程序或 SPA 的多功能框架 - 现在正式处于公共测试阶段。 期待虫子！ [latest blog post](/blog/sveltekit-beta)中的更多细节。 想知道 1.0 何时关闭吗？ 查看[github](https://github.com/sveltejs/kit/milestone/2)上的里程碑。

想了解更多关于如何入门，与 Sapper、新功能和迁移路径相比有什么不同？ 查看本周的 [episode of Svelte Radio](https://www.svelteradio.com/episodes/svelte-kit-public-beta) 与 Antony、Kev 和 Swyx 进行深度潜水。

Svelte 和语言工具的新功能[](#New-in-Svelte-Language-Tools)
-----------------------------------------------------------

*   插槽组件，包括 `<svelte:fragment slot="...">` 允许组件使用者针对具有丰富内容的特定插槽（**svelte 3.35.0，语言工具 [104.5.0](https://github.com/sveltejs/language-tools/releases/tag/extensions-104.5.0)**）
*   链接编辑现在适用于 svelte 文件中的 HTML（**语言工具，[104.6.0](https://github.com/sveltejs/language-tools/releases/tag/extensions-104.6.0)**）
*   类型定义 `svelte.d.ts` 现在按顺序解析，允许库作者使用其 svelte 组件发送类型定义（**语言工具，[104.7.0](https://github.com/sveltejs/language-tools/releases/tag/extensions-104.7.0)**）
*   [vite-plugin-svelte](https://github.com/sveltejs/vite-plugin-svelte) 可用于 Svelte in Vite 的一般使用。 `npm init @vitejs/app` 包括使用此插件的 svelte 选项。

社区展示[](#Community-Showcase)

### 应用和网站[](#Community-Showcase-Apps-Sites)

*   [Nagato](https://nagato.app/) 是一种任务管理工具，将流行的时间跟踪和待办事项工具集中在一个地方。
*   [type-kana](https://type-kana.cass.moe/setup) 是一个测验应用程序，用于帮助您学习日本音节 ひらがな（平假名）和 カタカナ（片假名）。
*   [Pittsburgh Steps](https://pittsburgh-steps.samlearner.com/)是宾夕法尼亚州匹兹堡800多套公共户外楼梯的互动地图。
*   [Music Mode Wheels](https://tobx.github.io/music-mode-wheels/) 是一个将音乐模式显示为交互式轮子的网站。
*   [Critical Notes](https://www.critical-notes.com/) 帮助游戏大师和玩家跟踪他们的角色扮演游戏活动和冒险。
*   [Svelte Game of Life](https://github.com/alanrsoares/svelte-game-of-life)是康威在Typescript + Svelte中对Conway的生命游戏的教育实现
*   [foxql](https://github.com/foxql) 是在浏览器上运行的点对点全文搜索引擎。

### 演示、库、工具和组件[](#Community-Showcase-Demos-Libraries-Tools-Components)

*   [svelte-nodegui](https://github.com/nodegui/svelte-nodegui) 是一种使用 Node.js 和 Svelte 构建高性能、原生和跨平台桌面应用程序的方法
*   [Svelte Story Format](https://www.npmjs.com/package/@storybook/addon-svelte-csf) 允许您使用 svelte 语法在 Storybook 中编写“故事”。 更多信息[Storybook blog](https://storybook.js.org/blog/storybook-for-svelte/)
*   [SelectMadu](https://github.com/pavish/select-madu) 是选择菜单的替代品，支持搜索、多项选择、异步数据加载等。
*   [Svelte Checklist](https://www.npmjs.com/package/svelte-checklist) 是使用 svelte 构建的可定制检查表。
*   [Suspense for Svelte](https://www.npmjs.com/package/@jamcart/suspense) 是实现 React `<Suspense>` 的核心思想的 Svelte 组件。
*   [MiniRx](https://spierala.github.io/mini-rx-store/) 是一个 RxJS Redux 存储，它适用于 Svelte 和 TypeScript
*   [svelte-formly](https://github.com/arabdevelop/svelte-formly) 为 Svelte 和 Sapper 生成动态表单
*   [7ty](https://www.npmjs.com/package/@jamcart/7ty) 是一个静态站点生成器，使用 svelte，支持组件的部分水合，并使用类似于 Sapper 和 11ty 的基于文件的路由。

**想贡献您自己的组件吗？** [Submit your own component](https://sveltesociety.dev/help/submitting?type=package) 到 Svelte Society 网站上的 [packages](https://sveltesociety.dev/packages) 列表中。

### 初学者[](#Community-Showcase-Starters)

*   [sveltekit-tailwindcss-external-api](https://github.com/acidlake/sveltekit-tailwindcss-external-api) 是您使用 Tailwindcss 和外部 API 构建 Svelte 项目所需的一切，由 create-svelte 提供支持。

### 学习资源[](#Community-Showcase-Learning-Resources)

*   [How to Build a Website with Svelte and SvelteKit](https://prismic.io/blog/svelte-sveltekit-tutorial) 是一个逐步的教程，介绍了新的 Sveltekit 设置。
*   [A Svelte store for prefers-reduced-motion](https://geoffrich.net/posts/svelte-prefers-reduced-motion-store/) 演示如何制作一个自定义 svelte 商店，其值将指示用户是否请求减少动作并提高可访问性。
*   [TypeScript support in Svelte](https://developer.mozilla.org/en-US/docs/Learn/Tools_and_testing/Client-side_JavaScript_frameworks/Svelte_TypeScript) 是在 Svelte 中使用 TypeScript 的 MDN 指南。
*   [How to merge cells with svelte-window](https://gradientdescent.de/merging-cells/) 是 svelte-window 的演练，它是流行的 react-window 工具合并表单元的端口。 有关此迁移的更多信息，请参见 [from react-window 1:1 to svelte-window](https://gradientdescent.de/porting-react-window/)。
*   [Easy-to-Embed Svelte Components](https://codeandlife.com/2021/03/06/easy-to-embed-svelte-components/) 解释了如何使用 rollup 和 script 标签在任何地方嵌入 svelte 组件。
*   [Convert Svelte project from Rollup to Snowpack](https://www.youtube.com/watch?v=-sHcqj4YLeQ) 在视频上浏览常见的迁移模式。
*   [How to internationalize routing in Svelte & Sapper](https://www.leaf.cloud/blog/how-to-internationalize-routing-in-svelte-sapper?utm_medium=story&utm_source=reddit.com&utm_campaign=awareness&utm_content=sapper_routing) 解释了 Leaf.Cloud 如何将他们的网站翻译成荷兰语。
*   [Svelte Store: Reactive context using Svelte Store](https://www.youtube.com/watch?v=-rTnWlbdjoY) 是对“我们如何使 \[a\] 上下文值响应式”的问题的视频回答？
*   [Creating Social Sharing Images with Cloudinary and Svelte](https://www.youtube.com/watch?v=-Si5o-R7KHY) 是来自 Cloudinary 的视频，演示了如何为 JamStack 网站动态开发开放式图形图像和 Twitter 卡。
