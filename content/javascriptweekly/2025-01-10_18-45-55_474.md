**简而言之：**

* 🥊 Deno 与 Oracle 围绕 JavaScript™ 商标的斗争仍在继续，Oracle 已通知 Deno [他们不会自愿放弃该商标。](https://javascriptweekly.com/link/164152/d076523b1d) Deno 现在的工作是展示 JavaScript 长期以来如何被用作通用术语并且不受 Oracle 控制。

* Express.js 团队已发布[有关该项目最近的复兴及其在 2025 年推动 Express.js 发展的计划。](https://javascriptweekly.com/link/164153/d076523b1d)

* ❄️ “WinterCG”*Web 互操作运行时社区小组*，致力于促进 JavaScript 运行时的运行时互操作性标准，[已移至 Ecma International](https://javascriptweekly.com/link/164154/d076523b1d)，并且正在现在称为 \[WinterTC （TC55）。]（https://javascriptweekly.com/link/164155/d076523b1d）

* 📺 Node.js 创建者 Ryan Dahl 在 [*GOTO Chicago 2024* 上发表了关于 Deno 2 的演讲](https://javascriptweekly.com/link/164156/d076523b1d)，涵盖了 Deno 与 Node 的差异以及 \[Deno 2.0]\( https://javascriptweekly.com/link/164157/d076523b1d）（和 JSR）有为 JavaScript 开发人员提供完整的现场演示。

**发布：**

* [pnpm 10](https://javascriptweekly.com/link/164159/d076523b1d) – 出于安全原因，高效的“npm”替代方案不再运行依赖项的生命周期脚本，哈希算法已升级到 SHA256，以及许多次要的调整。

* [Bun v1.1.43](https://javascriptweekly.com/link/164160/d076523b1d) – 高性能运行时获得一流的 S3 支持、HTML 捆绑器，并且可以输出 V8 堆快照（这与Bun 使用 JavaScriptCore，而不是 V8）。

* 🔠 [Tesseract.js 6.0](https://javascriptweekly.com/link/164161/d076523b1d) – 流行的纯 JS 多语言 OCR 库解决了各种内存泄漏问题。

* [Docusaurus 3.7](https://javascriptweekly.com/link/164162/d076523b1d) – 流行的面向文档的站点生成器已全面支持 React 19。

* [Node.js v22.13.0 (LTS)](https://javascriptweekly.com/link/164163/d076523b1d) – [权限模型系统](https://javascriptweekly.com/link/164164/d076523b1d)是现在稳定。

* [Puppeteer 24.0](https://javascriptweekly.com/link/164165/d076523b1d)、[RxDB 16.0](https://javascriptweekly.com/link/164166/d076523b1d)、[Ember 6.1](https://javascriptweekly.com/link/164167/d076523b1d), [QuickJS 0.8](https://javascriptweekly.com/link/164168/d076523b1d)

📄 [在 PDF 文件中玩俄罗斯方块](https://javascriptweekly.com/link/164212/d076523b1d "th0mas.nl") —（直接链接到 PDF）

我会让你决定这个是有趣还是可怕！这是否有效取决于您的 PDF 阅读器或浏览器支持，但它至少适用于 Chrome 和 Firefox。

PDF文档格式支持嵌入JavaScript，本实验使用它来实现俄罗斯方块游戏。开发者 Thomas Rinsma [使用 Python 输出包含游戏 JavaScript 的 PostScript。](https://javascriptweekly.com/link/164213/d076523b1d) 事实上，许多浏览器 PDF 渲染器都是“自己”实现的在 JavaScript 中（例如 [PDF.js](https://javascriptweekly.com/link/164214/d076523b1d)）并且您这里有一个名副其实的俄罗斯套娃技术玩偶。
