[Make Flaky Tests a Last-Year Problem](https://javascriptweekly.com/link/178793/d076523b1d "www.meticulous.ai") — Meticulous creates and maintains a continuously evolving E2E UI test suite with zero developer effort. Built on Chromium with a deterministic engine, it’s the only testing tool that eliminates flakes. Relied on by Dropbox, Notion, and Lattice.

Meticulous Ai sponsor

[MicroQuickJS: A New JavaScript Engine from Fabrice Bellard](https://javascriptweekly.com/link/178797/d076523b1d "github.com") — [Fabrice](https://javascriptweekly.com/link/178798/d076523b1d), one of the world’s most prolific developers well-known for creating FFmpeg, QEMU and [QuickJS](https://javascriptweekly.com/link/178799/d076523b1d), is back with a new JavaScript engine targeting embedded systems, and that can run with as little as 10KB of RAM.

Fabrice Bellard

💡 The [discussion about MicroQuickJS on Hacker News](https://javascriptweekly.com/link/178800/d076523b1d) was particularly rich. Redis's creator, Salvatore Sanfilippo, even noted that Redis would have used JavaScript as its scripting language instead of Lua if this had existed in 2010.
