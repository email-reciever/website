### MWC为黄金时段做好准备

本月早些时候，Google 的 Material Web 组件宣布他们现在是 [officially in beta](https://github.com/material-components/material-web/discussions/4527) 并计划在本季度晚些时候推出他们的第一个稳定版本时，每个人都感到惊讶。

**为什么这令人惊讶？** 因为 MWC 的首次公开发布是在 2018 年 5 月，当时 _AVENGERS: Infinity War_ 仍在影院上映（我们都认为灭霸赢了）。 从那时起，我们就没有听说过太多关于 MWC 的消息，所以这里有一个快速的复习。

顾名思义，MWC 是 Material 的 Web 组件实现，Google 的开源设计系统的任务是帮助每个网站看起来相同的“实现最佳 UI 实践”。

这有点令人困惑，因为迄今为止最流行的材料实现是一个名为 [Material UI](https://mui.com/material-ui/getting-started/) 的第三方 React UI 库，它与 Google 没有官方联系。

但谁知道呢，也许 Mui 的成长有助于激励 Material 团队最终发布他们自己的 UI 库的稳定版本。 用 Web 组件实现它很有意义，因为 1）它们是 Google，2）它允许库的组件与各种框架和项目一起使用。

**我们对 v1.0 有什么期望？**

*   22基础的稳定性[components](https://github.com/material-components/material-web/#roadmap)
*   改进的可访问性
*   动态颜色和材料标记
*   本机 HTML 表单支持

**底线：** 谁知道 Material Web 是否会成为主流库，但如果是的话，这将是我们在过去几年中看到的更大的 Web 组件复兴的另一个驱动力。

发现错误：解决方案
-----------------------

#### 赞助[Callstack](https://www.callstack.com/campaigns/super-apps-training?utm_campaign=super_apps&utm_source=email&utm_medium=react_newsletter&utm_content=bytes)

chatapp.receiveMessage("嗨，你好吗？"); // “Chatapp：你好，今天有什么可以帮助你的吗？”
chatapp.receiveMessage("你好，你能帮帮我吗？"); // 没有日志记录
    

在 JavaScript 中，由于 lastIndex 属性，RegExp 对象具有 `g` (global) 标志在匹配之间保留状态，这可能会导致在不同输入之间重复使用时出现意外的结果。

解决方案是为每个传入的消息创建一个新的正则表达式对象，确保正确识别和响应所有问候语。

类聊天应用 {
接收消息（消息）{
让 KeywordRegex = /hello|hi|hey/g;
if (keywordRegex.test(message)) {
this.sendgreeting();
}
}
    
发送问候（）{
console.log("chatapp: 你好，今天有什么可以帮助你的吗？");
}
}
