### 朗链进入JS八角形

我们没有写大量关于 AI 工具的字节故事的主要原因有两个：1）我通常会尝试专注于更多特定于 Web 开发的主题，以及 2）尽管其他人在 Twitter 上做了什么，但我们尝试只谈论我们知道的事情。

但由于 Langchain 决定通过释放 [LangChain.js](https://blog.langchain.dev/js-envs/) 进入 _our_ 沙箱，我们知道我们必须覆盖它。

**什么是 LangChain？** 它是一个开发应用程序的框架，可以通过 API 轻松调用 GPT 等大型语言模型 (LLM)。 它还致力于使应用程序能够将 LLM 连接到 _other_ 数据源，并允许语言模型与其环境进行交互。

该框架通过提供不同的 [components](https://js.langchain.com/docs/) 来实现这一点，这使开发人员可以轻松地为其应用程序添加一些强大的 LLM 功能。 以下是其中一些：

*   **Models** — 允许您的应用与各种 LLM 和聊天模型集成。
    
*   **索引** — 用于处理应用自己的数据并准备好与语言模型（包括文档加载器、矢量存储和文本检索器）交互的模式和功能。
    
*   **Memory** — 为您提供一个标准的内存接口，指的是 LLM 链/代理之间的持续状态。 它还为您提供了可以使用的不同内存实现的集合。
    

LangChain 最初是一个 Python 工具，但 _langchain.js_ 为浏览器、Deno、Cloudflare Workers、Vercel/Next.js、Supabase Edge 函数和 ESM/Common JS 带来了所有的大语言优势。 因此，我们可能很快就会开始看到更多的 AI Web 应用程序。

**底线：** 我希望这会产生下一代聊天界面，这些聊天界面是 Chatgpt 的轻包装器。 一个人永远不能有足够的聊天界面。

弹出测验：回答
-----------------

`<p>` 标签的文本是什么颜色的？

<p class="hello">你好</p>
    
    <style>
身体{颜色：红色； }
P { 颜色：绿色； }
.hello { 颜色：未设置； }
    </style>
    

答案是 `red`，因为 `unset` “取消” `p` 标签的样式，因此它继承自其父级 – `body`。
