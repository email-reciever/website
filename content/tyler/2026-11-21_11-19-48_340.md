Framer Motion 3D
----------------------

抓住你的帽子和（3D）眼镜——因为 Framer Motion 已经进入 [the 3rd dimension](https://www.framer.com/docs/three-introduction/)。

**好吧，什么？** Framer 是一个设计和原型制作工具，它很友好地发布了他们的 React 动画库，恰当地命名为 Framer Motion。 因为……你知道，它_MOVES_。 有了它，您可以创建声明性的、高性能的动画，让使用您的网站（绿色或其他）的任何人都大吃一惊。

** 3D 怎么样？** 浏览器多年来一直在使用 WebGL 将 3D 视图渲染到 `<canvas>` 元素，而流行的 [three.js](https://threejs.org/) 库使它变得更容易****。 [React Three Fiber (R3F)](https://docs.pmnd.rs/react-three-fiber/getting-started/introduction) 已经成为事实上在 React 中使用三个.js 的方式，允许您的相机、灯光和 3D 对象可以作为 React 组件组成。

此新更新使 Framer Motion 可以为 R3F 组件设置动画功能。 它就像一个 API 抽象的俄罗斯娃娃，但在 3D 中。

使用它很容易：只需导入他们的魔法 `motion` 助手并将其放在组件名称的前面即可。 它适用于任何 R3F 组件，并支持 Framer Motion 提供的所有强大功能，而不会牺牲 R3F 的便利性。

这是一个渲染 3D 立方体并使用 Framer Motion 的声明性 API 连续旋转它的示例。

<motion.mesh
旋转={[math.pi / 2, 0, math.pi * 2]}
规模={3}
动画={{
旋转：0，
旋转：0.3，
过渡：{
rotatez: { 持续时间：1.5，缓解：“线性”，重复：无限大
},
}}
    >
      <boxGeometry args={[1, 1, 1]} />
<meshphongmaterial
颜色="#FFDD00"
发射="#FF9500"
specular="#FFF"
光泽="100"
/>
    </motion.mesh>
    

Framer Motion 3D 还解决了 3D 上最难的问题之一：您如何在不引入失真的情况下为 2D 屏幕上的 3D 画布设置动画？ Framer Motion 的解决方案是微不足道的：使用 `<MotionCanvas>` 和 `<LayoutCamera>` 组件，为周围的 DOM 元素设置动画，它“正常工作” - 没有使用 CSS 变换和凌乱的矩阵数学。

请务必查看 [some of the examples](https://www.framer.com/docs/three-introduction/) - 它们是真实的，而且非常壮观。

创建 React 应用程序 v5
--------------------

它可能没有像 Vite、Esbuild 或 Snowpack 这样的所有新的热构建工具——但 `create-react-app` 仍然是使用一个命令启动 React 应用程序的 OG 方式。 他们 [just released v5](https://github.com/facebook/create-react-app/releases/tag/v5.0.0) 上周。

**快速回顾：** CRA 的魔力是它如何使您不必阅读 Webpack 文档为您配置和更新您的所有构建工具（Webpack、Babel 和 ESLint）。

这有点像使用 SparkNotes 编写您的学期末的书籍报告——您可能不了解书中发生的所有内容（或在您的应用程序的引擎盖下），但您肯定会更快地完成作业。

**CRA5 亮点：**

*   **Updated Dependencies** — 所有主要依赖项都更新到最新版本，包括 Webpack、Jest、Eslint 和 PostCSS。 您可以通过将 `react-scripts` 更新到 V5 一次性更新它们。
    
*   **New Tailwind CSS Support** — Tailwind Stans 欢欣鼓舞，因为现在将 CSS 框架与 CRA 一起使用是一种更容易（和更清洁）的体验。
    
*   **快速刷新改进** — 修复了一些已知的错误并整体提高了快速刷新性能。
    

**底线：** 像 [the Houston Rockets](https://www.youtube.com/watch?v=kGtGQQUMDjs) 一样，CRA 的最佳日子可能是 [behind it](https://www.npmtrends.com/create-react-app)。 话虽如此，它仍然是开发 React 应用程序的最流行方式，团队已经表明他们仍然致力于保持最新状态——即使使用“上个月”的技术。
