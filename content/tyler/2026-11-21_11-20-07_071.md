Node.js 发布 v17
---------------------

**OG JavaScript 运行时** 上周刚刚发布了一个主要版本，`v17`。 他停止接听我们的电话，但有人可以确保 Ryan Dahl [gets this](https://open.spotify.com/playlist/02pbr2lfuQv7gAErpNe6xy?si=94331fa18b114576)。

在这一点上，与你的前任不同，节点是相当稳定的。 但是有一些新的东西值得强调（在 Node，而不是你的前任——不要发送那个文本）。

*   **OpenSSL 3.0 支持** — OpenSSL 是一个用于传输层安全性 (TLS) 和安全套接字层 (SSL) 协议的低级工具包，该协议刚刚发布 [v3.0](https://www.openssl.org/blog/blog/2021/09/07/OpenSSL3.Final/)，节点 17 现在支持它。 这些更改中的大多数都非常低调，这意味着您可能不会注意到（或理解）它们。 但是，如果您想阅读有关 Hot New [FIPS module](https://www.openssl.org/docs/man3.0/man7/fips_module.html) 的信息，请成为我的客人。
    
*   **更多 Promisified API** — Node 一直在稳步引入更多基于 Promise 的核心 API，Node 17 为 [Readline module](https://nodejs.org/api/readline.html#readline_readline) 提供了更多新的“Promisified”API。 巧合的是，_Promisified_ 是我在 2010 年执导的关于乔纳斯兄弟和他们的承诺戒指的直接 DVD 纪录片的标题。
    
*   **堆栈跟踪附加** — “您使用的是什么版本？” 是第一个问题，当有什么东西坏掉时总是会问。 因此，Node 团队决定通过最终仅包含堆栈跟踪末尾的节点版本来使我们变得可靠。
    

**底线：** 为什么 Node 团队中的任何人都没有想到让 Zac Efron 再次客串宣布此版本是他的 17 角色？ 或者至少是马修佩里？ GitHub 赞助商还有什么用途？

当您使用 CSS 来维持纵横比

`Aspect-Ratio` 祝福
-------------------------

如果你必须用一个词来描述网络，那么这个词很有可能是“hacky”。 它被称为 _css tricks_ 而不是 _css 提示_，amrite 是有原因的？

以此为例： [How do you maintain the aspect ratio of a div with CSS?](https://stackoverflow.com/a/10441480/4697675) 看起来很简单的内容实际上需要一个包装器 `<div>`、一堆额外的 CSS 和一些不方便的数学计算。

    <style>
.space-wrapper {
宽度：200像素；
}
.aspect-box {
宽度：100%；
填充底：56.25%； /* 什么？ */
背景：黄金；
}
    </style>
    <div class="aspect-wrapper">
      <div class="aspect-box"></div>
    </div>
    

[Here’s the CodePen.](https://codepen.io/alexanderson1993/pen/xxLRmgg)

不理想。 一方面，您必须计算您希望盒子保持的纵横比的百分比。 上例中使用的`56.25%`是用于宽屏16∶9的宽高比。

此外，此技巧仅允许您保持固定宽度的宽高比，而不是固定高度 - 甚至可能没有黑客来解决这个问题！

**好消息**：现在这些都不重要。 我这么说不仅仅是因为我（再次）阅读了太多的推文。 这是因为 CSS gods _working group_ 爱我们，所以新的 `aspect-ratio` CSS 属性的提议已经完成，现在可以在每个浏览器中使用。

**这是它的工作原理：**你喜欢，使用它。

    <style>
.no-hack-box {
高度：200像素；
背景：Rebeccapurple；
纵横比：16 / 9；
}
    </style>
    <div class="no-hack-box"></div>
    

一 `<div>`，没有数学，它也适用于固定高度元素。 它甚至可以在 flexbox 或网格布局中的元素上工作，或者在处理图像时与 `object-fit` 配对。

您可以在行动中看到它 [in this CodePen](https://codepen.io/alexanderson1993/pen/OJjRmNN)。

**底线**：CSS 神已经听到了我们的祈祷。 事实证明，当 CSS 沙箱中只有一组脚印时，这是因为_他们_一直带着_我们_。

欲了解更多信息，这是 CSS 技巧大师本人的 [a **nice** breakdown](https://twitter.com/chriscoyier/status/1452412591066652672)。

发现错误 - 答案
----------------------

`String.prototype.replace` 仅替换字符串中的第一个出现。 如果可能有不止一种情况，请使用 [`String.prototype.replaceAll`](https://github.com/tc39/proposal-string-replaceall) 是 ES2021 的一部分。

常量 petname = 'Leo'
const 占位符 = '{name}'
const reminderTemplate = '{name} 将进行另一次访问。 请致电我们，以便我们安排新的约会。 我们期待很快见到您和{姓名}。
    
常量提醒 = ReminderTemplate.ReplaceAll(占位符，PetName)
