Turborepo 完成后节省了 347 年的计算时间

### Turborepo 2.0 击中亚硝酸盐

自2021年12月推出v1.0以来，Turborepo发生了很多变化：他们被Vercel收购，他们推出了Turbopack JS捆绑器，Jared Palmer（Turbo的创建者）构建了V0并成为Vercel的AI副总裁， 它有助于节省“使用 Vercel 远程缓存 347 年的计算时间”。

哦，它的 npm 下载量也几乎达到了 100 倍到每周 240 万🥵。

[Turborepo 2.0](https://turbo.build/blog/turbo-2-0) 没有放缓的迹象，也是帮助您在 Polyrepos _single-package 工作空间_中解锁更多可扩展的单仓和更快的工作流的又一大步。

**让我们看看亮点：**

*   **新的终端UI**，对日志和交互式任务进行了改进，可以让您执行特定的测试套件或处理数据库迁移等操作
    
*   **Watch Mode** 让您在 repo 中使用任何工具或框架为您提供依赖感知的热重新加载
    
*   **全新文档**具有更多的Monorepo基础和集成指南
    

**底线：** Monorepos 不乏纯粹的仇恨_frustration_，但像Turborepo和NX这样的工具正在使它们更快、更容易使用且更具可扩展性。 神速。

发现错误：解决方案
-----------------------

#### 赞助[Raygun](https://raygun.com/ebooks/how-developers-really-use-ai-a-survey-on-software-teams-and-llms?utm_medium=sponsorship&utm_source=bytes&utm_campaign=ai-er&utm_content=ebook)

在堆栈数据结构中，添加的最后一个元素是要删除的第一个元素（LIFO）。 `peek` 方法应该返回最后添加的元素，而不是第一个元素。

类堆栈 {
构造函数() {
this.Items = [];
}
    
推（元素）{
this.items.push(元素);
}
    
弹出（）{
如果 (this.isEmpty()) {
抛出新错误（“堆栈为空”）；
}
返回 this.items.pop();
}
    
偷看（）{
如果 (this.isEmpty()) {
抛出新错误（“堆栈为空”）；
}
返回 this.items[this.items.length - 1];
}
    
是空的（）{
返回 this.items.length === 0;
}
    
大小（）{
返回 this.items.length;
}
    
清除（）{
this.Items = [];
}
}
