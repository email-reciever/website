Bootstrap 5 Drops jQuery，开始与酷孩子们一起吸烟
------------------------------------------------------

**New V. New Me…** 世界上最受欢迎的 CSS 框架又回来了，其中包括一个新的 API、新标志、新文档和一个新方向：

*   **jQuery，SmayQuery**：所有引导组件现在都已迁移到普通的旧 JavaScript。 通过放弃 jQuery 作为依赖，Bootstrap 团队使我们所有人免于可怕的引导程序的困境：_“jQuery 的便利性是否值得将 jQuery 添加到我的项目中的成本？（无意冒犯）”_。
    
*   **实用程序API**：这种基于API的新方法为Bootstrap提供了类似于Tailwind CSS的感觉，并让开发人员有机会创建用于间距、定位、大小等的所有类型的实用程序类。构建设计系统并让您的父母变得更加简单 为你感到骄傲。
    
*   **CSS 自定义属性**：BOOTSTRAP 5 [dropped support for Internet Explorer](https://bytes.dev/images/content/hellyes.gif)，因此它可以结合 Sass 和 CSS 自定义属性的功能，以实现更灵活的现代系统。
    
*   **better docs**：每个版本都承诺更好的文档，但 V5 文档的新自定义部分似乎确实为如何最好地定制框架提供了一些真正有用的指导。
    

### 底线

多年来，对 Bootstrap 最常见的两个批评是 1）很难在框架中自定义您的 CSS，以及 2）在使用 Bootstrap 的 JavaScript 组件与 Vue 和 React 等流行技术时，很难使用 jQuery。

Bootstrap 5 的每个更改似乎都旨在通过提供新功能和资源进行定制以及将 jQuery 换成“Just JavaScript”来解决这些特定问题。 百万美元的问题是——这足以真正解决这些问题吗？

发现错误 - 问题
-----------------------

常量 animal = (name, type) => {
this.name = 名称
this.type = 类型
this.age = 0
}
    
animal.prototype.birthday = 函数 () {
this.age++
}
    
const leo = new Animal('Leo', 'Lion')
    

箭头函数没有自己的 `this`。 这会导致我们的代码中出现三个错误。

首先，我们在构造函数中将属性添加到 `this`。 同样，因为箭头函数没有自己的 `this`，所以你不能这样做。

其次，我们不能使用带有箭头函数的 `new` 关键字。 这将引发 `X is not a constructor` 错误。

第三，如果该函数是箭头函数，我们不能在函数原型上添加属性，因为没有 `this`。

* * *

发现错误 - 解决方案
----------------------------

功能动物（名称，类型）{
this.name = 名称
this.type = 类型
this.age = 0
}
    
animal.prototype.birthday = 函数 () {
this.age++
}
    
const leo = new Animal('Leo', 'Lion')
