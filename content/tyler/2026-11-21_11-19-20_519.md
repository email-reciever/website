Node.js 终于拥抱了 `fetch`
--------------------------------

他们做到了。 Node.js 团队终于 [made fetch happen](https://github.com/nodejs/node/pull/41749)。

**wtfetch?** `fetch` API 使发出 HTTP 请求变得容易。 在 `fetch` 之前，我们必须使用开发世界的“蝴蝶”，`XMLHttpRequest`。 尽管它们的名字，蝴蝶不是用黄油制成的，`XMLHttpRequest` 可以用来检索任何类型的数据，而不仅仅是 XML。

`fetch` 简化了使用基于承诺的最小 API 的流程，该 API 建立在代表 HTTP 请求生命周期的部分的 `Request` 和 `Response` 之类的原语上。 它已经存在了一段时间——自2015年以来，我们已经在浏览器中使用了`fetch`，而DeNo自2019年以来一直在使用它。

**那么是什么花了 Node 这么长时间？ 为什么现在？**

事实证明，浏览器和节点是 [not alike at all](https://www.youtube.com/watch?v=F-n1AyJgaeY&t=49s)。 浏览器中已经存在的功能需要在 Node 中重新创建——例如 `Headers`、`EventTarget`、`AbortController`、`Blob`、`File`、`FormData`……你明白了。 浏览器认为理所当然的东西，比如“原点”（也就是发出 HTTP 请求的网站），在服务器环境中没有意义。 许多浏览器安全功能也是如此。

所以，是的，这是很多工作。 将像 `fetch` 之类的浏览器优先 API 添加到 Node 就像为您的家庭团聚添加一个开放式栏 - 这似乎是一种足够简单的方式来增强乐趣，但如果您还没有花时间弄清楚所有的物流，事情会很快变得非常复杂。

**为什么现在？** `fetch` 添加最终由 Node 现有的 HTTP 客户端 `http` 实现。 2018 年，Node.js 团队开始了一项名为 [undici](https://github.com/nodejs/undici)（意大利语表示 [eleven](https://youtu.be/FGe8Lo_GXGQ?t=29)）的工作，以实现现代化和改进 `http`。 UndiCi 使用 Promise，它启用了异步/等待，比现有 API 快 14 倍。

在 Node Core 和 UndiCi 中实现所需的一切实际上需要数年时间，但它最终完成了。 上周，UndiCi 及其内置的 `fetch` API 被合并到 Node.js 核心中。 您可以在 4 月 Node 18 发布时使用它。

**底线：** 在节点中有 `fetch` 是 [kind of a big deal](https://www.youtube.com/watch?v=Hzx8KHjQD6c&t=16s)。 它提供了一个与浏览器相同的数据获取标准，这使我们更接近能够互换使用服务器代码和客户端代码。 不过，仍然对蝴蝶感到不安。

MDX 2
------

每个人最喜欢的过度设计博客的工具_将酷组件插入长篇内容_上周变得更好了。 我说的是MDX——Markdown和JSX的恰当命名的Lovechild [just released v2](https://mdxjs.com/blog/v2/)。

V1 发布后 2.5 年发布，几乎需要完全重写。 让我们深入了解亮点：

*   **格式化改进** — 这些使 MDX 感觉更像 [writing JSX](https://mdxjs.com/blog/v2/#improvements-to-the-mdx-format) 而不是 Markdown，这应该会使整个体验更加直观。 他们还添加了对 JavaScript 表达式的支持。
    
*   **rollup 和 esbuild 加入派对** — MDX 过去只与 Babel 和 Webpack 一起工作，但现在它已经集成了 Rollup 和 Esbuild 等热门新构建工具的集成。 您还可以使用新的 `@mdx-js/node-loader` 在 Node.js 中直接导入 MDX 文件。
    
*   **自带JSX运行时** — MDX现在可以将JSX编译为普通的JavaScript，因此支持任何和所有JSX运行时。 您仍然可以使用 React，但您也可以使用 Vue、Preact、Emotion 或您可能喜欢的任何其他奇怪的东西（没有判断力）。
    

**底线：** 此版本应该使 MDX 更受欢迎，因为它将非黄油翅膀传播到 React 生态系统之外。 它肯定会彻底改变我一直在为全家人写的关于 _gourment 意大利食物的代笔的妈妈博客。 ziti_ 食谱——显然是从 20,000 个单词开始的，我的家族，“ziti”这个词的词源，以及 MDX 2 中所有酷炫新功能的快速分解。
