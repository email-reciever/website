### Google I/O 速度运行

我们从上周的 Google I/O 中获得了很多重大公告，或者我喜欢称之为 _Coachella for Nerds._

主舞台上的大部分动作都集中在传达一件事上：“我们的人工智能实际上是惊人的，所以请现在停止出售我们的股票。” 但由于我一直是个独立的孩子，所以我对发生在侧面舞台上的事情更感兴趣。

在这种情况下，其中包括一系列主要类别的 Web 开发公告：Firebase 更新、Web 平台更新和 Dart 3 更新。 这有很多内容要涵盖，因此这里有一个快速的概述，以帮助您在循环中感受。

**Firebase 更新：**

*   新的 AI 扩展可让您使用 Google 的 Palm API 为您的应用添加智能功能（想想 ChatGPT 类型体验）。
    
*   远程配置的实时更新使推出和回滚新功能变得更加容易。
    
*   Firestore 中的支持或查询允许您在多个字段中组合多个条件。
    
*   你可能不关心的一些Python和Android的东西。
    

**平台更新：**

*   大量强大的新CSS功能，包括类似于Sass的CSS嵌套（也用于媒体查询和容器查询的嵌套）、级联层和作用域的CSS。
    
*   响应式设计功能，如容器查询和样式查询，`:has()` 选择器使组件更具动态性，以及新的 [popover API](https://developer.mozilla.org/en-US/docs/Web/HTML/Global_attributes/popover)。
    

**飞镖3：**

*   此版本是长达数年的大修，将 DART 变成“快速、便携和现代语言”的高潮，具有 100% 零安全性和实心型系统。
    
*   其他主要的新功能包括记录、模式、类修饰符和用于编译到 Wasm 的开发人员预览。
    
*   这绝对是 Dart 迄今为止最大的版本，所以我们将来可能会更多地报道这个。
    

**底线：** 遗憾的是，Blink 182 没有成为今年的 I/O 的头条新闻，因为他们在 _actual_ 科切拉音乐节忙于比赛。 但是桑达尔和公司。 还是带来了热度。

发现错误：解决方案
-----------------------

#### 赞助[Datadog](https://www.datadoghq.com/bytes/)

函数 addTriple(inputs: number[]): number {
返回输入[0] + 输入[1] + 输入[2]；
}
    

TypeScript 会警告我们，如果我们将除数字数组以外的任何内容传递给该函数，但如果该数组中的项目少于 3 个，则第三个项目将是未定义的，我们的函数将返回 `NaN`。 TypeScript 无法知道数组中有多少项，因此它无法警告我们。

对此有许多解决方案。 人们会让我们将类型签名更改为元组类型而不是数组。 如果我们的数组没有足够的选项，TypeScript 可以警告我们。

函数 addTriple(inputs: [number, number, number]): number {
返回输入[0] + 输入[1] + 输入[2]；
}
    

另一个选项是启用 `noUncheckedIndexedAccess` TypeScript 编译器选项，这将迫使我们检查每个项目是否未定义。

函数 addTriple(inputs: number[]): number {
如果（
输入[0] ===未定义||
输入[1] === 未定义||
输入[2] === 未定义
){
抛出新错误（“无效输入”）；
}
    
返回输入[0] + 输入[1] + 输入[2]；
}
