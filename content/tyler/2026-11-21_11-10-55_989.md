### 热规格夏天又回来了

ECMAScript 2023 上个月正式获得批准，这意味着是时候迎接 JavaScript 系列的一些新功能了。

为了庆祝，我们将举办我们的**第三次年度 Hot Spec Summer™️ — 一个友好的异教徒仪式_传统_我们在这里喝一杯白怪物、紫色 Kool-Aid 和红色流行摇滚的仪式鸡尾酒，然后继续进行愿景任务以预测哪些新的 JS 功能将是未来最有益的。

为了帮助您在家中保持分数，我们将以 1-5 的热度等级对每个新的 ES2023 功能进行评分。 让我们潜入：

**`Array.findLast()` 和 `Array.findLastIndex()`** — 从结尾开始搜索数组的两种新方法，而不是开头。

🔥 评分：3.2/5。 _这为您提供了一种更简洁的方法来进行不需要手动数组反转或复杂索引计算的反向顺序搜索。_

**Hashbang 语法** — 不要与 [The Hash-slinging Slasher](https://www.youtube.com/watch?v=nsNjflBN3Sgc) 混淆，我们现在可以在脚本的开头使用 Hashbang 符号 `#!` 来指定要执行脚本的 JS 解释器。

🔥评分：2/5。 _这个想法来自Unix世界，并且已经在Node.js等非浏览器环境中实现，这可能仍然是您使用它的最常见的地方。

**符号作为 WeakMap Keys** — 这扩展了 WeakMap API，以允许唯一的符号现在也可以用作键。 以前，只有对象可以用作键。

🔥 评分：4.1/5。 _symbols 有助于在 WeakMaps 中提供更清晰和更好的人体工程学，这应该可以帮助更多的开发人员利用 API 的 [memory-optimization benefits](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/WeakMap#why_weakmap)._

**按副本更改数组** — 我们有幸在 `Array.prototype` 上使用了四种新的但熟悉的方法，这些方法允许您对数组进行更改并返回一个带有更改的新副本，而无需更改原始数组。 您可能已经猜到这些功能：`toReversed()`、`toSorted()`、`toSpliced(start, deleteCount, ...items)` 和 `with(index, value)`。

🔥 评分：5/5。 _这个 4 比 1 的特价比你在 Wendy's 买到的更好。 这些新方法应该立即与想要避免突变的 JS 开发人员相关。

**底线：** 请记住负责任地庆祝炎热的夏季。

#### 赞助[Secureframe](https://secureframe.com/request-demo-4?utm_source=partner&utm_medium=newsletter&utm_campaign=071023-bytes-newsletter)

记录什么？

for (var i = 0; i < 5; i++) {
setTimeout(() => console.log(i), i * 1000)
}
    

为你们所有的老头回去一点。 这曾经是每个人最喜欢的 JavaScript 面试问题。

此代码最终将记录 `5`，5 次。

原因是我们用 `var` 声明了我们的变量，它是函数范围的。 当我们给 `setTimeout` 的函数运行时，`i` 已经是 `5` 并且每个函数都会引用相同的变量。

要解决此问题，请使用块作用域的 `let`，并将为我们的 for 循环提供自己的每次迭代 `i`。

for (let i = 0; i < 5; i++) {
setTimeout(() => console.log(i), i * 1000)
}
    

或者，您可以通过 `setTimeout` 的第三个参数将 `i` 作为参数传递给函数的正确值。

for (var i = 0; i < 5; i++) {
setTimeout((CaptureDi) => Console.log(CaptureDi), I * 1000, I)
}
    

或者你可以使用 iife 来做同样的事情，哈哈。

for (var i = 0; i < 5; i++) {
（（捕获）=>
setTimeout(() => console.log(Capturedi), I * 1000)
)(我);
}
