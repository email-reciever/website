### 包豪斯，野兽派和…… React Native？

抱歉，自昨天以来，当 React Native 团队为其新架构放弃了一些 [performance benchmarks](https://github.com/reactwg/react-native-new-architecture/discussions/123) 时，我就一直在大脑中进行架构。

这可能是 React Native 5 年传奇的最后一章，所以让我们缩小并看看_为什么_他们决定重构他们的整个核心以及我们如何走到今天的位置。

**快速背景：** 您可能已经知道 React Native 如何让您使用 JavaScript 和 React 编写跨平台移动应用程序——而不是使用像 Swift 和 Kotlin 这样的本地语言。 这种魔力的很大一部分最初来自 React Native “Bridge”，它使用序列化的 JSON 消息来允许您的 React/JavaScript 代码与应用程序的本机端进行通信，反之亦然。

这种方法有效，但它带有 [performance tradeoffs](https://youtu.be/8wAj0KG5H6U?t=80)，它源于太多的 JSON 消息需要通过单个通信渠道（除其他外）。 最终，这座桥变得过于瓶颈，它需要去。

**大重构：** 在 2018 年第二季度，React Native 团队开始使用 RN 为所有 1,000 多个 Facebook 应用程序表面开发新架构。 （我希望他们将其称为_Operation Burning Bridges_。）当他们在2018年底开始公开谈论它时，React Native社区被炒作了。

花了将近4年的时间，但在2022年3月，我们终于获得了React Native 0.68的祝福，让开发人员有机会选择加入新的Architecture™️——它由4个主要支柱组成：

*   **JSI（JavaScript 接口）** — 用于与任何 JS 引擎交互的新 C++ API。 这取代了JS和C++之间的直接接口，并删除了需要的JSON-IFY数据。
    
*   **FABRIC** — 新的并发渲染系统将所有 React 18 功能都带到了 RN。
    
*   **turbo 模块** — 通过仅在实际需要时加载模块来提高性能，并允许同步调用本机方法。
    
*   **CodeGen** — 一种可选的工具生成代码，以提高类型的安全性和代码质量。
    

从那时起，他们将新架构置于默认状态，并且仍在努力解决一些边缘案例性能问题——这些问题看起来将在即将推出的 0.72 版本中得到解决。

**底线：** 大规模的建筑项目总是很长的旅程，但幸运的是，React Native 的新核心应该在 [The Sagrada Famillia](https://www.euronews.com/culture/2021/12/05/why-has-barcelona-s-sagrada-familia-taken-over-100-years-to-be-built) 之前完成。

#### 赞助[Unlayer](https://unlayer.com/embed)

要创建 SVG 精灵，您可以利用 [`<symbol>` 元素](https://developer.mozilla.org/en-US/docs/Web/SVG/Element/symbol)。

1.  创建一个包含要重用的符号的 SVG 精灵：

    <svg xmlns="http://www.w3.org/2000/svg" style="display:none;">
      <symbol id="icon-circle" viewBox="0 0 32 32">
        <circle cx="16" cy="16" r="16" />
      </symbol>
      <symbol id="icon-square" viewBox="0 0 32 32">
        <rect x="0" y="0" width="32" height="32" />
      </symbol>
    </svg>
    

2.  在您的站点中使用 SVG 符号：

    <svg xmlns="http://www.w3.org/2000/svg" width="32" height="32">
      <use href="#icon-circle" />
    </svg>
    
    <svg xmlns="http://www.w3.org/2000/svg" width="32" height="32">
      <use href="#icon-square" />
    </svg>
    

使用 SVG 精灵可以帮助减少请求，并为您提供内联 SVG 的大部分好处。 双赢。
