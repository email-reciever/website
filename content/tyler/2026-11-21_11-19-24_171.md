在 Deno 登记入住
--------------------

**Deno 的案例很简单：** Ryan Dahl 早在十年前就建立了 Node——但在重新观看了 Heath Ledger 的 [greatest films](https://www.imdb.com/title/tt0147800/mediaviewer/rm953815296/) 之一后，他决定有 [10 things he hated](https://www.youtube.com/watch?v=M3BM9TB-8yA) 关于 OG JavaScript 运行时。 因此，他从头开始构建了一个使用 V8 和 Rust 的新型和改进的运行时，“默认是安全的”，并且不需要任何重度 `node_modules`。

**Deno V1 诞生于 2020 年 5 月，** 炒作仪立即升级到 11 点。 每个博主都在写关于它的思考文章，每个时事通讯都是关于它的时事通讯，每个 YouTuber 都在制作关于它如何成为下一件大事的视频。

**快进到今天，** 事实证明，Deno _hasn't_ 杀死了节点（尽管 Twitter 上的一些思想流畅的人会让你相信）。 但是，尽管现在肯定比2020年夏季（以及更多的COVID WTF？）现在的DeNo Buzz更少，但去年仍然是[a big year for the Deno team:](https://deno.com/blog/deno-in-2021)

*   他们成立了 [Deno the Company](https://deno.com/blog/the-deno-company)，筹集了 490 万美元，并推出了 Deno Deploy 的第一个测试版。 （通过无服务器云产品实现更多VC支持的开源项目，Yayyy 😬）
    
*   他们用一些现金支付给 [join the TC39 Working Group](https://deno.com/blog/deno-joins-tc39)——这就像付钱让大学里的朋友_加入兄弟会_，但有更疯狂的欺凌仪式（不要问）。
    
*   他们提供了 11 个次要版本，这些版本引入了 Moire 优化核心、本地 HTTP 服务器绑定等新功能。
    
*   他们开始使用 Node.js 兼容性，这将允许 deno 为 [seamlessly run npm packages developed for Node](https://www.youtube.com/watch?v=45RYX77veK0)。 这与 Deno 早期的立场（我引用）“节点模块是魔鬼”的重大转变。 但事实证明，当您试图让开发人员使用您的运行时时，与 npm 生态系统分离是一个错误，而不是一个功能。
    

**底线：** Deno 可能仍然是服务器端 JavaScript 的未来，而且他们已经取得了很多进展——但很明显，他们不会在一夜之间取代 Node。 在涉及风险投资的情况下，时钟总是在滴答作响。

类型检查终于得到升级（我们希望）
-------------------------------------------------

**JavaScript 构建工具在过去几年中变得更快**，这要归功于 SWC、ESBuild 等热门新项目——用 Rust 和 Go 等语言编写。

但是 TypeScript 的类型检查器 `tsc` 仍然是 AF ATDM 的慢速（_as the Dune Movie_）。 不过好消息是：本周，SWC 背后的人宣布他们正在研究 [a Go port of the type checker](https://kdy1.dev/posts/2022/1/tsc-go)。

**但是为什么它很慢？

硬（和慢）部分正在检查代码中的类型错误。 到目前为止，`tsc`（TypeScript 团队提供的 CLI 工具）是唯一可以做到这一点的工具。 它为您的 VS Code 错误突出显示和自动完成功能提供支持，并输出库用于共享其类型的 `.d.ts` 文件。 但它是用 JavaScript 编写的——这为性能改进留下了很大的空间。

**为什么没有人建立更快的版本？**相信我，[people have tried](https://zackoverflow.dev/writing/tyty)。 [SWC](https://github.com/swc-project/swc/issues/571#issuecomment-572304093) 和 [Deno](https://github.com/denoland/deno/issues/5432) 背后的团队已经工作了 2 年多，没有任何表现。 事实证明，TypeScript 继承了许多粗糙、奇怪的 JavaScript 部分——这使得类型检查器成为边缘情况的雷区。

**是什么让这次最新尝试有什么不同？**

*   SWC 团队将移植它而不是重写 `tsc`，因此代码的结构和行为将与其 JS 对应（更平滑的过渡）相同。
    
*   Vercel 正在为整个项目提供支持，承诺开源它。 众所周知，Daddy Warbucks Guillermo 这些天的财力相当雄厚。
    
*   早期对Rust重写的失败尝试应该为Go中的这项新工作提供有价值的见解。
    
*   是[Evan Wallace-approved](https://news.ycombinator.com/item?id=30079403)。
    

**底线：** 如果他们能做到这一点，我们应该开始一个 GoFundMe 来支付 Jeff Goldblum 的客串费用，说他的 [most iconic line](https://www.youtube.com/watch?v=gXBJRz_33Y8)。
