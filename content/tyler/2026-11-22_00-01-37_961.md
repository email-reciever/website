## Cool Bits

1.  Tanner [released the well-named `redact`](https://tanstack.com/blog/introducing-tanstack-redact), a smaller, synchronous version of React, for those of you who still suffer from bundle phobia.
    
2.  Jeff Lindsay created [`webframe`, a tool that lets you run browser-dependent scripts from the command line](https://github.com/tractordev/webframe).
    
3.  Equip your AI on [Apify](http://apify.com/apify/e-commerce-scraping-tool?fpr=fireship-bytes) for Black Friday and get live prices, availability, and ratings from Amazon, Walmart, eBay, or any other online store. Use code BYTES for $25 in credits. \[sponsored\]
    
4.  Remix [released version 3.1](https://github.com/remix-run/remix/releases/tag/remix%403.1.0), patching up some post-launch issues and making it faster so now it’s really actually ready… probably.
    
5.  Jake Archibald explains [when to use JPEG XL rather than AVIF](https://jakearchibald.com/2026/jpeg-xl-vs-avif/) in his latest blog post. JPEG is also wearing size XL? The post-COVID years have been rough for all of us.
    
6.  James Long [compared Rune’s text render to macOS text rendering, pixel by pixel](https://jamesbox.exe.xyz/artifacts/rune-vs-macos-text/). Developers with OCD are the best.
    
7.  [Hyperagent](https://hyperagent.com/fireship100) lets you hire AI staff to take on roles across your business. They run in the cloud with their own browser, shell, and file system, connect to your tools, and hand work off to each other. Your whole team can work with the same agents—not just the person who set them up. \[sponsored\]
    
8.  Shu Ding, inspired by Cheng Lou’s latest wizardry, [compiled a dashboard UI into a single math function](https://calculus-of-interfaces.vercel.app/) giving new meaning to the trope `UI = fn(state)`.
    
9.  [Firefox 159 is out](https://developer.mozilla.org/en-US/docs/Mozilla/Firefox/Releases/159), which means `scroll-driven-animations` are now supported in all major browsers. I _think_ this is a good thing.
    
10.  Your code has bugs. [Sentry finds them, figures out what caused them, and helps your agents fix them](https://sentry.io/resources/automated-debugging/?utm_source=bytes&utm_medium=paid-community&utm_campaign=automateddebugging-fy27q3-evergreen&utm_content=newsletter-resource-hub-learnmore). \[sponsored\]
    
11.  Vercel Labs created [wterm](https://github.com/vercel-labs/wterm/), a terminal emulator for the web that renders DOM so text selection actually works 🥲.
    
12.  [`tsts` is another slopfork of the TypeScript compiler](https://github.com/zzj3720/tstst), but this time it’s running inside TypeScript’s own type system? I think this is the equivalent of Doom running inside of a pregnancy test.
