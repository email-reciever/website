### 迄今为止最大的飞镖

Dart 3 刚刚在 Google I/O 上发布，Dart 团队称其为“迄今为止最大的版本”。 但要了解为什么这是真的，我们需要快速复习一些飞镖历史。

**我们是如何到达这里的：** Dart 编程语言最初是在 Google 上创建的，作为 JavaScript 的替代方案，可以追溯到 2011 年的派对摇滚时代。

就像 dubstep 一样，这个想法并没有持续多久。 但 Dart 仍然是独一无二的，因为它可以编译到多个目标——用于移动的 ARM64 和 x64、用于 Web 的 JavaScript 和独立的桌面可执行文件。

这使它最终能够为 Flutter 提供动力，这是用于构建本地编译的跨平台应用程序的 UI 工具包。 尽管 Flutter 已经变得超级受欢迎，但 Dart 从未享受过同样的主流采用。

这就是Dart团队为Dart 3的这三大进步投入了大量资金的原因：

*   **NULL 安全性和类型安全：** 花了四年时间，但 DART 团队为 DART 增加了 100% 零安全性，以及一个完善的类型系统。 因此，如果一个类型说一个值不是 `null`，这意味着它永远不可能是 `null`。 这有助于防止编码错误，并允许 DART 的编译器和运行时更有效地优化代码。
    
*   **主要新语言功能：** Dart 添加了新功能，如记录、模式和类修饰符，以帮助现代化和改进 DX。
    
*   **WebAssembly 汇编：** Dart 无法抗拒性感的新编译目标，因此 V3 带有 Dart to Wasm 编译的预览。 他们目前专注于 Flutter Web 支持，但这最终可能会改变游戏规则，让 Wasm Stans 给 Dart 一个机会。
    

**底线：** 很高兴看到 Dart 继续像这样发展，在它首次发布 12 年后。 它只是表明如果你想击中靶心，有时你需要做的就是问自己，[Who’s in charge, me or the devil?](https://youtu.be/H0qc7WZvEAY?t=2)（_language warning_ 🤐）

发现错误：解决方案
-----------------------

#### 赞助[Tigris](https://www.tigrisdata.com/blog/adding-real-time-full-text-search-to-a-next.js-app-with-tigris/)

函数 makeCamelCase(文本) {
const changeCase = import('https://cdn.skypack.dev/change-case')
    
返回 ChangeCase.CamelCase(文本)
}
    

这个 `import` 语句实际上是一个 [dynamic import](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/import#dynamic_imports)。 当它第一次调用时，它将从 CDN URL 中获取模块的代码并异步解析，这意味着 `import()` 返回一个 Promise。 我们需要使用 `.then()` 方法或 `async/await` 来访问模块。

异步函数 makeCamelCase(文本) {
const changeCase = await import('https://cdn.skypack.dev/change-case')
    
返回 ChangeCase.CamelCase(文本)
}
