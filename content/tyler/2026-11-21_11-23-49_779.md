Svelte 支持 TypeScript，因为这就是朋友所做的
------------------------------------------------------

![Svelte and TypeScript evangelism](https://bytes.dev/images/content/svelte-ts.jpg)

太远了？

**人们问……** 苗条的神灵回答。 经过无数次请求（以及大量随机、独立的 TS 工具），上周 [Svelte officially announced full support for TypeScript](https://svelte.dev/blog/svelte-and-typescript)。

哦? 你还没有学会svelte吗？ 哇。 我敢打赌，您也喜欢在夜晚和周末与朋友和家人共度美好时光的同时拥有平衡、充实的生活，而不是不断地感觉自己永远不会知道得足够多，并且您必须跟上 JavaScript 生态系统中的每一件事情，这样您就可以每周一写一份时事通讯，优雅地跨越 当前流行文化、幽默和技术相关性之间的界限。

如果是你，这里是 Svelte 的两个主要卖点的快速概述：

1.  **较小，更快的应用程序：** Svelte 在技术上是一个 JavaScript 编译器，而不是一个框架，这意味着它会在构建时将所有代码编译到 Vanilla JS 中，依赖性较少且没有虚拟 DOM。 理论上，这允许 Svelte 更轻、更快。
    
2.  **简单的语法：** Svelte 的“明确目标”之一是减少您必须编写的代码量，并使该代码易于阅读。 [This example component in Svelte, React, and Vue](https://svelte.dev/blog/write-less-code#Yes_I_m_talking_about_Svelte) 给出了 Svelte 如何做到这一点的基本概念。
    

### “官方打字稿支持”实际上是什么样子的？

还记得我们前面提到的那些随机、独立的打字稿工具吗？ 其中大多数只是被吸收到苗条的组织中，现在将由一群对苗条生态系统有“共同目标”的人维护（#sveltegang）。

有关更多详细信息，让我们去#stta（直至公告）：

*   您可以通过添加 `lang="ts"` 属性在 `script` 块中使用 TypeScript
*   TypeScript的组件可以通过`svelte-check`命令进行类型检查
*   在编写组件时，您会获得自动完成提示和类型检查，即使是在标记内的表达式中
*   TypeScript 文件了解 Svelte 组件 API — 将 `.svelte` 文件导入 `.ts` 模块时不再出现红色波浪

### 底线

TypeScript 支持应该为 Svelte 释放更大的潜在用户群，特别是在构建越来越多使用 TypeScript 的大型应用程序的开发团队中。 这也意味着，如果您是 Typescript 的忠实粉丝，您可能会没有借口不尝试 Svelte。

Vue 3 击中 RC
------------------

![old lady from Titanic](https://bytes.dev/images/content/titanic.png)

Vue 开发人员耐心等待 v3

**让我们回去……**到2018年9月：

埃隆·马斯克（Elon Musk）在乔·罗根（Joe Rogan）播客和[Evan You announced plans for Vue 3 at the Vue.js conference in London](https://medium.com/the-vue-point/plans-for-the-next-iteration-of-vue-js-777ffea6fabf)上吸食大麻后，刚刚暴跌了特斯拉的股价。

从那以后，发生了很多变化。 特斯拉的股票已经上涨了 6 倍 (WTF)，而且……我们仍在等待 Vue 3。

但它几乎就在这里！ 上周，[Evan announced that Vue 3 was in RC](https://github.com/vuejs/rfcs/issues/189)，团队预计在接下来的几周内公开发布之前不会发生任何重大变化。

知道这一点，以下是 Vue 3 的 3 个大亮点：

*   **[Composition API](https://v3.vuejs.org/guide/composition-api-introduction.html#why-composition-api):** 一种替代的、可选的语法，用于编写较大的组件、跨组件重用代码和使用 TypeScript。
    
*   **[Teleport](https://v3.vuejs.org/guide/teleport.html#using-with-vue-components):** 一种新组件，它为门户提供本机支持，并简化了使用模态和弹出窗口等元素的工作，而无需进行丑陋的变通。
    
*   **[Fragments](https://v3.vuejs.org/guide/migration/fragments.html):** 像 React 一样，Vue 3 现在对片段（又名多根节点组件）有了官方支持。
    

### 底线

Vue 受到使用它的开发人员的喜爱，但它也没有像 Angular 和 React 这样的框架广泛使用，尤其是在大型企业应用程序中（不要@我）。 V3 中的新功能似乎将提供 React 提供的更多功能，同时仍保留 Vue 独特的多功能性。 有趣的是，这最终是否会导致大公司越来越多地采用 Vue。

祝贺埃文和所有贡献者在这个大版本中！
