以前称为 React 查询的艺术家
---------------------------------------

当您是 React 生态系统中最受欢迎的数据提取库时，很容易自满——但 RQ 团队不是关于这种生活的。

上周，当他们发布 [React Query v4](https://tanstack.com/blog/announcing-tanstack-query-v4) 并透露一些重大新闻时，他们再次突破了界限：他们正式_单身并准备好融合_（与 JS 生态系统的其他部分）。

这是一种有品位的委婉说法，React Query 现在与框架无关，每个特定的 JS 框架都有“适配器”。 他们已经有一个内置的 React 适配器，Vue、Solid 和 Svelte 的适配器正在开发中。

为了证明他们没有玩最喜欢的东西，他们将他们的名字从 React Query 改为 TanStack Query——有点像 Prince 将他们的名字改为 Ƭ̵̬̊ 并永远成为传奇（即使一开始会造成很多混乱）。

除了让开发人员在日常生活中非出乎地说“坦克”之外，V4 中的技术改进令人印象深刻。

*   **离线支持：** 在 V4 中，Query 不再假定活动网络连接，适用于任何类型的异步数据——它有一个 [Network mode](https://tanstack.com/query/v4/docs/guides/network-mode) ，可以让您先离线开发。
    
*   **性能改进：** 跟踪查询有助于优化渲染并为您提供良好的性能提升。
    
*   **持久性：**您现在可以更好地控制存储数据的位置，以及本地存储之类的开箱即用的功能。
    
*   **First Class React 18 支持：** _tanStack_ 查询可能与框架无关，但它并没有忘记它的初恋。 React 适配器现在使用 `useSyncExternalStore` 来确保与 [concurrent mode](https://www.youtube.com/watch?v=NZoRlVi3MjQ) 的兼容性。
    

**底线：** 在这个版本中，TanStack Query 似乎是处理几乎任何前端应用程序异步数据的理想解决方案。 我们非常喜欢它，如果你想给我们钱🤑，我们就做了一个[full course](https://ui.dev/react-query)。

Docusaurus V2 从其 3 年的 Alpha/Beta 期出现

文档商店谈话
--------------

它花了 4 年、75 个 Alpha 和 22 个测试版，但它终于来了。

不，我们不是在谈论 React 18（一次）。 我们谈论的是 Docusaurus——另一个由元支持的开源项目，其静态站点生成器的 [just launched v2](https://docusaurus.io/blog/2022/08/01/announcing-docusaurus-2.0) 用于构建文档站点。

**我们是如何到达这里的：** 创建文档站点最难的部分显然是_\*写作\*_ 好文档。 但早在 2017 年，“原名 Facebook 的艺术家”的开发人员意识到，构建实际网站可能比一遍又一遍地复制相同的 Jekyll 模板更好的方法。

因此，他们用独特的 [value prop](https://twitter.com/sebastienlorber/status/1452722577785425926) 构建了自己的 SSG — 10 分钟内将您的 Doc 网站在线，这样您就可以专注于编写内容（使用 Markdown），但提供足够的灵活性来稍后返回并使用您自己的品牌、设计和功能（使用 React）真正定制它。

快进几年，Docusaurus 可能比你想象的要 [a lot more popular](https://npmtrends.com/@docusaurus/core-vs-@redwoodjs/core-vs-@remix-run/react-vs-gatsby)，即使与更“通用”的 React 框架相比也是如此。

** V2 中的新功能：**

*   现在在客户端（不仅仅是像v1这样的服务器）上使用了React，这使得更现代化的导航
    
*   MDX 支持，因此您可以在文档中创建交互式 React 组件
    
*   更多的主题化灵活性和新的插件系统使定制更容易
    

**底线：** Docusaurus V2 刚刚在 ProductHunt 上直播——因此请通过投票进行 [show them some love](https://www.producthunt.com/posts/docusaurus-2-0?utm_source=badge-featured&utm_medium=badge&utm_souce=badge-docusaurus-2-0)，以便除了 Chrome 扩展之外的其他内容可以窃取大量不敬虔的个人数据，可以赢得一次当天的产品。
