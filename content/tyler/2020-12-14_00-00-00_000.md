**GitHub Universe** 上周发生了——是的，我们听说过黑暗模式🌛。

当我们第一次看到 [the announcement video](https://twitter.com/github/status/1336362679506784256) 时，我们认为这可能是 GitHub 受洗到撒旦教堂的现场镜头。 但自从 GH 早在 2018 年被微软收购以来，我们就认为该仪式已经发生在很久以前。

撇开笑话不谈，我们很高兴在黑暗中编码变得更加……**黑暗。**

**这是我们最喜欢的其他新 GH 功能的快速概述。

*   **[Codespaces:](https://docs.github.com/en/free-pro-team@latest/github/developing-online-with-codespaces/about-codespaces)** 一个“由 GitHub 托管并由 VSCode 提供支持的在线开发环境”（Microsoft Tag-Team）。 它基本上是浏览器中功能齐全的编辑器，包含您为特定仓库开发所需的一切（项目依赖、终端和外壳访问、调试工具等）。 GitHub 称之为“在云中编程”，如果您想知道 — [yes, they’re going to make bank off this.](https://docs.github.com/en/free-pro-team@latest/github/developing-online-with-codespaces/about-billing-for-codespaces)
    
*   **[Auto-merge pull requests:](https://github.com/github/roadmap/issues/107)** 启用后，您可以自动合并和关闭 PR，而不是手动（就像农民一样）。 如果所有支票都通过并且您的更改获得批准，GH 将自动将您的 PR 合并到您的目标分支中。
    
*   [New GitHub CLI:](https://cli.github.com/) `gh` 允许您使用超过 45 个 CLI 命令将拉取请求、问题和其他 GitHub 概念带到终端。
    

其他有趣的新功能包括本地 iPad 应用程序、GH Enterprise Server 的主要版本、新的依赖项审查工具、公司参与 GH 赞助商的能力以及开发人员的 Build-A-Bear [code-your-own-OctoCats.](https://myoctocat.dev/)

js提示 - 将数字格式化为JS中的美元
---------------------------------------

函数 formatToDollar (number) {
返回新的 intl.numberFormat('en-us', {
风格：“货币”，
货币：“美元”，
}).format(编号)
}
    
formatToDollar(873) //“$873.00”
formattoDollar(1634) //“$1,634.00”
FormatToDollar(1523.65) //“$1,523.65”
格式托收纳(1893042.3498) //“$1,893,042.35”
    

在上面的示例中，我们了解如何使用 `Intl.NumberFormat` API 在 JavaScript 中将数字格式化为美元。 让我们浏览不同的选项，以防您需要自己定制。

`style` 是要使用的格式化样式。 有三个选项 - `decimal`（默认值）、`currency` 和 `percent`。

如果您使用的 `currency` 中的 `style` 与我们上面一样，您还需要指定货币格式，在我们的例子中，`USD`。 其他选项包括欧元的 `EUR`、人民币的 `CNY`、比索或任何其他的 [“ISO 4217” currency](https://www.currency-iso.org/dam/downloads/lists/list_one.xml)。

如果您需要更多的微调定制，您可以查看[full API here](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/NumberFormat#Parameters)。
