### RouterActMix 6.4

早在 3 月，Remix 团队（他也是 React 路由器团队）宣布他们将“Remix 的数据和异步 UI 管理的一切都很棒”，并将其放入 React 路由器中。

这将为 React Router 用户（也就是 50% 的 React 开发人员）提供一些很酷的新功能，而无需完全投入 Remix。 它还将为 Remix 提供一个很好的漏斗增长策略，用于获取新用户。 双赢。

快进到上周，Merge™️正式开始[React Router v6.4](https://remix.run/blog/react-router-v6.4)的发布。 以下是新的RrouterActMix在引擎盖下的样子：

*   **LOADING DATA** — React 路由器现在有了“loaders”的概念，它可以预加载和并行化每个路由的请求。
    
*   **更新数据** — 90 年代又酷了，所以 RR 正在带回表格。 路线现在可以处理您所有“行动”的提交导航、取消和比赛条件。
    
*   **错误处理** — “您的绝大多数应用程序错误都是由 React Router 自动处理的。” 这是一个相当大胆的主张，棉花，因为他们从未见过我的代码。
    
*   **UX Goodies** — RR 正在为您的用户赠送 Goodie Bags。 我们正在谈论繁忙的指标、乐观的 UI、滚动恢复、骨架 UI 等——正好赶上万圣节。
    

**底线：** 对于 Remix 将其 Wagon 连接到 React 路由器（以及每周约 800 万次 NPM 下载）是一个明智的商业举措。 但现在已经不是2021年11月了，VC已经意识到公司需要“卖”一种产品以获得“真钱”才能产生“回报”。

Remix 最终将不得不弄清楚如果他们想作为一家企业变得可行，或者他们可能只是加入 $BIGCO 并继续实现梦想，那么如何做到这一点。
