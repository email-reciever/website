### 它与feetConf押韵

但我很高兴地报告 _vite_conf 为 JavaScript 生态系统提供了一堆令人兴奋的新公告，而 _This Little Piggy 的现场表演正好为零，这一点就进入了市场_🙏。

对于这个故事，我们想专注于我们对 Vite 本身的 3 个最大收获，我们将在 Cool Bits 中提到会议的其他一些具有新闻价值的部分。

**外卖#1：Vite 仍在蓬勃发展。** Evan 你分享说，Vite 的每周 npm 下载量在过去一年中增长了 4 倍，达到 720 万以上，这在很大程度上要归功于 Storybook 7、Angular 16、Preact 等重大项目的采用， Redwood 6、Bun 0.7 和 Remix（仍然是早期的 WIP）。

**外卖#2：Vite 意识到其问题。** 尽管增长爆炸式增长，但 Evan 承认 Vite 在多个关键领域仍有改进的空间。 最大的痛点之一是它相对较慢的生产构建速度，因为它使用的是汇总而不是像 esbuild 和 bun 这样的纯粹的原生捆绑器。

但即使它较慢，Rollup _does_ 也比下一代捆绑器提供了更大的灵活性和成熟度。 如果有办法让两全其美……

**外卖#3：Rolldown 是 Vite 的未来。** Vite 团队正在开发一个范围稍大的 Rust 端口，称为 [Rolldown](https://youtu.be/veCxKeLl35A?t=1535)。 它仍然是早期的 WIP，但目标是通过 Rust 提高 Vite 性能，同时保持与现有汇总 API 的“尽力兼容”。

这是一项将在多个阶段进行的重大任务，但最终结果可能是对 Vite 核心的整体“锈化”。

**底线：** Vite 的使命是成为“网络生态系统中更高层次创新的共享基础”。 通过继续通过创新解决方案改进其弱点，它似乎已经准备好继续朝着这一目标快速增长。
