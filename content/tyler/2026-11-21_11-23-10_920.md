### 因为我们没有计算机科学博士学位而理解的变化

*   [Bye bye, Node.js Polyfills](https://webpack.js.org/blog/2020-10-10-webpack-5-release/#automatic-nodejs-polyfills-removed) - 为了允许大多数 npm 软件包在浏览器中运行，历史上 webpack 会自动填充大多数 Core Node.js 模块。 这样，事情就成功了™。 使用 V5，他们已经删除了这些 polyfills 和东西 [Just Don’t Work™](https://blog.sindresorhus.com/webpack-5-headache-b6ac24973bf1)。
*   [Module Federation](https://webpack.js.org/blog/2020-10-10-webpack-5-release/#module-federation) - 尽管您猜到了最好的猜测，但这并不是一个以模块化意识形态为中心的新政府。 模块联合使您能够更轻松地在不同项目之间共享模块。 非常适合#microfrontend 人群。
*   [Asset Modules](https://webpack.js.org/blog/2020-10-10-webpack-5-release/#asset-modules) - 从历史上看，您必须将 `raw-loader`、`url-loader` 或 `file-loader` 的正确组合用于表示资产（字体、图标等）的模块。 借助 V5，Webpack 现在提供了相同的功能，因此您可以摆脱这些加载器。

### 底线

Webpack V5 有很多新功能，其中大部分你可能不会理解（我们也没有！）。 坐在电脑后面开玩笑很容易。 现实是 Webpack 是一个重要的工具，可以继续解决难题。 恭喜新版本，团队。

[Volta: A New CLI Tool](https://github.com/volta-cli/volta)
--------------------------------------------------------

![Volta](https://bytes.dev/images/content/volta.jpg)

☝️它是如何开始的，进展如何

**在这里为正义和 JavaScript 辩护……** Volta 是一种新的、“无忧无虑”的方式来管理您的所有 JavaScript CLI 工具，如 Node、NPM 或 YARN。 它将自己作为 NVM 的更快、更轻量级的替代品，它提供了更多的功能并承诺让您摆脱困境。

### 它是如何工作的？

Volta 根据您当前的目录（就像包管理器一样）跟踪您正在处理的项目。 从那里，您的 Volta 工具链中的工具会自动检测您项目中使用的每个工具的哪个版本，并将您引导到所需的工具版本。

每当您使用 Volta 安装工具时，它通过向 `PATH` 添加一个 shim（透明地拦截 API 的小库）来实现这一点。 然后，该垫片充当该工具的正确版本的智能路由器，并使用正确的节点引擎运行它。 相当光滑。

**其他酷炫功能：**

*   跨平台支持，包括Windows和大多数Unix shell。
    
*   支持多个包管理器。
    
*   稳定工具安装（无需在每次节点升级上重新安装）。
    
*   内置了Rust作为一个单一的本地可执行文件，因此没有外部依赖。 （另外，所有 Rust 开发人员都会为您提供 #RustClout 来使用它 - 然后尝试说服您加入他们的邪教。）
    

### 底线

该项目仍处于早期阶段，但 Volta 可以（理论上）使您不必再次输入 `nvm use`。

Volta 甚至有自己的超级英雄式的流行语：“无论是包管理器、节点运行时还是操作系统，您都需要一个命令：`volta install`。” `</Christian-Bale-Batman-Voice>`

发现错误 - 解决方案
------------------------

箭头函数没有自己的 `this`。 这会导致我们的代码中出现三个错误。

首先，我们在构造函数中将属性添加到 `this`。 同样，因为箭头函数没有自己的 `this`，所以你不能这样做。

其次，我们不能使用带有箭头函数的 `new` 关键字。 这将引发 `X is not a constructor` 错误。

第三，如果该函数是箭头函数，我们不能在函数原型上添加属性，因为没有 `this`。

功能动物（名称，类型）{
this.name = 名称
this.type = 类型
this.age = 0
}
    
animal.prototype.birthday = 函数 () {
this.age++
}
    
const leo = new Animal('Leo', 'Lion')
