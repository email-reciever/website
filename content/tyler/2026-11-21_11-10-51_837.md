### Turso 全力以赴

**16 个月前，** 我们写了一篇名为 Chiselstrike 的初创公司如何构建一个无服务器平台，让您使用简单的 TypeScript 定义创建 RESTful 后端。

** 10 个月后，**他们推出了 [Turso](https://turso.tech/) 的私有测试版——一个边缘托管的分布式数据库，让您可以将数据带到边缘，使用称为 libsql 的分叉版本 SQLite。

这得到了 [a lot](https://twitter.com/mjackson/status/1656352953320751104) 的人 [real excited](https://twitter.com/kentcdodds/status/1650579952981676032) - 因为在边缘运行你的应用程序很棒，但除非你的 [data is on the edge too](https://twitter.com/rauchg/status/1522946481103294466?) ，否则它不会更快。 Turso 给了我们一个非常简单的方法来做到这一点。

**快进到今天，** 团队以 Turso 而闻名，而不是他们的 OG Chiselstrike 平台。 因此，他们决定通过将他们的名字改为 Turso 并将他们 100% 的精力集中在 Edge DB 平台上来拥抱人群的智慧。

有些人可能会称之为卖光了，但是嘿——在她开始为大众制作流行歌曲并将她的名字改为 Lady Gaga 之前，没有人知道 Stefani Germanotta 是谁。

**那么这位以前称为 Chiselstrike Turso 的艺术家的下一步是什么？** 扩大规模。 📈

私人测试版仅提供免费的入门计划，非常慷慨（9 GB 和 3 分贝），但不够强大，无法在生产中使用。 所以他们刚刚推出了一个新的 [Scaler Plan](https://blog.turso.tech/announcing-the-turso-scaler-plan-404e03c6cbf7)，它是付费 _(boo)_，但似乎确实提供了足够的存储和功能，使其可用于大型生产应用程序_(yay)。

此版本还附带 CLI 改进、新的 Turso Web UI 和完全公开的 Turso Platform API——它允许您将其与自己的解决方案集成。 谢天谢地，免费层不会去任何地方。

**底线：**如果我们能让每个人的数据都在边缘运行，那么每次我们使用网络时都会感觉我们都住在 `us-east-1` 的隔壁——但我们实际上不必搬到弗吉尼亚🙏。

尖端
--------

#### 赞助[Postman](https://blog.postman.com/build-software-faster-with-productivity-apis/?utm_source=bytes&utm_medium=email&utm_campaign=bytes_newsletter&utm_term=june_30_2023&utm_content=developer_productivity_apis)

_ 想知道用于提高开发人员生产力的最强大的 API 吗？ [This article](https://blog.postman.com/build-software-faster-with-productivity-apis/?utm_source=bytes&utm_medium=email&utm_campaign=bytes_newsletter&utm_term=june_30_2023&utm_content=developer_productivity_apis) 来自 Postman 分享了他们的首选，并为您提供了一种简单的方法来尝试它们。_

CSS 的 `currentColor` 属性（我们大多数人都知道和喜爱）允许您使用元素的当前颜色作为另一个属性的值。 这对边框、轮廓和盒子阴影等很有用。 但是您知道您可以动态调整透明度吗？

身体{
字体系列：无衬线；
颜色：浅粉色；
背景颜色：黑色；
}
    
分区{
填充：16px；
边框风格：实心；
边框颜色：color-mix（srgb，透明 60%，currentColor）；
}
    

CSS 中的 `color-mix` 函数通过按给定百分比将两种颜色混合在一起来返回新的颜色值。 第一个参数是颜色空间，第二个是百分比，第三个是要混合的颜色。 结合`currentColor`，非常有用。

您可以签出演示 [here](https://codesandbox.io/s/color-mix-demo-ddvdcq?file=/styles.css)
