### codesandbox 进入热点

自 2017 年 CodeSandbox 作为“React 应用程序的在线编辑器”首次推出以来，世界发生了很大变化。 我们已经看到了一些历史性的艺术进步，包括 \*Two\* _Sonic the Hedgehog_ 电影。 哦，Web Dev 也有一些进步。

多亏了 Wasm，Web 不再是 JavaScript 或 GTFO 的建立。 开发人员现在正在使用 Rust 和 C++ 等语言来构建比以往任何时候都更强大的 Web 应用程序，新的浏览器功能一直在使 Platform™️ 更加强大。

CodeSandbox 很好地驾驭了这一波，利用 Rust 使他们自己的 Web 应用程序更强大，并稳定地为大多数 Poplar JS 框架添加了支持。 仅在 2022 年，开发人员就使用它创建了超过 1400 万个沙箱。

就像网络本身一样， CodeSandbox 最近开始以其他一些有趣的方式展开它的翅膀并扩展其功能：

*   去年，他们引入了在MicroVMS而不是浏览器中运行的云沙盒和存储库。 这消除了一些浏览器限制，让您在 CodeSandbox 中运行服务器和数据库。 它还允许您通过其扩展直接在 VS Code 中进行编码。
    
*   迁移到 microVMS 允许他们在本月早些时候引入本机 Docker 支持，它允许您为 _any_ 编程语言创建沙箱——而不仅仅是 JavaScript。
    
*   上周，他们宣布正式支持Rust。 现在，您可以使用 CodeSandbox 快速启动 Rust 开发环境，并在其 Web 编辑器、iOS IDE 或您自己的 VS Code 设置上打开它。
    

**底线：** 我们看到很多玩家挤进了基于云的 IDE 军备竞赛，包括 Replit、Stackblitz 等。 现在说谁（如果有的话）将成为主导平台还为时过早，但关注 Web 开发和 Web 本身的相互依赖的发展是令人兴奋的——只是不像不断增长的 _Sonic Cinematic Universe_ 那样令人兴奋（明年第三部电影上映，标记你的日历）。

这个功能有什么作用？

常量惊喜 = (...fns) => 输入 => fns.reduce(
(ACC, Fn) => Fn(ACC)，输入
)
    

它是一个 `pipe` 函数，允许您通过将一系列函数作为参数并将它们按特定顺序应用到输入来将多个操作链接在一起。

哇，字。

而不是做这样的事情。

常量 toupperCase = str => str.toUpperCase()
const removeSpaces = str => str.replace(/\s/g, "")
常数附加解释 = str => str + "!"
    
ToupperCase(removeSpaces(addExclamation("订阅字节")))
    

你可以做这样的事情。

const pipe = (...fns) => 输入 => fns.reduce(
(ACC, Fn) => Fn(ACC)，输入
)
    
const formatString = pipe(ToupperCase, removeSpaces, addExclamation)
    
formatString("订阅字节") // 订阅字节！
    

目前有一个永久的 [TC39 proposal](https://github.com/tc39/proposal-pipeline-operator) 用于向 JavaScript 添加 True Pipe 运算符 (|>)。
