### Astro的新时代？

Astro 的发布周让我们感到自豪的父母在中学毕业时走过舞台时，泪流满面地拍摄了我们的孩子。

好吧，也许我们不是“父母”，因为我们实际上没有做任何事情来帮助创建它——但我们在2021年6月写下了它的首次公开发布，在2022年将其作为“最佳性能”的Osscar，我们用它来构建它 [react.gg](https://react.gg/) 和 [useHooks](https://usehooks.com/) 今年早些时候。 至少，这必须使我们有资格成为不恰当的_fun_叔叔。

但我离题了。 我们来这里庆祝 Astro 的发布周，以及它在过去两年中的每周 npm 下载量如何，宣布了与 Vercel 的官方 [hosting partnership](https://astro.build/blog/vercel-official-hosting-partner/)，并刚刚推出了一个具有里程碑意义的 [v3.0 release](https://astro.build/blog/astro-3/)。

让我们深入了解亮点：

*   **View Transitions API Support** — 此平台 API 为您提供 SPA 的所有柔滑流畅的过渡，无需任何页面刷新。 只需将 `ViewTransitions` 组件添加到任何页面的 `<head>` 元素，您就可以轻松地变形、滑动、持久化和淡入淡出 ([see live demo](https://astro-records.pages.dev/))。
    
*   **图像优化** — 新的内置 `<Image>` 组件允许您从代码库中导入图像并将它们放在页面上。 从那里，构建管道会自动为您检测和优化每个图像。
    
*   **更快的渲染性能：**现在大多数组件的渲染速度至少比Astro 2.9快30%，这要归功于删除不必要的代码并优化了其余代码。
    

我的 Astro 3.0 宾果卡上绝对没有另一项新功能：对内部 JSX 构建进行重大重构，以支持 React 快速刷新并显着改善 HMR 整体。

这应该可以更轻松地嵌入一个spa _within_您的Astro项目，并通过三个内聚元素解锁全新的Astro-Tastic体验：

1.  面向注销用户的快速、内容驱动的营销网站
2.   一个嵌入式客户端 SPA，用于在 React/Vue/Svelte 中编写的登录用户，并针对管理大量状态进行了优化
3.  可选的动态服务器API，为幕后的一切提供动力

考虑到 Astro 建立了狂热的热情粉丝群，主要是通过倡导反对 JS 重型水疗中心来建立其狂热的粉丝群，这似乎是一个令人震惊的举动。

但 Fred & Co 从未反对 _all_ 水疗中心，他们反对将更复杂、性能较低的 SPA 架构用于不需要它的简单内容网站。 值得称赞的是，Astro 一直承认客户端 SPA 通常是构建真正的 Web 应用程序的最佳方式。

而现在，Astro 3.0似乎可以为开发人员提供两全其美的优势——一个保持简单和快速的营销网站（尽可能少的JS），以及一个具有Spa所有功能的网络应用程序，可以用于长寿的会话，这不会 对注销用户的性能产生负面影响。

**底线：** 有了这样的版本，Astro Hype Train _Rocket_ 可能不会很快放慢速度。 所以我们必须珍惜这样的时刻，因为你的孩子总是长得太快了🥹。

发现错误：解决方案
-----------------------

#### 赞助[Secureframe](https://secureframe.com/request-demo-4?utm_source=partner&utm_medium=newsletter&utm_campaign=083123-bytes-newsletter)

这是一个由一个错误关闭的经典示例。 让我们逐步了解逻辑：

1.  `numbers1`被排序为`[2, 3, 4, 5, 8]`（奇数个元素）
2.  要得到中间元素，我们需要将数组的 `length` 除以 `2` (5 / 2 = 2.5)
3.  由于 `2.5` 不是一个有效的索引，我们需要四舍五入到最接近的整数，`2`
4.  然而减去 `1` 给了我们数组中的第二个元素，`3`，而不是中间元素，`4`

`Math.floor` 有效地执行了与减去 1 相同的事情，因此删除它可以修复错误。

函数 getMiddleValue(arr) {
arr.sort((a, b) => a - b);
    
if (arr.length % 2 === 0) {
const mid1 = arr[arr.length / 2 - 1];
const mid2 = arr[arr.length / 2];
返回 (mid1 + mid2) / 2;
} 其他{
返回 arr[math.floor(arr.length / 2)]; // 删除 -1
}
}
    
常数编号1 = [5, 3, 8, 4, 2];
常数编号2 = [40, 20, 60, 80, 50, 30];
    
console.log(getMiddleValue(numbers1)); // 4
console.log(getMiddleValue(numbers2)); // 45
