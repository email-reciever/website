### 移动 Qwik 并打破事物

当它故意拼错自己的名字时，你总是可以说出一些东西是_cool-and-edgy_ - Boyz II Men，Linkin Park，Froot Loops。

现在有 **QWIK** ——一个 HTML 优先的框架，它刚刚发布了第一个测试版，并声称提供“最快的页面加载时间，无论您的网站的复杂程度如何。”

我们通常对“最强”的说法有点怀疑，但Qwik背后的团队肯定赢得了怀疑的好处：Miško Hevery（AngularJS的创建者），Manu Almeida（杜松子酒和模板的共同创造者）， 和 Adam Bradley（Ionic 和 Stencil 的共同创造者）基本上是 WebVengers。

与 React 一样，Qwik 是基于组件的。 但与 React（以及其他所有当前 Gen 框架）不同的是，Qwik 以一种完全独特的方式呈现您网站的 UI，完全不需要水合作用。 （来自_waterboy_的Bobby Boucher陷入困境。）

**为什么不补水？** 因为 Hydration 是纯粹的开销，可以重复工作并减慢您的应用程序，尤其是当您添加更多 JavaScript 时（我们都知道您将添加更多 JavaScript）。

因此，Qwik 引入了 [Resumability](https://github.com/BuilderIO/qwik/blob/main/packages/docs/src/routes/docs/concepts/resumable/index.mdx#introducing-resumability) — 一种新的渲染范式，它允许完全交互式站点加载少量的 JavaScript，然后从服务器停止的位置获取。 当您的用户与您的网站交互时，IT 的相关部分按需加载。

这种“精确延迟加载”是可能的，因为 Qwik 应用程序完全序列化为 HTML。 因此，通过服务器端渲染，整个应用程序可以仅作为 HTML 传送到浏览器，在那里它将“恢复”加载它离开的地方——而无需执行任何 JavaScript。

假设，这可能意味着 Qwik 是一个真实的帝国时代 II_ 作弊代码的版本：您可以将尽可能多的 JavaScript 添加到您的网站，并且 _still_ 得到一个 [perfect Lighthouse score](https://dev.to/builderio/how-we-cut-99-of-our-javascript-with-qwik-partytown-3i3k) （您甚至不必输入“奶酪牛排” 吉米的”来激活它）。

**底线：** Qwik 感觉像是迄今为止最有前途的新 JavaScript 框架之一，因为 1）它以一种与大多数开发人员现有的技能和偏好一起工作的方式解决了性能问题，以及 2）它是由一个知道如何扩展的团队构建的 OSS UI 框架。 继续关注。

发现错误：解决方案
-----------------------

#### 赞助[FusionAuth](https://fusionauth.io/tech-papers/multi-factor-authentication-for-developers?utm_medium=advertising&utm_source=uidev&utm_campaign=mfa-tech-paper)

Const Newsletter = "字节"
const tagline = "您每周的 JavaScript 剂量"
    
[通讯，标语].forEach((El) => Console.log(El))
    

得知此代码未执行，您可能会感到惊讶。 如果你尝试，你会得到一个错误——`Uncaught ReferenceError: tagline is not defined`。 但很明显，对吧？ 错了。

这是 _very_ 罕见的情况，不使用分号会咬你。 因为我们有一个字符串后面跟 _no_ 分号后面跟一个开口数组括号，所以 JavaScript 会像这样解释我们的代码，就好像我们试图从字符串中访问元素一样。

“您每周的 JavaScript 剂量”[通讯，标语].forEach();
    

当然，这会引发错误，因为标语没有定义。 要解决此问题，请在数组之前添加 `+` 符号。

Const Newsletter = "字节"
const tagline = "您每周的 JavaScript 剂量"
    
+[时事通讯，标语].forEach((el) => console.log(el))
    

这主要是一个笑话，但它确实有效……

相反，只需使用分号。

Const 时事通讯 = “字节”；
const tagline = "您每周的 JavaScript 剂量";
    
[时事通讯，标语].forEach((El) => Console.log(el));
