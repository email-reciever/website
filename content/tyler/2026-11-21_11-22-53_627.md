[Aleph.js - A Bleeding Edge React Framework](https://alephjs.org/)
--------------------------------------------------------------

![Identity Theft](https://bytes.dev/images/content/jim.jpg)

身份盗窃不是笑话，吉姆

**aleph.js 是一个内置的新 React 框架**，它说它“受”Next.js 的“启发”。 这有点像说我的高中生物学决赛“受到了我聪明朋友的回答的启发”，但如果你不这样做，我们不会评判。

无论如何，网络是一个协作的地方，[the Next.js team seems cool with Aleph.js](https://twitter.com/leeerob/status/1324719349932924929) “受到”他们的标志、登录页面和文档的启发。 也许这是因为下一个团队是相信免费和开放互联网的好人，或者可能是因为 aleph.js 文档明确建议使用 Vercel 部署您的应用程序。

Aleph.js 有许多您期望从下一个克隆（SSR 和 SSG 功能、基于页面的路由等）中获得的功能。 但有一些关键功能使其独一无二：

*   **它是内置的 Deno** — 支持 TypeScript 的 [“simple, modern, and secure” runtime](https://deno.land/) 开箱即用，并且仅提供单个可执行文件。 这意味着您可以与 `package.json` 和 `node_modules` 目录说再见，因为所有依赖项都作为 URL 导入并由 aleph.js 管理。
    
*   **它使用 ESM 导入语法** — 这使得 Aleph 不需要使用 webpack 或任何其他捆绑器。
    
*   **`useDeno` 是一个 React Hook**，它允许您在构建时在组件（用于 SSR）中获取数据或异步获取数据（对于 SSG）。 与 Next 的 `getStaticProps` 和 `getServerSideProp` 功能相比，这更像是一个混合解决方案。
    

### 底线

Aleph 仍处于 alpha 中（或 _aleph-a_），尚未准备好生产，但查看这些前沿框架并看到 Deno 生态系统开始形成仍然很有趣。

[Supabase.js 1.0 Released](https://supabase.io/blog/2020/10/30/improved-dx/)
------------------------------------ ------------------------------------

![Nicki Minaj](https://bytes.dev/images/content/nicki.jpg)

有人请告诉他们我是谁

**Supabase.js 上周发布了其后端即服务平台的 v1.0**，该平台自称是“Firebase 的开源替代方案”。

创作者建立 Supabase 是因为他们喜欢 Nicki “Firebase 的功能”，但厌倦了遇到扩展问题。 所以他们做了我们任何人在这种情况下会做的事情：[stitched five open-source tools together into one platform](https://supabase.io/docs/#how-it-works)，进入 YCombinator，并筹集了 510 万美元的 VC，因为 WTFN。

为了提高可扩展性，Supabase 使用 **PostgreSQL** — 比 Firebase 的 NoSQL 功能更大的关系数据库。 Postgres 可能很难使用，因此 Supabase 构建了 [a nice UI around it](https://youtube.com/watch?v=1gNDMMsUPI0) 来为我们提供两全其美：PostgreSQL 的可扩展性 + Firebase 的可用性。 这是后端的汉娜蒙大拿。

如果您已经使用过 Supabase 的 Alpha 版本，您会欣赏此 v1.0 版本的一些 **新功能：**

*   现在返回错误而不是抛出（少喊大叫）
*   一个新的子库调用了Netlify的GoTRUE AUTH服务器`gotrue-js`
*   Supabase的所有自定义库现在都使用TypeScript原生构建

### 底线

*   拥有一个不属于科技巨头的新的开源后端平台是不是很酷？ 是的。
*   这看起来不是和Hasura真的很相似吗？ 也是。
*   我们还会在 9 年后谈论 _Supabase_，就像我们今天谈论 Nicki 的标志性_Super Bass_ 一样吗？ 你告诉我们。
