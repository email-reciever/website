### 未来的Solid.js元框架

我从来不想为奇怪的 Al Yankovic 粉丝和 Ryan Carniato [never wanted](https://x.com/RyanCarniato/status/1793000648079716783) 建立一个约会网站来为 Solid.js 构建一个元框架——但我们俩都在这里。

在 Ryan 的案例中，我说的是 [SolidStart 1.0](https://start.solidjs.com/)，它刚刚在周二推出，并建立在一个大胆的前提之上：_如果你的元框架少了一点元数据怎么办？

像大多数应用程序框架一样，SolidStart 仍然集成多个包来为您提供全栈功能，但它都是可组合的。 因此，可以用您选择的不同选项替换框架的每一部分。

**让我们分解它的工作原理：**

*   SolidStart 建立在 Vinxi（基于 Vite+Nitro 的捆绑器和运行时）、Seroval 序列化程序和 Solid 路由器之上——但您可以用自己的实现替换其中的任何一个。
    
*   您获得了所有应用程序框架功能，例如基于文件的路由、流式传输、所有渲染模式、服务器功能和操作以及 API 路由——但它永远不会将您锁定在任何特定的约定中。
    
*   您可以轻松部署到 Nitro 预设的 25 多个平台中的任何一个，包括 Cloudflare、Vercel、Deno 和 Bun。
    

**底线：** SolidStart 声称他们选择自己的冒险方法将是“未来框架的形式”。 这听起来可能有点大胆，但Solid已经在JavaScript生态系统中拥有了良好的趋势记录——在2019年开创了信号的使用，并在2022年初加入了服务器功能。

现在，如果你能原谅我，我需要在我的 _Poodle Hat_ 匹配算法中解决一些问题。

记录什么？

for (var i = 0; i < 5; i++) {
setTimeout(() => console.log(i), i * 1000)
}
    

对你们所有的老头来说都是一个小小的回归。 这曾经是每个人最喜欢的 JavaScript 面试问题。

此代码最终将记录 `5`，5 次。

原因是我们用 `var` 声明了我们的变量，它是函数范围的。 当我们给 `setTimeout` 的函数运行时，`i` 已经是 `5` 并且每个函数都会引用相同的变量。

要解决此问题，请使用块作用域的 `let`，并将为我们的 for 循环提供自己的每次迭代 `i`。

for (let i = 0; i < 5; i++) {
setTimeout(() => console.log(i), i * 1000)
}
    

或者，您可以通过 `setTimeout` 的第三个参数将 `i` 作为参数传递给函数的正确值。

for (var i = 0; i < 5; i++) {
setTimeout((CaptureDi) => Console.log(CaptureDi), I * 1000, I)
}
    

或者你可以使用 iife 来做同样的事情，哈哈。

for (var i = 0; i < 5; i++) {
（（捕获）=>
setTimeout(() => console.log(Capturedi), I * 1000)
)(我);
}
