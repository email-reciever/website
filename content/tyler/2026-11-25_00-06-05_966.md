## Cool Bits

1. Vadim Makeev 撰写了关于 [新的 CSS 属性：`link-parameters`](https://pepelsbey.dev/articles/svg-link-params/) 的文章，它允许你将 CSS 值传递到链接资源中，例如 SVG。唯一的缺点是，它还“远远没有达到生产就绪状态” 😭。

2. 说到 CSS，Ahmad Shadeed 展示了 [如何使用 CSS 检测元素是否重叠](https://ishadeed.com/article/css-detect-overlap/)。在层叠样式表的领域里，事情变得越来越奇怪。

3. [Apify Store](https://apify.com/store?fpr=fireship) 搜索现在支持意图匹配。你可以根据需要的数据、搜索的网站或工具是否连接到 MCP 服务器进行筛选。使用代码 BYTES 即可获得 25 美元的积分。 \[sponsored]

4. Meta 团队撰写了一篇非常长的文章，并制作了一段不错的视频，展示了 [他们如何为 Muse 构建安全的 VM 架构](https://research.meta.ai/blog/security-and-safety-for-ai-agents-our-approach-with-muse)。你可以完全信任他们来处理你的数据。

5. Addy Osmani 撰写了关于 [如何充分利用 Opus 5.5](https://claude.dev/blog/getting-the-most-out-of-opus-5-5/) 的文章。它是你不知道自己需要的礼仪教训。

6. DHH [在 Rails World 2026 上打破了 Rails 开发者的心](https://www.youtube.com/watch?v=vDjW_dRyKXY) ，当时他说他已经从专业编程中退休，并且正在让代理为 HEY 的后端编写 Rust 代码。这就像教皇否认天主教吗？

7. Convex 的 CTO James Cowling 发表了一个重要的演讲，关于 [抽象仍然很重要](https://www.youtube.com/watch?v=3EUsbss8UOw) 的原因，以及即使工程师没有编写代码，他们仍然对所交付的内容负责。 \[sponsored]

8. Anant Goel 撰写了关于 [评估的盲点](https://delta.dev/blog/beyond-pass-rate) 的文章。

9. Vue Router 正在开发 [实验性的滚动恢复](https://github.com/vuejs/router/pull/2805) 功能。迟做总比不做好 🫡。

10. [Hyperagent](https://hyperagent.com/fireship100) 允许您构建一队专家代理，运行他们自己的浏览器、shell 和文件系统。它们与您的工具集成并共享上下文，因此它们可以在不需要您监督的情况下将特定任务交给他人。 [在此获取免费积分](https://hyperagent.com/fireship100). \[sponsored]

11. Manu Martínez-Almeida 撰写了关于他在 LLMs 之前为 Builder.io 构建 [Figma-to-code](https://manualmeida.dev/articles/figma-to-code-before-llms/) 的文章。

12. Google 发表了一篇关于 [如何自动化“连贯”的长视频生成](https://research.google/blog/coherent-long-form-video-generation/) 的博客文章。 不幸的是，他们让每个人都沉迷于 YT 短视频。
