### 我们应得的英雄

如果有一场 Code Golf 的大师赛，杰森“在他身上得到了那条狗”，米勒可能会比老虎伍兹拥有更多的绿夹克。 首先，他创建了 Preact——一种替代字节数比这份时事通讯更少的反应的替代方案，现在他和他的团队再次使用一个名为 [Signals](https://preactjs.com/blog/introducing-signals/) 的新的状态管理库重新使用它。

在我们深入 [nitty gritty](https://www.youtube.com/watch?v=GCMtwS1mNxc) 之前，让我们快速回顾一下，让每个人都跟上进度。

当人们抱怨 React 时，它通常与不神圣的三位一体有关：捆绑大小、性能（虚拟 DOM + 重新渲染）和钩子。 Preact 是为了解决第一个问题而创建的，但它仍然有许多与 React 相同的问题。

在更新状态时，两个框架都会在引擎盖下进行大量额外的工作以确定要更新的元素。 当 Hooks 被释放时，事情变得……很奇怪。 输入信号。

信号将状态完全转移到 preact 之外。 它跳过了重新渲染组件的所有昂贵工作，只更新了直接访问状态值的那些。 更少的工作=更快的速度。 [See for yourself.](https://preactjs.com/blog/introducing-signals#:~:text=This%20difference%20is%20most%20apparent%20when%20measured%20in%20the%20browser%20%2D%20the%20screenshot%20below%20shows%20a%20DevTools%20Profiler%20trace%20for%20the%20same%20app%20measured%20twice%3A%20once%20using%20hooks%20as%20the%20state%20primitive%20and%20a%20second%20time%20using%20signals%3A)。

**这是信号的工作方式：**

*   **lazy 默认** - 信号仅在它们真正需要时才起作用（我们钦佩的特征）。
    
*   **最佳更新** — 如果信号的值没有改变，即使信号的依赖关系发生了变化，使用该信号值的组件和效果也不会被更新。
    
*   **最佳依赖跟踪** — 没有更多的依赖数组🙏。 信号处理所有这些，就像一个真正的绅士和学者一样。
    
*   **直接访问** — 当您访问信号值（没有选择器或自定义钩子）时，您会自动订阅更新。
    

最好的部分，信号全开[Mason Ramsey](https://twitter.com/LuisThePhotog/status/999472968110673920?s=20&t=XBmYN1_rOS0Z7dB7E8krhw)并创建了一个React包🔥。

**底线：** Jason [literally hacked React](https://github.com/preactjs/signals/blob/main/packages/react/src/index.ts#L25-L39) 并给了我们自 Hooks 首次问世以来一直在要求的一切。 再给这个人买另一件绿色夹克。

日期库对决 - 来自 npmtrends.com 的数据

Moment.js 一直是日期库游戏中最大的玩家（在 JavaScript 中），但在得到捆绑大小的羞辱后，他们最近认输并宣布开源破产。

Date-FNs 旨在成为 Moment 的“现代”（又名树木摇晃）替代品，并享有很多人气，但这种趋势的真正推动因素是 Day.js——一种更快、现代的等价物，具有相同的 API（有点像 Preact 是 React）。

提升后部是卢克森。 它也做了一些很酷的东西，但可能比作为一个真正的替代品更适合常绿项目。

**要点：** 在 JavaScript 中处理日期仍然很糟糕，您可能需要某种类型的库。
