## Cool Bits

1.  Will Binns-Smith wrote about [how to use agents to reduce your Next.js bundle size](https://nextjs.org/blog/ship-less-javascript-with-ai). Glad Will kept the hyphen in his name because we did NOT need another Michael Jackson situation.
    
2.  Felix Rieseberg wrote [some advice for junior engineers](https://felixrieseberg.com/hunger-beats-tenure-advice-for-junior-engineers/). Basically “stay hungry stay foolish” but for the AI era. Good luck out there.
    
3.  Node2Shell? Broccoli2Shell? Call it \*2Shell. Attackers are already exploiting it while your coding agent is blissfully unaware and shipping code. [Semgrep Guardian](https://semgrep.dev/guardian/?utm_source=fireship_bytes&utm_medium=referral&utm_campaign=2026-10_fireship_guardian_campaign) catches vulnerabilities and makes your agent fix them as it builds, so the bad stuff never makes it to a PR. Bytes readers can get an [exclusive 60-day free trial here](https://semgrep.dev/onboarding/guardian?offer=fireship_202610&utm_source=fireship_bytes&utm_medium=referral&utm_campaign=2026-10_fireship_guardian_campaign). \[sponsored\]
    
4.  Google [released Gemini Carbon](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-carbon/) their latest frontier model. Any bets on how many elements they get through before people start using their models?
    
5.  Luke Edwards created [an HTML parser](https://github.com/lukeed/html) that’s 3-6x faster than other JavaScript parsers complete with source offsets and CSS selectors.
    
6.  Cartesia Research shared some of their learnings about [how to scale hierarchical networks](https://www.cartesia.ai/blog/from-tokens-to-bytes-part-1). TLDR h-nets use bytes instead of tokens, 10x less compute, and work for all kinds of data 🤯.
    
7.  [Jam’s new Mac app](https://jam.dev/mac?utm_campaign=mac-launch&utm_source=bytes&utm_content=2) lets you record your screen and hand your agent the video, logs and transcript, all synced to the moment you’re talking about. It’s the most targeted context you can give an agent to fix a bug or redesign the UI. \[sponsored\]
    
8.  Someone with way too much time (or tokens) [documented a Romeo and Juliet style love story](https://tiboandpoteto.com/) between two tech leads at competing AI labs.
    
9.  Nolan Lawson did some research on [what front end frameworks cost the most tokens to use](https://nolanlawson.com/2026/10/28/the-ai-cost-of-javascript-frameworks/). None of this will matter when we’re all using H-nets right?
    
10.  Congrats, your AI agent writes code 10x faster. Now you just review it 10x slower – which is why teams at Dropbox, Wiz and ElevenLabs use Meticulous to [verify every user flow and edge case](https://www.meticulous.ai/?utm_source=bytes&utm_medium=newsletter&utm_campaign=26q3_1&utm_term=Oct&utm_content=secondary). There’s no developer effort, so they can get back to actual engineering. \[sponsored\]
    
11.  Alexandre Trotel whipped up [an in-depth guide walking you through React’s internals](https://www.alexandretrotel.org/articles/understanding-react-internals).
    
12.  Antonio Scandurra wrote about [how he built fine grained version control for his agents using Rust, CRDTs and Durable Objects](https://delta.dev/blog/fine-grained-version-control-for-agents). Congrats Antonio I think you checked off every buzzword on my Hacker News bingo card.
