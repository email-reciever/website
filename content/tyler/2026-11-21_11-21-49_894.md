盖茨比 3.0
-----------

![Kyle Matthews as Gatsby](https://bytes.dev/images/content/kyle.jpg)

🙃

**我们是如何到达这里的：** GatsbyJS 是一个用于静态站点生成 (SSG) 的 React 框架，它是在 React 的旧石器时代 (AppX. 2015) 创建的。 它很快成为建立博客和电子通讯商店等静态网站的默认选项，并利用这种人气建立了一家此后在风险投资中筹集了 4700 万美元的公司。 这是很多[fancy shirts](https://www.youtube.com/watch?v=uyZrLD_fDLY&t=35s)。

竞争最近一直在升温，像 Next.js/Vercel 这样的新玩家将脚趾浸入 SSG 水中，所以我们很高兴看到 Gatsby 为 v3.0 准备了什么——这是它 2 年来的首次主要版本。

**亮点：**

**更快的本地开发体验** — 快速刷新所有内容，更易于访问和可靠的错误叠加，以及“仅在需要时获取所需的东西”帮助 Gatsby 3 在某些情况下更快地“提高 70%”的本地开发体验 （他们的话）。

**增量构建** — 这被标记为实验性的一段时间，但现在它是 Gatsby 开源中默认启用的真正男孩（就像您可能正在使用的 Gatsby - 命名内容很难）。 一般的想法是，不是内容更新启动整个网站的完整重建，IB 只更新具有要显示新内容的页面。

**2 大插件更新** — Gatsby 插件图像（为 Gatsby 众所周知的图像处理提供支持）已更新，使其更易于使用且性能更高。 还有一个更新的[Gatsby Shopify source plugin](https://github.com/gatsbyjs/gatsby-source-shopify-experimental)候选版本，它可以让您在Gatsby中获取Shopify数据并提高Shopify网站的构建性能。

他们还为 Gatsby Cloud 引入了新的托管功能，这显然为客户提供了“超快”的部署时间。 它还为 Gatsby 提供了一个新的货币化角度。

Flutter 2.0 即将推出 Web 一切
------------------------------------------

![Napoleon Dynamite](https://bytes.dev/images/content/napoleon.png)

OG 扑通扑通

**您甚至是真正的科技巨头……** 如果您不花费数百万美元来构建自己的编程语言/框架/库？

谷歌不打算知道，所以他们用他们的一些老大钱“有针对性的广告收入”来构建 Flutter UI 工具包，上周只是 [released v2.0](https://developers.googleblog.com/2021/03/announcing-flutter-2.html)。

**快速评论：** 谷歌在 2019 年发布了 Flutter，作为最终将 Dart 用于构建本地编译的跨平台移动应用程序的开源工具包的一种方式。 它由 [Dart](https://developers.google.com/learn/topics/dart) 构建，并稳步扩展到移动应用程序之外，这有助于推动其快速 [rise in popularity](https://voximplant.com/blog/flutter-for-real-communication)。

**Flutter 2.0** 在很大程度上将可扩展性加倍。 发布公告自豪地声称，V2 使开发人员能够使用相同的代码库将原生应用程序运送到五个不同的操作系统（iOS、Android、Windows、MacOS 和 Linux），并为所有主要浏览器创建 Web 体验。

**网络支持：** Flutter 摆脱了传统的“以 DOM 为中心”的 Web 开发方法，转而采用“以应用为中心”的方法 [CanvasKit rendering engine](https://skia.org/user/modules/canvaskit)。 这个 WebAssembly 项目使 Skia 图形引擎（为 Android 和 Chrome 提供支持）可用于 Web 应用程序，提供 [modern graphics](https://flutterplasma.dev/) 和可靠的性能。

**支持其他一切：** 就像 UNI 的努力一样，Flutter 希望参与尽可能多的课外活动。 他们与 Canonical（Ubuntu Linux 发行版的创建者）、微软和丰田等公司建立了官方合作伙伴关系，为平板电脑、汽车和各种物联网设备创造“数字体验”。 亚马逊、Adobe 和 Square 等公司有超过 15,000 个用于 Flutter 和 Dart 的套餐。

### 底线

“好吧，为什么谷歌要做这一切？” 我们可以听到你的要求。 因为它是谷歌，所以这个问题的答案总是一样的：**“显然是为了广告。”**

Flutter 2 版本的最后一个版本提到了 Google Mobile Ads for Flutter 的新测试版——“一种与 AdManager 合作的新 SDK，可提供各种新的广告格式。”

**想象这个乌托邦：** _你在 2024 年 3 月的一个早晨起床。你在智能手表上检查你的智能烤面包机应用程序（使用 Flutter 内置），看看你的芝麻百吉饼是否完成了完美的烤面包。 它没有。 在您等待的同时，您的智能手表会通过 Google 的草莓奶油奶酪广告与您联系。 你昨晚完全忘记在商店买一些了——真是一场危机！ 但对你来说幸运的是，谷歌已经学会了你的敬酒习惯、你的百吉饼消费习惯和奶油奶酪偏好（有时你喜欢纯奶油奶酪，但谷歌知道这将是一个草莓的早晨）。 您可以在您的 Smart Toaster 应用程序中订购草莓奶油奶酪，Google Shopping 可以在几分钟内将其交付给您。 避免了危机！_
