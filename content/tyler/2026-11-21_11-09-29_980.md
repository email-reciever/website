### V0 为英雄

在今天的_我们的创业公司的节目中，现在实际上是一家人工智能公司，_ Vercel 刚刚推出了 [v0](https://v0.dev/)，他们将其描述为“中途反应”。

不，这并不意味着它可以组成半史莱克半驴人的诅咒图像。 但它 _does_ 允许您使用自然语言提示生成基于 Tailwind CSS 和 Shadcn/UI 的复制粘贴 React 组件。

V0 仍处于私有 Alpha 中，但我们迄今为止看到的联系表、推荐卡、定价页面和其他示例组件的早期结果看起来很有希望。

在这一点上，你可能会想，_等一下，这是我为我的工作所做的 90%。_

是的，但我也有好消息：当奥的斯电梯公司在 20 世纪初开始销售自动电梯时，它让电梯运营商的所有工作变得更容易……几个月了。

好吧，我（大部分）在开玩笑。 像大多数生成式人工智能技术一样，V0 并没有在第一次尝试时吐出像素完美的最终产品。 目前，对于解决空白画布问题似乎最有用，以帮助您更快地开始和迭代。

以下是构建时尚着陆页的 V0 工作流程：

*   键入初始提示，如“时尚、条纹启发的 `my boring SaaS product` 着陆页”，V0 返回三个不同的 UI 选项，并附有代码。
    
*   选择您最喜欢的一款，并通过提供额外的提示继续迭代。 您可以提示对特定元素或整个 UI 进行更改。 V0 保留版本历史记录并创建您可以与团队共享的链接。
    
*   一旦你在AI提示下尽可能接近，你就可以复制和粘贴React代码并继续自己继续工作。

发现错误：解决方案
-----------------------

#### 赞助[Secureframe](https://secureframe.com/request-demo-4?utm_source=partner&utm_medium=newsletter&utm_campaign=091823-bytes-newsletter)

从“反应”导入 { useState }；
    
导出默认函数 counter() {
const [number, setNumber] = useState(0);
    
返回（
<>
<h1>{编号}</h1>
<button onClick={() => {
setNumber(数字+1);
setNumber(数字+1);
setNumber(数字+1);
}}>增量</button>
        </>
)
}
    

您可能会期望单击按钮会将我们的 `number` 状态增加 3，但这不是它的工作方式。 简而言之，JavaScript 围绕 `number` 变量创建了一个闭包，就好像我们在做

setNumber(0 + 1);
setNumber(0 + 1);
setNumber(0 + 1);
    

当然，这将始终将 `number` 设置为 1。

相反，如果我们想在下一次渲染之前多次更新相同的状态，我们可以像这样将函数传递给我们的 setter 函数 -

setNumber(n => n + 1);
setNumber(n => n + 1);
setNumber(n => n + 1);
    

现在 React 会将所有这些函数添加到队列中，在下一次渲染期间，React 会通过队列中的前一个项目的结果传递到下一个项目，最终导致 3 的 `number`。

0 + 1 = 1
1 + 1 = 2
2 + 1 = 3
