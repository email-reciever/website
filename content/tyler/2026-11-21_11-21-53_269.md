打字稿版本_v4.20-blaze-it_
----------------------------------

![Elon Musk smoking TypeScript](https://bytes.dev/images/content/elon.png)

这些类型是**有效的。**

**TypeScript 上周发布了其季度更新……** 恰好是 _4.20_ 版本。 尽管不是主要版本，但我们计算了十个新功能和九项重大更改。 显然，比尔·盖茨仍在微软的一艘紧凑的船上。

这是很多功能/更改要解包，因此我们将覆盖前 3 个（根据我们的说法），并让您在非常长的详细 [release notes](https://devblogs.microsoft.com/typescript/announcing-typescript-4-2/#breaking-changes) 中自己查看其余部分。

**1.** **[Changes to rest elements in tuple types](https://github.com/microsoft/TypeScript/pull/41544)** — 元组（发音元组）有点像 VR/AR 耳机：人们更喜欢谈论它们而不是实际使用它们。 **tl;dr** 是元组是数据类型，可以让你用固定数量的元素表达数组，它们不需要是相同类型的元素（即你可以在一个数组中有一个字符串和一个数字）。

TypeScript 用于仅允许在元组的最后一个位置处允许 REST 元素，但现在它们可以出现在元组中的任何位置，这（根据 PR 的说法）很有用，“对于具有以固定参数集结尾的变量参数列表的强键入函数。

**2.** **`abstract` 构造签名](https://github.com/microsoft/TypeScript/pull/36392)** — 此功能的原始 PR 是在 2020 年 1 月首次制作的：当我们大多数人都没有听说过 Covid 和 GameStop 只是一个有趣的商店，孩子们去那里 [ripped off](https://twitter.com/GameStop/status/1151169537989107712) 时，这是一个更简单的时期。 十年后，我们终于支持构造函数类型和构造签名的 `abstract` 关键字，这有助于以支持抽象类的方式编写 mixin 工厂。

**3.** **`--explainFiles` 用于找出您的项目结构](https://github.com/microsoft/TypeScript/pull/40011)** — 一种新的和改进的方法来回答古老的问题：_“为什么世界上是包含此文件的打字稿？”_现在您可以只使用 `--explainFiles` 标志和 ts 编译器 将为您提供一个输出列表，说明为什么它包含各种 `lib.d.ts` 文件、本地文件和 `node_modules` 文件。 低调，这可能是该版本中最有用的新功能。

Hasura 发布 v2.0
---------------------

![Hasura](https://bytes.dev/images/content/hasura.png)

美国准备与哈斯克尔恶魔作战

**这只是对 Hasura 这个名字的致敬，我们刚刚了解到的是梵文单词“恶魔”_(Asura)_ 和 Haskell 的组合。 好吧，那些疯狂的小哈斯克尔恶魔上周刚刚发布了 Hasura 的 GraphQL 引擎的 v2.0，这是他们多年来最重要的版本。

**快速回顾：** Hasura 的开源 GraphQL 引擎是几年前首次将 Hasura 放在地图上的原因。 它是 [fast](https://github.com/hasura/graphql-backend-benchmarks)，它不需要构建步骤，因为它的配置是完全动态和基于 API 的。 该引擎还为您提供实时的 GraphQL API，而不是 Postgres 上的 Webhook 触发器，用于业务逻辑的数据库事件和远程模式。

** V2 有什么新功能：**

*   **数据库多样性** — 最初，Hasura 仅支持 Postgres，但 Hasura 2.0 具有重构的“查询编译管道”，因此可以将引擎通用化以与任何数据库一起工作。 它还允许您同时连接到多个独立的数据库。
    
*   **最好的 REST 和 GraphQL** - 由于 REST API 似乎不会很快消失，因此 Hasura 2.0 现在可以让您创建 [idiomatic REST endpoints based on GraphQL templates](https://github.com/hasura/graphql-engine/blob/master/rfcs/rest-endpoints.md)。 这里的想法是在您需要时为您提供 GraphQL 和 REST 的所有好处。
    
*   **新的和改进的授权引擎** — 更新的授权引擎扩展了跨数据源的 Hasura 的 Auth 策略能力。 这意味着您可以在您自己的 GraphQL 服务或外部 GraphQL API 上控制您不拥有的基于角色的模式和预设参数的授权。
