### 加入

您可能还记得我们今年早些时候运行的 [TEN PREDICTIONS FOR 2022](https://bytes.dev/archives/81) 问题。 在“React 18 Will……_Launch_ 🥲”（粗体）和“Rip Babel and Webpack”（也很粗体）等预测中，我们还对每个人最喜欢的元框架进行了介绍。

“Netlify 将收购 Remix。‘Bottoms Up’ 框架是一波。Netlify 将想要发行版和 Remix 想要的……钱。这将让 Remix 团队将时间花在他们擅长的东西上，混音框架，而不是混音框架，而不是 “remix-the-business. 配对将使他们能够更好地赶上vercel/next.js。”

当时这种做法是 [controversial](https://twitter.com/remix_run/status/1478368210810404864)，但就像马鞋、手榴弹和年度技术预测一样，数量足够多。 一个快速的 `prediction.replaceAll("Netl", "Shop")`，我们成功了！

因此，随着“我们告诉你”的行列，让我们深入了解细节。

**为什么？** 每当您看到收购时，您应该问的第一个问题是“为什么”。 对于 Shopify，“为什么”似乎与他们在 RSC（React Server 组件）[not panning out](https://twitter.com/jplhomer/status/1587095536833859584?s=20&t=U3I1Bb8rYuSCSG8PlMcdaw) 上的下注有很大关系。 “虽然我们对 RSC 的长期未来感到兴奋，但作为一个关键的依赖，它提出了许多挑战，这些挑战成为我们开发人员的性能风险，也是我们进步的瓶颈。” 因为氢气已经建立在 React 路由器之上，所以 Remix 是 RSC 的自然替代品（解决了许多相同的问题，但……就像不同的）。 对于 Shopify 来说，这似乎是一个坚实的举措。 但是混音呢？ 好吧，显而易见的答案是……金钱。

**混音 Rich Rich 也是如此吗？** 也许，_也许不是_。 Remix 在 2021 年 10 月筹集了 300 万美元。有 7 名员工每人进行市场利率，他们可能已经没钱了。 在这种情况下，您要么获得盈利 (LOL)，要么筹集另一轮融资，要么出售，要么关闭商店。 根据当前的市场动态，提高种子轮所需的差距与提高系列 A 所需的差距是 [bigger than it’s ever been](https://twitter.com/Austen/status/1566503990287732736)，限制了 Remix 的选择。

我们假设是一个不利的偏好堆栈（这决定了谁在出售时首先获得报酬，提示：投资者），有可能“加油”、BigCo 特权和软着陆是“加入”发生的一切。

**底线**：Remix 在过去几年中一直是 JavaScript 领域中最两极分化的项目，这已经不是什么秘密了。 但无论你站在哪一边，都很难否认它从根本上改变了我们对 Web 应用程序的思考和构建方式——因此 Web 会因此而变得更好。

发现错误：解决方案
-----------------------

#### 赞助[Callstack Open Source](https://www.callstack.com/open-source)

当您调用 `array.push` 时，它不会返回更新的数组，而是使用新项目的数组的更新 `length`。 这意味着您不能将 `.sort()` 调用链接到结尾，因为 `.push` 的结果是一个数字。

有两种方法可以解决此问题。 一种选择是在 `.push` 呼叫后调用 `array.sort()`。

函数 addAndSort(数组, 元素) {
array.push(元素)
返回数组.sort();
}
    

第二个选项将该项附加到带有 `array.concat()` 的新数组，然后对新数组进行排序。

函数 addAndSort(数组, 元素) {
返回 array.concat(元素).sort();
}
