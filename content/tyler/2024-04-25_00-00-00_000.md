### 反应本土瑜伽

当我第一次得知周二的 [React Native 0.74 release](https://reactnative.dev/blog/2024/04/22/release-0.74) 带有“Yoga 3.0”时，我认为 React Native 团队已经为我的下背部疼痛创建了下一代软件解决方案。

但事实证明 [Yoga](https://www.yogalayout.dev/) 只是 RN 布局引擎的名称，它可能不会帮助您打开任何脉轮😭。

也就是说，Yoga 3.0 确实提供了一些新的更新，这些更新应该使样式更具可预测性：

*   完全支持 `static` 位置类型，允许您相对于不是其直接父级的祖先定位元素
    
*   支持 `align-content: 'space-evenly'`，它使用均匀间隔的间隙在多行 Flex 容器中分布线
    

这个 0.74 版本的另一个大新闻是，当您启用（仍然是实验性的）新架构时，React Native 将 [Bridgeless Mode](https://github.com/reactwg/react-native-new-architecture/discussions/174) 设置为默认值。

从历史上看，这座桥促进了 JavaScript 和 Native 之间的通信——但由于其异步设计、消息批处理和序列化成本，它一直在限制 React Native。 这就是为什么 RN 团队在过去几年中一直在努力移动组件渲染，而 RN 运行时间_Off_ 的其余部分将完全结束。

**底线：**他们说保持相关性的最佳方式是扰乱自己，当React Native接近它的10周年（！！）周年纪念时，这种新架构看起来可以为该框架带来一个全新的时代——一个具有并发React功能、改进的DX和更现代化的架构 构建跨平台应用程序的方法。

记录什么？

常量 myObject = {};
    
常量键 = 符号('键');
    
myObject[key] = '这是键的值';
    
console.log(myObject[symbol('key')]);
console.log(json.stringify(MyObject));
    

1.  `undefined` - `Symbol` 构造函数创建一个唯一值，因此用于设置 `myObject[key]` 值的 `Symbol` 与用于获取 `myObject[key]` 的值的 `Symbol` 不同。
    
2.  `{}` - `JSON.stringify` 在字符串化对象时忽略 `Symbol` 属性。
    

这对于在对象外部无法访问或修改的对象上创建私有属性很有用。 您可以阅读有关符号 [here](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Symbol) 的更多信息。
