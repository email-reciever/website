Prisma 的新方向
-----------------------

![Katy Perry](https://bytes.dev/images/content/katie.png)

你会看到（我的后端）ROAR-R-R-R-R

**Prisma 又回来了** 一套新的工具和一个稍微新的方向。 经过多年告诉大家他们肯定不是_一个ORM（对象关系映射工具），他们的新标语将Prisma描述为“Node.js和TypeScript的下一代ORM”。 🤔

在过去的几年里，他们一直 [made a few pivots](https://twitter.com/nikolasburk/status/1384908920301490176)，并声称新的 ORM 标签主要是为了帮助开发人员了解 Prisma 解决的问题，即使它解决这些问题的方法与大多数 ORM 有着根本的不同。

以下是现在构成**Prisma Holy Trinity™的3个主要工具的简要介绍：**

*   **[Prisma Client](https://www.prisma.io/client)** — 适用于不同语言和数据库的 Node.js 和 TypeScript 的自动生成且类型安全的查询生成器
    
*   **[Prisma Migrate](https://www.prisma.io/migrate)** — 一种声明式数据建模工具，可自动为您生成完全可定制的数据库架构迁移，因此您不必手动编写 SQL
    
*   **[Prisma Studio](https://www.prisma.io/studio)** — 一个光滑的小用户界面，可让您查看和编辑您的数据
    

### 底线

Prisma 是那些有一半的有趣公司之一，_“我们是一个可爱且创新的开源项目”_，一半，

但是，嘿，它被 RedwoodJS、Blitz.js、KeystoneJS 等一些很棒的产品和框架所喜爱和使用。 如果 Prisma 可以帮助我们所有人花更少的时间撕毁我们的头发，那么它在我们心中永远值得一提。

RXJS 发布 V7.0
-------------------

![Mario](https://bytes.dev/images/content/mario.png)

不同类型的RXJ

**RxJS 是 _not_ 一个 JavaScript 处方，** 但对于顽固的粉丝来说，也许是这样？

这是我对数百人支付 300 美元以上观看 RxJS 7.0 在上周的 _RXJS Live!_ 虚拟会议上发布的唯一解释，而不是在 6 小时后在 YouTube 上免费观看完整的重播。

但是，嘿，如果 2021 年教会了我们一件事，那就是钱不是真的。 问问那个刚刚[banked half a mil](https://www.npr.org/2021/04/30/992383825/disaster-girl-the-stuff-of-memes-sells-for-nearly-500-000-as-nft)的房子里的女孩。

**快速审查：** RxJS 是一个用于 JavaScript 的响应式库，可用于前端和后端（使用 Node.js）。 它使用 Observables 来更轻松地编写异步或基于回调的代码，并且是管理应用中数据和事件的有用工具（即鼠标点击、用户输入等）。

RXJS 7.0 是该图书馆 3 年来的第一个主要版本，是在为期一年的测试期之后发布的。

**Lucky V7的新功能：**

*   **Better TypeScript Typeings** — RxJS 6 针对较旧版本的 TypeScript（这很烦人），但 RxJS 7 现在针对 TS 4.2，这为使用 `Subject next()`、`toPromise()` 和 其他
    
*   **新的和改进的方法和运算符** - 有很多这些（您可以查看 [here](https://rxjs.dev/deprecations/breaking-changes#operators)），但它们背后的首要目标是为 RxJS API 引入更好的可用性和一致性
    
*   **WAY Smarsm** — 即使使用所有新东西，V7 也比 V6 小了近 50%。 他们通过“缓慢而稳定的重构，并进行了数千次测试”，而不是一次大规模的重写或架构更改
    

### 底线

RxJS 仍然被许多人认为主要是一个 Angular 工具，但 TikTok 的 React Web 应用程序 [just saved 14.3KB](https://twitter.com/BenLesh/status/1388125014474567682) 通过升级到 RxJS 7，这样我们就可以让像 [this gem](https://www.tiktok.com/@kiki.tiel/video/6902455027269389570) 这样的视频比以往更快地加载。

也许 V7 会看到 RxJS 继续扩大其与其他框架的影响力。

常数数 = [2,4,6]
    
const reducer = (prev, current) => {

**答案：两次**

如果未提供初始值，则数组中的第一个元素将用作初始值，并且将跳过 reducer 函数的第一次调用。
