## Cool Bits

1. Jenna Smith 撰写了关于 [如何使用 React 编译器优化 React Context](https://jjenzz.com/making-react-context-cheap/) 的文章。谁正在为 React 编译器优化 gas 价格？

2. 由于 JavaScript 开发人员正忙于将所有内容重写为 Rust，Nicholas Nethercote 撰写了一篇关于 [如何加速 Rust 编译器](https://nnethercote.github.io/2026/09/30/how-to-speed-up-the-rust-compiler-in-september-2026.html) 的有用文章。

3. [移动开发的未来是代理的](https://try.expo.dev/4xTRl5Y)。并且它是建立在 Expo 之上的。多年来，移动开发的速度比 web 慢。现在，代理正在编写代码、测试它、修复它、通过 OTA 发布它，并监控它。所有这些都在 Expo 上。 \[sponsored]

4. Jared Palmer 创建了 [Kev](https://jaredpalmer.com/blog/introducing-kev)，一个受 `Jev` 启发的开源决策模型家族，你可以在本地运行它。

5. Rich Harris 和团队发布了 [SvelteKit 3.0](https://svelte.dev/blog/sveltekit-3-is-here)，Svelte 团队将其描述为具有“更多的精致，更多的类型安全性和更少的垃圾”。

6. Cassidy Williams 写了一篇关于 [代理如何可能无意中使网站更易访问](https://cassidoo.co/post/accessibility-and-the-internet/) 的文章。喜欢这种开心的意外。

7. 如果你一直在想软件工程是否已经死亡，你应该观看 Convex CEO Jaimie Turner 在 Abstract Conf 的主题演讲 [我们从未被付钱来编写代码](https://youtu.be/VeT54QhrmdM)。\[sponsored]

8. Alice Moore 宣称 [是时候停止安装代理技能](https://www.builder.io/blog/stop-installing-skills) 了。

9. 这是一个给书呆子的冷门话题，但 [Gleam 1.19 有一种新的生成 Erlang 代码的方法](https://gleam.run/news/gleam-doesnt-compile-to-erlang-source-anymore/)，它可以使针对 BEAM 的项目的构建速度大大加快。

10. [Greptile 是唯一一个实际运行你的代码的 AI 代码审查工具](https://www.greptile.com/?utm_source=bytes\&utm_medium=sponsorship\&utm_campaign=bytes_oct6)，而不是只是阅读它。这就是为什么它能够在 Netflix、Posthog、NVIDIA 等许多开源仓库中捕捉到真正的 bug。\[sponsored]

11. Matt Rothenberg 被一波怀旧情绪所席卷，重温了 Guillermo 11 年前的帖子，并写了 [Pure UI in the Agentic Era](https://mattrothenberg.com/notes/pure-ui-agentic-era/)。

12. Tanner 发布了 [TanStack Charts 1.0.0](https://tanstack.com/charts/latest)，现在已经稳定，并准备好帮助您在生产环境中进行一些数据可视化的“犯罪”。
