Astro 的发布周
--------------------

Astro 刚刚结束了他们的第一个“发布周”（明白吗？原因火箭？好吧），他们宣布发布“Astro V1 Beta”、“Ssr with Astro”、“Themes & Integrations”以及其他一些我们已经忘记的东西。

如果您错过了我们上次谈论 Astro 时，TLDR 是他们的任务是成为 [Jenny Craig of JavaScript](https://www.youtube.com/watch?v=PLxesVFWhCE)，并帮助您摆脱那些不需要的字节。

**“Astro V1 Beta”有什么作用？** 好吧，就像 Devrels 一样，我们仍然不完全确定。 但他们承诺不再发生重大变化（直到 V2）。 Astro 还推出了主题和集成（又名入门模板和插件），并为其某些依赖项的维护者宣布了财务支持。

然而，最大的公告是Astro现在对服务器端渲染有（实验性的）支持。 以前，Astro 仅支持 SSG（静态站点生成），因此必须在构建时或从这些“交互岛”之一上获取动态数据。 借助 SSR，Astro 现在可以让您在不牺牲性能的情况下构建更动态的网站。 此新产品还包括 API 路由（用于 REST API、用户上传、服务资产等）——类似于 Next 或 Remix。

**那么是什么让Astro与初学者不同？ 该团队还声称，与其他框架不同，Astro 是“设计用于在服务器上运行的”——这对我们来说是足够的证据。

**底线：** Astro 似乎非常适合您的个人博客、电子商务网站、文档和其他不需要太多客户端 JavaScript 的网站（他们认为这些网站是 _most_ 网站）的理想之选。 立即致电 1-800-94-Jenny，并开始丢失那些不需要的字节。

红木的发布周
----------------------

Redwood 不想感到被冷落，所以他们也只是有自己的发射周。 像 Astro 一样，这是可能是一封电子邮件（或博客文章）的发布周之一——但是，嘿，我们都必须找到庆祝的理由。

所有庆祝活动中传出的大新闻是，经过三年的工作，[RedwoodJS 1.0 was finally released](https://community.redwoodjs.com/t/redwood-1-0-is-now-available/2958)。

那么 RedwoodJS 到底是什么，它来自哪里，它的未来会怎样？ 让我们潜入。

*   Redwood 的宣传是它将 React、GraphQL、Prisma、Typescript、Jest 和 StoryBook 的“最佳部分”编织在一起，为您提供一个完整的堆栈框架，随时可以开箱即用。 抽象出大多数不同的技术堆栈选择会带来很多好处和很多权衡——有点像在 In-N-Out 而不是 Cheesecake 工厂吃饭。 两者都很棒，但非常不同。
    
*   Redwood 由 Tom Preston-Warner 创建，他也是 GitHub 的共同创始人，并创建了 Jekyll、Toml 和 Semver 规范。 Tom 看起来也有点像 _tom-from-myspace_，但我们的研究团队已经确认他们实际上是两个不同的人。
    
*   红木的未来看起来很有希望。 上周，Tom 还承诺 100 万美元为该项目提供资金，并投资 100 万美元用于投资建立在 Redwood 上的初创公司（#Launchweek 🚀）。 如果您想知道这些数百万来自哪里，让我提醒您 [this man co-founded GitHub.](https://www.celebritynetworth.com/richest-businessmen/ceos/tom-preston-werner-net-worth/)
    

**底线：** Redwood 专注于帮助想要尽快构建副项目和初创公司的开发人员，而不是痴迷于所有技术细节。 现在说，在不断变化的 JavaScript 框架层次中，Redwood 将把 Redwood 带走多远还为时过早——但至少我们知道它们可能不会很快用完钱。

🔬 发现错误解决方案 — 由 [PostHog](https://posthog.com/?utm_source=bytes&utm_medium=newsletter) 赞助
--------------------------------------------------- ---------------------------------------------------

从历史上看 - 在 JavaScript 中，因为我们缺乏拥有私有类字段的能力，我们会用下划线和希望最好的方式标记它们。 现在，感谢最近添加的 [Private Class features](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Classes/Private_class_fields)，我们现在可以使用 `#` 前缀将类字段标记为 `private`。

级车{
#milesdriven = 0
驱动器（距离）{
this.#milesdriven += 距离
}
GetMilesDrive() {
返回 this.#milesdriven
}
}

Tesla.getMilesDrive() // 10
