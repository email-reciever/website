## Cool Bits

1.  Fatih Arslan [wrote about how he manages his agents](https://arslan.io/2026/09/11/how-i-manage-my-agents/), a post you’ve read a million times, but this time from an engineer at Cursor who actually knows what he’s doing.
    
2.  It only took Shopify 12 weeks to [migrate the Shop app from React Native to Swift/Kotlin](https://shopify.engineering/shop-app-migration) leaving the React Native Stans in shambles.
    
3.  Only idiots write manual tests – modern engineering teams like Notion, Dropbox and LaunchDarkly use Meticulous to maintain e2e UI tests that [cover every edge case of your web app](https://www.meticulous.ai/?utm_source=bytes&utm_medium=newsletter&utm_campaign=26q3&utm_content=secondary). \[sponsored\]
    
4.  Vercel made [a cool website](https://vercel.com/labs) to showcase their R&D projects that their “Labs” team has been working on.
    
5.  Lovable used `oj` [to improve their preview sandbox cold starts](https://lovable.dev/blog/faster-previews-oj) from 4.9s with `vite` to 1.2s and reduced their memory usage by 84%.
    
6.  The engineers at Meta wrote [a post about ZGateway and proxying traffic to ZippyDB](https://engineering.fb.com/2026/09/03/core-infra/zgateway-proxy-zippydb-meta/). I’m pretty sure I saw a billboard for a cannabis store that was selling ZippyDBs. Coincidence?
    
7.  Convex created [an official set of plugins](https://github.com/get-convex/convex-agent-plugins) for AI agents that includes skills, custom agents, MCP integrations and more to help you [build better apps](https://www.convex.dev/ai). \[sponsored\]
    
8.  Laurie Voss [cracked the code for how to get everyone paid in open source](https://seldo.com/posts/nobody-pays-for-open-source-we-can-force-them-to/). Private registries with a hint of Marxism are VERY on brand.
    
9.  GitHub Actions added [cache-mode](https://github.blog/changelog/2026-09-10-control-github-actions-cache-access-with-cache-mode/) to save you from cache-poisoning.
    
10.  Dominic Gannaway [removed lazy destructuring from `tsrx`](https://tsrx.dev/blog/removing-lazy-destructuring) which means we’re only a few more cuts away from it going back to just being JSX.
