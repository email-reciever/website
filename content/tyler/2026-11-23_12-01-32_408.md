## Cool Bits

1.  Mise, the dev tool to manage your dev tools, can now [automatically keep everything in your environment up to date](https://mise.jdx.dev/dev-tools/#automatic-tool-updates) with its latest release.
    
2.  React Aria just released [a sheet component](https://react-aria.adobe.com/blog/sheet) that has gesture-synced animations, snap points, stacking, and a whole bunch of other sheet.
    
3.  [The future of mobile development is agentic](https://d2bn2k04.na1.hs-sales-engage.com/Ctc/L0+23284/d2BN2k04/Jks2-6qcW69sMD-6lZ3lHW6mx1nw63Sym_W7N_Jt850QlZkVVhHy91q5FYwW7qpkws72K_D3N7NrhRVHvC_HW4CpCZc1BVxDSW8r6xnG5wHq8SW3RqW8m5Zvxm7W97GXWJ3pLz86W98B2Lf3nqZ_BW8lZ73r6vsTHYW9knHzb8c4q2TW8Dc44G3cYb5vW7jSsQl4ky_4RW20rkWK7mfhC7W7f4_XD4scYDGW4M2h1Y502kJQW12XMbB6TJXhfW6yxVkz6tmwGNW2lBh1t9j7lgBf96948M04). And it’s built on Expo. For years, mobile shipped slower than the web. Now agents are writing code, testing it, fixing it, shipping it OTA, and then monitoring it. All on Expo. \[sponsored\]
    
4.  Simeon Griggs wrote [a great blog post on “leaky buckets”](https://planetscale.com/blog/leaky-buckets-in-software-explained), which surprisingly is about the intersection of software and water clocks and not how agents are bankrupting your company.
    
5.  The team at [Base UI released version 1.9.0](https://base-ui.com/react/overview/releases/v1-9-0), which fixes a bunch of things your agent would never notice but that your users will.
    
6.  Anomaly released [OpenCode 2.0](https://anoma.ly/notes/opencode-2-0/), a major overhaul with a new API and SDK, plus “Code Mode”, background tasks, and plugins.
    
7.  “What’s the best way to use the Sentry MCP, CLI, and Seer with my coding agent?” Paul Jaffre wrote [this detailed blog post](https://blog.sentry.io/seer-mcp-cli-or-coding-agent/?utm_source=bytes&utm_medium=paid-community&utm_campaign=seer-fy27q3-evergreen&utm_content=newsletter-secondary-seer-mcp-cli-blog-learnmore) to answer that question for good. \[sponsored\]
    
8.  [Meta released Muse Wonder](https://research.meta.ai/blog/muse-wonder), a frontier model ranked only behind Opus 5.5 on the TMBBs, with certain “dev influencers” saying it’s better than Sol 6.1. My only question is how do I also get paid to say nice things about the models?
    
9.  Richie McIlroy created [Tov, a TypeScript-shaped language built for coding agents](https://github.com/richiemcilroy/Tov) that compiles to native binaries that are faster than Rust (allegedly).
    
10.  [TanStack Start is finally stable](https://tanstack.com/blog/tanstack-start-1-0) with yesterday’s 1.0 release. Is now a bad time to admit I’ve been using it in production for over a year?
