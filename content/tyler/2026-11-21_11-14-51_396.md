“零配置”

### 这两个神奇的词

多年来，Storybook 已成为独立开发和测试 UI 组件的事实上的工具。 问题，就像我的骨关节炎奶奶为田径比赛热身一样，起床和跑步是一场噩梦。

也就是说，直到现在。

这是因为上周，Storybook 宣布了他们全新的 [Framework API](https://storybook.js.org/blog/framework-api/)，它为您最喜欢的框架带来了“零配置”支持……只要您最喜欢的框架是 Vite。 但不用担心，对 NextJS、Sveltekit、Remix 和 Nuxt 的支持也在筹备中。

以下是详细信息。

*   **零配置：** 英语中最美的两个词。 但除非您最喜欢的框架使用 Vite，否则您要么必须等待 StoryBook 构建它，要么现在就走 DIY 路线。 值得庆幸的是，这个新的 API 可以很容易地构建和维护您的框架自己的“零配置”解决方案。
    
*   **mocking:** 当您尝试隔离组件时，处理可能在您的应用程序中运行但在故事书中中断的数据提取或路由钩子之类的事情非常烦人。 这个新的 API 可以轻松模拟这些调用（甚至可以自动执行）。
    
*   **可扩展：**如果您是那种在他们可以自定义 `[insert random tool to fit your bizarrely specific use case]` 之前永远不会满足的人，您会很高兴知道 Storybook V7 可扩展为 Nerds 高级用户。
    

**底线：** 除了使 Storybook 更易于使用之外，看看这个新的框架 API 如何优先支持 Vite 支持，这很有趣。 这说明了 Vite 疯狂的快速增长，让我们想知道它是否最终会成为 NEXT 最强大（也可能是最意想不到的）竞争对手。

发现错误：解决方案
-----------------------

#### 赞助[The Developer Nation Survey](https://developereconomics.net/?member_id=bytes&utm_medium=nl_pr1)

函数 getEvenNumbers(numbers) {
让偶数数 = [];
    
for (let i = 0; i < numbers.length; i++) {
if (numbers[i] % 2 === 1) {
evennumbers.push(数字[i]);
}
}
    
返回偶数；
}
    
GetEvenNumbers([1,2,3,4,5,6])
    

我们的逻辑有点偏离。 `n % 2` 将返回 `0` 如果 `n` 是偶数。 错误是我们的代码检查它是否返回`1`（这将是一个奇数）。

要解决此问题，我们可以更改该行以查看它是否计算为 `0` 而不是 `1`。

函数 getEvenNumbers(numbers) {
让偶数数 = [];
    
for (let i = 0; i < numbers.length; i++) {
if (numbers[i] % 2 === 0) {
evennumbers.push(数字[i]);
}
}
    
返回偶数；
}
    
GetEvenNumbers([1,2,3,4,5,6])
