## Pop Quiz: Answer

#### Sponsored by [Retool’s livestream](https://click.convertkit-mail4.com/4zum43m267behppnqzvuqu6g9z777s5/g3hnhwu3vqwegqbr/aHR0cHM6Ly9ldmVudHMucmV0b29sLmNvbS9haS1tb2RlbHM_dXRtX2NhbXBhaWduPWJ5dGVfZGV2JnV0bV9tZWRpdW09bmV3c2xldHRlciZ1dG1fc291cmNlPWJ5dGVfZGV2)

What will be logged to the console when this code executes?

```js
window.name = "Mike Tyson";

const me = {
  name: "Tyler",
  sayName() {
    console.log(this.name);
  },
};

const sayName = me.sayName;
sayName();
```

The answer? “Mike Tyson”.

Since we’re not in strict mode, `sayName` isn’t a method, and we’re not using `call` or `apply`, `this` inside of `sayName` will default to the `window` object.
