Chrome 醒来并选择了暴力

Chrome 打破了网络
----------------------

还记得上周我们写的关于新 IE 的 Safari 的文章吗？ 好吧，Chrome 一定看到了这一点，因为他们决定为事情增添趣味并……打破网络。

**我们是如何到达这里的：** 当圣蒂姆·伯纳斯-李在 1989 年带着万维网从山上下来时，它带有对浏览器供应商的单一说明：

> 你不应该打破网络~ — 蒂姆，可能

从那时起，每个创建浏览器的人（主要）都遵守了这条诫命。 在网络发明后的32年里，只有[10 breaking changes](https://styfle.dev/projects/breaking-changes-web)（RIP Flash😢）。 记录不佳。

这是因为浏览器供应商和标准机构向后弯腰，以防止网络浏览器的新变化发生破坏。 （有人记得 [#SmooshGate](https://developers.google.com/web/updates/2018/03/smooshgate) 吗？）这就是我们的一些长期 [favorite websites](https://old.homestarrunner.com/sbsite/) 能够在几十年后继续前进的方式。

这将我们带到了**上周的戏剧：**

最新版本的 Google Chrome [disables](https://www.chromestatus.com/feature/5148698084376576) `alert()`、`prompt()` 和 `confirm()` JavaScript API 用于跨域 iframes。 其目的是 [stop bad websites](https://twitter.com/estark37/status/1422694845076762629) 使用可怕的警报消息来欺骗您的祖母安装间谍软件。 他们在没有真正告诉任何人的情况下做到了。

您可能会想“没关系，谁使用跨源 `alert`s/`prompt`s/`comfirm`s？” 事实证明，不少人：

*   [Chris Coyier uses them](https://twitter.com/chriscoyier/status/1420027533005836298) 用于 CodePen。
*   [Dan Abramov uses them](https://twitter.com/dan_abramov/status/1422579810077904900) 教人们 React。
*   [Matt Karl uses them](https://twitter.com/bigtimebuddy/status/1422953235111825416) 支付他的账单。

更疯狂的是，这甚至不是关于“跨源”。 Chrome 的长期目标是 [“eventually deprecating and removing them from the platform”](https://twitter.com/Rich_Harris/status/1423631525564887040) 在一起。 #useThePlatform 人群的另一个 L。

**底线：** Chrome 已经回溯并重新启用了这些功能（暂时），但每个人都想到的是——接下来会发生什么？ Chrome 将如何在不破坏当前网络的情况下平衡构建更好的网络？ 我们没有答案，但请务必从 [LingsCars.com](https://www.lingscars.com/) 租用一辆车。

谁会登上领奖台的顶部？

来自框架奥运会的报道
-----------------------------------

**Stack Overflow 的 2021** [Developer Survey](https://insights.stackoverflow.com/survey/2021) 上周问世，JavaScript 框架奥运会的仪式火炬被点燃（至少在我们心中）。

*   在“最流行的Web框架”类别中，React 击败了 jQuery (LOL) 获得了第一名，这连续三年结束了 jQuery 的优势。 值得称赞的是，jQuery 反弹并在“最可怕的_ Web 框架”类别中获得第三名，因为没有糟糕的宣传（我认为）。
    
*   Vue 也度过了重要的一周。 维基百科选择它而不是 React 作为维基媒体基金会的 [official JavaScript framework](https://lists.wikimedia.org/hyperkitty/list/wikitech-l@lists.wikimedia.org/thread/SOZREBYR36PUNFZXMIUBVAIOQI4N7PDU/)。 这绝对是为了客观、有原则地看待框架的利弊，而不是因为他们的主要开发人员有一个 Angular.js 迷恋 [😮‍💨](https://bytes.dev/images/content/hellyes.gif)。
    
*   最后，我们有“上周最热门的框架”——React 和 Vue 陷入了一场时代的战斗。 由于维基百科的公告和围绕 Vue 3 即将推出的一些很酷的 [new features](https://github.com/vuejs/vue-next/blob/master/CHANGELOG.md) 的炒作，Vue 开始领先。但最终，由于无休止的猜测和 [experimentation](https://swizec.com/blog/react-18-and-the-future-of-async-data/) 具有悬念和并发性等新的 React 18 功能，React 赢得了金牌。
    

**底线：** 框架奥运会与真正的奥运会几乎相同，只是运动能力少得多，民族主义也少了很多。 2024年见。
