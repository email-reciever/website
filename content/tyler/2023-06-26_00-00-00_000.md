Svelte 3 ➡️ Svelte 4：相同，但不同。

### 欢迎来到Svelte 4发射派对

在让我们等待上次大版本发布后 1,522 天后，您可能会认为 Svelte 团队为上周的 [Svelte 4](https://svelte.dev/blog/svelte-4) 公告计划了一些重大的计划，对吧？

错了。

好吧，这并不完全公平。 这个“维护版本”可能不会包含新功能，但 V4 的主要目的是“为下一代 Svelte 发布 Svelte 5 奠定基础。” 此外，Svelte 团队一直在优先考虑 Sveltekit 元框架的工作，该元框架最近发布了 v1.0。

但既然 Vercel 正在赞助 Svelte 团队，Guillermo & Co. 就不能为 Svelties 举办某种发射庆祝活动吗？ 也许是一个以苗条为主题的无人机表演，或者是一盘巨大的椰子虾，呈丰富的哈里斯头部形状？ 让 Vercel 员工在没有收到 HR 的正式警告的情况下发疯并穿多色 T 恤怎么样？

好吧，这似乎没有发生任何事情，所以考虑一下这个_官方非官方的Svelte 4 Launch Party™️。

我们将帮助您以我们知道的唯一方式来庆祝这个场合——通过诅咒的表情包、讽刺的笑话和快速的摘要，帮助您比同事更聪明、更好。

说到这里，我们来讨论一下Svelte 4中的实际内容：

*   **Perf 改进** — 此版本将 Svelte 的封装尺寸缩小了 75% 🤯。 它们还将依赖项的数量从 61 个减少到 16 个，以实现更快的下载和更好的安全性。
    
*   **DX 改进** — svelties 是 [very excited](https://twitter.com/htmleverything/status/1671889888894148610) 关于 [IDE authoring experience](https://github.com/sveltejs/svelte/pull/8702) 的一些具体改进。 他们还引入了一些更一般的更改，以使 Svelte 整体感觉更轻松、更直观。
    
*   **文档改进** — 您可以看出团队已经投入了大量时间来重做官方网站和检修 TypeScript Svelte 文档。 尝试 Svelte 从未如此简单。
    

**Svelte 从这里去哪里？** Svelte 5，显然。 这应该是一件大事，团队承诺对 Svelte 编译器和运行时进行全面重写。 希望我们能在 2027 年之前看到它！

**底线：** 直到现在，Svelte 一直是 JS 生态系统中的经典之作——它一直拥有一群强大的铁杆粉丝，它受到普遍的喜爱和尊重，它帮助激发了许多下一代的极简主义者 近年来出现的框架。

但是，Svelte 是否能够跨越鸿沟并开始从更“主流”的框架中获得真正的市场份额，如 React（又名 JavaScript 的 MCU）？ 在接下来的几个月和几年里，我们将开始找出答案。 继续关注。

发现错误：解决方案
-----------------------

#### 赞助[PropelAuth](https://www.propelauth.com/?utm_source=bytes&utm_campaign=q223&utm_medium=jun26)

常量汽车 = {
名称：'特斯拉'，
StartEngine() {
控制台.log(`The ${this.name} engine is starting...`);
},
延迟启动（）{
setTimeout(this.startEngine, 1000);
}
};
    
car.delayedStart();
    

该错误与我们对 `startEngine` 的调用有关。 因为我们将 `this.startEngine` 作为参数传递给 `setTimeout`，所以我们不是调用它的人。 这意味着它不会被正确的上下文（`this`）调用。 我们可以通过两种方式解决这个问题——使用 `.bind` (🙃) 或像这样调用函数。

常量汽车 = {
名称：'特斯拉'，
StartEngine() {
控制台.log(`The ${this.name} engine is starting...`);
},
延迟启动（）{
setTimeout(() => this.startEngine(), 1000);
}
};
    

如果您想要更长的解释，我们将其分解为 [Understanding the “this” keyword, call, apply, and bind in JavaScript](https://ui.dev/this-keyword-call-apply-bind-javascript)。
