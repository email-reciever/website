### 邦的大月份

我最喜欢的节日传统是我身体允许的尽可能多的烘焙食品。 值得庆幸的是，Jared Sumner 和 Bun 团队最近一直在为我们提供帮助，而不是在 12 月为我们喂食，而是在 12 月（[v0.3](https://bun.sh/blog/bun-v0.3.0) 和 [v0.4](https://bun.sh/blog/bun-v0.4.0)）单独发布了两个单独的包子。

由于我的饮食要到星期一才开始，让我们继续这个麸质派对，深入了解这些面包更新中的一些最热门的新功能。

*   **与 Node API 的兼容性更好：** 您现在可以在 BUN 中使用一堆 Node API，包括 `node:child_process`、`process.stdout`、`node:util/types` 等。
    
*   **`bunx`:** 这个 BUN 等价于 `npx` 的本地或远程 npm 软件包运行可执行文件，而不是 `npx`。 我很确定每个 Bun 发布都必须包含一个声称比另一个构建工具快 100 倍的功能。
    
*   ** 更好的稳定性：** BUN 现在通过与事件循环协调安排垃圾收集使用 3-5 倍的内存减少。 他们还为 `console.log()` 提供了一些新的错误修复和格式改进，以使调试更容易。
    
*   **新的和改进的BUN API：** `FileSystemRouter`为您提供了一个类似于下一步的文件系统路由器来解析文件，`bun:ffi`现在支持从本机代码到 JavaScript 的线程安全回调，`bun:test` 有一堆新的测试功能（其中一些显然是 [100x faster](https://twitter.com/jarredsumner/status/1595681235606585346) 比开玩笑）。
    

**BOTTOM LINE:** BUN 专注于构建与 Node 和 Web API 的兼容性，以便开发人员可以使用 npm 包、web API、bun-specific API 和 JavaScript API，而不必担心他们的运行时是否支持它。

但随着 Node 和 Deno 朝着类似的方向发展，很明显，如果 Bun 想要成为一款真正的 Runtime™，它将会有一些激烈的竞争。

![Express, Mocha, Canvas, and Commander](https://bytes.dev/images/content/tj-trends.jpg)

TJ Holowaychuk 最受欢迎的库 – [npmtrends.com](https://npmtrends.com/canvas-vs-commander-vs-express-vs-mocha) 的数据

由于我们今天谈了很多关于运行时的问题，让我们向节点生态系统的教父 TJ Holowaychuk 致敬。 TJ 有点像 `node_modules` 的尼克经典——没有人知道他负责创建多少儿童包，但这绝对是一个很大的数字（[~500](https://www.npmjs.com/~tjholowaychuk)）。

让我们来看看他的一些最伟大的热门歌曲：

**express:** 你知道它，你喜欢它，它自 2010 年以来一直是 Node 的顶级 HTTP 服务器（尽管 npm 的 stats api 有一个错误，所以我们看不到这些下载）。 令人惊讶的是，它仍在增长，每周下载 2800 万次。

**Mocha:** 多年来，Mocha 是 Node 中最受欢迎的测试框架，尽管它最近被 Jest 传递了。 也就是说，它仍然每周下载超过 700 万次。

**Canvas:** 虽然不像 Express 或 Mocha 那样广泛使用，但 `node-canvas` 仍然将 HTML 5 Canvas API 带到 Node，为我们提供了服务器生成的图形。

**指挥官：** 最热门的可能是指挥官，每周下载量超过 1 亿次。 显然，其中很大一部分不是最终用户直接使用的，但它显示了它在 JavaScript 堆栈中的基础。

**要点：** 是否有 10 倍开发人员之类的东西？ 我们会让 Twitter 和 Hacker News 争论这一点。 但 TJ 证明我们肯定至少有 500X 节点开发人员的案例。
