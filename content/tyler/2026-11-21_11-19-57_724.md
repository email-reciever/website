介绍 Remix v1.0
-----------------------

如果您在过去 3 个月内打开了 Twitter，您可能已经 [heard of Remix](https://twitter.com/search?q=from%3A%40kentcdodds%20remix&src=typed_query&f=top)。 这是一种全新的 React 框架，没有人使用，因为它要花钱，但现在它是免费的，所以这很酷。 他们最近筹集了一些 VC 现金，聘请了 Kent Dodds（作为创始人），今天——他们已经发布了 v1.0。

现在我知道你在想什么——如果你取出 C_，_Kent 的名字看起来很有趣。 哦，除了炒作，_wtf 实际上是混音？_

Remix 是 [three things](https://twitter.com/ryanflorence/status/1459318249825320961) – “一个编译器，一个 React 元框架，一个可以部署到任何地方的通用 Web 框架，甚至可以部署到 Cloudflare 等工作环境”。

这里还有一些让它变得酷的东西-

*   **仅服务器端渲染** — 没有适合您的静态站点，但由于边缘计算，它可能是 [even faster](https://twitter.com/remix_run/status/1460698948339859463) 而不是静态的，Theoret[i](https://giphy.com/explore/i-dont-believe-you)cally。
    
*   **Platform-Annostic Deployment** - 这样您就可以在任何地方部署您的应用。 Remix 支持常规的 Node.js 服务器、无服务器函数、Cloudflare 工作人员以及最终的浏览器 ServiceWorkers。
    
*   **通过内置浏览器功能进行渐进式增强**。 即使 JavaScript 尚未加载，您也可以利用 `<form>` 等功能来保持交互性。 #usetheplatformlol
    
*   **每页样式**通过 _actual `<link>` 标签_（下一步是什么？使用 [tables for layout?](http://shouldiusetablesforlayout.com)）。 您告诉它需要在页面上加载什么 CSS，并在用户导航时将文件交换出来，避免选择器冲突。
    

[translations](https://www.npmjs.com/package/remix-i18next)、[authentication](https://www.npmjs.com/package/remix-auth)和[a bunch of other things](https://www.npmjs.com/package/remix-utils)的软件包生态系统也在不断增长。

> 网络基础设施与 SSG 与 Cloudflare Workers、Deno Deploy、Fly.io 等边缘计算一样快。您可以使您的服务器快速，但您无法控制用户的网络！ Remix 专为 Edge 设计，通过网络发送更少的快速、清新、现代的 UX，无需 Spinner 的 Spinner Jank 和 SPA 的复杂性。 ——瑞恩·弗洛伦斯。 Remix 的联合创始人

**底线**：时间会告诉 Remix 是否成为“构建任何 Web 应用程序的最佳方式”，但它肯定会推动最先进的技术发展。 我个人期待观看 Remix 和 Next.js 直接为用户竞争，同时假装他们 [not at all](https://twitter.com/mjackson/status/1459656714362310658) 相互竞争。

Cloudflare全栈周的亮点
------------------------------------------

在我的家庭中，_full stack week_ 指的是我妈妈出城的时候，我爸爸花了 4 个小时制作一大堆煎饼来喂我和我的兄弟姐妹在接下来的 6 天里。 （妈妈确实回来了……最终。）

Cloudflare 的整个堆栈周也像这样_ ——除了煎饼，大约有 612 个新版本和公告。 我们将在这里分解一些最有趣的，让您自己检查 [the rest](https://www.cloudflare.com/full-stack-week/)。

[Full Stack Cloudflare Pages](https://blog.cloudflare.com/cloudflare-pages-goes-full-stack/) 现在是一件事。 它基本上是 CF Workers + Pages，这意味着您可以通过一个提交来部署整个应用程序。 这也意味着 CF 页面现在几乎可以完成 Netlify 可以做的所有事情。

[Wrangler 2.0](https://blog.cloudflare.com/wrangler-v2-beta/) 是 Cloudflare 的牧马人 CLI 的新版本（与 Brett Favre 广告无关的爸爸牛仔裤）。 此版本使 CF 工作人员（仅使用单个 JavaScript 文件）更容易上手，更容易进行实时调试，也更容易切换到本地模式。

[Socket Workers](https://blog.cloudflare.com/introducing-socket-workers/) 可以使用非 HTTP 套接字连接到 CF 工作器和持久对象（TCP、UDP、QUIC 等）。 这里的大新闻是，Cloudflare 标准化了一个套接字原语，可以在不同的 JavaScript 运行时无缝运行——包括浏览器、节点、Deno 以及 Ryan Dahl 的大脑可以梦想的任何其他字谜。

[Services](https://blog.cloudflare.com/introducing-worker-services/) 已将脚本替换为用于在 CF 工作人员上部署应用程序的“构建块”。 它们是可组合的（因此它们可以相互交谈），并且能够支持多种环境——因此您可以在预览环境中进行测试，然后轻松推广到生产中。
