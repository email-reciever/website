### Angular和Vue的秘密爱子

_**编辑说明：**我们已经忙着打破我们的新年决心，所以我们向我们的好朋友 [David East](https://twitter.com/_davideast) 寻求有关这个故事的帮助。 他是谷歌的 idx.dev 的主要开发者和 Firebase Lifer_

自从我们在 10 月份首次写到它们以来，[Analog.js](https://analogjs.org/) 的事情变得更加有趣。 这是因为新兴的Angular MetaFramework正在为名为`.ng`的Angular开发新的单文件组件格式。

您可能知道，SFC 是一种特殊的文件格式，一直是 Vue 的一个定义特性，允许您将组件的模板、逻辑和样式封装在单个文件中。

**那么为什么要把它带到Angular呢？**因为Analog.js团队的[Brandon Roberts](https://twitter.com/brandontroberts)和[Chau Tran](https://twitter.com/Nartc1410)认为SFC格式将与Angular在去年添加的_Many_新功能非常吻合，包括简化状态管理的信号，新的控制流语法，生命周期 用于安全 DOM 操作的循环挂钩、改进的 SSR 系统等。

让我们通过查看一些基本语法来深入了解：

    <script lang="ts">
从“@angular/core”导入{注入，信号}；
    
定义元数据（{
选择器：“应用根”
});
    
常量计数器 = 信号（1）；
常量增量 = () => 计数器.update((值) => 值 + 1);
    </script>
    <template>
<div>计数：{{ counter() }}</div>
<button (click)="increment()">增量</button>
    </template>
    <style>
div { 颜色：#f00; }
    </style>
    

每个文件可以包含三个部分：`<script>`、`<template>` 和 `<style>`。

`defineMetadata({ })` 函数的工作方式很像传统的 `@Component()` 装饰器添加在角组件类之上。 它可以定义选择器名称、指令和管道导入，以及组件需要的其他有用的元数据。

使用 `.ng` 导入组件的方式变得更加有趣。 传统上使用 Angular，您必须在 `imports` 数组中指定组件。

从 './bytes-article.component' 导入 { bytesarticle };
    
@组件（{
独立：真实，
选择器：'bytes-issue-list'，
// 告诉组件可以在模板中使用什么
导入：[bytesarticle]，
模板：`
        <bytes-article></bytes-article>
`，
})
导出类 ByteSissueList {
    
}
    

这最终是一个三步过程：导入、数组条目，然后是标签。 但是，使用 `.ng` 更像您对 Vue 或 _(gasp)_ 反应的期望。 您导入组件，它就可以在模板中使用了。

    <script lang="ts">
从 './bytes-article.component.ng' 导入 BytesArticle
    
定义元数据（{
选择器：'字节-issue-list'
});
    </script>
    <template>
      <BytesArticle />
    </template>
    

**它是如何工作的：** 模拟寄存器一个 `vite` 插件来定位模板部分（`<script>`、`<template>` 和 `<style>`），并在幕后创建一个基于类的 Angular 组件。 Angular-the-Framework 对这种 `.ng` 格式没有任何明智之处，并且一直像往常一样继续前进。

重要的是，`.ng` 格式允许 Angular 在 2023 年添加的所有新功能大放异彩。 `inject()` 函数（在 2023 之前添加）提供了在构造函数之外的依赖注入，信号提供了 RXJS 或类方法之外的可观察性，并且与基于指令的结构流语法相比，新的控制流语法更清晰。

**底线：** 单个文件组件是一个（实验性）Analog.js 功能，而不是官方的 Angular 功能。 但它确实看起来像是 Angular 生态系统正在进行的发光的另一个有希望的发展。

如果您想亲自尝试 Vue-angular lovechild，可以查看 [sample repo](https://github.com/brandonroberts/analog-ng)。
