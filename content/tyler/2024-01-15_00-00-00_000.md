我在想 Vue 2 是如何在 7 年前推出的

### 为 Vue 2 倒出一张

12 月 31 日，Evan You [took Vue 2 away](https://blog.vuejs.org/posts/vue-2-eol) 把它送到那个特殊的农场，和我儿时的金鱼、我侄子的宠物豚鼠和 Angular.js 一起生活。

这并不令人意外——Vue 团队在过去 18 个月里一直在警告我们所有人 Vue 2 将在 2023 年除夕到临终。这是一个明智的举动，允许 Vue 团队将所有精力集中在 Vue 3 上，但 看到一个时代的结束仍然很痛苦😢。

在 2016 年 10 月推出的 Vue 2 之前，Vue 是一个快速增长但仍然很小的框架，每周的 NPM 下载量低于 45,000 次。

Vue 2 发布后的第二年，这个数字在 2020 年 9 月推出时增加了近 5 倍到 21.8k 的每周下载量，并且在 Vue 3 上发布时高达 1.9 百万周（比本周增加了 42 倍） Vue 2 推出）。

正是在 Vue 的 2 年中，开发人员才真正开始爱上该框架的渐进式、逐步采用的构建 UI 的方法。 这在很大程度上要归功于 Vue 2.0 引入的虚拟 DOM、模板语法、反应性等。 Vue 2 还使较大的 Vue 生态系统能够使用 Vuex 和 Nuxt.js 等库支持更复杂的 Vue 项目。

在许多方面，Vue 2 有点像 Blink 182 的 _Enema 专辑——一个标志性的版本，它帮助将独立框架推向主流，同时孕育了许多相似的东西。

**底线：** 现在 Vue 团队显然会得到很好的控制，因为 Vue 团队可以将所有注意力都投入到 Vue 3 上。但是您无法完全了解情况，而不欣赏他们的去向。

享受农场，伙计。

很酷的位
----------

1.  Josh Goldberg 写了一篇关于如何 [The speed gains from Rust linters aren’t comparable to the full feature set of typescript-eslint](https://www.joshuakgoldberg.com/blog/rust-based-javascript-linters-fast-but-no-typed-linting-right-now/) 的细致入微的文章。 事实证明，Rust linters 仍然很棒而且非常快，但确实在类型安全性方面进行了一些权衡。
    
2.  [Basedash](https://www.basedash.com/?ref=bytes) 使用 AI 免费为您构建完整的管理面板。 只需连接您的数据库，您将立即获得一套漂亮的可定制内部工具，如仪表板、图表和多人游戏数据编辑器。 这很狂野。 \[赞助\]
    
3.  [typed-route-handler](https://github.com/venables/typed-route-handler) 为 Next.js 提供类型安全的 API 路由处理程序。
    
4.  Matt Henderson 从 Sentry 网站上写了关于 [What happened when his team removed advertising cookies](https://blog.sentry.io/we-removed-advertising-cookies-heres-what-happened/) 的文章。 也许如果我们每个人都将其发送给我们各自公司的营销团队，我们将能够共同逃避当前网络的 Cookie 横幅地狱景观。
    
5.  Philipp Burckhardt 写了这篇文章 [2023 retrospective on the npm ecosystem](https://socket.dev/blog/2023-npm-retrospective)。 这是最好的时代，是[blursed](https://www.youtube.com/watch?v=no_elVGGgW8)的时代。
    
6.  如果第一个很酷的位没有说服你，Rust 是一文不值的，Joshua Mo 写了一篇关于 [Getting Started with Axum, Rust’s most popular web framework](https://www.shuttle.rs/blog/2023/12/06/using-axum-rust) 的文章。
    
7.  Codepen 发布了他们的 [Top 100 pens of 2024](https://codepen.io/2023/popular/pens/10)。
    
8.  SNYK 正在托管一个免费的 [Ethical Hacking 101 Workshop](https://go.snyk.io/202402-ethical-hacking-101-workshop.html?utm_campaign=dm_pp-bytes-advertiser_240115_wbn_240208_eh-101&utm_medium=email-paid&utm_source=bytes-advertiser&utm_content=wbn_240208_eh-101)，以帮助您在攻击者之前学习如何识别系统中的安全弱点。 当您学习实时查找和修复漏洞时，您将在动手实验室获得实时支持。 \[赞助\]
    
9.  [remote-storage](https://github.com/FrigadeHQ/remote-storage) 将 LocalStorage API 与远程服务器相结合，以跨浏览器和设备保存数据。
    
10.  [Sutra.js](https://github.com/yantra-core/Sutra.js) 是一个新的 JavaScript 行为树库，用于轻松创建和管理复杂的行为模式。 将其与 Karma.js 和去年的 Kenny G 专辑 _innocence_ 相结合，您将拥有一个辛辣的情人节。
