### 摩尔定律是一种社会建构

上周，当戈登·摩尔在 94 岁去世时，我们失去了一个计算传奇。你可能因为摩尔定律而认出这个名字，它指出集成电路上的晶体管数量将每两年翻一番。

但摩尔定律根本不是科学的“定律”。 它不是基于物理或化学的——它是基于一个人在随机杂志文章中的预测（就像所有伟大的预测一样）来自一个小样本量和一些快速的餐巾纸数学。 那么为什么它改变了世界呢？

**做出预测：** 早在 1965 年，在联合创立英特尔之前，Gordon Moore 是 Fairchild Semiconductor 的研发总监。 _Electronics_ 杂志正在庆祝成立 35 周年，因此他们要求 Gordon 写一篇关于半导体未来的贡献故事。

Gordon 的文章被称为 [Cramming more components onto integrated circuits](https://web.archive.org/web/20190327213847/https://newsroom.intel.com/wp-content/uploads/sites/11/2018/05/moores-law-electronics.pdf)，它基本上是内容营销来炒作 Fairchild 集成电路的未来（当时卖得不好）。

文章指出，将 50 个组件（或晶体管）安装到一个集成电路上花了大约五年时间，而且它们每年每个 IC 的晶体管数量增加了一倍。 摩尔只是预测，这一翻倍将继续，到1975年每个IC达到65,000个晶体管。

我们在 60 年代没有 Twitter，所以我不确定他在这次拍摄中得到了多少反击——但在 2015 年，甚至摩尔都说这是他当时的一次非常“疯狂的推断”。

**一个自我实现的预言：** Gordon 可能是从臀部射击，但结果证明他是正确的。 1975 年的数字是正确的，人们第一次开始提到摩尔定律。 摩尔将他的预测修改为“大约每两年”将晶体管翻倍。

在这一点上，科技行业开始从摩尔定律作为常数倒退。 人们认为半导体公司有可能（也许是不可避免的）每两年将每个 IC 的晶体管数量翻一番。

由于没有半导体公司不想被抛在后面，他们利用摩尔定律来指导数十亿美元的研发投资在各种生产技术上——这使得摩尔定律在过去 50 年中始终如一地实现。

**底线：** 摩尔最初的预测永远改变了计算世界——不是因为它本质上是正确的，而是因为它让足够的人相信它是正确的（或至少可能）。 事实证明，这就足够了。

发现错误：解决方案
-----------------------

#### 赞助[Interview Kickstart](https://learn.interviewkickstart.com/?utm_source=bytesdev&utm_campaign=bytesdev_presenting_spotthebug)

这一款是给初学者的。

函数 safeUpdate(obj, key, value) {
if (!obj.hasownProperty(key)) {
obj.key = 价值；
}
}
    

我们的错误是我们正在为我们的对象添加一个文字 `key` 属性。

console.log(user.key) // “美国”
    

在 JavaScript 中，如果要将变量用作对象的键，则需要使用括号表示法而不是点符号。

函数 safeUpdate(obj, key, value) {
if (!obj.hasownProperty(key)) {
obj[key] = 值；
}
}
