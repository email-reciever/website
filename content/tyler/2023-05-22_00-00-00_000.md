### Cloudflare 开发者周现场笔记

对于某些人来说，Cloudflare 的年度开发者周是一种精神体验。

我不是那些人中的一员——但上周我仍然爬到 Cloudflare Mountain 山顶，与信徒们聚会，接收所有新的 CF 发布和公告。

整个星期仍然是模糊的（我的衣服仍然闻起来像死藤水），但这里有亮点：

[Database Integrations](https://blog.cloudflare.com/announcing-database-integrations/) 现在，使用新的“集成”选项卡将 Cloudflare 工作人员（又名无服务器功能）连接到您选择的数据库变得非常容易。 它目前支持 Neon、PlanetScale 和 Supabase，但它们正在为其他人建立支持，以及一个允许任何人添加自己的数据库的集成平台。

[LangChainJS now supports CF Workers](https://blog.cloudflare.com/langchain-and-cloudflare/)。 未来我们可能会写一个关于 LangChain 的完整故事，但要知道它是一个框架，可以帮助您构建复杂的大型语言模型应用程序，可以在多个 LLM 和链式提示之间进行切换。 现在您可以在 CF 工作人员上构建这些应用程序。

Cloudflare 还发布了他们自己的 AI 产品 [Constellation](https://blog.cloudflare.com/introducing-constellation/)——它允许您在 CF 网络上运行预训练的机器学习模型和推理任务。 这应该使安全地构建和部署用于情感分析、文本到语音、图像分类等的 AI 应用程序变得更加容易。

值得庆幸的是，Cloudflare 还通过 V3 版本的 Wrangler CLI 制作了 [big improvements to the local dev experience](https://blog.cloudflare.com/wrangler3/)。 这是第一个具有“本地默认”开发的 Wrangler 版本，这要归功于将 CF 的全局部模拟器直接集成到 Wrangler 中。

**底线：** Cloudflare Smartly 似乎专注于向 AI 黄金矿工出售镐和铲子（加上我们其他人仍在构建无聊的网络应用程序）。 但我不禁想知道——Vercel 会通过在这些东西上放置一个漂亮的包装来赚多少钱？

### [Appwrite Cloud](https://appwrite.io/cloud?utm_source=newsletter_ui.dev&utm_medium=email&utm_campaign=cloud_private_beta) 终于登陆公测

它看起来像是心爱的开源后端服务器（31k github stars 😱）的游戏转换器。

**快速审查：** AppWrite 很棒，因为它抽象出了使用一组简单的 REST API 构建后端的最糟糕的部分。

但它总是要求你自我托管——直到现在。 开发人员正在疯狂地争取获得 AppWrite Cloud 的私人测试邀请，但它最终刚刚上市。 让我们放大：

*   **完全管理的后端基础设施** – 不再担心机器配置、安全性、维护等。
    
*   **自动缩放** – 因此您的应用程序可以轻松处理流量峰值而不会降低性能。
    
*   **内置安全性** – 高级安全功能，如 DDoS 保护、WAF 规则以及更多标准。
    

[Check out the public beta](https://appwrite.io/cloud?utm_source=newsletter_ui.dev&utm_medium=email&utm_campaign=cloud_private_beta) 以获得早期访问。 不需要邀请🙏。

#### 赞助[Snyk](https://snyk.io/blog/dependency-injection-in-javascript?utm_campaign=aom_2023&utm_medium=paid-email&utm_source=bytes-advertiser&utm_content=dependency-injection-in-javascript)

我们可以使用“事件委托”向父元素（`ul`）添加一个事件监听器，并检查事件目标是否是列表项，而不是将事件侦听器添加到 _each_ 列表元素。 这有几个优点：

_memory 效率：_ 事件委托通过减少事件侦听器的数量来节省内存，因为一个父监听器替换了多个子监听器。

_handling 动态元素：_ 事件委派顺利管理添加或删除的元素，因为父监听器保持一致，无需重新绑定。

    <ul>
<li>项目 1</li>
<li>项目 2</li>
<li>项目 3</li>
<li>项目 4</li>
<!-- ...这是一个非常长的清单-->
    </ul>
    
    <script>
让 ul = document.QuerySelector('ul');
ul.addEventListener('点击'，(事件) => {
if(event.target.tagname === 'li') {
Event.Target.Style.BackgroundColor = 'Lightblue';
}
});
    </script>
