### TanStack 查询点击 V5

上一次我们在 2022 年 8 月写到 React 最流行的数据提取库时，它刚刚推出了 V4，将其名称从 React Query 更改为 _TanStack Query_，并决定开始支持其他 JS 框架。

快进 15 个月，TQ 的工作人员已经走了很长一段路：TanStack 的 React 查询版本每周下载量超过 2 倍，达到 350 万左右，他们推出了适用于 Vue、Svelte 和 Solid.js 的适配器，他们刚刚发布了 [TanStack v5](https://tanstack.com/blog/announcing-tanstack-query-v5) 星期二。

该团队对 V5 的主要重点是使 TanStack 查询“更小、更好、更直观”，他们似乎检查了所有这些框。

V5 比 V4 小 20%，一些关键的更改和新功能有助于它实现“更好、更直观”的承诺：

*   他们从代码库中移除了重载，统一了您如何使用 `useQuery` 和其他钩子。 这使 Object API 更加一致，并帮助您避免烦人的 TypeScript 错误消息。
    
*   一种新的、简化的方式来进行乐观更新，您可以利用 `useMutation` 中返回的 `variables`，而无需编写手动更新缓存的代码。
    
*   可共享的突变状态使您可以使用新的 `useMutationState` 钩子访问组件之间共享的所有突变的状态。
    
*   对 `suspense` 的一流支持，以及对 RSC 流式传输的实验支持。
    

**底线：** 通过继续适应不断变化的 React 生态系统并添加对其他 JS 框架的支持，TanStack Query 证明它将长期存在。

这就是为什么我们一直与来自 React Query Core 团队的 Tanner 和 Dominik 合作构建 [query.gg 🔮](https://query.gg/) 的原因——一个全新的 React 查询课程，包含交互式视觉效果和现实世界的挑战，以帮助您快速掌握库。

单击内部div时记录了什么？

// 外部div点击！ <div id=​"innerDiv">​内层【1】
// 内部div点击！ <div id=​"innerDiv">​内层【1】
    

即使在子项的事件处理程序中调用了 `stopPropagation()`，但父的事件处理程序仍会执行，因为它已设置为捕获，并且在捕获阶段的事件到达孩子之前执行。

如果父的事件处理程序设置为泡沫，那么子的事件处理程序将首先执行，而父事件处理程序将根本不会执行，因为该事件将在子级的事件处理程序中停止。

最后，事件对象的 `target` 属性始终是事件被分派到的元素，在这种情况下是内部 div。
