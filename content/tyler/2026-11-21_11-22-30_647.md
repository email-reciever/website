有了这个，让我们进入 **Cloudflare 页面的亮点：**

**与内置构建的深度 Git 集成** 应该使持续集成工具变得不那么麻烦和烦人（我们希望）。 您只需选择 repo 和框架，cf pages 将为您构建和部署更改。 每个提交也有自己唯一的预览 URL，因此您可以进行一半体面的代码审查，而无需拉下整个分支。

**更简单的分级** 具有预览和生产环境，这些环境可以构建所有功能分支和预览链接，并使用“预览变量”进行预览，因此您可以在不影响生产数据的情况下进行实验。

**一个慷慨的免费层**，一次允许 1 个构建，每月 500 个构建，以及无限的站点、请求、带宽和管理席位。 [Cloudflare says they did this to give back to the community for the holidays](https://blog.cloudflare.com/cloudflare-pages/)，但当我们看到一个营销策略时，我们已经厌倦了知道一种营销策略。 也就是说，我们可以尊重一个好的营销策略，尤其是当它有很多免费的东西时。

网络 30 岁
-----------------

![The web turns 30](https://bytes.dev/images/content/30.jpg)

我很漂亮。 我很聪明。 我是网络规模。

**30 年前的昨天……** 英国科学家 Tim Berners-Lee 在 [info.cern.ch](http://info.cern.ch/) 和世界上第一个网页地址：[http://info.cern.ch/hypertext/WWW/TheProject.html](http://info.cern.ch/hypertext/WWW/TheProject.html) 发布了世界上第一个网站。 网络诞生了👼。

很确定蒂姆（又名 TBL）在那一点上可以得到一个更好的域名，但让我们暂时搁置这一点。

该网站包含有关 Web 项目本身的信息 — 超文本描述、创建 Web 服务器的说明等。

为了创建世界上第一个网站，TBL 还必须创建世界上第一个浏览器和 Web 服务器。 他在 CERN 研究中心花了几个月的时间在下一台计算机上开发了浏览器**WorldwideWeb**（是的，[that](https://www.edn.com/next-computer-debuts-october-12-1988/)下一台计算机）。

他（理所当然地）对 CERN 实验室的某个人不小心关闭了计算机感到偏执，因此他用红色墨水将手写的标签贴在电脑上，上面写着：“这台机器是一台服务器。不要关机！！”

原来的浏览器只能在下一台计算机上运行，这意味着 WorldwideWeb 实际上并不是很全球化（考虑到下一台机器的成本大约是当时的一大笔钱）。

因此，在 1991 年，TBL 与 Nicola Pellow（CERN 的数学实习生）合作创建了线路模式浏览器——第一个也可以在旧终端上工作的跨平台 Web 浏览器。 （将其称为其时间的反应本机。）

尼古拉可能没有为那次实习而获得报酬，但她确实“为她的简历获得了丰富的经验”。

那是该说法可能是真的一次。

快乐的网络马斯！ 🎄

🔥 JS 提示 - 了解“this”关键字
------------------------------------------

随着我们抽象出 JavaScript 的奇怪部分，JavaScript 的 `this` 关键字的知识变得不那么重要了。 但是，截至今天，我仍然认为它对任何 JS 开发人员来说都是至关重要的知识。

这是一个备忘单，用于了解 `this` 关键字引用的内容。

1.  查看函数被调用的位置。
2.  点左边是否有一个对象（`foo.bar`）？ 如果是这样，这就是 `this` 关键字所引用的内容（`foo`）。 如果没有，继续#3。
3.   函数是否使用 `.call`、`.apply` 或 `.bind` 调用？ 如果是这样，它将明确说明 `this` 关键字所引用的内容。 如果没有，继续#4。
4.   函数是否使用 `new` 关键字调用？ 如果是这样， `this` 关键字是引用由 JavaScript 解释器创建的新创建的对象。 如果没有，继续#5。
5.  是否在箭头函数内部？ 如果是这样，它的引用可以在封闭（父级）范围中词汇方式找到。 如果没有，继续#6。
6.  你在`strict mode`吗？ 如果是，`this` 关键字是 `undefined`。 如果没有，继续#7。
7.  JavaScript 很奇怪。 `this` 正在引用 `window` 对象。

如需更详细的解释，请访问 [Understanding the “this” keyword, call, apply, and bind in JavaScript](https://ui.dev/this-keyword-call-apply-bind-javascript)
