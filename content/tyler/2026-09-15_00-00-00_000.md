### 反应 19.3

当世界上大多数人都在争论人工智能是否会在未来 10 年内杀死我们所有人时，[the React team quietly shipped React 19.3](https://react.dev/blog/2026/09/09/react-19-3)。 因此，就像我们只需要担心的是一个流氓 `useEffect` 摧毁互联网的美好时光一样，我们又开始写关于 React 的文章了。

作为一个在 2005 年观看太多 TMZ 的人，我的第一个观察是，团队结构似乎发生了一些变化，以及有关该项目未来可能走向的一些线索。

_项目更新：_

除了一些离开该项目的 OGS（Sebastian Markbåge 和 Joe Savona）之外，该项目现在似乎围绕 4 个支柱进行了组织：服务器、DOM、光纤和编译器。 虽然这可能已经有一段时间了，我现在才注意到，它确实表明该项目正在稳定，不太可能看到任何狂野的范式变化 - a la 钩子和 RSC（尤其是现在 SEB 消失了）。 我认为这显示在这个版本中，已经制作了一年多的功能终于发布了。

_什么登陆了 19.3：_

*   **ViewTransitions：** 这个新组件允许您使用对浏览器的视图转换 API 的内置支持在进入、退出、移动或调整大小时对其进行动画处理。 请注意，您仍然需要编写CSS。
    
*   **fragment refs:** fragment refs 允许您访问片段子的 DOM，允许您设置事件监听器、管理焦点和观察者，而无需额外的 DOM 元素。
    
*   **Client / Server Updates：** 现在您可以直接在服务器组件中使用上下文并将数据传递给您的上下文。
    

// server-component.js
从 './user-context' 导入 { userContext };
    
导出异步函数布局({ 子 }) {
const currentUser = await getCurrentUser();
    
返回（
        <UserContext value={currentUser}>
{孩子}
        </UserContext>
)
}
