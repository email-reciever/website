Vue 3 生态系统

### 新年的影响

因为时间是一个只在一个方向上跳舞的残酷情妇，今年已经完成了 10% 的完成。 而且我讨厌吹牛，但我已经在我的一个也是唯一的 2023 决议上取得了一些非常好的进展：批量生产一种新的官方顶级拉面风味，称为_flamin' Hot Chili Limón Creamy Cool Ranch Beef_。

而且我不是唯一一个有大计划的人。 埃文，你刚刚发表了一次演讲，他为 2023 年布置了 [Vue’s goals and objectives](https://www.youtube.com/watch?v=OrT0tHGXyqE)——这主要分为两大类。

**类别 #1：共享是关怀。** 两年前，Vue 团队 [shared Vite with the world](https://dev.to/yyx990803/announcing-vite-2-0-2f0a) 通过从 Vue 核心中提取它并使其框架不可知。 这是一个巨大的成功，将 Vite 转变为网络最受欢迎的构建工具之一，每周下载超过 320 万次。

现在，他们希望使用 [Volar.js](https://blog.vuejs.org/posts/volar-a-new-beginning.html) 运行相同的 playbook——一个用于构建嵌入式语言的语言工具的框架。 它最初是为 Vue 单文件组件的特定需求而设计的，但他们只是将其提取到与框架无关的基础上，可以支持任何涉及嵌入式语言的文件格式——包括 Astro、Svelte 和 Angular。

**类别2：最好的能力是_稳定_.** Vue 生态系统仍携带着来自Vue 2 ➡ Vue 3 迁移的一些相当新鲜的战斗疤痕，因此核心团队专注于提高2023年的稳定性和减少碎片化。

这种“无子代码库”方法将具有更小、更频繁的版本，并且已经影响了即将推出的 V3.3 版本——这将不再包含 Suspense 等更复杂的功能。 他们还逐步淘汰了一些更偏振的特征，例如反应性变换。

**底线：** 很高兴看到我和 Vue 在 2023 年都在加倍关注我们最擅长的事情。

发现错误：解决方案
-----------------------

#### 赞助[Courier](https://bit.ly/3Xl7a2E)

常量 animal = (name, type) => {
this.name = 名称
this.type = 类型
this.age = 0
}
    
animal.prototype.birthday = 函数 () {
this.age++
}
    
const leo = new Animal('Leo', 'Lion')
    

箭头函数没有自己的 `this`。 这会导致我们的代码中出现三个错误。

首先，我们在构造函数中将属性添加到 `this`。 同样，因为箭头函数没有自己的 `this`，所以你不能这样做。

其次，我们不能使用带有箭头函数的 `new` 关键字。 这将引发 `X is not a constructor` 错误。

第三，如果该函数是箭头函数，我们不能在函数原型上添加属性，因为没有 `this`。

这是解决方案-

功能动物（名称，类型）{
this.name = 名称
this.type = 类型
this.age = 0
}
    
animal.prototype.birthday = 函数 () {
this.age++
}
    
const leo = new Animal('Leo', 'Lion')
