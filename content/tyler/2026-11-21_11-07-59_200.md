### 评分我们2023年的预测

这是一年中的神奇时刻，时事通讯的作者、YouTube 和那些将自己称为“思想领袖”的人喜欢分享他们对来年的预测。

但只有少数宝贵的人有勇气公开审查他们去年的预测，并面对那些冰冷的寒冷。

但是，当您向我们支付大笔费用时，您会得到如此多的信任，而对我们如此信任的轻微遗憾是您所得到的。

扣起来。

**预测 #1：** RIP 到 VC 资助的开源。

**等级：A-.**我们不再在Twitter上看到投资者对他们的投资组合公司拥有多少GitHub明星表示不满——因为他们突然对这个被称为“盈利能力”的新奇会计指标更感兴趣。 但我们并没有给自己一个完整的成绩，因为像 Hugging Face 这样的开源 AI 公司仍在筹集资金，让他们的 VC 忘记了 2022 年的所有痛苦……现在。

**Prediction #2:** Remix 将全力以赴 Web 组件。

**等级：D.** 这个想法是 Remix 将放弃对框架可以自由竞争的中立土地的反应。 相反，也许在 1984 年有一点温斯顿史密斯 [psychological torture energy](https://twitter.com/ryanflorence/status/1737867055020614060) - 他们接受了 React 及其新的 RSC 理念。

**预测 #3:** TRPC 将替换 GraphQL 作为类型 Nerd 的后端选择™。

**等级：D+。** 在这辆滑雪板上，我们的滑雪板上有一个_小_。 TRPC 今年的增长速度接近 5 倍，但它仍然 [~20x smaller](https://npmtrends.com/@trpc/server-vs-graphql) 比 GraphQL，而且在取代任何东西之前还有很长的路要走。 考虑一下您的日常提醒，您在 Twitter 上看到的不是现实生活。

**预测 #4：** Qwik 将吃掉 React 市场份额

**等级：F.** 没有多少人知道这一点，但“Qwik”是犹他州南部的俚语，意思是“ASTRO”——这就是我们真正的意思……小指的承诺。

**预测 #5：** React Hate 将达到历史最高水平……因此 React 的使用情况也会达到历史最高水平。

**等级：A+.** 格兰芬多 10 分。

**预测 #6:** UI 框架竞赛将变成工具链竞赛。

**等级：A.** 借助 Astro、Nuxt、Angular 和最近的混音所有使用 Vite，MetaFramework 的竞争已经真正成为 Next.js vs Vite。 有人可能会说这就像苹果与安卓的网络一样——但尽管 Vercel 要求所有员工都穿着史蒂夫·乔布斯的黑色高领毛衣，但这实际上更多的是 [Das Sound Machine vs The Barden Bellas](https://www.youtube.com/watch?v=x2bTh_QhtYQ) 情况。

**预测#7：** Gatsby 收购 Astro。

**F.** Gatsby 不仅没有收购 Astro，他们还在我们做出这个预测一个月后通过 Netlify 收购了 😭。 凯尔非常粗鲁，没有警告我们，但这很好。 盖茨比现在似乎大部分时间都在一个更好的地方 [maintenance mode](https://www.netlify.com/blog/developing-gatsby-enhancing-stability-and-reliability/)，但他们永远无法夺走我们在一起的时间。

**预测 #8：** 加密开发人员将成为 AI 开发人员。

**B+级。 瓦格米。

**底线：** 总的来说，我给我们一个 A 的努力，A B- 的准确性，以及对课堂行为的“需要改进”。 明年见。

答案是 65。 MDN 解释了“传递 REST、默认或解构参数的非严格函数将不会与参数对象中的函数主体中的参数同步新值。”

如果我们删除默认参数，我们会得到不同的答案：

函数 calculateTotalCost(MealCost, Taxrate, Tip) {
参数[1] = 0.15；
参数[2] = 参数[2] + 5;
    
让 TotalCost = 膳食成本 + 膳食成本 * 税率 + 小费；
返回总成本；
}
    
让 total = calculateTotalCost(50, undefined, 10);
console.log（总计）；
    

没有默认参数的答案是 `72.5` (`50` + `7.5` + `15`)。
