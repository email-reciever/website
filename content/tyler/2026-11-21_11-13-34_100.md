### 无法控制的感情

在情人节那天，当 Chrome 团队宣布所有稳定浏览器都支持 [container queries](https://web.dev/cq-stable/) 时，Web 开发人员感受到了爱——这要归功于最新的 Firefox 版本 ❤️‍🔥。

这是 2023 年 Interop 中的 [26 focus areas](https://webkit.org/blog/13706/interop-2023) 之一——我们最喜欢的小 polycule _working group_ 浏览器供应商，他们负责提高浏览器的兼容性。

**那么容器查询到底是什么，为什么每个人都如此兴奋？**

容器查询允许您根据预定容器的大小将样式应用于页面上的特定项目。 这通常会取代十年前首次引入的媒体查询的使用，以根据视口大小修改整个页面的样式。

媒体查询的问题在于，对于 2023 年以组件为中心的 Web 开发，这种视口驱动的方法可能会变得很糟糕——需要您编写复杂的 CSS、修饰符类和/或客户端 JS 以获得所需的响应式布局和组件。

但是容器查询使所有这些问题都消失了。 您需要做的就是在容器本身上定义 `container-type`，使用 `@container` 并开始查询。 一旦满足该条件，CSS 将应用于该容器内的组件。

**底线：** 很高兴看到 Interop 团队共同努力，以获得所有主要浏览器供应商支持的真正有用的平台功能。 名单上的下一个？ 添加对 [CSS Style Queries](https://ishadeed.com/article/css-container-style-queries/) 的支持，它允许您查询容器的 _style_ ，而不仅仅是大小。 Chrome的V111测试版刚刚开始支持它，所以希望[it’s just a matter of time](https://www.youtube.com/watch?t=35&v=SNKrBQCzQOI&)。

弹出测验：回答
-----------------

您将如何定位小于 400px 的容器？

通过使用 `@container` [at-rule](https://developer.mozilla.org/en-US/docs/Web/CSS/At-rule)，您可以轻松地将样式应用于与查询匹配的任何容器。

.横幅{
/* 一些横幅样式 */
}
    
@Container（宽度< 400像素）{
.横幅{
/* 在这里应用一些样式 */
}
}
    

上面的示例适用于所有容器，但如果您想要对所选元素进行更微调的控制，可以使用 `named container contexts`。

.banner-container {
容器类型：内联大小；
容器名称：横幅； /* 应用命名容器上下文 */
}
    
@Container 横幅（宽度 < 400px）{
.横幅{
/* 在这里应用一些样式 */
}
}
    
    

容器查询还可以评估容器元素的计算样式🤯（注意：这部分规范不完全支持）。 这使得做一些疯狂的事情成为可能。

@Container 样式（颜色：蓝色）{
      * {
颜色：红色；
}
}
    

这需要很多东西，但是 `container queries` 确实是基于组件的网页设计的游戏规则改变者。 如果您需要更多灵感，请查看 Ahmad Shadeed 的 [container query examples](https://lab.ishadeed.com/container-queries/)。
