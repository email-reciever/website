## Cool Bits

1. Luke Karrys 写了一篇关于 [vlt.io 如何比 npmjs.org 服务 70% 少的包元数据](https://www.vlt.io/blog/registry-metadata-70-percent-smaller) 的文章。我也 90% 确信 Luke 编造了“packument”这个词，但它似乎是为什么你的包下载如此臃肿的原因。

2. Armin Ronacher 撰写了一篇 [博客文章来帮助你理解 codemode](https://lucumr.pocoo.org/2026/10/6/codemode/)，一种编排 MCP 工具的方式，可以为你节省令牌，给你的代理提供“表达自由”，同时它又是 Kenton Varda 发明的另一件事。Pi 获取加载？

3. [Blacksmith 是 GitHub 运行器的替代品](https://www.blacksmith.sh/?utm_source=bytes\&utm_medium=newsletter\&utm_campaign=bytes_secondary_2026_10_09)，它的速度明显更快，成本减少 60%。它非常简单，并且可以在你的 CI 流水线中完全观察到。 \[sponsored]

4. William Candillon 刚刚发布了 [React Native Skia v3](https://github.com/wcandillon/react-native-skia)，它包括一个闪亮的新 GPU 后端，可以使跨平台图形运行得更快。

5. Next.js 团队推出了一种新的编程模型，该模型“解决了您从一开始就对 App Router 的许多烦恼”，随着 [Next 16.4 的发布](https://nextjs.org/blog/next-16-4)。这个解决方案是另一个名为 `use cache` 的指令 🫠。

6. Bret Taylor 和 Clay Bavor 撰写了 [一个用于个人代理的新协议](https://sierra.ai/blog/introducing-personal-agent-protocol)，该协议建立在 OAuth 之上。这是为了帮助所有苦苦挣扎的认证公司终于上市而精心设计的计谋吗？

7. [使用 SerpApi 为您的应用程序和 AI 代理提供 100+ 个搜索引擎的实时数据](https://serpapi.com/bytesdev)。使用 Google Search、Maps、AI 概述等的实时结果为您的 AI 工具提供动力，跟踪排名或发现本地企业。只需一个简单的 GET 请求即可获得结构化的 JSON 或 Markdown。\[sponsored]

8. Lucas Bonomi 创建了一种名为 `gss` 的新语言（GPU 样式表） ，它允许您使用 CSS 编写着色器 🤯。

9. Max Barvian 撰写了 [一个小的 React 技巧，帮助您改进退出动画](https://barvian.me/react-exit-animations)。

10. Dev Agrawal 创建了 [`solid-yield`](https://github.com/devagrawal09/solid-yield) ，它允许你在 Solid.js 应用中使用生成器函数，每次读取都是一个 `yield*` 。如果你使用 Solid.js 并且不会因生成器语法而头痛欲裂，你可能会喜欢它。
