另一个框架？？？

有一个新的新鲜王子
---------------------------

不，我不是在谈论没有人要求的新电视剧重启。 我说的是 [Fresh](https://fresh.deno.dev/) — 新的全栈 SSR 框架……没有人要求。

Fresh 是由 Deno 团队创建的（上个月筹集了非常新的 2100 万美元），他们上周刚刚发布了该框架的稳定 v1.0。 它建立在 Deno 之上，并将自己描述为使用 Preact 和 JSX 的“路由框架和模板引擎，可以在服务器上按需呈现页面”的组合。

_所以它基本上是混音和 next.js 和 Astro 以及 Hydrogen 和 RedwoodJS……但是对于 Deno？_

是的，但实际上不是。 Fresh 从其他框架中借用了许多功能和概念，但它以独特的方式结合了它们，同时添加了一些很酷的新功能——这要归功于健康的 Deno Dust。 让我们放大：

*   类似于 Astro，Fresh 使用 Islands 架构仅将 JavaScript 用于实际需要交互性的组件——它默认将零 JS 运送到客户端。
    
*   它的文件系统路由与 next.js 和 remix-style [form submissions](https://fresh.deno.dev/docs/getting-started/form-submissions) 非常相似。
    
*   建立在 Deno 上意味着 Fresh 具有一流的 TypeScript 支持，不需要配置，并且没有构建步骤。
    

**底线：** 最终，Fresh 希望让您使用 Deno 和 Deno Deploy™ 将您的应用程序部署到边缘变得非常简单，这样您就可以轻松构建很酷的东西，以便您的公司最终会向他们支付大量资金。

到目前为止，他们似乎在做[a good job](https://twitter.com/search?q=deno%20deploy&src=typed_query&f=top)。

eslint 仍然很强劲
-----------------------------

OG JavaScript Linter 上周刚满 9 岁，JS 年大约是 63 岁（是的，这和狗年一样……感觉是对的）。

对于每个人都使用的工具来说，这是一个非常令人印象深刻的运行。 像任何好狗一样，eslint 有时可能是 [a little overbearing](https://www.reddit.com/r/FunnyAnimals/comments/u4ajyk/is_this_normal/)，但它的心总是在正确的地方。 所以让我们拿出一罐新的花生酱_（羽绒男孩）_，并对棉绒王表示敬意。

**我们是如何到达这里的：** ESLint 由 [Nicholas Zakas](https://twitter.com/slicknet) 创建，用于折磨您的标记并修复您的 JavaScript 代码的常见问题。 直到2019年，它比Babel或TypeScript更广泛地使用，今天它仍然得到[26 million weekly downloads](https://npmtrends.com/@babel/core-vs-eslint-vs-typescript)。

它如此受欢迎的一个重要原因是因为配置和创建插件是多么容易。 在许多方面，ESLint 负责启动至今仍在进行的 JavaScript 工具革命。

以下是它在引擎盖下的工作方式：

*   ESLint 是一个编译器，它将你的 JavaScript 解析为 AST 并通过一堆插件和规则运行它。
    
*   插件用于为 ESLint 添加功能（又名 Band-Aid React 用于帮助您理解 [hooks](https://www.npmjs.com/package/eslint-plugin-react-hooks)）。
    
*   然后它将输出传递给您的IDE或构建工具，以羞辱您的工作不佳（它只是因为它在乎而对您大喊大叫）。
    
*   最后，它为您完成了 `--fix` 🪄 命令自动修复（部分）标记的问题
    

**底线：** 不可否认，eslint 让我们的生活成倍地变得更好。 但是，如果您被 Airbnb eslint 配置所伤痕累累，您可能有权获得赔偿！ 使用标签#airbnbeslintpain 今天加入我们的集体诉讼的推文。
