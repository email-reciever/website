### 欢迎来到第二届奥斯卡尔

你们都在红地毯上看起来_Amazing_——我很荣幸能站在你们面前举办这个非常真实的颁奖典礼（我们编造的），以表彰我们都知道和（主要）喜欢的一些 OSS 项目。

可悲的是，我没有像 Jimmy Kimmel 那样因为主持这场演出而得到报酬——但幸运的是，我没有他那么无聊。 让我们开始吧。

_和奥斯卡去了……_

**最佳男配角/女演员：** VITE。 这个下一代前端工具包随处可见，就像 Zoe Saldana 一样，它在许多大型项目中扮演着关键的配角。 Vite 帮助 Power Astro、Sveltekit、Nuxt (Vue)、Solid Start、Qwik City 等。 我想这是它每周 npm 下载量爆发式增长的原因之一……自去年的 Osscars 以来增长了 6 倍。

**最佳摄影：** Astro。 他们刚刚推出了一个很酷的新网站、炒作视频和人工智能助手，名为休斯顿。 所以现在，阅读新的 Astro Docs 基本上感觉就像你在生活的 IRL 版本的_Zenon：21 世纪的女孩。_ [Cetus-Lupeedus!](https://www.youtube.com/watch?v=iX1GXfs1izM)

**最佳原创剧本：** Qwik。 这是一个心爱的 OSS 作者（Misko Hevery）的精彩故事，他离开了他的第一个创作（Angular），帮助一个伟大的团队从头开始一个新的项目。 在此过程中，他们向我们介绍了一种新的渲染范式，称为可恢复性，并编写了比您最喜欢的 O'Reilly 作者更具技术性的内容。

**最佳表现：**面包。 基准在这里不言自明，但你有没有想过_为什么_这个下一代运行时间这么快？ Bun 说这是因为他们在 Zig 中进行分析、基准测试和优化的“大量时间”——他们编写的低级语言和手动记忆管理，他们编写了 Bun。事实证明，我的瑜伽教练是对的：“如果你想去 快。” 🧘‍♀️

**最佳戏剧：** 混音。

### 第二届年度奥斯卡 - 部分双人

**最佳导演：** 坦纳·林斯利。 他是 TanStack Query (FKA React Query)、TanStack 表和 TanStack 路由器背后的团队领导者，他们还有另外 5-7 个库正在进行中。 像任何伟大的导演一样，他绝对有一种标志性的风格——但不是韦斯·安德森调色板或 M. Night Shyamalan 扭曲结局，他只是……做得更好，增加了类型的安全性。 不要质疑他的天才，人们。

**最佳突破性能：** ZOD。 不顾一切，我从未见过打字稿优先的模式声明和验证库捕捉到这么多开发人员的心灵和思想。 未来是类型安全的，而 Zod 正在使未来成为现实。

**最佳服装设计：** Next.js。 你必须尊重他们如何在经典的_mean girls_ [aesthetic](https://youtu.be/xBbOAVSBvpE?t=13) 上投入自己的原创。 他们不只是说“在星期三穿粉色”，而是说“我们每天都穿黑色”，将其提升到一个新的水平。 喜欢看到团队团结。

**克里斯托弗·诺兰终身成就奖：** 反应。 像诺兰一样，在过去的十年里，没有人像 React 那样吸引观众的想象力。 另外[like Nolan](https://www.youtube.com/watch?v=XkO-Wp8HrB0)，近年来没有人让他们的观众怀疑他们是否太愚蠢而无法理解发生了什么。

**底线：** 感谢您今晚出来，请出来参加派对。 Pit Bull 将首先表演，Vue 核心团队将在 Doja Cat 的唱片中演唱每首歌曲的卡拉 OK 版本，成为头条新闻。

很酷的位
----------

1.  Julia Evans 写了这篇关于 [Some possible reasons for 8-bit bytes](https://jvns.ca/blog/2023/03/06/possible-reasons-8-bit-bytes/) 的文章。 我不认为她在写关于我们的文章，但无论如何我们决定给她自己的字节数。
    
2.  Bo Ingram 写了关于 [How Discord stores trillions of messages](https://discord.com/blog/how-discord-stores-trillions-of-messages) 的文章……我敢肯定几千英尺的照片。
    
3.  [CarbonQA](https://carbonqa.com/?utm_source=bytes&utm_medium=email&utm_campaign=cool_bits&utm_content=mar13) 为开发团队提供 QA 服务，因此您再也不用自己做。 他们在您的工具中工作，在 Slack 上与您的团队交谈，并让您的开发人员成为开发人员——因此您不必再将工程时间浪费在测试上。 \[赞助\]
    
4.  [Million.js just released v2.0](https://millionjs.org/) 的低级虚拟 DOM 库，具有优化实用程序，使渲染更快。
    
5.  Simon Holthausen 写了 Sveltekit 现在如何提供 [Zero-effort type safety](https://svelte.dev/blog/zero-config-type-safety)。 你让我在“零努力”，西蒙。
    
6.  在 [Were React Hooks a Mistake?](https://jakelazaroff.com/words/were-react-hooks-a-mistake/) 中，Jake Lazaroff 敢问我们是否应该一直坚持使用类组件。 触发警告：他提到“信号”28 次。
    
7.  在 [All JavaScript and TypeScript Features of the last 3 years](https://betterprogramming.pub/all-javascript-and-typescript-features-of-the-last-3-years-629c57e73e42) 中，Linus 打破了导致 SVB 崩溃的宏观经济趋势，以及美联储的决定最终意味着什么——哦，等等，不抱歉，他了解了过去 3 年的所有 JavaScript 和 TypeScript 功能。
    
8.  现在可以执行 [Trigonometric functions in CSS](https://web.dev/css-trig-functions/)，例如计算正弦、余弦和切线。 也许我的 8 年级 Trig 老师来得正是时候，我会在工作中使用它。
