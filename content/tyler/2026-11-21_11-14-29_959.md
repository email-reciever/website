### 2023 保证实现或退款的预测

1.  **RIP 到 VC 资助的开源。** 如果您还没有听说过，资金龙头坏了，没有人知道如何重新打开它。 这意味着您最喜欢的 VC 支持的 OSS 项目从未想过如何赚钱，很快就会重新要求捐款和销售课程。 我们永远不会忘记你，2021 Fever Dream。
    
2.  **remix 将全力投入 Web 组件。 这也意味着他们将向 React 宣战并完成他们的 WWE 背叛弧线。
    
3.  **TRPC 将取代 GraphQL 作为类型的 Nerd 的后端选择™️。 在 2023 年，我们将看到 TRPC 继续攀升，成为思想领袖最喜欢在推特上发布的关于没有人真正采用的推文。
    
4.  **可重现性是一个词。** 因为所有的 React 开发人员都在忙着弄清楚他们的应用程序为什么要重新渲染，[Qwik](https://qwik.builder.io/) 他们的 React 的 Good Parts API 将开始占用所有非 React 的市场份额。 说到反应…
    
5.  **反应仇恨将达到历史最高水平……也将反应使用。**与您在 Mastodon 上听到的相反，Supplants React 的框架尚未发明。 不幸的是，它在 2023 年不会去任何地方。
    
6.  **UI 框架竞赛将变成工具链竞争。s** UI 框架的战争是如此_2000-and-Late_。 最新的竞争性前沿看起来像 Next+Turbo 与 Vite，看看谁可以为开发人员提供终极的“端到端”体验。
    
7.  **Gatsby 收购了 Astro。 与此同时，Gatsby 2.0 Astro 将在 2023 年到达跑道的尽头，正如 F. Scott 预测的那样，他们将“击败水流，船只逆流而上，不断地回到过去。”
    
8.  **加密开发人员将成为 AI 开发人员。** 然后他们会假装自己比我们其他人更好，因为他们已经掌握了在输入字段中输入的艺术。
