### 灯光、相机、天文动作

如果我从上周末重新观看每部 M. Night Shyamalan 电影中学到了一件事（不要问），那就是伟大的电影制作人理解一个好的转折的力量。

这就是 Astro 上周给我们提供的 [v4.8](https://astro.build/blog/astro-480/) 的惊喜预览 Astro Actions 的内容——这是一个长期要求的功能，可以轻松地从客户端代码中定义和调用后端功能（具有完整类型的安全性）。

这是[how to use it](https://docs.astro.build/en/reference/configuration-reference/#experimentalactions)上的快速TLDR：

*   在全局操作处理程序中声明您的所有操作
    
*   使用 `defineAction()` 定义动作
    
*   使用 `astro:actions` 中的 `actions` 对象从任何客户端组件调用操作
    

这种方法似乎与 Remix 和 Sveltekit 等其他框架中的动作如何工作非常密切地跟踪，并且它提供了一些强大的优势，超出了明显的范围。 例如，您不再需要基于 `Content-Type` 安全解析请求正文或从请求正文中检索表单数据值的样板。

**底线：** [Actions RFC](https://github.com/withastro/roadmap/blob/actions/proposals/0046-actions.md) 提到了新的 Astro 数据库平台如何“将 ASTRO 社区从静态内容推进到更动态的用例中，例如计数器和评论小部件”。 因此，从业务角度和 DX 的角度来看，Astro 投资于使后端功能变得简单，这是完全有道理的。

发现错误：解决方案
-----------------------

#### 赞助[Snyk](https://go.snyk.io/240422_ad_report_appsec_risk_ciso.html?utm_campaign=dm_pp-bytes-advertiser-240513-con_240422_ad_report_appsec_risk_ciso&utm_medium=em-pa&utm_source=bytes-advertiser&utm_content=con_240422_ad_report_appsec_risk_ciso)

常量汽车 = {
名称：'特斯拉'，
StartEngine() {
控制台.log(`The ${this.name} engine is starting...`);
},
延迟启动（）{
setTimeout(this.startEngine, 1000);
}
};
    
car.delayedStart();
    

该错误与我们对 `startEngine` 的调用有关。 因为我们将 `this.startEngine` 作为参数传递给 `setTimeout`，所以我们不是调用它的人。 这意味着它不会被正确的上下文（`this`）调用。 我们可以通过两种方式解决这个问题——使用 `.bind` (🙃) 或像这样调用函数。

常量汽车 = {
名称：'特斯拉'，
StartEngine() {
控制台.log(`The ${this.name} engine is starting...`);
},
延迟启动（）{
setTimeout(() => this.startEngine(), 1000);
}
};
    

如果您想要更长的解释，我们将其分解为 [Understanding the “this” keyword, call, apply, and bind in JavaScript](https://ui.dev/this-keyword-call-apply-bind-javascript)。
