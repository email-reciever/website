## Cool Bits

1. TJ Zhang 撰写了一篇博客文章 [教系统工程师前端 Web 开发](https://tj-zhang.com/blog/frontend-for-systems-engineers/)。使用 Dune 参考资料帮助他们在第一次看到 React 后情感调节，可能是一个好主意。

2. Angelique Nehmzow 和 Emma Guo 对 [Notion 如何使用 CRDT 处理并发编辑](https://www.notion.com/blog/how-notion-handles-concurrent-editing-with-crdts) 进行了深入探讨。

3. [Sentry 日志，超越基础](https://sentry.io/resources/beyond-logs-basics-workshop/?utm_source=bytes\&utm_medium=paid-community\&utm_campaign=logs-fy27q3-logsworkshop\&utm_content=newsletter-secondary-logs-beyond-basics-workshop-register) 是一个免费的工作坊，于 10 月 1 日举行，展示如何将日志与跟踪和错误一起使用，以更快地找到根因，并如何跨服务边界记录日志。 \[sponsored]

4. Joe Bell 发布了 [`cva` 的 `1.0.0-beta.12` 版本](https://cva.style/)，这是一个用于构建类型安全、变体驱动的类名的微型库，支持 Tailwind。

5. Sunil 撰写了关于 [“高级工程师死亡螺旋”](https://sunilpai.dev/posts/the-senior-engineer-death-spiral/) 的文章，或者说，我喜欢称之为如何快速被解雇的方法。

6. Alec Larson 创建了 [一个比较表格](https://gist.github.com/aleclarson/0f4266d63fd83c7a5ea5512441bbea0c)，展示了 Octane 和 Solid 2 的区别，以及哪一个更胜一筹。没有什么比 TMBB 更能让框架作者们准备好他们的“炮弹”在评论中展开战斗。

7. 只有白痴才会写手动测试——像 Notion、Dropbox 和 LaunchDarkly 这样的现代工程团队使用 Meticulous 来维护 e2e UI 测试，这些测试 [涵盖了您的 Web 应用的每一个边缘情况](https://www.meticulous.ai/?utm_source=bytes\&utm_medium=newsletter\&utm_campaign=26q3\&utm_content=secondary)。 \[sponsored]

8. [Claude](https://www.anthropic.com/claude-opus-5-5)、[SpaceXAI](https://x.ai/news/grok-4-7) 和 [OpenAI](https://openai.com/index/introducing-gpt-6-sol-and-luna/) 都发布了他们的模型更新。这是否意味着我们正在减速或加速？

9. 从 Chrome 154 开始，[iframes 现在可以自动调整大小以适应内容](https://www.bram.us/2026/09/23/responsive-iframes/) 🙏。

10. Vinod Khosla 撰写了关于 [我们需要在 AI 时代改变税法代码](https://www.khoslaventures.com/posts/refounding-america-the-tax-code-needs-to-change-in-the-age-of-ai) 的文章。人们仍然需要钱来购买 Seahawks 的票。
