### 2023年大会JS辩论

当我们美国人在周二庆祝我们的独立日时，我花时间在我的第三次和第四次热狗之间思考我们的开国元勋如何为我们最基本的人权而战——在互联网上开始无意义的 JavaScript 论点的权利。 🫡

Deno 和 Bun 团队在假期周末前重新引发了一场关于 CommonJS 未来的老辩论时，显然也感受到了同样的节日气氛。 这是发生的事情。

**上周五，** Andy Jiang 在 Deno 博客上写了一篇关于如何 [CommonJS is hurting JavaScript](https://deno.com/blog/commonjs-is-hurting-javascript) 的文章。 他认为，就像黑眼豆豆一样，CommonJS 正是 2009 年世界所需要的——但它今天的表现并不好。

*   CommonJS 模块同步加载，会导致阻塞行为。
    
*   很难树摇CJS模块，这会导致更大的捆绑包尺寸。
    
*   CJS 模块不是浏览器原生的，因此您需要捆绑器和转译器来使您的代码在客户端工作。
    

您可能知道，TC39 团队早在 2015 年就发布了 ES 模块来解决这些特定问题——因此安迪认为，是时候让我们“埋葬 CommonJS 并过渡到 ESM 的未来”了。

**反驳：** Jarred Sumner 和 Bun 团队_Might_ 感觉这篇文章有点像他们的运行时竞争对手的小推文，因为 Bun 最近的 [release notes](https://bun.sh/blog/bun-v0.6.5) 明确提到了 CommonJS 的支持。

所以同一天晚些时候，Jarred 放弃了他自己的 Diss Track 博客文章，标题为 [CommonJS is not going away](https://bun.sh/blog/commonjs-is-not-going-away) 除非你从我冰冷的 Thiel 手指上撬开它。 _（好的，我添加了最后一部分。）_

在这篇文章中，他认为 CommonJS 实际上在较大的应用程序中启动 [faster than ESM](https://bun.sh/blog/commonjs-is-not-going-away#commonjs-starts-faster)，并且它允许您在函数主体中 `require()` 有条件地或 `require()` 中 `require()` 文件进行动态加载。

但他最有说服力的论点是 CommonJS “已经在这里停留了”。 CJS 仍然有 [dominant market share](https://twitter.com/wooorm/status/1588905279206621184)，尽管 ES 模块已经存在了近十年，而且它仍然有“真正的存在的理由”——因此，Bun 将 CJS 视为一流的公民。

**底线：** 安迪的批评出现在 Deno 的一个有趣时刻，考虑到该团队去年对 [embrace compatibility](https://deno.com/blog/changes#compatibility-with-node-and-npm) 进行了艰难的转折，Node 和 NPM。 我敢打赌，我们将继续从 Bun 和 Deno 看到这种类型的实用主义，因为两个 VC 支持的运行时试图尽可能快地增长。

JavaScript 至少有 20 种不同的方式来循环遍历事物，包括所有数组方法，如 `forEach`、`map` 和 `filter`、递归函数和 `while` 和 `for`。

对于数组方法和递归函数，您可以提前用 `return` 语句结束循环，但如果您要在 `while` 或 `for` 循环中使用 `return` 语句，它将结束整个函数，这并不理想。 相反，如果你想跳到循环的下一个迭代，你可以使用 `continue` 语句，就像这样。

for (let i = 0; i < 10; i++) {
// 跳过 2 的倍数
如果 (i % 2 === 0) {
继续
}
控制台.log(i)
}
// 1、3、5、7、9
    

`break` 语句允许您过早地结束循环，而无需再运行任何迭代。

for (let i = 0; i < 10; i++) {
// 当我们得到 3 的倍数时结束循环
如果 (i % 3 === 0) {
打破
}
控制台.log(i)
}
// 1, 2
    

这两个语句适用于单个循环，但是如果我们需要协调嵌套循环呢？ 如果我们只是在内部循环中使用 `break` 或 `continue`，它将无法停止或跳过外循环。

常数编号列表 = [1, 2, 3, 4, 5]
for (let i = 0; i < numberList.length; i++) {
const inum = numberlist[i]
for (let j = 0; j < numberList.length; j++) {
常量 jnum = numberlist[J]
if ((inum * jnum) % 2 === 0) {
// 如果数字是偶数，则会继续内部循环
继续
}
console.log(inum * jnum)
}
}
// 1,3,5,3,9,15,5,15,25
    

为了让我们从内部循环内部调用外部循环上的 `continue` 或 `break`，我们需要对外循环应用一个标签。 标签就在 `for` 语句之前。 然后，我们可以将标签与 `continue` 语句一起使用。 注意我们添加标签后结果如何变化。

常数编号列表 = [1, 2, 3, 4, 5]
OuterLoop: for (let i = 0; i < numberList.length; i++) {
const inum = numberlist[i]
for (let j = 0; j < numberList.length; j++) {
常量 jnum = numberlist[J]
if ((inum * jnum) % 2 === 0) {
// 如果数字是偶数，则会继续内部循环
继续外环
}
console.log(inum * jnum)
}
}
// 1,3,5
    

下次由于某种原因需要嵌套循环时，您可以使用 label、`break` 和 `continue` 来更好地控制循环的流。
