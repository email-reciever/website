### TypeScript 7 在这里

通常，当我们撰写有关 TypeScript 版本的文章时，我需要一切都假装对“推断类型谓词”之类的事情感到兴奋。 幸运的是，在上周终于出来的 [TypeScript 7](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0) 中，有一些我们都可以兴奋的事情：速度。

一年多前，Anders Hejlsberg 宣布微软团队正在从 JavaScript 移植 TypeScript 代码库，以使编译器快 10 倍。 快进到今天，这项工作终于登陆了。 现在，当您打开文件时，您可以立即看到那些红色的波浪。 耶。 以下是 Go 端口解锁的一些显着改进。

*   **Max 并行化：** 在 TypeScript 7 [parsing, type-checking, and emitting file updates](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/#custom-scaling:-parallelization-and-controls) 中主要是并行完成的。 由于这可能会使内存有点不足，因此它们包含一个 `--singleThreaded` 标志以选择在资源受限的环境中退出。
    
*   **更好的编辑经验：**由于更好地模糊现有代码库，[language server in version 7](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/#editor-experience)比版本6“更稳定”，并支持自动导入，可扩展悬停，嵌入式提示，代码镜头，转到源定义， JSX 链接编辑和标记完成等。
    
*   **改进的手表模式：** 构建在 Parcel 的文件观察器之上，[`--watch` 模式](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/#improved---watch-mode) 现在跨平台更可靠，占用更少的 CPU 时间，并且可以更好地扩展大型项目。
    

版本 7 仍然没有程序化 API，因此 MDX、Svelte、Vue 和 Astro 等项目暂时停留在版本 6 上。

**底线：** 烘焙打字书呆子是我最喜欢的活动之一，但今天，感谢 Anders 和朋友们，我们都在性能提升餐桌上大吃一惊。

发现错误：解决方案
-----------------------

#### 赞助[Tabstack](https://tabstack.ai/?utm_source=bytesdev&utm_medium=newsletter&utm_campaign=bytes-presenting-2026-07-10)

这一款是给初学者的。

函数 safeUpdate(obj, key, value) {
if (!obj.hasownProperty(key)) {
obj.key = 价值；
}
}
    

我们的错误是我们正在为我们的对象添加一个文字 `key` 属性。

console.log(user.key) // “美国”
    

在 JavaScript 中，如果要将变量用作对象的键，则需要使用括号表示法而不是点符号。

函数 safeUpdate(obj, key, value) {
if (!obj.hasownProperty(key)) {
obj[key] = 值；
}
}
