### replit 想帮你写鞭子

…如果说“鞭子”，则指的是“人工智能可以为您编写的无聊代码”。

这就是他们刚刚推出 [GhostWriter](https://blog.replit.com/ai) 的原因——一种新的人工智能驱动的代码完成工具，它声称比 Copilot 或任何其他有一天会取代我们所有人的机器人“更快、更强大、更容易访问”。

**我们是如何到达这里的：**您可能将 Replit 称为您 12 岁的侄女和侄子过去成为比您更好的程序员的精美、浏览器中的 IDE。 但在过去的几年里，Replit 推出了大量的新功能，这些新功能正在帮助其向上移动并开始吸引更多专业的开发人员。

Ghostwriter（连同 Replit 的其他新“AI 模式”一样）希望通过将 AI 和机器学习融入 IDE 的各个方面来延续这一趋势。

**让我们潜入：**

*   **GhostWriter**是AI模式的旗舰功能，它指的是我们已经提到的AI代码完成工具。 IT 和 GH Copilot 之间最大的区别在于它在不同的数据集（Salesforce 的 CodeGen）上进行了训练，并且由于一些独特的 [optimization tactics](https://blog.replit.com/ai#:~:text=Here%20we%27ll%20go%20over%20some%20of%20the%20optimization%20tactics%20we%27ve%20used%20or%20are%20actively%20exploring%3A)，它声称要快得多。
    
*   **Semantic Search** 允许您使用自然语言搜索可在代码库中使用的开源函数。 由于您是从 _inside_ the editor 中搜索的，因此通过将搜索结果基于您已经编写的代码，Replit 的搜索可以更加上下文 🔥。
    
*   **transform** 在适当的时候提示您重构代码，然后为您执行此操作。
    
*   **解释** 让您突出显示一段代码并简单解释它的作用。
    
*   **generate** 是一个文本到代码的功能，您可以在其中描述您希望程序或文件以自然语言执行的内容，然后 AI 生成代码以实现它。 （CodeGen 的数据集 [specifically targets](https://blog.salesforceairesearch.com/codegen/) 使用这样的情况。）
    

**底线：** Ghostwriter 是否能够吸引更多专业开发人员为未来的项目尝试 REPLIT？ 我们不知道，但我们确实知道我们会很遗憾没有借此机会通知您 [this video](https://youtu.be/SBPJTK1YBvs?t=14) 存在。

发现错误：解决方案
-----------------------

#### 赞助[Appwrite](https://appwrite.io/?utm_source=newsletter&utm_medium=homepage&utm_campaign=bytes)

从“反应”导入 { useState }；
    
导出默认函数 counter() {
const [number, setNumber] = useState(0);
    
返回（
<>
<h1>{编号}</h1>
<button onClick={() => {
setNumber(数字+1);
setNumber(数字+1);
setNumber(数字+1);
}}>增量</button>
        </>
)
}
    

这一款直接来自新的（测试版）[React Docs](https://beta.reactjs.org/learn/queueing-a-series-of-state-updates)。 您可能会期望单击按钮会将我们的 `number` 状态增加 3，但这不是它的工作方式。 简而言之，JavaScript 围绕 `number` 变量创建了一个闭包，就好像我们在做

setNumber(0 + 1);
setNumber(0 + 1);
setNumber(0 + 1);
    

当然，这将始终将 `number` 设置为 1。

相反，如果我们想在下一次渲染之前多次更新相同的状态，我们可以像这样将函数传递给我们的 setter 函数 -

setNumber(n => n + 1);
setNumber(n => n + 1);
setNumber(n => n + 1);
    

现在 React 会将所有这些函数添加到队列中，在下一次渲染期间，React 会通过队列中的前一个项目的结果传递到下一个项目，最终导致 3 的 `number`。

0 + 1 = 1
1 + 1 = 2
2 + 1 = 3
