### WebContainers 获得自己的 API

Stackblitz 早在 2021 年就首次引入了 WebContainers 作为基于 WebAssembly 的“微操作系统”，让您可以在浏览器中运行 Node.js。 尽管有“微型”标签，但这实际上是一件大事。 开发人员首次可以创建快速、可共享且安全的全栈节点环境。

上周，他们用 [WebContainers API](https://blog.stackblitz.com/posts/webcontainer-api-is-here/) 为未洗过的群众带来了这种力量——所以现在任何人都可以直接在他们的 Web 应用程序中构建一个全栈开发环境。

**我为什么要这样做？** 我不知道，也许您想构建一个派对策划应用程序，要求人们正确解决编码挑战以“解锁”他们的邀请。 但由于 Ben Awad 可能已经在努力，您可以使用一些更传统的用例——例如构建交互式编码教程、低代码工具，甚至是直接在浏览器中运行的 [AI apps](https://blog.stackblitz.com/posts/webcontainer-api-is-here/#ai-applications)。

就像 Willy Wonka 的工厂一样，这里唯一真正的限制是您的想象力，因为 WebContainers API 几乎拥有您需要的一切：

*   它在浏览器中运行 npm、pnpm 和 yarn 的本机版本。
    
*   它支持每个主要的 JavaScript 框架，您可以将任何其他非 JS 语言移植到 Wasm。
    
*   API 具有很好的人体工程学特性，例如浏览器内文件系统、开发服务器和节点命令行。
    

**底线：** 过去，我们写过关于退休本地主机并在浏览器中完成所有开发的想法。 虽然未来可能会比这更微妙（#onlyasithdealsinabsolutes），但看到WebContainers、Sandpack、Codespaces等项目推动浏览器的边界向前发展真的很酷。

#### 赞助[Retool](https://retool.com/?utm_source=sponsor&utm_medium=newsletter&utm_campaign=bytes)

您将如何将 console.log 添加到此表达式？

const names = ["ben", "alex", "lynn", "tyler"];
const mappedNames = names.map(name => ({
名字，
公司：“UidotDev”
}));
    

您可以重写该函数以使用块体，但没有人有时间这样做。 因为 `console.log` 返回 `undefined` 我们可以使用逻辑 OR 运算符 (`||`) 内联添加日志。

const names = ["ben", "alex", "lynn", "tyler"];
const mappedNames = names.map(name => console.log(name) || ({
名字，
公司：“UidotDev”
}));
