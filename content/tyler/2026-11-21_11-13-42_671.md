### 框架实地考察

这是一个缓慢的新闻周刊，因此我们将带大家进行一次小规模的实地考察，以访问您可能听说过的三个下一代框架，但可能没有密切关注所有这些框架。

所以系好安全带，和你的朋友呆在一起，记住——当你在进行字节实地考察时，你不仅仅是代表自己，你代表了我们中的所有 152,000。 不要让我[turn this bus around](https://youtu.be/6dncx6O5J4U?t=13)。

**QWIK:** 这个 HTML-First 框架采用“精密延迟加载”的方法来渲染可恢复性而不是传统的水合。 他们在 9 月推出了他们的第一个测试版，以及 Qwik City，他们的 Next.js 元框架。

从那时起，他们发布了一些小更新，并一直在利用他们的内心猎人 S. Thompson 撰写大量内容——今年已经有 27 篇博客文章了！ 该团队显然专注于教育开发人员为什么他们应该让 _Wikness 感到沮丧。_

**ASTRO：**他们的杀手功能是他们的[islands architecture](https://docs.astro.build/en/concepts/islands/)，它将您的UI提取到页面上较小的孤立组件中，并用静态的非交互式HTML代替未使用的JavaScript。

Astro 最初是一个 SSG 框架，开发人员喜欢它的速度和简单性，但从那时起，他们一直在稳步添加更多功能——比如 SSR 支持、携带自己的组件框架的能力，以及他们新的“Markdown Typescript”API。

**Remix:** Remix 最初将自己定位为更多的 React MetaFramework，但如今它将自己描述为一个非常专注于 Web 标准的“全栈 Web 框架”。 它还普及了嵌套路由的概念（Next.js 用户对此表示感谢），并重新强调了对 Web 开发的逐步增强。

在 10 月份被 Shopify 收购后，Remix 团队（由 React Router 的创建者创建）的下一步是让尽可能多的 RR 用户 [start using Remix](https://bytes.dev/archives/153)。

**底线：** 在你问之前，我们是这三个人的忠实粉丝。 如果你今天开始一个新项目，你就不会出错。
