[Vue 3 is finally here](https://github.com/vuejs/vue-next/releases/tag/v3.0.0)
-------------------------------------- --------------------------------------

![Vue 3 release](https://bytes.dev/images/content/vue3.png)

#周一动机

**这不是演习……** 2 年后，Vue 3.0 提交了 2,600 次，实际上是_上周五发布的。 这不是另一个测试版、阿尔法或您（可能）知道的其他 4 个希腊字母中的任何一个。

### 亮点：

**大性能提升：** Vue 现在变得_更小、更快，这要归功于新引入的树摇和完全重写 Vue 的虚拟 DOM，它具有基于编译器的优化的新差异算法。

**Composition API：**这套新的 API 是明确设计的，使 Vue 在大规模应用程序中更容易使用，并具有用于跨组件管理功能和功能的替代语法。

**Teleport:** 一种新组件，它为门户提供本机支持，并简化了使用模态和弹出窗口等元素的工作。

**fragments:** 与 React 一样，Vue 3 现在对片段（又名多根节点组件）有了官方支持。

Vue 3.0 完全用 TypeScript 编写，包括对 TS 用户的增强支持。 查看上周五在 Vue.js 阿姆斯特丹会议上的 [Evan’s keynote](https://youtu.be/Vp5ANvd88x0?t=554) 深入了解 V3。

### 底线

Vue 一直（理所当然地）得到了使用它的开发人员的很多喜爱。 但此版本中的新功能应有助于框架开始将自身定位为大规模应用程序的有吸引力的选择。

重要提示：Evan 说，如果 Vue 3 在第一周的下载量超过 100,000 次，他将合法地将他的名字改为 Evan Vue（k 好吧，我们编造的）。

[Deno releases v1.4.0](https://deno.land/posts/v1.4)
------------------------------------------------

![Deno 1.4](https://bytes.dev/images/content/deno1.4.png)

它在我们眼前生长！

**运行时，欢乐时光……**上周，Node Turncoats Deno团队发布了v1.4.0，并称其为“我们迄今为止最大的功能版本”。 Deno 自 5 月以来一直存在，所以这不是说 _ton,_ 但这仍然是一个非常重要的版本，也是新的 JavaScript/TypeScript 运行时向前迈出的一大步。

### 亮点：

** Web 标准 WebSocket API：** 新添加的 `WebSocket API` 支持允许您通过 WebSocket 协议与远程服务器进行通信，该协议在所有现代浏览器中都可用。

**在文件更改时自动重新启动：** 一个新的集成文件监视器允许您在任何依赖项更改时重新启动脚本。

**集成测试覆盖率：** 如果您使用 `--coverage` 标志在 Deno 测试中运行测试，您将能够找到测试未涵盖的代码。 测试完成后，Deno 将为您打印每个文件的代码覆盖率的摘要。 （您可能想向您团队中沉迷于 100% 测试覆盖率的开发人员隐藏此内容，但牺牲了其他所有内容……）

### 底线

Deno 仍然是一个婴儿，但就像那些父母非常聪明的婴儿之一。 Ryan Dahl 的目标是让 Deno 比 Node.js（Ryan 的第一个出生的运行时）更“简单、现代和安全”。 这些早期版本是否会提供足够的独特功能来让开发人员从 Node.js 中跳转？ 我想我们会看到的。

“Dee-No”听起来更像是你附近的那只大狗的名字，而不是超现代的 JavaScript 运行时，但我们没有制定规则。
