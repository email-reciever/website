### TRPC与醉酒的韵律

唯一比我们更喜欢 2000 年早期说唱参考的人更喜欢 _anything_ 的人可能是 Twitter [aggressively simping](https://twitter.com/alexdotjs/timelines/1441435105910796291) 上的人。 我们尊重喧嚣，所以我们决定看看有什么大不了的。

**什么是 TRPC？** RPC（远程过程调用）是不同程序如何相互通信的网络协议。 早在 2016 年，Google 就开发了自己的版本，称为 GRPC（Gripsy？），它可以做一些很酷的事情，比如客户端和服务器之间的自动生成绑定——但它从来没有真正起飞在浏览器中构建应用程序。

[Enter tRPC](https://trpc.io/docs/v10/) （“TRIP-C”） — 对 RPC 协议的不同看法，该协议使用 TypeScript 为您的应用程序提供端到端类型的安全性，而无需生成模式或代码。 让我们来看看它的一些更酷的功能：

*   **type-safety:** 没有端到端安全性的 ts 应用程序就像非品牌、在黑暗中发光的避孕套——令人兴奋和有趣，但充满了意想不到的后果（有人告诉我）。 TRPC 可帮助您防止不必要的类型错误，并让您安心地完全覆盖。
    
*   **运行时适配器：** TRPC 提供了对 Express、Fastify、Next、AWS Lambda 甚至 Fetch 的开箱即用支持（如果您生活在边缘）。
    
*   **请求批处理：**同时发出的请求可以自动组合成一个请求。 佩尔弗洛德批准。
    
*   **轻量级：** TRPC 没有依赖关系，只有一个“微小的”客户端足迹。
    

**底线：** J-Kwon 教会了我们所有“青少年饮酒非常糟糕”——但幸运的是，TRPC 向我们展示了远程过程调用不必是。

让我们获取这些数据

### [Bright Data](https://brightdata.grsm.io/bytes)是获取公共网络数据的最简单方法

您的团队对这个新应用程序有一个好主意。 问题？ 数据……不容易访问，您不想花费大量的工程时间来获取它，法律/人力资源团队表示您“永远不能再次访问 BlackHatworld”。

这就是 [Bright Data](https://brightdata.grsm.io/bytes) 可以提供帮助的地方。 它们可以从互联网上的任何地方获取公共数据，并通过 JSON 或 Webhooks 轻松消费。 以下是如何：

*   它带有预先构建的网络刮板，您可以开箱即用，或者您可以使用其IDE在JavaScript中构建自己的。
    
*   他们的“unblocker”工具可让您从超级复杂的网站上抓取公共 Web 数据——包括验证码的解决方案。
    
*   如果您不想担心抓取，Bright Data 有自定义的独特数据集，用于 [ecomm](https://brightdata.com/use-cases/ecommerce) 和 [finance](https://brightdata.com/use-cases/financial) 等行业，您可以通过他们的 API 访问。
    

**想要一个实践用例？** 查看 [this video](https://www.youtube.com/watch?v=ASWS7eU5ao4) 其中 Nick White 使用明亮的数据构建了一个应用程序，在 Airbnb 价格下跌时提醒他——尽管 Airbnb 甚至没有定价 API 🔥。

您在寻找什么数据？ 明亮的数据可以为您提供 — [just ask.](https://brightdata.grsm.io/bytes)
