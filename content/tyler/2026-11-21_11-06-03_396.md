### 反应 19 贝塔富矿

React 团队很像我的肛门裂缝，我会在没有消息的情况下花很多年时间，然后它会随机地让我的整个周末脱轨。

上周的 [React 19 beta release](https://react.dev/blog/2024/04/25/react-19) 绝对是一件大事。

它具有以前仅限于 Canary 通道和与“shrext.js”押韵的元框架的所有 React Server 组件功能——但它也引入了大量有意义的非 RSC 功能。

由于我们在过去 3.5 年中写了一篇关于服务器组件的 _lot_，让我们更深入地了解我们对其他 19 款好东西的期望。

**功能 #1 – 动作：** 这是指使用异步转换以允许 React 管理数据提交的生命周期的一组函数。

操作可以帮助自动处理未决状态、错误、表单和乐观更新，这要归功于以下功能：

*   管理乐观更新的新`useOptimistic`钩子，因此您可以在请求提交时向用户显示即时反馈
    
*   `<form>` 通过允许您将功能传递给 `action` 和 `formAction` 道具来帮助您自动管理表单的操作
    
*   在请求开始时开始并在提交最终状态更新时自动重置的挂起状态
    

**功能 #2 – `use`:** 用于读取渲染中资源值的新 React API，如 Promise 或上下文。 这使您可以执行诸如传递 Promise 的值之类的操作，并暂停该组件，直到 Promise 解决。 与钩子不同，`use` 可以有条件地调用。

**Feature #3 – `ref` 作为道具：** 您现在可以将 `ref` 作为功能组件的道具访问，这意味着新的功能组件将不再需要 `forwardRef`。

**底线：** React 19 时代终于来临了，它在这里让您所有最疯狂的数据提交梦想成真。

`<p>` 标签的文本是什么颜色的？

<p class="hello">你好</p>
    
    <style>
身体{颜色：红色； }
P { 颜色：绿色； }
.hello { 颜色：未设置； }
    </style>
    

答案是 `red`，因为 `unset` “取消” `p` 标签的样式，因此它继承自其父级 – `body`。
