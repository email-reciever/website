### 2024 可以将您带到银行的预测

1.  **bun 实现了成为前端默认运行时的目标。 对于大多数开发人员来说，这是不费吹灰之力的选择。 去年 9 月的 v1.0 版本是 Windows 支持和总体稳定性的重要一步，我们打赌 Bun 今年开始成为默认选择。
    
2.  **您最喜欢的 OSS/DevTool 初创公司会死于超过三家。** 我们没有命名，但如果他们已经存在了 2 年多并且没有盈利增长的收入，那么他们就处于危险区域。 尽管有些人可能会在成为一家僵尸初创公司时停留更长时间，在那里创始人解雇了团队中的大部分人，并将 VC 成长公司作为一个单独的独立黑客梦想——这对任何人来说都不是一个好的结果。
    
3.  **AI 将取代无代码/低代码工具。** 事实证明，AI 在构建分析仪表板方面比营销中的 Jim 更好、更快。 像 [Basedash](https://www.basedash.com/) 这样的工具已经使用 AI 来构建一整套自定义内部工具，而其他工具将出现以取代拖放式构建器来创建不依赖于业务逻辑的站点。
    
4.  **Netlify 被 GoDaddy 收购。** 经过多轮裁员，2023 年显然不是 Netlify 的最佳年份。 但有时最好的反弹方法是给自己找一个新的傍大款 GODADDY。 几个月前退役 Media Temple 品牌后，感觉 GoDaddy 可能会回到 Netlify 这样的平台的收购市场。
    
5.  **每个人都会真正弄清楚如何使用 RSC** 构建应用程序**——无需搜索随机的 Twitter 线程。 它比预期的时间长了几年，但这就是 React 生态系统的现状，说到比预期更长的事情需要几年的时间……
    
6.  **react forgot will _not_ ship.** 我们首先在 [issue #78](https://bytes.dev/archives/78) 字节中写了关于 React Forget 的实验记忆编译器 React Forget 的文章。 尽管我们听说他们已经在 Meta 上使用它，但这是一个难以解决的问题，我们仍然怀疑它是否会在 2024 年发货。幸福的关键是期望值低。
    
7.  **没有人会弄清楚“本地优先”的实际含义。**是关于乐观更新吗？ 数据主权？ 新的服务器/客户端范式？ 网络不可知的数据存储？ 所有这些东西？ 我们仍然不确定，但我们将在2024年继续尝试。
    
8.  **2024 是 Linux 的年份在边缘的桌面数据。 将是我们最终开始将数据更接近用户的一年。
    

**底线：** 我不确定 FanDuel 和其他赌博网站是否让您押注年度 JavaScript 预测，但如果他们这样做了，您现在可能想锁定这些。 我想不出2024年更好的投资。

很酷的位
----------

1.  Mayank 写了一篇名为 [React Server Components: the Good, the Bad, and the Ugly](https://www.mayank.co/blog/react-server-components/) 的文章。 我读了两遍，我仍然不确定 Next.js 是应该是克林特·伊斯特伍德还是玩 Tuco 的人。
    
2.  Colin Campbell 写了关于 [Concurrent React, External Stores, and Tearing](https://interbolt.org/blog/react-ui-tearing/) 的文章。
    
3.  查看您的 [2023 Year in code](https://year-in-code.com/)。 由 Graphite 团队创建，它为您的所有 GitHub 统计数据提供了一个个性化的 _Spotify 包装_\ 风格视频。 我刚刚了解到我在使用 `!important` 的开发人员中处于前 1% 的位置。 退房。 \[赞助\]
    
4.  [date-fns v3](https://blog.date-fns.org/v3-is-out/) 刚刚发布，现在是 100% 的 TypeScript，并支持 ESM 对 Node 的支持。 现在每月的下载量也高达 7000 万次。
    
5.   Chris Rybicki 写了关于 [Why JavaScript promises aren’t technically monads](https://rybicki.io/blog/2023/12/23/promises-arent-monads.html) 的文章，这意味着我欠我的继母道歉，因为我们在圣诞节早上进行了一场漫长的战斗。
    
6.  [jQuery 4.0](https://github.com/jquery/jquery/issues/5365) 即将来到您附近的剧院。
    
7.  Ben Visness 写了一篇名为 [I made JSX for Lua (because I hate static sites)](https://bvisness.me/luax/) 的文章。 捂住耳朵，网化，他不是故意的。
    
8.  v8 引入了一个名为 [Maglev](https://v8.dev/blog/maglev) 的快速新型优化编译器。
    
9.  Glauber Costa 敢问，[Is NoSQL dead?](https://blog.turso.tech/is-nosql-dead-fe57c5e4) 不管答案如何，当人们开始写这些类型的关于你的文章时，这通常不是一个_great_标志。
    
10.  西蒙·威利森写了关于 [Stuff we figured out about AI in 2023](https://simonwillison.net/2023/Dec/31/ai-in-2023/) 的文章。 我有点惊讶人们并不担心人工智能“获得了对人肉的品味”的部分，但我想我们都很忙。
