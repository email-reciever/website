### 开发者家庭不和

我们刚刚从堆栈溢出调查中得到了结果，这意味着是时候玩每个人最喜欢的游戏（我刚刚编造的）-_Developer Family Feud 🎊._

我是你的主持人，脚本哈维，我根据调查结果为你创建了 5 个琐事问题。 如果你能在不作弊的情况下把它们弄好，Reddit 的首席执行官向我保证，他将把 API 定价改回过去的样子。 没有压力。

**问题 1：** 最受推崇的编程语言是什么？

**调查说：**生锈。 在 90,000 名受访者中，超过 84% 的人表示他们欣赏这种超快、低级的语言，没有运行时间或垃圾收集器。 不确定这些开发人员中有多少人对 Rust _Foundation_ 有着同样的钦佩，但他们没有问过这一点。

**问题 2：** 将这些前 5 个 Web 框架按最常用到最不常见的顺序排列：Angular、React、JQuery、Next.js、Express 和 Vue。

**调查说：** React、jQuery、Express、Angular、Next.js、Vue。 看到 OG 的持久力总是有点令人惊讶，但更令人惊讶的是，Next 是如何通过 Vue 并在 Angular 的脚后跟上火爆的。 按照这个速度，明年的调查可能会落后于 React 本身的 2 或#3。

**问题 3：** 什么是最付费的技术？

**调查说：** Zig。 调查数据显示，Zig 开发商的平均收入高达 103,611 美元。 唯一的问题是你需要在 Bun 找到一份工作，每周工作 85 小时💀。

**问题 4：** 今天专业开发人员最常见的经验是多少？ （提示：这是一个5年的范围）

**调查说：** 5-9 年。 如果你落入这个范围，这意味着你可能足够年轻，知道谁是冰香料，但太老了，无法理解人们为什么喜欢她的音乐。

**问题 5：** 哪种编程语言在“最受欢迎”_和“最想要”的类别中获得了第一名？

**调查说：** JavaScript，显然。 它不是无缘无故地被称为“编程舞会女王”！

这里有很多误导。 错误发生在我们的 `if (!completed)` 检查中。 `completed` 是一个布尔值，意思是当 `completed` 是 `false` （使它为假）时，我们的代码会抛出一个错误。 相反，我们可以检查 `completed` 是否属于 `boolean` 类型，而不是它是否为假。

if (typeof completed !== 'boolean') {
抛出新错误（“完成是必需的参数”）；
}
