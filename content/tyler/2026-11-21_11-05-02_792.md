### 热规格夏天又回来了

ECMAScript 2024 上个月正式获得批准，这意味着是时候欢迎 JavaScript 系列的一些新功能了。

为了庆祝，我们将举办第四届年度热门规格 Summer™️——友好的庆祝活动，我们消耗足够的酸糖来杀死一匹马，喝一杯爱国的红白蓝红牛鸡尾酒，然后在我的车库中进行视觉任务，以预测哪些新的 JS 功能将 是最有帮助的。

我们将通过在 1-5 的热度等级中对每个新的 ES2024 功能进行评分来保持分数。 让我们潜入。

`Promise.withResolvers()` 是一种新的 Promise 方法，可以更轻松地推迟承诺的决议。 以前，如果你想推迟一个承诺，你必须做这样的事情：

让解决，拒绝；
常量承诺 = 新承诺（（res，rej）=> {
解析 = 水库；
拒绝 = rej;
});
    

但是新的规范使事情变得更容易：

让 { 承诺，解决，拒绝 } = Promise.withResolvers();
    

🔥 评分：4.1/5。 _你永远不会有太多的承诺方法，即使这个方法很小，你很有可能真正使用它。_

下一个功能是二合一。 `ArrayBuffers` 现在可以像这样调整大小：

const buffer = new ArrayBuffer(8, { maxByteLength: 16 });
console.log(buffer.bytelength);
// 预期输出：8
    
buffer.resize(12);
    
console.log(buffer.bytelength);
// 预期输出：12
    

和 `SharedArrayBuffers` 有一个新的 `.grow` 方法：

const buffer = new SharedArrayBuffer(8, { maxByteLength: 16 });
    
if (buffer.growable) {
console.log("sab 是可增长的！");
buffer.grow(12);
}
    

🔥评分：2/5。 _不改变生活，但这应该有助于依赖这些对象（如 Web 容器）的项目使用更少的内存并提高性能。_

最后，`Object.groupBy` 和 `Map.groupBy` 现在允许您添加一个回调函数来转换您的数据。 这对于一些不同的东西很有用，包括组织数据以显示在表格视图中，如下所示：

常量库存 = [
{ 名称：“芦笋”，输入：“蔬菜”，数量：5 }，
{ 名称：“香蕉”，输入：“水果”，数量：0 }，
{ 名称：“山羊”，输入：“肉”，数量：23 }，
{ 名称：“樱桃”，输入：“水果”，数量：5 }，
{ 名称：“鱼”，输入：“肉”，数量：22 }，
];
    
常量结果 = object.groupby(inventory, ({ type }) => type);
/* 结果为：
{
蔬菜：[
{ 名称：“芦笋”，类型：“蔬菜”，数量：5 }，
],
水果：[
{ 名称：“香蕉”，输入：“水果”，数量：0 }，
{ 名称：“樱桃”，输入：“水果”，数量：5 }
],
肉类：[
{ 名称：“山羊”，输入：“肉”，数量：23 }，
{ 名称：“鱼”，输入：“肉”，数量：22 }
]
}
*/
    

🔥 评分：3.5/5。 _这可能不是您每天都会使用的东西，但有更多选择来组织数据总是很好的。_
