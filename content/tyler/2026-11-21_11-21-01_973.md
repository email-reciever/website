悬念正在杀死我

React 18 上线了！ （有点）
--------------------------

React 团队上周发布了他们的 [plan for React 18](https://reactjs.org/blog/2021/06/08/the-plan-for-react-18.html) 并发布了第一个 Alpha 版本。 除此之外，他们还创建了一个仅限受邀的“工作组，为社区准备好在 React 18 中逐步采用新功能”。

我们没有被邀请，但这很酷，因为我们真的不想被邀请。 无论如何，我们已经在一个工作组中，你可能不认识她——她去了另一所高中。

**新东西：**

*   **并发模式 _features_** — 不是一个可能会破坏一大堆应用程序的全有或全无的“模式”，React 18 将带有一组可选的“并发功能”，没有对组件进行重大更改。 您可以使用所有、一些或不使用它们并且很好。 亮点包括 [SSR with selective hydration](https://github.com/reactwg/react-18/discussions/37)（帮助您的应用加载并更快地互动）和 [`startTransition`](https://github.com/reactwg/react-18/discussions/41) （在大屏幕更新期间保持您的应用响应）。
    
*   **suspense** — 希望这能杀死所有“悬念正在杀死我”的双关语。 我再也受不了了。 好的，让我们继续。 _wtf 确实 `<Suspense>` \*实际上\* do?_ tl;dr — 它让您的组件“等待”某些东西（如数据）在渲染之前。 React 18 将为所有 Suspense 功能提供稳定的支持，包括令人兴奋的新内容，例如数据提取 (!!)。
    
*   **新根 API** — `ReactDOM.createRoot` 将替换 `ReactDOM.render()` 作为“启动”您的 React 应用程序的方式。 当您切换到 `createRoot` 时，您将默认获得 React 18 的所有新功能。 不错。

Astro 正在运送网站 _without_ JavaScript (GASP)
--------------------------------------------------

无论您是尝试建立更快的网站还是在苏伊士运河中减少流量，建议都是一样的：_Just less Ship_。

但如今，随着产品经理_用户（？）_需要越来越多的需要[more and more JavaScript](https://httparchive.org/reports/state-of-javascript#bytesJs)的功能，这变得更加困难。 Astro 希望通过其“默认提供零 JavaScript”的新 [static-site generator](https://astro.build/) 来改变这一切。

**TF 是如何工作的？** Astro 将您的整个站点呈现为静态 HTML，并且仅通过 [Islands Architecture](https://jasonformat.com/islands-architecture/) 方法将 JavaScript 运送到您网站需要它的部分。 交互式组件（如图像传送带和购物车）被 Astro 加载 - 但如果用户从未看到交互式元素，他们将永远不会加载运行它所需的 JavaScript。 （这对我来说类似于代码拆分，但这与“我们不提供JavaScript”的环不太相同。）

**但是我的框架呢？** [Calm yourself, Iago](https://www.youtube.com/watch?v=3Gd2ch1FsPU)。 您仍然可以使用任何您想要的框架（以及 TypeScript 或 Taywind 的任何其他 npm 包）来构建您的 UI 组件。 Astro 只是在构建过程中将不需要 JavaScript 的所有内容呈现为静态 HTML。

### 底线

Astro 是由 [Fred K. Schott](https://twitter.com/FredKSchott) 建造的——Snowpack 的创造者，也是 _Using-your-initial-makes-you-smarter_ 理论的明确支持者。 Snowpack 连接很重要，因为 Astro 的“JavaScript On-Demand”方法才有可能，因为这些更新、捆绑较少的构建工具，如 Snowpack、Parcel、Esbuild 等。

随着这些构建工具继续在世界的 Webpack 上占据一席之地，我们不禁想知道——我们最终会说同样的话，关于 Astro 获得顶级 SSG/SSR 框架，如 Next.js 和 Gatsby？
