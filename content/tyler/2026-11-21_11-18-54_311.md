镇上有一个新的服务器警长

ChiselStrike 允许您使用 TypeScript 构建后端
------------------------------------------------

还记得 20 年前，如果您花了几周时间自学 HTML、JavaScript 和 MySQL，您会被认为是“经验丰富的全栈开发人员”吗？

好吧，[ChiselStrike](https://www.chiselstrike.com/) 将同样的能量带回了现代网络。 他们刚刚宣布了一个新的，[open-source serverless platform](https://docs.chiselstrike.com/) 和他们的第一个技巧？ 通过创建 TypeScript 定义，允许您创建一个 RESTful 后端。

因此，准备好告诉贵公司的那个自命不凡的马尾辫后端建筑师，镇上有一位新的服务器警长。

**这是它的工作原理：**

您创建模型 (`/models/User.ts`)

从“@chiselstrike/api”导入{chiselentity}
    
导出类用户扩展轮廓图 {
用户名：字符串；
电子邮件：字符串；
城市：字符串；
年龄：数量；
}
    

然后将文件添加到 `endpoints` 目录 (`endpoints/user.ts`)。

从“../models/user”导入 { user }
导出默认 user.crud('user');
    

就是这样。 Chiselstrike 然后为您生成该端点 - 没有数据库设置，没有数据库连接，没有合规性的担忧，没有查询，只有 API。 这是🪄魔法，但以最好的方式。

🔬 发现错误解决方案 — 由 [PostHog](https://posthog.com/?utm_source=bytes&utm_medium=newsletter) 赞助
--------------------------------------------------- ---------------------------------------------------

通过将 `1` 添加到 `Math.random() * array.length` 的结果中，它将始终大于 `1`，这意味着永远不会选择数组中的第一个元素 (`jersey mikes`)。

函数 getRandomChoice (数组) {
返回数组[math.floor((math.random() * array.length))]
}
    
getRandomChoice(["泽西麦克", "消防站", "地铁"])
