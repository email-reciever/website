一些 OG 容器化

**Wasmer，Boss-Mer...** 经过两年的工作，YC 支持的 Wasmer 刚刚发布了 v1.0 的运行时，承诺让您“在任何客户端上运行任何代码”。

**WTF 是 Wasmer？** 它是一个服务器端 WebAssembly 运行时，它可以支持可以以任何编程语言运行的轻量级容器。 因此，您可以使用您喜欢的任何工具和语言（如 JavaScript、OBVI），然后 Wasmer 将所有内容编译到 WebAssembly。

让我们进入一些使 Wasmer 1.0 甚至……Awesome-R 的新功能。

*   **在任何地方运行：**因为Wasmer使用WebAssembly进行所有容器化，因此它能够创建在每个平台（Linux、MacOS、Windows、Web浏览器等）上运行的“通用二进制文件”，而无需修改。
    
*   **Fast and Safe:** Wasmer 以“近乎本机”的速度运行并自动沙箱应用程序，因此您可以安全地执行不受信任的代码。 由于 WebAssembly 提供了这样一个精益的执行环境，Wasmer 容器可以在 Docker 容器太重而无法工作的地方运行（例如边缘的 IoT 设备）。
    
*   **可插拔的基础设施：**选择您自己的冒险编译器框架，支持Singlepass、Cranelift、LLVM等的开箱即用支持。
    
*   **n00b 友好的 API：** Wasmer 1.0 的主要目标之一是简化其 API，以便对于不太熟悉 WebAssembly 生态系统（也就是大多数开发人员）的开发人员来说很容易学习。

公平点，但作为 [WebAssembly continues to make its way into the mainstream web-dev world,](https://www.youtube.com/watch?v=njt-Qzw0mVY)，我们认为值得熟悉 Wasmer 等工具。

js 提示循环和标签
-------------------------

JavaScript 至少有 20 种不同的方式来循环遍历事物，包括所有的数组方法，如 `forEach`、`map` 和 `filter`； 递归函数； 和 `while` 和 `for`。

对于数组方法和递归函数，您可以使用 `return` 语句提前结束循环，但如果您要在 `while` 或 `for` 循环中使用 return 语句，它将结束整个函数，这并不理想。 相反，如果你想跳到循环的下一个迭代，你可以使用 `continue` 语句，就像这样。

for (let i = 0; i < 10; i++) {
// 跳过 2 的倍数
如果 (i % 2 === 0) {
继续
}
控制台.log(i)
}
// 1、3、5、7、9
    

`break` 语句允许您过早地结束循环，而无需再运行任何迭代。

for (let i = 0; i < 10; i++) {
// 当我们得到 3 的倍数时结束循环
如果 (i % 3 === 0) {
打破
}
控制台.log(i)
}
// 1, 2
    

这两个语句适用于单个循环，但是如果我们需要协调嵌套循环呢？ 如果我们只是在内部循环中使用 `break` 或 `continue`，它将无法停止或跳过外循环。

常数编号列表 = [1, 2, 3, 4, 5]
for (let i = 0; i < numberList.length; i++) {
const inum = numberlist[i]
for (let j = 0; j < numberList.length; j++) {
常量 jnum = numberlist[J]
if ((inum * jnum) % 2 === 0) {
// 如果数字是偶数，则会继续内部循环
继续
}
console.log(inum * jnum)
}
}
// 1,3,5,3,9,15,5,15,25
    

为了让我们从内部循环内部调用外部循环上的 `continue` 或 `break`，我们需要对外循环应用一个标签。 标签就在 `for` 语句之前。 然后，我们可以将标签与 `continue` 语句一起使用。 注意我们添加标签后结果如何变化。

常数编号列表 = [1, 2, 3, 4, 5]
OuterLoop: for (let i = 0; i < numberList.length; i++) {
const inum = numberlist[i]
for (let j = 0; j < numberList.length; j++) {
常量 jnum = numberlist[J]
if ((inum * jnum) % 2 === 0) {
// 如果数字是偶数，则会继续内部循环
继续外环
}
console.log(inum * jnum)
}
}
// 1,3,5
    

下次由于某种原因需要嵌套循环时，您可以使用 label、`break` 和 `continue` 来更好地控制循环的流。
