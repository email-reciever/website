twih — svelte 转 4
----------------------

![Svelte turns 4](https://bytes.dev/images/content/4.jpg)

祝大家生日快乐

**当我们上周四用馅饼塞满脸**时，我们停下来感谢 Svelte，它是 4 年前在感恩节上首次发布的。

当创作者（和兼职洗发模型）里奇哈里斯在2016年首次宣布Svelte时，他将其称为[“a framework without the framework.”](https://svelte.dev/blog/frameworks-without-the-framework)，这是一种非常元的说法，即Rich认为框架比构建实际代码更能构建您的想法，因为 框架的膨胀通常会减慢应用程序的速度。

因此，Rich 构思了一个勇敢的 _svelte_ 新世界，其中框架没有在浏览器中运行，而是将您的代码转换为不需要随附运行时的低级 Vanilla JavaScript。 这样，您仍然可以获得框架的好处，但您的应用程序会更轻、更快。

快进 4 年，这仍然是 Svelte 背后的驱动理念，以及这些 **3 个主要卖点**：

1.  没有虚拟DOM——因为Svelte直接操纵DOM。
    
2.  在没有样板的情况下用HTML、CSS和JavaScript编写组件。
    
3.  在没有状态管理库的情况下将 [“true reactivity”](https://www.youtube.com/watch?v=AdNJ3fydeao) 带到 JavaScript。
    

### 底线

4 年后，Svelte 仍然位于 JavaScript 框架流行谱上的“仅限时髦开发人员”和“有希望的范式转变”之间。 这是一个备受推崇的项目，拥有忠实的追随者，但（客观地）仍然没有获得很多主流采用。

那么Svelte的下一步是什么？

Rich 和团队专注于改进开发人员体验，使开始变得更加容易，同时也增加了框架的多功能性。

我们很高兴看到未来 4 年将发生什么，我们将在 2024 年感恩节再次入住。

以下是我对是否应该使用 `.reduce` 的看法。

1）我是否将数组转换为另一个数组
只是通过删除一些元素？ 使用 .filter
    
2）我是否将数组转换为另一个数组？ 使用 .map
    
3）我是否将数组转换为另一个数组以外的东西？ 使用 .reduce
    

现在我们了解了 `.reduce` 的用途，让我们看一下 API。 如果这令人困惑，请不要担心，强大的力量会带来很大的最初混乱。 谷歌“减少 JavaScript”并阅读结果的前两页。 这将是值得的 - 承诺。

我将首先向您展示如何完成将数字数组汇总为单个整数的目标，然后我们将完成它。

函数和 (arr) {
return arr.reduce((总数, num) => {
返回总数 + 数字
}, 0)
}
    
sum([1,2,3]) // 6
sum([5,5,5]) // 15
    

请记住，这里的目标是将传递到 `sum` 函数的数组转换为单个整数，这是数组中所有数字的总和。

您会注意到的第一件事是我们传递了 `.reduce` 两个参数。 第一个是将为数组中的每个元素调用的函数。 第二个是我们所说的“初始值”。 在我们的示例中，因为我们将所有数字相加，因此我们希望初始值为 0（因此我们不会遇到任何 NaN 问题）。 如果我们创建一个新对象，初始值将是一个空对象。 如果我们正在创建一个数组，它将是一个空数组。

接下来，我们需要找出传递给 `.reduce` 的函数的参数是什么。 在我们的示例中，我们将它们命名为 `total` 和 `num`。 请记住，将为数组中的每个元素调用此函数。 我们命名它 `num` 的原因是因为我们减少了一个充满整数的数组，并且对于每次迭代，`num` 将是数组中的任何数字。 我们可以在下面的示例中看到这一点。

函数和 (arr) {
return arr.reduce((总数, num) => {
控制台.log(num)
}, 0)
}
    
总和([1,2,3])
// 1
// 2
// 3
    

这是有道理的。 接下来我们需要弄清楚的是`total`。 这就是它变得有点麻烦的地方。 在我们的示例中，`total` 最初将为 0，因为这是我们将初始值设置为的值。 之后，`total` 将是之前的迭代返回的任何内容。 我们可以在下面的示例中清楚地看到这一点。

函数和 (arr) {
return arr.reduce((总数, num) => {
console.log（总计）
返回日期.now()
}, 0)
}
    
总和([1,2,3])
    

我们的回调函数第一次运行时，它将 0 记录到控制台。 同样，这是因为我们将初始值设置为 0。然后，对于每次函数运行的新时间，我们在控制台中获得一个时间戳，因为这就是我们要返回的内容。

现在让我们借鉴这些知识，回顾我们最初的解决方案。

函数和 (arr) {
return arr.reduce((总数, num) => {
返回总数 + 数字
}, 0)
}
    
总和([1,2,3])
    

第一次运行回调函数时，`total` 将为 0，`num` 为 1。然后，下一次迭代，`total` 将是 1，num 将是 `2`。 原因 `total` 是一是因为我们之前返回 `0 + 1`。 然后，`total` 将是 3，`num` 将是 3。然后，数组中没有更多的元素，所以返回的是 6。我们可以在下图中看到这一点。

初始值：0
    
第一次迭代：
总计：0
编号：1
    
第二次迭代：
总数：1
编号：2
    
第三次迭代：
总数：3
编号：3
    
数组中没有更多的元素，返回 3 + 3，即 6。
