### 联合状态级联

我的 Div-Lords 同胞……我们今天聚集在这里，回顾 2023 年 [State of CSS](https://2023.stateofcss.com/) 调查的结果，并讨论这种伟大语言的过去、现在和未来。

可悲的是，CSS 世界并没有像 JavaScript 生态系统那样滋生那么多的戏剧和部落主义——但不用担心，还有很多话要说。

以下是我们最大的5个收获：

**1\。 开发人员喜欢 CSS 变量。** 连续第四年，自定义属性在所有 CSS 功能中排名第一，用于“最高使用率”和“最高意识”。 事实证明，开发人员真的很喜欢重复使用相同的值，而不是在他们的代码库中使用 36 种“Lightgrey”（感谢设计团队🙄）。

但是，我们第一次看到变量和其他流行的CSS特性之间的_gap_开始关闭，因为…

**2\。 `gap` 物业的表现强劲。** 它的使用量已从 2021 年的 55% 的受访者增长到今年的 90%。 我认为每个人都很高兴我们不必再做 `:last-child { margin-left: 0 }` 只是为了获得均匀的间距 🙏。

**3\。 Css-in-JS 正在下降。** 一旦球的美景，像样式组件、情感和针迹（不再被维护）等库在过去几年中真的消失了。 但是 [Panda CSS](https://panda-css.com/) 正在尽最大努力以更快的性能、类型安全性和 RSC 兼容性引领 CSS-in-JS 卷土重来。

**4\。 CSS 技巧在 CSS 学习资源方面仍然是顶级狗**，而且还不是很接近。 尽管事实上它现在贴满了数字海洋横幅（去年收购了该网站），并且自 4 月以来就没有上传新内容。 _看看他们是如何屠杀我的男孩_😭的。

**5\。 我们都想要和平与和谐**——在浏览器之间。 在过去的几年里，我们都看到 Web 平台添加了大量出色的 CSS 功能，但调查中 CSS 开发人员的第一大痛点是缺乏所有这些功能的浏览器兼容性。

**底线：** 这是一个很难解决的问题，但如果你选择我为 CSS 镇的市长，我保证每个浏览器都会支持 `:has()` 选择器和 CSS 嵌套——我们所有的饮水机都将充满苏打水。 #VoteFortyler
