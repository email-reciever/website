## Cool Bits

1.  TkDodo saw his “most CoolBits” lead shrinking, so he decided to get back in the game and write about [reliable query prefetching with TanStack Router](https://tkdodo.eu/blog/reliable-query-prefetching-with-tanstack-router).
    
2.  Boshen added [support for the React Compiler to OXC](https://oxc.rs/blog/2026-08-18-react-compiler-support), meaning your dreams of having a bare-metal Rust dev environment in Vite are finally a reality.
    
3.  If your React Native app feels slow, open Expo Observe, which monitors real-user metrics like cold starts and time-to-interactive, and will tell you exactly which build caused the regression. [You get 100k events a month for free, so try it today](https://try.expo.dev/observe-ga-bytes). \[sponsored\]
    
4.  Vercel Labs created its own [minimalist agent harness](https://fx.sh) called `fx`.
    
5.  Rapha Amorim [created `oj`](https://rapha.land/introducing-oj/), a bundler with Vite’s API and performance that uses way less memory.
    
6.  It only took 60 years, but System R developers are finally having their moment now that everyone is talking about WALs (write-ahead logs) and object storage, including Chroma, who wrote [a very long post](https://www.trychroma.com/engineering/wal3) about how they built theirs.
    
7.  Agents are writing more of your code, and that’s fine — the trouble is your release process still moves at human speed. [LaunchDarkly’s CodeControl](https://srv.buysellads.com/ads/long/x/THMQS3SPTTTTTTDROCFCWTTTTTTGUZ6K2VTTTTTTN3FV5BETTTTTTLSVKJIFKI4527AWN2ZBC2SC4MIDGH3MPEQJZQ4E?cid=391666) enables teams to roll changes out gradually and helps automatically revert issues in production. \[sponsored\]
    
8.  Formisch, a framework-agnostic, type-safe, modular form library (try saying that 10 times fast), just [released version 1.0](https://formisch.dev/blog/formisch-v1/).
    
9.  [Bun 1.4 is out](https://bun.com/blog/bun-v1.4#what-s-new), featuring better Node.js compatibility, significantly less memory usage, and a bunch of new built-in APIs.
    
10.  React added a [new API to detect whether your code is running in the browser](https://react.dev/reference/react-dom/browser): `use(browser(reason?))`. I’m Ron Burgundy?
