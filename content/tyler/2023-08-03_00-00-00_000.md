### 灯光、相机、顺风

耳机麦克风一直是被低估的电源移动。

因此，在上个月的 [Tailwind Connect](https://tailwindcss.com/blog/2023-07-18-tailwind-connect-2023-recap) 主题演讲中，很高兴看到 Adam Wathan 穿着他父亲最好的西装外套和一个令人难以置信的微妙耳机麦克风走出舞台，这会让 Nsync 男孩感到自豪。

Adam 谈到了 Tailwind 的历史，分享了一些令人兴奋的增长数据（每月 2500 万次下载🤯），并演示了一个名为 Catalyst 的新的“完全组件化”的 React UI 套件，它仍然是一个 WIP。

但最令人兴奋的部分是当他引入**氧化物**时——Tailwind CSS 引擎的下一次发展，它将使该框架更像是一个“多合一的 CSS 处理工具”。

它通过集成 [Lightning CSS](https://lightningcss.dev/) 来实现这一点，这是由 Devon Govett 和 Parcel 团队创建的基于 Rust 的 CSS 解析器、转换器、捆绑器和迷你器。 Tailwind v3.4 将很快推出氧化物，它应该立即提供三个显着的好处：

*   ** 一个更统一的工具链，**因此您不再需要安装 PostCSS 或 AutoPrefixer 之类的其他工具。 诸如 vendor 前缀、语法转换和导入其他 CSS 文件之类的内容将正常工作。
    
*   **提高了性能，** 因为 Lightning CSS 是用 Rust 编写的，而且整体速度非常快。 使用氧化物的实际顺风项目的构建时间已经下降了 50%。
    
*   **简单的配置**具有自动内容检测功能，这意味着您不再需要配置模板文件的路径。
    

**底线：**您通常不会看到 200 人付出真钱去参加 CSS 框架的会议/聚会，但 Tailwind 是一个鼓舞人心的项目——这就是为什么我只是在 [this bad boy](https://www.ebay.com/itm/304992555080?_trkparms=amclksrc%3DITM%26aid%3D1110006%26algo%3DHOMESPLICE.SIM%26ao%3D1%26asc%3D251752%26meid%3Dd686401d91e64fcb864eadde1f3f5de3%26pid%3D101224%26rk%3D3%26rkt%3D5%26sd%3D304604278214%26itm%3D304992555080%26pmt%3D1%26noa%3D1%26pg%3D2047675%26algv%3DDefaultOrganicWebV9BertRefreshRanker&_trksid=p2047675.c101224.m-1) 上进行了中标。

记录什么？

函数 getport(url) {
const { port } = 新网址(url);
    
如果（端口 === '80'）{
console.log("你使用的是默认端口");
}
    
如果（端口 === '443'）{
console.log("您使用的是默认的安全端口");
}
    
控制台.log(`You are running on port "${port}"`);
}
    
getport(`http://example.com:80`) // 你在端口“”上运行
getport(`http://example.com:8080`) // 你在端口 "8080" 上运行
getport(`https://example.com:443`) // 你在端口“”上运行
getport(`https://example.com:3000`) // 你在端口“3000”上运行
    

JavaScript 中的 `URL` 构造函数即使明确提供了默认端口，也会剥离默认端口。 由于端口 `80` 是 HTTP 的默认值，而端口 `443` 是 HTTPS 的默认值，因此该端口会从 URL 中剥离，从而导致一个空字符串。 在您可能不需要知道的JavaScript Quirks下将此归档，但可以为未来的调试节省数小时。
