## Cool Bits

1.  Kirupa created [an interactive post](https://www.kirupa.com/ai_fundamentals/riemann_hypothesis.htm) to help normies understand the Riemann hypothesis.
    
2.  Luke Edwards created [Tidy, a Prettier-style code formatter written in Rust](https://tidy.lukeed.com). Giving @lukeed AI is like letting prime LeBron play on 8-foot rims.
    
3.  Build a Black Friday price tracker this week. Apify’s [E-commerce Scraping Tool](https://apify.com/apify/e-commerce-scraping-tool?fpr=fireship-bytes) returns prices, availability, and ratings from Amazon, Walmart, and eBay as JSON. Code BYTES gets you $25 in credits. \[sponsored\]
    
4.  Leonardo Galante created an [oxlint plugin called “slimdeer”](https://github.com/lndgalante/oxlint-plugin-slimdeer) that finds images in your codebase that could be significantly smaller with the same visual quality and then fixes them for you.
    
5.  Adeel Raza created [Hyper Elements](https://www.hyperelements.dev/), a set of React components that can render to PDF, email, images, or the DOM, keeping the “write once, run anywhere” React renderer dream alive.
    
6.  [A new “independent” browser called Ladybird just dropped](https://ladybird.org/posts/alpha/) and no, it’s not a Chromium fork. It has a brand-new engine written from scratch in C++ and Rust with a dual Hemi, and a pair of “Truck Nutz” mounted to the hitch.
    
7.  Build software factories that work for humans.
