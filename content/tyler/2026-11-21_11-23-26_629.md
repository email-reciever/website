装饰所有的东西

**本月晚些时候，** 规范奖学金 (TC39) 将讨论针对 JavaScript 类的装饰器的新第 2 阶段提案。 如果您不熟悉，装饰器是扩展 JavaScript 类的提案。

**等等，我以前没听过这首歌吗？**你肯定听过。 TC 团伙已经在 _5 年间断断续续地讨论 JavaScript 装饰器的不同迭代。 自然，一些开发人员已经厌倦了等待，所以他们继续将它们整合到各种 JS 框架和库中（看着你，Mobx）。 Babel 7、TypeScript 和 Angular 基于先前拒绝的 TC39 提案，EverythingIsFine.gif 的所有要素装饰器。

**那么这次有什么不同？** 这个最新的提案比以前版本的装饰器更简单，范围更有限。 根据提案的自述文件，这些装饰师将“总是简单地包装他们正在装饰的东西，而不是进行其他转换”。 理论上，这应该更容易避免过度使用装饰器并抽象出太多的代码库（在 TypeScript 和其他框架中使用装饰器时，这是一个常见的抱怨）。

### 底线

如果只是为了在整个 JavaScript 生态系统中提供更高的一致性，似乎很可能会在不久的将来将某种形式的装饰器添加到 ECMAScript 标准中。 一些开发人员会讨厌这一点，因为他们过去曾与装饰师有过糟糕的经历，而另一些开发人员会在经过多年的多填充等待后欢迎它。 不管你站在哪一边，只要[remember this sage advice](https://www.youtube.com/watch?v=0la5DBtOVNI)。

[Playwright releases a major, minor update](https://github.com/microsoft/playwright/releases/tag/v1.4.0)
------------------------------------------------ ------------------------------------------------

![skakespeare](https://bytes.dev/images/content/skakespeare.jpg)

另一位对无头执行感兴趣的剧作家

**测试或不测试……** 那是（总是）问题。 Playwright 上周发布了 v1.4，尽管没有重大的重大变化，但由于添加了三个新的、高度请求的功能，这对 Microsoft 流行的 Node.js 测试库来说是一个相当大的更新。 以下是细分：

1.  **新的 `playwright-cli`:** Playwright 的新 CLI 可让您记录用户交互以生成 Playwright 脚本、模拟设备和配色方案、生成页面截图、在 Chromium、Firefox 和 Safari 中打开页面。 这应该可以帮助您在单击时更轻松地生成 e2e 测试脚本。
    
2.  **视频截屏：** 这个实验性的新功能允许您记录脚本的视频，以在任何浏览器和无头模式下的任何浏览器和任何平台上检查无头执行情况。
    
3.  **新客户端/服务器有线协议：** Python、C#和其他语言绑定的新线协议，将为那些希望在非节点环境中使用PlayWright的人提供更大的支持。
    

### 底线

去年，当 Puppeteer 团队的一些创始成员移居微软并推出 Playwright 时，很容易看出这两个库之间的相似之处。 一些开发人员甚至将剧作家称为“跨浏览器木偶师”，因为这是 Playwright 唯一真正的显着特征。 但是这个最新版本中的新功能和功能应该可以帮助 Playwright 在众多其他测试和浏览器自动化工具中脱颖而出。

🔥 提示 - 在 JavaScript 中获取当前 URL
----------------------------------------

函数 getCurrentUrl () {
返回 window.location.href
}
    
// 示例
const url = getCurrentURL()
    
网址 // https://ui.dev/get-current-url-javascript/
    

够简单的。 如果您在浏览器中使用 JavaScript，您可以使用 `window.location.href` 获取完整的当前 URL。 我认为还值得注意的是，`window.location` 上有许多不同的属性，这些属性也可能对您有用。

假设这是我们当前的网址

    https://ui.dev/get-current-url-javascript/?comments=false
    

这些都是 `window.location` 给我们的属性。

常数{
主机，主机名，href，源，路径名，端口，协议，搜索
} = window.location
    
主机 // "ui.dev"
主机名 // “UI”
href // "https://ui.dev/get-current-url-javascript/?comments=false"
原点 // "https://ui.dev"
路径名 // "/get-current-url-javascript/""
端口 // ""
协议 // "https:"
搜索 // "?comments=false"
