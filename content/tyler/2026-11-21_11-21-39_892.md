Sveltekit 进入公开测试版
-----------------------------

![Boat](https://bytes.dev/images/content/boat.png)

它正在尽力而为

**与大牌 OSS 作者一起工作有时听起来有点粗鲁。

好吧，如果你去年在纽约时报与里奇哈里斯一起工作时建造了一个 [Covid Tracker](https://www.nytimes.com/interactive/2020/us/coronavirus-us-cases.html)，你已经知道斯维尔特会参与其中。 但是，当这些开发人员被迫有机会_使用当时未完成的 [SvelteKit](https://kit.svelte.dev/) 框架时，他们得到了另一个有趣的曲线球。

公平地说，它奏效了。 虽然 Rich 确实承认这种 Dogfood-on-Steroids 并不是最佳实践，但谁没有在 2020 年春季争先恐后？

快进一年，Sveltekit 上周刚刚宣布了它的 [public beta](https://svelte.dev/blog/sveltekit-beta)。

**它称自己为“Svelte的Next.js”，**因为Sveltekit也是构建使用灵活的基于文件系统路由的Web应用程序的“元框架”——这不是因为它的母公司已经筹集了6100万美元的资金。 Sveltekit 还处理所有无聊的东西，例如代码分割、离线支持和客户端提供的服务器渲染视图。

它的秘密是什么？ 在去年 10 月的在线 Svelte 峰会上，Rich [stared deeply](https://www.youtube.com/watch?v=qSfdtmcZ4d0) 融入我们所有的灵魂并宣扬 [Snowpack](https://www.snowpack.dev/) 的福音 - 告诉我们如何在 Sveltekit 的引擎盖下使用这个超快前端构建工具是一种改变游戏规则的替代品，可以替代 Webpack 等更重的捆绑器 和包裹。

众所周知，这个行业发展迅速。 自从 4 个月前 Svelte Summit _Checks Notes_ 以来，Rich 已经重生，现在发现自己在 Evan You's House [Vite](https://vitejs.dev/)。 Rich 表示，重构启蒙是因为 Vite 内置的 CSS 代码分割和 SSR 功能更接近 Sveltekit 的特定要求。

Rich 和 Evan 是在 Twitter 上分享抨击 React 的爱好的 BFF 也可能不会受到伤害。

### 底线

现在，有一个漂亮的 [big gap](https://2020.stateofjs.com/en-US/technologies/front-end-frameworks/) 的兴趣（非常高）和苗条的使用（还没有那么高）。 让 Sveltekit 成为轻松开始使用 Svelte 的首选方法应该有助于通过使 Svelte-World 更加平易近人来缩小这一差距。

香草精华——CSS-in-JS的新方法
---------------------------------------

![Mark](https://bytes.dev/images/content/mark.png)

好的停止，协作和聆听

**直接离开墨尔本……** 是一种新的、改进的方法来恢复 Meme Lord 和 CSS 模块的创建者之一，[Mark Dalgleish](https://twitter.com/markdalgleish)。

[Vanilla-extract](https://github.com/seek-oss/vanilla-extract) 是一个全新的库，它称之为“CSS 模块的精神继承者，但具有散列的 CSS 变量”。 它也是我们在一分钟内听到的新开源库的最佳名称之一（您可以将男孩从模因中取出，但您不能从男孩中取出模因）。

V-E（正如酷孩子所说）允许您使用本地范围的类名和CSS变量在Typescript或JavaScript中编写样式，然后在构建时生成静态CSS文件。

在这一点上，我们对香草提取了解不多，但这里还有一些亮点，由 Mark 的 [announcement tweet](https://twitter.com/markdalgleish/status/1375316120530382848) 提供：

*   在打字稿中的零运行时样式表
*   在标准CSS上的最小抽象
*   适用于任何前端框架
*   本地范围的类 + CSS 变量
*   高级主题系统

### 底线

由于香草提取物是“CSS 模块的精神继承者”，我们开始思考——这份时事通讯的精神继承者是什么？_
