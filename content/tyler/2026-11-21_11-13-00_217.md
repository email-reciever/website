### 电子时代

上周我们见证了两个重要的里程碑：Electron 正式转为 [10 years old](https://www.electronjs.org/blog/10-years-of-electron)，Taylor Swift 正式开始了她的 _ERAS_ 巡演。

由于我们是极少数（但自豪）的一小部分人，他们深深地关心这两件事，让我们放大并仔细看看电子时代。

**早期：** 电子最初被称为原子壳，因为它最初是作为 GitHub 的 Atom 编辑器 (RIP) 的主干构建的。 但由于其强大的关键创新——捆绑 Node.js 和 Chromium 来为 HTML、CSS 和 JavaScript 等 Web 技术创建桌面运行时，该框架很快扩展到了 Atom 生态系统之外。

**辉煌岁月：** 让 Web 开发人员构建跨平台桌面应用程序的简单方法就像将免费的红色围巾送给一个满是 Swifties 的体育场——开发人员为此疯狂。 在 2016 年推出 V1 后，Electron 迅速成为小型初创公司和大型企业应用程序的首选桌面框架，如 Slack、Discord、VS Code 和 Notion。 在 2017-2020 年的高峰电子时代，其每周 NPM 下载量增长了 10 倍。

**现在：** 在过去的几年里，我们看到了 Electron 的增长平台，主要是因为它有据可查的性能问题。 事实证明，Electron 的 DX（捆绑节点和 Chromium）最好的事情是 Electron 的 _UX_ 最糟糕的事情——正如我的笔记本电脑风扇在我有松弛和不和谐的情况下所证明的那样。

**未来：** 此时，Electron 团队似乎主要专注于通过定期释放节奏和最小的破坏性变化来保持稳定性。 对于每天使用 Electron 应用程序的数百万最终用户来说，这是个好消息。 我们还看到了来自 Tauri、Flutter 和 Expo/React Native 等较新框架的许多创新，这些框架建立在 Electron 的跨平台愿景之上。

**底线：**在Javascript-land中，与17岁相关的流行歌星几乎一样罕见。这就是为什么Electron和Taylor总是可以说， 让整个地方闪闪发光。”_
