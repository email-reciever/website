Angular 10 正在从 IE 继续前进
------------------------------

![Woody dropping IE](https://bytes.dev/images/content/woody.png)

我，12年前。 角度，上周

**他们成长得如此之快……** Angular 上周年满 10 岁（版本），并决定是时候成长并从 Internet Explorer 9、10 和 IE 移动。 目前，他们只是“弃用了支持”（无论这意味着什么），但他们承诺在未来的版本中完全放弃支持。

**来自文档：**“支持像这样的过时浏览器会增加捆绑包大小、代码复杂性和测试负载，并且还需要花费在改进框架上的时间和精力。”

**此版本的其他一些亮点：**

*   **新日期范围选择器：** Angular Material 现在包括一个看起来很光滑的新日期范围选择器。 ​
*   **新的严格项目设置：** 启用此新的可选 `strict` 标志使用一些新设置初始化您的项目，这些设置可提高可维护性并帮助您提前捕获错误。 ​
*   **警告 CommonJS 导入：** 每当您的项目拉入包含 CommonJS 打包的捆绑包时，您现在会收到警告，这通常会导致更大、更慢的应用程序。

### 底线

像 Ed Sheeran 一样，Angular 最受欢迎的日子可能是它的幕后黑手。 仇恨者会说这是因为它的相对复杂性，这为框架的新开发者创造了一个陡峭的学习曲线。 不过，等到他们看到我带着我全新的 Angular 10 日期范围选择器来到俱乐部。

“JavaScript：前 20 年”
--------------------------------

**我们是如何到达这里的……** 和 `we` 我的意思是，`the JavaScript ecosystem`。

本月早些时候，ACM Journal [published a 189-page paper on the history of JavaScript from 1995-2015](https://zenodo.org/record/3707008) 由最优秀的两个人撰写：JavaScript 创作者 Brendan Eich 和 Allen Wirfs-Brock（基本上是 JavaScript 的 Walter Isaacson）。 Ironically, this definitely took longer to write than JavaScript itself.

**开场白让我们着迷：** “在 Netscape 中创建的 Sidekick 脚本语言如何在十天的黑客中最终成为世界上使用最广泛的编程语言。” 如果你没有进一步做，这是本文其余部分的 TL;DR：

*   **第 1 部分 – JavaScript 的起源：** Brendan 在 1995 年最初开发 JavaScript 的方式和原因，Netscape 想要它做什么，以及它演变为做什么。
    
*   **第 2 部分 – 创建一个标准：** TC39 如何成为 JavaScript Jedi 委员会并帮助 JS 在 2000 年代初期的 Netscape 衰退中幸存下来。
    
*   **第 3 部分 – 改革失败：** 讨论了修改 JavaScript 的失败尝试以及它在 2000 年代中期给社区带来的问题。 如果他们从来没有想出来，我们现在都会成为 Flash 开发人员吗？
    
*   **第 4 部分 – 现代化 JavaScript：** 我们如何最终获得 ECMAScript 2015 和坚实的 JavaScript 基础来构建（希望）未来几十年的网络。

const leo = new Animal('Leo', 'Lion')
    

在我们的 `Animal` 构造函数中，我们依靠 JavaScript 为我们创建一个 `this` 对象。 但是，为了让它知道要做到这一点，我们需要使用 `new` 关键字调用该函数。

### JavaScript 的原型

每当您在 JavaScript 中创建函数时，该函数上都有一个 `prototype` 属性，其值为对象。 您放在该对象上的任何属性（或方法）都将可用于函数的每个实例。 这意味着您可以使用函数的 `prototype` 属性在函数的所有实例之间共享方法。

this.energy = 能量
}
