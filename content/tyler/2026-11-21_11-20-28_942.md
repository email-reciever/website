打字稿新闻转储
---------------------

TypeScript 团队显然知道 Kanye 最终将在昨天发布 Donda，因此他们决定上周在“Ye”接管新闻周期之前发布一些关于我们的公告。

他们是怎么知道的？ 好吧，TypeScript 是由 Microsoft 创建的，它也恰好是 Windows Media Player_and_ Microsoft Zune 背后的公司。 所以，是的，他们在音乐行业有一些非常紧密的联系，显然。

本周最大的 TS 新闻是 [TypeScript 4.4 release](https://devblogs.microsoft.com/typescript/announcing-typescript-4-4/)，它添加了一些不错的功能（这些功能可能需要也可能不需要博士来理解），例如：

*   ** 混淆条件和判别项的控制流分析** — 这意味着它更了解变量的类型，而无需使用 `if` 语句。 （埃隆马斯克非常喜欢这个功能，他考虑以它命名他未来的孩子。）
    
*   **Template 文字和符号索引签名** — 让您使用符号和模板文字类型作为对象键。
    
*   **默认为 catch 变量中的 `unknown` 类型** — 尝试帮助您捕获 `try/catch` 子句中的类型错误（看看我在那里做了什么？）
    

tl;dr — v4.4 将帮助您编写更安全、更无错误的代码。

他们还宣布了 [brand new website](https://devblogs.microsoft.com/typescript/announcing-the-new-typescript-homepage/) 以帮助人们更快地使用 TypeScript。 它有更多的例子，完全重写的文档，改进的导航。 可悲的是，它有 [no dark theme](https://devblogs.microsoft.com/typescript/announcing-the-new-typescript-homepage/#comment-212)，这使其完全无法使用。

最后，虚拟 [TSConf](https://tsconf.io) 将在两周内出现——如果您想直接从核心团队听到最新的 TypeScript 新闻（或者询问他们是否有任何关于 Zune 重新启动何时发生的内部信息）。

SWR 已准备好迎接黄金时段
----------------------------

上周五，SWR 终于用 V1.0 的 React Hooks 数据提取库祝福我们——在它首次由 Vercel（其 Creator™）开源两年后。

**快速审查：** SWR 代表 `stale-while-revalidate`，指的是库对数据提取的“缓存和请求”方法。 我们不太清楚 SWR [squiggly eyebrow logo](https://swr.vercel.app/) 背后的更深层次的含义，但话又说回来，我们从来没有真正进入过现代艺术。

**这是SWR 1.0的新增功能：**

*   一个新的 `fallback` 选项，您可以在其中提供任何预取数据作为所有 SWR 挂钩的初始值。 这应该有助于 SSR、SSG 和/或数据模型进行测试。
    
*   一个新的 `provider` 选项，可让您自定义 SWR 的全局数据缓存，以像这样 [partial mutation helper](https://swr.vercel.app/docs/advanced/cache#mutate-multiple-keys-from-regex) 的 API 中构建独特的功能。
    
*   “不可变模式”是一种新的辅助钩子，它使资源更容易标记为不可变，并且只发出一次必要的请求。
    

作为奖励，SWR 1.0 已正式缩小到有趣的尺寸——这要归功于 41% 的核心和 52% 的安装尺寸更小。

**底线：** 现在，SWR 不像 React Query 和 RTK Query 等其他数据获取解决方案无处不在。 但是_might_改变有两个原因：

1.  这些新的SWR功能中的许多功能都旨在帮助该库利用并发渲染和悬念等新的React 18功能。
2.  这是一个Vercel产品，Guillermo是我的父亲。
