## Cool Bits

1. Lovable 团队写了一篇关于 [如何将 lovable.dev 从 Next.js 迁移到 TanStack Start](https://lovable.dev/blog/how-we-migrated-lovable-dev-away-from-nextjs) 的文章。显然，编码代理喜欢的不仅仅是紫色渐变，还有引发框架争论。

2. Matt Lenhard 写了一篇关于 [令牌经纪人](https://vectoral.com/blog/who-are-the-token-brokers) 的文章，他们通过出售数千万个来自折扣优惠的 LLM 令牌来赚取差价。当然，我们绝对不处于 AI 泡沫中，你为什么这么问？

3. 只有白痴才会写手动测试——像 Notion、Dropbox 和 LaunchDarkly 这样的现代工程团队使用 Meticulous 来维护 e2e UI 测试，涵盖 [你网页应用的每一个边缘情况](https://www.meticulous.ai/?utm_source=bytes\&utm_medium=newsletter\&utm_campaign=26q3\&utm_content=secondary)。 \[sponsored]

4. Tyler Sticka 分享了一个使用 [CSS 中的 `paint-order` 属性](https://tylersticka.com/journal/improved-css-text-stroke/) 的一个很好的例子。

5. 正好在此时，Gareth Heyes 撰写了关于 CSS 的文章，称其为 [你收件箱中的炸弹](https://portswigger.net/research/css-the-bomb-inside-your-inbox)，这使得它容易被攻击者利用。这就是为什么我选择不去深入学习 CSS 的原因。风险太大。

6. Expo 团队分享了 [5 条 React Native 团队的 OTA 更新最佳实践](https://try.expo.dev/ota-best-practices)，这可能会在你下次将 bug 发布到生产环境时挽救你的... 背部。它就是 NYC 交通应用程序能够在 90 秒内从重大 bug 报告到部署修复的原因。 \[sponsored]

7. [pnpm 12 RC](https://pnpm.io/blog/whats-different-in-pnpm-12) 刚刚发布，其头条功能是现在它是用 Rust 编写的。Zig 团队：你有 24 小时的时间来响应。

8. Dave Rupert 创建了 [MicroLighter](https://daverupert.com/2026/08/microlighter/)，一个小型的客户端语法高亮器，使用 CSS Custom Highlights API。

9. [Convex 获得 5700 万美元 B 轮融资](https://news.convex.dev/convex-raises-57m/) 以继续为你（和你的代理）构建最好的响应式后端平台。并且它全部都是 100% 有机的 TypeScript。 \[sponsored]

10. Shawn Walton 在 Yelp 工程博客上写了关于他的团队如何 [将一个大型 Flow 单仓库迁移到 TypeScript](https://engineeringblog.yelp.com/2026/08/migrating-a-large-flow-monorepo-to-typescript.html)。我会给它评为 4.1/5.0，因为服务有点慢，但是面包棒的味道很好。

11. [Vitest 5](https://main.vitest.dev/guide/migration.html#vitest-5) 默认启用 `clearMocks`，并添加了一些其他不错的 DX 功能。

12. Cody Mazza-Anthony 和 Paige Vegna 在 Shopify 博客上写了关于 [Gisting](https://shopify.engineering/gisting) 的文章，幸好它并不指的是旧金山多元恋爱圈中的一种小众性癖好 - 而是关于将 LLM 上下文压缩成一组学习的 token，以使模型更快、更便宜。好吧，也许这两者都有一点。
