## Cool Bits

1.  Nub built [a phantom dependency detector](https://nubjs.com/blog/phantom-dependencies-package-extensions) that finds undeclared deps in popular packages and publishes them in a new `@nubjs/extensions` package.
    
2.  [React Router released version 8.4](https://reactrouter.com/changelog#v840) featuring more efficient route matching, reduced route re-renders, and reduced team size (bye Ryan and Pedro 🥲).
    
3.  For years, mobile shipped slower than the web. But now agents are writing, testing, shipping, monitoring, and fixing their code using Expo. [Try it today](https://try.expo.dev/4xTRl5Y). \[sponsored\]
    
4.  Anthony Fu created [Devframe, a framework that lets you BYODT](https://devfra.me/posts/pluggable-extensible-playful-devtools) (build your own dev tools).
    
5.  Aflac Turso created their own [accident prevention plan](https://turso.tech/blog/let-your-agents-run-free-with-turso-accident-protection) so you don’t have to worry about agents dropping your database.
    
6.  Brooks Lybrand is asking the question every framework author asks when they’re alone in bed at night: [“do frameworks even matter anymore”](https://brookslybrand.com/posts/do-frameworks-matter-anymore/)?
    
7.  [webmcp-react](https://github.com/agentcathq/webmcp-react) helps modern React websites build WebMCP support so agents can call them directly. Zod-first and Strict Mode safe. \[sponsored\]
    
8.  Ahmad Shadeed wrote about [how to properly align icons with labels using CSS](https://ishadeed.com/article/aligning-list-icons/). Everyone with OCD can breathe a sigh of relief.
    
9.  Jacob Kernel is doing the Lord’s work helping developers to stop using double negatives with the [cheatsheet for interface design patterns](https://interfaces.dev/cheat-sheet) he created.
    
10.  [SerpApi lets you scrape 100+ search engines with a single API](https://serpapi.com/?utm_source=bytesdev). One simple GET request gets you real-time results from Google Search, Maps, AI Overviews and more – all as structured JSON. \[sponsored\]
    
11.  GitHub Copilot, you guessed it, [migrated to Rust](https://github.blog/ai-and-ml/generative-ai/migrating-the-github-copilot-runtime-to-rust-using-copilot/). It’s tough out there for the TypeScript truthers.
    
12.  Claude [finally adopted AGENTS.md](https://github.com/anthropics/claude-code/tree/main/mods/agents-md)… trying to drum up a little goodwill for that IPO?
