### 平台电源

CSS 世界比平时更热闹——不仅仅是因为他们取笑你不理解 `clamp()`。 这是因为浏览器供应商正在以极快的速度推出新的 CSS 功能，为我们提供了用更少的 JavaScript 构建交互式网站的新方法。

因此，让我们尽快从玩新的 _Super Mario Bros. Wonder. 游戏中休息一下，仔细看看这些新款平台 Power-UPS™ 中的三个：

**🍄 `:has()` 选择器** 刚刚登陆 Firefox，现在所有主要浏览器都支持。 它允许您根据 _inside_ 中发生的情况将 CSS 应用于元素 - 就像您想根据其输入字段之一的状态将不同的样式应用于表单（Jen Simmons [wrote more](https://webkit.org/blog/13096/css-has-pseudo-class/) 有关它）一样。

**⭐️CSS 嵌套** 允许您将一种样式规则嵌套在另一个样式规则中，子规则的选择器相对于父规则的选择器。 这有助于使您的 CSS 更具可读性和模块化，并可以减少 CSS 文件的大小。 您曾经需要像 Sass 这样的 CSS 预处理器来执行此操作，但现在所有浏览器都支持它，因此您可以只需 #useThePlatform。

**🌷 `color()` 功能** 允许浏览器在任何颜色空间中显示颜色，例如 P3 颜色空间，它可以在默认 sRGB 颜色空间之外显示颜色。 这使得在飞行中操作颜色的alpha（不透明度），甚至使用`color-mix`函数操作颜色变得非常容易。 它也适用于所有浏览器🙏。

**底线：** 平台中添加所有这些强大的新 CSS 功能只有一个缺点——现在我们都必须学习如何实际_使用平台。 小心你的愿望。

#### 赞助[Sentry Launch Week](https://sentry.io/events/launch-week/?utm_source=bytes&utm_medium=paid-community&utm_campaign=general-fy24q3-launchweek&utm_content=newsletter-launchweek-tunein)

记录什么？

for (var i = 0; i < 5; i++) {
setTimeout(() => console.log(i), 1000)
}
    

为你们所有的老头回去一点。 这曾经是每个人最喜欢的 JavaScript 面试问题。

此代码将记录 `5` 5 次。

原因是我们用 `var` 声明了我们的变量，它是函数范围的。 当我们给 `setTimeout` 的函数运行时，`i` 已经是 `5` 并且每个函数都会引用相同的变量。 要解决此问题，请使用 `let` 的块范围，并将为我们的 for 循环提供自己的每次迭代 `i`。

for (let i = 0; i < 5; i++) {
setTimeout(() => console.log(i), 1000)
}
