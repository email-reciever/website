像 Michael Bublé 一样，React 团队决定在圣诞节期间重新夺回他们在排行榜上的位置。

满足 React 服务器组件。 是的，在服务器上做出反应。

_OMG 他们刚刚重新发明了 PHP 大声笑 Poggers_

停止它。 这是我喜欢思考的方式。 在服务器上渲染有好处——主要允许轻松访问数据源和快速绘画。 在客户端上渲染有好处——主要是交互性，让应用程序感觉“实用”。

问题是我们一直陷入一个非此即彼的情况。 您要么跳过 **[ALL](https://ui.dev/react-router-v5-server-rendering)** SSR 环，以获得快速的第一次油漆（然后希望保湿效果很好），或者您一起忘记 SSR，并希望您的用户在 MacBook Pro 上使用 Brave。

使用 React Server 组件，您不再需要进行这些权衡。 利用服务器/客户端渲染的优势，同时避免弱点。

以下是详细信息-

*   组件的路径名现在指定它是服务器组件（`X.server.js`）、客户端组件（`Y.client.js`）还是两者（`Z.js`）。
    
*   服务器组件在服务器上运行*******，对客户端的捆绑包大小没有影响。
    
*   由于服务器组件在服务器上运行，它们可以直接访问服务器端资源（数据库、文件系统等）。
    
*   服务器组件在重新加载时保留客户端状态。 这就是使服务器组件与 React 的传统 SSR 不同的原因。 使用传统的 SSR，您可以通过（HTML）字符串通过线路发送您的应用程序。 一旦 React 将该字符串呈现给 DOM，它就会将其抛出，JavaScript 接管。 服务器组件使用比 HTML 更丰富的格式。 这种格式使服务器组件可以根据需要重新获取并逐步更新 UI，而不会吹走状态。
    
*   服务器组件将所有客户端组件的导入视为潜在的代码分割点。 这意味着您基本上可以免费获得代码拆分，因为 React 永远不会提供客户端不需要的客户端组件。

很酷的位
----------

1.  [Radix Primitives](https://radix-ui.com/primitives/docs/overview/introduction) 是一个低级组件库，专注于可访问性和轻松定制。
    
2.  [Tailwind Shades](https://www.tailwindshades.com/) 是一个有趣的工具，可以帮助您为 Tailwind CSS 生成色调。 它也可以用来为 [Kylie vs. Kendall Jenner online dress up game.](https://www.crazygames.com/game/kylie-vs-kendall-oscars) 找到完美的腮红
    
3.  如果您仍然无法获得足够的 React Server 组件，Addy Osmani 也在其上写了一个 [nice article](https://addyosmani.com/blog/react-server-components/)。
    
4.  W3Techs 发布了 [the results of their 2020 Web Technologies Survey.](https://w3techs.com/) TL;DR — WordPress 仍在 CMS 世界中占据主导地位（并且仍在快速增长），许多开发人员仍在使用 jQuery。 思想和祈祷。
    
5.  Ryan 写了 [a really in-depth performance comparison of JavaScript frameworks.](https://medium.com/javascript-in-plain-english/javascript-frameworks-performance-comparison-2020-cd881ac21fce) 我们通常不包括这样的硬核表演内容，但在看到这件事情付出了多少努力后，我们别无选择。 打得好，瑞恩。
    
6.  Umaar 写了一个 [in-depth article](https://umaar.com/dev-tips/242-considerate-javascript/)，它介绍了一些选择性地下载/执行 JavaScript 的技术，只有在合适的时候才会这样做。
    
7.  亚马逊发布了一个新的 [modular AWS SDK for JavaScript](https://aws.amazon.com/blogs/developer/modular-aws-sdk-for-javascript-is-now-generally-available/)，其中包括 TypeScript 支持和其他一些新功能。
    
8.  [Snapdrop is a fun project](https://github.com/RobinLinus/snapdrop) 基本上重新创建了 Apple 的 AirDrop 功能，用于在浏览器本地共享文件。 如果我们再次飞行（以及世界上其他所有人都开始使用 Snapdrop），这将是在机场打发时间的好方法。
