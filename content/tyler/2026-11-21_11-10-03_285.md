### 来自 Chrome-land 的更新

我不确定他们在 Mountain View 的盒装椰子水中放了什么，但这显然将 Chrome 团队推向了一个全新的生产力水平。

过去的几个 Chrome 版本是无所不能的，因此如果您有一段时间没有访问 Chrome-Land，这里有五个值得一试的新功能：

*   新的 CSS `subgrid` 值允许子元素从其父元素继承列和行。 这是如何帮助简化复杂布局的[an example](https://twitter.com/jh3yy/status/1692262942547345913)。
    
*   `text-wrap: balance` 和 `text-wrap: pretty` 让浏览器创建一个更“平衡的文本块”，并确保您的文本块中没有任何文本块存在寡妇/孤儿问题。 这些不是纯粹专注于性能，而是有助于优化布局的可读性和一般美观💁‍♀️（[see demo](https://codepen.io/argyleink/pen/dyQxmYK)）。
    
*   [Document Picture-in-Picture API](https://developer.chrome.com/docs/web-platform/document-picture-in-picture/)可以打开一个可以填充任何HTML内容的浮动窗口，而不仅仅是视频。 对我的在线赌场广告业务来说是个好消息。
    
*   Chrome 117 DevTools 现在具有更精简的本地覆盖功能。 Addy Osmani [demoed](https://twitter.com/addyosmani/status/1691833832817967315) 如何使用它来覆盖 fetch/xhr 请求和模拟 API 的内容，而无需等待后端更改。
    
*   **Bonus:** CSS 粘性状态容器查询将允许您使用容器查询来设置粘性定位容器的后代样式。 这刚刚进入 [Intent to Prototype](https://groups.google.com/a/chromium.org/g/blink-dev/c/C1D321h3OnA/m/JTkqUj8RAQAJ) 阶段，因此距离可能还有几个月的时间，但它提供了我们最终将通过 CSS 容器查询获得的更高级功能的酷炫预览。
    

**底线：** 这只是在谷歌总部的花式椰子水预装了 5 毫克的处方级 Adderall 和 Ozempic 的“飞溅”。 现在一切都说得通了。

错误是数组的大小太大。 数组的最大大小为 `2^32 - 1`。

// const arraySize = math.pow(2, 32);
const arraySize = math.pow(2, 32) - 1;
    

在 ECMAScript 中，数组的 `length` 属性是一个 32 位无符号整数，它限制了数组可以拥有的最大条目数。 因为 `length` 属性表示条目的数量，并且它是基于零的，因此最大 `length` 是 `Math.pow(2, 32) - 1`。 #themoreyouknow
