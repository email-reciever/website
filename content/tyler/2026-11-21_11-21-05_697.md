由于每个技术平台都复制了 Snapchat，因此 Chrome 92 还具有名为 [Memories](https://chromeunboxed.com/chrome-memories) 的新功能。 这是您的书签、历史和打开标签的综合视图（我们希望）将提供有趣的通知，例如“在 3 年前的这一天，您花了 2 小时跟踪您前任前往毛伊岛之旅的每张照片_ 现在？**”

**[Firefox 89](https://www.mozilla.org/en-US/firefox/89.0/releasenotes/)** 上周也发布了一些重大的设计变化。 张开双臂欢迎一些更新——例如更清洁/更简单的菜单、模式和工具栏。 但是新的标签重新设计已经产生了更多的内脏愤怒_[mixed reviews](https://www.reddit.com/r/firefox/comments/npz18m/firefox_89_new_tab_design_is_awful/)_。 V89 还采用了新的 `forced-colors` 媒体功能和新的 `-override` 功能，同时使用了 Firefox 心爱的 [CSS DevTools](https://developer.mozilla.org/en-US/docs/Mozilla/Firefox/Releases/89#css)。

**Mighty** \[未赞助，但 DTF\] 一个月前，当它推出了带有扭曲的超快和昂贵浏览器的 V1 时，它一头扎进了浏览器领域。 每月 30 美元，您可以将其位于云中的远程 Chromium 浏览器流式传输到您自己的机器。 这就像 Netflix，但不是流式传输 _breaking bad_，而是流式传输 _a 速度稍快的 Chrome_ 版本。

有人说 Mighty 是 [the future](https://twitter.com/balajis/status/1388028094733160448?s=20) 最终将帮助 Web 替换所有原生应用程序，而其他应用程序则更多…… [skeptical](https://twitter.com/cozyunoist/status/1387223531520499712) 的 Chrome-in-A-Server 模型。

[React Spectrum](https://github.com/adobe/react-spectrum) 是 Adobe 创建的库和工具的集合，以证明您不需要 Warby Parker 眼镜和 200 美元的理发来在 React 中构建美丽且易于访问的用户体验。 它于去年夏天首次发布，但由于本周再次引起轰动，我们想让您快速复习一次。

React Spectrum 功能 3 个主要库/工具：

*   **反应谱** — 元。 这是 Adobe 设计系统 Spectrum 的实现，如果您与 Adobe 软件集成或只是想在项目中使用其组件库，这可能会很有用。
    
*   **React Aria** — 基于 [WAI-ARIA Authoring Practices](https://www.w3.org/TR/wai-aria-practices-1.2/) 实现行为和可访问性的一组钩子。 它还实现了 30 多种语言的国际化。
    
*   **React Stately** — 另一个 Hooks 库，为每个组件提供跨平台状态管理和核心逻辑。 他们不对他们所在的平台做出假设，也没有任何主题或设计系统特定的逻辑。
