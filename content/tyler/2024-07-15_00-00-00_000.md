### React Native 正式发布

React Native 团队只是 [declared](https://reactnative.dev/blog/2024/06/25/use-a-framework-to-build-react-native-apps) 使用 Expo 框架现在是构建新的 React Native 应用程序的官方推荐方式。

这并不是令人震惊的消息，但如果您最近没有使用 React Native，可能会感觉有点奇怪。 _为什么您需要使用完全不同的框架来构建 RN 应用程序？

根据 React Native 团队的说法，这是因为“您要么使用框架，要么正在构建自己的框架。”

首先，这是一个酒吧。 这与 React 团队在今年早些时候为 React 开发人员制作 [similar recommendation](https://react.dev/learn/start-a-new-react-project#can-i-use-react-without-a-framework) 时所表达的相同。

让我们仔细看看世博会使RN开发人员不必自行构建的一些关键问题，这得益于React Conf的[Kadi Kraman’s talk](https://youtu.be/0ckOUBiuxVY?t=3899)：

*   ** 访问本机功能** – Expo SDK 充当具有 70 多个本机库的 RN 的“扩展标准库”，Expo 模块 API 使构建其他本机模块变得更加简单。
    
*   ** Simple Navigation** – Expo 路由器为您提供基于文件系统的 RN 路由，因此您可以从单个代码库为 Android、iOS 和 Web 构建。
    
*   **本机代码管理** – Expo 的连续本机生成为项目中的本地代码维护提供了更流畅的体验。
    

**底线：**您可能有充分的理由选择为您的 React Native 应用程序从头开始构建类似框架的功能。 也许你是一个需要深度整合的定制解决方案的大型组织——或者你是一个单身开发者，他试图在佛罗里达州南部的一次家庭聚会上避开他所有奇怪的表亲，所以你正在为自己发明新的问题来解决 让接下来的 5 天过得更快哈哈，这不是很疯狂吗？

但对于 99% 的 RN 开发人员来说，世博会显然是现在的最佳选择。 很高兴看到 React Native 团队正式认识到这一点。

发现错误：解决方案
-----------------------

#### 赞助[Apryse](https://apryse.com/capabilities/annotation?utm_source=bytes.dev&utm_medium=newsletter&utm_campaign=jul1524)

错误在 `applyDiscount` 函数中。

应用折扣后，我们使用 `toFixed(2)` 将价格四舍五入到小数点后两位。 但是，`toFixed()` 返回一个字符串，而不是一个数字。 这意味着当我们稍后尝试使用 `reduce()` 计算总价格时，我们实际上是在执行字符串连接而不是数字相加。

有很多方法可以解决这个问题。 最简单的（如果你对自己的数据有信心）是使用`Number`。

函数 applyDiscount(项目、折扣) {
返回 items.map(项目 => ({
...项目，
价格：数字（（项目.价格 *（1 - 折扣））.toFixed(2))
}));
}
