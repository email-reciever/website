### 哎呀，Svelte又做了一次

_**编辑说明：** 上周我们一直在忙着运送衬衫，所以我们向我们的好朋友 [David East](https://twitter.com/_davideast) 寻求有关这个故事的帮助。 他是 Google 的 idx.dev 的主角，（如您所见）是布兰妮斯皮尔斯斯坦的长期领导者。_

早在 2019 年，布兰妮可能会看着 Svelte 说：“你不是那么无辜。” 快进到现在，Svelte 的编译器已经将 JavaScript 调成了一个反应性的超级巨星，宣扬“有时”是新的更多。 就像布兰妮的风格从未停滞不前一样，科技也没有。 输入 [Svelte 5](https://svelte.dev/blog/runes) 及其时髦的运行时符文，向老式 Knockout.js 致敬。 让我们明确一点：这不仅仅是一个发光，它比昨天“更强大”。

Svelte 以其易于理解的反应性系统而闻名，因为它是_just_ JavaScript。

<!-- svelte 4 -->
    <script>
让毒性 = 0；
让消息；
    
$: {
如果（毒性< 25）消息=“宝贝，再一次？”；
否则如果（毒性< 50）消息=“哎呀……我又做了一次。”；
else 消息 = "它有毒！";
}
    </script>
    
    <input type="range" min="0" max="100" bind:value={toxicity} />
<p>{消息}</p>
    

在这里，`toxicity` 和 `message` 是开箱即用的反应式，因为 Svelte 对其编译器进行了全面魔力，以跟踪所有内容。 现在，使用 `$` 语法可能会有点奇怪。 这是一个 reactive 语句，当引用的值发生变化时，该块中的所有内容都将运行，例如 `toxicity`。

这是一小部分用于幸福反应的代码，因为 Svelte 正在为我们完成工作。 但是，一旦您离开编译器辅助 `.svelte` 文件并进入 Wild World 常规 JavaScript 的舒适性，Svelte 的情况就会开始崩溃。 但是所有这些（可选地）随着Svelte 5而改变。

离编译时的反应性5英寸远，并使用一个名为Runes的新的（可选的）反应性系统将其推入运行时。 这些符文是作为反应实用程序的 `$` 美元前缀函数。 不，他们不是 [RxJS’ Finnish notation](https://benlesh.medium.com/observables-and-finnish-notation-df8356ed1c9b)，不，他们不是 [Reactive Transform in Vue](https://twitter.com/youyuxi/status/1704643604546007227)，他们不是 [Knockout.js observables](https://knockoutjs.com/documentation/observables.html)，他们当然不是 [signals in Solid.js](https://www.solidjs.com/tutorial/introduction_signals)。 实际上，事实检查。 他们确实是 [signals under the hood](https://svelte.dev/blog/runes#signal-boost)。 但说真的，让我们把它们分解。

`$state()` - Svelte 著名的 terse 反应性系统获得了一个 _tiny bit_ 更详细的信息。 现在，您不再使用 `$ref()` `$state()` 符文声明什么是反应性的，而不是自动分配的反应性。 这可能是一个额外的步骤（你的意思是，我必须真正考虑现在的代码更新！？）但它对其他符文有很多好处。

<!-- svelte 5 -->
    <script>
让毒性 = $state(0);
    </script>
    
    <input type="range" min="0" max="100" bind:value={toxicity} />
    

`$derived()` - 此符文根据其依赖关系自动重新计算派生值。 对于奖励点，它可以在函数内部工作并接收函数本身，这与 `$` 反应语句相比有了巨大的改进。

<!-- svelte 5 -->
    <script>
让毒性 = $state(0);
让消息 = $derived(level());
    
函数级别() {
如果（毒性< 25）返回“宝贝，再一次？”；
否则如果（毒性 < 50）返回“哎呀！...我又做了一次。”；
否则返回“它变得危险的有毒！”；
}
    </script>
    
    <input type="range" min="0" max="100" bind:value={toxicity} />
<p>{消息}</p>
    

`$effect()` - 有一些你想运行的副作用吗？ 每次你做出改变，Svelte 都会为你提供保障。 此外，Svelte 的创建者 Rich Harris 声称这个符文可以取代 `onMount()` 等生命周期方法。

<!-- svelte 5 -->
    <script>
让毒性 = $state(0);
让消息 = $state("");
    
$效果(() => {
如果（毒性< 25）消息=“宝贝，再一次？”；
否则如果（毒性 < 50）消息 =“哎呀！...我又做了一次。”；
else 消息 = “它变得危险的有毒！”；
});
    
    </script>
    
    <input type="range" min="0" max="100" bind:value={toxicity} />
<p>{消息}</p>
    

`$props()` - 检索组件的属性，这将消除使用 `export let` 定义组件属性或使用 `$$restProps` 等复杂概念的需要。

<!-- svelte 5 -->
    <script>
让 { 毒性，消息 } = $props(); // 没有更多 `export let`
    </script>
    

**底线：** 就像 Svelte 从 Knockout 的 2010 [tour guide](https://knockoutjs.com/documentation/introduction.html) 中获得了一页。 Svelte 5 的反应性由信号驱动，我们正在回忆 Knockout 以其反应模式掀起波澜的日子。 但是，虽然 Svelte 可能会受到经典的启发，但它正在为自己的现代风格提供服务。 这就像在 2023 年打开 Razr 手机一样，但这一次您实际上可以在 Twitter X 上啜饮燕麦奶拿铁并讨论四天工作周的优点。
