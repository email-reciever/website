### 骑着闪电CSS

差不多一年前，德文·戈维特和包裹团队在包裹总部（可能）参加了一场电影马拉松比赛后，将 Parcel CSS 重新命名为 [Lightning CSS](https://lightningcss.dev/)。

快进到今天，“极快的 CSS 解析器、变压器、捆绑器和微型器”已经每周获得超过 350k npm 的下载量。

并且这个数字应该继续攀升，因为 Tailwind 最近 [announced](https://youtu.be/CLkxRnRQtDE?t=2146) 将 Lightning CSS 集成到其名为 Oxide 的下一代发动机中。 这将有助于 Tailwind 成为一种多合一的 CSS 处理工具，同时使其更快更轻。 _我是速度。_

**那么是什么让 Lightning CSS 如此之快？** 显然生锈了。

因为 Rust 是一种原生系统编程语言，它使 Lightning CSS 比基于 JavaScript 的可比工具快 100 倍（[see benchmarks](https://github.com/parcel-bundler/lightningcss#benchmarks)）。 它可以在单个线程上每秒减少超过 270 万行代码，并通过删除不必要的供应商前缀、将手写属性组合到速记等中来产生更小的输出。

以下是 Lightning MCCSS 带来的其他一些强大功能和优化：

*   它的浏览器级解析器建立在Mozilla创建的`cssparser`和`selectors`板条箱上。 这让它像浏览器一样完全解析每个CSS规则、属性和值，从而提高性能。
    
*   它不是将属性值视为一个未类型化的一系列令牌，而是为每个属性公开了一个特定的值类型。
    
*   它支持现代CSS功能，如CSS模块、自定义媒体查询、CSS嵌套和逻辑属性——它会根据浏览器目标自动将较新的功能转换为更兼容的语法。
    

您可以将 Lightning CSS 用作 JavaScript 或 Rust 库，也可以将其作为插件包装在其他构建工具中。 Devon 也只是 [announced](https://twitter.com/devongovett/status/1693326470410829934) 它现在可以在 Stackblitz 中运行，因此您也可以在那里玩它。

**底线：**我不确定他们通常是否通常将活塞杯授予最快的 CSS 工具，但一切都是第一次。
