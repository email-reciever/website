React Router + Remix = React Router (??)
---------------------------------------

React Router自2014年最初从Ember移植后，就一直垄断了React游戏中的路由。不幸的是，在查看了数字后，GitHub Stars不支付账单。

但你知道什么是支付账单吗？ 让人们使用您的免费 OSS 框架。 等待。

无论如何，Remix 团队（为您带来 React 路由器的同一位）上周宣布，他们将撕掉 Remix 的大脑并将其放入 React 路由器中。

这到底是什么意思？

*   允许嵌套路由并行获取数据的数据加载功能（加载器）（BRRRRR）
*   数据突变API（表单/操作）-表单操作总是向URL发出POST请求...（显然适合RR）
*   自动处理中断、错误、重新验证、竞争条件（也就是我们假装没有发生的东西🙈）
*   没有突破性的变化

为了实现这一点，RR 团队将所有内容合并到 React 路由器 repo 中，将其重命名为 remix (tada 🎉)，并且仍将其分发为 `react-router-dom`（`@remix-run/router` 是主要依赖项）。

底线：

Remix（公司）需要他们所有的 React 路由器用户成为 Remix（框架）用户，他们利用他们最好的资产来实现这一目标是有道理的。 但有了这些新功能，以及向后兼容的承诺，这似乎对每个人来说都是一个胜利。

AppWrite 是一个 _self-hosted_ baas（后端即服务）平台，它为您提供了一组易于使用的 REST API，这些 API 将构建安全后端的所有复杂和重复部分抽象出来。

而且由于它被打包为一组（开源）Docker 微服务，您可以随心所欲地托管它，而不必担心被基于使用情况的定价所烧毁。
