## 小测验：答案

#### 由 \[Datadog] 赞助(https://click.convertkit-mail4.com/68u0wq06r5a8hk3kqz8sohpkq2okkh9/9qhzhdupmd85klt9/aHR0cHM6Ly9kYXRhZG9naHEuY29tL2J5dGVz)

```js
let i = 0

function x() {
  i++
  return 10
}

i += x()

console.log(i) // ?
```

答案是“10”。这是它的工作原理。

为了清楚起见，我们可以将 `i += x()` 重构为 `i = i + x()`。从那里，解释器开始评估我们的代码。在计算函数调用之前，“i”的计算结果似乎是“0”，所以现在我们的代码是“i = 0 + x()”。调用“x”返回“10”，所以现在是“i = 0 + 10”，这给了我们“i = 10”。

请注意，如果您交换“i”和“x()”的顺序，例如“i = x() + i”，您会得到不同的值 - 🫂。
