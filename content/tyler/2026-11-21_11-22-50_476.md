--------------------------------------------- ---------------------------------------------

![Angular Angel](https://bytes.dev/images/content/angel.jpg)

创世记 2:1

**许愿……** 11/11 时的 11:11，我们希望所有企业级 Web 应用程序开发人员™ 都会感到被爱。 当天晚些时候，Angular 11 被发布。

此版本不包括许多大而华丽的更改，但它确实附带了一系列较小的功能和改进。 这里是**3件大事**您应该了解_Angel_版本。 （角十一=>_天使。_）

（只需聘请我们来运行您的品牌，Google。）

**1\。 CLI 更新：** 这里有很多速度和可用性改进。 自动内联（至少对于谷歌字体）可以加快应用的第一个内容丰富的绘画。 新的 CLI 支持热模块刷新 (HMR) 以使用最新的开发更改即时更新正在运行的应用程序。 对 CLI 输出进行更新，使日志和报告更加漂亮且 _actually_ 可读。

**2\。 组件测试线束：** 此测试套件可用于 V9 中的一些 Angular 材料组件，但现在它可用于所有组件。 还有一个新的并行函数，可以让您并行运行多个异步交互，这应该会使测试这些组件变得更加容易。

**3\。 Webpack 5 的实验支持：** 目前，您只能尝试模块联合。 但对增量构建和其他 Webpack 5 功能的支持正在进行中，预计将在不久的将来发布。

其他著名的 V11 功能/改进包括更严格的类型、更快的构建、更新的 linting 以及在 Angular 之外使用翻译字符串的能力。

[Babylon.js 4.2 — A powerful game engine](https://babylonjs.medium.com/babylon-js-4-2-simplicity-reimagined-965f88d0fad)
-------------------------------------------------------- --------------------------------------------------------

![Kid playing Gameboy](https://bytes.dev/images/content/portable-gameboy.png)

你们都想找个系统链接吗？

Babylon.js 是一个基于 JavaScript 和 Web 标准的开源 3D 渲染引擎。 它主要由游戏开发人员使用，因为它在尝试为网络构建跨平台游戏和体验时提供了简单性。

上周，Babylon 发布了 v4.2（又名 _v420-blaze-it_），通过一组强大的新工具和功能，将“强大但简单”的想法加倍。

我们将介绍一些很酷的内容，并包含指向巴比伦游乐场适当部分的链接，您可以在其中玩耍并假装是我们都希望自己能成为的艺术创意开发人员（深入了解）。

**[New Particle Editor:](https://playground.babylonjs.com/#M7MYT8#11)** 允许您使用或不使用编写代码来创建、编辑和塑造粒子系统（取决于您是否要使用可点击的编辑器）。

**[Skeleton Viewer:](https://playground.babylonjs.com/#KK9Z6D#1)** 一种新的调试工具，可以渲染骨骼和关节，可视化皮肤重量等，以便更轻松地捕捉 3D 图像中的纹理问题。

**[Physically Based Rendering (PBR) Support in the Node Material Editor:](https://playground.babylonjs.com/#D8AK3Z#16)** 另一个新的可点击编辑器，可让您以多种方式创建和修改自己的 PBR 材料。

**[Babylon React Native:](https://www.youtube.com/watch?v=x6baGsEQhcU&feature=emb_logo)** 一种用于构建具有用于 Babylon Web 应用程序的相同代码的原生应用程序的系统，该系统“利用 React Native 的强大功能并将其与 Babylon.js 的功能和简单性相结合，创造出一些真正令人惊叹的跨平台体验。”

### 底线

发现错误 - 答案
----------------------

const 选项 = ["泽西麦克", "消防站", "地铁"]
    
选项[math.floor((math.random() * 3) + 1)]
    

通过将 `1` 添加到 `Math.random() * 3` 的结果中，它将始终大于 `1`，这意味着永远不会选择 `jersey mikes`。
