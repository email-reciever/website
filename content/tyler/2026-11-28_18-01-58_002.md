## Cool Bits

1. [SolidStart v2 现在已经稳定](https://github.com/solidjs/solid-start/discussions/2281) 并且由于 Vite 的环境 API 而更容易部署。

2. vlt 团队（你好 Darcy & Luke）刚刚宣布了他们的 [包管理器 1.0 版本](https://www.vlt.io/blog/1-0) 和一个新的托管包注册表，可以让你免受 Shai-Hulud 的影响。

3. [SerpApi 允许你使用单个 API 爬取 100+ 个搜索引擎](https://serpapi.com/?utm_source=bytesdev)。一个简单的 GET 请求可以让你获取来自 Google Search、Maps、AI 概述等的实时结果，所有结果都以结构化 JSON 格式返回。 \[sponsored]

4. [Base UI 发布了 1.7 版本](https://base-ui.com/react/overview/releases/v1-7-0)，其特点包括组件的更小的包大小、bug 修复和其他只有 Jenna Smith 才能理解的修复。

5. Colin McDonnell 创建了一个叫做 [Boron 的工具](https://boron.sh/)，用于生成你终端的漂亮图像。我听说一些 Moltbook 上的代理正在使用它提供写真拍摄服务。

6. Ryan Dahl 暂停与 Oracle 的诉讼，转而进行另一项副业——创建了 Durable Objects 的开源实现，名为 [celld](https://celld.dev/)，任何人都可以自行托管。

7. Temporal 撰写了一篇关于 [可靠执行的白皮书](https://temporal.io/pages/saga-patterns-state-machines-whitepaper?utm_source=newsletter\&utm_medium=sponsorship-bytes\&utm_campaign=saga-state-machines-whitepaper-2026-07\&utm_content=whitepaper-saga-state-machines) ，介绍如何处理故障而不增加应用程序的复杂性。 \[sponsored]

8. Meta 团队发布了 [Muse Code 和 Muse Spark 1.2](https://research.meta.ai/blog/introducing-muse-code-and-muse-spark-1-2) ，并正在庆祝成为第四好的模型。

9. Jaimie Lord 撰写了关于 [为什么 Cloudflare OS 是一个不信任的架构](https://lord.technology/2026/08/05/cloudflare-os-is-an-architecture-of-distrust.html) 的文章（附赠）。感谢您，Lord。

10. Justin Jay 撰写了关于他 [如何使用代码设计一切](https://justinjay.wang/designing-with-code/) 的文章，包括海报、标志和动画。关于“设计师是否应该编码”的辩论终于结束了吗？
