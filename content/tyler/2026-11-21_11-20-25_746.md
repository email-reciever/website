Electron 发布 V14 并获得新的竞争对手
--------------------------------------------

你_可能_错过了关于[new Electron release](https://www.electronjs.org/blog/electron-14-0)的新闻。 但别担心，这就是你付钱给我们的原因。 等待。

**Electron 14** 是那些主要版本之一_without_ 大量的主要新功能。 它升级了 Chromium 和 V8，添加了一些新的 API（没有什么过于突破性的），修复了一些错误，并引入了一些（小）[breaking changes](https://www.electronjs.org/blog/electron-14-0#breaking-changes)。

**缩放：** Electron 于 2013 年夏天首次发布。Electron 最好的一点是它捆绑了 Chromium 和 Node.js，这允许跨平台桌面应用程序开发。

快进 8 年，事实证明，关于 Electron 的_最糟糕的事情也是它如何捆绑 Chromium 和 Node.js——这就是它（相对）如此大而缓慢的主要原因。

但是，嘿，Electron 不会很快去任何地方，对吧？ 它可能有太多的 BDE（大桌面能量），但大量的应用程序仍然依赖它，包括 VSCode、[Discord](https://twitter.com/ralex1993/status/1433121033930817540) 和 Facebook Messenger。

关于最后一个…

**React Native 已经进入（桌面）聊天：** 刚推出自己的新版本，React Native 团队刚刚宣布他们现在的目标是 [new platforms](https://reactnative.dev/blog/2021/08/26/many-platform-vision)，从桌面和 VR 开始。

他们已经与微软合作，在Windows和MacOS上为Facebook Messenger创建了“真正的原生”视频通话体验，“完全破坏了它所取代的电子实现的性能”。 开枪。

**底线：** 大多数 Electron 应用程序不会放弃所有内容以立即切换框架（Facebook 拥有的应用程序除外）。 但这绝对是对本机桌面应用程序格局的重大改变，值得关注。

js 提示 - .find
---------------

我发现一种被低估的数组方法是 `.find`。 它允许您 `find` 满足给定函数指定的测试的数组中的第一个元素。

常量推文 = [
{ id: 1, stars: 13, text: '原来“git reset --hard head^”是一个糟糕的主意。” },
{ ID: 2, Stars: 87, 文本：“科技会议太贵了。” },
{ id: 3, stars: 51, text: 'clean code 是主观的。 优化删除。 },
{ ID: 4, Stars: 19, 文本：“也许开源的真正好处是我们在此过程中建立的友谊？” },
]
    
const tweet = tweets.find((t) => t.id === 3)
