嘈杂的噪音

基本音频 — 使用计算机发出声音的新方法
---------------------------------------------------------

我们将在这里冒险说你们中的大多数人可能没有花太多时间构建音频软件——我们不怪你们。 构建合成器、处理器和声音过滤器等应用程序在历史上是一个需要大量 C++（总量）的冗长、耗时的过程。

但由于 [Elementary Audio](https://www.elementary.audio/) 的所有这些可能正在发生变化——一种用 JavaScript 编写功能性、声明式音频应用程序的全新方式。

**快速背景：** 小学由 Nick Thompson 创建，他在 Facebook 的 Instagram 团队中工作，同时还为 React 做出了贡献。 离开 Zucktown 后，他开始研究不同的音频应用程序，并亲身了解了这个命令式面向对象的代码的世界是多么令人沮丧。

Nick 希望让 JavaScript 开发人员更容易访问音频软件世界，因此他在过去几年中构建了一个基本的 JavaScript 运行时 _and_ 框架，该框架“受到 React 的强烈启发”。

**一些很酷的功能：**

*   **functional and reactive** — 与 React 一样，您将信号处理块写为 App 状态的纯粹的声明性函数，而 Elementary 处理其余部分
    
*   **build on node.js** — 这意味着您可以轻松地将所有您喜爱的库和工具与 Elementary 一起使用
    
*   **跨平台兼容性** — 与 [Web Audio API](https://www.youtube.com/watch?v=laCjGMhASp8) （直接内置于浏览器）不同，Elementary 还可用于构建适用于桌面、移动、嵌入式系统等的本地音频应用程序
    

### 底线

通过向 JavaScript 开发人员开放音频软件世界，Elementary 可能只是迎来了一个音频应用程序的复兴——这可能意味着我们也在进行 Dubstep/DJ 复兴。 `<Skrillex />` 有人吗？

我的沙拉手指上生锈的感觉

Twih — 锈蚀 11
---------------------

**您最喜欢的程序员最喜欢的编程语言** 正好在 11 年前的上周，即 7 月 7 日（一年中最幸运的一天）向全世界揭幕。 就在那时，[Graydon Hoare](https://twitter.com/graydon_pub) 登上了 2010 年 Mozilla 峰会的舞台，并分享了他的 [bold vision](http://venge.net/graydon/talks/intro-talk-2.pdf)，因为他自 2006 年以来一直在研究一种“稍微不那么烦人”的编程语言。

快进到今天，Rust 连续 5 年被评为 Stack Overflow 开发人员调查中排名第一的“最受欢迎”编程语言。

如果你和我们一样，你可能想知道为什么 Rust 总是得到爱和炒作的_beyonce-level_。 事实证明，有 **3 主要原因：**

*   **PERFORMANCE** — Rust 是一种与 C++ 语法相似的低级系统语言，但速度明显更快、更安全。 Rust 也没有垃圾收集器，没有运行时，并且内存效率超高。
    
*   **可靠性** 它是静态类型的，它（除 _Many_ 其他事物中的其他因素外）允许您将错误从运行时间移动到编译时。
    
*   **Community** — [Rustaceans](https://www.rustaceans.org/) 基本上就像软件开发的 [BTS Army](https://www.usbtsarmy.com/)，但少了很多青少年的焦虑（遗憾的是）。 他们对传播 Rust 的福音充满热情，他们创造了许多有用的开发工具和有用的资源来帮助他人入门。
    

### 下一步是什么？

既然 Rust Can [compile to Web Assembly](https://developer.mozilla.org/en-US/docs/WebAssembly/Rust_to_wasm)，它的下一个大前沿可能是 Web 开发。 人们已经在[Node.js developers](https://itnext.io/deep-dive-into-rust-for-node-js-developers-5faace6dc71f)中发现了使用Rust的很酷的方法，React/JavaScript开发人员使用Rust [in the browser](https://www.youtube.com/watch?v=CMB6AlE1QuI)的新可能性，以及[the future of serverless](https://www.youtube.com/watch?v=CMB6AlE1QuI)与Rust和Wasm的外观。

Rust 是一种很棒的语言，但我们已经看到许多其他伟大的语言从未在构建 Web 应用程序（👋 Elm, Reason）中达到主流采用。 Rust 能突破吗？ 我想我们会在 11 年后回来检查。
