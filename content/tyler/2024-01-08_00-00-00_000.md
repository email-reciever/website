### V8 加速

很容易将 JavaScript 引擎视为理所当然。 我们知道他们解析、编译和执行我们的代码，但只有一个被诅咒的 _blessed_ 我们中的一些人从事需要您经常思考低级香肠是如何制作的项目。

但是，虽然您（可能）没有注意，但 V8 最近引入了一些重大改进，这些改进已经使网络更快、更安全。

*   **Maglev** — 一种全新的 [mid-tier optimizing JIT compiler](https://v8.dev/blog/maglev)，位于 V8 现有的 Sparkplug 和 Turbofan 编译器之间。 它旨在通过生成“足够好的代码，足够快”来填补这两个编译器之间的性能差距。 它已经将性能提高了 6-10%。
    
*   **TurboShaft** — TurboFan 的新内部架构，我们刚才提到的顶级优化编译器。 这使得通过新的优化来更快、更容易地扩展，为2024年未来的业绩增长铺平了道路。
    
*   **Faster HTML Parser** — 他们在 Chromium 的渲染引擎 Blink 中添加了一个更快的 HTML 解析器。 这将 Chrome 的速度计分数提高了 3.4%，并导致 WebKit 集成了相同的更改。
    

经过多年的工作，V8 团队还通过运输 [Wasm Garbage Collection](https://v8.dev/blog/wasm-gc-porting) 对 WebAssembly 进行了一些重大更新。

这为垃圾收集提供了更好的支持，如 Java、Python、C# 和其他语言——允许将它们编译为 Wasm，它们的运行速度大约是编译为 JavaScript 时的两倍。

这个功能有什么作用？

常量惊喜 = (...fns) => 输入 => fns.reduce(
(ACC, Fn) => Fn(ACC)，输入
)
    

它是一个 `pipe` 函数，允许您通过将一系列函数作为参数并将它们按特定顺序应用到输入来将多个操作链接在一起。

哇，字。

而不是做这样的事情。

常量 toupperCase = str => str.toUpperCase()
const removeSpaces = str => str.replace(/\s/g, "")
常数附加解释 = str => str + "!"
    
ToupperCase(removeSpaces(addExclamation("订阅字节")))
    

你可以做这样的事情。

const pipe = (...fns) => 输入 => fns.reduce(
(ACC, Fn) => Fn(ACC)，输入
)
    
const formatString = pipe(ToupperCase, removeSpaces, addExclamation)
    
formatString("订阅字节") // 订阅字节！
    

目前有一个永久的 [TC39 proposal](https://github.com/tc39/proposal-pipeline-operator) 用于向 JavaScript 添加 True Pipe 运算符 (|>)。
