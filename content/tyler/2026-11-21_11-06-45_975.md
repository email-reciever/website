### [Pieces Copilot vs. GitHub Copilot](https://pieces.app/)

GH Copilot 很棒，但每个游戏玩家都知道您最终需要升级您的默认武器。

这就是为什么成千上万的开发人员转向 Pieces Copilot 的原因。 个人100％免费，并具有更强大的功能：

*   **超越 IDE** 并连接到您的 _entire_ 工作流（浏览器扩展、devtools 等）。 它 [persists saved materials](https://code.pieces.app/blog/workflow-integration-with-ai-a-unified-approach-to-development) 和与副驾驶的对话以使您保持流动并帮助您从中断的地方继续。
    
*   **更多上下文** — 您可以上传文件、文件夹、屏幕截图和代码片段以获得有关更复杂问题的帮助，并生成不只是样板的代码。
    
*   **让您使用多个 LLM** ——包括像 Mistral 这样的本地 LLM，因此 [it can work on-device](https://code.pieces.app/blog/the-importance-of-on-device-ai-for-developer-productivity) 以获得更高的安全性，就像他们的整个存储和自动充实引擎一样。
    

[Download the desktop app for free](https://docs.pieces.app/installation-getting-started/what-am-i-installing) 自己尝试一下。

HTMX 当他们听到 Vite 和 CSS 旁边的名字时

### 奥斯卡斯，第 2 部分

**最佳突破性能：Hono。 这在很大程度上要归功于其一流的性能，其超快的 RegexProuter 以及它基于 Web 标准的事实驱动。

**最佳男配角/女演员：VITE。** 这是连续第二年获此奖项，但选择其他人感觉很亵渎神明。 它的 npm 下载量在去年增加了 3 倍，它有助于 Power Astro、Sveltekit、Remix 以及您能想到的任何其他框架。 Vite 已正式达到 Samuel L. Jackson 的地位——只需立即将 Vite 添加到您的作品中，就可以让它看起来更酷、更坚韧、更令人生畏。

**最佳独立电影：HTMX.** 像大多数独立电影一样，每个人都喜欢谈论 HTMX 有多棒，尽管他们从未真正使用过它。 这就是您知道 HTMX 团队扩展的 PSYOP _meme 营销活动_ 的方式。

**配角中的最佳演员：Turso.** 随着 PlanetScale 上周的免费级别下降，有人不得不站出来支持所有这些孤儿项目。 Turso 很乐意提供帮助。

**终身成就奖：CSS.** 就像 Jamie Lee Curtis 一样，CSS 一直存在，但正在以令人兴奋的新方式重塑自己。 我们已经看到 `:has()` 选择器、CSS 变量和容器查询等新功能使开发人员真正更轻松地生活——而且跨浏览器的兼容性从未像现在这样好。

1.  Houssein Djirdeh 在 Chrome 博客上写了关于 [Developing a Next.js package for managing third-party libraries](https://developer.chrome.com/blog/next-third-parties) 的文章。 值得庆幸的是，这个特殊的 Google 项目并没有像上次发布的 Gemini 版本那样受到强烈反对。
    
2.  Vite 团队刚刚发布了 [Rolldown](https://rolldown.rs/) 的新登录页面 — 基于 WIP、基于 Rust 的 JavaScript 捆绑程序，该捆绑程序兼容 Rollup 并最终将在 Vite 中使用。
    
3.  [Product for Engineers](https://newsletter.posthog.com/?utm_source=bytes&utm_campaign=bytes) 是 Posthog 的通讯，致力于帮助工程师提高他们的产品技能。 它伴随着对顶级初创公司的深入了解、他们的教训和错误，他们从建造 Posthog、制作出色产品的建议和不合理的刺猬插图中获得了一些错误。 \[赞助\]
    
4.  Arisa Fukuzaki 写了关于 [Internationalization with Remix](https://remix.run/blog/remix-i18n) 的文章，因此您可以确保您的网站得到 Pitbull 的批准，又名 Mr. Worldwide。
    
5.  [TypeScript 5.4](https://devblogs.microsoft.com/typescript/announcing-typescript-5-4/) 刚刚发布了一系列次要的新功能，包括新的 `NoInfer` 实用程序类型。
    
6.  CarbonQA 提供 [high-quality QA services for dev teams](https://carbonqa.com/?utm_source=bytes&utm_medium=email&utm_campaign=cool_bits&utm_content=mar11)，因此您再也不用在 QA 测试上浪费工程时间了。 他们位于美国的 QA 测试人员直接在您的工具中工作，并帮助您发现错误 _before_ 出现问题。 \[赞助\]
    
7.  [Puter](https://github.com/HeyPuter/puter) 只是在浏览器中开源了他们先进的、高度可扩展的桌面环境，有助于构建远程桌面环境、远程服务器等。
    
8.  Marijn Haverbeke 刚刚发布了 [Eloquent JavaScript](https://eloquentjavascript.net/) 在线教科书的第 4 版。 它是免费的，因此与您在大学使用的大多数在线教科书不同，您无需担心将其洪流并用世界上最糟糕的恶意软件感染宿舍中的每台计算机。
    
9.  Jen Simmons 和 Jon Davis 写了关于新的 [WebKit Features in Safari 17.4](https://webkit.org/blog/15063/webkit-features-in-safari-17-4/)。
    
10.  Antonello Zanini 写了关于 [Top 8 recent V8 updates](https://blog.appsignal.com/2024/02/28/top-8-recent-v8-in-node-updates.html) 的文章。 这是一篇好文章，但我还没有准备好原谅安东内罗在 2006 年将我从他的 Myspace 前 8 中删除。
