给我看 GitHub 宇宙

### 嘿 GitHub

我们知道，上周的 [GitHub Universe 2022](https://github.blog/2022-11-09-everything-new-from-github-universe-2022/) 将以一个铁杆 Guillermo Rauch Steve 风格的主题演讲拉开序幕。 虽然我更像是一个汗流浃背的史蒂夫鲍尔默（#sweatysteve），但有一些不错的公告。

就像您在工作中的绩效评估一样，今年会议的重点是提高您的生产力。 具体来说，GitHub 宣布了对项目、操作以及失败的 Web3 初创公司等事物的一系列更新，他们正在全力投入 AI。

以下是一些引起我们注意的事情：

*   **“Hey GitHub”：** 移开 Alexa，GitHub Copilot 现在有一个 [voice-to-text interface](https://githubnext.com/projects/hey-github) 可以将纯文本转换为代码。 您以通常的 GitHub 方式激活它——说“+1”和“这个项目还在维护吗？” 一遍又一遍，直到它回答你。
    
*   ** 60 小时免费的代码空间：** [Codespaces](https://github.com/features/codespaces) 更令人讨厌的限制之一是您只能在 2 个项目上使用它，然后您必须开始在 Satya 和 Bill 投掷您辛苦赚来的钱。 但是通过此更新，您可以每月免费使用代码空间长达 60 小时，这使得它对于快速修复、调试某人的 PR 或在您的 iPad 上进行编码很有用（👋有几十个）。
    
*   **代码搜索：** GitHub 上的搜索一直……很糟糕。 幸运的是，我们在 Octoverse 的朋友们听到了我们的呼声，并推出了带有语言、路径、所有者、回购等过滤器的 [brand new search engine](https://github.com/features/code-search)。 他们添加了 `cmd + click` 之类的功能来导航导入。
    

**底线：**自从被收购以来，GitHub一直在为开发人员提供越来越多的有用功能。 我不得不承认，我们微软霸主下的生活非常好。 谢谢#sweatysteve。

发现错误：解决方案
-----------------------

#### 赞助[Datadog](https://www.datadoghq.com/resources/synthetic-monitoring-onepager/?utm_source=advertisement&utm_medium=newsletter&utm_campaign=dg-bytesdev-synthetics-ww-synthetics-onepager)

for 循环通过为每个迭代赋值给变量一个值而工作，但无法重新分配用 `const` 定义的变量。 相反，我们应该使用 `let` 来定义我们的变量。

函数因子(n) {
如果 (n === 0 || n === 1) 返回 1;
    
for (let i = n - 1; i >= 1; i--) {
n *= i;
}
    
返回 n；
}
