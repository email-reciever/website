### 点击你的（捆绑）宏

Parcel 最近添加了 [support for Macros](https://parceljs.org/blog/v2-12-0/)，与实现此功能的 Bun 进行了一些追赶 [last year](https://bun.sh/blog/bun-macros)。

那么宏实际上做了什么，为什么它们是目前最热门的构建工具趋势？ 让我们潜入。

Bundler 宏构建在 [import attribute](https://github.com/tc39/proposal-import-attributes) 规范之上，并提供了一种在构建时运行 JavaScript 函数的机制。 从这些函数返回的值直接内联到您的捆绑包中，而不是捆绑到输出中。

这有点像您的JavaScript捆绑包的SSG，但也有一些限制。 例如，一个宏的所有参数必须是静态可分析的（该值必须是常量或另一个宏的结果）。

也就是说，宏绝对可以使您不必在一些常见情况下编写自定义插件进行额外的工作：

*   **内联代码** — 您可以使用 Bundler 宏来消除使用库的运行时成本。 例如：`regexgen(['foobar', 'foobaz', 'foozap', 'fooza']);` 编译为 `/foo(?:zap?|ba[rz])/`。
    
*   **在构建时进行取出请求** — 如果您的应用程序有一些远程配置设置，宏将允许您在构建时获取该数据并使用适当的配置捆绑所有内容。
    
*   **生成资产** — 您可以使用宏和包裹的 `addAsset` 的组合实现静态提取（又名圣杯）之类的 css-in-js 之类的东西。
    

**底线：** 如果您在捆绑时间运行大量代码，您可能只想运行服务器，但将宏作为选项很好。

#### 赞助[STRICH](https://strich.io/?utm_source=newsletter&utm_medium=email&utm_campaign=bytes)

您可以使用 `AbortController` 一次删除所有事件侦听器。 当传递一个 `signal` 作为选项时，调用 `AbortSignal` 的 `abort()` 方法时将删除事件侦听器。

常量控制器 = 新 AbortController();
const { 信号 } = 控制器；
    
element.AddEventListener('点击'，() => {
console.log('点击');
}, { 信号 });
    
element.AddEventListener('鼠标转移', () => {
console.log('悬停');
}, { 信号 });
    
element.addEventListener('mouseout', () => {
console.log('未悬停');
}, { 信号 });
    
element.AddEventListener('焦点', () => {
console.log('聚焦');
}, { 信号 });
    
控制器.abort();
    

注意：较旧的浏览器可能不支持 `addEventListener` 的 `options` 参数，但在所有现代浏览器中都支持它。
