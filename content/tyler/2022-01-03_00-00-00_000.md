2022年预测第1部分 — 热门片段🔥
------------------------------------

有些人通过移除悬挂在他们大部队上的所有夹克来庆祝新年周。 我们花了我们的时间来反思人类的一些[greatest moments](https://twitter.com/drewcoffman/status/1476341284755456002)，并在2022年对网络开发的广阔世界做出预测。

我们为您提供了 10 个预测（显然是一年中的每个月），Spicier 需要在第 2 部分中进行。让我们进入它。

1.  **next.js 将不再是一个 React 元框架，而是更多的 \*_web_\* 元框架。 使用任何框架为 Web 构建。 他们将在 2022 年更加关注这一点，舒适地使用更多的 JS 框架/库（枕套装满现金），并为 IPO 做准备。
    
2.  **Serverless 将帮助前端开发人员成为（真正的）全栈开发人员**——并且（希望）相应地获得报酬。 大量无服务器技术建立在 V8 之上，并且采用了 Web API，因此前端开发人员已经熟悉无服务器基础设施的关键部分。 现在，Serverless 不再启动 Express 服务器并称自己为“全栈开发人员”，而是使您能够真正成为其中之一。
    
3.  **反应 18 将……_\*发射\*_ 🥲.**
    
4.  **Rip Babel 和 Webpack。** 它们不会永远消失，但它们将在很大程度上被更快、更直观的新构建工具所取代——比如 SWC、ESBuild 和 Vite。 现在我只需要弄清楚如何处理这个“打开以防你必须阅读Webpack文档”我拥有的酒精...
    
5.  **没有/低代码工具将更加主导。 在2022年，我们还将开始看到更多成熟的软件公司使用“真正的开发人员”使用无/低代码工具，因为最好的代码是您不必维护的代码。

预测第 2 部分 — 更热的 Takes 🔥🔥
------------------------------------

6.  **Meta 将放弃对 React 的控制。** 类似于他们在 2018 年创建 GraphQL 基础时，Meta 将在今年晚些时候创建一个 React 基础并放弃对 React 的控制。 与微软/亚马逊/谷歌不同——Meta 从未（成功）将开发人员货币化，因此 React 并不是业务的战略重点。 现在这可能更是正确的，Zuck 的眼睛盯着 [✨Metaverse✨](https://twitter.com/alexkehr/status/1453825653841620996/photo/1) 和 Sebastian Markbåge [leaving](https://twitter.com/sebmarkbage/status/1470761450541142023) for Vercel。
    
7.  **VC 至少会解决 OSS 资金**，至少会有这样的感觉。 随着一些收入前/牵引力/PMF OSS 项目以 25-50 毫米的估值筹集种子轮，它会让你想除掉你的旧项目。 我不知道它是否是可持续的（它不是），但它比我们依靠 [Patreon](https://twitter.com/youyuxi/status/970722976739086336) 为我们关键的 Web 基础设施提供资金要好得多。
    
8.  **谈到 VC 资金 OSS**，这些 OSS 项目之一以 25-50 毫米的估值筹集了一轮种子，将烧掉所有的钱（任务完成？），因为它在关闭之前难以获得牵引力/收入。
    
9.  **Netlify 将获得混音。**“自底向上”框架是浪潮。 Netlify 会想要发行版，而 remix 会想要……钱。 它将让 Remix 团队将时间花在他们擅长的事情上，_remix-the-framework_，而不是 _remix-the-business_。 配对将使他们俩更好地赶上 Vercel/next.js。
    
10.  **Web3 将接管一切。** NFT 和 DeFi 将颠覆所有传统艺术、金融、娱乐和银行业务。 同时，我们都将搬到迈阿密，用我们将形成的 DAO 取代我们的家人和朋友（加入我们的不和谐，顺便说一句）。 从那里我们将创建具有我们自己的政府形式的云城市，我们只能通过我们的匿名身份进行，JPEG 将作为 [drivers licenses](https://www.youtube.com/watch?v=ZITP93pqtdQ)。 最后，毕竟，我们可能拥有为 Web3 找到有效用例的技术和思想自由。
