### Node 20 进入热点

Node.js 有点像我的真空吸尘器：它不是世界上最强大的技术，但它在我的生活中已经存在了很长时间，而且它（大部分）完成了工作。 哦，我已经好几年没有升级它了。

但是现在是你忘记你对 Node 了解的所有内容的时候了，因为 [v20 just came out](https://nodejs.org/en/blog/release/v20.0.0) 具有一些您可能实际使用/通知的改变游戏规则的新功能。 好吧，不要真正忘记你所知道的一切，但新东西非常令人兴奋：

*   **新（实验）权限模型** — 这使您可以在程序执行期间限制对特定机器资源的访问，因此您可以防止应用程序访问或修改敏感数据或运行潜在的有害代码。 对于 Node 解决其一些有据可查的安全问题，这是一个重要的里程碑。
    
*   **Stable Test Runner** — `node:test` 模块可能是硬核节点粉丝 _(nodelers?)_ 的旧消息，他们已经使用了实验版本一段时间了。 但对于我们其他人来说，这个现在稳定的核心模块为您提供了测试框架提供的功能的有限子集，例如 Node 中的 Jest。
    
*   **Single 可执行应用程序** — 您现在可以将应用程序与 [the entire Node.js core](https://twitter.com/wesbos/status/1648362070818140165) 一起编译为单个可执行文件。 这允许您在未安装节点的系统上运行 Node 应用程序。 请记住，如果您不喜欢这样，请确保 [let Wes know](https://twitter.com/wesbos/status/1648745919540604929)。 他亲自构建了这个特性、Node 和 JavaScript。
    

**底线：** Deno Stans 可能会想吹嘘并说“Deno 已经拥有所有这些功能多年了。” 他们是对的。

但 Node 占主导地位的市场份额意味着它可以花更长的时间引入新的东西，而且大多数开发人员可能会坚持下去——因为即使他们不是_true_nodelers，他们也可能懒得把它换成全新的吸尘器。

您是否知道 Chrome DevTools 有一些由 `$` 提供支持的神奇快捷方式？ 以下是一些最有用的：

`$()` - 是 `document.querySelector()` 的别名。 它允许您选择与给定的 CSS 选择器匹配的第一个元素。 例如，`$('div')` 将返回页面上的第一个 div 元素。

`$$()` - 是 `document.querySelectorAll()` 的别名。 它返回与给定的CSS选择器匹配的所有元素的数组。 例如，`$$('div')` 将返回页面上的所有 div 元素。

`$0, $1, $2, ... $n` - 是对您最近在“元素”面板中选择的元素的引用。 `$0` 代表最近选择的元素，1 美元代表最近的第二个元素，依此类推。

`$_` - 表示控制台中最近评估的表达式的值。

`$x()` - 允许您使用 XPath 表达式查询 DOM。 例如，`$x("//div")` 将返回页面上的所有 div 元素。
