## Cool Bits

1.  Rikiya Takehi and some of his homies spent their weekend discovering that [LLMs can read and write neural network weights](https://rikiyat.github.io/blog/weight-space-programming/). Good to know we’re at the “Neo going to the Kung Fu dojo” part of this story.
    
2.  Eric Zhang [open sourced `resin`](https://github.com/ekzhang/resin), an experimental library for building inference engines. Fortunately he hasn’t _yet_ released `resign`, a tool that auto-enrolls you in UBI and releases you from the burdens of employment.
    
3.  Extract content from any public web page with [SerpApi’s new Extract API](https://serpapi.com/?utm_source=bytesdev). Use it alongside 100+ APIs for real-time, structured search results from Google and other engines. \[sponsored\]
    
4.  [Matt Perry shipped `timeline-sequences`](https://motion.dev/docs/timeline-sequences), a new feature in `motion` that lets you orchestrate complex animations GSAP style.
    
5.  Lochie Axon built Skullet - [a library that automatically generates skeleton UIs](https://skullet.lochie.me/) for your app.
    
6.  Former React core team legend Brian Vaughn published new versions of all his big open source projects including [`react-resizable-panels` which got a new <Workspace> component](https://react-resizable-panels.vercel.app/examples/workspace) so you can finally build the IDE of your dreams.
    
7.  Your coding agent swears the fix works on its machine. Small problem: it doesn’t have one. [Expo Simulators](https://try.expo.dev/4h5siXx) give it cloud iOS simulators & android emulators on demand to tap through its own changes, and you get a replay to watch before you merge. \[sponsored\]
    
8.  Craig Kerstiens [wrote about REPACK](https://www.snowflake.com/en/blog/engineering/postgres-19-repack-table-bloat/), a Postgres 19 feature that cleans up your table bloat.
    
9.  OpenAI wrote a technical deep dive about [how they built their own Git backend called Pando](https://openai.com/index/scaling-git-at-openai/). I get it. Some days GitHub makes me want to vibe code my own critical infrastructure too.
    
10.  Catherine Woneis wrote about [How to detect agent traffic from Meta’s Muse using Fingerprint](https://fingerprint.com/blog/how-to-detect-meta-muse-ai-agent/?utm_campaign=Secondary110326&utm_source=bytes&utm_medium=newsletter). It’s actually a pretty tricky problem since Muse is designed to blend in like a human user. \[sponsored\]
    
11.  Sarah Rainsberger wrote [a nice post](https://astro.build/blog/whats-new-october-2026/) about all the features Astro shipped in October.
    
12.  Zeke Sikelianos made [`faster-chrome-devtools-skill`](https://github.com/zeke/faster-chrome-devtools-skill), which lets your agents use a CLI and CDP to control Chrome. This is the type of thing one builds to help break their Twitter addiction.
