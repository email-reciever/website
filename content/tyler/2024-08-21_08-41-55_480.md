## Pop Quiz: 答案

#### 赞助 由[百度](https://click.convertkit-mail4.com/75u9w592ens8hkn6x98c9uw642666tn/e0hph0u0o0krmes8/aHR0cHM6Ly9zZW50cnkuaW8vcmVzb3VyY2VzL2V4dGVuZGVkLXRyYWNpbmctZnJvbnRlbmQtaXNzdWVzLXdpdGgtYmFja2VuZC1zb2x1dGlvbnMvP3V0bV9jYW1wYWlnbj10cmFjaW5nLWZ5MjVxMy10cmFjZXdvcmtzaG9wJnV0bV9jb250ZW50PXN0YXRpYy1hZC1oZWFkc2hvdHMtcnN2cCZ1dG1fbWVkaXVtPXBhaWQtY29tbXVuaXR5JnV0bV9zb3VyY2U9Ynl0ZXM=)

```js
async function completeCheckout(orderId) {
  await updateAnalytics(orderId);
  const order = await processOrder(orderId);

  return order;
}
```

因为`processOrder`并不取决于结果`updateAnalytics`,你可以平行两个召唤。

```js
async function completeCheckout(orderId) {
  const [_, order] = await Promise.all([
    updateAnalytics(orderId),
    processOrder(orderId)
  ])

  return order;
}
```
