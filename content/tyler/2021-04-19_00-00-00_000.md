顺风无头
-----------------------

![Headless Jack](https://bytes.dev/images/content/headless.png)

10/10 会在热门话题上买这件 T 恤，@Adamwathan

**有一些我不想与之竞争的公司，顶级是**条纹、Vercel 和我们在 Tailwind 的自力更生的朋友。 就像 [Steak-umms](https://twitter.com/steak_umm/status/1381822900521607171) 的 Twitter 帐户一样——他们不会错过。 随着 [Headless UI v1.0](https://headlessui.dev/) 的发布，它们再次让其他人看起来很糟糕。

**快速审查：** 我已经这样做了一段时间，在这一点上，我相当肯定我们都得到了太多的报酬，只是为了一遍又一遍地构建相同的东西——列表、模式、选项卡或少数其他 UI 组件。 现在我知道正确构建这些东西（考虑到 A11Y）很困难，但也许不应该是？ 这就是 Headless UI 背后的整个理念——“完全非风格、完全可访问的 UI 组件”。

**Headless UI v1.0** 不会带来任何巨大的变化，因为它只是在去年 10 月发布的版本中（字面意思）将组件类型的数量扩大了 2 倍。 这是 React 的四个新组件和 Vue 的另外五个组件（如果您在家中保持分数），包括对话模式、广播组和弹出窗口等一些人群的最爱。

V1 还带有一些闪亮的 [new docs](https://headlessui.dev/)，它们与您期望的团队一样漂亮，该团队清楚地吃掉了自己的设计狗粮（以一种好的方式）并由 Steve Schoger 领导。

### 底线

按设计，无头的 UI 组件完全没有样式。 这使您可以 BYOS 并让组件非常适合您正在构建的任何应用程序。 这也允许 Tailwind 在 Tailwindui 上向您推销，这就像无头 UI，但风格化，而不是免费的。 辉煌。

WebRTC — 不仅仅是盗版
--------------------------------------

![Webrtc](https://bytes.dev/images/content/webrtc.png)

我们想不出一个好的表情包，所以这里有一个很好的图表

**WebRTC 已经存在了十多年，**但您只能在实时音频和视频应用程序中看到它。 好吧，本周有一些项目出现在我们的雷达上，提醒我们如何使用 WebRTC 来实现一些实时的、点对点的好处（除了 t\*rrenting），所以我们决定仔细看看。

**快速审查：** 互联网与两种协议一起工作 — [slow-but-reliable TCP](https://www.reddit.com/r/ProgrammerHumor/comments/6p8hmy/hello_would_you_like_to_hear_a_tcp_joke/) 和 [fast-but-unreliable UDP](https://www.reddit.com/r/ProgrammerHumor/comments/6pew9l/hello_would_you_like_to_hear_a_udp_joke/)。 在 WebRTC 之前，浏览器只使用 TCP（即使是 WebSockets 之类的东西），因为将 UDP 放在浏览器中是 [asking for a DDOS disaster](https://gafferongames.com/post/why_cant_i_send_udp_packets_from_a_browser/)。 另一个问题是浏览器（就像我们中学时的许多人一样）不擅长“点对点通信”。 WebRTC 解决了这两个问题。

**WebRTC 是一种协议**，它允许两个或多个 Web 浏览器以低延迟进行实时通信。 它非常适合视频和音频聊天应用程序之类的东西，缺少一个数据包并不是一件大事。 这两个浏览器确实需要一个中间服务器来交换一些秘密的巫术，但是一旦连接到位，消息只会在浏览器之间传递。

它旨在避免在浏览器中启用 UDP 的安全危险，它包括一个数据通道，因此您也可以发送任何基于文本的数据（不仅仅是视频和音频）。

以下是一些 **WebRTC 项目和工具**，它们可能会激发您在未来的项目中使用它：

*   **[PeerJS](https://peerjs.com/)** 简化了整个 WebRTC 协议，使视频、音频或数据的连接变得容易
    
*   **[Geckos.io](https://geckosio.github.io)** 是 Socket.io 的替代品，使用 WebRTC 而不是 WebSockets — 非常适合 P2P 视频游戏
    
*   **[FoxQL](https://github.com/foxql)** 是一个开源的、使用 WebRTC 构建的点对点社交网络，于上周刚刚推出。 显然，他们即将推出一个加密代币（不是开玩笑），所以你可能想清算你的一些狗狗币，因为 [our analysts indicate that FoxCoin could go a heck of a lot higher than that](https://www.youtube.com/watch?v=MJXLV_DMKa0&t=42s)。
    

### 底线

WebRTC 包含在每个现代浏览器中——因此希望您有机会使用它来构建一些高质量的 t\*rrent 网站，这些网站不会在未来使用它使我的笔记本电脑变得有趣、实时的网络应用程序崩溃！
