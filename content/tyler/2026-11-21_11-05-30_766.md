原始矢量数据库

### WTF是一个矢量数据库？

既然每家 SaaS 初创公司都已将自己转变为 AI 初创公司，我们不应该对每个数据库初创公司现在提供矢量数据库来尝试从淘金热中兑现感到惊讶。

Supabase 推出了 [Postgres Vector database](https://supabase.com/vector)，PlanetScale 带来了 [vector search to MySQL](https://planetscale.com/blog/planetscale-is-bringing-vector-search-and-storage-to-mysql)，而 Turso 上周刚刚推出了 [vector search to SQLite](https://turso.tech/blog/turso-brings-native-vector-search-to-sqlite)。

**但是 WTF 是一个矢量数据库？** 它是一个将您的数据存储为 [high-dimensional vectors](https://learn.microsoft.com/en-us/semantic-kernel/memories/vector-db) 的数据库——表示数据特征或属性的数字数组。

每个向量可以有多达数千个不同的维度，这些维度是通过对原始数据（文本、图像等）应用嵌入函数来生成的。 两个向量彼此越接近，它们相关的数据就越相似。

**这与其他数据库有何不同？ 这使您可以提高结果的质量、性能和相关性。

Vector DBs 非常适合为产品和视频提出相关建议——但正如您现在可能已经猜到的那样，它们也非常适合希望从 LLMS 或图像模型中生成更相关和一致的响应的 AI 应用程序。 所以不要指望他们很快就会消失。

**底线：** 看看是否有任何数据库初创公司能够找到创新的方法来使矢量数据库更容易被大众访问，因为它们通常需要更高的计算和扩展成本，这将是一件很有趣的事情。

但我想你不能在没有“VC”的情况下拼写 Vector 是有原因的。

函数差数毫秒(date1, date2) {
常量 t1 = 新日期(date1).gettime();
const t2 = 新日期(date2).gettime();
返回 T1 - T2；
}
    
差距毫秒（'2021-01-01'，'2021-01-02'）；
    

在 JavaScript 中，类方法不是实例的直接属性，而是属于类的原型。 当您尝试对方法进行解构时，您会尝试直接从实例中提取它，这不起作用，因为 `getTime` 不是直接属性。 另一方面，`new Date().getTime()` 之所以有效，是因为 JavaScript 检查 `prototype` 链并在 `Date` 原型上找到 `getTime`。

如果您想了解更多信息，这是我们不久前关于该主题的文章。 – [A Beginner’s Guide to JavaScript’s Prototype](https://ui.dev/beginners-guide-to-javascript-prototype)。
