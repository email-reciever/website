### 你梦想的打字稿

我们对如何庆祝今天的第 300 期有一些不同的想法：对我们的 300 大 JavaScript 框架进行排名，为我们最喜欢的 300 个 ESLint 规则编写 Haikus，或者在等待 Lerna 构建时尝试屏住呼吸 300 秒。

但最终，我们决定写下上周 [TypeScript 5.5 release](https://devblogs.microsoft.com/typescript/announcing-typescript-5-5/) 的 3 个最大功能。 这可能看起来有点随机，但我整个周末都在将 7,000 字的令人难以置信的无聊的 _Thorough_ 发行说明转化为一个有趣且内容丰富的故事，这感觉像是庆祝这一里程碑的最合适的方式。

此外，V5.5 不仅仅是另一个普通的 TypeScript 更新——它可以说是自我们在 2020 年 6 月开始写字节以来最大的 TS 版本。让我们通过仔细看看三个最有趣的新功能来分解为什么这是自我们的。

**功能 #1：推断类型谓词** – 经过 10 年的跳跃跳跃，开发人员终于可以获得对数组类型优化的正确推断。 在 v5.5 之前，此代码会导致错误：

函数 makebirdcalls(countries: string[]) {
// 鸟类：（鸟 | 未定义）[]
常数鸟类 = 国家
.map(country => nationalbirds.get(country))
.filter(bird => bird !== 未定义);
    
对于（const bird of birds）{
鸟.sing(); // 错误：'bird' 可能是'undefined'。
}
}
    

现在，TypeScript 足够聪明地知道我们过滤掉了所有的 `undefined`s，所以数组只包含 `Birds`。 这将帮助您编写更少的代码并使 TypeScript 变得不那么烦人。

**功能#2：JSDOC 改进** – 在 TS 5.5 中，您现在可以在 JSDOC 注释中 `import` 键入定义。 以前，如果该类型在运行时不可用，这是不可能的。

/** @import { someType } 来自 "some-module" */
    
/**
     * @param {SomeType} MyValue
*/
函数 doSomething(myValue) {
// ...
}
    

**功能#3：编辑器的可靠性和性能** – 除了运行时和编译器性能的改进，此版本还改进了 `watch` 功能。 如果您厌倦了每天多次在 VSCode 中按 `Restart TypeScript Server` 按钮，那么今天是个好日子。

**底线：** TypeScript 🤝 Bytes – 在我们最好的日子里，都达到了重要的里程碑。

默认情况下，JavaScript中的字符串比较对语言不敏感（这意味着它不考虑特定语言的规则或像重音这样的特殊字符），这导致排序列表不符合正确的顺序。

解决方案是利用 `Intl.Collator` 来实现对语言敏感的字符串比较。

函数 sortAlphabetical(arr) {
const collator = new intl.collator("en", { 灵敏度："base" });
return arr.sort((a, b) => collator.compare(a.firstname, b.firstname));
}
