[esbuild - An extremely fast JavaScript bundler and minifier](https://github.com/evanw/esbuild)
-------------------------------------------- --------------------------------------------

![Sully falling](https://bytes.dev/images/content/esbuild-webpack.png)

你已经排在第一位太久了，webpack。

**进入 HOT…** [Evan Wallace](https://twitter.com/evanwallace)（CTO 和 Figma 联合创始人）最近发布了 Esbuild 的早期版本——一个 JavaScript 捆绑器和最小化器，旨在比现有的捆绑器更快地“数量级”。

事实证明，“数量级”，Evan 的意思是“比其他人快 100 倍”（他的话，不是我们的话）——至少在这两个基准中是这样：

![esbuild benchmarks](https://bytes.dev/images/content/esbuild.png)

> 我们联系了评论，以了解“数量级”是否比“闪电般的快速”和“闪电般的快速”更快或更慢。 作者没有立即回应我们的置评请求。

**是什么让它这么快？**

让我们直接转到 [the README](https://github.com/evanw/esbuild/blob/master/README.md) 中：

*   它是用 Go 编写的，一种编译为本机代码的语言
*   解析、打印和源图生成都是完全并行的
*   在没有昂贵数据转换的情况下，很少通过
*   编写代码时考虑到速度，并尽量避免不必要的分配

### 底线

埃文明确表示，他并没有试图在这个项目上与整个 JavaScript 生态系统竞争。 相反，他想构建一个适用于一些特定用例的工具，并提高 JavaScript 社区对“快速”JavaScript 构建工具的期望。

无论如何，我们坚定地加入团队“任何工具都可以让我们少使用 Webpack”。

找到一个像 Rust Devs 一样爱你的人
--------------------------------------------------------

![Rusty salad fingers](https://bytes.dev/images/content/rustyspoon.png)

我的沙拉手指上生锈的感觉

**重写 React?** 上周，React 核心团队被问到是否有计划在 [livestream with Cassidy Williams](https://www.twitch.tv/videos/667925289?t=00h39m06s) 中重写 React 中的 React。

在整个团队的几秒钟的紧张笑声之后，安德鲁·克拉克说：“如果我们用 Rust 改写，我们会以一种你不会注意到的方式来做这件事。”

这让我们对 Rust 有了更多的思考，也就是连续 5 年 Stack Overflow 调查中排名第一的“最受喜爱”的编程语言。

### 为什么爱这么多？

*   **Performance:** 它是一种与 C++ 语法相似的低级系统语言，但速度明显更快更安全。 它没有垃圾收集器，没有运行时，并且内存效率高。
    
*   **可靠性：**它是静态类型的，它（在_Many_其他事物中）允许您将错误从运行时间移动到编译时。
    
*   **社区：** 社区创建了大量有用的开发工具，并以提供有用的资源和指导来帮助人们学习该语言而闻名。
    

###  Web Dev 的 Rust

由于 Rust 现在可以编译成 Web 程序集，因此我们看到了更多在 Web 开发空间中使用它的机会。 就在本周，Nicolo 写了关于 [moving from TypeScript to Rust / Web Assembly](https://nicolodavis.com/blog/typescript-to-rust/) 的文章，Shesh 写了一系列帖子给 [help JavaScript developers learn Rust](http://www.sheshbabu.com/posts/rust-for-javascript-developers-functions-and-control-flow/)。 同样在这 [video from last year](https://www.youtube.com/watch?v=ohuTy8MmbLc) 中，Sean Grove 为一个充满 React 开发人员的房间提供了一个非常令人信服的 Rust 推销（当面对面会议仍然是一件事时）。

### 底线

显然，Rust 是一种很棒的语言。 然而，有很多很棒的语言从未在构建 Web 应用程序的主流采用（👋 Elm，Reason）。 Rust会茁壮成长还是让您需要破伤风疫苗？ （明白吗？因为它的名字是生锈？好吧，我完成了）。

[Google wants you to build Flutter apps for Linux now](https://ubuntu.com/blog/canonical-enables-linux-desktop-app-support-with-flutter)
--------------------------------------------------------------- ---------------------------------------------------------------

![Napoleon Dynamite flutter](https://bytes.dev/images/content/napoleon.png)

OG 扑通扑通

**匹配 OSS Heaven？** 上周谷歌宣布他们正在与 Canonical（创建 Ubuntu 的公司）合作，为 Flutter 带来 Linux 支持。 开发人员还可以将 Flutter 应用程序部署到 Snap Store（Linux 应用商店）。

** Flutter 是如何到达这里的？** 谷歌在 2018 年 12 月推出了 Flutter，以此来证明他们为建造 DART 投入的时间和资源的数量和资源的合理性。 这是个笑话，我想。

Flutter 允许开发人员使用相同的代码库构建原生感、跨平台的移动应用程序。 从那时起，Google Play 商店已添加了 80,000 多个 Flutter 应用程序。

2019年5月，[Google expanded the Flutter mobile app SDK](https://venturebeat.com/2019/05/07/google-expands-flutter-mobile-app-sdk-to-the-web-desktop-and-embedded-devices/)包括Web、桌面和嵌入式设备。 这使 Flutter 开发人员能够开始为从 Windows 应用程序到智能冰箱的所有应用程序构建 UI。

去年年底，谷歌高管开始谈论他们对 [“ambient computing”](https://www.blog.google/products/hardware/made-by-google-2019) 的愿景——也就是“在后台，任何你需要的地方”的计算，并发生在各种设备（桌面、手机、可穿戴、物联网设备）上。

高管们还谈到了 Flutter 在为任何平台上构建 UI 提供“便携式框架”方面将发挥的重要作用。 Flutter 已经在 Google Nest Hub Max 和 Google Assistant 上运行。

**进入规范：** Flutter-Canonical 的合作伙伴关系是 Google 向 Flutter 提供支持所有平台并迎来勇敢的“环境计算”新世界的一大步，无论这意味着什么。 借助 Linux 支持，Flutter 开发人员当然能够为 Linux 构建桌面应用程序。 但他们也将能够为构建在 Linux 上的许多平台和系统构建。 这就是谷歌和颤振粉丝大肆宣传的原因。

作为回报，Ubuntu（以及一般的 Linux）将能够使自己成为更有吸引力的平台，供 Flutter 开发人员构建，这意味着为数百万 Linux 用户提供更多更好的应用程序。 这是真正感觉像是双赢的罕见交易之一。

**有趣的皱纹**

Red Hat 是去年被 IBM 以 340 亿美元收购之前最大的独立 Linux 公司（资本为 B）。 Canonical 现在是最大的独立 Linux 公司，有关潜在 IPO 或（更有可能）收购的传闻多年来一直在盘旋。

这种伙伴关系是否正在为 Big Tech 的另一次重磅炸弹收购奠定基础？ 继续关注。

发现错误 - 解释
---------------------------

函数 calcprice（价格、税收、折扣）{
税=税|| 0.05
折扣 = 折扣 || 0
    
返回 // 数学
}
    
计算价格(10, 0, .1)
    

|| 运算符检查虚假值，`0` 是一个虚假值。 要解决此问题，您可以检查 `undefined` 或仅使用 ES6 的默认参数，而不是检查虚假值。

发现错误 - 解决方案
---------------------------

// ES5
函数 calcprice（价格、税收、折扣）{
税=税==='未定义'
? 0.05
: 税
折扣 = 类型折扣 === '未定义'
? 0
: 折扣
    
返回 // 数学
}
    

或使用 ES6 的默认参数

函数 calcprice（价格，税 = 0.05，折扣 = 0）{
返回 // 数学
}
