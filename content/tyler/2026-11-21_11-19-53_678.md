开放式道具——一种假装你知道 CSS 的新方法
-------------------------------------------

**除非你的名字与 _Bosh Bumeau_ 押韵……** CSS 很可能不是你的爱好。

这就是为什么优秀的 WebLord 为我们提供了 Bootstrap 和 Tailwind 等框架的原因——这样我们就可以让我们的应用程序看起来很漂亮，同时尽可能少地学习 CSS。

**但有一个权衡：** Bootstrap 位于 164kb 缩小 (😱)，Tailwind 需要一个复杂的设置过程和构建步骤（不要问它的 CDN 包有多大）。

进入，[Open Props](https://open-props.style) 作者亚当·阿盖尔。 这是一个全新的 CSS 变量集合，您可以在自己的 CSS 文件中使用。 这些变量代表颜色、字体、大小、形状、媒体查询、动画和其他一些花哨的东西的设计标记。 换句话说，_tailwind：好的部分。_

**这还有什么让开放式道具很酷：**

*   一个小得多的捆绑包大小（包括标准化样式表），只需包含您需要的实用程序，就可以进一步缩小。
    
*   这些变量为您提供了一致、和谐的布局和设计。
    
*   您可以直接从 CDN 导入它（无需构建步骤）或将其作为项目中的依赖项进行安装。
    
*   因为它只是CSS变量，你仍然可以写出你想要的任何其他CSS。 Open Props 不像成熟的 CSS 框架（或 Wayne Campbell 的 [Ex](https://youtu.be/RJRvPmONjVY?t=14)）那么粘稠。
    

**内幕：**

> “首先我从[transition.style](https://www.transition.style/)运送了黑客包，它们是图书馆的‘道具’，这样人们就可以创建自己的过渡。只发货道具的想法比图书馆本身更有价值，但不是一个流行的概念。Open Props 希望让运输只是道具 主流和常用做法。” ——亚当·阿盖尔

发现错误 - 问题/解决方案
------------------------------

常量 animal = (name, type) => {
this.name = 名称
this.type = 类型
this.age = 0
}
    
animal.prototype.birthday = 函数 () {
this.age++
}
    
const leo = new Animal('Leo', 'Lion')
    

箭头函数没有自己的 `this`。 这会导致我们的代码中出现三个错误。

首先，我们在构造函数中将属性添加到 `this`。 同样，因为箭头函数没有自己的 `this`，所以你不能这样做。

其次，我们不能使用带有箭头函数的 `new` 关键字。 这将引发 `X is not a constructor` 错误。

第三，如果该函数是箭头函数，我们不能在函数原型上添加属性，因为没有 `this`。

这是解决方案-

功能动物（名称，类型）{
this.name = 名称
this.type = 类型
this.age = 0
}
    
animal.prototype.birthday = 函数 () {
this.age++
}
    
const leo = new Animal('Leo', 'Lion')
