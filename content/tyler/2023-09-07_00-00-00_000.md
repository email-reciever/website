我们都去过那里——但这就是字节存在的原因。 自从Cardi B第一次唱“马卡罗尼在锅里”以来，React发生了很大的变化。 如果您没有关注，这是细分。

**新钩**：已经发布了一些平滑 React 粗糙部分的卧铺钩。

`useSyncExternalStore` 可以更轻松地订阅外部数据源（例如，浏览器已经管理的任何内容，如 `localStorage` 或 `matchMedia`），而无需在组件中冗余复制该状态作为 react 状态。

`useEffectEvent`（仍然是 `experimental` ，但以前从未停止过您）让您可以将反应性但非同步的值抽象到他们自己的事件处理程序中，然后可以在 `useEffect` 中使用，而无需在 `useEffect` 的依赖数组中声明它。 这对那些“我需要在效果中使用它，但我不想在每次改变的时候重新应用它的效果”时刻有所帮助”的时刻。

`useDeferredValue` 允许您告诉 React 以延迟更新值，直到其所有高优先级工作完成。 为什么会有帮助？ 它允许您通过延迟昂贵的非紧急组件的重新渲染来向用户提供视觉反馈。

**其他超级有趣的东西**：

`startTransition` 让您明确告诉 React 哪些更新是较低的优先级。 这样做的方式是当任何更新被包装在 `startTransition` 中时，React 将以较低的优先级处理该更新，并在发生更高优先级的更新（如用户事件）时中断它。

“悬念”是你多年来可能听到的一个词。 Suspense 的整个目标是使通过网络读取数据就像使用道具或状态一样简单。 实际上，Suspense 只是一个 React 组件，它允许您在尚未准备好显示的情况下为组件树的任何部分指定加载 UI。 它将从显示给用户的加载 UI 中读取数据分离，并使加载 UI 成为一流的关注点，更好地与 React 的编程模型保持一致。

服务器组件允许您编写可以在服务器上呈现和可选地缓存的 UI。 因为它们在服务器上运行，所以你可以更早和更接近源数据获取一堆整洁的东西，更接近你的源数据，更好的安全性，缓存，更小的捆绑包大小，更快的FCP和更容易的SEO。

**底线：** 花了一段时间，但 React 似乎已经走出了黑暗时代，最近又开始大步向前。 当然，要学习 React 世界中所有最新和最伟大的东西，请查看 [react.gg](https://react.gg)。

发现错误：解决方案
-----------------------

#### 赞助[🕹️ react.gg](https://react.gg/)

错误是我们在 `delay` 或 `step` 更改时不必要地删除和重新添加间隔。

我们希望能够从 `useEffect` 内部访问 reactive `step` 值，但我们不希望将其包含在依赖数组中，因为它与设置和删除间隔无关。

这是 React 的新实验钩子 `useEffectEvent` 的完美用例。 您可以将反应性但不同步的逻辑抽象到 `useEffectEvent` 中，然后您可以在 `useEffect` 中使用该事件处理程序，而无需将其作为依赖项数组中的依赖项包含。

import * as react from "react"
从“./滑块”导入滑块
    
React.UseEffectEvent = React.Experimental_UseEffectEvent;
    
导出默认函数 app() {
const [count, setCount] = react.useState(0)
const [delay, setDelay] = react.useState(100)
const [step, setStep] = react.useState(1)
    
const handleDelayChange = (d) => setDelay(d)
const handleStepChange = (s) => setStep(s)
    
常量 onInterval = React.UseEffectEvent(() => {
setCount(计数+步)
})
    
react.useEffect(() => {
const id = window.setInterval(onInterval, delay)
    
返回 () => window.clearInterval(id)
}, [延迟])
    
返回（
        <main>
<h1>{计数}</h1>
<滑块
最小={100}
最大={2000}
步骤={100}
onChange={HandleDelayChange}
label="ms 延迟"
/>
<滑块
最小值={1}
最大={10}
步骤={1}
onChange={HandleStepChange}
label="增量"
/>
        </main>
)
}
