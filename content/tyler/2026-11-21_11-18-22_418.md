React Hooks 一直是乌龟
--------------------------------------

使用 React Hooks 有点像剪头发。 看起来很容易，但实际上你远离了嗡嗡声和不快乐的配偶（不可能是我……）。 多年来，React 开发人员一直在使用 Hooks API，特别是 `useEffect`。 到目前为止，为了避免 `useEffect` 出现问题，您可能不得不 [write code you aren’t proud of](https://twitter.com/DavidWells/status/1521986578276515841?s=20&t=UL7AgmWld4nVzlckghNKgw)。

幸运的是，React Core 团队只是 [posted a RFC](https://github.com/reactjs/rfcs/pull/220)（请求评论）来解决您的问题……或者让您更加困惑……或两者兼而有之（陪审团仍未解决）。

我们没有空间来深入了解所有细节（这就是 RFC 的用途），但这里是 TL；DR。 新的钩子被称为`useEvent`。 它提供了一个“稳定身份”函数，它总是在不需要依赖数组的情况下使用最新的 props/state 运行。 就像 `useCallback` 但也_not_ like `useCallback`。 那么`useEffect`从哪里来呢？ 好吧，它就像 `useEffect` 但也_not_ like `useEffect`。

如果这令人困惑，这里有一个 [great tweet](https://twitter.com/Huxpro/status/1522273995801776129) 应该有帮助。

React Core 团队仍在收集有关 API 的反馈，因此名称或其他重要内容的可能性很小。 但我们相信它会变得很好（考虑到委员会的设计通常会产生很好的效果🙂）。

**底线：** 一些钩子令人困惑。 更重要的是，更少混乱的钩子将有助于混淆钩子。 如果您感到困惑，请不要担心 - [you’re not alone](https://twitter.com/schickling/status/1523378971458498560?s=21&t=mHNQl9wFvCYNCvdsxBU-AA)。

浏览器中的Python？
-----------------------

我们知道这一天最终会到来：Python 即将到来。 这不是演习。

**WTF?** Anaconda 团队刚刚宣布 [PyScript](https://engineering.anaconda.com/) — 一个全新的框架，让您在浏览器中运行 Python 并使用 Python 和“特殊 HTML 标签”构建 Web 应用程序，我们都知道并且喜欢 _______________________________________

**为什么？** 因为就像 [Jörmungandr](https://mythus.fandom.com/wiki/J%C3%B6rmungandr) 一样，北欧神话中的洛基巨蛇之子环绕着整个世界，蟒蛇正在为我们所有人而来。

Pyscript 团队在更真实（和更少的世界末日）意义上说，他们创建它是为了“为用户提供比 JavaScript 更不奇怪、更具表现力和更易于学习的一流编程语言。” 哎哟😔

除了子推文之外，PyScript 中还有其他内容：

*   一个简洁的API和HTML元素，自定义组件“有意见和可预测”。
    
*   基于WebAssembly，Emscripten的技术堆栈，Emscripten（不，我们没有编造这个词），和[Pyodide](https://pyodide.org/en/stable/)通过启用插入内容、外部文件托管和应用程序托管来“消除客户端/服务器现代网络的大部分复杂性” 依靠服务器端配置。
    
*   在浏览器中运行流行的python包和科学堆栈的简单方法。
    
*   Python和JavaScript对象和命名空间之间的双向通信，让每个人都可以一起玩得很好。

`!important` 覆盖元素上的任何其他背景颜色，但 `animation` 关键帧覆盖 `background` 属性，即使使用 `!important`。 这意味着背景颜色实际上是`rebeccaPurple`。

该错误是在[the first place](https://twitter.com/stevenpemberton/status/1505839184287870981)中使用`!important`，并使用`animation`关键帧黑客来覆盖它。 这些迹象表明您的 CSS 难以维护，并且可能会给您带来未来的问题。 更好的解决方案是 [using appropriate classes and specificity rules](https://developer.mozilla.org/en-US/docs/Web/CSS/Specificity) 覆盖背景颜色而不诉诸黑客。
