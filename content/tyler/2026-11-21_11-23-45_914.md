Next.js 发布 v9.5
----------------------

![f yo couch](https://bytes.dev/images/content/fyocouch.jpg)

为什么我不伸展？

**谢谢你，Next…** [Next.js released v9.5 last week](https://nextjs.org/blog/next-9-5) 并加倍努力使用新的 [incremental static re-generation feature](https://nextjs.org/docs/basic-features/data-fetching#incremental-static-regeneration) 来生成静态站点。

**WTF 这意味着吗？** 这是一种新机制的长名称，它可以通过在流量进来时在后台静态重新渲染它们来更新您网站上的现有页面。目标是为您提供静态和动态内容的好处。 [Check out this Github Reactions demo](https://reactions-demo.now.sh/) 看到它在行动。

**来自 V9.5 的其他功能：** 可自定义的基本路径、重定向和重写、Webpack 5 Beta 版等。

### 我们是如何到达这里的？

在过去的好日子里，（在COVID和上周的[that terrible twitter joke format](https://twitter.com/MenonBioPhysics/status/1286577862280085504)之前）很容易在Gatsby和Next.js之间进行选择。 如果您想构建一个静态站点，则使用 Gatsby，如果您想要服务器端渲染，则使用 Next.js。

然后，当火之国攻击 VC 写支票时，一切都变了。

Gatsby 和 Vercel（Next.js 背后的公司）都筹集了大量现金，认为他们可以使用他们非常受欢迎的开源框架作为其付费平台的分发渠道。

但是拿VC资金意味着您的公司需要快速增长，这意味着您的分销渠道也需要快速增长。 因此，Next.js 在宣布首次大型 VC 投资时宣布支持静态网站生成可能不是巧合。 支持更多的用例意味着更多的用户，这最终意味着更多的收入（理论上）。

### 底线

Next.js 9.5 中的新功能有助于加强框架的新静态站点产品，同时继续为 SSR 添加其已经强大的功能集。 对于 Next.js 的粉丝来说，这是一个令人兴奋的消息，但是 Gatsby 呢？ Next.js 的新静态支持是否传达了一条信息：“这个小镇对我们俩来说还不够大？还是有不止一位获胜者的空间？我想我们会拭目以待。

历史上的这一周
---------------------

![myspace tom](https://bytes.dev/images/content/tom.jpg)

英雄被记住，但传说永远不会消亡。

当 Myspace 于 17 年前的本周正式推出时，前卫的青少年找到了一个新的互联网家园。 OG 社交网络最初是使用 ColdFusion 和 SQL 构建的（后来迁移到 ASP.NET），并在其高峰期每天处理 15 亿次页面浏览量。 它在 2006 年成为美国访问量第一的网站，领先于谷歌和雅虎。

自从辉煌岁月以来，该公司已被买卖，出售并转售给所有人，从贾斯汀·汀布莱克（这听起来像是个玩笑，这不是《时代》杂志）。 在这一点上，我认为不会发生大规模的复出。

MySpace 最持久的遗产可能是它 [inspired a whole generation](https://news.codecademy.com/myspace-and-the-coding-legacy/) 学习 HTML 和 CSS 的基础以自定义其配置文件的方式。
