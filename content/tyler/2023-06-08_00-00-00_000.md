### ASTRO 放大它

现在是正式的夏季时间，这意味着 Astro 团队正在更加努力地帮助我们所有人减少我们的 JS 捆绑包尺寸，这样我们的网站最终就有足够的信心脱掉他们在游泳池中的长袖衬衫。

就在过去的一个月里，Astro 发布了 _three_ 小更新、新的图像优化体验和一个名为 [Starlight](https://starlight.astro.build/) 的新文档站点构建器（Muse 批准）。 这里有一些亮点：

*   **Middleware** 允许您在页面呈现并返回给用户之前或之后运行代码，这为auth、重定向等提供了更多功能。 截至周二的 v2.6 发布，它现在稳定。
    
*   **Hybrid 渲染**在 v2.6 中也变得稳定，旨在为您提供静态和动态的最佳部分。 设置 `output: "hybrid"` 允许您将交互式页面和 API 端点混合到您的站点中，但每个页面仍默认为静态预渲染。
    
*   [Assets](https://docs.astro.build/en/guides/assets/) 是用于优化图像和其他文件的一组新的（仍在实验性的）功能。 它带有更强大的 `<Image />` 组件，一个图像服务 API，可轻松连接到 Vercel 或 Cloudinary 等外部服务，并完全支持 Markdown、MDX 和 MarkDoc。
    

**底线：**我们最近使用 Astro 构建了 [two](https://react.gg) 不同的 [things](https://usehooks.com)，我们喜欢“The Tony Perkis of JavaScript”如何帮助我们轻松获得可靠的灯塔分数（因此这些 Google Devrels 不会在 Twitter 上生我们的气）。 而且我们不是唯一的——Astro 的每周下载量在去年增长了 10 倍，而且它们没有任何放缓的迹象。

很酷的位
----------

1.  Dan Abramov 在 [Building a simplified version of RSC from scratch](https://github.com/reactwg/server-components/discussions/5) 上写了一篇技术深度潜水。 他以最“我是他”的方式做到了这一点，在 GitHub 讨论帖子中。
    
2.  Felix Raab 写了一篇关于 [How the Raycast API and extensions work](https://www.raycast.com/blog/how-raycast-api-extensions-work) 的有见地的文章。
    
3.  [PostHog’s Session Replays tool](https://posthog.com/session-replay?utm_source=bytes&utm_medium=newsletter) 是观察用户的最佳操作并根据您所看到的内容进行改进的最佳方式。 尝试它是愚蠢的（和免费）。 \[赞助\]
    
4.  [ReactPy](https://github.com/reactive-python/reactpy) 是一个我认为它结合了我最喜欢的两个东西的库：React 和 Key Lime Pie。
    
5.  Hunter Johnston 创建了 [shadcn-svelte](https://www.shadcn-svelte.com/)，这是流行组件库的非官方 svelte 端口。 这有点像我最近画的驾驶低音的所有非官方粉丝艺术。 （是的，我一直在看很多_我想你应该离开。_）
    
6.  来自 Chrome 团队的 Jeremy Wagner 写了关于 [How large DOM sizes affect interactivity, and what you can do about it](https://web.dev/dom-size-and-interactivity/) 的文章。 请记住：只有您可以防止大的 DOM 尺寸。
    
7.  François Zaninotto 写了 [Is React Having An Angular.js Moment?](https://marmelab.com/blog/2023/06/05/react-angularjs-moment.html) 答案可能是否定的，但它是一个有趣的作品。
    
8.  前端掌握写了关于[The evolution of React APIs and code reuse](https://frontendmastery.com/posts/the-evolution-of-react-patterns/)的文章。 如果你是一个年纪大到可以记得看_男孩遇见世界的人，这将是一段不错的步行记忆中。 科里、托潘加和肖恩。
