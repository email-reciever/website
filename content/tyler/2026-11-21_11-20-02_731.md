** Next.js 12 中有什么新功能？**

*   Rust 驱动的编译器，这意味着，是的，[this meme](https://bytes.dev/images/content/rustyspoon.png) 可以再次出现。
*   支持 [AVIF images](https://jakearchibald.com/2020/avif-has-landed/) 使用 `<Image>` 组件，将您的猫图片缩小 20%。
*   本机 ES 模块支持，因为 CommonJS 是 _SO_ 2010。
*   URL imports，它允许您直接从网络导入文件，而不是用 peasant 模块弄脏您的 `node_modules` 文件夹。

但最令人兴奋的部分是两大实验功能。

**Middleware (beta)** — 这解决了 JamStack 的最大问题之一 — 当您仅提供静态文件时，您如何在请求上运行服务器端代码？ 中间件允许您使用有限但快速的运行时编写在每个请求之前运行的函数。 这允许您执行 [lots of stuff](https://github.com/vercel/examples/tree/main/edge-functions) 之类的身份验证、功能标志、A/B 测试和分析。

[**React Server Components (Alpha)**](https://vercel.com/blog/everything-about-react-server-components) — Next.js 成为第一个实现这种闪亮的新服务器渲染方法的人，这与 next.js 为页面生成 HTML 通常执行的 SSR 不同。 相反，这会在服务器上呈现单个组件并将结果流式传输到客户端。 这为您提供了更快的页面加载、较小的 JavaScript 捆绑包（因为所有处理都发生在服务器端），并且是一位出色的开发人员 [experience.](https://twitter.com/sam_lavigne/status/1453891385631944704)

**底线：** 我们是否准备好通过建立 React 的基础，并通过与 React 核心团队建立特权关系来讨论如何利用 React Core 团队来获得免费劳动力？ 还没有？ 对。

遍布整个（github）宇宙
--------------------------------

GitHub Universe 有点像 CodeSpaces 的一大广告——GH 今年早些时候首次宣布的云中功能齐全的开发环境（是一种付费企业产品）。

公平地说，CodeSpaces 比我们见过的任何其他基于云的 IDE 更强大。 它允许您执行本地机器可以执行的所有操作（访问终端、运行服务器、执行测试、同步本地 VS 代码设置等）——但可以从 Metaverse 世界中的任何计算机进行。

GitHub 上周宣布了一系列新的 [CodeSpaces features](https://github.blog/2021-10-27-everything-new-from-universe-2021/)，这将使它更易于使用——包括一个新的（测试版）REST API，以编程方式管理你的代码空间，新添加的 CS 支持在 GitHub CLI 中，以及创建/更新 `devcontainer.json` 开发的能力 环境作为代码定义，一键式设置。

这是其余的非代码空间亮点：

*   新的 **GitHub 问题** 经验登上公共测试版 — 具有被动积极地羞辱您的同事 _collaborating_ 的新功能和创新功能，例如项目板和动态表格。
    
*   新的 **GH Command Palette** (Beta) 允许您使用 Trusty `cmd/ctrl k` 导航到任何项目、存储库、PR 或 issue 和 run 命令。
    
*   新的 **GH 讨论**功能获得了一些 [additional updates](https://github.blog/2021-10-27-everything-new-from-universe-2021/#connecting-communities-with-github-discussions) 旨在帮助开发人员、团队和 OSS 社区直接在 GitHub 上进行通信（也许可以从另外一台不协调的服务器中拯救世界）。
    

**底线：** GitHub 正试图在保持对个体开发人员和小团队的吸引力的同时，同时尝试通过代码空间等仅限企业的功能来吸引 Big-Fish 客户。 在 Git_Lab_ IPO 两周前以 150 亿美元（主要是因为其强大的企业客户群）之后，我猜我们很快就会看到 GIT_HUB_ 的更多企业游戏。
