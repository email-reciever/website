### Modern.js 是一个巨大的神秘肉中辣酱

没有比滚动 TikTok 更好地反映现代生活：你总是会得到一些高点、一些低点和一些令人深感不安的 ASMR 视频的混合。 另一个 90 分钟的便便用得好✅。

因此，当 TikTok 的母公司 ByteDance 的 Web Infra 团队创建了一个开源的“Web 工程系统”时，他们选择将其命名为 [Modern.js](https://github.com/web-infra-dev/modern.js)。 它可能会出现在您附近的代码库中。

**WTF 是一个网络工程系统？** 好问题。 事实证明，这就是“一堆不同的OSS工具卷入一个巨大的神秘肉中辣酱玉米饼馅”。 Modern.js 带有一个 React 元框架、一个 NPM 模块构建器、一个文档站点构建器、一个构建引擎。 您可以将所有这些工具单独或单独使用。

元框架是 Modern.js 生态系统其余部分的主要基础，所以让我们仔细看看它：

*   ** 与 Next.js 类似的功能** — 您可以获得基于文件的路由、默认的 TS 支持以及所有渲染选项（SSR、SSG、CSR）。 但也有一些关键的区别。
    
*   **重新发明轮子** — 它建立在 [Rspack](https://www.rspack.dev/) 上，这是一个基于 Rust 的捆绑器，编译速度比 Webpack 快 5-10 倍，也是由 Web Infra 团队创建的。 该框架还包括一个定制的 [state management library](https://github.com/web-infra-dev/reduck)、Monorepo、_and_ 微前端解决方案，因为为什么不呢？
    
*   **集成 BFF 方法** — [Backend for Frontends](https://samnewman.io/patterns/architectural/bff/#bff) 是为每个用户体验拥有一个后端的想法。 Modern.js 以一些巧妙的方式支持这一点，例如允许您将 [define APIs by adding a function](https://modernjs.dev/en/guides/advanced-features/bff/function.html) 放在 `api/` 目录中，它允许您将该 API 作为函数导入到您的页面中。
    

**底线：** 就巨型神秘辣酱玉米饼馅而言，这似乎对我的生产力来说实际上是一个净积极的人。

如何为提取请求设置超时？

由于 fetch API 没有内置超时选项，因此您可以使用 `AbortController` 和 `Promise.race()` 来实现超时。 使用 `Promise.race` 是一个很好的技巧，因为它允许您同时中止单个请求或多个请求。

const AbortController = new AbortController();
const 信号 = AbortController.signal;

常数 fetch2 = fetch("https://api.example.com/data-2", { 信号 });
