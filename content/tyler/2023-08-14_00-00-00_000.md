### 世博会投掷狂怒者

上周的 [Expo Launch Party](https://expo.dev/launch-party) 很像 Diddy 的白人派对——但我们并没有在汉普顿与 Paris Hilton 和 Ludacris 一起做可口可乐，而是安静地阅读博客文章，偶尔检查 Discord。 _为了什么而拒绝，阿米尔人？？_

好吧，好吧，从技术上讲，这不是一个“派对”，但我们仍然有一些很酷的新世博会好东西，第二天早上我没有充满遗憾地醒来🙏。

**icymi，以下是亮点：**

*   新的 [`useUpdates()` 反应钩](https://expo.dev/changelog/2023/08-08-use-updates-api) 模块可让您从任何组件获取更新信息，跟踪应用程序上次检查更新的时间，并检查在更新的不同阶段发生的错误。
    
*   [Expo Orbit](https://expo.dev/changelog/2023/08-09-orbit) 是一款新的 macOS 菜单栏应用程序，可让您一键安装和启动 EA 的构建，列出并启动 Android 模拟器和 iOS 模拟器，并从本地文件安装和启动应用程序。
    
*   EAS Update 已经允许您在 App Store 版本之间直接向用户发送应用更新，但它们刚刚启动 [percentage-based rollouts](https://expo.dev/changelog/2023/08-08-rollouts-eas-update)，因此您可以首先在较小的用户群中测试更新。
    

**底线：** Expo 已经将 React Native 生态系统背负了一段时间。 这有助于推动他们的世博应用服务 (EAS) 业务的增长，这使他们能够继续投入更多资源，让世博会（和 RN 生态系统）变得更好，从而发展 EAS 业务，等等。

很高兴知道我们至少有一个积极的方式来资助 OSS 🥲。

很酷的位

1.  Million (VDOM 替换 React) 刚刚启动 [Automatic Mode](https://twitter.com/aidenybai/status/1689773623827943424)，它允许您使用 `npm i million` 自动使您的 React 项目“最多快 70%”，同时使用 Next.js、RSC、Vite、Astro 等编写您的 React 代码。
    
2.  [Zero](https://tryzero.com/?s=bytesnl) 创建了一种将第 3 方 API 凭证集成到项目中的简单方法。 他们的 SDK 可用于 TypeScript、Rust、Python 和 Go。 \[赞助\]
    
3.  乔什·科林斯沃思写了 [Things you forgot (or never knew) because of React](https://joshcollinsworth.com/blog/antiquated-react)。 我不敢相信丹·阿布拉莫夫已经把这一切都藏了这么久。
    
4.  [Deno v1.36](https://deno.com/blog/v1.36) 具有更灵活的安全选项、新的测试选项和更好的节点兼容性。
    
5.  [playhtml](https://playhtml.fun/) 是一个新的库，通过处理实时同步、持久性和反应性，以最少的代码和最大的表现力实现交互功能。 它也是我投资的新的、以 HTML 为主题的街机的名称。孩子们会喜欢的。
    
6.  Phil Booth 写了一篇名为 [Four ways to shoot yourself in the foot with Redis](https://philbooth.me/blog/four-ways-to-shoot-yourself-in-the-foot-with-redis) 的文章，我印象深刻的是他能够将其缩小到只有 4 个。
    
7.  [Onboard](https://getonboard.dev/?ref=bytes) 通过 AI 聊天帮助您快速浏览和理解任何大型代码库。 放入 GitHub 链接，几分钟内您就可以开始与任何 repo 聊天以定位功能、了解不同的部分并从 repo 生成代码。 \[赞助\]
    
8.  [SQLedge](https://github.com/zknill/sqledge) 使用 Postgres 逻辑复制将源 Postgres 数据库中的更改流式传输到可以在边缘上运行的 SQLite 数据库。
    
9.  Alvar Lagerlöf 写了一篇名为 [Devtools for React Server Components](https://www.alvar.dev/blog/creating-devtools-for-react-server-components) 的文章，它探讨了 RSC 如何在网络上表示，以及 Alvar 如何使用它来创建 DevTools。
    
10.  [jsisweird.com](https://jsisweird.com/) 是一个测验，它给你 25 个“古怪的表达”，看看你是否能猜到输出。 如果你把所有 25 个都做对了，你就会赢得 Zooey Deschanel 奖，该奖项旨在“最有可能在独立乐队中唱歌的 JS 开发者，在流行的 2010 年代情景喜剧中穿色彩缤纷的连衣裙，并最终开始与其中一个 Property Brothers 约会。”

`try/catch` 是同步的。 当我们的错误为 `throw`n 时，`try/catch` 块将消失 - 离开我们 `Uncaught Error: Oops!`。 为了解决这个问题，我们希望依靠允许我们进行更多异步控制的 Promise。

函数最终失败（时间）{
返回新的承诺((res, rej) => {
setTimeout(() => {
rej(error("哎呀！)")
}，时间）
})
}
    
最终失败(1000)
.catch((原因) => console.error(reason.message))
