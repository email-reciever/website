### 解决旧问题的新方法

它很乱，不可预测，边缘有点粗糙——但它很漂亮。 不，我们不是在谈论你的前任（或不忠的 Proactiv 发言人），而是在谈论 CSS。

因为即使有所有的危险信号，仍然有一些开发人员将“我可以修复他”的能量带到 CSS。 最新的挑战者是我们的朋友 Nate Moore（嘿 Nate 👋），他刚刚发布了一个名为 [Token CSS](https://github.com/tokencss/tokencss) 的新库。

token CSS 将自己计为 [“Tailwind but for CSS”](https://youtu.be/RlwlV4hcBac?t=16) — 我认为这意味着它为您提供了 Tailwind 的一致性和结构，但具有编写自己的 CSS 选择器的灵活性。

**这里有一些主要功能：**

*   ** Just CSS️** — 令牌 CSS 编译为标准的自定义属性，并允许您使用 `.css` 或 `style` 标签编写您的样式，例如“好日子”。
    
*   **内置预设** — 开箱即用，您可以获得用于间距、排版、颜色等的预设令牌。 基本上是设计系统所需的一切。
    
*   **社区标准** — 令牌 CSS 使用 [interoperable JSON structure](https://design-tokens.github.io/community-group/format/) 来定义令牌，因此您可以（理论上）在不同的项目或库中重用您的令牌。
    
*   **VSCode 插件** — IntelliSense，“悬停功能”，语法突出显示，所有的好东西。
    

如果您认为 Token 是您的口味，那么值得注意的是，它仍在进行中，并且“错误、缺失的功能和重大的更改是有希望的”。 但我们都知道演习（明天会把这个坏人投入生产）。

![Emotion vs Bootstrap vs Styled Components vs Tailwind](https://bytes.dev/images/content/emotioncore-vs-bootstrap-vs-styled-components-vs-tailwindcss.jpg)

css-in-js 是否达到顶峰？ - npmtrends.com的数据

在比较样式组件（css-in-js）、情感（css-in-js）、tailwind（实用程序css）、bootstrap（oocss？）时，不完全是🍎s，有一些非常有趣的趋势 这里。

到目前为止，2022年是兔子顺风的一年。 它的每周下载量几乎翻了一番，而 Styled 组件和 Emotion 等现有产品仍稳定在约 30% 的增长中。 Bootstrap 的增长有所下降，但仍有很大的使用（特别是考虑到我们不计算 CDN 下载量）。

**4 外卖：**

1.  JS 生态系统正在增长（涨潮提升了所有船只）。
    
2.  开发人员仍然喜欢CSS-in-JS。 情感和风格成分的使用量都在继续增长，但这种增长肯定减慢了速度。
    
3.  尾风即将迎来皇冠。 它们应该在年底前成为顶级狗（并且是您下一个项目的绝佳选择）。
    
4.  随着 CSS 规范现在有多好，我们可能会看到这些趋势在未来发生变化，因为开发人员选择#useThePlatform 而不是框架。
