### 我们其他人的WASM

你有没有想过，“为什么每个人突然都在谈论 WebAssembly？” 或者……“什么是 WebAssembly？”

好吧，你很幸运——因为在我摄入了特别有效的 P5P 剂量来降低催乳素水平之后，Wasm 的过去、现在和未来的幽灵拜访了我（是的，即使是一月）。 现在我的精细运动技能恢复了正常，我会给你他们告诉我的火花笔记版本。

**过去：** 从历史上看，JavaScript 是唯一能够在浏览器中运行的编程语言——直到 2017 年 WebAssembly 作为“各种编程语言的便携式编译目标”发布。 这使得那些激进激情的“JavaScript 不是一种真正的语言”开发人员有可能使用更快、更低级的语言（如 C++ 和 Rust）来构建具有近乎原生性能的 Web 应用程序。

Wasm在2019年成为WC3的官方标准，标志着Web的重大突破，并使其有可能成为能够运行_Any_类型程序的“通用操作系统”。 然而，我们大多数人还没有使用 WASM。 那么最近在做什么呢？

**现在：** 就像 90 年代的 Socker Boppers 一样，Wasm 开始变得更加主流。 最引人注目的例子是 Figma，它使用 Wasm 和 C++ 为其 [$20 billion](https://techcrunch.com/2022/09/15/adobe-is-buying-figma-for-20b-taking-out-one-of-its-biggest-rivals-in-digital-design) 协作设计工具提供支持。 最近，我们看到其他公司在浏览器中使用 Wasm 来运行 [Postgres](https://www.crunchydata.com/blog/crazy-idea-to-postgres-in-the-web-browser)、[Photoshop](https://hypebeast.com/2022/6/adobe-photoshop-free-version-for-web-launch-info) 甚至 [Wordpress](https://github.com/WordPress/wordpress-playground)。

在许多方面，Wasm 都遵循与实时视频或多人文本编辑等技术相同的采用曲线。 如今，只有真正具有真正业务需求和投入大量资源的公司才能利用这项技术。 但随着时间的推移，这个复杂的基础设施应该被抽象为简单的 API，使大众可以使用它。 这将我们带到了我们的下一个幽灵……

**未来：** 如果你眯着眼睛，你已经可以开始看到 Wasm 未来几年的样子。 Stackblitz 已经将 [Web Containers](https://github.com/stackblitz/webcontainer-core) 作为一种“用于 Wasm 的 Docker 容器”而努力工作，而其他项目也在努力消除一些粗糙的边缘并完全释放浏览器作为操作系统的潜力。

随着这些基础的建立，我们可能会开始进入“框架时代”。 最终，像“Next.js for Wasm”的东西将让 Normie 开发人员利用 Wasm 的所有功能，而无需成为低级系统的专家。

**底线：** 上帝保佑我们，每个人。

#### 赞助[Explo](https://www.explo.co/products/explore?utm_source=Bytes&utm_medium=email&utm_campaign=free-trial&utm_content=Explore)

感谢史蒂夫的这一。 这是他的[fantastic breakdown](https://twitter.com/Steve8708/status/1611437686958739456)。

fetch("/用户")
.then((res) => res.json())
.then((用户) => {
    
})
    

实际上，如果我们的服务器响应除 `user` 以外的任何内容（如 `400`、`404`、`500` 等），我们就不会处理这些情况。 您可能认为我们可以添加一个 `catch`。

fetch("/用户")
.then((res) => res.json())
.then((用户) => {
    
})
.catch((err) => {
    
})
    

不完全。 问题是未触发任何这些状态代码的 `catch`。 更糟糕的是，即使您想检查请求的状态，当您在第一个 `.then` 中将响应转换为 JSON 时，您已经忽略了它。

更好的方法是这样的，在转换为JSON之前检查状态。

fetch("/用户")
.then((res) => {
如果 (!res.ok) {
// 检查状态
// 决定你做什么
}
    
返回 res.json()
})
.then((用户) => {
    
})
.catch((err) => {
    
})
    

查看 [Steve’s video](https://twitter.com/Steve8708/status/1611437686958739456) 更进一步。
