### 不再有漏油的脸颊

Meta/Facebook 刚刚开源了一个名为 [MemLab](https://engineering.fb.com/2022/09/12/open-source/memlab/) 的新库，这是一个用于检测 JavaScript 中内存泄漏的框架。 记忆泄漏有点像我奶奶到 80 多岁时，因为她有一箱 LGC（漏奶奶奶脸颊），她迈出的每一步都大声疾呼。

如果您正在建立一个水疗中心，您的应用程序也可能拥有 LGC。 好消息是，虽然还没有治愈老年人和松散的括约肌的方法，但 Memlab _can_ 可以帮助您修复泄漏的 JS。

Memlab 能够通过“通过预定义的测试场景运行无头浏览器并对 JavaScript 堆快照进行区分和分析”来查找内存泄漏。 本质上，它在 Puppeteer 中运行您的应用程序，打开和关闭一堆选项卡，并跟踪页面关闭时仍在使用的内存量。

如果您在浏览器之外使用节点或 JavaScript 应用程序，您仍然可以使用 Memlab 编写断言/测试以进行内存分配。 它还带有一些方便的实用程序，可帮助确定优化代码的机会。

*   **按对象形状分解堆：** 这是 [“I have a CS Degree”](https://www.youtube.com/watch?v=eSqexFg74F8) 说话，“它可以帮助您更轻松地找到内存泄漏的对象。”
    
*   **检测连续的单个对象增长：** Memlab 可以帮助分类容易出现问题的类和对象的类型。
    
*   **查找重复的字符串实例：** 将此视为您的字符串的玛丽公寓——如果它们不激发欢乐，他们就必须离开，因为您不需要相同的 2 个。
    

**底线：** LGC 是真实的，没什么好尴尬的，所以不要让反 JavaScript 人群说“你使用的 JS 太多”让你感到羞耻。 只需找到像 Memlab 这样的好工具，可以帮助您继续获得面包。 （在Delores的记忆中- RIP ❤️。）

![React vs Vue vs Lit vs Svelte](https://bytes.dev/images/content/lit-html-vs-react-vs-svelte-vs-vue-trends.jpg)

React 的下一代框架 - npmtrends.com 的数据

在过去的几年里，我们看到了很多关于“{insert new framework}是Web开发未来”的推文和博客文章。

但任何新人声称该标题的唯一方法是从 React 手中夺走腰带——正如这张图表所示，还没有人走近。

Vue 是下一代最成熟的框架，但它的每周下载量仍然只有大约 1/5，并且增长速度较慢（过去两年 75% 的增长，与 React 的 89% 相比。

Svelte 和 Lit 的增长速度要快得多，但它们仍然如此早且相对较小，以至于很难预测他们的未来。 其他框架，如 Astro 和 Solid 更小更早，所以我们没有在这里包含它们（而且它们使图表的底部看起来很混乱）。

**十亿美元的问题：** 另一个框架会在未来五年内超越 React 吗？ 如果是这样，它是否已经被创造出来，还是我们还在等待它的诞生？
