### PartyKit的派对时间

这是因为从红杉资本构建实时多人应用程序 [just raised $2.5m](https://blog.partykit.io/posts/partykit-raises-a-pre-seed-round-2-5-m-from-sequoia-remote-first-and-more) 的开源平台，现在可以公开供任何人使用。

在PartyKit创始人和[Bytes friend](https://x.com/threepointone/status/1668708288676913154)的公告中，Sunil Pai写到“互联网的未来是协作的”。 但从历史上看，构建和扩展 Figma 或 Google Docs 等多人游戏应用程序非常昂贵，而且在技术上很难实现。

值得庆幸的是，Edge Computing 让这些协作应用程序变得更便宜，现在 PartyKit 提供了一种包含电池的方式，可以使用 JavaScript 轻松构建和部署它们——这有点像 next.js/vercel 的实时多人应用程序。

**让我们仔细看看：**

*   您带来了有趣的部分（您的 JavaScript 或 WASM 代码），PartyKit 带来了无聊的部分（基础设施、边缘部署和熟悉的编程模型）。
    
*   您可以获得有用的平台好东西，例如环境变量、预览 URL、管理 API 等。 PartyKit 公开承认从 Cloudflare 页面、Vercel 和 Heroku 中窃取了许多好主意——我很欣赏这种诚实。
    
*   它使用WebSockets、Fetch和Request-Response等web标准，它与Y.js和Automerge等流行的协作库很好地集成。
    

PartyKit 还可以更轻松地构建多人应用程序，您可以在其中与 LLM 实时协作，而不是与其他人进行实时协作。 如果你像我一样害怕人际接触，不能等到我们都被机器取代，这将是个好消息。

**底线：** 现在 PartyKit 是一家官方企业，他们必须弄清楚所有无聊的东西，如招聘、工资、绩效评估和人力资源政策——但今晚他们可以像 1999 年一样聚会。
