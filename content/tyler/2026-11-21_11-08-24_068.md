### Typescript 5.3 有一个有趣的皱纹

你知道技术中那些开创性的时刻，当你看到如此令人兴奋的东西以至于你只是敬畏地站在那里对人类能够产生的创新感到敬畏时吗？

好吧，这个即将到来的 [TypeScript 5.3](https://devblogs.microsoft.com/typescript/announcing-typescript-5-3-rc/) 版本不是那样的。 但它_does_引入了一些你应该知道的值得注意的新功能。 让我们潜入：

*   **import attributes** — 虽然仍然是 JavaScript 的 Stage-3 提案，但 TypeScript 5.3 添加了对导入属性的支持，这确保了模块类型和资源的 MIME 类型匹配。 这使得导入远程模块更加安全。
    
*   **改进的类型缩小** — [Mateusz Burzyński](https://twitter.com/AndaristRake) 显然厌倦了 TS 不适用于 `switch(true)` 和布尔比较之类的东西，因为他为这两个 (OSS FTW) 提供了修复。
    
*   **DX 改进** — 此版本还为类型添加了新的镶嵌提示、首选 `type` 自动导入 (`import { type Person } from "./types";`) 的设置以及 JSDoc 真相器的性能优化。
    

**底线：** 虽然我们对 TypeScript 添加新的语言功能感到兴奋，但它确实提出了一个有趣的问题，即 TypeScript 可以默许特定的 JavaScript 提案——有点像 TC39 委员会的 SuperPAC。

值得庆幸的是，小众语言功能不像实际政治那样令人担忧，似乎这里的每个人都只是想让开发人员更轻松。

发现错误：解决方案
-----------------------

#### 赞助[Datadog](https://www.datadoghq.com/bytes/)

函数 getEvenNumbers(numbers) {
让偶数数 = [];
    
for (let i = 0; i < numbers.length; i++) {
if (numbers[i] % 2 === 1) {
evennumbers.push(数字[i]);
}
}
    
返回偶数；
}
    
GetEvenNumbers([1,2,3,4,5,6])
    

我们的逻辑有点偏离。 `n % 2` 将返回 `0` 如果 `n` 是偶数。 错误是我们的代码检查它是否返回`1`（这将是一个奇数）。

要解决此问题，我们可以更改该行以查看它是否计算为 `0` 而不是 `1`。

函数 getEvenNumbers(numbers) {
让偶数数 = [];
    
for (let i = 0; i < numbers.length; i++) {
if (numbers[i] % 2 === 0) {
evennumbers.push(数字[i]);
}
}
    
返回偶数；
}
    
GetEvenNumbers([1,2,3,4,5,6])
