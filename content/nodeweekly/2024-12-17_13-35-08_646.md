2024 年对于 Node 来说是坚实的一年，[Node.js v22 版本](https://nodeweekly.com/link/163510/0a4070b383) 早在 4 月份就发布了（\[现在处于 LTS]\(https://nodeweekly. com/link/163511/0a4070b383)) 和 [v23 10 月。](https://nodeweekly.com/link/163512/0a4070b383) Node 今年也有了一个新的吉祥物\*(上图)\*，\[Express 5.0]\(https://nodeweekly.com/link/163513/0a4070b383 ）到达，节点已经[涉足类型剥离](https://nodeweekly.com/link/163514/0a4070b383)以更好地支持 TypeScript，并且[原生 SQLite 模块](https://nodeweekly.com/link/163515/0a4070b383) 一直在积极开发中。 *祈求 2025 年过得有趣！*

[Node v23.4.0（当前）发布](https://nodeweekly.com/link/163516/0a4070b383 "nodejs.org") — 新增 `--trace-env`、`--trace-env-js -stack` 和 `--trace-env-native-stack` 选项用于跟踪脚本使用的环境变量。此外，还添加了“assert.partialDeepStrictEqual”，作为一种更快速地断言对象中存在*某些*属性的方法 - 您不必提供全部属性。

🥇 2024 年顶级节点项目

从我们今年在 *Node Weekly* 中收录的 1694 个史诗般的链接中，我们将其归结为您点击次数最多的前 8 个链接：

1. [读写 Node.js 流指南](https://nodeweekly.com/link/163526/0a4070b383 "blog.platformatic.dev") — 看到这是我们最受欢迎的链接，我并不感到惊讶今年的。虽然 [streams](https://nodeweekly.com/link/163527/0a4070b383) 是一个长期存在的 Node 功能，但它们经常被误解，Matteo 很好地介绍了它们的优点、用例等。

马泰奥·科里纳

2. [九个节点支柱](https://nodeweekly.com/link/163528/0a4070b383 "www.platformatichq.com") — 一个有趣的列表，列出了自称的“在企业环境中正确使用 Node.js 的原则”由一群多产的 Node 贡献者编写。它可以作为一个清单来确定您当前实践中的差距，特别是在构建更大规模的应用时。

斯内尔、文迪托、道森、科里纳等人。

[使用 pgai Vectorizer 在 Postgres 中自动创建嵌入并同步](https://nodeweekly.com/link/163529/0a4070b383 "github.com") — 🚀 pgai Vectorizer 使用一个 SQL 命令在 Postgres 中自动创建嵌入并同步 — 保持嵌入已更新，无需任何工具。

时间尺度赞助商

3. [2024 年开始使用的 10 个现代 Node.js 运行时功能](https://nodeweekly.com/link/163530/0a4070b383 "snyk.io") — 这不仅仅是 Bun 和 Deno 添加了十几个新功能过去几年，Node 中也出现了很多新东西。 2024 年您使用了多少个？

利兰·塔尔

4. [Express v5 简介](https://nodeweekly.com/link/163513/0a4070b383 "expressjs.com") — 我们首次在 9 月份发现 Express.js v5 的发布，但官方博客文章最终在 10 月份发布，解释了 Node 长期存在的 Web 框架的总体计划。 v5 仍然是一个“*前沿*”版本，安全领域（例如[此安全审核](https://nodeweekly.com/link/163531/0a4070b383)）和整体流程仍需要开展工作。

韦斯·托德（快报）

5. [TypeSpec：一种受 TypeScript 启发的 API 定义方法](https://nodeweekly.com/link/163532/0a4070b383 "typespec.io") — 一种用于简明描述云服务 API 并生成其他 API 描述语言的语言 (例如 OpenAPI）、客户端和服务代码、文档等。顺便说一句，[v0.63](https://nodeweekly.com/link/163533/0a4070b383) 刚刚发布。

微软

💡 Nate Totten 的“[使用 TypeSpec 将类型引入 API](https://nodeweekly.com/link/163534/0a4070b383)”将使您了解使用 TypeSpec 的实用性。

6. [zx v8.0：Google 使用 Node 编写 Shell 脚本的方法](https://nodeweekly.com/link/163535/0a4070b383 "github.com") — 一种使 shell 脚本编写成为更愉快体验的长期方法与节点。 zx 围绕“child\_process”提供有用的包装器，转义参数并提供合理的默认值。 v8.0 使 zx *20x 更小*、更快，更容易终止进程、将输入传递给命令等等。它仍然是最新的主要版本，[v8.2.4](https://nodeweekly.com/link/163536/0a4070b383) 已于几周前登陆。

谷歌

7. [Node.js 最佳实践列表：2024 版](https://nodeweekly.com/link/163537/0a4070b383 "github.com") — 我们多年来链接的针对 Node 开发人员的深入指南。它分为八个部分并定期更新，深入探讨了从错误处理和代码风格到 Docker 和安全实践等领域。

约尼·戈德堡

8. [宣布 AdonisJS v6](https://nodeweekly.com/link/163538/0a4070b383 "adonisjs.com") — 一个 TypeScript 优先的后端 Web 框架，具有\[令人惊叹的文档]\(https://nodeweekly.com/link /163539/0a4070b383）并包含开箱即用的功能。 v6 是向前迈出的一大步，默认情况下转为使用 ESM，并且尽管是在一月份发布的，但它仍然是最新的主要版本。

哈明德·维克
