[Node.js 27 alpha：Node的新时间表下的第一个版本](https://nodejs.org/en/blog/release/v27.0.0-alpha.0.0.0 "NodeJS.org") — 在 Node 的 [new release model](https://nodejs.org/en/blog/announcements/evolving-the-nodejs-release-schedule) 下，每个主要版本在 Alpha 稳定发布之前花费了六个月的时间 — 因此 V27 的最终版本将于明年 4 月到期。 alpha 是从 `main` 中构建的，具有重大更改，适用于库作者/测试而不是 prod。

*   **V8 15.6** 默认带 [`Math.sumPrecise()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/sumPrecise)、[`Iterator.zip()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Iterator/zip) 和其他迭代器助手， [`import defer`](https://github.com/tc39/proposal-defer-import-eval) 和 [不可变 `ArrayBuffer`s](https://github.com/tc39/proposal-immutable-arraybuffer) 可用 国旗后面。
    
*   **有一个新的默认堆限制** 一半的物理内存（夹在 256MB 和 4GB 之间），以及 `Buffer`s [counts toward it](https://github.com/nodejs/node/pull/66601) 保存的内存。 如果您依赖旧的默认值，您可以设置 `--max-old-space-size`。
    
*   `v8.serialize()`、`structuredClone()` 和 `postMessage()` 使用旧节点无法读取的新格式，因此请注意混合版本的使用。
    
*   [`fs.glob`](https://nodejs.org/docs/v27.0.0-alpha.0.0.0/api/fs.html#fsglobpattern-options-callback) 现在是本地实现的，有一个实验性的 [`net/promises`](https://nodejs.org/docs/v27.0.0-alpha.0.0.0/api/net.html#netpromises-api) API，[`--allow-env`](https://nodejs.org/docs/v27.0.0-alpha.0.0.0/api/cli.html#--allow-env) 加入了权限模型。
    
*   [npm 12(.1)](https://github.com/npm/cli/releases/tag/v12.0.0) 现在捆绑在一起，所以 [there are breaking changes](https://github.blog/changelog/2026-06-09-upcoming-breaking-changes-for-npm-v12/) 需要注意。

**简要说明：**

*   Express 的 [October security roundup](https://expressjs.com/en/blog/2026-10-31-security-releases/) 涵盖了 `body-parser` 和 `multer` 中的 DOS 修复，以及 Brotli 缺陷：升级节点（但如果您不能的话，有一个解决方法）。
    
*   Vercel Now [block known-malicious npm package versions](https://vercel.com/changelog/blocking-malicious-npm-packages-before-and-during-installation) 在安装之前和安装期间，无需配置。
    
*   🔒 服务器框架安全更新是忙碌的一周：[Fastify 5.12.8](https://github.com/fastify/fastify/releases/tag/v5.12.8) 引领一波 Fastify 建议，包括 [critical proxy prefix escape](https://github.com/fastify/fastify-http-proxy/security/advisories/GHSA-h3vp-4jfr-v364)、[Hono 4.13.16](https://github.com/honojs/hono/releases/tag/v4.13.16) 修复了几个问题，[Nuxt 4.6.4 and Nitro 2.13.6](https://github.com/nuxt/nuxt/releases/tag/v4.6.4) 关闭了 11 个。
    

[跨包注册处的签名和证明](https://nesbitt.io/2026/10/30/signing-and-attestations-across-package-registries.html "nesbitt.io") — 对哪些 npm、pypi、rubygems、crates.io、go 和其他签名进行注册的注册表调查，这些标志产生出处证明，以及提供 值得信赖的出版，以方便的比较表结束。
