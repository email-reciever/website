Master.dev 赞助商

[立即升级：Node 的 10 月安全版本修复了 Brotli 漏洞](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases "nodejs.org") — 上周的版本（26.12.1、24.22.1 和 22.23.4）修复了十个 CVE， 包括 [a flaw in the bundled Brotli decoder](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases#nodejs-brotli-decoder-out-of-bounds-write-permits-remote-code-execution-cve-2026-111497---high)，因为被称为 [_Node2Shell_](https://www.imperva.com/blog/node2shell-from-brotli-data-to-remote-code-execution/)，如果应用解压缩恶意 Brotli 数据，例如通过 `node:zlib`，则可以允许远程执行代码。

node.js 项目

**简要说明：**

*   🔒 express [explains a body-parser bug](https://expressjs.com/en/blog/2026-10-28-cve-2026-111181/) 在 gzipped 主体之后的尾随字节可以让请求崩溃的进程。 它固定在 2.4.0 和 1.20.9 中。
    
*   在 [a TSC vote](https://github.com/nodejs/TSC/issues/1900) 之后，Node 将一个新的实验标志合并到 `node_modules`](https://github.com/nodejs/node/pull/63869 中的 TypeScript 中的 strip 类型)，但仅在标记为私有的包中，例如 Monorepo 工作空间。
    
*   [Electron 45](https://www.electronjs.org/blog/electron-45-0) 已退出，移至 Chromium 156、V8 15.6 和 Node 24.22。 沙盒预加载脚本丢失了 `Buffer` 和 `setImmediate` 全局变量，Electron 42 现在已经达到了它的生命周期。
    
*   GitHub 操作 [workflow lockfiles are now generally available](https://github.blog/changelog/2026-10-28-github-actions-workflow-lockfiles-are-generally-available) 让您在参与的工作流中固定操作及其依赖项。
    

[Web 无法承受 JavaScript 运行时单一文化](https://redmonk.com/kholterhoff/2026/10/27/js-runtime-monoculture/ "redmonk.com") — 由于 Deno 的运行时间将在其团队迁移到 Cloudflare 后逐渐减少，主要服务器端运行时的字段可能会缩小到 node、bun 和 `workerd`。 一位分析师利用 IE6、Chromium 的主导地位和 io.js 分叉来争论为什么这可能会让我们担心。

[Reylo: 将 `.sql` 文件导入到 TypeScript 中，使用完整类型推断](https://reylo.dev/ "reylo.dev") — 来自 ZOD 的创建者：将查询写入普通 `.sql` 文件和 `import` 到 TypeScript 中，从 SQL 中推断出行和参数类型。 没有 CodeGen 步骤，但它依赖于 TypeScript 7.1 的 [new content mappers](https://devblogs.microsoft.com/typescript/announcing-typescript-7-1-beta/#content-mappers)（现在处于测试阶段）。
