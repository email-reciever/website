**IN BRIEF:**

* Node already bundles `simdjson`, and its co-creator, Daniel Lemire, [has proposed a `node:json` module](https://nodeweekly.com/link/193051/0a4070b383) to expose it for faster, lazier JSON parsing.

* 💰 The OpenJS Foundation is [launching the *OpenJS Ad Network*](https://nodeweekly.com/link/193052/0a4070b383) as a way to raise funds for its various projects, including Node, Express and Fastify. The good news is it will use no behavioral targeting or third-party tracking.

* If you're running a long-lived HTTP server on Node 24, there's a setting you'll want to check. [A team traced steady memory growth](https://nodeweekly.com/link/193053/0a4070b383) to 24.18's larger default `Buffer.poolSize`, which setting it back to 8192 resolved.

* Node allows TLS 1.2 renegotiation by default, but [it's being deprecated](https://nodeweekly.com/link/193054/0a4070b383). The plan is to disable it by default in Node 27, with opt-in support (via the `allowRenegotiation` option) for legacy servers.

[Express is Now Observable by Design](https://nodeweekly.com/link/193055/0a4070b383 "expressjs.com") — Bye-bye monkey patching! Express 5's router now publishes a Node [`TracingChannel`](https://nodeweekly.com/link/193056/0a4070b383) for all middleware, route handlers and `router.param()` callbacks so APMs (or your own code) can subscribe from anywhere to get timings, errors and route patterns.

Abdelrahman Awad (Express)

💡 On a related note, [OpenTelemetry's JavaScript SDK 3.0](https://nodeweekly.com/link/193057/0a4070b383) is out. It now requires Node 22.15+, ships proper ESM and CommonJS exports, and makes logs stable.

[How Green Threads Would Work in Node](https://nodeweekly.com/link/193094/0a4070b383 "www.jasnell.me") — Last week we covered [James's PR](https://nodeweekly.com/link/193059/0a4070b383) adding an experimental `node:green_threads` module to Node. Here, he blogs about how they work, how they compare to worker threads and `vm` contexts, and the limitations of the approach.

James M Snell

[Replay Node 26: Time-Travel Debugging for Node](https://nodeweekly.com/link/193065/0a4070b383 "replay.io") — Wouldn't it be neat if you could add a `console.log` *after* a bug crops up?
