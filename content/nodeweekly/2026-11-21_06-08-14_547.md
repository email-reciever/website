**简要说明：**

*   Node 已经捆绑了 `simdjson`，它的共同创建者 Daniel Lemire [已经提出了一个 `node:json` 模块](https://github.com/nodejs/node/issues/67504) 来公开它以进行更快、更懒惰的 JSON 解析。
    
*   💰 OpenJS 基金会是 [launching the _OpenJS Ad Network_](https://openjsf.org/blog/introducing-the-openjs-ad-network) 为其各种项目筹集资金的一种方式，包括 Node、Express 和 Fastify。 好消息是它不会使用行为定位或第三方跟踪。
    
*   如果您在 Node 24 上运行长寿命的 HTTP 服务器，则需要检查一个设置。 [A team traced steady memory growth](https://github.com/nodejs/node/issues/67235) 到 24.18 的较大默认值 `Buffer.poolSize`，将其设置回 8192。
    
*   Node 默认允许 TLS 1.2 重新协商，但是 [it's being deprecated](https://github.com/nodejs/node/pull/67532)。 该计划是在 Node 27 中默认禁用它，并为传统服务器提供选择加入支持（通过 `allowRenegotiation` 选项）。
    

[EXPRESS 现在可以通过设计观察](https://expressjs.com/en/blog/2026-11-17-express-tracing-channels/ "ExpressJS.com") — 再见猴子补丁！ Express 5 的路由器现在为所有中间件、路由处理程序和 `router.param()` 回调发布一个节点 [`TracingChannel`](https://nodejs.org/api/diagnostics_channel.html#diagnostics-channel)，以便 APMS（或您自己的代码）可以从任何地方订阅以获取时序、错误和路由模式。
