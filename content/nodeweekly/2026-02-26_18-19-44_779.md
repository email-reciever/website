[AdonisJS v7 Released: 'Batteries-Included' Node.js Framework](https://nodeweekly.com/link/181226/0a4070b383 "adonisjs.com") — A popular webapp framework that includes auth, ORM, queues, testing, etc. in a cohesive fashion. With v7 comes [an all new web site](https://nodeweekly.com/link/181227/0a4070b383), modernizations, OpenTelemetry integration, new starter kits to rapidly build new apps, barrel file generation, and end-to-end type safety.

[Clerk Kills Credential Stuffing with Client Trust](https://nodeweekly.com/link/181225/0a4070b383 "go.clerk.com") — Valid password + new device + no MFA enabled = Clerk automatically requires a second factor. * [Node.js v25.7.0 (Current)](https://nodeweekly.com/link/181229/0a4070b383) and [v24.14.0 (LTS)](https://nodeweekly.com/link/181230/0a4070b383) have been released. [`node:sqlite`](https://nodeweekly.com/link/181264/0a4070b383) is now in the 'release candidate' stage.

* 🔒 In response to a growing number of low quality vulnerability reports, the Node.js project recently increased the 'signal score' required on HackerOne. Now, they've gone further [by not accepting reports from 'new researchers without signal'](https://nodeweekly.com/link/181233/0a4070b383) at all.

[How to Prevent Path Traversal Attacks in Node](https://nodeweekly.com/link/181234/0a4070b383 "nodejsdesignpatterns.com") — Path traversal attacks abuse specially crafted file paths to reach files an app didn't intend to expose. Luciano demonstrates a complete scenario, explores mitigations in depth, and includes a handy TLDR if you just want the essentials.

Luciano Mammino

🤖 [Getting Started with the Vercel AI SDK in Node](https://nodeweekly.com/link/181235/0a4070b383 "thecodebarbarian.com") — It provides a more abstract way to work with various AI API providers than jumping around different provider libraries.

Valeri Karpov

[Adding a Database Is Easier Than Removing One](https://nodeweekly.com/link/181236/0a4070b383 "www.tigerdata.com") — Extend the one you have instead. TimescaleDB adds hypertables, 95% compression, and continuous aggregates. [Try free](https://nodeweekly.com/link/181236/0a4070b383).

📄 [Why JavaScript Needs Structured Concurrency](https://nodeweekly.com/link/181238/0a4070b383) – And how [Effection](https://nodeweekly.com/link/181239/0a4070b383) can provide it. Taras Mankovski

[numpy-ts: A NumPy Implementation for TypeScript](https://nodeweekly.com/link/181241/0a4070b383 "numpyts.dev") — [NumPy](https://nodeweekly.com/link/181242/0a4070b383) is a fundamental piece of the Python scientific computing ecosystem and well-entrenched in many use cases. JavaScript has *some* options in this regard (e.g. [TensorFlow.js](https://nodeweekly.com/link/181243/0a4070b383)), but numpy-ts is an attempt to replace the NumPy experience as closely as possible (currently at 94% API coverage). There’s [an online playground](https://nodeweekly.com/link/181244/0a4070b383) if you want to give it a quick spin.

Nicolas Dupont

[Edge: A JS-Like Template Engine for Node](https://nodeweekly.com/link/181245/0a4070b383 "edgejs.dev") — A template engine that tries to stick as closely to JavaScript as possible, so you don’t have to learn a lot of new syntax for writing logic into your views (as you do with [Nunjucks](https://nodeweekly.com/link/181246/0a4070b383) or [Pug](https://nodeweekly.com/link/181247/0a4070b383), say).

📢  Elsewhere in the ecosystem

* [Deno 2.7 has been released.](https://nodeweekly.com/link/181256/0a4070b383) The alternative runtime, built by Node's original creator, makes its Temporal API support stable, adds Windows on ARM support, gains support for `overrides` in `package.json`, improved Node.js compatibility, and more.

* [NanoVM](https://nodeweekly.com/link/181257/0a4070b383) is an experimental RISC-V Linux userland emulator that can run Node.js and the npm toolchain in the browser. We've featured a few 'run Node.js in the browser' projects recently ([almostnode](https://nodeweekly.com/link/181258/0a4070b383), [BrowserPod](https://nodeweekly.com/link/181259/0a4070b383)) – it's an interesting space.

* A cute technical trick for [using the browser's `canvas` element to compress textual data from JavaScript.](https://nodeweekly.com/link/181260/0a4070b383)

* The React team has [unveiled the details of the new *React Foundation*](https://nodeweekly.com/link/181261/0a4070b383) which has now launched and means React (and its associated projects) are no longer owned by Meta.

* [Detailed notes for performing a TypeScript 5.x to 6.0 migration.](https://nodeweekly.com/link/181262/0a4070b383) The author suggests it might be handy to feed to an AI agent of your choice.
