[pnpm 10.21: Safer Installs and Smarter Runtime Management](https://nodeweekly.com/link/176820/0a4070b383 "pnpm.io") — pnpm can now automatically install the Node version required by a dependency, declared in its `engines.runtime` field, meaning CLI apps and `postinstall` scripts will run with the specified version. A new `trustPolicy` setting also adds protection against supply-chain attacks by failing to install packages whose trust level drops (e.g. if a package’s build pipeline loses attestation).

Zoltan Kochan
