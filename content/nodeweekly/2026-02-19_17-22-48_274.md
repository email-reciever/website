**IN BRIEF:**

* [Node.js 25.6.1 (Current)](https://nodeweekly.com/link/180912/0a4070b383) has been released replacing `cjs-module-lexer` with `merv`. [v24.13.1 (LTS)](https://nodeweekly.com/link/180913/0a4070b383) has also been released.

* ⭐ [The Temporal API is close to being enabled by default](https://nodeweekly.com/link/180914/0a4070b383) in a future Node.js release.

* Joyee Cheung has added the ability for Node [single executable applications (SEA)](https://nodeweekly.com/link/180915/0a4070b383) to [support ESM entrypoints](https://nodeweekly.com/link/180916/0a4070b383) (non-builtin access is not supported, but Matteo Collina's [work on a virtual file system module](https://nodeweekly.com/link/180917/0a4070b383) may enable that).

* 🔒 npm package pages [now link directly to Socket's security analysis](https://nodeweekly.com/link/180918/0a4070b383) for each package. Here's [the one for `express`](https://nodeweekly.com/link/180919/0a4070b383), for example.

* Node's `zlib` is also about to get [support for custom Brotli compression dictionaries.](https://nodeweekly.com/link/180920/0a4070b383)

📊 [Node.js vs Deno vs Bun Performance Benchmarks](https://nodeweekly.com/link/180921/0a4070b383 "www.repoflow.io") — A few weeks ago, RepoFlow did a handy [version-by-version Node benchmark](https://nodeweekly.com/link/180922/0a4070b383) and now they’re back with some micro-benchmarks comparing Node, Deno and Bun. As always with benchmarks, apply a critical eye!
