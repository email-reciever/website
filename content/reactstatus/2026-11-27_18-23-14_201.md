[Ricky Hanlon 离开 Meta (但不会离开 React)](https://react.statuscode.com/link/193565/5d0bbb4a61 "bsky.app") — 经过多年帮助 React *"从 400 万增长到 2.5 亿的每周下载量"*, Ricky 离开了 React 的诞生地，提到 *"大多数 React 核心团队成员已经离开 Meta"*. 这更像是 *"一个时代的结束"* 而不是大新闻，因为他将继续为 React 工作，且 [React 今年拥有自己的基金会](https://react.statuscode.com/link/193566/5d0bbb4a61) 向我们展示了发展方向。
