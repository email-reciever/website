⚠️ [A Critical Security Vulnerability in React Server Components](https://react.statuscode.com/link/177946/5d0bbb4a61 "react.dev") — Breaking news from the React team for anyone whose app supports RSCs, even if it’s not using them. v19.0, 19.1.0, 19.1.1, and 19.2.0 of `react-server-dom-webpack`, `react-server-dom-parcel` and `react-server-dom-turbopack` are susceptible to a remote code execution vulnerability and you need to upgrade. However, **"if your app’s React code does not use a server, your app is not affected by this vulnerability."**
