仔细看看为什么用户在日常生活中不需要更多的工具。 他们需要的是无缝集成有用的功能，以匹配现有的、既定的心智模型。 由 [Design Patterns For AI Interfaces](https://ai-design-patterns.com/) 带给您，**关于 UX** 的友好视频课程和 Vitaly 的设计模式。

我们经常听到改变一切的闪亮的新工具（再次）。 但在实践中，大多数人**在日常生活中不需要更多的工具**来处理。 我们真正需要的是**更好地整合有用的能力**，与我们现有和既定的心理模型完美契合。

用户不会对闪亮的新“智能”工作流程、导航终端命令或在无休止的来回聊天交互之间跳跃感到兴奋。 他们需要有用功能的**无缝集成**来解决高严重性、高频率和高水平挫败感的问题。

1\。 人工智能与安静的人工智能
--------------------------

我一直对 **“AI-First”** 产品的概念感到困惑。 它们可能会加快生产速度，但我们首先需要非常清楚我们真正想要构建的内容。 AI-First 通常不考虑多年来塑造了期望和心理模型的**年大小的设计决策**。

[![A neat Claude Excel integration](https://res.cloudinary.com/indysigner/image/fetch/f_auto,q_80/w_400/https://files.smashing.media/articles/ux-impact-seamless-integrations/claude-excel-integration.jpg)](https://www.reddit.com/r/ClaudeAI/comments/1ql5rme/claude_in_excel_is_now_available_on_pro_plans/)

一个简洁的 [Claude Excel integration](https://www.reddit.com/r/ClaudeAI/comments/1ql5rme/claude_in_excel_is_now_available_on_pro_plans/)，用户研究特定的行或列，而不是一直在工具之间切换。 （[Large preview](https://files.smashing.media/articles/ux-impact-seamless-integrations/claude-excel-integration.jpg)）

我喜欢**“安静的人工智能”**的概念。 这些工具大多是不可见的，坐在后台，并代表用户完成小任务。 他们从不尖叫着引起注意，但很乐意帮助重复、令人沮丧的任务，这些任务可以很容易地自动化或协助智能助手。

安静人工智能的优秀示例包括 **Claude 在 Microsoft Excel、PowerPoint 和 Word 中的集成，在不影响用户工作流程的情况下提供帮助。

2\。 AI 操作的文件夹说明
------------------------------------

所以难怪我绝对喜欢[folder instructions](https://uxdesign.cc/folder-instructions-instructions-for-system-level-ai-c6113ff78287)的想法！ 在那里，用户可以根据他们创建的目的定义文件夹应该做什么。 这听起来比实际复杂得多。

[![A dark-themed digital interface showing a folder labeled Passport Application, with instructions and system rules for a passport renewal process.](https://res.cloudinary.com/indysigner/image/fetch/f_auto,q_80/w_400/https://files.smashing.media/articles/ux-impact-seamless-integrations/folder-instructions-passport-application.jpg)](https://uxdesign.cc/folder-instructions-instructions-for-system-level-ai-c6113ff78287)

用户定义指令，选择系统规则，系统负责完成任务。 （[Large preview](https://files.smashing.media/articles/ux-impact-seamless-integrations/folder-instructions-passport-application.jpg)）

指令定义了文件夹的用途、**文件的组织方式**、子文件夹的行为方式以及内部可能发生的操作。 而不是手动维护一个文件夹，你设置它的意图一次，让系统跟随它。

它是 AI Helpers 的**无缝集成**，只是用户在何时何地想要和需要它。 除非用户自行扩展访问权限、权限或系统规则，否则将权限和操作局限于用户计算机上的该特定文件夹。

[![A dark-themed software interface showing a file management setup for summarizing PDFs. It displays instructions and system rules.](https://res.cloudinary.com/indysigner/image/fetch/f_auto,q_80/w_400/https://files.smashing.media/articles/ux-impact-seamless-integrations/file-management-setup-summarizing-pdfs.jpg)](https://uxdesign.cc/folder-instructions-instructions-for-system-level-ai-c6113ff78287)

用户可以自动执行工作实际发生的任务，例如，即时生成摘要。 （[Large preview](https://files.smashing.media/articles/ux-impact-seamless-integrations/file-management-setup-summarizing-pdfs.jpg)）

以下是一些有用的例子：

*   对于**护照更新**，请获取表格并收集我需要的所有文件。 告知缺少文件，并尽您所能填写表格。
*   当**新发票**添加到文件夹中时，按顺序对它们进行重命名，按发票编号对它们进行排序，并按客户端将它们组织到文件夹中。
*   当一个**新的PDF添加到文件夹**时，生成一个摘要，发送到我的口袋，并通过电子邮件向我发送通知。

**注意**：为了更深入地了解这个概念，您可以跳转到 Karthikeya GS 的精彩帖子“[Folder Instructions: Instructions For System-Level AI](https://uxdesign.cc/folder-instructions-instructions-for-system-level-ai-c6113ff78287)”。

包起来
------------

用户的价值不会来自于每隔几分钟就不得不在多个应用程序、视图和来源之间进行协调的用户的价值。 那是他们放慢速度的时候，那是他们犯错误的时候。

它来自帮助用户完成他们需要做的工作——通过**减少挫败感**、减速和错误，以及处理否则会花费太多时间和过多努力才能完成的任务。

再一次，**无缝集成** - 一种非常未被利用但非常有影响力的快速交付价值的方式，无需增加安装和学习另一个工具的负担。
