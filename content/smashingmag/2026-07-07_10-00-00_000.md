多年来，WordPress 用户一直依靠传统的页面构建器来创建没有编写代码的网站。 虽然这些构建器使网页设计更易于访问，但许多仍然带有熟悉的折衷方案——严格的布局、依赖多个第三方插件、臃肿的代码和可能会减慢您网站速度的性能权衡。

[Kirki](https://kirki.com/) 采用不同的方法。 它不是建立在旧页面构建器的惯例上，而是通过自由形式的无限画布、集成的 CMS 和一组全面的内置功能重新构想了网站创建体验。 结果是简化的工作流程，在制作更清晰、更快的网站的同时为您提供更大的创作自由。

无论您是寻求像素完美控制的设计师、寻求更清洁输出的开发人员，还是只是想建立一个没有不必要复杂性的专业网站的企业主，Kirki 的目标都是消除与 WordPress 页面构建器相关的许多限制。

在这篇评论中，我们将在选择网站构建器时将 Kirki 与传统的 WordPress 构建器进行比较，这些因素最重要，包括：

*   价格和整体价值，
*   对网站性能的影响，
*   易用性与设计灵活性，
*   内置的特性和功能，
*   主题兼容性和布局定制。

到最后，您将清楚地了解 Kirki 的立场以及它是否是您下一个 WordPress 项目的正确选择。

探索功能
-----------------------

既然我们已经看到了 Kirki 如何在竞争激烈的情况下表现出色，并以极具竞争力的价格做到了这一点，让我们深入了解功能，看看是什么让它成为如此强大的多合一构建器。

### 真正的设计自由的自由形式无限画布

Kirki 与现有页面构建器的不同之处在于它的 [infinite canvas](https://kirki.com/canvas/)。

有了 Kirki，您终于可以获得现代设计的布局灵活性，不再需要将元素放置在刚性结构中。

[![Interface screenshot of Kirki’s drag-and-drop freeform visual canvas.](https://res.cloudinary.com/indysigner/image/fetch/f_auto,q_80/w_400/https://files.smashing.media/articles/kirki-freeform-visual-website-builder-wordpress/7-kirki-drag-and-drop-freeform-visual-canvas.jpg)](https://files.smashing.media/articles/kirki-freeform-visual-website-builder-wordpress/7-kirki-drag-and-drop-freeform-visual-canvas.jpg)

Kirki 灵活的自由曲面画布可实现像素完美的设计自由。 （[Large preview](https://files.smashing.media/articles/kirki-freeform-visual-website-builder-wordpress/7-kirki-drag-and-drop-freeform-visual-canvas.jpg)）

在**无限画布上进行设计**，您可以在其中自由平移、放大和缩小，将元素精确放置在您想要的位置，重叠部分，图层背景，并在视觉上构建复杂的交互。

每个元素的布局行为都可以在画布上编辑，无需触摸代码即可为您提供像素级控制。

编辑器支持明暗模式，以获得更舒适、更集中的工作空间。

如果您使用过 Figma 或 WebFlow，您会立即感到宾至如归。 如果您还没有，这是设计您尝试过的网站的最自然方式。

### 所有响应视图的并发编辑

借助 Kirki 的无限画布，您所有的响应式视图、桌面、平板电脑、景观和移动设备都可以并排显示。 你不切换模式。 您可以在同一幅画布上实时、实时地跨所有这些工作。

这意味着您可以在设计桌面版本时在移动设备上发现布局问题，立即修复它，并在不破坏流程的情况下继续前进。 没有来回。

[![Interface screenshot of Kirki’s drag-and-drop freeform visual canvas.](https://res.cloudinary.com/indysigner/image/fetch/f_auto,q_80/w_400/https://files.smashing.media/articles/kirki-freeform-visual-website-builder-wordpress/8-concurrent-editing-responsive-views.jpg)](https://files.smashing.media/articles/kirki-freeform-visual-website-builder-wordpress/8-concurrent-editing-responsive-views.jpg)

在无限画布上的所有响应视图中并发编辑。 （[Large preview](https://files.smashing.media/articles/kirki-freeform-visual-website-builder-wordpress/8-concurrent-editing-responsive-views.jpg)）

而且由于 Kirki 使用级联系统，因此在较大断点处所做的更改会自动流向较小的系统，因此您永远不会在每个屏幕尺寸上从头开始。 您只需踏入您需要的位置，在设计需要的地方进行调整，并让其余部分自己处理。

### 动态内容不需要第三方插件

在传统的 WordPress 中，处理动态内容意味着安装 ACF 或其他第三方插件。

[![Image showing Kirki’s dynamic content management capabilities.](https://res.cloudinary.com/indysigner/image/fetch/f_auto,q_80/w_400/https://files.smashing.media/articles/kirki-freeform-visual-website-builder-wordpress/10-kirki-native-dynamic-content-management.jpg)](https://files.smashing.media/articles/kirki-freeform-visual-website-builder-wordpress/10-kirki-native-dynamic-content-management.jpg)

Kirki 的原生动态内容管理，无需第三方插件。 （[Large preview](https://files.smashing.media/articles/kirki-freeform-visual-website-builder-wordpress/10-kirki-native-dynamic-content-management.jpg)）

但是对于 Kirki，所有这些都是本地集成的。 它带有一个强大的 [Dynamic Content Manager](https://kirki.com/docs/content-manager-overview/)，让您：

*   创建自定义内容类型和字段。
*   使用引用和多引用关系。
*   可视化构建动态模板。
*   将动态SEO添加到模板页面。
*   对集合元素应用高级过滤。

全部无需编写一行代码或依赖外部插件。

### 基于类编辑的可重复使用的样式

Kirki 也有一种有效的方式来大规模管理设计，而无需重复工作。

[![Screenshot of Kirki’s CSS class management panel.](https://res.cloudinary.com/indysigner/image/fetch/f_auto,q_80/w_400/https://files.smashing.media/articles/kirki-freeform-visual-website-builder-wordpress/11-reusable-styling-class-based-editing.jpg)](https://files.smashing.media/articles/kirki-freeform-visual-website-builder-wordpress/11-reusable-styling-class-based-editing.jpg)

可重复使用和可扩展设计的高效基于类的造型系统。 （[Large preview](https://files.smashing.media/articles/kirki-freeform-visual-website-builder-wordpress/11-reusable-styling-class-based-editing.jpg)）

它使用基于类的样式系统，为您的设计过程带来结构和可扩展性。 当您对元素进行样式设置时，这些样式会自动保存为可重用的 CSS 类。

这对你来说意味着什么：

*   您可以**为按钮、卡片或标题等常见组件创建全局类**。
*   **在页面和项目中以一致性重复使用这些样式**。
*   更新一个类一次，每个实例立即更新。
*   您还可以**创建子类**以进行细微的变化，例如辅助按钮，同时仍然从父级继承样式。

Kirki 进一步使用 [Global Variables](https://kirki.com/docs/variables/) 进行样式化，允许您定义可以在整个站点上重复使用的颜色、字体、间距和大小等设计令牌。

[![Interface displaying CSS variables used for colors, fonts, and spacing in Kirki.](https://res.cloudinary.com/indysigner/image/fetch/f_auto,q_80/w_400/https://files.smashing.media/articles/kirki-freeform-visual-website-builder-wordpress/12-css-variables-global-styling.jpg)](https://files.smashing.media/articles/kirki-freeform-visual-website-builder-wordpress/12-css-variables-global-styling.jpg)

您可以将这些全局变量与基于类的结构配对：

*   保持视觉一致性。
*   单一更改全局更新值。
*   一键轻松管理诸如在明暗模式之间切换的主题。

虽然 Kirki 提供了完全的视觉体验，但它并没有限制高级用户。 您可以为任何类或元素编写自定义 CSS，甚至在需要时在页面或元素级别注入 JavaScript。

Kirki no-code 网站构建器真正帮助您超越通用并创建独特的动画和复杂的交互。
