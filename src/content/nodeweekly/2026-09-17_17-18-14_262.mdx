[Why (and How) GitHub Ported Copilot's Runtime from Node to Rust](https://nodeweekly.com/link/190504/0a4070b383 "github.blog") — GitHub's _Copilot_ runtime moved to Rust, ported in pieces behind [napi-rs](https://nodeweekly.com/link/190505/0a4070b383) shims while shipping daily. Startup times and memory usage inspired the move, but the gold for porters is in the regressions they hit involving number types, `||` semantics, and blocking the event loop.

Stephen Toub (Microsoft)

[![](https://res.cloudinary.com/cpress/image/upload/c_limit,w_480,h_480,q_auto/copm/fe329987.png)](https://nodeweekly.com/link/190503/0a4070b383)

[That p99 Spike Is One Slow Analytics Query](https://nodeweekly.com/link/190503/0a4070b383 "www.tigerdata.com") — One endpoint runs an analytics query over millions of rows, and latency spikes for everyone. TimescaleDB extends Postgres so that query returns in milliseconds at scale. Hypertables, compression, continuous aggregates. [Get $1000 credit to start](https://nodeweekly.com/link/190503/0a4070b383).

Tiger Data (creators of TimescaleDB) sponsor

**IN BRIEF:**

*   Node is to get [`util.debounce()` and `util.throttle()` functions](https://nodeweekly.com/link/190506/0a4070b383), two staples of utility libraries. They've landed on main for a future release.
    
*   🔒 [Moment.js 2.31.0](https://nodeweekly.com/link/190507/0a4070b383) is a key update. The date library is in 'maintenance mode', but gets 25M downloads a week, and v2.31.0 [fixes a path traversal vulnerability](https://nodeweekly.com/link/190508/0a4070b383).
    
*   The Node.js Web Team's [redesigned API docs](https://nodeweekly.com/link/190509/0a4070b383) have [been merged](https://nodeweekly.com/link/190510/0a4070b383) and should reach `nodejs.org/api` alongside a release soon.
    
*   In Node 27, the HTTP client will [reject responses with more headers than `request.maxHeadersCount`](https://nodeweekly.com/link/190511/0a4070b383) (1000 by default right now) instead of just truncating them.
    

[Node.js 26.9.0 (Current) Released](https://nodeweekly.com/link/190512/0a4070b383 "nodejs.org") — A reasonably significant minor release that brings a few new things to the table:

*   [`node:ffi`](https://nodeweekly.com/link/190513/0a4070b383) is enabled by default (but still _experimental_), so you can call functions in native libraries without writing an addon.
*   [`node:bench`](https://nodeweekly.com/link/190514/0a4070b383) is a new benchmarking module modeled on `node:test`.
*   [Web Workers now have an experimental implementation](https://nodeweekly.com/link/190515/0a4070b383) (behind a flag), so browser-style `new Worker()` and `postMessage`, etc. can be used.
*   [Worker threads start up to twice as fast](https://nodeweekly.com/link/190516/0a4070b383) (per initial benchmarks) and use less memory, as they now start from Node's [built-in snapshot](https://nodeweekly.com/link/190517/0a4070b383).
