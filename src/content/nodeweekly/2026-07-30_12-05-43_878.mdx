[npm to Scan Every Package For Malware at Publish Time](https://nodeweekly.com/link/188600/0a4070b383 "github.blog") — The npm registry is beginning to scan packages at publish time, meaning new versions can take several minutes to become installable, and _could_ be held or blocked.

GitHub

**IN BRIEF:**

*   🔒 The [Wednesday, July 29, 2026 Security Releases](https://nodeweekly.com/link/188601/0a4070b383) of Node are available as [Node v26.5.1](https://nodeweekly.com/link/188602/0a4070b383), [v24.18.1](https://nodeweekly.com/link/188603/0a4070b383) and [v22.23.2](https://nodeweekly.com/link/188604/0a4070b383). 11 CVEs are tackled, including two HTTP/2 flaws, a Permission Model allowlist bypass, and more.
    
*   Microsoft is previewing [a way to call native Windows APIs from Node](https://nodeweekly.com/link/188605/0a4070b383) (and therefore Electron) _without_ native addons via a new dynamic Windows Runtime API (WinRT) projection.
    
*   [Amazon's security team has narrowed down](https://nodeweekly.com/link/188606/0a4070b383) several npm supply chain attacks (such as those on `debug` and `chalk`) to a single North Korean-linked group.
    
*   Cloudflare's `wrangler` can now [run integration tests against Workers from any Node.js test runner](https://nodeweekly.com/link/188607/0a4070b383).
    

[Check Out Node's New API Documentation Preview](https://nodeweekly.com/link/188608/0a4070b383 "nodejs.org") — Node's official API docs have been getting redesigned (now sharing a design system with [nodejs.org](https://nodeweekly.com/link/188609/0a4070b383) itself) and have a new built-in search feature. You're invited to [try the preview here](https://nodeweekly.com/link/188610/0a4070b383) and report what breaks.

Guilherme Araújo (Node.js Team)

[How GitHub Is Disrupting Supply Chain Attacks on npm and Actions](https://nodeweekly.com/link/188611/0a4070b383 "github.blog") — Separate to the scanning news above, GitHub's team explains recent npm and Actions changes designed to mitigate supply chain attack techniques.

[scriptc: Vercel's New TypeScript-to-Native Compiler](https://nodeweekly.com/link/188615/0a4070b383 "scriptc.dev") — A new entry into the growing field of JS/TS native ahead-of-time compilers that makes the promise that _"what compiles behaves byte-for-byte like Node."_ Static by default, but you can opt in to a `--dynamic` mode which embeds a JavaScript engine for runtime dynamism. [GitHub repo](https://nodeweekly.com/link/188616/0a4070b383).

Vercel Labs

[Fast Endpoints Shouldn't Choke on Analytics](https://nodeweekly.com/link/188617/0a4070b383 "www.tigerdata.com") — TimescaleDB extends Postgres so heavy queries stay fast at scale. One database, not two. [Get $1000 credit to start](https://nodeweekly.com/link/188617/0a4070b383).

Tiger Data (creators of TimescaleDB) sponsor

[tslog 5: Zero-Dependency Logger for Node, Deno, Bun and Browsers](https://nodeweekly.com/link/188618/0a4070b383 "tslog.js.org") — A ground-up rewrite that's now ESM-only. Pretty output by default, JSON optionally, plus middleware, file/HTTP/worker transports, secret masking, and error stacks that resolve through source maps to your `.ts` code. [GitHub repo](https://nodeweekly.com/link/188619/0a4070b383).

Eugene Terehov

[npm-check-updates 23.0: Find Newer Versions of Dependencies](https://nodeweekly.com/link/188620/0a4070b383 "github.com") — Find newer versions than your `package.json` allows. Has a `-i` interactive mode to look at upgrades and opt in to them one by one. Supports custom cooldown periods. [v23](https://nodeweekly.com/link/188621/0a4070b383) is faster, smaller, and is now a pure ESM package.

Raine Revere

[jsdom 30.0: Pure JS Implementation of Web Standards for Node](https://nodeweekly.com/link/188622/0a4070b383 "github.com") — The venerable browser-environment emulator used by countless test suites. v30.0 adds `CSS.escape()`, `CSS.supports()`, `background-position-x`/`y`, as well as some fixes.

Denicola, Insua, et al.

[crypto-random-string 6.0: Generate a Cryptographically Strong Random String](https://nodeweekly.com/link/188623/0a4070b383 "github.com") — For example: `cryptoRandomString(&lcub;length: 10})` might return `2cf05d94db`. v6.0 improves performance and removes `cryptoRandomStringAsync`.

Sindre Sorhus

*   [Ada v4](https://nodeweekly.com/link/188624/0a4070b383) – The WHATWG-compliant URL parser used by Node is now even faster.
    
*   [Wasp v0.25](https://nodeweekly.com/link/188625/0a4070b383) – The Rails-esque framework for building full-stack webapps with React & Node introduces Vite 8 and React Router 8.
    
*   [modern-tar 0.8](https://nodeweekly.com/link/188626/0a4070b383) – Zero-dependency streaming `tar` parser and writer.
    
*   📋 [tinyclip 1.0](https://nodeweekly.com/link/188627/0a4070b383) – Cross-platform clipboard utility library.
    
*   [Nub 0.6](https://nodeweekly.com/link/188628/0a4070b383) – Fast all-in-one toolkit that augments Node.
    
*   [Verdaccio 6.9](https://nodeweekly.com/link/188629/0a4070b383) – Self-hostable private npm registry.
