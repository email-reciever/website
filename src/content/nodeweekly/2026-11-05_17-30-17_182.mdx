[Node.js 27 Alpha: The First Release Under Node's New Schedule](https://nodeweekly.com/link/192446/0a4070b383 "nodejs.org") — Under Node's [new release model](https://nodeweekly.com/link/192447/0a4070b383), each major release spends six months in alpha before stable release — so v27's final is due next April. Alphas are built from `main` with breaking changes, and are meant for library authors / testing rather than prod.

*   **V8 15.6** brings [`Math.sumPrecise()`](https://nodeweekly.com/link/192448/0a4070b383), [`Iterator.zip()`](https://nodeweekly.com/link/192449/0a4070b383) and other iterator helpers by default, and [`import defer`](https://nodeweekly.com/link/192450/0a4070b383) and [immutable `ArrayBuffer`s](https://nodeweekly.com/link/192451/0a4070b383) are available behind flags.
    
*   **There's a new default heap limit** of half of physical memory (clamped between 256MB and 4GB), and memory held by `Buffer`s [counts toward it](https://nodeweekly.com/link/192452/0a4070b383). If you relied on the old defaults, you can set `--max-old-space-size`.
    
*   `v8.serialize()`, `structuredClone()` and `postMessage()` use a new format unreadable by older Nodes, so take care with mixed-version use.
    
*   [`fs.glob`](https://nodeweekly.com/link/192453/0a4070b383) is now implemented natively, there's an experimental [`net/promises`](https://nodeweekly.com/link/192454/0a4070b383) API, and [`--allow-env`](https://nodeweekly.com/link/192455/0a4070b383) joins the permission model.
    
*   [npm 12(.1)](https://nodeweekly.com/link/192456/0a4070b383) is now bundled so [there are breaking changes](https://nodeweekly.com/link/192457/0a4070b383) to be aware of.
