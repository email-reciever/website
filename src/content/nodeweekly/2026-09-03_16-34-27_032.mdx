📊 [Bun 1.4 Now Passes 80% of Node's Test Suite](https://nodeweekly.com/link/189813/0a4070b383 "bun.com") — [Bun 1.4](https://nodeweekly.com/link/189814/0a4070b383)'s headline feature is a [big jump in Node.js compatibility](https://nodeweekly.com/link/189815/0a4070b383) as part of its goal of being a _"drop-in replacement"_. This page lets you see the project's progress and where Bun is strong and weak.

Bun Project

**IN BRIEF:**

*   Matteo Collina has landed [`node:ffi` enabled by default](https://nodeweekly.com/link/189816/0a4070b383), so calling into a native C library will no longer need `--experimental-ffi`, an addon, or `node-gyp`. It remains experimental, warns on first load, and hasn't shipped in a release yet.
    
*   Matteo has also added support for _Single Executable Applications_ to [mount their bundled assets as a read-only virtual file system](https://nodeweekly.com/link/189817/0a4070b383) by setting `"useVfs": true` in the config.
    
*   🔒 Express has patched [six vulnerabilities across `hbs`, `multer` and `morgan`](https://nodeweekly.com/link/189818/0a4070b383).
    
*   Node's issue tracker reaches issue `2**16` with [a proposal to remove dual ESM/CJS code samples in the API docs](https://nodeweekly.com/link/189819/0a4070b383).
    

[Rewriting a Node.js Service in Go with AI Agents](https://nodeweekly.com/link/189820/0a4070b383 "www.checklyhq.com") — A very 2026 tale of an overnight porting run, with a focus on doing agentic engineering well. Good takeaways on building a test harness _first_ and the rollout experience.

Edvinas Janusevicius (Checkly)

[Your Trace Shows the Slow Span. Not the Exception](https://nodeweekly.com/link/189823/0a4070b383 "blog.sentry.io") — OTLP carries traces and logs, not errors. Sentry's OtlpIntegration connects both in one trace waterfall. [Learn more about Sentry’s OTLP](https://nodeweekly.com/link/189823/0a4070b383).

Sentry sponsor

🛠 Code & Tools

[![](https://res.cloudinary.com/cpress/image/upload/w_1280,e_sharpen:60,q_auto/deovjytt53exk0rla8fs.jpg)](https://nodeweekly.com/link/189826/0a4070b383)

[Drydock: Diff Your `npm` Tarballs Before You Publish](https://nodeweekly.com/link/189826/0a4070b383 "drydock.org") — From a Preact core team member comes a tool to diff built npm tarballs against the last published version, flagging install scripts, network access and new binaries. It can then gate your _Actions_ publish job or watch npm's new staged publishing flow.

Jovi De Croock

💡 You can get a quick taste without installing anything: [this web-based diff viewer](https://nodeweekly.com/link/189827/0a4070b383) can compare two versions of an npm package file by file.

[srvx 1.0: One `fetch` Handler for Node, Deno and Bun](https://nodeweekly.com/link/189828/0a4070b383 "srvx.h3.dev") — You can export a handler that takes a web-standard `Request` and returns a `Response`, then run it unchanged on Node, Deno or Bun. Includes a CLI with watcher and static serving, and `srvx fetch` can hit your handler without starting a server.

Pooya Parsa

[NVM for Windows 2.0: Node Version Manager for Windows](https://nodeweekly.com/link/189829/0a4070b383 "docs.nvm-windows.com") — A modern Node workflow for Windows users with version pinning, native integrations, auto-install of missing versions, and more. v2 is a rewrite that introduces a lighter shim-based mechanism and _no longer needs admin privileges_. [GitHub repo](https://nodeweekly.com/link/189830/0a4070b383).

Author Software Inc

[Got 16.0: Built-In HTTP/2 and QUERY Method Support](https://nodeweekly.com/link/189831/0a4070b383 "github.com") — The popular Node HTTP client now has a built-in HTTP/2 client, its own DNS cache, fewer dependencies, and support for the newly standardized [`QUERY` HTTP method](https://nodeweekly.com/link/189832/0a4070b383).

Sindre Sorhus

[SimpleWebAuthn 14.0: Now with Post-Quantum Passkeys](https://nodeweekly.com/link/189833/0a4070b383 "github.com") — The passkeys library now verifies post-quantum ML-DSA passkeys and, on Node 24.7 and up, prefers ML-DSA-44 at registration by default.

Matthew Miller

*   [Restify 12.0](https://nodeweekly.com/link/189834/0a4070b383) – The REST API framework returns after a two and a half year gap with Node 26 support and `url.parse()` replaced with WHATWG URL. Existing users have [a few breaking changes](https://nodeweekly.com/link/189835/0a4070b383) to note.
    
*   [Zod 4.5](https://nodeweekly.com/link/189836/0a4070b383) – A big performance release for the popular TypeScript-first schema validation library.
    
*   [np 12.1](https://nodeweekly.com/link/189837/0a4070b383) – Sindre Sorhus's improved `npm publish` workflow gets some speedups.
    
*   [express-rate-limit 8.7](https://nodeweekly.com/link/189838/0a4070b383) – Rate-limiting middleware for Express.
