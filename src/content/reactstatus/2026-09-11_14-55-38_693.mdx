What's New in React 19.3

[React 19.3 is here with a _huuuge_ release post](https://react.statuscode.com/link/190230/5d0bbb4a61) (that's packed with examples) bringing two anticipated APIs out of experimental status, as well as some [Server Components additions](https://react.statuscode.com/link/190231/5d0bbb4a61). Here are some of the goodies:

*   **Fragment Refs:** Manage focus, events and measurements across a group of DOM nodes (a _component_, say!) _without_ adding a wrapper element that could disrupt your layout.
    
*   **View Transitions:** &lt;`ViewTransition`\> animates elements entering, leaving or changing in transition updates, with support for Suspense reveals and animations you can customize with CSS.
    

💡 For a hands-on feel, [Chris Coyier's review of `&lt;ViewTransition>`](https://react.statuscode.com/link/190232/5d0bbb4a61) from January still holds up, though it doesn't cover `addTransitionType`.

*   **Trusted Types support:** React now preserves trusted objects when passing values to DOM APIs like `innerHTML`, avoiding string coercion that caused browsers enforcing [Trusted Types](https://react.statuscode.com/link/190233/5d0bbb4a61) to reject them.
    
*   **Opt out of server rendering:** [`use(browser())`](https://react.statuscode.com/link/190234/5d0bbb4a61) lets a component render only in the browser, showing its nearest Suspense fallback in the generated HTML.
    

Elsewhere, &lt;`Activity`\> gains Server Component support, there's support for the new &lt;`select`\> parsing rules, and transitions now render independently, so a slow one no longer blocks unrelated ones. [The full release notes](https://react.statuscode.com/link/190235/5d0bbb4a61) (not the same as the release post!) paint the full picture.

[Live Components Deserve Live Data, Not a Stale Cache](https://react.statuscode.com/link/190229/5d0bbb4a61 "www.tigerdata.com") — Your components re-render instantly, but they read a cache that's minutes behind, because the live query is too slow to hit every render. TimescaleDB extends Postgres so dashboards query live data fast at scale. [Get $1000 credit to start](https://react.statuscode.com/link/190229/5d0bbb4a61).

We also learn what's going to happen to React Native Skia, FlashList and Restyle.

Shopify Engineering

📊 A [companion post covers the 12-week Shop app rewrite](https://react.statuscode.com/link/190237/5d0bbb4a61), with before-and-after startup, stability and app-size metrics.  
  
🤔 **But not everyone's convinced:** In [a busy `r/reactnative` thread](https://react.statuscode.com/link/190238/5d0bbb4a61), one of Expo's founders [suggests](https://react.statuscode.com/link/190239/5d0bbb4a61) Shopify made _"more of a political decision than a technical one"_ and that they were comparing an old-architecture app against a fresh rewrite.

**IN BRIEF:**

*   [Tailwind Labs, creator of Tailwind CSS, is joining Shopify](https://react.statuscode.com/link/190240/5d0bbb4a61). The open source projects stay MIT-licensed with the same team.
    
*   [React DevTools 8.0 is out](https://react.statuscode.com/link/190241/5d0bbb4a61) with the _Suspense_ tab on by default and the Timeline profiler gone, with the browser's _Performance_ panel taking over. There's also [an experimental package](https://react.statuscode.com/link/190242/5d0bbb4a61) that exposes React DevTools to coding agents through `chrome-devtools-mcp`.
    
*   TanStack has published [a write-up of its partnership with Vercel](https://react.statuscode.com/link/190243/5d0bbb4a61), with new TanStack AI adapters for Vercel's AI Gateway and Sandbox now available.
    
*   [Expo Modules 2.0 is on the way](https://react.statuscode.com/link/190244/5d0bbb4a61), introducing annotation-based Swift and Kotlin classes for writing native modules.
    

[React Now Rusted All the Way Out](https://react.statuscode.com/link/190245/5d0bbb4a61 "blog.master.dev") — A team moved a 1000+ file React Router app onto oxc's Rust port of the React Compiler and watched the compile step drop from 14.3s to 0.81s. Better still, the port already handles patterns the Babel-based 1.0 skips, and the post ends with the Vite config to make the switch.
