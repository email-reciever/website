[Declarative Dragging](https://react.statuscode.com/link/192893/5d0bbb4a61 "declarative-dragging.github.io") — Rather than designing drag and drop interactions as needed, what if you could _declare_ the possible outcomes and let a library work out the interaction? [Dragology](https://react.statuscode.com/link/192894/5d0bbb4a61) is an experimental React library for SVG interfaces that does just that. There are [lots of demos](https://react.statuscode.com/link/192895/5d0bbb4a61) to try.

Horowitz, Blinn, and Heer

[![](https://res.cloudinary.com/cpress/image/upload/c_limit,w_480,h_480,q_auto/copm/baddea09.png)](https://react.statuscode.com/link/192892/5d0bbb4a61)

[Debug Errors and Agents Faster: Sentry Changelog Live](https://react.statuscode.com/link/192892/5d0bbb4a61 "sentry.io") — A walkthrough of what’s new for debugging errors and performance issues, including fixing production bugs with Seer and tracing the agents you build. Live Q&A. Nov 18, 10am PT. [Save your spot](https://react.statuscode.com/link/192892/5d0bbb4a61).

Sentry sponsor

📊 [e18e's Ongoing Benchmarks for JavaScript Meta-Frameworks](https://react.statuscode.com/link/192896/5d0bbb4a61 "e18e.dev") — e18e is now benchmarking meta-frameworks like Next.js, Nuxt, and Astro on everything from install and build costs to SSR throughput, alongside Core Web Vitals data. Built with input from maintainers, [the results](https://react.statuscode.com/link/192897/5d0bbb4a61) can be tracked release by release and have already led to fixes in Nuxt, React, and Solid.

e18e Project

**IN BRIEF:**

*   ⚠️ Using Vite? [A critical flaw](https://react.statuscode.com/link/192898/5d0bbb4a61) allows remote code execution on dev servers exposed to the network with `--host` or `server.host`. Update to 8.3.7, 8.2.5, 8.1.7, 7.3.8 or 6.4.6.
    
*   [Storybook 11 beta now has an official post](https://react.statuscode.com/link/192899/5d0bbb4a61). React projects get faster, more accurate component metadata, and there are type-safe stories and official skills for agents. The final release is due in December.
    
*   React's `&lt;form>` docs now explain [how to keep field values after an Action](https://react.statuscode.com/link/192900/5d0bbb4a61), and `requestFormReset` gets [a reference page](https://react.statuscode.com/link/192901/5d0bbb4a61) of its own.
    

[UI SDK: Vercel and shadcn's Headless UI Behaviors Library](https://react.statuscode.com/link/192902/5d0bbb4a61 "ui-sdk.dev") — A low-level library of behaviors, like keyboard navigation, popups, drag and drop, that you compose into your own components. A core idea is to give a solid base for agents to build full components from. In beta, but you can [get started now](https://react.statuscode.com/link/192903/5d0bbb4a61).

shadcn (Vercel)

[How X is Rebuilding Its Web App with React, Relay and Vite](https://react.statuscode.com/link/192904/5d0bbb4a61 "blog.x.com") — X/Twitter is replacing its decade-old client-rendered React app with a stack built around streaming SSR and Suspense. Lab tests show profiles displaying posts much sooner, and the hydration and chunking fixes make this an interesting case study.

Yagiz Nizipli (X)

📊 [Six React Chart Libraries vs Hand-Written SVG](https://react.statuscode.com/link/192906/5d0bbb4a61) – The results are close at native speed but with large gaps under CPU throttling or with large datasets. Pavel Gusev

📊 [Remix v3 vs TanStack Start: Fast Pages, Thin Ecosystem](https://react.statuscode.com/link/192905/5d0bbb4a61) – Comparing the same site built in React-free Remix v3 and TanStack Start. Jonathan Arnault (Marmelab)

📱 [How Five Web Developers Built an iOS Keyboard Extension with Expo](https://react.statuscode.com/link/192907/5d0bbb4a61) Anirudh Coontoor (Supernova)

🛠  Code, Tools & Libraries

[![](https://res.cloudinary.com/cpress/image/upload/w_1280,e_sharpen:60,q_auto/rzyk9hdnriuqphjxnsvj.jpg)](https://react.statuscode.com/link/192908/5d0bbb4a61)

[Text.js: React Apps That Render in the DevTools Console](https://react.statuscode.com/link/192908/5d0bbb4a61 "textjs.org") — Continuing the trend of rendering React apps _everywhere_, this new framework heads to DevTools as a host environment, supporting App Router-style routing, Suspense, keyboard input and ASCII fonts. Open the console on the page to see it in action!

Anomaly

[Exact: A New Rust-Powered App Framework from Expo's Co-Founder](https://react.statuscode.com/link/192909/5d0bbb4a61 "ccheever.expo.app") — It _isn't_ React as the UI is written in a small, constrained language called Contract that's designed specifically for agents to write and test, but [𝕏 Andrew Clark says](https://react.statuscode.com/link/192910/5d0bbb4a61) it's _"eerily similar"_ to what he thinks React 20 is shaping up to be.

Charlie Cheever

[React Shepherd 8.0: Guided Tours for Apps, Now with a Leaner Engine](https://react.statuscode.com/link/192929/5d0bbb4a61 "github.com") — The React wrapper ([React docs here](https://react.statuscode.com/link/192930/5d0bbb4a61)) for [Shepherd](https://react.statuscode.com/link/192912/5d0bbb4a61), a popular library for building step-based on-page tours. _Note that it's AGPL, with a paid license for commercial use._

Ship Shape

*   [EmbedPDF 3.0](https://react.statuscode.com/link/192913/5d0bbb4a61) – Powerful PDF viewer with a drop-in React component and a headless library for adding your own UI. ([Demo](https://react.statuscode.com/link/192914/5d0bbb4a61).)
    
*   [react-virtualized 10.0](https://react.statuscode.com/link/192915/5d0bbb4a61) – The original list and grid virtualization library, modernized. Now in TypeScript, built on function components, and requires React 18+.
    
*   📱 [React Native Audio API 1.0](https://react.statuscode.com/link/192916/5d0bbb4a61) – Software Mansion's Web Audio API for React Native goes stable. Adds spatial audio, and FFmpeg is now opt-in.
    
*   [Mantine 9.8](https://react.statuscode.com/link/192917/5d0bbb4a61) – Adds an emoji picker package, plus new `Diff`, `PhoneInput` and week and quarter picker components.
    
*   [BagUI](https://react.statuscode.com/link/192919/5d0bbb4a61) – A `shadcn/ui` registry of blocks and templates for SaaS landing pages, like pricing and hero sections.
    

📰 Classifieds

🔍 Can ChatGPT and Claude read your React site? Run a free SEO and GEO scan with [Fimo](https://react.statuscode.com/link/192920/5d0bbb4a61) and see what they miss. By the Strapi team.

[Build durable AI agents & workflows in TypeScript with Trigger.dev](https://react.statuscode.com/link/192922/5d0bbb4a61). If steps fail or code deploys, tasks pick up right where they left off.

📢  Elsewhere in the ecosystem

[![](https://res.cloudinary.com/cpress/image/upload/w_1280,e_sharpen:60,q_auto/wjp1pnhalfiz0jddculv.jpg)](https://react.statuscode.com/link/192923/5d0bbb4a61)

*   [Vectoys](https://react.statuscode.com/link/192923/5d0bbb4a61) is a set of React components that render phones, laptops and other small 3D objects as SVG, with interactive HTML inside their screens. Could be handy for mockups or 'in-situ' teasers on your homepage.
    
*   🤖 Chrome's [Modern Web Guidance 1.0](https://react.statuscode.com/link/192924/5d0bbb4a61) is a set of skills that steer coding agents toward modern, Baseline-aware HTML and CSS. The team has also listed [the 'top 10 things AI gets wrong'](https://react.statuscode.com/link/192925/5d0bbb4a61) when building for the Web.
    
*   Need a clip of a component or animation for a PR or README? Paul Irish's [chrome-capture](https://react.statuscode.com/link/192926/5d0bbb4a61) tool can record a Chrome tab to an MP4 at 60fps with a single `npx` command.
    
*   📊 The [State of JavaScript 2026 survey](https://react.statuscode.com/link/192927/5d0bbb4a61) is now open if you want to get involved.
