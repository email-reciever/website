🛠  Code, Tools & Libraries

[![](https://res.cloudinary.com/cpress/image/upload/w_1280,e_sharpen:60,q_auto/eekvnbhdbukialvphr1t.jpg)](https://react.statuscode.com/link/193213/5d0bbb4a61)

[React Anatomy: Explode a React Page into 3D Layers](https://react.statuscode.com/link/193213/5d0bbb4a61 "react-anatomy.com") — A DevTools extension that splits a running React page into 3D layers mapped to the components that rendered it, with live props for whatever you click. You can [try the demo](https://react.statuscode.com/link/193214/5d0bbb4a61) without installing anything.

Nicolas Charpentier

[Stepperize 9.0: Type-Safe Multi-Step Flows for React](https://react.statuscode.com/link/193215/5d0bbb4a61 "stepperize.com") — A popular library for wizards, checkouts and onboarding where you define steps once and get typed navigation, plus guards that block a user from advancing until a step is valid.

Damian Ricobelli

[Fate 2.0: The Async React Data Client Now Handles Client State Too](https://react.statuscode.com/link/193216/5d0bbb4a61 "fate.technology") — The Relay-inspired data client now manages client-only and offline state through the same views and mutations as server data, and works as a GraphQL client too. It's already replaced Relay and TinyBase in Christoph's game, [Athena Crisis](https://react.statuscode.com/link/193217/5d0bbb4a61).

Christoph Nakazawa

[Detent: A Wheel Picker for React with Real Inertia](https://react.statuscode.com/link/193218/5d0bbb4a61 "detent.hayder.sh") — An iOS-style wheel picker that uses its own physics rather than `scroll-snap`, meaning that a 'throw' has momentum and lands cleanly on options. The demo on the homepage is very cute and worth… a spin. 😎

Hayder

[![](https://res.cloudinary.com/cpress/image/upload/w_1280,e_sharpen:60,q_auto/syuisr0pjgfgzjub1sks.jpg)](https://react.statuscode.com/link/193219/5d0bbb4a61)

*   📊 [Recharts 3.11](https://react.statuscode.com/link/193219/5d0bbb4a61) _(above)_ – Popular charting library. Now with [context-based themes](https://react.statuscode.com/link/193220/5d0bbb4a61) and accessible fill patterns.
    
*   ⚠️ [React Router 8.5.2](https://react.statuscode.com/link/193221/5d0bbb4a61) and [7.18.6](https://react.statuscode.com/link/193222/5d0bbb4a61) – Upgrade to either version for fixes covering [seven security advisories](https://react.statuscode.com/link/193223/5d0bbb4a61), four rated high.
    
*   [You Might Not Need an Effect 1.2](https://react.statuscode.com/link/193224/5d0bbb4a61) – ESLint plugin that flags unnecessary `useEffect` calls. Now 'sees through' popular third-party effect wrappers.
    
*   [ka-table 13.0](https://react.statuscode.com/link/193225/5d0bbb4a61) – Lightweight React table component. Now a keyboard-accessible ARIA grid and has added fixed columns and virtual scrolling of columns.
    
*   [Redux Toolkit 2.15](https://react.statuscode.com/link/193226/5d0bbb4a61) – Each store now gets its own RTK Query runtime, fixing long-standing SSR and test isolation problems.
    
*   📱 [React Native Bottom Sheet 1.0](https://react.statuscode.com/link/193227/5d0bbb4a61) – Software Mansion's bottom sheet goes stable.

⚡ Next.js, Astro or React Router site? [Fimo](https://react.statuscode.com/link/193229/5d0bbb4a61) hosts it and runs AI agents that keep it found on Google and in AI answers.

🎬 Your app needs video, not a video team. Upload any format to [Hyperserve's API](https://react.statuscode.com/link/193230/5d0bbb4a61), get back MP4 on a global CDN. Ship video in an afternoon.

📢  Elsewhere in the ecosystem

*   The Next.js team is [experimenting with Switchyard](https://react.statuscode.com/link/193231/5d0bbb4a61), a Go-powered server that [sits in front of `next start`](https://react.statuscode.com/link/193239/5d0bbb4a61). Currently, it forwards requests to Node, but the plan is to move routing work out of Node and into Switchyard. If you're self-hosting Next.js, this is one for your long-term radar.
    
*   [Solid 2.0 is now stable](https://react.statuscode.com/link/193232/5d0bbb4a61). Async is now part of the signals graph and server functions have moved into core. There are also new diagnostics aimed at coding agents.
    
*   If you want to try speeding up your npm package installs, vlt's registry mirror [serves much less metadata](https://react.statuscode.com/link/193233/5d0bbb4a61), making clean installs 20-70% faster and, now, [it's open for all to use](https://react.statuscode.com/link/193234/5d0bbb4a61) with no account/token needed.
    
*   🐘 [PostgreSQL 19 is finally here!](https://react.statuscode.com/link/193235/5d0bbb4a61) If Postgres is part of your stack, our sister newsletter [_Postgres Weekly_ covered it in depth this week](https://react.statuscode.com/link/193236/5d0bbb4a61) (please subscribe! 😅)
    
*   [npkill 1.0](https://react.statuscode.com/link/193237/5d0bbb4a61) (`npx npkill`) no longer just clears out old `node_modules` folders, but build output and caches like `.next` and `.turbo` too.
