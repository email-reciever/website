TanStack Start Reaches 1.0

After a year as a release candidate, [TanStack Start 1.0 is officially stable](https://react.statuscode.com/link/191882/5d0bbb4a61). Tanner Linsley explains how it grew out of _TanStack Router_, and is candid about RSC, which felt like _"this box we had to check to be taken seriously as a React framework"_, and which [tanstack.com](https://react.statuscode.com/link/191926/5d0bbb4a61) itself no longer uses. Plus:

*   📊 [The same app in Start and Next.js 16.4, benchmarked](https://react.statuscode.com/link/191883/5d0bbb4a61) – _Start_ handled 2.9x-8.6x more dynamic requests and built ~1.7x faster with type-checking included.
    
*   🚚 Moving over? There are official guides for [migrating from Next.js](https://react.statuscode.com/link/191884/5d0bbb4a61) and [from the RC](https://react.statuscode.com/link/191885/5d0bbb4a61). Sarthak Mishra [moved his site over from Astro](https://react.statuscode.com/link/191886/5d0bbb4a61) (and explains why) and Lovable offers older projects a migration option ([here's how one went](https://react.statuscode.com/link/191887/5d0bbb4a61)).
    
*   💬 Ryan Carniato called it [_"a React metaframework with an architecture I can get behind"_](https://react.statuscode.com/link/191888/5d0bbb4a61), while in [the r/reactjs thread](https://react.statuscode.com/link/191889/5d0bbb4a61) Tanner explained why '1.0' is listed as `1.169` on npm.

TanStack

There's also an unstable ['API-only' mode](https://react.statuscode.com/link/191910/5d0bbb4a61) that serves static HTML but keeps a server for loaders and actions.

Nate Wienert

*   [Unistyles 3.6](https://react.statuscode.com/link/191916/5d0bbb4a61) – High-performance React Native styling library. Now with an experimental zero-config Metro integration instead of the Babel plugin.
