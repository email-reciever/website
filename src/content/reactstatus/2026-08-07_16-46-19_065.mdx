[TanStack Table v9: A Faster, More Modular Foundation](https://react.statuscode.com/link/189014/5d0bbb4a61 "tanstack.com") — Arriving four years after v8, the popular headless table library gets a tree-shakable architecture where you register only what you need (so a pagination-only table, say, ships no filtering/grouping code). State moves to [TanStack Store](https://react.statuscode.com/link/189015/5d0bbb4a61) for [fine-grained reactivity](https://react.statuscode.com/link/189016/5d0bbb4a61), and there are [big memory wins](https://react.statuscode.com/link/189017/5d0bbb4a61) for large datasets.

The Next.js Team

💡 Vercel has put together [a guide to its support for Next.js 16.3](https://react.statuscode.com/link/189023/5d0bbb4a61) and the efficiency gains seen from its new features.

*   shadcn has added [a new `Questionnaire` component](https://react.statuscode.com/link/189027/5d0bbb4a61) (in Base UI, React Aria, and Radix UI flavors) for rendering multi-step questionnaires.

🛠  Code, Tools & Libraries

[![](https://res.cloudinary.com/cpress/image/upload/w_1280,e_sharpen:60,q_auto/rk6mx0cvwj0ccpzqec7o.jpg)](https://react.statuscode.com/link/189032/5d0bbb4a61)

[Plate: Build Your Own Rich Text Editor](https://react.statuscode.com/link/189032/5d0bbb4a61 "platejs.org") — A framework (with very thorough [docs](https://react.statuscode.com/link/189033/5d0bbb4a61)) for building React-based text editors that lets you select the specific features and functionality you need. [GitHub repo.](https://react.statuscode.com/link/189034/5d0bbb4a61)

Ziad Beyens

🤖 [use-webmcp-tool: A Hook for Using WebMCP](https://react.statuscode.com/link/189035/5d0bbb4a61 "github.com") — [WebMCP](https://react.statuscode.com/link/189036/5d0bbb4a61) is a proposed web standard for exposing page-based JavaScript functions for AI agents to use. This hook wraps its usual imperative API for React's declarative approach.

Sarah Drasner (Google Chrome Labs)

[rshono: A Minimal Framework for React Server Components](https://react.statuscode.com/link/189037/5d0bbb4a61 "www.rshono.com") — Uses Hono for the server, Rspack for building, and React Server Components for rendering. This brand-new project has similarities to [Waku](https://react.statuscode.com/link/189038/5d0bbb4a61) but is simpler and doesn't require Vite.

Lasse Tange

[Morphicons: Morphing Library for Stroke-Based Icons](https://react.statuscode.com/link/189039/5d0bbb4a61 "www.morphicons.com") — To morph an icon, all you do is change a prop. Works with Lucide, Tabler, Heroicons, Iconoir and the shadcn icon registry. The live demo on the homepage demonstrates the effect.

Guillermo López

*   [SWR 2.5](https://react.statuscode.com/link/189040/5d0bbb4a61) – A minimal hook-based data fetching mechanism with caching, revalidation and deduplication. [v2.5](https://react.statuscode.com/link/189041/5d0bbb4a61) adds RSC cache preloading and an `unload()` API to clear the cache and discard in-flight operations.
    
*   [React Aria 1.20](https://react.statuscode.com/link/189042/5d0bbb4a61) – Adobe's popular component suite adds new `PreviewTrigger` and `TokenField` components.
    
*   [react-dropzone 20.0](https://react.statuscode.com/link/189043/5d0bbb4a61) – React hook providing a standards-compliant drag-and-drop zone for files. Now requires Node 22+. ([Examples](https://react.statuscode.com/link/189044/5d0bbb4a61))
    
*   [Base UI 1.7](https://react.statuscode.com/link/189045/5d0bbb4a61) – The unstyled UI component library that's [shadcn/ui's new default](https://react.statuscode.com/link/189046/5d0bbb4a61).
    
*   [Astryx 0.3](https://react.statuscode.com/link/189047/5d0bbb4a61) – Meta's React and StyleX-based design system. ([Homepage](https://react.statuscode.com/link/189048/5d0bbb4a61))
    
*   [Material UI 9.3](https://react.statuscode.com/link/189049/5d0bbb4a61) – Popular, comprehensive suite of React components.
    
*   [react-hcaptcha 2.1](https://react.statuscode.com/link/189050/5d0bbb4a61) – Component for the reCAPTCHA alternative.
    
*   [React Three Fiber 9.7](https://react.statuscode.com/link/189051/5d0bbb4a61) – React renderer for Three.js.

📢  Elsewhere in the ecosystem

[![](https://res.cloudinary.com/cpress/image/upload/w_1280,e_sharpen:60,q_auto/bxe6plfkpetnok8vflch.jpg)](https://react.statuscode.com/link/189054/5d0bbb4a61)

*   🤖 Fred K. Schott, of [Astro](https://react.statuscode.com/link/189055/5d0bbb4a61) fame, has [unveiled Flue 2.0](https://react.statuscode.com/link/189054/5d0bbb4a61), the latest version of his TypeScript-based open agent framework. The novel addition is using React-style hooks (called Agent Hooks – _see above_) to build dynamic agents that manage their own state.
    
*   Talking of Astro, [Astro 7.2 has been released](https://react.statuscode.com/link/189056/5d0bbb4a61) with experimental incremental static build support (skipping the regeneration of prerendered pages which haven't changed since the last build).
    
*   ⚠️ Earlier this week, [the `keyv` package was compromised by attackers](https://react.statuscode.com/link/189057/5d0bbb4a61) who injected a credential-stealing worm which spread across [400+ other packages](https://react.statuscode.com/link/189058/5d0bbb4a61) so far.
