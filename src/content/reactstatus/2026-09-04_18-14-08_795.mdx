[Mantine 9.6: A Huge Component Library Update](https://react.statuscode.com/link/189953/5d0bbb4a61 "mantine.dev") — A big update for the popular component library with a new [lightbox](https://react.statuscode.com/link/189954/5d0bbb4a61) component, an [`ActionBar`](https://react.statuscode.com/link/189955/5d0bbb4a61) for contextual bulk actions, four new chart types ([waffle](https://react.statuscode.com/link/189956/5d0bbb4a61), [matrix](https://react.statuscode.com/link/189957/5d0bbb4a61), [gauge](https://react.statuscode.com/link/189958/5d0bbb4a61), and [candlestick](https://react.statuscode.com/link/189959/5d0bbb4a61)), and _much_ more besides.

The Mantine Team

[`cn`: shadcn's Faster Drop-In Replacement for `tailwind-merge` and `clsx`](https://react.statuscode.com/link/189960/5d0bbb4a61 "github.com") — Precompiles Tailwind's conflict rules into lookup tables rather than working them out every time classes are merged, plus `cn build` can trim the bundle to only the rules needed. [Here's how it works](https://react.statuscode.com/link/189961/5d0bbb4a61).

shadcn and Aiden Bai

[GPUIX: Build GPU-Rendered Native Desktop Apps with React](https://react.statuscode.com/link/189962/5d0bbb4a61 "gpuix.dev") — An interesting attempt to render React components through Zed's (yes, the [Rust-powered code editor](https://react.statuscode.com/link/189963/5d0bbb4a61)!) GPUI framework, to create native desktop apps in a single binary with no Electron/webview needed.

*   [React Aria 1.21.0](https://react.statuscode.com/link/189964/5d0bbb4a61) – Adobe's popular component suite adds a new `NavigationTree` component _(above)_ and `Menu` gets a big upgrade too.
    
*   [React Countdown Clock 3.0](https://react.statuscode.com/link/189965/5d0bbb4a61) – Canvas-based countdown component now rewritten for React 18 and 19 and using `requestAnimationFrame` for smoother rendering. [Live demo](https://react.statuscode.com/link/189966/5d0bbb4a61).
    
*   [Uppy 6.0](https://react.statuscode.com/link/189967/5d0bbb4a61) – Popular, powerful modular file uploader, with [React components](https://react.statuscode.com/link/189968/5d0bbb4a61) and [React Router](https://react.statuscode.com/link/189969/5d0bbb4a61) and [Next.js](https://react.statuscode.com/link/189970/5d0bbb4a61) integrations.
    
*   [Storybook 10.6](https://react.statuscode.com/link/189971/5d0bbb4a61) – The component workshop adds CLI bindings for agents to drive Storybook's tools and skills.
