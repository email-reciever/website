Putting MUI, Mantine, Ant Design  
and React Spectrum Under Load

Den Odell wanted to see how popular design systems cope when you give them real work, [so he timed ten of them](https://react.statuscode.com/link/192218/5d0bbb4a61), including MUI, Mantine, Ant Design and React Spectrum, and profiled the slowest cases. _"Performance belongs on the design system team's priority list, next to accessibility,"_ he says. Some highlights:

*   📊 With the CPU slowed 4x, opening a 249-country dropdown took 84ms in Mantine and 134ms in Ant Design, but over 200ms in MUI and React Spectrum, both of which froze the UI past his 100ms budget.
    
*   🔍 React Spectrum's problem was React Aria measuring options one at a time and forcing layout for each. Den [filed an issue](https://react.statuscode.com/link/192219/5d0bbb4a61) and [a fix is in review](https://react.statuscode.com/link/192220/5d0bbb4a61).
    
*   ⚖️ Framework alone didn't decide the results as non-React Ionic was by far the slowest to open (1,266ms) yet was quick at checking 100 checkboxes, while MUI handled them in 70ms compared to Ant Design's 421ms.
    
*   🧪 Want to try this on your own components? [Den's Playwright tests are available on GitHub](https://react.statuscode.com/link/192221/5d0bbb4a61).

Expo sponsor

[TanStack Redact: A Smaller React for the Browser](https://react.statuscode.com/link/192222/5d0bbb4a61 "tanstack.com") — A drop-in replacement for React/React DOM in the browser. Add it to your build config (Start, Vite, Vinext and Next.js are supported) and ship less JavaScript. But it renders _synchronously_, with no time slicing, so [the compatibility guide](https://react.statuscode.com/link/192223/5d0bbb4a61) is handy.

Tanner Linsley

💬 Does Redact pay off? [On r/reactjs](https://react.statuscode.com/link/192224/5d0bbb4a61), commenters pondered who needs it and how it differs from Preact, while [one tester](https://react.statuscode.com/link/192225/5d0bbb4a61) found re-renders cost about twice the CPU across two production sites.

**IN BRIEF:**

*   ⚠️ Next.js has [a security release scheduled for November 3](https://react.statuscode.com/link/192226/5d0bbb4a61), fixing seven medium-severity vulnerabilities. Advisories will be published with the patches.
    
*   Dan Abramov is [fuzzing React's Flight protocol](https://react.statuscode.com/link/192227/5d0bbb4a61), the format behind Server Components, by streaming random value graphs through the real server and client. It's turned up [six stream bugs](https://react.statuscode.com/link/192228/5d0bbb4a61) and [three writer bugs](https://react.statuscode.com/link/192229/5d0bbb4a61) so far.
    
*   [TanStack AI 1.0](https://react.statuscode.com/link/192230/5d0bbb4a61) is stable: a vendor-neutral AI toolkit with React hooks like `useChat()`, 23 provider adapters and MCP support.
    
*   📱 [React Native Windows 0.85](https://react.statuscode.com/link/192231/5d0bbb4a61) completes its move to the New Architecture, and there's more React Native on the desktop with [Expo Desktop](https://react.statuscode.com/link/192232/5d0bbb4a61) (an independent project – not by _Expo_) and [Legend Spark](https://react.statuscode.com/link/192233/5d0bbb4a61) for macOS.

Here's how one team traced the delay, and what fixed it.
