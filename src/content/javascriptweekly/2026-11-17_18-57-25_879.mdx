**IN BRIEF:**

*   [Solid 2.0](https://javascriptweekly.com/link/193001/d076523b1d) is now stable, with `2.0.0` [now on npm](https://javascriptweekly.com/link/193002/d076523b1d) and [the docs](https://javascriptweekly.com/link/193003/d076523b1d) updated to match. There's no official announcement post (beyond the earlier [Solid 2.0 RC posts](https://javascriptweekly.com/link/193004/d076523b1d)) so expect more on this soon.
    
*   The Chrome team has [proposed a Cross-Origin Storage API](https://javascriptweekly.com/link/192936/d076523b1d) for sites to share large assets like AI models and WASM modules, so users would only have to download them once.
    
*   The cloud-based JavaScript hosting service [_Val Town_ is winding down](https://javascriptweekly.com/link/192938/d076523b1d) with services ending January 10 and the code being open sourced in February.
    
*   The Bun team has published [a dense technical tour of how its in-development ahead-of-time compiler works](https://javascriptweekly.com/link/192937/d076523b1d).
    

**RELEASES:**

*   [Prettier 3.10](https://javascriptweekly.com/link/192939/d076523b1d) – The code formatter now supports the latest JavaScript proposals and new Flow syntax, and adds an opt-in plugin that swaps in the Zig-based [Yuku](https://javascriptweekly.com/link/192940/d076523b1d)'s JS/TS parsers for speed.
    
*   🎨 [p5.js 2.4](https://javascriptweekly.com/link/192941/d076523b1d) – The creative coding library expands its SVG and 3D model support. Here's [a starter sketch](https://javascriptweekly.com/link/192942/d076523b1d) if you want to play quickly.
    
*   🔒 [Node.js v26.13.1 (LTS)](https://javascriptweekly.com/link/192943/d076523b1d), [v24.22.3](https://javascriptweekly.com/link/192944/d076523b1d) and [v22.23.5](https://javascriptweekly.com/link/192945/d076523b1d) – The [security releases](https://javascriptweekly.com/link/192946/d076523b1d) we mentioned last week fix an HTTP/2 flaw that lets clients crash a server and an HTTPS bug that can leak other connections' memory.
    
*   [PixiJS 3D](https://javascriptweekly.com/link/192947/d076523b1d) – The popular 2D rendering library's official 3D engine is now in open beta. It's WebGPU-first, with a WebGL 2 fallback.

📊 [e18e's Ongoing Benchmarks of JavaScript Meta-Frameworks](https://javascriptweekly.com/link/192948/d076523b1d "e18e.dev") — The [e18e](https://javascriptweekly.com/link/192949/d076523b1d) performance initiative tracks releases of frameworks across the ecosystem (e.g. Nuxt, Astro, SvelteKit, SolidStart, and more), measuring everything from install size and build times to rendering speed. e18e

A handy checklist for humans too.

Philip Walton (Google)

SonarSource sponsor

[How a Third-Party Script Turned Malicious on Major Sites](https://javascriptweekly.com/link/192953/d076523b1d "blog.report-uri.com") — An attacker exploited a flaw in Optimizely's A/B testing platform to inject a ([now removed](https://javascriptweekly.com/link/192954/d076523b1d)) malicious script into pages served to end users. Scott's analysis found it on sites including Zoom, the BBC, and GitLab, and shows how CSP can, and did, help.

Scott Helme (Report URI)

💡 Third-party scripts are an increasingly common attack vector, as [Polymarket's users recently found](https://javascriptweekly.com/link/192955/d076523b1d). If you load any, brush up on [CSP](https://javascriptweekly.com/link/192956/d076523b1d) and [Subresource Integrity](https://javascriptweekly.com/link/192957/d076523b1d), and if you _provide_ them, see [how Fathom secures theirs](https://javascriptweekly.com/link/192958/d076523b1d).

[How Promises Really Resolve, Explained via a WebKit Bug](https://javascriptweekly.com/link/192959/d076523b1d "alistair.sh") — A contrived promise that should have thrown instead caused Bun and Safari (both of which use [JavaScriptCore](https://javascriptweekly.com/link/192960/d076523b1d)) to hang. Alistair fixed the bug and uses it to explain what `resolve()` actually does and why `resolved` isn't _'a real promise state'_.

Alistair Smith

[The Web Is More Than Enough](https://javascriptweekly.com/link/192961/d076523b1d "ftrain.com") — A reminder of how the vast array of powerful web platform APIs enables the development of complex apps in the browser, particularly as AI reduces the headaches involved in tying them together.

Paul Ford

[Your JS Error Is Lying to You](https://javascriptweekly.com/link/192962/d076523b1d "blog.gaborkoos.com") — Why can `JSON.stringify(err)` unexpectedly leave you with `&lcub;}`? Gabor presents a tour of what an `Error` holds, and how much of that makes it through stack traces, `cause` chains, worker boundaries, and loggers like Pino and Winston.

Gabor Koos

[BrowserPod 4.0: A Linux-Like MicroVM for the Browser](https://javascriptweekly.com/link/192966/d076523b1d "browserpod.io") — A WASM-powered sandbox that runs Node, npm, git, and bash in the browser. Previously a metered service, v4.0 is free for any use, though it's not open source, and you must load it via their CDN (but no account or API key is needed).

Leaning Technologies

💡 Going somewhat deeper, Nitro creator Pooya Parsa has compiled [the actual Linux kernel to WebAssembly](https://javascriptweekly.com/link/192967/d076523b1d) ([repo](https://javascriptweekly.com/link/192968/d076523b1d)). It boots to a shell in under a second in modern browsers, or via `npx unkernel` _(tip: use `halt` to exit!)_.

[Debug Errors and Agents Faster: Sentry Changelog Live](https://javascriptweekly.com/link/192969/d076523b1d "sentry.io") — A walkthrough of what’s new in debugging, from fixing prod bugs with Seer to tracing your agents. [Register today](https://javascriptweekly.com/link/192969/d076523b1d).

Sentry sponsor

[Kitesurf: Cloudflare's Browser Engine Now Open Source](https://javascriptweekly.com/link/192970/d076523b1d "blog.cloudflare.com") — An experimental browser for agents we featured in August. Mostly written in TypeScript and runs JavaScript in V8 isolates on _Workers_, with Rust compiled to WASM for layout and painting. There's no Chromium, and Puppeteer can drive it.

Cloudflare

[File Viewer: A Multi-Format File Viewer for Internal Apps](https://javascriptweekly.com/link/192971/d076523b1d "github.com") — Read-only views for Office, PDF/OFD, CAD, archives, email and other complex formats, with integrations for React, Vue, and Svelte. The [docs site](https://javascriptweekly.com/link/192972/d076523b1d) has demos showing off the formats covered.

Flyfish Dev

[Flashwright: A Faster, API-Compatible Playwright Fork](https://javascriptweekly.com/link/192973/d076523b1d "flashwright.dev") — Keeps Playwright's API and test runner, but reuses a browser context per worker and doesn't wait for animations to settle, plus similar tricks. Benchmarks show a ~2-4x speedup, while [this post explains how it works](https://javascriptweekly.com/link/192974/d076523b1d).

Codebeast

[React Flow 13: The Node-Based UI Library Gets Faster](https://javascriptweekly.com/link/192975/d076523b1d "xyflow.com") — The first major release in two years cuts re-renders in large flows, with new `useNode` and `useEdge` hooks. [Vue Flow has joined the xyflow family](https://javascriptweekly.com/link/192976/d076523b1d) too.

xyflow

[![](https://res.cloudinary.com/cpress/image/upload/w_1280,e_sharpen:60,q_auto/kg7bhtjdxtgjgocpxf3z.jpg)](https://javascriptweekly.com/link/192977/d076523b1d)

*   [SlickGrid 6.0](https://javascriptweekly.com/link/192977/d076523b1d) _(above)_ – Long-standing data grid component. Now with zero dependencies, plus [pinning on all four sides](https://javascriptweekly.com/link/192978/d076523b1d) and sticky rows and columns. Examples and introductions [on the project homepage](https://javascriptweekly.com/link/192979/d076523b1d).
    
*   [XState v6 Beta](https://javascriptweekly.com/link/192980/d076523b1d) – First beta of the state machine/actor library's next major version. The core API is considered stable and you can try it with `xstate@beta`.
    
*   🕹️ [Excalibur 1.0](https://javascriptweekly.com/link/192981/d076523b1d) – After 13 years, the 2D TypeScript game engine reaches v1 with 2D lighting, a plugin API, and a rebuilt Web Audio mixer. [Sample games here](https://javascriptweekly.com/link/192982/d076523b1d).
    
*   🕹️ [JSNES 3.0](https://javascriptweekly.com/link/192983/d076523b1d) – JavaScript NES emulator. Now has a cycle-accurate core that passes all 134 'AccuracyCoin' tests. There are [playable demos here](https://javascriptweekly.com/link/192984/d076523b1d).
    
*   [type-fest 6.0](https://javascriptweekly.com/link/192985/d076523b1d) – Popular collection of essential TypeScript types ([listed here](https://javascriptweekly.com/link/192986/d076523b1d)). v6.0 adds 120 new types and requires TypeScript 6.
    
*   [Fontkit 3.0](https://javascriptweekly.com/link/192987/d076523b1d) – Advanced font engine for Node and the browser. Now ESM-only, with a new `core` export so you can ship only the formats needed.
    
*   [dts-bundle-generator 10.0](https://javascriptweekly.com/link/192988/d076523b1d) – A tool to tree-shake and bundle a project's TypeScript declarations into one file.

📢  Elsewhere in the ecosystem

[![](https://res.cloudinary.com/cpress/image/upload/w_1280,e_sharpen:60,q_auto/ldgdhmhflcadzj94nlv6.jpg)](https://javascriptweekly.com/link/192992/d076523b1d)

*   [You Don't Need jQuery](https://javascriptweekly.com/link/192992/d076523b1d), the long-standing guide to replacing jQuery methods with plain JavaScript, has had a big [v3.0 update](https://javascriptweekly.com/link/193005/d076523b1d). _Internet Explorer_ fallbacks are out in favor of modern one-liners like `el.replaceChildren()`, `structuredClone()`, and `Promise.withResolvers()`.
    
*   Adam Argyle shares [PropFLIP](https://javascriptweekly.com/link/192993/d076523b1d), a take on [FLIP (First, Last, Invert, Play) animations](https://javascriptweekly.com/link/192994/d076523b1d) where four `@property` custom properties do the inverting and a CSS transition does the playing.
    
*   AWS has released [AWS Emulator](https://javascriptweekly.com/link/192995/d076523b1d), an _official_ local emulator you can point your AWS SDK or CLI at, covering hundreds of its service interfaces. It's largely aimed at agents, and [was built with them too](https://javascriptweekly.com/link/192996/d076523b1d).
    
*   🎂 Happy birthday to [Svelte](https://javascriptweekly.com/link/192997/d076523b1d)! Svelte turned ten years old on Monday (Rich Harris made [its first commit](https://javascriptweekly.com/link/192998/d076523b1d) on November 16, 2016).

[![](https://res.cloudinary.com/cpress/image/upload/w_1280,e_sharpen:60,q_auto/pskrn2fbmsv0dydrn175.jpg)](https://javascriptweekly.com/link/192966/d076523b1d)

[BrowserPod 4.0: A Linux-Like MicroVM for the Browser](https://javascriptweekly.com/link/192966/d076523b1d "browserpod.io") — A WASM-powered sandbox that runs Node, npm, git, and bash in the browser. Previously a metered service, v4.0 is free for any use, though it's not open source, and you must load it via their CDN (but no account or API key is needed).

Leaning Technologies

💡 Going somewhat deeper, Nitro creator Pooya Parsa has compiled [the actual Linux kernel to WebAssembly](https://javascriptweekly.com/link/192967/d076523b1d) ([repo](https://javascriptweekly.com/link/192968/d076523b1d)). It boots to a shell in under a second in modern browsers, or via `npx unkernel` *(tip: use `halt` to exit!)*.

[Debug Errors and Agents Faster: Sentry Changelog Live](https://javascriptweekly.com/link/192969/d076523b1d "sentry.io") — A walkthrough of what’s new in debugging, from fixing prod bugs with Seer to tracing your agents. [Register today](https://javascriptweekly.com/link/192969/d076523b1d).

Sentry sponsor

[Kitesurf: Cloudflare's Browser Engine Now Open Source](https://javascriptweekly.com/link/192970/d076523b1d "blog.cloudflare.com") — An experimental browser for agents we featured in August. Mostly written in TypeScript and runs JavaScript in V8 isolates on *Workers*, with Rust compiled to WASM for layout and painting. There's no Chromium, and Puppeteer can drive it.

Cloudflare

[File Viewer: A Multi-Format File Viewer for Internal Apps](https://javascriptweekly.com/link/192971/d076523b1d "github.com") — Read-only views for Office, PDF/OFD, CAD, archives, email and other complex formats, with integrations for React, Vue, and Svelte. The [docs site](https://javascriptweekly.com/link/192972/d076523b1d) has demos showing off the formats covered.

Flyfish Dev

[Flashwright: A Faster, API-Compatible Playwright Fork](https://javascriptweekly.com/link/192973/d076523b1d "flashwright.dev") — Keeps Playwright's API and test runner, but reuses a browser context per worker and doesn't wait for animations to settle, plus similar tricks. Benchmarks show a ~2-4x speedup, while [this post explains how it works](https://javascriptweekly.com/link/192974/d076523b1d).

Codebeast

[React Flow 13: The Node-Based UI Library Gets Faster](https://javascriptweekly.com/link/192975/d076523b1d "xyflow.com") — The first major release in two years cuts re-renders in large flows, with new `useNode` and `useEdge` hooks. [Vue Flow has joined the xyflow family](https://javascriptweekly.com/link/192976/d076523b1d) too.

xyflow

* [SlickGrid 6.0](https://javascriptweekly.com/link/192977/d076523b1d) *(above)* – Long-standing data grid component. Now with zero dependencies, plus [pinning on all four sides](https://javascriptweekly.com/link/192978/d076523b1d) and sticky rows and columns. Examples and introductions [on the project homepage](https://javascriptweekly.com/link/192979/d076523b1d).

* [XState v6 Beta](https://javascriptweekly.com/link/192980/d076523b1d) – First beta of the state machine/actor library's next major version. The core API is considered stable and you can try it with `xstate@beta`.

* 🕹️ [Excalibur 1.0](https://javascriptweekly.com/link/192981/d076523b1d) – After 13 years, the 2D TypeScript game engine reaches v1 with 2D lighting, a plugin API, and a rebuilt Web Audio mixer. [Sample games here](https://javascriptweekly.com/link/192982/d076523b1d).

* 🕹️ [JSNES 3.0](https://javascriptweekly.com/link/192983/d076523b1d) – JavaScript NES emulator. Now has a cycle-accurate core that passes all 134 'AccuracyCoin' tests. There are [playable demos here](https://javascriptweekly.com/link/192984/d076523b1d).

* [type-fest 6.0](https://javascriptweekly.com/link/192985/d076523b1d) – Popular collection of essential TypeScript types ([listed here](https://javascriptweekly.com/link/192986/d076523b1d)). v6.0 adds 120 new types and requires TypeScript 6.

* [Fontkit 3.0](https://javascriptweekly.com/link/192987/d076523b1d) – Advanced font engine for Node and the browser. Now ESM-only, with a new `core` export so you can ship only the formats needed.

* [dts-bundle-generator 10.0](https://javascriptweekly.com/link/192988/d076523b1d) – A tool to tree-shake and bundle a project's TypeScript declarations into one file.

📢  Elsewhere in the ecosystem

[![](https://res.cloudinary.com/cpress/image/upload/w_1280,e_sharpen:60,q_auto/ldgdhmhflcadzj94nlv6.jpg)](https://javascriptweekly.com/link/192992/d076523b1d)

* [You Don't Need jQuery](https://javascriptweekly.com/link/192992/d076523b1d), the long-standing guide to replacing jQuery methods with plain JavaScript, has had a big [v3.0 update](https://javascriptweekly.com/link/193005/d076523b1d). *Internet Explorer* fallbacks are out in favor of modern one-liners like `el.replaceChildren()`, `structuredClone()`, and `Promise.withResolvers()`.

* Adam Argyle shares [PropFLIP](https://javascriptweekly.com/link/192993/d076523b1d), a take on [FLIP (First, Last, Invert, Play) animations](https://javascriptweekly.com/link/192994/d076523b1d) where four `@property` custom properties do the inverting and a CSS transition does the playing.

* AWS has released [AWS Emulator](https://javascriptweekly.com/link/192995/d076523b1d), an *official* local emulator you can point your AWS SDK or CLI at, covering hundreds of its service interfaces. It's largely aimed at agents, and [was built with them too](https://javascriptweekly.com/link/192996/d076523b1d).

* 🎂 Happy birthday to [Svelte](https://javascriptweekly.com/link/192997/d076523b1d)! Svelte turned ten years old on Monday (Rich Harris made [its first commit](https://javascriptweekly.com/link/192998/d076523b1d) on November 16, 2016).
