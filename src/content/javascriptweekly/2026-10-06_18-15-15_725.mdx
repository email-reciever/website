[Preact 11 Released](https://javascriptweekly.com/link/191127/d076523b1d "preactjs.com") — Six years after [the road to Preact 11](https://javascriptweekly.com/link/191128/d076523b1d) began, the latest version of the popular _"alternative to React with the same modern API"_ is here, with improved hydration, automatic ref forwarding, and an ESM-only package. The [upgrade guide](https://javascriptweekly.com/link/191129/d076523b1d) covers the changes.

The Preact Team

[Nuxt 4.6: A Big Step Towards a Server-Agnostic Nuxt](https://javascriptweekly.com/link/191130/d076523b1d "nuxt.com") — A meaty release for the full-stack Vue framework with a server layer that no longer ties you to Nitro (pure Vite server builds are now an experimental option), built-in sessions, Vue Vapor support, and a new CLI ([Nuxt CLI 4.0](https://javascriptweekly.com/link/191131/d076523b1d)).

Daniel Roe

**IN BRIEF:**

*   Prolific package maintainer [Sindre Sorhus has disabled outside pull requests](https://javascriptweekly.com/link/191132/d076523b1d) due to AI contribution spam, though he'll keep maintaining his projects. [SWC also now restricts PRs](https://javascriptweekly.com/link/191133/d076523b1d) to trusted contributors.
    
*   📊 The [JavaScript Framework Benchmark](https://javascriptweekly.com/link/191134/d076523b1d) site has added [results for Chrome 154](https://javascriptweekly.com/link/191135/d076523b1d) covering 196(!) ways to implement an app, how each performs, and how large they are.
    
*   [`npm stage publish` can now create new packages](https://javascriptweekly.com/link/191136/d076523b1d), so automated workflows no longer need a manual first publish.
    

**RELEASES:**

*   [Remix 3.0](https://javascriptweekly.com/link/191137/d076523b1d) – No official post yet, but the new stable release of the rebuilt full-stack framework, with no React required. The [RC release post](https://javascriptweekly.com/link/191138/d076523b1d) has more info, though.
    
*   [Ink 8.0](https://javascriptweekly.com/link/191139/d076523b1d) – The popular TUI renderer now requires React 19.3 and adds scroll offsets for building scrollable views, now common in coding agent UIs.
    
*   [Inferno 10](https://javascriptweekly.com/link/191140/d076523b1d) – React-like UI library built for raw rendering speed. Now shifts more work from runtime to its JSX compiler.
    
*   [Qwik 2.0 RC](https://javascriptweekly.com/link/191141/d076523b1d), [pnpm 12.10](https://javascriptweekly.com/link/191142/d076523b1d), [Ember 7.3](https://javascriptweekly.com/link/191143/d076523b1d), [Video.js 10](https://javascriptweekly.com/link/191144/d076523b1d), [ESLint 10.12](https://javascriptweekly.com/link/191145/d076523b1d)

David Bushell

SerpApi sponsor

The author of [ffetch](https://javascriptweekly.com/link/191155/d076523b1d) tested eleven options and found five still attempt retries after cancellation.

Gabor Koos

📄 [Readable Regular Expressions for TypeScript, Inspired by Emacs](https://javascriptweekly.com/link/191158/d076523b1d) – Rebuilding the SemVer regex from named, composable pieces. Rahul M. Juliato

The Svelte Team

Miris sponsor

[Effect 4.0: A Smaller Core, Rebuilt Runtime](https://javascriptweekly.com/link/191166/d076523b1d "effect.website") — A ground-up rewrite of the popular library for building reliable apps that handles tricky stuff like resource management, concurrency, retries, typed errors, and more. v4.0 boasts 5x smaller minimal bundles and 86% less memory used per concurrent task.

Sebastian Lorenz

[Lightpanda 1.0: A Headless Browser for Automation](https://javascriptweekly.com/link/191167/d076523b1d "lightpanda.io") — A headless browser built from scratch in Zig. With no graphical rendering, it uses a fraction of Chrome's CPU and memory (~35MB memory in a run I just did!). Drive it with Puppeteer/Playwright or, the fun bit, [script it with plain JavaScript](https://javascriptweekly.com/link/191168/d076523b1d).

Francis Bouvier

*   [pixelmatch 8.0](https://javascriptweekly.com/link/191171/d076523b1d) – Tiny, fast pixel-level image comparison library. Switches to a more perceptually accurate color metric, so diff counts will change.
    
*   [PR Comment Inbox](https://javascriptweekly.com/link/191172/d076523b1d) – Nicholas Zakas's email-style inbox for GitHub review comments, with threads and read/unread state.
    
*   [Electron Forge 8](https://javascriptweekly.com/link/191173/d076523b1d) – Toolkit for building, packaging, and publishing Electron apps.
    
*   [Redux Toolkit 2.13](https://javascriptweekly.com/link/191174/d076523b1d) – The official Redux toolset adds TypeScript 7 support.
