The AI Cost of JavaScript Frameworks

[Nolan Lawson had Claude build the same app](https://javascriptweekly.com/link/192302/d076523b1d) five times in each of twelve JS stacks to test common _"X is better for agents"_ claims. Costs varied significantly between runs, and [Gautam Parab found](https://javascriptweekly.com/link/192303/d076523b1d) that the observed cost ranges overlapped or touched for most pairs of frameworks.

But a clearer difference was in the median amount of JavaScript sent to browsers: 0KB for Astro, 18K for Hono+htmx, 36K for SvelteKit, and 115–142K for React Router, TanStack Start and Next.js. If you've gone "hands-free", Nolan asks, why stick to a particular stack you chose when you wrote all the code? [His benchmark](https://javascriptweekly.com/link/192304/d076523b1d) is on GitHub to try for yourself.

* Chrome 157 is due today with the headline feature being [HTML-in-Canvas](https://javascriptweekly.com/link/192351/d076523b1d) for drawing live, interactive DOM elements into 2D, WebGL and WebGPU canvases. This feature has [numerous striking applications](https://javascriptweekly.com/link/192352/d076523b1d).

* ☕ [CheerpJ 5.0](https://javascriptweekly.com/link/192353/d076523b1d) brings Java 21 and 25 to the browser via WebAssembly, ships the full JDK so you can compile Java in a tab, and previews a new WasmGC-based engine the team hopes will run Minecraft and IntelliJ one day.

* 🤖 LLM-whisperer Simon Willison [looks at the world of browser games being built with coding agents](https://javascriptweekly.com/link/192354/d076523b1d), and argues October was the point where agents got good enough to ship playable games.

* 🕹️ Talking of games… GitHub's game jam [*Game Off* is back for its 14th year](https://javascriptweekly.com/link/192355/d076523b1d) with the theme 'SHIFT'. Entries are due on [itch.io](https://javascriptweekly.com/link/192356/d076523b1d) by December 1.
