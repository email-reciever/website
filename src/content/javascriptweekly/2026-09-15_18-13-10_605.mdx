[Modern Web Types: TypeScript Support for Newer Web APIs](https://javascriptweekly.com/link/190312/d076523b1d "philipwalton.com") — TypeScript's DOM types only include APIs shipped in _multiple_ browser engines, so things like element-scoped `startViewTransition` and `fetchLater` throw up errors. [modern-web-types](https://javascriptweekly.com/link/190313/d076523b1d) is a drop-in `lib.dom` replacement that adds missing interfaces/members shipped in any single browser engine.

The React Team

**IN BRIEF:**

*   🔒 Attackers are [scanning for exposed Vite dev servers](https://javascriptweekly.com/link/190316/d076523b1d) exploiting a `server.fs.deny` bypass (patched in Vite 7.3.2 and 8.0.5 earlier this year) to grab credentials from `.env` files. Vite listens on localhost by default, but double check your setup.
    
*   [Safari 27](https://javascriptweekly.com/link/190317/d076523b1d) shipped yesterday (alongside macOS/iOS 27), bringing the module loader rewrite [we covered last week](https://javascriptweekly.com/link/190318/d076523b1d), so top-level `await` now works reliably in all major browsers.
    
*   TC39 meets in Tokyo in two weeks. [Here's the agenda](https://javascriptweekly.com/link/190319/d076523b1d) with three iterator helper follow-ups ([join](https://javascriptweekly.com/link/190320/d076523b1d), [includes](https://javascriptweekly.com/link/190321/d076523b1d) and [chunking](https://javascriptweekly.com/link/190322/d076523b1d)) all up for Stage 4, plus more.
    
*   🔒 Starting this Thursday, [the OpenJS Foundation's CVE team is taking a break](https://javascriptweekly.com/link/190323/d076523b1d) till October 6 due to burnout driven by a surge of AI-generated reports. Actively exploited issues will still get a response.
    
*   🔒 [npm now places a temporary 72-hour 'security hold'](https://javascriptweekly.com/link/190369/d076523b1d) on _any_ account after a successful recovery-code sign-in.
    

**RELEASES:**

*   [pnpm 12.4](https://javascriptweekly.com/link/190324/d076523b1d) – The package manager can now manage Rust crates and Python packages alongside npm ones in a single workspace.
    
*   [Playwright 1.63](https://javascriptweekly.com/link/190326/d076523b1d) – Tests can now declare a named `lock` so those sharing a resource never run concurrently.
    
*   [Node.js v26.8.2 (Current)](https://javascriptweekly.com/link/190327/d076523b1d) and [v24.21.0 (LTS)](https://javascriptweekly.com/link/190328/d076523b1d) – Both include a security release of Undici to fix numerous vulnerabilities.
    
*   [React Router 8.4](https://javascriptweekly.com/link/190372/d076523b1d), [Vite 8.3](https://javascriptweekly.com/link/190330/d076523b1d), [Moment.js 2.31.0](https://javascriptweekly.com/link/190331/d076523b1d) (security release).

Matt Ström-Awn
