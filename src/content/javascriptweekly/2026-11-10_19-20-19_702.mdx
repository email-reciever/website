Yagiz, famed for his performance work on Node, explains the streaming architecture behind it, along with some bottlenecks they had to fix, like how hundreds of tiny JavaScript files slowed startup.

Yagiz Nizipli (X Engineering Blog)

[![](https://res.cloudinary.com/cpress/image/upload/c_limit,w_480,h_480,q_auto/copm/966f3f3a.png)](https://javascriptweekly.com/link/192645/d076523b1d)

[Why Standard Webhooks Hit 118m npm Downloads a Month](https://javascriptweekly.com/link/192645/d076523b1d "link.svix.com") — OpenAI, Anthropic, and Gemini all sign webhooks with Standard Webhooks, the open spec Svix started. That's one finding in the State of Webhooks 2027, where we scored 489 API companies on retries and signatures. [Immediate download, no email required](https://javascriptweekly.com/link/192645/d076523b1d).

Svix sponsor

[Parcel 3 Alpha: The Bundler Rewritten in Rust](https://javascriptweekly.com/link/192647/d076523b1d "v3.parceljs.org") — A ground-up Rust rewrite of the popular bundler that the team reports is up to 100x faster than Parcel 2 at cold builds of React Spectrum. It runs as a standalone binary without Node, with support for native plugins written in Rust, Go or Swift, while JavaScript plugins run on an embedded QuickJS runtime.

The Parcel Team

*   ESLint [now officially lints shell scripts](https://javascriptweekly.com/link/192651/d076523b1d) with the `@eslint/shell` plugin adding ShellCheck-like rules for Bash, sh and mksh.
    

**RELEASES:**

*   [Playwright 1.65](https://javascriptweekly.com/link/192652/d076523b1d) – The browser testing tool's test runner can now run under Bun, plus there's a new failures reporter.
    
*   [Storybook 11 Beta](https://javascriptweekly.com/link/192653/d076523b1d) – The UI component workshop gets more agent-ready, with official skills, Claude/Codex plugins, headless CLI tools, and more.
    
*   🔒 Vite has disclosed [a critical remote code execution flaw](https://javascriptweekly.com/link/192654/d076523b1d) affecting _dev_ servers exposed to the network via `--host` or `server.host`. Upgrade to 8.3.7, 8.2.5, 8.1.7, 7.3.8 or 6.4.6.
    
*   🔒 Next.js [16.4.5 and 15.5.29 fix seven security issues](https://javascriptweekly.com/link/192655/d076523b1d), including a high-severity cross-tenant cache disclosure.
    
*   🔒 Node.js [security releases are due tomorrow](https://javascriptweekly.com/link/192656/d076523b1d) (or shortly after) for the 26.x, 24.x and 22.x lines.

[Experiments with Multithreaded JavaScript](https://javascriptweekly.com/link/192657/d076523b1d "blog.arv.tools") — What would JavaScript look like if threads could share objects directly? Erik Arvidsson

[The New JavaScript Features Between V8 14.6 and 15.6](https://javascriptweekly.com/link/192660/d076523b1d "nodejs.org") — Node 27, released in alpha recently, is built on V8 15.6, and Joyee tours what that brings to developers, including `Math.sumPrecise`, new iterator methods, and some behavior changes in sorting, dates and promises, all with sample code.

Joyee Cheung

[How to Build Your Own Automated Debugging Workflow](https://javascriptweekly.com/link/192661/d076523b1d "sentry.io") — Connect your coding agent to Sentry and turn errors into fix PRs. See the guides and recipes in the resource hub.

Misaki Nakano

[Reviving Facebook's Abandoned JavaScript Optimizer](https://javascriptweekly.com/link/192663/d076523b1d "jamesbox.exe.xyz") — Prettier creator James Long put agents to work resurrecting [Prepack](https://javascriptweekly.com/link/192664/d076523b1d), Facebook's attempt to make JavaScript faster by running it ahead of time. There's [an experimental demo](https://javascriptweekly.com/link/192665/d076523b1d) that shows off the gains on a sample React app.

James Long

[Yavashark: Building a JavaScript Engine for 950 Days Straight](https://javascriptweekly.com/link/192666/d076523b1d "yavashark.dev") — A solo developer's progress report on a Rust-based engine they're building that passes around 82% of test262 and can server-render a React app. There's [a playground](https://javascriptweekly.com/link/192667/d076523b1d) to try it for yourself.

Sharktheone

📄 [A Fifth Object Shape Made the Same Loop Twice as Slow](https://javascriptweekly.com/link/192668/d076523b1d) – V8's hidden classes and inline caches in action. Mohsen Fallahnejad

📺 [ReactiveScript: Early Findings](https://javascriptweekly.com/link/192669/d076523b1d) – A lengthy stream by Solid's creator on [ReactiveScript](https://javascriptweekly.com/link/192670/d076523b1d), his experimental reactive UI language he [first shared in 2021](https://javascriptweekly.com/link/192671/d076523b1d). Ryan Carniato
