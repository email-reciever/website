[tsrs: Cloudflare and VoidZero's Rust Port of TypeScript](https://javascriptweekly.com/link/191669/d076523b1d "blog.cloudflare.com") — A Rust port of the Go-based TypeScript 7 compiler, built with [some input from the TypeScript team](https://javascriptweekly.com/link/191670/d076523b1d) and heading into [Oxc](https://javascriptweekly.com/link/191671/d076523b1d). Benchmarks claim up to 8x the speed of TypeScript 7.0 and it runs in WebAssembly. Experimental, but `npx tsrs` works.

Chen, Mitropoulos and Nakazawa (Cloudflare / VoidZero)

💡 Max Schwenk started the port with agents writing the code, and [tells the full tale here](https://javascriptweekly.com/link/191672/d076523b1d), including how it took his company's typecheck from 80 seconds to 7.

[![](https://res.cloudinary.com/cpress/image/upload/c_limit,w_480,h_480,q_auto/copm/dc7dffad.png)](https://javascriptweekly.com/link/191668/d076523b1d)

[Send Webhooks from Your TypeScript API in Minutes](https://javascriptweekly.com/link/191668/d076523b1d "link.svix.com") — One typed npm package, one call per event. Svix handles retries, signing, delivery logs, and a portal for your customers, so you don't build any of it. Resend sends 200M+ webhooks a year through it.

Svix sponsor

[Thank You, Deno: Competition Keeps JavaScript Moving](https://javascriptweekly.com/link/191673/d076523b1d "www.vlt.io") — Last week we covered [Deno joining Cloudflare](https://javascriptweekly.com/link/191674/d076523b1d) and the future of the Deno runtime. Deno was valuable, says Darcy, as it (and Bun) made the entire ecosystem better by pushing Node and npm to adopt its best ideas.

Darcy Clarke (vlt)

**IN BRIEF:**

*   🔒 [Next.js has patched two critical RCE flaws](https://javascriptweekly.com/link/191675/d076523b1d): one in `use cache` functions via an [upstream React Server Components bug](https://javascriptweekly.com/link/191676/d076523b1d) and one in the image optimizer's SVG handling. Upgrade to 16.4.1 or 15.5.28; a [public PoC](https://javascriptweekly.com/link/191677/d076523b1d) is already out.
    
*   🔒 [Node.js security releases are due tomorrow](https://javascriptweekly.com/link/191678/d076523b1d) for the 26.x, 24.x and 22.x lines, with the highest severity issue rated high.
    
*   Bun compiling JavaScript ahead-of-time, [previewed a few weeks ago](https://javascriptweekly.com/link/191679/d076523b1d), now has [a draft PR](https://javascriptweekly.com/link/191680/d076523b1d) to produce binaries with no JIT or bytecode.
    

**RELEASES:**

*   [Node.js v26.12.0 (Current)](https://javascriptweekly.com/link/191681/d076523b1d) and [v24.22.0 (LTS)](https://javascriptweekly.com/link/191682/d076523b1d) – 26.12 can now synchronously load most ES modules and marks the config file stable; 24.22 gains `util.throttle` and `util.debounce`.
    
*   [Astro 7.4](https://javascriptweekly.com/link/191683/d076523b1d) – Adds a `--timings` flag for `astro build` to see where build time is spent, plus experimental parallel prerendering across worker threads.
    
*   [React Router 8.5](https://javascriptweekly.com/link/191684/d076523b1d) – Deprecates its own view transition APIs in favor of React's &lt;`ViewTransition`\> component, and adds an experimental 'API-only' mode.
    
*   [Pretext 1.0](https://javascriptweekly.com/link/191685/d076523b1d) – Multiline text layout without touching the DOM. 1.0 ports browsers' own line breakers, so results more closely match what would render.
    
*   [React Native 0.88](https://javascriptweekly.com/link/191686/d076523b1d), [Elysia 2.0 RC](https://javascriptweekly.com/link/191687/d076523b1d), [ESLint 10.13](https://javascriptweekly.com/link/191688/d076523b1d), [tsup 9.0](https://javascriptweekly.com/link/191689/d076523b1d), [Vuetify 4.3](https://javascriptweekly.com/link/191690/d076523b1d)
