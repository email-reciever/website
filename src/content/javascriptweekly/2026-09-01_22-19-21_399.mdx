[Remix 3 RC: A Full-Stack Framework with No React Required](https://javascriptweekly.com/link/189717/d076523b1d "remix.run") — Remix's big rewrite from its previous life as a React framework into an independent full-stack framework is largely done. This post makes a good pitch, but even better is the [all-new homepage](https://javascriptweekly.com/link/189718/d076523b1d) explaining how Remix offers everything you need to build a modern webapp in 'a single package'.

💡 The final release is due on October 2 but it's more than ready to start working with.

[pnpm 12: Rewritten in Rust, Same Commands and Lockfile](https://javascriptweekly.com/link/189672/d076523b1d "pnpm.io") — The Rust rewrite is stable, and nearly all of v11's commands, flags and lockfile format carry over with only a [handful of changes](https://javascriptweekly.com/link/189673/d076523b1d). npm's `latest` tag still points to pnpm 11, though, so you'd need `pnpm self-update next-12` to upgrade.

Zoltan Kochan

**IN BRIEF:**

*   TypeScript has [landed support for import-attribute-aware ambient modules](https://javascriptweekly.com/link/189719/d076523b1d). Declarations such as `declare module "*" with &lcub; type: "css" }` can now match imports carrying that attribute.
    
*   Dani Sandoval rounds up [what's new in the Svelte world this month](https://javascriptweekly.com/link/189676/d076523b1d) including Svelte 5.57's new `SvelteMap` methods, SvelteKit 3 reaching RC, and an `ai-tools` add-on for the `sv` CLI.
    
*   Sarah Rainsberger rounds up [what's new in Astro this month](https://javascriptweekly.com/link/189677/d076523b1d) too, including Matthew Phillips taking over as 'Project Steward', and a new [Astro Playground](https://javascriptweekly.com/link/189729/d076523b1d).
    

**RELEASES:**

*   [Cypress 16](https://javascriptweekly.com/link/189720/d076523b1d), [NestJS 12](https://javascriptweekly.com/link/189681/d076523b1d), [Vue 3.6 RC6](https://javascriptweekly.com/link/189682/d076523b1d), [Deno 2.9.6](https://javascriptweekly.com/link/189683/d076523b1d), [Mocha 12.0](https://javascriptweekly.com/link/189684/d076523b1d), [Electron 44](https://javascriptweekly.com/link/189685/d076523b1d) (mentioned last week but there's now an official post).
    
*   [Node.js v26.8.0 (Current)](https://javascriptweekly.com/link/189686/d076523b1d) and [Node.js v24.20.0 (LTS)](https://javascriptweekly.com/link/189687/d076523b1d)
