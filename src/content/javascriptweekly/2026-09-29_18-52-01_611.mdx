[Still Writing Tests? Meticulous Is Here](https://javascriptweekly.com/link/190937/d076523b1d "www.meticulous.ai") — Notion, Dropbox and Wiz are now using a testing paradigm they can’t ship without. Built by former Palantir engineers, Meticulous creates an evolving suite of deterministic E2E UI tests, delivering exhaustive coverage with zero developer effort.

Meticulous AI sponsor

[Vite+ 1.0: One CLI for Your Entire JavaScript Toolchain](https://javascriptweekly.com/link/190939/d076523b1d "voidzero.dev") — The single `vp` command can now manage your Node runtime (if you wish), package manager, dev server, linting, formatting, testing, builds and task running, configured from `vite.config.ts`. [`vp migrate`](https://javascriptweekly.com/link/190940/d076523b1d) can be used to bring existing Vite, Vitest, ESLint, tsup, and similar setups into Vite+.

VoidZero

💡 Evan You also [looks back at four months of VoidZero at Cloudflare](https://javascriptweekly.com/link/190941/d076523b1d), including work on the Oxc React Compiler, Vitest 5, stable type-aware linting, and more.

**IN BRIEF:**

*   The [latest TC39 meeting](https://javascriptweekly.com/link/190942/d076523b1d) is taking place in Tokyo now, and three iterator proposals have already advanced to stage 4: [chunking](https://javascriptweekly.com/link/190943/d076523b1d), [join](https://javascriptweekly.com/link/190944/d076523b1d) and [includes](https://javascriptweekly.com/link/190945/d076523b1d) (the latter just [shipped in Chrome 154](https://javascriptweekly.com/link/190946/d076523b1d)).
    
*   Jarred Sumner shared [𝕏 a preview of Bun compiling JavaScript ahead of time](https://javascriptweekly.com/link/190947/d076523b1d): 24% faster startup and 48% less memory for Claude Code, but ~2x binary size.
    
*   🎉 Cloudflare _finally_ has [a single CLI for all of its APIs](https://javascriptweekly.com/link/190948/d076523b1d). `cf` is written in TypeScript and covers everything, whereas Wrangler only ever covered a subset.
    
*   The Angular team is [building a partly Rust-powered compiler](https://javascriptweekly.com/link/190949/d076523b1d), because TypeScript 7's Go port lacks APIs the current one relies on.
    

**RELEASES:**

*   [MSW (Mock Service Worker) 3.0](https://javascriptweekly.com/link/190950/d076523b1d) – The popular API mocking library is now ESM-only, adds a Vite plugin, supports GraphQL subscriptions, and can intercept page navigations and form submissions.
    
*   [Vinext 1.0](https://javascriptweekly.com/link/190951/d076523b1d) – Cloudflare's Vite-based Next.js reimplementation now supports the Pages and App Routers, and offers a migration path for existing apps.
    
*   [Mermaid 12.0](https://javascriptweekly.com/link/190952/d076523b1d) – The diagramming tool now defaults to the ELK layout engine for flowchart, class, state and similar diagrams, so existing ones will look different unless you set `layout: dagre`. Also adds [UML use case diagrams](https://javascriptweekly.com/link/190953/d076523b1d).
    
*   [pnpm 12.8](https://javascriptweekly.com/link/190954/d076523b1d), [Angular 22.2](https://javascriptweekly.com/link/190955/d076523b1d), [TinyBase 10](https://javascriptweekly.com/link/190956/d076523b1d), [QUnit 3.0](https://javascriptweekly.com/link/190957/d076523b1d)

[Optimizing Objects with `null` Prototypes](https://javascriptweekly.com/link/190961/d076523b1d "adventures.nodeland.dev") — In V8, objects created with `&lcub; __proto__: null }` or `Object.create(null)` start in a slower 'dictionary mode'. Flavio Copes

📄 [JavaScript's Greatest Pun? `$&lcub;&lcub; }}`](https://javascriptweekly.com/link/190964/d076523b1d) – Looks like Mustache, but `$&lcub;&lcub; name }}` passes an object using shorthand properties to a tag function, preserving both the variable's name and value. Nishant Shukla
