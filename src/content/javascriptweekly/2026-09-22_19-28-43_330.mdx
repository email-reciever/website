[tinyjs: Build JavaScript Desktop Apps in &lt;10MB](https://javascriptweekly.com/link/190636/d076523b1d "tinyjs.app") — I built an app with this and was impressed. You get a [txiki.js](https://javascriptweekly.com/link/190637/d076523b1d)\-powered backend with full system access (including FFI!), native webview rendering, and tiny macOS, Linux, and Windows builds. It even makes it easy to sign/notarize the final app.

Tarwin Stroh-Spijer

There are lots of great options in this space though:

*   [Electrobun](https://javascriptweekly.com/link/190638/d076523b1d) offers richer multi-window and GPU features, at the cost of a larger TypeScript runtime – though it can instead use Zig, Rust, Go, or Odin for a tiny native main process.
    
*   [Perry](https://javascriptweekly.com/link/190639/d076523b1d) is a TypeScript to native AOT compiler whose primary UI model renders AppKit, Win32 and GTK4 widgets for a more conventionally native feel.
    
*   [Electron](https://javascriptweekly.com/link/190640/d076523b1d) and the experimental [Deno Desktop](https://javascriptweekly.com/link/190695/d076523b1d) are powerful, but their executables typically run several times larger.
    
*   [Neutralinojs](https://javascriptweekly.com/link/190642/d076523b1d) apps can be even smaller than tinyjs's, but you lose the general-purpose JavaScript privileged backend by design.
    

[![](https://res.cloudinary.com/cpress/image/upload/c_limit,w_480,h_480,q_auto/copm/5c853e9e.png)](https://javascriptweekly.com/link/190635/d076523b1d)

[Full-Text Search in Drizzle Without a Second System](https://javascriptweekly.com/link/190635/d076523b1d "github.com") — Try the official ParadeDB integration for Drizzle. Search your live Postgres tables. No ETL, no Elasticsearch. ParadeDB cloud coming soon.
